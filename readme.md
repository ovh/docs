# OVHcloud Documentation (archived)

> [!IMPORTANT]
> **This repository is archived and no longer maintained.**
>
> The OVHcloud documentation has moved to **[ovh/ovhcloud-docs](https://github.com/ovh/ovhcloud-docs)**,
> and the website has moved from <https://help.ovhcloud.com/csm> to **<https://docs.ovhcloud.com>**.
> All guides in this repository have been migrated, and every legacy URL now redirects to its new location.
>
> **New contributions must be made to [ovh/ovhcloud-docs](https://github.com/ovh/ovhcloud-docs)**, not here.
> Pull requests and issues opened on this repository will not be reviewed or merged.

This repository contained all the public documentation about OVHcloud products, in 7 languages. It is kept online for historical reference only.
