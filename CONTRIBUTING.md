# How to contribute to OVHcloud documentation

> [!IMPORTANT]
> **This repository is archived and is no longer accepting contributions.**

The OVHcloud documentation has moved to **[ovh/ovhcloud-docs](https://github.com/ovh/ovhcloud-docs)**, and the website has moved from <https://help.ovhcloud.com/csm> to **<https://docs.ovhcloud.com>**.

Please open your pull request against **[ovh/ovhcloud-docs](https://github.com/ovh/ovhcloud-docs)** and follow the contribution guidelines there: **[CONTRIBUTING.md](https://github.com/ovh/ovhcloud-docs/blob/develop/CONTRIBUTING.md)**.

Pull requests and issues opened on this repository will not be reviewed or merged.
