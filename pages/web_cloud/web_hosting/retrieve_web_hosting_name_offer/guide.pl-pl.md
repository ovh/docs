## Wprowadzenie

Nie pamiętasz nazwy swojej [oferty hostingu](/links/web/hosting) ?
Chcesz sprawdzić jej szczegóły lub porównać ją z inną ofertą ?

W trakcie korzystania z usług może się zdarzyć, że będziesz potrzebował nazwy swojej oferty hostingu.

**Dowiedz się, jak zidentyfikować typ oferty hostingu, której aktualnie korzystasz w Panelu klienta OVHcloud.**

## Wymagania początkowe

- Posiadanie [oferty hostingu](/links/web/hosting).
- Zalogowanie się do [Panelu klienta OVHcloud](/links/manager).

## W praktyce

Kliknij poniższe zakładki, aby wyświetlić kolejne **3** kroki.

> [!tabs]
> **Krok 1**
>>
>> Zaloguj się do [Panelu klienta OVHcloud](/links/manager) i przejdź do sekcji `Web Cloud`{.action}.
>>
>> ![Web Cloud](/pages/assets/screens/control_panel/product-selection/web-cloud.png){.thumbnail}
>>
> **Krok 2**
>>
>> Kliknij menu `Hosting`{.action}, następnie wybierz odpowiedni hosting.
>>
>> ![Web Hosting](/pages/assets/screens/control_panel/product-selection/web-cloud/hosting-plans.png){.thumbnail}
>>
> **Krok 3**
>>
>> W sekcji **Abonament**, znajdziesz wpis **Pakiet**.
>>
>> ![Plan](/pages/assets/screens/control_panel/product-selection/web-cloud/web-hosting/general-information/find-plan-pro.png){.thumbnail}
>>
>> Pod tą nazwą znajdziesz nazwę oferty hostingu (np. Perso, Pro, Performance, itd.).
