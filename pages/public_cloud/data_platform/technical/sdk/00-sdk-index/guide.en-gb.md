## Objective

ForePaaS provides three SDKs to be used according to your development needs.

| SDK   | Language | Main context of use |
| :---- | :------: | :------------- |
| [Custom Actions](/pages/public_cloud/data_platform/technical/sdk/dpe/00-dpe-index) | Python | [Integrated Jupyter Notebooks](/pages/public_cloud/data_platform/product/ml/notebooks/00-notebooks-index) & [DPE Custom Actions](/pages/public_cloud/data_platform/product/dpe/actions/custom/00-custom-index)|
| [Front APP](/pages/public_cloud/data_platform/technical/sdk/app/00-app-index) | ReactJS | To create your unique Dashboards |
| [Front API](/pages/public_cloud/data_platform/technical/sdk/api/00-api-index) | NodeJS | To customize API used by Front App to access your Projects |
