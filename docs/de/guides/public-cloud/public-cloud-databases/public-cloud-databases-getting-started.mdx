## Objective

OVHcloud Databases as-a-service (DBaaS) allow you to focus on building and deploying cloud applications while OVHcloud takes care of the database infrastructure and maintenance.

**This guide explains how to order a database solution in the OVHcloud Control Panel.**

## Requirements

- Access to the [OVHcloud Control Panel](/links/manager)
- A [Public Cloud project](/links/public-cloud/public-cloud) in your OVHcloud account

## Instructions

Log in to your [OVHcloud Control Panel](/links/manager) and switch to the `Public Cloud` section. After selecting your Public Cloud project, click on `Databases` in the left-hand navigation bar under **Databases & Analytics**.

> [!info]
>
> - Clicking on `Data Streaming` will give you access to `Kafka`, `Kafka Connect` and `KafkaMirrorMaker` services.
> - Clicking on `Data Analysis` will give you access to `Dashboards` and `OpenSearch` services.
>

Click on the button `Create a database instance`. (`Create a service` if your project already contains databases.)

### Step 1: Select your database type

Click on the type of database you want to use and then select the version to install from the respective drop-down menu.

![Choose database](/images/guides/public-cloud/public-cloud-databases/databases-01-order-control-panel/databases_01_order_control_panel-20231208145850.png)

### Step 2: Select a Plan

Choose an appropriate service plan. You will be able to upgrade the plan after creation.

Please visit the [capabilities page](/guides/public-cloud/public-cloud-databases/overview) of your selected database type for detailed information on each plan's properties.

![Choose plan](/images/guides/public-cloud/public-cloud-databases/databases-01-order-control-panel/databases_01_order_control_panel-20231208150215.png)

### Step 3: Select a location

Choose the geographical region of the data centre in which your database will be hosted.

![Choose region](/images/guides/public-cloud/public-cloud-databases/databases-01-order-control-panel/databases_01_order_control_panel-20231208150326.png)

### Step 4: Configure database nodes

You can choose the node template in this step.

![Order nodes](/images/guides/public-cloud/public-cloud-databases/databases-01-order-control-panel/databases_01_order_control_panel-20231208150805.png)

Please visit the [capabilities page](/guides/public-cloud/public-cloud-databases/overview) of your selected database type for detailed information on the hardware resources and other properties of the database installation.

Take note of the pricing information.

### Step 5: Sizing

Additional storage can be ordered and, depending on the engine, the number of nodes in your cluster can be adjusted:

![Sizing](/images/guides/public-cloud/public-cloud-databases/databases-01-order-control-panel/databases_01_order_control_panel-20230414151211.png)

### Step 6: Configure your options

Define your network configuration:

![Configure options](/images/guides/public-cloud/public-cloud-databases/databases-01-order-control-panel/databases_01_order_control_panel-20230414151536.png)

#### Connecting a private network (optional)

![Attach network](/images/guides/public-cloud/public-cloud-databases/databases-01-order-control-panel/databases_01_order_control_panel-20230414152851.png)

If you already have a private subnet available, check the box **Private** and select it from the drop-down menu. Note that this option might not be available for the selected service type.

You can be forwarded to create a private network or subnet by clicking on the respective links. You will have to start the database order process anew in that case.

Please follow [this guide](/guides/public-cloud/public-cloud-network-services/public-cloud-network-services-vrack) for detailed instructions.

### Step 7: Summary and confirmation

The final section will display a summary of your order as well as the API equivalent of creating this database instance with the [OVHcloud API](/guides/manage-and-operate/api/first-steps).

![Confirm order](/images/guides/public-cloud/public-cloud-databases/databases-01-order-control-panel/databases_01_order_control_panel-20231208153010.png)

Within a few minutes your new database service will be deployed. Messages in the OVHcloud Control Panel will inform you when the database is ready to use.

Continue with the *Configure your instance to accept incoming connections* guide of your selected database type available [here](/guides/public-cloud/public-cloud-databases/overview) to configure your service after installation.

Note that the configuration options might be different, depending on the database type. You will find example on this repository: [https://github.com/ovh/public-cloud-databases-examples](https://github.com/ovh/public-cloud-databases-examples).
