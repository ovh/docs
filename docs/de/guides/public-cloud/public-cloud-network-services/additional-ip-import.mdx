Seit dem 6. Oktober 2022 heißt unser Dienst "Failover-IP" nun [Additional IP](https://www.ovhcloud.com/de/network/additional-ip/). Die Namensänderung hat keine Auswirkungen auf dessen technische Funktionen.

:::


## Ziel

Es gibt verschiedene Gründe, auf Ihrer Instanz eine Additional IP-Adresse zu konfigurieren:

- Sie verwalten mehrere Webseiten auf Ihrer Instanz.
- Sie hosten internationale Projekte.
- Sie möchten von einem Dedicated Server zu einer Public Cloud Instanz migrieren.

Im OVHcloud Kundencenter können Sie eine Additional IP-Adresse, die mit einem anderen OVHcloud Dienst verknüpft ist, einfach Ihrem Projekt zuordnen.

**In dieser Anleitung wird erläutert, wie Sie eine Additional IP in Ihr OVHcloud Public Cloud Projekt importieren.**

## Voraussetzungen

- Sie haben ein [Public Cloud Projekt](https://www.ovhcloud.com/de/public-cloud) in Ihrem Kunden-Account.
- Sie verfügen über eine [Additional IP-Adresse](https://www.ovhcloud.com/de/bare-metal/ip/).

## In der praktischen Anwendung

Öffnen Sie im linken Menü <code className="action">Öffentliche IPs</code> unter **Network**.

Öffnen Sie den Tab <code className="action">Additional IP</code> und klicken Sie auf den Button <code className="action">Aktionen</code>. Wählen Sie <code className="action">Eine Additional IP importieren</code>, um alle IP-Adressen anzuzeigen, die in Ihr Public Cloud Projekt importiert werden können.

<img className="thumbnail" alt="Import Additional IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-import/import22_01.png" loading="lazy" />

Wenn Sie noch keine Additional IP-Adresse für Ihr Public Cloud Projekt haben, wird die Import-Option für Additional IPs auf der Startseite angezeigt.

Klicken Sie auf <code className="action">...</code> in der Zeile der IP-Adresse, die Sie importieren möchten, und klicken Sie auf <code className="action">Diese Additional IP importieren</code>.

<img className="thumbnail" alt="Import Additional IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-import/import22_02.png" loading="lazy" />

Bestätigen Sie, indem Sie auf <code className="action">Importieren</code> klicken.

<img className="thumbnail" alt="Import Additional IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-import/import22_03.png" loading="lazy" />

Nach einigen Minuten ist der Import abgeschlossen. Öffnen Sie den Tab <code className="action">Additional IP</code>, um die importierte Additional IP-Adresse zu sehen. Aktualisieren Sie die Seite falls nötig.

Klicken Sie rechts auf <code className="action">...</code> und wählen Sie <code className="action">Verbundene Instanz bearbeiten</code>.

<img className="thumbnail" alt="Import Additional IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-import/import22_04.png" loading="lazy" />

Im neu angezeigten Fenster kann die Instanz ausgewählt werden, der die IP-Adresse zugewiesen werden soll.

<img className="thumbnail" alt="Import Additional IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-import/import22_05.png" loading="lazy" />

Klicken Sie auf <code className="action">Verbinden</code>, um zu bestätigen. Im Interface wird nun eine Änderungsmeldung angezeigt.

:::warning
Eine Additional IP kann nicht von einer Länderzone zur anderen umgezogen werden. So kann beispielsweise eine IP-Adresse von SBG nach GRA oder RBX umgezogen werden, aber nicht nach BHS. 

:::


Ihre Additional IP-Adresse wird nun mit Ihrer Instanz verbunden.

Im nächsten Schritt muss die IP-Adresse in Ihrem Betriebssystem konfiguriert werden. Lesen Sie dazu unsere [Anleitung zur IP-Konfiguration](/guides/public-cloud/public-cloud-network-services/getting-started-04-configure-additional-ip-to-instance/).
