## Ziel

Der Zugriff auf Horizon und die OpenStack API erfolgt über Benutzername/Passwort-Kombinationen, die als "OpenStack User" bezeichnet werden. Sie können so viele OpenStack User wie nötig erstellen und ihnen verschiedene Zugriffsrechte zuweisen.

Mithilfe des Horizon-Interface kann jedem Benutzer ein Passwort zugewiesen werden. Beachten Sie, dass mit dem Ändern eines Benutzer-Passworts die bisherigen Login-Daten unmittelbar deaktiviert werden.

**Diese Anleitung erklärt, wie OpenStack-Benutzer über das OVHcloud Kundencenter und das Horizon-Interface verwaltet werden.**

## In der praktischen Anwendung

### Erstellung eines OpenStack Benutzers

Klicken Sie auf <code className="action">User und Rollen</code> im linken Menü unter **Einstellungen**.

Klicken Sie auf den Button <code className="action">Benutzer erstellen</code>.

<img className="thumbnail" alt="User roles" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/users_roles.png" loading="lazy" />

Die "Beschreibung des Benutzers", die Sie hier eingeben können ist nicht der Benutzername für den OpenStack User, sondern eine erläuternde Bezeichnung, um Ihnen bei der Organisation der Benutzer und deren Berechtigungen zu helfen. Geben Sie eine Beschreibung für den Benutzer ein und klicken Sie auf <code className="action">Weiter</code>.

<img className="thumbnail" alt="Add user" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/adduser.png" loading="lazy" />

Sie können nun Rollen auswählen, welche die Berechtigungen repräsentieren, die der Benutzer erhalten soll. Für jedes angehakte Feld erhält der Benutzer Zugriffsrechte gemäß der nachstehenden Tabelle.

<img className="thumbnail" alt="Berechtigungen" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/permissions.png" loading="lazy" />

Klicken Sie auf <code className="action">Bestätigen</code>, um den OpenStack Benutzer zu erstellen. Der Benutzername und das Passwort werden automatisch erzeugt und in Ihrem Kundencenter angezeigt.

<img className="thumbnail" alt="User_pw" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/user_pw.png" loading="lazy" />

Achten Sie darauf, das Passwort, das nur zu diesem Zeitpunkt im grünen Rahmen angezeigt wird, in einem Passwortmanager zu speichern. Das Passwort kann später nicht mehr abgerufen werden. Sie können jedoch stets ein neues Passwort erstellen, indem Sie auf <code className="action">...</code> klicken und <code className="action">Passwort neu generieren</code> auswählen.

<img className="thumbnail" alt="Generate" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/generatepw.png" loading="lazy" />

Sobald der OpenStack User erstellt ist, können Sie seine Zugangsdaten für den Login zum [Horizon Interface](/guides/public-cloud/public-cloud-cross-functional/introducing-horizon/) verwenden, indem Sie im linken Menü auf den Eintrag <code className="action">Horizon</code> klicken.

### Passwörter von OpenStack-Benutzern verwalten

Nachdem Sie sich bei [OpenStack Horizon](https://horizon.cloud.ovh.net) eingeloggt haben, können Sie ein OpenStack-Passwort erstellen:

<img className="thumbnail" alt="Login Horizon" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/1_H_login_window.png" loading="lazy" />

Die Benutzerkennung für Horizon sehen Sie oben rechts im Horizon-Interface. Klicken Sie auf die Kennung, um im Menü alle Optionen zu sehen.  
Wählen Sie <code className="action">Settings</code> und dann links <code className="action">Change password</code>.

<img className="thumbnail" alt="Passwort ändern" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/2_H_pass_change_option.png" loading="lazy" />

Tragen Sie im ersten Feld Ihr aktuelles Passwort und in den beiden folgenden Feldern Ihr neues Passwort ein.

:::info
Beachten Sie beim Ändern des Passworts folgende Richtlinie:

- Das Passwort muss mindestens 8 Zeichen umfassen.
- Es darf maximal 30 Zeichen umfassen.
- Es muss mindestens einen Großbuchstaben enthalten.
- Es muss mindestens einen Kleinbuchstaben enthalten.
- Es muss mindestens eine Zahl enthalten.
- Es darf nur aus Zahlen und Buchstaben bestehen.

:::


Bestätigen Sie anschließend das neue Passwort, indem Sie auf <code className="action">Change</code> klicken.

<img className="thumbnail" alt="Neues Passwort erstellen" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/3_H_set_new_passord.png" loading="lazy" />

Beachten Sie, dass beim Ändern des Benutzerkonto-Passworts die bisherigen Login-Daten sofort gelöscht werden.

### Löschung eines OpenStack Benutzers

Klicken Sie auf <code className="action">User und Rollen</code> im linken Menü unter **Einstellungen**.

<img className="thumbnail" alt="public-cloud" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/delete.png" loading="lazy" />

Klicken Sie auf <code className="action">...</code> und wählen Sie <code className="action">Löschen</code> aus.

:::warning
Die Löschung eines Benutzers ist endgültig und führt zur Ungültigkeit aller zugehörigen Token, auch derjenigen, deren Ablaufdatum noch nicht überschritten ist.

:::
