## Ziel

Das Erstellen eines Projekts ist die Voraussetzung, um [Public Cloud Instanzen](https://www.ovhcloud.com/de/public-cloud/) verwenden zu können.

**Diese Anleitung erklärt die Schritte zur Erstellung Ihres ersten Public Cloud Projekts.**

## Voraussetzungen

### Zugriff auf das OVHcloud Kundencenter

- **Direkter Link:** [Public Cloud Projekte](https://manager.eu.ovhcloud.com/#/pci/projects)
- **Navigationspfad:** <code className="action">Public Cloud</code> > Wählen Sie Ihr Projekt aus

## In der praktischen Anwendung

Nachdem Sie die Vertragsbedingungen gelesen haben, bestätigen Sie diese, indem Sie das entsprechende Kästchen ankreuzen und auf <code className="action">Das Public-Cloud-Universun entdecken</code> klicken.

<img className="thumbnail" alt="Projekt erstellen" src="/images/public-cloud/public-cloud-cross-functional/create-a-public-cloud-project/firstproject2024.png" loading="lazy" style={{ maxWidth: '400px' }} />

- Wenn Sie noch kein gültiges Zahlungsmittel in Ihrem OVHcloud Account haben, beginnt direkt der Erstellungsprozess des Public Cloud Projekts. Ihr Projekt wird dann zunächst im [Discovery-Modus](#discovery) erstellt.
- Wenn Sie bereits eine Zahlungsart in Ihrem OVHcloud Account hinterlegt haben, können Sie Ihr Public Cloud Projekt benennen und dann Ihre Zahlungsart auswählen.

<img className="thumbnail" alt="Projekt erstellen" src="/images/public-cloud/public-cloud-cross-functional/create-a-public-cloud-project/project-creation.png" loading="lazy" style={{ maxWidth: '400px' }} />

Sobald der Erstellungsprozess abgeschlossen ist, wird Ihr neues Public Cloud Projekt oben links im Bereich <code className="action">Public Cloud</code> Ihres OVHcloud Kundencenters angezeigt:

<img className="thumbnail" alt="Neues Projekt erstellt" src="/images/public-cloud/public-cloud-cross-functional/create-a-public-cloud-project/pci-interface-2025.png" loading="lazy" style={{ maxWidth: '400px' }} />

Sie haben ab sofort Zugriff auf das gesamte OVHcloud Public Cloud Ökosystem. Entdecken Sie mehr über dieses Interface in Ihrem Kundencenter in unserer Anleitung "[Einführung in das Public Cloud Interface](/guides/public-cloud/public-cloud-cross-functional/03-public-cloud-interface-walk-me/)".

<a name="discovery"></a>

:::info
**Discovery-Modus**

Wenn es sich um Ihr erstes Public Cloud Projekt handelt und Sie keine Zahlungsart in Ihrem Account angegeben haben, ist Ihr Public Cloud Projekt auf den Discovery-Modus des OVHcloud Kundencenters beschränkt. Das bedeutet, dass Sie Zugang zur Public Cloud Oberfläche haben und die verfügbaren Dienste sehen können, aber noch keine Ressourcen wie etwa Instanzen erstellen können.

Um das volle Potenzial der Public Cloud auszuschöpfen und Ihre ersten Ressourcen zu verwenden, klicken Sie auf der Startseite Ihres Projekts auf <code className="action">Projekt aktivieren</code>.

:::
