## Ziel

Das OpenStack Horizon-Interface bietet Optionen zur Konfiguration des Zugriffs auf Ihre Instanzen und andere Dienste.<br />
Sie können zum Beispiel Sicherheitsgruppen definieren, um ein- und ausgehende Verbindungen zu filtern, oder eine OpenRC-Datei herunterladen, die Zugangsdaten für die OpenStack API enthält.

## In der praktischen Anwendung

Loggen Sie sich im [Horizon-Interface](https://horizon.cloud.ovh.net/auth/login/) ein.

Die Zugriffs- und Sicherheitseinstellungen bestehen aus den folgenden Abschnitten, die über das Menü links zugänglich sind:

- **API Access** (unter `Project`)

Die Tabelle unter "API Access" listet die Service-Endpunkte der OpenStack API auf.

![Sicherheit Horizon](/images/guides/public-cloud/public-cloud-cross-functional/access-and-security-in-horizon/api_access.png)

Um die Werte für den API-Zugriff einzusehen, klicken Sie auf `View Credentials`.

Über den Button `Download OpenStack RC File` öffnen Sie ein Untermenü, aus dem Sie die passende RC-Datei zum Download auswählen können.

- **Key Pairs** (unter `Project` / `Compute`)

In diesem Bereich können Sie SSH-Schlüsselpaare anlegen und verwalten. Sie können einfach einen öffentlichen und einen privaten Schlüssel erstellen und hinzufügen, indem Sie auf die Schaltfläche `Create Key Pair` klicken.

![Sicherheit Horizon](/images/guides/public-cloud/public-cloud-cross-functional/access-and-security-in-horizon/key_pairs.png)

Wenn Sie einen vorhandenen Schlüssel hinzufügen möchten, klicken Sie auf `Import Public Key`. Im Popup-Fenster können Sie dann den Schlüssel direkt oder über eine Datei hinzufügen.

Dieser Teil der Benutzeroberfläche enthält einige grundlegende Anweisungen; ausführlichere Informationen zu SSH-Schlüsseln finden Sie in [dieser Anleitung](/guides/public-cloud/compute/compute-creating-ssh-keys).

- **Security Groups** (unter `Project` / `Network`)

Sicherheitsgruppen bestehen aus Filterregeln, die auf Netzwerkschnittstellen angewendet werden. Sie können sie verwenden, um den Zugriff auf Instanzen nach IP-Adressen und Ports zu verwalten.

![Sicherheit Horizon](/images/guides/public-cloud/public-cloud-cross-functional/access-and-security-in-horizon/security_groups.png)

Fügen Sie eine Sicherheitsgruppe mit dem Button `Create Security Group` hinzu. Anschließend können Sie über `Manage Rules` in der Tabelle angepasste oder vorkonfigurierte einrichten.
