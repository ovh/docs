## Ziel

Zusätzlich zum OVHcloud Kundencenter können Sie Ihre OVHcloud Public Cloud Projekte auch über das [Horizon-Interface](https://horizon.cloud.ovh.net/auth/login/) verwalten. In diesem Interface finden Sie alle Ihre Infrastruktur- (Instanzen, Backups, Festplatten, SSH-Schlüssel usw.) und Storage-Projekte (einschließlich der Liste Ihrer Container).

**Diese Anleitung erklärt, wie Sie Ihre Public Cloud Instanzen über das Horizon-Interface verwalten.**

## Voraussetzungen

- Sie haben eine Public Cloud Instanz über Ihr [OVHcloud Kundencenter](/guides/public-cloud/compute/first-steps-with-public-cloud-instance/) oder über das [Horizon-Interface](/guides/public-cloud/compute/create-instance-in-horizon/) erstellt.
- Sie haben einen [SSH-Schlüssel erstellt](/guides/public-cloud/compute/compute-creating-ssh-keys/).

## In der praktischen Anwendung

### Zugriff auf das Verwaltungsinterface der Instanz

Loggen Sie sich zunächst im [Horizon-Interface](https://horizon.cloud.ovh.net/auth/login/) ein.

Anders als im OVHcloud Kundencenter unterscheidet Horizon Ihre Dienste je nach Region. Sie können die Region im Menü oben links auswählen:

<img className="thumbnail" alt="public-cloud" src="/images/public-cloud/compute/managing-instances-horizon/region2021.png" loading="lazy" />

Klicken Sie links im Menü auf <code className="action">Compute</code> und wählen Sie dann <code className="action">Instances</code> aus. Auf der angezeigten Seite finden Sie eine Zusammenfassung aller Ihrer Instanzen. Hier werden folgende Informationen angezeigt:

- Das Modell Ihrer Instanz (*Flavor*)
- Namen, Stromversorgungszustand (Power State) und die seit Erzeugung verstrichene Zeit (*Time since created*) der Instanz
- IPv4- und IPv6-Adresse Ihrer Instanz
- Zugehöriges privates Netzwerk und private IPv4-Adresse
- Status der Instanz
- Das für die Installation der Instanz verwendete Image (falls zutreffend)

<img className="thumbnail" alt="public-cloud" src="/images/public-cloud/compute/managing-instances-horizon/options2022.png" loading="lazy" />

**Launch Instance** 

Mit dieser Option können Sie eine Instanz erstellen. Weitere Informationen finden Sie in [dieser Anleitung](/guides/public-cloud/compute/create-instance-in-horizon/).

**Delete Instances**

Mit dieser Option können Sie mehrere Instanzen gleichzeitig löschen. Setzen Sie einfach einen Haken links des Instanznamens.

**More Actions**

In diesem Menü können Sie die folgenden Aktionen auf einer oder mehreren Instanzen ausführen. Vergewissern Sie sich zunächst, dass Sie den Haken links vom Namen der Instanz setzen:

- Start Instances: Mit dieser Option können Sie eine oder mehrere Instanzen im Status *shutoff* oder *off* neu starten.
- Shut Off Instances: Mit dieser Option können eine oder mehrere Instanzen gesperrt werden.
- Soft Reboot Instances: Mit dieser Option können Sie einen Software-Neustart auf einer oder mehreren Instanzen durchführen.

**Create Snapshot**: Mit dieser Option können Sie einen Snapshot Ihrer Instanz erstellen. Weitere Informationen finden Sie in [dieser Anleitung](/guides/public-cloud/compute/managing-snapshots-in-horizon/).

### Instanz bearbeiten

Wählen Sie im Verwaltungsinterface der Instanz die gewünschte Option aus der Drop-down-Liste.

<img className="thumbnail" alt="public-cloud" src="/images/public-cloud/compute/managing-instances-horizon/list2022.png" loading="lazy" />

- Attach Interface: Mit dieser Option können Sie über das VLAN eine oder mehrere private Interfaces zu Ihrer Instanz hinzufügen. Weitere Informationen finden Sie in [diesem Abschnitt](/guides/public-cloud/public-cloud-network-services/getting-started-07-creating-vrack#ein-privates-interface-hinzufugen/) der vRack-Anleitung.
- Detach Interface: Diese Option ermöglicht das Abtrennen einer Schnittstelle, die mit einer Instanz verbunden ist. Weitere Informationen finden Sie in [diesem Abschnitt](/guides/public-cloud/public-cloud-network-services/getting-started-07-creating-vrack#loschung-eines-interfaces/) der vRack-Anleitung.
- Edit Instance: Mit dieser Option können Sie den Namen der Instanz und die [Sicherheitsgruppen ändern](/guides/public-cloud/compute/setup-security-group/).

:::warning
Die rot markierten Optionen geben an, ob während des Vorgangs Datenverlust möglich ist. Stellen Sie sicher, dass Sie immer über ein Backup Ihrer Daten verfügen, bevor Sie Änderungen an Ihrer Instanz vornehmen.

:::


### Änderung der Größe einer Instanz

Mit der Public Cloud können Sie die Ressourcen Ihrer Instanz mit nur wenigen Klicks erhöhen.

:::warning
Bei klassischen Modellen ist nur die Umstellung auf ein größeres Modell möglich.  
Beachten Sie weiterhin, dass der Betrieb der Instanz während der Operation unterbrochen wird.

:::


:::tip[Success]
*Flex*-Instanzen erlauben die Anpassung auf höhere oder niedrigere Modelle aufgrund einer festen Größe einer einzelnen Disk.

:::


Ausführliche Informationen finden Sie in der folgenden Anleitung: [Änderung der Größe einer Instanz mit Horizon](/guides/public-cloud/compute/resize-of-an-instance/).

### Instanz rekonstruieren

Mit dieser Option können Sie Ihre Instanz auf einer neuen Basis rekonfigurieren oder einfach das Betriebssystem wechseln.

:::danger
Hierbei werden die Daten der Instanz gelöscht.

:::


Wählen Sie <code className="action">Rebuild Instance</code> in der Drop-down-Liste der Instanz aus.

<img className="thumbnail" alt="public-cloud" src="/images/public-cloud/compute/managing-instances-horizon/rebuildinstance.png" loading="lazy" />

Wählen Sie das Image für die Rekonstruktion aus.  
Wählen Sie den Partitionstyp ("Automatisch" oder "Manuell") aus. Dies ist optional.  
Klicken Sie abschließend auf <code className="action">Rebuild Instance</code>. Diese Operation kann einige Minuten dauern.

### Aussetzen oder Pausieren einer Instanz (Shelve or pause an instance)

Um zu erfahren, wie Sie eine Instanz aussetzen oder pausieren, klicken Sie [hier](/guides/public-cloud/compute/suspend-or-pause-an-instance/), um die Anleitung zu diesen Funktionen einzusehen.

### Zugriff auf die Konsole einer Instanz <a name="console"></a>

Bei Verlust des Zugangs zu Ihrer Instanz aufgrund einer fehlerhaften Konfiguration oder einer Unterbrechung des SSH-Dienstes können Sie Ihre Instanz jederzeit mithilfe der VNC-Konsole rekonfigurieren.

:::info
Sie können direkt über die VNC-Konsole auf Ihre Instanz zugreifen. Sie müssen jedoch zuerst ein Passwort für den Root-Benutzer konfigurieren.  
Weitere Informationen finden Sie in [dieser Anleitung](/guides/public-cloud/compute/public-cloud-first-steps#user-mgmt/).  
Die VNC-Konsole kann auch als erster Diagnose-Ansatz bei einer Fehlfunktion verwendet werden, indem die Bootphase Ihrer Instanz analysiert wird.

:::


Wählen Sie in der Drop-down-Liste der Instanz <code className="action">Console</code>.

<img className="thumbnail" alt="public-cloud" src="/images/public-cloud/compute/managing-instances-horizon/accessconsole.png" loading="lazy" />

Die Konsole der Instanz wird angezeigt.

:::tip[Success]
Wenn die Konsole nicht mehr auf die Tastatureingaben antwortet, klicken Sie auf die Statusleiste.  
Um den Vollbildschirmmodus zu verlassen, klicken Sie auf den Button "Zurück zum Browser".

:::


**Konsole der Instanz**

<img className="thumbnail" alt="public-cloud" src="/images/public-cloud/compute/managing-instances-horizon/console.png" loading="lazy" />

### Instanz neu starten

Es gibt zwei Methoden, um eine Instanz neu zu starten:

- Soft Reboot Instance (Software)
- Hard Reboot Instance (Hardware)

Wählen Sie in der Drop-down-Liste der Instanz entweder <code className="action">Soft Reboot Instance</code> oder <code className="action">Hard Reboot Instance</code>.

<img className="thumbnail" alt="public-cloud" src="/images/public-cloud/compute/managing-instances-horizon/rebootinstance.png" loading="lazy" />

Bestätigen Sie anschließend Ihre Anfrage im angezeigten Fenster.

### Instanz löschen

Wenn Sie eine Ihrer Instanzen nicht mehr benötigen, können Sie diese jederzeit löschen.

:::danger
Die Daten auf der Instanz werden gelöscht.  
Sie können auch ein Backup dieser Instanz erstellen, wenn Sie die Daten speichern und eine identische Instanz später neu starten möchten.

Wenn Sie eine Instanz löschen, werden nicht automatisch alle zugehörigen Optionen gelöscht (z.B. Storage, Snapshot, Backup). Stellen Sie sicher, dass alle Optionen, die mit der Instanz verbunden sind, ebenfalls gelöscht werden, um deren Abrechnung zu stoppen.

:::


Wählen Sie in der Drop-down-Liste der Instanz <code className="action">Delete Instance</code>. 

<img className="thumbnail" alt="public-cloud" src="/images/public-cloud/compute/managing-instances-horizon/deleteinstance.png" loading="lazy" />

Klicken Sie anschließend auf <code className="action">Confirm</code>, um den Vorgang zu starten.

:::tip[Success]
Wenn Sie die Instanz gelöscht haben, werden Ihnen keine Kosten mehr berechnet und die Instanz ist nicht wiederherstellbar.

:::
