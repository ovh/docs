## Ziel

Sie können ein einzelnes Backup einer Instanz erstellen oder einen Zeitplan konfigurieren, um Backups Ihrer Instanzen zu automatisieren. Diese Backups können verwendet werden, um Ihre Instanz auf einen früheren Zustand wiederherzustellen oder um eine neue, identische Instanz zu erstellen.

**Diese Anleitung erklärt, wie Sie manuelle und automatische Backups einer Public Cloud Instanz erstellen.**

## Voraussetzungen

- Sie haben eine [Public Cloud Instanz](https://www.ovhcloud.com/de/public-cloud/) in Ihrem OVHcloud Kunden-Account.
- Sie haben [OpenStack CLI auf Ihrem System installiert und konfiguriert](/guides/public-cloud/public-cloud-cross-functional/prepare-the-environment-for-using-the-openstack-api/).

## In der praktischen Anwendung

### Backup einer Instanz erstellen

:::warning
Diese Option ist für Metal Instanzen nur über einen **Cold Snapshot** verfügbar. Die Metal-Instanz wird in den Rescue-Modus versetzt, und sobald das Backup abgeschlossen ist, wird die Instanz im normalen Modus neu gestartet.

:::


:::info
Zwei Arten von Sicherungen sind verfügbar:

- *Local*: Eine lokale Sicherung wird in derselben Region wie Ihre Instanz gespeichert.
- *Distant*: Eine Distanz-Sicherung erstellt automatisch eine Kopie der lokalen Sicherung in einer anderen, von Ihnen ausgewählten Region.

Jede Sicherung wird gesondert berechnet. Die Distanz-Sicherung wird gemäß der Speicherplatzkosten der ausgewählten Region berechnet.

**Hinweis:** Local Zones sind für entfernte Backups nicht geeignet.

:::

    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/region"} />

Verwenden Sie anschließend folgenden API-Aufruf:
    
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/region/\\{regionName\\}/instance/\\{instanceId\\}/snapshot"} />

Füllen Sie die Felder für die Parameter aus:
    
    - **instanceId**: Eindeutige ID der betreffenden Instanz.
    - **regionName**: Name der Region, in der sich die Quell-Instanz befindet.
    - **serviceName**: ID des OVHcloud Projekts.
    - **distantRegionName (optional)**: Name der Zielregion, in der die Sicherung gespeichert wird.
    - **distantSnapshotName (optional)**: Name der Sicherung in der Zielregion.
    - **snapshotName**: Name der lokalen Sicherung.
    
    :::info
    Erstellen Sie eine Sicherung in einer Zielregion nur, wenn die Parameter **distantRegionName** und **distantSnapshotName** eingetragen sind.

### Automatisches Backup einer Instanz erstellen

:::info
Wenn Sie diese Funktion direkt über OpenStack automatisieren möchten, können Sie einen Mistral-Workflow mit einem Cron-Trigger erstellen.

:::


Klicken Sie in der Instanzenverwaltung auf <code className="action">...</code> rechts neben der Instanz und wählen Sie <code className="action">Automatisches Backup erstellen</code>.

<img className="thumbnail" alt="public-cloud-instance-backup" src="/images/public-cloud/compute/save-an-instance/createbackup4.png" loading="lazy" />

Sie können dann folgende Backup-Einstellungen konfigurieren:

#### **Workflow** 

Derzeit existiert nur ein Workflow. Er erstellt ein Backup für die Instanz und das primäre Volume.

<img className="thumbnail" alt="public-cloud-instance-backup" src="/images/public-cloud/compute/save-an-instance/createbackup5.png" loading="lazy" />

#### **Ressource** 

Sie können die zu sichernde Instanz auswählen.

<img className="thumbnail" alt="public-cloud-instance-backup" src="/images/public-cloud/compute/save-an-instance/createbackup6.png" loading="lazy" />

#### **Name**

Geben Sie einen Namen für die Planung des automatischen Backups ein. Nehmen Sie die Abrechnungsinformationen zur Kenntnis und erstellen Sie das Scheduling, indem Sie auf den Button <code className="action">Erstellen</code> klicken.

<img className="thumbnail" alt="public-cloud-instance-Backup" src="/images/public-cloud/compute/save-an-instance/createbackup7.png" loading="lazy" />

#### **Scheduling** 

Sie können eine personalisierte Backup-Planung festlegen oder eine der Standardrotationen auswählen:

- Tägliche Sicherung mit Speicherung der letzten 7 Backups
- Tägliche Sicherung mit Speicherung der letzten 14 Backups

<img className="thumbnail" alt="public-cloud-instance-backup" src="/images/public-cloud/compute/save-an-instance/createbackup8.png" loading="lazy" />

<details>

<summary>**Hinzufügen einer Remote-Sicherung**</summary>


Klicken Sie auf die Schaltfläche <code className="action">Ein Remote-Backup hinzufügen</code>, wählen Sie einen Standort aus, überprüfen Sie die Preisinformationen und klicken Sie auf die Schaltfläche <code className="action">Erstellen</code>.

<img className="thumbnail" alt="public-cloud-instance-Backup-distant" src="/images/public-cloud/compute/save-an-instance/createbackup8distant.png" loading="lazy" />

</details>


### Verwaltung der Backups und Zeitpläne

Zeitplanungen können im Bereich <code className="action">Workflow Management</code> unter **Compute** im linken Menü erstellt und entfernt werden.

<img className="thumbnail" alt="public-cloud-instance-backup" src="/images/public-cloud/compute/save-an-instance/createbackup9.png" loading="lazy" />

Die Backups Ihrer Instanzen werden im Bereich <code className="action">Instance Backup</code> in Ihrem Public Cloud Kundencenter verwaltet, unter **Compute** im linken Menü.

<img className="thumbnail" alt="public-cloud-instance-backup" src="/images/public-cloud/compute/save-an-instance/createbackup10.png" loading="lazy" />

:::warning
Die Option, die Instanz zu sichern, muss separat abgestellt werden, damit sie nicht mehr in Rechnung gestellt wird. Das Löschen einer Instanz entfernt nicht automatisch die mit ihr verbundenen Dienst-Optionen.

:::



:::warning
**Beachten Sie, dass Sie ein Instanz-Backup nicht löschen können, wenn eine Instanz, die aus diesem Backup erzeugt wurde, zum Zeitpunkt des Löschvorgangs ausgeführt wird.**

:::


Erfahren Sie in [dieser Anleitung](/guides/public-cloud/compute/create-restore-a-virtual-server-with-a-backup/), wie Sie Sicherungen verwenden, um Instanzen zu klonen oder wiederherzustellen.
