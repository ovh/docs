## Ziel

Ein NAS (Network Attached Storage) ist ein Dateiserver, der mit einem Netzwerk verbunden ist und dessen Hauptfunktion darin besteht, Daten auf einem zentralisierten Volume für heterogene Netzwerk-Clients zu speichern.

## Voraussetzungen

- Sie verfügen über eine IP-Adresse, die an einen OVHcloud Dienst angebunden ist (Hosted Private Cloud, Dedicated Server, VPS, Public Cloud Instanz, etc.).
- Sie haben ein [OVHcloud HA-NAS](https://www.ovhcloud.com/de/storage-solutions/nas-ha/) in Ihrem Kunden-Account.

## In der praktischen Anwendung

Klicken Sie auf Ihre Dienstleistung, um Zugriff auf das Verwaltungsinterface zu erhalten.

<img className="thumbnail" alt="Zugang zum NAS" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-01.png" loading="lazy" />

### Eine Partition erstellen <a name="partition"></a>

Um eine neue Partition hinzuzufügen, klicken Sie auf <code className="action">Eine Partition erstellen</code>.

<img className="thumbnail" alt="eine Partition erstellen" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-02.png" loading="lazy" />

Geben Sie dann den **Namen** der Partition, deren **Größe** sowie das autorisierte **Protokoll** (NFS oder CIFS) ein.

<img className="thumbnail" alt="Attribute der Partition" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-03.png" loading="lazy" />

### Größe einer Partition ändern

Um die Größe einer Partition zu ändern, klicken Sie auf den Button <code className="action">...</code> rechts neben der betreffenden Partition und anschließend auf <code className="action">Größe ändern</code>.

<img className="thumbnail" alt="Größe einer Partition ändern" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-04.png" loading="lazy" />

Geben Sie die neue Größe ein und bestätigen Sie.

### Die Frequenz der Snapshots ändern

Eine Sicherung des Inhalts Ihres NAS erfolgt stündlich und wird auf Ihrem NAS gespeichert.

Sie können jedoch auf Wunsch bis zu 3 zusätzliche Snapshots mit unterschiedlichen Frequenzen erstellen, die ebenfalls auf Ihrem NAS gespeichert werden.

Klicken Sie hierzu rechts neben der betreffenden Partition auf <code className="action">...</code> und dann auf <code className="action">Frequenz der Snasphots</code>.

<img className="thumbnail" alt="Snapshot-Frequenz ändern" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-05.png" loading="lazy" />

Wählen Sie die neue Frequenz aus und bestätigen Sie.

### Snapshot erstellen

Zusätzlich zu den automatisch erstellten Snapshots können Sie jederzeit einen Snapshot einer Partition erstellen, indem Sie auf den Button <code className="action">...</code> rechts neben der Partition und dann auf <code className="action">Custom Snapshot</code> klicken.

<img className="thumbnail" alt="snapshot" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-10.png" loading="lazy" />

Benennen Sie den Snapshot und klicken Sie auf <code className="action">Hinzufügen</code>.

### Zugang hinzufügen <a name="addaccess"></a>

Um auf die zuvor von Ihnen erstellte Partition zuzugreifen, müssen Sie einen Zugang konfigurieren.

:::info
Nur IP-Adressen von OVHcloud Diensten können auf Ihr NAS zugreifen (Hosted Private Cloud, Dedicated Server, VPS, Public Cloud Instanz, etc.)

:::


Um einer IP den Zugriff auf das NAS zu erlauben, klicken Sie auf <code className="action">...</code> rechts neben der bestehenden Partition und anschließend auf <code className="action">Zugriff verwalten</code>.

<img className="thumbnail" alt="Zugang verwalten" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-06.png" loading="lazy" />

Klicken Sie auf <code className="action">Zugang hinzufügen</code> und wählen Sie dann die IP-Adresse Ihres OVHcloud Dienstes aus.
<br/>Sie müssen auch festlegen, ob der erlaubte Zugriff auf diese IP-Adresse nur lesend (*Read-only*) oder lesend/schreibend (*Read/Write*) ist.

<img className="thumbnail" alt="Zugang hinzufügen" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-07.png" loading="lazy" />

Um einen Zugang zu einer Partition zu löschen, klicken Sie rechts neben der betreffenden IP-Adresse auf <code className="action">...</code> und dann auf <code className="action">Löschen</code>.

### ZFS-Einstellungen

:::warning
Alle ZFS-Einstellungen sind bereits standardmäßig optimiert. Obgleich wir von einer Änderung dieser Einstellungen abraten, erlaubt dieses Menü die Anpassung des vom HA-NAS verwendeten ZFS.

:::


Um die ZFS-Einstellungen einer Partition zu ändern, klicken Sie auf den Button <code className="action">...</code> rechts neben der betreffenden Partition und dann auf <code className="action">Z File System (ZFS) Einstellungen</code>.

<img className="thumbnail" alt="zfs" src="/images/storage-and-backup/file-storage/ha-nas/nas-get-started/nas2021-13.png" loading="lazy" />

- **Access time update (atime)** deaktivieren: Die Deaktivierung von *atime* bedeutet, dass der Kernel den Zeitstempel des Dateisystems nicht mehr bei jedem Zugriff auf eine Datei aktualisiert. Dies kann nützlich sein, um häufige Lesevorgänge zu beschleunigen, zum Beispiel bei statischen Webseiten. Es sollte jedoch nicht für konsistenzkritische Anwendungen wie Datenbanken angewendet werden.
- **ZFS recordsize**: Diese Eigenschaft ändert die maximale Blockgröße im ZFS-Dateisystem. Bitte beachten Sie, dass ZFS auch dann eine kleinere Blockgröße verwendet, wenn die Datei kleiner als das Maximum ist. Zum Beispiel wird eine 16 KB große Datei einen 16 KB großen Block (plus Metadaten) verwenden, um keinen Speicherplatz zu verschwenden. Aus diesem Grund raten wir generell davon ab, ZFS *recordsize* zu ändern.
- **Sync**: Diese Einstellung verändert das Verhalten von Transaktionen des ZFS-Dateisystems in Bezug auf die Daten-Pufferung im RAM und das Schreiben der Daten auf die Disk. Wenn keine besonderen Gründe vorliegen, empfehlen wir Ihnen, diese Eigenschaft nicht zu ändern.

Beim Löschen einer Partition werden alle darin enthaltenen Daten vollständig und endgültig gelöscht.

:::


Um eine Partition zu löschen, klicken Sie auf den <code className="action">...</code> Button rechts neben der bestehenden Partition und anschließend auf <code className="action">Löschen</code>.
