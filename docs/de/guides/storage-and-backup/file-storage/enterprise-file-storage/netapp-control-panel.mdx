## Ziel

Enterprise File Storage Dienste können über die [OVHcloud API](/guides/storage-and-backup/file-storage/enterprise-file-storage/netapp-quick-start/) oder in Ihrem OVHcloud Kundencenter verwaltet werden.

**Diese Anleitung erklärt, wie Sie Enterprise File Storage Volumes und Snapshots in Ihrem Kundencenter verwalten.**

## Voraussetzungen

- Sie haben einen Enterprise File Storage Dienst in Ihrem Kunden-Account. Der Dienst kann über die [Produktseite](https://www.ovhcloud.com/de/storage-solutions/enterprise-file-storage/) oder das [OVHcloud Kundencenter](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.de/&ovhSubsidiary=de) bestellt werden.

## In der praktischen Anwendung <a name="instructions"></a>

Wählen Sie Ihre Dienstleistung in der Liste aus.

<img className="thumbnail" alt="Allgemeine Informationen" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise01.png" loading="lazy" />

Im Tab <code className="action">Allgemeine Informationen</code> werden technische Informationen zu Ihrem Dienst, allgemeine Details zum Abonnement sowie ein Shortcut zur [Erstellung eines Volumes](#create_volume) angezeigt.

:::info
Detaillierte Informationen zu den technischen Eigenschaften der Enterprise File Storage Lösung finden Sie auf der Seite [Enterprise File Storage - Konzepte](/guides/storage-and-backup/file-storage/enterprise-file-storage/netapp-concepts/).

:::


### Verwaltung der Volumes <a name="manage_volume"></a>

Klicken Sie auf den Tab <code className="action">Volumes</code>. Die Tabelle listet alle für den ausgewählten Dienst erstellten Volumes auf. Klicken Sie auf eine Volume-Kennung, um dessen[Verwaltungsseite](#modify_volume) zu öffnen.

<img className="thumbnail" alt="Volumes" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise02.png" loading="lazy" />

Sie können diverse Aktionen durchführen, indem Sie auf den Button <code className="action">...</code> in der entsprechenden Zeile der Tabelle klicken.

- **Volume bearbeiten**: Öffnet den Bereich "[Allgemeine Informationen](#modify_volume)" des Volumes.
- **Snapshot erstellen**: Öffnet den Bereich "[Snapshots](#snapshots)", um eine manuelle Volume-Sicherung durchzuführen.
- **Letzten Snapshot wiederherstellen**: Öffnet den Abschnitt "[Snapshots](#snapshots)" und ein Fenster zur Wiederherstellung des Volumes.
- **Die Snapshots verwalten**: Öffnet den Bereich "[Snapshots](#snapshots)" des Volumes.
- **IP-Zugang verwalten (ACL)**: Öffnet den Bereich "[Zugriffskontrolle](#access_control)", um den Zugriff auf das Volume zu verwalten.
- **Größe ändern**: Öffnet ein Fenster, in dem Sie die Größe des Volumes ändern können.
- **Volume löschen**: Löscht dieses Volume, nachdem die Aktion im Popup-Fenster bestätigt wurde.

#### Erstellung eines Volumes <a name="create_volume"></a>

Klicken Sie auf den Button <code className="action">Volume erstellen</code>. Geben Sie im neuen Fenster den Namen und die Beschreibung des Volumes ein. Legen Sie die Größe in GB fest und klicken Sie auf <code className="action">Volume erstellen</code> um die Aktion zu bestätigen.

<img className="thumbnail" alt="Volume" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise03.png" loading="lazy" />

#### Volume bearbeiten <a name="modify_volume"></a>

Klicken Sie in der Tabelle auf eine Volume-ID, um die Verwaltungsseite dieses Volumes zu öffnen.

Im Tab <code className="action">Allgemeine Informationen</code> werden die Details Ihres Volumes sowie detaillierte Anweisungen zur Verbindung mit dem Volume angezeigt, einschließlich der individuellen Verbindungsparameter.

<img className="thumbnail" alt="Verwaltung der Volumes" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise04.png" loading="lazy" />

In diesem Tab können Sie auch den Namen und die Beschreibung des Volumes ändern.

### Volume löschen <a name="delete_volume"></a>

Sie können ein Volume löschen, indem Sie auf den Button <code className="action">...</code> in der Tabelle im Tab <code className="action">Volumes</code> und dann auf <code className="action">Volume löschen</code> klicken.

<img className="thumbnail" alt="Volume delete" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise05.png" loading="lazy" />

Geben Sie `DELETE` ein, und klicken Sie auf <code className="action">Bestätigen</code>, um den Löschvorgang zu bestätigen.

#### Erstellung und Verwaltung von Volume Snapshots <a name="snapshots"></a>

:::info
Snapshots nutzen die Speicherkapazität Ihrer Enterprise File Storage-Lösung. Standardmäßig sind 5 % der Größe eines Volumes immer für Snapshots reserviert.

:::


Im Tab <code className="action">Snapshots</code> finden Sie alle für das ausgewählte Volume erstellten Snapshots.

<img className="thumbnail" alt="Snapshots" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise06.png" loading="lazy" />

Im gleichen Tab können Sie auch alle für den Dienst erstellten [Snapshot-Policys](#snapshot_policy) einsehen und auf dieses Volume anwenden.

<img className="thumbnail" alt="Volume Snapshot Policy Management" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise07.png" loading="lazy" />

Klicken Sie auf die entsprechende Policy-Zeile, um die Details der Snapshot-Planung anzuzeigen. Wählen Sie eine Regelung über den betreffenden Button und klicken Sie dann auf <code className="action">Regel anwenden</code> unter der Tabelle.

Um Ihre [Snapshot-Regeln](#snapshot_policy) zu konfigurieren, gehen Sie in den Bereich [Volume-Verwaltung](#instructions) Ihres Dienstes und öffnen Sie den Tab <code className="action">Snapshot-Regeln</code>.

### Erstellung eines Snapshots <a name="create_snapshot"></a>

Um einen neuen Snapshot eines Volumes im aktuellen Zustand zu erstellen, klicken Sie auf <code className="action">Aktionen</code> und dann auf <code className="action">Snapshot erstellen</code>.

<img className="thumbnail" alt="Snapshot create" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise08.png" loading="lazy" />

Im neu geöffneten Fenster können Sie einen Namen und eine Beschreibung eingeben.

Klicken Sie auf <code className="action">Snapshot erstellen</code>, um die Erstellung zu starten.

<img className="thumbnail" alt="Snapshot create window" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise09.png" loading="lazy" />

#### Snapshot bearbeiten <a name="modify_snapshot"></a>

Sie können den Namen oder die Beschreibung eines Snapshots ändern, indem Sie auf den Button <code className="action">...</code> in der Tabelle klicken und dann auf <code className="action">Bearbeiten</code>. Es wird ein Fenster geöffnet, in dem Sie einen neuen Namen und eine Beschreibung eingeben können.

<img className="thumbnail" alt="Snapshot edit" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise10.png" loading="lazy" />

Klicken Sie auf <code className="action">Bestätigen</code>, um Ihre Änderungen zu bestätigen.

<img className="thumbnail" alt="Snapshot edit window" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise11.png" loading="lazy" />

### Löschen eines Snapshots <a name="delete_snapshot"></a>

:::warning
Snapshots vom Typ `system` können nicht gelöscht werden.  
Diese sind für das reibungslose Funktionieren Ihres Enterprise File Storage Angebots notwendig.

:::


Sie können einen Snapshot löschen, indem Sie auf den Button <code className="action">...</code> in der Tabelle und dann auf <code className="action">Löschen</code> klicken.

<img className="thumbnail" alt="Snapshot delete" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise12.png" loading="lazy" />

Klicken Sie auf <code className="action">Snapshot löschen</code>, um die Löschung zu bestätigen.

<img className="thumbnail" alt="Snapshot delete confirm" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise13.png" loading="lazy" />

### Wiederherstellung des Volumes mit einem Snapshot <a name="restore_volume"></a>

:::warning
Beachten Sie, dass alle später erstellten Dateien oder Snapshots verloren gehen, sobald ein Volume mit einem Snapshot wiederhergestellt wurde.  
Wenn ein Volume wiederhergestellt wird, werden alle darin enthaltenen Daten durch die Snapshot-Daten ersetzt. Diese Aktion kann nicht rückgängig gemacht werden.

:::


Sie können ein Volume mit dem neuesten `manuellen` Snapshot wiederherstellen. Klicken Sie auf <code className="action">Aktionen</code> und dann auf <code className="action">Letzten Snapshot wiederherstellen</code>.

:::info
Um das Volume mit einem Snapshot vor dem letzten Snapshot wiederherzustellen, müssen die Snapshots gelöscht werden, bis der für die Wiederherstellung zu verwendende Snapshot der aktuellste ist.

:::


<img className="thumbnail" alt="Volume revert to latest snapshot" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise14.png" loading="lazy" />

### Automatisches Backup eines Snapshots <a name="hold_snapshot"></a>

Die von den [Snapshot-Richtlinien](#snapshot_policy) erstellten `automatischen` Snapshots können gesichert werden, indem Sie auf den Button <code className="action">...</code> in der Tabelle und dann auf <code className="action">Sichern</code> klicken.

<img className="thumbnail" alt="Volume hold" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise15.png" loading="lazy" />

Wenn Sie einen `automatisch` erstellten Snapshot sichern, wird er `manuell`, was seine Rotation durch die Snapshot-Richtlinie und somit seine automatische Löschung verhindert.

#### Verwaltung der Volume-Zugriffe (ACL) <a name="access_control"></a>

Die Zugriffskontrolle auf Volumes funktioniert über IP-Adressbeschränkungen. Da keine vorkonfiguriert sind, besteht der erste Schritt bei der Erstellung von Volumes in der Definition von IP-Adressen oder IP-Bereichen, denen Zugriff erlaubt werden soll.

Klicken Sie im Tab <code className="action">Zugriffskontrolle (ACL)</code> auf den Button <code className="action">+ Einen neuen Zugang hinzufügen</code>.

<img className="thumbnail" alt="ACL" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise16.png" loading="lazy" />

Diese Aktion erzeugt eine neue Zeile in der Tabelle, in die Sie eine IP-Adresse oder einen Adressblock (CIDR) eingeben können. Wählen Sie `Lesen und schreiben` oder `Nur Lesen` als Zugriffstyp im Drop-down-Menü aus und klicken Sie dann auf den Haken bei diesem Eintrag, um ihn zur ACL hinzuzufügen.

Um einen Zugang zu löschen, klicken Sie in der Tabelle auf das entsprechende Abfalltonnensymbol.

### Verwaltung der Snapshot-Policys <a name="snapshot_policy"></a>

:::info
Standardmäßig ist jedes Volume durch eine Snapshot Policy mit dem Namen `default` geschützt, die in regelmäßigen Abständen Snapshots des Volumes erstellt.

:::


Mit dem Hinzufügen von Regeln können Sie die Erstellung von Snapshots für alle Ihre Volumes planen.

Klicken Sie auf den Tab <code className="action">Regeln für Snapshots</code>. Die Tabelle listet alle für den ausgewählten Dienst erstellten Regeln auf.

Eine Standardrichtlinie ist bereits vorhanden und kann nicht geändert werden. Um eine eigene Snapshot-Regel hinzuzufügen, klicken Sie auf den Button <code className="action">Snapshot-Regel erstellen</code>.

<img className="thumbnail" alt="Snapshot policies" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise17.png" loading="lazy" />

Geben Sie in der neuen Ansicht einen Namen und eine Beschreibung für die Policy ein. Verwenden Sie anschließend den Button <code className="action">Eine neue Regel erstellen</code>, um eine oder mehrere Regeln zur Policy hinzuzufügen.

<img className="thumbnail" alt="Snapshots" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise18.png" loading="lazy" />

Füllen Sie die Felder aus, um die Kriterien für die Erstellung des Snapshots festzulegen. Sie müssen auch einen Präfix für die Snapshots eingeben, der für deren Benennung benötigt wird.

Weitere Informationen zu jedem Wert erhalten Sie, indem Sie jeweils auf das <code className="action">?</code> klicken. Wenn Sie den Bereich <code className="action">Beispiel</code> erweitern, werden exemplarisch zwei Policy-Regelsätze mit Erläuterung ihrer Ergebnisse angezeigt.

Klicken Sie rechts auf den Haken, um die Regel hinzuzufügen. Wenn Sie alle Regeln hinzugefügt haben, klicken Sie unten auf <code className="action">Eine neue Regel für Snapshots erstellen</code>.

[Wählen Sie ein Volume aus](#manage_volume) und gehen Sie zum Tab <code className="action">Snapshots</code>, um [Ihre Policys anzuwenden](#snapshots).

Um eine Policy zu löschen, klicken Sie in der Tabelle auf das entsprechende Abfalltonnensymbol.
