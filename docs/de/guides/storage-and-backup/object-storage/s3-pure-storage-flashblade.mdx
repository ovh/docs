## Objective

This guide aims to help you configure and use OVHcloud Object Storage as a replication target for Pure Storage [Flashblade unified storage platform](https://www.purestorage.com/uk/products/unstructured-data-storage/flashblade-s.html).

**Learn how you can easily configure, manage and start replicating Pure Storage FlashBlade S3<sup>1</sup>-compatible objects to OVHcloud Object Storage.**

## Requirements

- An OVHcloud Object Storage container/bucket.
- Access to the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB)
- A user with the required access rights on the bucket.
- Your Object Storage credentials (`access_key` and `secret_access_key`).

See our [Getting started with Object Storage](/guides/storage-and-backup/object-storage/s3-getting-started-with-object-storage) guide.

## Instructions

### Create an S3-compatible Target Connection

1\. Sign in to the PureStorage FlashBlade GUI.

2\. Go to the <code className="action">Storage</code> section and then <code className="action">Array</code>.

3\. Click the <code className="action">+</code> button next to `S3 Target Connections` to create a *Target Connections* cloud object storage.

4\. Name the connection (for example  `OVHCLOUD_OBJECT_STORAGE`) and add the associated OVHcloud Object Storage endpoints in the `Address` field.

<img className="thumbnail" alt="connection page" src="/images/storage-and-backup/object-storage/s3-pure-storage-flashblade/01-connections.png" loading="lazy" />

The list of all OVHcloud Object Storage endpoints can be found [here](/guides/storage-and-backup/object-storage/s3-location).

### Add Remote Cloud Object Storage Credentials

5\. Go to the <code className="action">Protection</code> section and then click on <code className="action">Object Replica Links</code>.

6\. Click the <code className="action">+</code> button to add remote credentials for object replication.

7\. Select <code className="action">OVHCLOUD_OBJECT_STORAGE</code> for Remote Array.

8\. Add the name of your connection (for example `OVHcloud_credentials`), and add your Access and Secret keys from the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB).

9\. Confirm by clicking on <code className="action">Create</code> and your remote credentials will be created.

<img className="thumbnail" alt="creds page" src="/images/storage-and-backup/object-storage/s3-pure-storage-flashblade/02-creds.png" loading="lazy" />

### Create a bucket that will be replicated to OVHcloud Object Storage

10\. If not already done, go to the <code className="action">Storage</code> section, then <code className="action">Object Storage</code> and finally <code className="action">Accounts</code> to create the account.

11\. Configure the different parameters: `account name`, `quota limit` and `bucket default quota limit` to create the account.

12\. Click the <code className="action">Buckets</code> section and select the account name.

13\. Enter a bucket name `OVHcloud-source-2025` and click on <code className="action">Create</code>.

### Setup the Bucket Replication to OVHcloud Object Storage

14\. Go to <code className="action">Protection</code> > <code className="action">Object Replication</code> and <code className="action">Bucket Replication Link</code>.

15\. Click the <code className="action">+</code> button to create a bucket replica link.

16\. Select the bucket you just created.

17\. Select <code className="action">OVHCLOUD_OBJECT_STORAGE</code> for Remote Array.

18\. Add the name of your OVHcloud Object Storage bucket: `OVHcloud-dest-2025`.

19\. Add your remote credentials: `OVHcloud_credentials`. The bucket replica link will be created.

<img className="thumbnail" alt="replica page" src="/images/storage-and-backup/object-storage/s3-pure-storage-flashblade/03-replica.png" loading="lazy" />

20\. You can now test and validate the bucket replication from Pure Storage Flashblade platform to OVHcloud Object Storage.
