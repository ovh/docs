## Ziel

Sie können sich nicht mehr an den Namen Ihres [Webhostings](https://www.ovhcloud.com/de/web-hosting/) erinnern?
Möchten Sie dessen Details prüfen oder mit einem anderen Angebot vergleichen?

Während der Nutzung Ihres Services könnten Sie den Namen Ihres Webhosting Angebots benötigen.

**Erfahren Sie, wie Sie den Typ des Webhostings identifizieren können, den Sie über das OVHcloud Kundencenter nutzen.**

## Voraussetzungen

- Sie haben ein [OVHcloud Webhosting](https://www.ovhcloud.com/de/web-hosting/).

{/* CP-NAV-START:web-hosting */}
---

### Zugriff auf das OVHcloud Kundencenter

- **Direkter Link:** [Hosting-Pakete](https://manager.eu.ovhcloud.com/#/web/hosting)
- **Navigationspfad:** <code className="action">Web Cloud</code> > <code className="action">Hosting-Pakete</code> > Wählen Sie Ihr Webhosting aus

---
{/* CP-NAV-END:web-hosting */}

## In der praktischen Anwendung

Klicken Sie auf die Tabs, um die **2** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite [Hosting-Pakete](https://manager.eu.ovhcloud.com/#/web/hosting), und wählen Sie das betreffende Webhosting aus.
    
    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Im Bereich **Abo** finden Sie die Bezeichnung **Angebot**.
    
    <img className="thumbnail" alt="Angebot" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-plan-pro.png" loading="lazy" />

Unter dieser Bezeichnung finden Sie den Namen Ihres Webhosting Angebots (z. B. Basic, Pro, Performance, etc.).
  </Tab>
</Tabs>
