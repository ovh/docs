## Ziel

Sie möchten Ihre Website über einen bestimmten Domainnamen erreichbar machen? Hierzu muss Ihr Domainname auf die IP-Adresse des Dienstes verweisen, auf dem sich Ihre Website befindet (Webhosting, Dedicated Server, VPS, etc.). Konfigurieren Sie hierzu die aktive DNS-Zone Ihrer Domain mit einem DNS-Eintrag vom Typ AAAA.

**Diese Anleitung erklärt, wie Sie einen DNS-Eintrag vom Typ AAAA zu einer von OVHcloud verwalteten DNS-Zone für Ihre Domain hinzufügen.**

:::info
Befolgen Sie [diese Anleitung](/guides/web-cloud/domains/dns-zone-edit/), um einen DNS-Eintrag vom Typ AAAA einer OVHcloud DNS-Zone zu ändern oder zu löschen.

:::


## Voraussetzungen

- Sie haben einen [Domainnamen](https://www.ovhcloud.com/de/domains/).
- Sie nutzen eine diesem Domainnamen zugeordnete DNS-Zone bei OVHcloud.

### Zugriff auf das OVHcloud Kundencenter

- **Direkter Link:** [DNS-Zone](https://manager.eu.ovhcloud.com/#/web/zone)
- **Navigationspfad:** <code className="action">Web Cloud</code> > <code className="action">DNS-Zone</code> > Wählen Sie Ihren Domainnamen aus

## In der praktischen Anwendung

:::warning
Das Hinzufügen, Ändern oder Löschen von DNS-Einträgen in einer aktiven DNS-Zone kann zu Dienstunterbrechungen führen. Im Zweifelsfall wenden Sie sich an einen [spezialisierten Dienstleister](https://partner.ovhcloud.com/de/directory/).

:::


### Einen DNS-Eintrag vom Typ AAAA für eine Domain hinzufügen

Klicken Sie auf die unten stehenden Tabs, um die **5** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite [DNS-Zone](https://manager.eu.ovhcloud.com/#/web/zone), und wählen Sie den betreffenden Domainnamen aus.
    
    <img className="thumbnail" alt="DNS zones" src="/images/assets/screens/control-panel/product-selection/web-cloud/dns-zones.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf die Schaltfläche <code className="action">Eintrag hinzufügen</code>.
  </Tab>
  <Tab label="Schritt 3">
    Wählen Sie im angezeigten Fenster das Feld <code className="action">AAAA</code> aus.
  </Tab>
  <Tab label="Schritt 4">
    Geben Sie in das Feld `Ziel *` die IP-Adresse (zum Beispiel `2001:db8:1:1b00:203:0:113:0`) des Dienstes ein, auf dem sich Ihre Website befindet (Webhosting, Dedicated Server, VPS, etc.), und klicken Sie dann auf <code className="action">Weiter</code>.
  </Tab>
  <Tab label="Schritt 5">
    Überprüfen Sie die Zusammenfassung, und klicken Sie auf <code className="action">Bestätigen</code>. Es dauert bis zu **24** Stunden, bis die Änderung im DNS-Netzwerk voll wirksam ist.
  </Tab>
</Tabs>

### Einen DNS-Eintrag vom Typ AAAA für die Subdomain einer Domain hinzufügen

Klicken Sie auf die unten stehenden Tabs, um die **5** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite [DNS-Zone](https://manager.eu.ovhcloud.com/#/web/zone), und wählen Sie den betreffenden Domainnamen aus.
    
    <img className="thumbnail" alt="DNS zones" src="/images/assets/screens/control-panel/product-selection/web-cloud/dns-zones.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Klicken Sie auf die Schaltfläche <code className="action">Eintrag hinzufügen</code>.
  </Tab>
  <Tab label="Schritt 3">
    Wählen Sie im angezeigten Fenster das Feld <code className="action">AAAA</code> aus.
  </Tab>
  <Tab label="Schritt 4">
    Geben Sie in das Feld `Subdomain` die betreffende Subdomain (zum Beispiel `www` für die Subdomain `www.domain.tld`) und im Feld `Ziel *` die IP-Adresse (zum Beispiel `2001:db8:1:1b00:203:0:113:0`) des Dienstes ein, auf dem sich Ihre Website befindet (Webhosting, Dedicated Server, VPS, etc.). Klicken Sie anschließend auf <code className="action">Weiter</code>.
  </Tab>
  <Tab label="Schritt 5">
    Überprüfen Sie die Zusammenfassung, und klicken Sie auf <code className="action">Bestätigen</code>. Es dauert bis zu **24** Stunden, bis die Änderung im DNS-Netzwerk voll wirksam ist.
  </Tab>
</Tabs>
