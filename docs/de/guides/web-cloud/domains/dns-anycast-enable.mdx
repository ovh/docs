## Ziel

Sie möchten, dass Ihre Dienstleistungen (z.B. Ihre Website) weltweit in Rekordzeit verfügbar sind? Sie möchten die DNS-Auflösung Ihrer Domain optimieren?  
OVHcloud bietet Ihnen die Option [DNS Anycast](https://www.ovhcloud.com/de/domains/options/dns-anycast/).

**Diese Anleitung erklärt, wie Sie mit der DNS Anycast Option Ihrer Domain den Zugriff auf Ihre Webdienste beschleunigen können.**

## Voraussetzungen

- Sie verfügen über einen [Domainnamen](https://www.ovhcloud.com/de/domains/).
- Der Domainname hat eine mit der DNS Anycast Option kompatible Endung.

{/* CP-NAV-START:web-domains */}
---

### Zugriff auf das OVHcloud Kundencenter

- **Direkter Link:** [Domainnamen](https://manager.eu.ovhcloud.com/#/web-domains/domain)
- **Navigationspfad:** <code className="action">Web Cloud</code> > <code className="action">Domainnamen</code> > Wählen Sie Ihren Domainnamen aus

---
{/* CP-NAV-END:web-domains */}

## In der praktischen Anwendung

Klicken Sie auf die Tabs, um die **4** Schritte anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite [Domainnamen](https://manager.eu.ovhcloud.com/#/web-domains/domain), und wählen Sie den Domainnamen aus.
    
    <img className="thumbnail" alt="Domain Names" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-names.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Wählen Sie den Tab <code className="action">DNS-Server</code> aus, nachdem Sie sich in der betreffenden Domain befinden.
    
    <img className="thumbnail" alt="DNS Servers" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 3">
    Klicken Sie auf der angezeigten Seite auf <code className="action">DNS Anycast bestellen</code>.
    
    <img className="thumbnail" alt="Order Anycast DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/order-anycast-dns.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Auf der neu geöffneten Seite:
    
    - Wählen Sie die vorgeschlagene Dauer im Abschnitt `1` aus und klicken Sie auf <code className="action">Weiter</code>.
    - Wählen Sie Ihre Zahlungsart aus und klicken Sie auf <code className="action">Bezahlen</code>, um mit der Aktivierung der DNS Anycast Dienste fortzufahren.
    
    <img className="thumbnail" alt="Order Anycast DNS step 2" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/order-anycast-dns-step-2.png" loading="lazy" />

Klicken Sie in der grün hervorgehobenen Nachricht auf den Button <code className="action">Bestellschein</code>, um zum Bestellschein für die Aktivierung der DNS Anycast Option weitergeleitet zu werden.
    
    Sobald Sie auf dem Bestellschein sind, können Sie mit einer Zahlungsart fortfahren, um die Bearbeitung der Bestellung abzuschließen.
  </Tab>
</Tabs>


Die Aktivierung der DNS Anycast Option kann einige Minuten dauern.
