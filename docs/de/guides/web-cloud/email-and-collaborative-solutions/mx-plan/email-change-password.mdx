## Ziel

Die Accounts Ihrer OVHcloud E-Mail-Dienste sind nur mit dem zugehörigen Passwort nutzbar. Je nach verwendetem E-Mail-Angebot können Sie es auf 2 Arten ändern:

- Über das Webmail-Interface
- Über das OVHcloud Kundencenter

**Diese Anleitung erklärt, wie Sie das Passwort eines OVHcloud E-Mail-Accounts ändern.**

## Voraussetzungen

- Sie verfügen über eine vorkonfigurierte OVHcloud E-Mail-Lösung, darunter:
    - **MX Plan** mit unseren [Webhosting Angeboten](https://www.ovhcloud.com/de/web-hosting/) oder in einem [100M Gratis-Hosting](https://www.ovhcloud.com/de/domains/free-web-hosting/) inklusive.
    - [Exchange](https://www.ovhcloud.com/de/emails-exchange/).
    - [E-Mail Pro](https://www.ovhcloud.com/de/emails/email-pro/).
    - [Zimbra](https://www.ovhcloud.com/de/emails/zimbra-emails/).

## In der praktischen Anwendung

:::info
Wenn Sie das Passwort Ihrer E-Mail-Adresse ändern, muss diese Änderung auch auf alle E-Mail-Clients, die auf diesen Account zugreifen, angewendet werden. Finden Sie dazu die Konfigurationsanleitung zu Ihrer E-Mail-Anwendung auf der Anleitungsseite für Ihr E-Mail-Angebot.

:::


### Passwort über das Kundencenter ändern <a name="controlpanel"></a>

:::warning
Aus Sicherheitsgründen empfehlen wir, Passwörter nicht mehrfach zu verwenden, eines auszuwählen, das keine persönlichen Angaben enthält (Namen, Vornamen und Geburtsdatum) und es regelmäßig zu ändern.

:::


<a name="whichmxplan"></a>

:::info
**E-Mail-Technologie Ihres MX Plan Angebots identifizieren.**

### Passwort über Webmail ändern

Die Änderung eines Passworts über Webmail ist für die OVHcloud E-Mail-Angebote unter Verwendung von **OWA** (**O**utlook **W**eb **A**pp) verfügbar:

- MX Plan OWA
- E-Mail Pro
- Exchange
- MX Plan Zimbra
- Zimbra Starter et Pro

:::warning
Beim Angebot **MX Plan Roundcube** erfolgt die Passwortänderung ausschließlich [über das Kundencenter](#controlpanel).

:::


#### OWA

Öffnen Sie die [Webmail-Seite](https://www.ovhcloud.com/de/mail/). Geben Sie dort Ihre vollständige E-Mail-Adresse und das aktuelle Passwort ein. Klicken Sie anschließend auf den Button <code className="action">Login</code>.

<img className="thumbnail" alt="E-Mail" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-change-password/mxplan-password-new-step2.png" loading="lazy" />

Klicken Sie oben auf den Button <i className="icons-gear-concept icons-masterbrand-blue"></i> und dann auf <code className="action">Optionen</code>.

<img className="thumbnail" alt="E-Mail" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-change-password/mxplan-password-new-step3.png" loading="lazy" />

Erweitern Sie im linken Bereich auf der neu geöffneten Seite den Tab "Allgemein" der Ordnerstruktur und klicken Sie auf <code className="action">Mein Konto</code>. Klicken Sie dann auf <code className="action">Kennwort ändern</code>.

<img className="thumbnail" alt="E-Mail" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-change-password/mxplan-password-new-step4.png" loading="lazy" />

Geben Sie im neu geöffneten Fenster zunächst Ihr aktuelles Passwort ein. Geben Sie anschließend Ihr neues Passwort ein und bestätigen Sie es. Um die Änderung zu speichern, klicken Sie auf den Button <code className="action">Speichern</code>.

:::info
Geben Sie das neue Passwort auch in allen für diesen Account verwendeten E-Mail-Clients ein.

:::


<img className="thumbnail" alt="E-Mail" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-change-password/mxplan-password-new-step5.png" loading="lazy" />

### Zimbra

Gehen Sie auf die Seite [Webmail](https://www.ovhcloud.com/de/mail/). Geben Sie Ihre E-Mail-Adresse und das Passwort ein und klicken Sie auf <code className="action">Anmelden</code>.

Klicken Sie rechts oben in Ihrem Interface auf den Namen Ihres E-Mail-Accounts. In diesem Menü können Sie das <code className="action">Passwort ändern</code>.

<img className="thumbnail" alt="Zimbra - Voreinstellungen" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/email-change-password/zimbra-password.png" loading="lazy" />

### Passwort abrufen

Aus Gründen der Sicherheit und der Vertraulichkeit ist es nicht möglich, ein Passwort **wiederherzustellen**. Wie in den vorherigen Schritten beschrieben, müssen Sie Ihr Kennwort zurücksetzen, wenn Sie es nicht mehr kennen.

:::info
Wenn Sie ein Kennwort speichern möchten, sollten Sie einen Passwortmanager verwenden, z. B. **KeePass**.

:::
