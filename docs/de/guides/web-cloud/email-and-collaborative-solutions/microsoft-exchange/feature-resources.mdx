## Ziel

Diese kollaborative Exchange-Funktion erlaubt die Erstellung von E-Mail-Adressen, die den Ressourcen Ihrer Organisation zugewiesen sind, etwa für Konferenzräume und gemeinsam genutzte Hardware. Die Verwendung dieser Ressourcen-Accounts erlaubt es, die Organisation von Events in einer kollaborativen Arbeitsumgebung zu optimieren, indem Verfügbarkeitsprüfungen automatisch ausgeführt und die Ressourcen unmittelbar im Exchange Kalender integriert werden können.

**Diese Anleitung erklärt, wie Sie Ressourcen mithilfe des OVHcloud Kundencenters und der Outlook Web App (OWA) verwalten.**

## Voraussetzungen

- Sie haben einen [OVHcloud Exchange](https://www.ovhcloud.com/de/emails/hosted-exchange/) Dienst eingerichtet.
- Sie verfügen über Login-Daten für die E-Mail-Accounts mit Zugriff auf die Ressource.

## In der praktischen Anwendung

### Schritt 1: eine Ressource erstellen

<img className="thumbnail" alt="Erstellen" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step1.png" loading="lazy" />

Klicken Sie auf den Button <code className="action">Ressourcen-Account hinzufügen</code> um Ihre erste Ressource zu erstellen. Füllen Sie im neuen Fenster folgende Felder aus:

<img className="thumbnail" alt="Erstellen" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step2.png" loading="lazy" />

|Name|Beschreibung|
|---|---|
|E-Mail-Adresse der Ressource|Geben Sie die Adresse der Ressource ein. Bitte beachten Sie, dass Sie keine existierende E-Mail-Adresse auswählen können.|
|Name der Ressource|Anzeigename, der in Ihrem [OVHcloud Kundencenter](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.de/&ovhSubsidiary=de) und im [OVHcloud Webmail](https://www.ovhcloud.com/de/mail/) (OWA) verwendet wird.|
|Kapazität|Sie können die maximale Größe einer Ressource festlegen (z.B. die Anzahl der Sitzplätze in einem Raum oder die Sitze in einem Unternehmensfahrzeug).|
|Konflikte erlauben|Wenn Sie dies anhaken, können Sie sich überschneidende Kalenderereignisse mit derselben Ressource erstellen.|
|Ressourcen-Typ|Wählen Sie den Ressourcentyp aus: "Ausrüstung" oder "Saal".|

Klicken Sie auf <code className="action">Weiter</code>, um zur Zusammenfassung zu gelangen, und bestätigen Sie den Task, indem Sie auf <code className="action">Erstellen</code> klicken.

### Schritt 2: Ressourcen verwenden

Ihre Ressourcen können in der Tabelle im Tab "Ressourcen" verwaltet werden. Klicken Sie auf <code className="action">...</code> um eine Ressource zu ändern oder zu löschen. Hier erscheint auch die Option <code className="action">Berechtigungen konfigurieren</code>. Mit dieser Option können Sie den Zugriff auf die gleiche Weise wie für einen Exchange Account delegieren. Die Details finden Sie [in dieser Anleitung](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-delegation/).

<img className="thumbnail" alt="Verwenden" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step3.png" loading="lazy" />

### Einen Ressourcenkalender in OWA hinzufügen

:::info
Nutzen Sie auch unsere Anleitung zur [Kalenderfreigabe über OWA](/guides/web-cloud/email-and-collaborative-solutions/using-the-outlook-web-app-webmail/owa-calendar-sharing/).

:::


Verbinden Sie sich mit Ihrem Exchange Account über das [OVHcloud Webmail](https://www.ovhcloud.com/de/mail/). Wechseln Sie zum "Kalender"-Interface, indem Sie in der oberen linken Ecke auf den "Launcher"-Button klicken und anschließend den <code className="action">Kalender</code> auswählen.

<img className="thumbnail" alt="Hinzufügen" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-calendars-step1.png" loading="lazy" />

Klicken Sie in der oberen Navigationsleiste auf <code className="action">Kalender hinzufügen</code> und dann auf <code className="action">Aus dem Verzeichnis</code>.

<img className="thumbnail" alt="Auswählen" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step4.png" loading="lazy" />

Schreiben Sie in das Feld, um automatisch Vorschläge aus Ihren Kontakte anzuzeigen, geben Sie direkt eine vollständige E-Mail-Adresse ein oder verwenden Sie die Suchfunktion über <code className="action">Verzeichnis durchsuchen</code>. Die E-Mail-Adresse der Ressource sollte hier jedoch bereits vorgeschlagen werden, da sie bei der Erstellung automatisch zur Globalen Adressliste (GAL) hinzugefügt wurde.

Klicken Sie auf <code className="action">Öffnen</code>, um den Ressourcenkalender zur Ihrer Kalenderübersicht hinzuzufügen.

### Ein Event in OWA erstellen

Um ein Ereignis zu planen, klicken Sie zunächst auf <code className="action">Neu</code> im oberen Menü und wählen Sie <code className="action">Kalenderereignis</code> aus. Im neuen Fenster können Sie die Details Ihres Events definieren und die erforderliche Hardware sowie den Standort hinzufügen, indem Sie die entsprechenden Ressourcen hinzufügen.

<img className="thumbnail" alt="Planung" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step5_1.png" loading="lazy" />

Der Ereignisplaner besteht aus drei Komponenten:

#### Details

- (1) Einen Titel für das Ereignis hinzufügen: Ereignis wird so in den Kalendern angezeigt.
- (2) Einen Ort oder Raum hinzufügen: Sie können aus Ihren Ressourcen-Accounts wählen.
- (3) Start/Ende: Legen Sie die Dauer des Ereignisses fest.
- (4) Wiederholen: Wählen Sie gegebenenfalls einen Wiederholungszyklus (täglich, monatlich am gleichen Tag usw.).
- (5) Erinnerung: OWA zeigt zur angegebenen Zeit ein Hinweisfenster an.
- (6) Anzeigen als: Wählen Sie einen Status für Ihren Verfügbarkeitskalender aus.
- (7) E-Mail-Erinnerung hinzufügen: eine Option, um Erinnerungen per E-Mail an Sie oder alle Teilnehmer zu versenden.

Geben Sie Ihre Einladungsnachricht in den Editor unten (8) ein und fügen Sie anschließend Teilnehmer zu Ihrem Event hinzu.

Wenn Sie versuchen, eine bereits reservierte Ressource ("belegt") hinzuzufügen, wird eine Nachricht angezeigt, die die [Verwendung des Planungsassistenten](#zeitplan) (9) vorschlägt, der einen umfassenderen Kalender-Überblick für den gewählten Zeitraum bietet.

#### Personen

Da ein Ressourcen-Account auch ein Kontakt ist, können Sie wie bei anderen Teilnehmern (10) Räume und Geräte in diesem Bereich hinzufügen. Schreiben Sie in das Feld, um automatisch Vorschläge aus Ihren Kontakte anzuzeigen, geben Sie direkt eine vollständige E-Mail-Adresse ein oder verwenden Sie die Suchfunktion über <code className="action">Verzeichnis durchsuchen</code> (ein Klick auf <code className="action">+</code> öffnet Ihre Kontakte).

Sobald Sie die Planung abschließen, indem Sie auf <code className="action">Senden</code> im oberen Menü klicken, sendet Ihnen der Ressourcen-Account eine Nachricht, um zu bestätigen, dass er für Ihr Event reserviert ist. Setzen Sie einen Haken bei "Antworten anfordern", wenn Sie eine aktive Bestätigung der Eingeladenen benötigen, um Ihren Kalender automatisch zu aktualisieren.

#### Zeitplan

Ein Kalender-Auszug aus Ihren eigenen Events (**Schedule**) erscheint rechts, sobald Sie eine Ressource oder eine Person zu dem Ereignis hinzufügen. Er liefert einen grafischen Überblick über die Verfügbarkeit der Ressourcen am gewählten Tag. Sie können Zeit und Dauer des Ereignisses direkt festlegen, indem Sie Mausklicks und das Auswahlmenü oben rechts verwenden.

Wenn nötig, klicken Sie auf den <code className="action">Planungsassistenten</code> im Bereich **Kontakte**, um einen noch detaillierteren Überblick zu erhalten. Dieser Assistent ist nützlich für größere Ereignisse oder wenn Sie Konflikte managen müssen, da er den gesamten Planungsprozess darstellt. Sie können Verfügbarkeiten überprüfen und Ihre Planung anpassen ohne dieses Interface zu verlassen, indem Sie Standorte und Kontakte auswählen.

<img className="thumbnail" alt="Assistent" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step6.png" loading="lazy" />

### Antwortnachrichten der Ressource

Nach Erstellung des Events (indem Sie auf <code className="action">Senden</code> im oberen Menü klicken) versendet Exchange automatisch Nachrichten:

- Die Teilnehmer erhalten Einladungen (um die betroffenen Kalender oder nur ihre eigenen zu aktualisieren, je nachdem, ob Sie zuvor "Antworten anfordern" ausgewählt haben).

- Sie erhalten eine Bestätigungsmail von jedem ausgewählten Ressourcen-Account (wenn die Ressource verfügbar ist oder reserviert ist, Sie aber bei der Erstellung **"Konflikte erlauben" angehakt** haben).

<img className="thumbnail" alt="Annahmenachricht" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step7.png" loading="lazy" />

- Sie erhalten eine ablehnende E-Mail von jedem ausgewählten Ressourcen-Account (wenn die Ressource nicht verfügbar ist **und** Sie bei der Erstellung **"Konflikte erlauben" nicht angehakt** haben).

<img className="thumbnail" alt="Ablehnungsnachricht" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-resources/exchange-resources-step8.png" loading="lazy" />
