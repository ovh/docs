## Ziel

Mit einer Outlook-Lizenz können Sie den Outlook E-Mail-Client nutzen, um die E-Mails Ihres Exchange Account einzusehen und zu verwalten.

OVHcloud bietet Ihnen die Outlook-Lizenz zum monatlichen Preis von 2 Euro (ohne MwSt.) an. Sie wird einem OVHcloud Exchange Account zugewiesen, dessen Verwaltung Sie innehaben.

Nach Ihrer Bestellung können Sie Outlook als eine der 3 folgenden Versionen herunterladen:

- Outlook für Windows 32 Bit
- Outlook für Windows 64 Bit
- Outlook für MAC 64 Bit

**Diese Anleitung erklärt, wie Sie eine Outlook-Lizenz von Ihrer OVHcloud Exchange-Plattform aus bestellen und aktivieren.**

## In der praktischen Anwendung

### Outlook-Lizenz bestellen

#### Für einen Hosted Exchange Account

<img className="thumbnail" alt="Outlook" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/order-outlook01.png" loading="lazy" />

Legen Sie das Verlängerungsintervall Ihrer Outlook-Lizenz fest und bestätigen Sie die Bedingungen. Klicken Sie anschließend auf <code className="action">Weiter</code>.

<img className="thumbnail" alt="Outlook" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/order-outlook02.png" loading="lazy" />

Überprüfen Sie die Zusammenfassung Ihrer Bestellung und klicken Sie dann auf den Button <code className="action">Bezahlen</code>, um den Bestellschein zu erstellen. Sie werden auf eine neue Seite weitergeleitet, auf der Sie Ihre Bestellung mit einer Ihrer Zahlungsmethoden begleichen können.

Es dauert einige Minuten, bis Ihre Outlook-Lizenz in Ihrem Kundencenter verfügbar ist.

#### Für einen Private Exchange Account

<img className="thumbnail" alt="Outlook" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/order-outlook03.png" loading="lazy" />

Im neuen Fenster werden Sie gefragt, ob Sie die Outlook-Lizenz für Ihren Exchange Account aktivieren möchten. Klicken Sie auf <code className="action">Bestätigen</code>, um die Lizenz für den betreffenden Account zu aktivieren.

<img className="thumbnail" alt="Outlook" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/order-outlook04.png" loading="lazy" />

Es dauert einige Minuten, bis Ihre Outlook-Lizenz in Ihrem Kundencenter verfügbar ist.

:::info
Die Kosten der Outlook-Lizenz werden jeden Monat in die Abrechnung Ihrer Private Exchange Plattform integriert.

:::


### Outlook herunterladen und installieren

Sie können nun die Installationsdatei für Ihr System herunterladen.

Klicken Sie in Ihrem Kundencenter auf den Button <code className="action">...</code> rechts neben dem betreffenden Exchange Account und dann auf <code className="action">Outlook-Lizenz verwenden</code>.

Wählen Sie die Version im Drop-down-Menü passend zu Ihrem Betriebssystem und der Sprache aus und klicken Sie dann auf <code className="action">Weiter</code>.

<img className="thumbnail" alt="Outlook" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/order-outlook05.png" loading="lazy" />

Kurz darauf wird ein Download-Link sowie der zur Aktivierung der Installation benötigte Lizenz-Key bereitgestellt.

<img className="thumbnail" alt="Outlook" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/order-outlook06.png" loading="lazy" />

Die heruntergeladene Datei ist im Format .ISO, also ein Disk Image. Starten Sie die Installation und geben Sie den Lizenz-Key ein, wenn dieser angefordert wird.

### Outlook-Lizenz von Ihrem Account löschen

<img className="thumbnail" alt="Outlook" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/office-outlook-license/order-outlook07.png" loading="lazy" />

Nach der Bestätigung wird die Lizenz zum Ablaufdatum endgültig gelöscht.
