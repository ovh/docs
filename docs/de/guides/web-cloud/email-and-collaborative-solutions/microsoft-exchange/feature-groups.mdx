## Ziel

Mit Exchange Gruppen können mehrere Benutzer durch Senden von E-Mails an eine Gruppenadresse untereinander kommunizieren. Mit dieser kollaborativen Funktion können Sie Mailinglisten erstellen und verwalten, die sowohl Exchange Benutzer als auch externe Kontakte enthalten können.

**In dieser Anleitung wird erläutert, wie Sie Exchange Gruppen über das OVHcloud Kundencenter und die Outlook Web App (OWA) verwenden.**

## Voraussetzungen

- Sie haben eine [OVHcloud Exchange Lösung](https://www.ovhcloud.com/de/emails/hosted-exchange/), die bereits eingerichtet ist.

## In der praktischen Anwendung

### Eine neue Gruppe erstellen

Gehen Sie dann auf den Tab <code className="action">Gruppen</code>.

<img className="thumbnail" alt="contactgroups" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/exchange-groups-create01.png" loading="lazy" />

Wenn Sie auf <code className="action">Kontaktgruppe erstellen</code> klicken, öffnet sich ein neues Fenster, in dem Sie die Gruppeneinstellungen definieren können:

<img className="thumbnail" alt="contactgroups" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/exchange-groups-create02.png" loading="lazy" />

- **E-Mail-Adresse**: Die neue Adresse, von der aus Nachrichten an die Mailingliste gesendet werden. Beachten Sie, dass Sie keine existierende E-Mail-Adresse eingeben können.
- **Name der Gruppe**: Der Anzeigename, der in Ihrem [OVHcloud Kundencenter](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.de/&ovhSubsidiary=de) und in [OVHcloud Webmail](https://www.ovhcloud.com/de/mail/) (OWA) erscheint.
- **Maximale Größe eingehend/ausgehend**: Sie können die maximale Größe eingehender und ausgehender E-Mails angeben.
- **Adresse in Outlook verbergen**: Wenn diese Option aktiviert ist, wird die Gruppenadresse nicht in der Adressliste des Exchange Dienstes angezeigt.
- **Authentifizierung erforderlich**: Wenn diese Option aktiviert ist, können nur Benutzer auf derselben Plattform eine Nachricht mit der Gruppenadresse senden.

Klicken Sie auf <code className="action">Weiter</code>, um fortzufahren.

Wählen Sie auf der zweiten Seite die **Kontakte** der Gruppe aus, und definieren Sie die **Administratoren**. Die Auswahl umfasst nur E-Mail-Adressen und externe Kontakte, die bereits für den Exchange Dienst angelegt wurden.

- **Administratoren**: E-Mail-Accounts, die E-Mails an alle Gruppenkontakte senden dürfen.
- **Kontakte**: E-Mail-Accounts, die von Administratoren an die Gruppe gesendete E-Mails empfangen.

:::info
Bitte beachten Sie, dass Administratoren als **Kontakte** konfiguriert sein müssen, um Gruppen-E-Mails zu erhalten.

:::


<img className="thumbnail" alt="ContactGroups" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/exchange-groups-create03.png" loading="lazy" />

Klicken Sie auf <code className="action">Weiter</code>, um fortzufahren, und klicken Sie auf <code className="action">Bestätigen</code>, um Ihre Auswahl abzuschließen.

### Gruppen verwalten

Nachdem die Gruppe erstellt wurde, können Sie die die oben beschriebenen Einstellungen anpassen, indem Sie auf <code className="action">...</code> rechts der Gruppe in der Tabelle klicken.

<img className="thumbnail" alt="contactGroups" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/exchange-groups-options01.png" loading="lazy" />

#### Benutzer in einer Gruppe verwalten

Um `Kontakte` zu Ihrer Gruppe hinzuzufügen oder `Administratoren` zu definieren, klicken Sie auf den Button <code className="action">...</code> und dann auf <code className="action">Benutzer konfigurieren</code>. Markieren Sie die Attribute, die Sie den E-Mail-Adressen in der Spalte `E-Mail-Account` zuordnen möchten.

:::info
Eine Gruppe kann bis zu 10.000 Kontakte enthalten.

:::


<img className="thumbnail" alt="ContactGroups" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/exchange-group-options-users01.png" loading="lazy" />

#### Delegierungen einer Gruppe verwalten

Die Menüoption <code className="action">Berechtigungen konfigurieren</code> erlaubt es, den Zugriff auf dieselbe Weise wie für einen Exchange Account übertragen. Weitere Details finden Sie in [dieser Anleitung](/guides/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-delegation/).

<img className="thumbnail" alt="contactGroups" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/feature-groups/exchange-groups-options-delegation01.png" loading="lazy" />

:::info
Beachten Sie, dass es einige Minuten dauern kann, bis alle Änderungen an diesem Dienst wirksam werden. Sie können den Status der meisten Operationen überprüfen, indem Sie im horizontalen Menü die Optionen <code className="action">Mehr</code> und <code className="action">Aktuelle Tasks</code> auswählen.

:::


### Nachricht an eine Gruppe mit OWA senden

Sie können jetzt Ihre Mailingliste über [OVHcloud Webmail](https://www.ovhcloud.com/de/mail/) (OWA) testen: Senden Sie einfach eine E-Mail an die Gruppenadresse.
