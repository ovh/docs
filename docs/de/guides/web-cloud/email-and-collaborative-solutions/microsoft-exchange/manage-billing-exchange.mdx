## Ziel

Die Dienste Hosted Exchange und Private Exchange bieten hinsichtlich der Abrechnung einzelner Accounts eine flexible Verwaltung.

**Diese Anleitung erläutert alle Schritte zur Konfiguration der Laufzeit von Exchange Accounts über Ihr OVHcloud Kundencenter.**

## Voraussetzungen

- Sie haben bereits einen [OVHcloud Exchange](https://www.ovhcloud.com/de/emails/hosted-exchange/) Dienst eingerichtet.

## In der praktischen Anwendung

### Hosted Exchange

#### Zusätzliche Accounts bestellen

Gehen Sie dann auf den Tab <code className="action">E-Mail-Accounts</code>. Klicken Sie dann links auf den Button <code className="action">Aktionen</code> und auf <code className="action">Accounts bestellen</code>.

<img className="thumbnail" alt="billing_exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-billing-exchange/billing-exchange-00.png" loading="lazy" />

#### Den Verlängerungszeitraum Ihrer Accounts ändern <a name="periodicity"></a>

Klicken Sie dann rechts oben auf den Button <code className="action">Aktionen</code> und auf <code className="action">Verlängerung konfigurieren</code>.

<img className="thumbnail" alt="billing_exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-billing-exchange/billing-exchange-01.png" loading="lazy" />

Sie werden weitergeleitet zum Bereich „Meine Dienste“ Ihres Kundencenters. Sie werden feststellen, dass ein Filter angewendet wird, um nur den Exchange Dienst anzuzeigen, für den Sie die Änderung vornehmen.

Klicken Sie in der Tabelle auf <code className="action">...</code> und danach auf <code className="action">Abrechnung bearbeiten</code>.

<img className="thumbnail" alt="billing_exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-billing-exchange/billing-exchange-02.png" loading="lazy" />

In der neuen Ansicht können Sie die Abrechnungsintervalle für jeden Ihrer Accounts anzeigen und ändern. Es ist möglich, Änderungen in der Spalte „**Verlängerung**“ bei einem oder mehreren Accounts gleichzeitig vorzunehmen. Jede Änderung an einem Account wird an dem Datum wirksam, das in der Spalte „**Ablaufdatum**“ angegeben ist.

Im folgenden Beispiel sind die notwendigen Schritte aufgeführt, um einen Acccount auf die monatliche Verlängerung einzustellen:

> Klicken Sie im ersten Schritt auf „**Monatlich**“ rechts vom Account Ihrer Wahl und danach weiter unten links auf <code className="action">Weiter</code>.
>
> Im zweiten Schritt zeigt eine Zusammenfassung die durchzuführende Änderung an. Klicken Sie unten links auf <code className="action">Absenden</code>.
>
> <img className="thumbnail" alt="billing_exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-billing-exchange/billing-exchange-03.png" loading="lazy" />

#### Accounts entfernen

Um einen Account von der Hosted Exchange Plattform zu löschen, müssen Sie ihn zunächst kündigen, indem Sie die Konfiguration für die Verlängerung auf „**Zum Ablaufdatum schließen**“ ändern. Informationen hierzu finden Sie im Abschnitt [Den Verlängerungszeitraum Ihrer Accounts ändern](#periodicity).

Hiernach wird der Account am Ablaufdatum gesperrt. Wenn Sie die vom Account verwendete E-Mail-Adresse vor dem Ablaufdatum löschen möchten (etwa, weil diese Adresse direkt weiter verwendet werden soll), setzen Sie noch den Account zurück.

Gehen Sie dann auf den Tab <code className="action">E-Mail-Accounts</code>. Klicken Sie auf <code className="action">...</code> rechts des betreffenden Accounts und schließlich auf <code className="action">Zurücksetzen</code>. Nach dem Zurücksetzen bleibt das Konto leer, bis es abläuft.

### Private Exchange

:::info
Auf einer Private Exchange Plattform werden Accounts nur monatlich verlängert. Es muss keine Verlängerung konfiguriert werden.

:::


#### Zusätzliche Accounts bestellen

Gehen Sie auf den Tab <code className="action">E-Mail-Accounts</code>. Klicken Sie dann links auf den Button <code className="action">Aktionen</code> und auf <code className="action">Account hinzufügen</code>. Der Account wird für den aktuellen Monat in Rechnung gestellt.

<img className="thumbnail" alt="billing_exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-billing-exchange/billing-exchange-06.png" loading="lazy" />

#### Accounts entfernen

:::warning
Um einen E-Mail-Account auf einer Private Exchange Plattform löschen zu können, **muss dieser konfiguriert worden sein** (verbunden mit einem Domainnamen Ihrer Exchange Plattform). Ein unkonfigurierter Account kann nicht gelöscht werden.

:::


Gehen Sie auf den Tab <code className="action">E-Mail-Accounts</code>. Klicken Sie auf <code className="action">...</code> rechts des betreffenden Accounts und schließlich auf <code className="action">Löschen</code>. Der Account wird sofort von der Plattform gelöscht; es erfolgt keine Kündigung.

<img className="thumbnail" alt="billing_exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-billing-exchange/billing-exchange-07.png" loading="lazy" />

### Plattform kündigen

Nachdem Sie die E-Mail-Accounts gelöscht haben, müssen Sie die Ihrer Exchange Plattform zugeordneten Domains löschen, bevor Sie diese kündigen können. Gehen Sie hierzu auf den Tab <code className="action">Assoziierte Domains</code>. Klicken Sie auf den Button <code className="action">...</code> in der Zeile des Domainnamens, den Sie löschen möchten, und klicken Sie dann auf <code className="action">Diese Domain löschen</code>.

<img className="thumbnail" alt="billing_exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-billing-exchange/billing-exchange-del-dom.png" loading="lazy" />

Klicken Sie im Verwaltungsfenster Ihrer Exchange-Plattform oben rechts auf <code className="action">Aktionen</code> und dann auf <code className="action">Kündigen</code>.

<img className="thumbnail" alt="billing_exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/manage-billing-exchange/billing-exchange-08.png" loading="lazy" />

:::info
Diese Aktion führt zur Aussetzung und anschließenden Löschung sämtlicher Accounts auf der Exchange Plattform am Ablaufdatum.

:::
