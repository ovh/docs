## Ziel

Sie können den Inhalt Ihrer Datenbank über ein Interface einsehen. Es gibt verschiedene Möglichkeiten, sich damit zu verbinden.

**Diese Anleitung erklärt, wie Sie sich mit Ihrer Datenbank auf Ihrem Datenbankserver verbinden.**

## Voraussetzungen

- Sie verfügen über eine [Web Cloud Databases Instanz](https://www.ovhcloud.com/de/web-cloud/databases/) (in einem [Performance Webhosting](https://www.ovhcloud.com/de/web-hosting/) Angebot enthalten).

## In der praktischen Anwendung

:::info
[Web Cloud Databases](https://www.ovhcloud.com/de/web-cloud/databases/) Dienste gewähren keinen Zugriff auf den Datenbankserver selbst, sondern auf die darauf gehosteten Datenbanken.

- Es gibt keinen Super-User-Zugang "root".
- Generische SQL-Befehle funktionieren normal, und Programme wie HeidiSQL, SQuirreL SQL oder Adminer sind vollständig kompatibel.

:::


### Mit einer MySQL oder MariaDB Datenbank verbinden

:::info
Da MariaDB ein Derivat von MySQL ist, sind die Befehle für diese beiden Datenbanktypen exakt gleich.

:::


#### Verbindung über OVHcloud phpMyAdmin

Klicken Sie auf die unten stehenden Tabs, um die **4** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite [Web Cloud Databases](https://manager.eu.ovhcloud.com/#/web/web/private_database), und wählen Sie die betreffende Lösung aus.
    
    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Rufen Sie die folgenden Verbindungsinformationen ab:
    
    - **Server (Hostname) und Port:** sichtbar im Tab <code className="action">Allgemeine Informationen</code>, Bereich "Verbindungsinformationen".
    - **Benutzername:** sichtbar im Tab <code className="action">Benutzer und Rechte</code>.
    - **Passwort:** das dem Benutzer zugehörige Passwort. Wenn Sie es vergessen haben, gehen Sie zum Tab <code className="action">Benutzer und Rechte</code>, klicken Sie rechts neben dem betreffenden Benutzer auf <code className="action">...</code> und dann auf <code className="action">Passwort ändern</code>.
    
    :::warning
    Wenn Sie das Passwort eines Datenbankbenutzers ändern, müssen alle Anwendungen und Websites, die auf diese Datenbank zugreifen, entsprechend aktualisiert werden.

    :::

  </Tab>
  <Tab label="Schritt 3">
    Suchen Sie im Tab <code className="action">Allgemeine Informationen</code> den Bereich **Administration der Datenbank** und klicken Sie auf den phpMyAdmin-Link unter **Benutzer-Interface**.
    
    <img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/general-information/database-administration.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 4">
    Geben Sie auf der phpMyAdmin-Loginseite die in Schritt 2 abgerufenen Informationen ein:
    
    <img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-login-web-cloud-db.png" loading="lazy" />
    
    - **Server:** Geben Sie den *Hostnamen* gefolgt von der *Port-Nummer* ein, getrennt durch "**:**" oder ein "**Leerzeichen**". Beispiel: **aaXXXXX-XXX.eu.clouddb.ovh.net:12345**.
    - **Username:** Geben Sie den *Benutzernamen* ein.
    - **Password:** Geben Sie das *Passwort* ein.
  </Tab>
</Tabs>


Wenn die Verbindung erfolgreich ist, wird die folgende Seite angezeigt.

<img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-main-page-web-cloud-db.png" loading="lazy" />

:::warning
**Im Fehlerfall:**

- Fehler #1045 bedeutet, dass die Zugangsdaten falsch sind. Überprüfen Sie Ihren Benutzernamen und/oder Ihr Passwort.
- Fehler #2005 bedeutet, dass der Servername überprüft werden sollte und ob dieser korrekt funktioniert.

:::


#### Verbindung zur Datenbank außerhalb des Kundencenters

:::warning
Wenn Sie eine "Web Cloud Databases"/"Private SQL"-Lösung verwenden, denken Sie daran, Ihre IP-Adresse mithilfe der Anleitung zur [Konfiguration Ihres Datenbankservers](/guides/web-cloud/web-cloud-databases/configure-database-server#gerer-vos-acces/) zu autorisieren.

:::


Klicken Sie auf die unten stehenden Tabs, um die **2** Schritte nacheinander anzuzeigen.

<Tabs>
  <Tab label="Schritt 1">
    Gehen Sie auf die Seite [Web Cloud Databases](https://manager.eu.ovhcloud.com/#/web/web/private_database), und wählen Sie die betreffende Lösung aus.
    
    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Schritt 2">
    Rufen Sie die folgenden Verbindungsinformationen ab:
    
    - **Server (Hostname):** sichtbar im Tab <code className="action">Allgemeine Informationen</code>, Bereich **"Administration der Datenbank"**, "Hostname" im Abschnitt **SQL**.
    - **Port:** sichtbar am gleichen Ort, "Port" im Abschnitt **SQL**.
    - **Benutzername:** sichtbar im Tab <code className="action">Benutzer und Rechte</code>.
    - **Passwort:** das dem betreffenden Benutzer zugehörige Passwort.
    - **Datenbankname:** sichtbar im Tab <code className="action">Datenbanken</code>.
  </Tab>
</Tabs>


**Klicken Sie auf die Verbindungsmethode Ihrer Wahl, um den Inhalt anzuzeigen.**

<details>

<summary>Verbindung über die Kommandozeile</summary>


```bash
mysql --host=server --user=user --port=port --password=password database_name
```

</details>


<details>

<summary>Verbindung per PHP-Skript</summary>


```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

</details>


<details>

<summary>Software-Verbindung (SQuirreL SQL)</summary>


:::info
In unserem Beispiel verwenden wir die Open-Source-Software SQuirreL, aber andere Interfaces wie HeidiSQL oder Adminer sind vollständig kompatibel.

:::


- Starten Sie SQuirreL SQL und klicken Sie auf <code className="action">Aliases</code> und dann auf <code className="action">+</code>.

<img className="thumbnail" alt="launch SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Füllen Sie die folgenden Felder aus und bestätigen Sie mit dem Button <code className="action">OK</code>:
    - **Name**: Wählen Sie einen Namen
    - **Driver**: Wählen Sie "MySQL Driver"
    - **URL**: Geben Sie die Serveradresse und den Port im Format jdbc:mysql://server:port ein
    - **User Name**: Geben Sie den Benutzernamen ein
    - **Password**: Geben Sie das Passwort ein

<img className="thumbnail" alt="config connection" src="/images/assets/screens/other/web-tools/squirrel/add-alias.png" loading="lazy" />

- Bestätigen Sie erneut mit dem Button <code className="action">Verbinden</code>.

<img className="thumbnail" alt="valid connection" src="/images/assets/screens/other/web-tools/squirrel/connect-to-mysql.png" loading="lazy" />

Sie sind nun mit Ihrer Datenbank verbunden:

<img className="thumbnail" alt="config connection" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard.png" loading="lazy" />

</details>


<details>

<summary>Verbindung über phpMyAdmin</summary>


Sie können Ihr eigenes phpMyAdmin-Interface verwenden, um den Inhalt Ihrer Datenbank zu durchsuchen. Installieren Sie dazu phpMyAdmin auf Ihrem eigenen Server oder Webhosting. Achten Sie bei der Installation darauf, die Verbindungsinformationen Ihres Datenbankservers und der gewünschten Datenbank korrekt zu konfigurieren, damit phpMyAdmin sich damit verbinden kann.

</details>
