## Ziel

Die Berechtigungen und Passwörter von Nutzern des vSphere Clients werden im OVHcloud Kundencenter verwaltet.

**Diese Anleitung erklärt, wie Sie Ihr Nutzerpasswort ändern können.**

## Voraussetzungen

- Sie haben Zugriff auf Ihr [OVHcloud Kundencenter](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.de/&ovhSubsidiary=de).
- Im OVHcloud Kundencenter wurde ein Nutzeraccount für Sie angelegt.  Bitte entnehmen Sie [dieser Anleitung](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/manager-ovh-private-cloud#benutzer/) weitere Informationen.

## In der praktischen Anwendung

### Passwort ändern

Loggen Sie sich in Ihrem [OVHcloud Kundencenter](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.de/&ovhSubsidiary=de) ein und wählen Sie dann den Bereich `Hosted Private Cloud` (1). Klicken Sie im linken Menü auf `Hosted Private Cloud` (2) und wählen Sie die betreffende Infrastruktur aus (3). Klicken Sie dann auf den Tab <code className="action">Nutzer</code> (4).

<img className="thumbnail" alt="Zugang zum Kundencenter" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/changement-du-mot-de-passe-utilisateur/userpassword1b.png" loading="lazy" />

Klicken Sie auf die Schaltfläche <code className="action">(...)</code> rechts neben dem jeweiligen Nutzer, dann auf <code className="action">Passwort ändern</code>.

<img className="thumbnail" alt="Passwort ändern" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/changement-du-mot-de-passe-utilisateur/userpassword2b.png" loading="lazy" />

Geben Sie nun ein neues Passwort ein und bestätigen Sie es.

<img className="thumbnail" alt="Passwort ändern" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/changement-du-mot-de-passe-utilisateur/userpassword3b.png" loading="lazy" />

:::info
Wenn Sie kein neues Passwort eingeben, wird ein zufällig generiertes Passwort per E-Mail an die Adresse gesendet, die mit dem Nutzer verbunden ist.

:::


:::warning
:::

>Um die Sicherheit Ihrer Infrastruktur nicht zu gefährden empfehlen wir Ihnen, diese bewährte Verfahren zu befolgen. Ihr Passwort muss:
>
> - Aus mindestens 8 Zeichen bestehen.
> - Mindestens 3 verschiedene Zeichentypen enthalten.
> - Es darf kein Wort aus dem Wörterbuch sein.
> - Es darf keine privaten Informationen enthalten.
> - Es darf nicht für mehrere Zugänge verwendet werden.
> - In einem Passwort-Manager gespeichert sein.
> - Alle drei Monate geändert werden.
> - Sich von den vorherigen Passwörtern unterscheiden.
>
