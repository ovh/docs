## Objective

vSAN disks are regularly upgraded with new versions. You need to update the vSAN disk format version to have new features or to maintain compatibility with the versions of your VMware cluster, as described in this article: [Understanding vSAN on-disk format versions and compatibility (2148493)](https://kb.vmware.com/s/article/2148493).

**This guide explains how to update the format of your vSAN disks.**

## Requirements

- Being an administrative contact of your [Hosted Private Cloud infrastructure](https://www.ovhcloud.com/de/enterprise/products/hosted-private-cloud/) to receive login credentials
- A user account with access to vSphere as well as the specific rights for NSX (created in the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.de/&ovhSubsidiary=de))
- A deployed [vSan cluster](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/)

## Instructions

Log in to your vSphere interface using [this guide](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vsphere-interface-connexion/).

In the vSphere interface, click on your <code className="action">Cluster</code> to the left, go to the <code className="action">Configure</code> tab, choose <code className="action">Services</code> in the **vSAN** section and click <code className="action">PRE-CHECK UPGRADE</code>.

<img className="thumbnail" alt="01 vSAN disk format upgrade 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan-disk-format-upgrade/01-vsan-disk-format-upgrade01.png" loading="lazy" />

The check result informs you that everything is in order to perform the upgrade.

Click on <code className="action">UPGRADE</code>.

<img className="thumbnail" alt="01 vSAN disk format upgrade 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan-disk-format-upgrade/01-vsan-disk-format-upgrade02.png" loading="lazy" />

In the new window, click <code className="action">UPGRADE</code> to confirm the operation.

<img className="thumbnail" alt="01 vSAN disk format upgrade 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan-disk-format-upgrade/01-vsan-disk-format-upgrade03.png" loading="lazy" />

The upgrade will take a few moments.

<img className="thumbnail" alt="01 vSAN disk format upgrade 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan-disk-format-upgrade/01-vsan-disk-format-upgrade04.png" loading="lazy" />

As soon as the upgrade is complete, you will receive a success message indicating the new vSAN disk format version number.

<img className="thumbnail" alt="01 vSAN disk format upgrade 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan-disk-format-upgrade/01-vsan-disk-format-upgrade05.png" loading="lazy" />
