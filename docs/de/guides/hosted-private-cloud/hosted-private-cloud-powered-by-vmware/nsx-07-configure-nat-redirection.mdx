## Instructions

When you deploy your NSX solution, a SNAT rule is automatically created by OVHcloud, so you can go online from your segments.

We will add a redirection rule (DNAT) from the public virtual IP address on port 2222 in TCP to a virtual machine on LINUX on port 22 in TCP. In our example, we will use fictitious IP addresses.

In the NSX interface, go to the <code className="action">Networking</code> tab, select <code className="action">NAT</code> in the **Network Services** section, then select <code className="action">ovh-T0-gw | Tier-0</code> to the right of **Gateway** and click <code className="action">ADD NAT RULE</code>.

<img className="thumbnail" alt="01 Create DNAT rule 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules01.png" loading="lazy" />

Fill in this information :

- **Action** : Select <code className="action">DNAT</code>.
- **Source IP** : Enter the IP address or range of addresses that can use this redirection.
- **Destination IP** : Public virtual IP address of NSX.
- **Destination PORT** : Listening port on public address such as `2222`.
- **Translated IP** : IP address of the virtual machine being redirected to.

Then click on the <code className="action">three vertical dots</code> to the right of **Select Services**.

<img className="thumbnail" alt="01 Create DNAT rule 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules02.png" loading="lazy" />

Enter <code className="action">SSH22</code> under the **Name** column and click <code className="action">Set</code> under the **Service Entry** column.

<img className="thumbnail" alt="01 Create DNAT rule 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules03.png" loading="lazy" />

Click <code className="action">ADD SERVICE ENTRY</code>.

<img className="thumbnail" alt="01 Create DNAT rule 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules04.png" loading="lazy" />

Fill in these values :

- **Name** : Enter `SSH22`.
- **Service Type** : Select <code className="action">TCP</code>.
- **Source Ports** : Write the number `22`.

Then click <code className="action">APPLY</code>.

<img className="thumbnail" alt="01 Create DNAT rule 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules05.png" loading="lazy" />

Click <code className="action">SAVE</code>.

<img className="thumbnail" alt="01 Create DNAT rule 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules06.png" loading="lazy" />

Click <code className="action">SAVE</code> to confirm the creation of the redirection rule.

<img className="thumbnail" alt="01 Create DNAT rule 07" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules07.png" loading="lazy" />

The rule is created and active.

<img className="thumbnail" alt="01 Create DNAT rule 08" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules08.png" loading="lazy" />
