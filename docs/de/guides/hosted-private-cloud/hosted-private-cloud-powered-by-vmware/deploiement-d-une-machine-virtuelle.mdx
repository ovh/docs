## Einleitung

Es gibt mehrere Möglichkeiten, um virtuelle Maschinen über Ihr vSphere Interface zu deployen. 

**In dieser Anleitung erfahren Sie, wie Sie eine virtuelle Maschine mithilfe einer ISO-Datei erstellen.**

## Voraussetzungen

- Sie verfügen über ein [Private Cloud](https://www.ovhcloud.com/de/enterprise/products/hosted-private-cloud/) Produkt.
- Sie sind auf Ihrem [vSphere Interface](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vsphere-interface-connexion/) eingeloggt.

## Beschreibung

### Virtuelle Maschine deployen

Das Deployment der neuen virtuellen Maschine geschieht über den vSphere Client im Bereich `Hosts und Cluster`.

Klicken Sie mit der rechten Maustaste auf den Cluster Ihrer Wahl und dann auf <code className="action">Neue virtuelle Maschine</code>.

<img className="thumbnail" alt="VM deployen" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm01.png" loading="lazy" />

Sie haben mehrere Optionen, um eine virtuelle Maschine zu erstellen:

- per ISO-Datei, verfügbar in Ihrem Datastore. Sie können [ein ISO in einen Datastore hochladen](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-datastore-upload/).
- über ein eigenes oder ein [von OVHcloud bereitgestelltes](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/) Template
- durch Klonen einer bereits vorhandenen virtuellen Maschine (achten Sie darauf, mögliche Konflikte in der IP-Adressierung zu vermeiden)
- durch Klonen einer virtuellen Maschine als Template, für ein schnelleres Deployment der nächsten virtuellen Maschinen
- Klonen eines Templates als ein anderes Template, um das Template beispielsweise auf verschiedenen Datastores abzulegen und Leistungseinbußen bei umfangreicheren Deployments zu vermeiden
- durch Konvertieren eines Templates in eine virtuelle Maschine. Dies führt zum Verlust des Templates, kann jedoch nützlich sein, wenn Sie dieses ändern möchten

<img className="thumbnail" alt="Erstellungsoptionen" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm02.png" loading="lazy" />

In dieser Anleitung erklären wir, wie Sie eine virtuelle Maschine mithilfe einer ISO-Datei erstellen.

Im folgenden Schritt können Sie den Namen Ihrer Maschine sowie deren Speicherort festlegen. Wenn Sie keinen Ordner auswählen, wird sie im Wurzelverzeichnis des Datacenters erstellt.

<img className="thumbnail" alt="Speicherort der virtuellen Maschine" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm03.png" loading="lazy" />

Anschließend können Sie den Cluster, den Host, [den Ressourcenpool](https://docs.vmware.com/de/VMware-vSphere/6.7/com.vmware.vsphere.resmgmt.doc/GUID-60077B40-66FF-4625-934A-641703ED7601.html) oder die [vApp](https://docs.vmware.com/de/VMware-vSphere/6.7/com.vmware.vsphere.vm_admin.doc/GUID-E6E9D2A9-D358-4996-9BC7-F8D9D9645290.html) auswählen, um die VM zu platzieren.

Im vorliegenden Beispiel wird die virtuelle Maschine entsprechend den konfigurierten DRS-Regeln deployt und im Wurzelverzeichnis des Clusters platziert.

<img className="thumbnail" alt="Auswahl der Ressourcen" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm04.png" loading="lazy" />

Wählen Sie nun die Datenbank aus, in der Sie die Konfigurations- und Festplattendateien speichern möchten.

Wir raten Ihnen davon ab, Ihre virtuelle Maschine in „storageLocal“, was dem lokalen Speicher Ihres Hosts entspricht, zu platzieren. Bei einer Störung Ihres Hosts könnte Ihre virtuelle Maschine sonst nicht neu gestartet werden und wäre somit nicht mehr verfügbar.

<img className="thumbnail" alt="Wahl des Speichers" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm05.png" loading="lazy" />

Wählen Sie anschließend die Kompatibilität zwischen Ihrer virtuellen Maschine und dem Host. Außer in Sonderfällen wird empfohlen, die aktuellste Version zu wählen.

<img className="thumbnail" alt="Auswahl der Kompatibilität" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm06.png" loading="lazy" />

Wählen Sie nun ein Gast-Betriebssystem. Das „Guest OS“ installiert nicht das Betriebssystem. Stattdessen wird die virtuelle Maschine automatisch vorkonfiguriert (Anzahl CPU/RAM, Netzwerkkartentyp, Installieren der VMware Tools).

<img className="thumbnail" alt="Auswahl des Gast-Betriebssystems" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm07.png" loading="lazy" />

### Virtuelle Maschine konfigurieren

In den nachfolgenden Schritten können Sie die Ressourcen Ihrer virtuellen Maschine konfigurieren.

In der Zeile `Neues Netzwerk` kann eine Netzwerkkarte hinzugefügt werden:

- „VM-Netzwerk“ wird als öffentliches Netzwerk und für den direkten Internetzugriff verwendet.
- Die VLANs werden für das private Netzwerk zwischen Ihren virtuellen Maschinen (sowie mit anderen OVHcloud Diensten via vRack) verwendet.

<img className="thumbnail" alt="Wahl des Netzwerks" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm08.png" loading="lazy" />

In der Zeile `Neues CD/DVD-Laufwerk` können Sie „ISO-Datei für Datenspeicher“ auswählen.

Es wird ein neues Fenster geöffnet, in dem Sie Ihre ISO-Datei auswählen können. Diese kann auch nach der Erstellung der virtuellen Maschine hinzugefügt werden.

<img className="thumbnail" alt="Auswahl der ISO-Datei" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm09.png" loading="lazy" />

Nachdem Sie die Datei ausgewählt haben, wird sie wie nachstehend angezeigt. Denken Sie daran, diese zu verbinden, indem Sie den Haken bei <code className="action">Beim Einschalten verbinden</code> setzen.

<img className="thumbnail" alt="ISO verbinden" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm10.png" loading="lazy" />

Daraufhin wird Ihnen eine Zusammenfassung zur Erstellung der virtuellen Maschine angezeigt. Wenn Sie Ihre Konfiguration bearbeiten möchten, klicken Sie direkt auf einen der Schritte auf der linken Seite.

Klicken Sie auf <code className="action">BEENDEN</code>, um das Deployment abzuschließen.

<img className="thumbnail" alt="VM Zusammenfassung" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm11.png" loading="lazy" />

Sobald die virtuelle Maschine in Ihrer Bestandsliste angezeigt wird, können Sie diese starten, indem Sie mit der rechten Maustaste auf die VM und dann nacheinander auf <code className="action">Power</code> und auf <code className="action">Einschalten</code> klicken. 

Klicken Sie schließlich auf <code className="action">Remote Console öffnen</code>, um Zugriff auf den Bildschirm der VM zu erhalten und mit der Installation des Betriebssystems zu beginnen.

<img className="thumbnail" alt="VM starten" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm12.png" loading="lazy" />

Die Konsole wird in einem neuen Tab geöffnet und Sie können Ihre neue virtuelle Maschine nach Abschluss der Installation verwenden.

<img className="thumbnail" alt="VM-Konsole" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/deploiement-d-une-machine-virtuelle/vm13.png" loading="lazy" />

:::info
Wir empfehlen Ihnen nach abgeschlossener Installation die ISO-Datei in den Einstellungen zu trennen. Tun Sie dies nicht, können Sie die virtuelle Maschine nicht verschieben.

:::
