## Ziel

Ihr OVHcloud Kunden-Account ermöglicht Ihnen, verschiedene Zahlungsarten zu hinterlegen und zu verwalten.

## Voraussetzungen

- Sie verfügen über eine gültige Zahlungsart.

## In der praktischen Anwendung <a name="payment_methods"></a>

Öffnen Sie die Seite [Zahlungsarten](https://manager.eu.ovhcloud.com/#/billing/payment/method).

<img className="thumbnail" alt="Hubpayment" src="/images/assets/screens/control-panel/product-selection/right-menu/my-payment-methods.png" loading="lazy" />

Die angezeigte Seite enthält eine Tabelle mit den in Ihrem Kundenkonto hinterlegten Zahlungsarten. Sie können dort:

- Eine Zahlungsart hinzufügen.
- Ihre Standardzahlungsart ändern.
- Beschreibung Ihrer Zahlungsart ändern.
- Eine Zahlungsart löschen.

### Eine Zahlungsart hinzufügen

Bei Ihrer ersten Bestellung werden Sie aufgefordert, ein Zahlungsmittel zu hinterlegen, um die Verlängerung Ihrer Dienstleistung per automatischer Lastschrift sicherzustellen.

Dieses Zahlungsmittel wird standardmäßig für alle Ihre Verlängerungen verwendet und Ihnen wird angeboten, neue Bestellungen zu begleichen.

Sie haben die Möglichkeit, andere Zahlungsarten zu hinterlegen, damit diese bei Neubestellungen angeboten werden oder standardmäßig für zukünftige Lastschriften verwendet werden.

Es können drei Zahlungsarten eingetragen werden:

- Kreditkarte
- Lastschrift
- PayPal® Konto

Klicken Sie hierfür auf <code className="action">Zahlungsart hinzufügen</code> und wählen Sie die Zahlungsmethode aus, die Sie verwenden möchten.

<img className="thumbnail" alt="manage-payment-methods" src="/images/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods/managepaymentmethods2.png" loading="lazy" />

Folgen Sie den Schritten für die Eintragung der Zahlungsart. Im ersten Schritt werden Sie aufgefordert, die Option <code className="action">Zahlungsmittel nach Validierung als Standardzahlungsmittel verwenden</code> anzuhaken, damit es für zukünftige Bestellungen oder automatische Lastschriften verwendet werden kann.

#### Lastschrift

:::warning
- Die Verwendung der SEPA-Lastschrift ist nur für französische, belgische, deutsche, spanische, irische, niederländische und italienische Kunden-Accounts möglich.

- Der Inhaber des Bankkontos muss mit dem Inhaber des OVHcloud Kunden-Accounts identisch sein.

:::


Um eine Lastschrift von Ihrem Bankkonto zu hinterlegen, werden Sie zu einem Bereich weitergeleitet, der die Registrierung dieses Accounts und die elektronische Signatur Ihrer Lastschriftanweisung erlaubt.

<img className="thumbnail" alt="Lastschrift SEPA" src="/images/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods/sepa.png" loading="lazy" />

Wenn Ihr Bankinstitut von unserem Partner bereits registriert ist, wird die Hinterlegung des Bankkontos sofort erfolgen. Andernfalls kann eine Bearbeitungsdauer von etwa 48 Stunden erforderlich sein.

#### Kreditkarte

<img className="thumbnail" alt="card-credit" src="/images/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods/credit-card.png" loading="lazy" />

Um eine neue Kreditkarte zu hinterlegen, werden Sie zum gesicherten Interface unseres Zahlungsdienstleisters weitergeleitet. Es wird eine Testabbuchung bei Ihrem Bankinstitut vorgenommen, um Nummer und Gültigkeit der Karte zu überprüfen.<br/>
Es wird kein Betrag abgebucht und Ihre Kreditkarte wird nach einigen Minuten aktiviert.

#### PayPal® Account

<img className="thumbnail" alt="paypal" src="/images/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods/paypal.png" loading="lazy" />

Klicken Sie auf den Button <code className="action">PayPal</code>. Es öffnet sich ein neues Fenster, um sich mit Ihrem PayPal® Account zu verbinden und diesen als autorisiertes Zahlungsmittel bei OVHcloud zu hinterlegen.

Ihr PayPal® Account wird in wenigen Minuten aktiviert.

### Ihre Standardzahlungsart ändern

Die Rechnungen für die Verlängerung Ihrer Dienstleistungen werden automatisch mit Ihrer Standardzahlungsart beglichen. Wenn Sie diese ändern möchten, müssen Sie zuerst in Ihrem OVHcloud Kundencenter eine neue Zahlungsart hinzufügen.

Klicken Sie dafür auf <code className="action">...</code> rechts neben der Zahlungsart und dann auf <code className="action">Dieses Zahlungsmittel als Standardzahlungsmittel festlegen</code>.

<img className="thumbnail" alt="manage-payment-methods" src="/images/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods/managepaymentmethods3.png" loading="lazy" />

> **Ich möchte mein Standardzahlungsmittel durch ein anderes ersetzen, wie kann ich das tun?**
>
> - Schritt 1: Die neue Zahlungsart hinzufügen.
> - Schritt 2: Legen Sie das neue Zahlungsmittel als Standardzahlungsmittel fest.
> - Schritt 3: Die alte Zahlungsart löschen.
>

### Eine Zahlungsart löschen

Wenn Sie eine Ihrer Zahlungsarten nicht mehr verwenden möchten, dann können Sie sie löschen, indem Sie auf <code className="action">...</code> rechts neben der Zahlungsart und dann auf <code className="action">Dieses Zahlungsmittel löschen</code> klicken.

<img className="thumbnail" alt="manage-payment-methods" src="/images/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods/managepaymentmethods4.png" loading="lazy" />

Wenn Sie alle Ihre Zahlungsarten löschen möchten, müssen alle Ihre Dienstleistungen [auf manuelle Verlängerung](/guides/account-and-service-management/managing-billing-payments-and-services/how-to-use-automatic-renewal/) umgestellt werden.

#### Löschen einer Zahlungsart über die OVHcloud API

Die Löschung einer Zahlungsart kann über die API erfolgen. Verbinden Sie sich hierzu über [https://eu.api.ovh.com/](https://eu.api.ovh.com/).

Fordern Sie zuerst die ID der Zahlungsart an:

<Api version="v1" section="/me" method="GET" route={"/me/payment/method"} />

Löschen Sie anschließend die Zahlungsart mithilfe der im vorigen Schritt erhaltenen ID:

<Api version="v1" section="/me" method="DELETE" route={"/me/payment/method/\{paymentMethodId\}"} />


:::info
Mehr Informationen finden Sie in der Einführung zur [Verwendung der OVHcloud API](/guides/manage-and-operate/api/first-steps/).

Falls Sie Schwierigkeiten haben, Ihre Zahlungsarten über die OVHcloud API zu identifizieren, verwenden Sie die Funktion <code className="action">Beschreibung ändern</code> im [Kundencenter](https://manager.eu.ovhcloud.com/#/billing/payment/method). Klicken Sie auf dazu <code className="action">...</code> rechts neben der Zahlungsart im Bereich [Meine Zahlungsarten](#payment_methods).

:::


### Der Prepaid-Account

#### Was ist der Prepaid-Account?

Der Prepaid-Account ist in Ihrem [OVHcloud Kundencenter](https://manager.eu.ovhcloud.com/#/billing/payment/method) verfügbar. Damit können Sie in Ihrem Kunden-Account im Voraus Guthaben aufladen und es für die Bezahlung Ihrer Bestellungen und Verlängerungsrechnungen verwenden.

Wenn Sie Ihren Account regelmäßig aufladen, stellen Sie damit sicher, dass die [automatische Verlängerung](/guides/account-and-service-management/managing-billing-payments-and-services/how-to-use-automatic-renewal/) Ihrer Dienstleistungen nie wegen Zahlungsausfalls unterbrochen wird.

Gehen Sie dazu in den Bereich `Zahlungsarten` Ihres Kundencenters:

- Öffnen Sie die Seite [Zahlungsarten](https://manager.eu.ovhcloud.com/#/billing/payment/method).
- Wählen Sie den Tab <code className="action">Mein Prepaid-Account</code>.

<img className="thumbnail" alt="prepaid-account" src="/images/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods/prepaid-account.png" loading="lazy" />

#### Wie funktioniert der Prepaid-Account?

Wenn Sie über Dienstleistungen verfügen, die auf *automatische Verlängerung* eingestellt sind, wird Ihre Rechnung zuerst von Ihrem Prepaid-Account eingezogen.

Wenn kein ausreichender Betrag zur Verfügung steht, wird der Kontostand entsprechend der ausstehenden Zahlung einen Minusbetrag aufweisen.

Wenn Sie über ein gültiges Zahlungsmittel in Ihrem Kundenkonto verfügen, wird dieser Betrag automatisch innerhalb von 24 Stunden abgebucht und Ihr Guthaben wieder auf Null gesetzt. Dies hat keine Auswirkungen auf den Zustand Ihrer Dienstleistungen.

Wenn Sie jedoch kein Zahlungsmittel hinterlegt haben, müssen Sie diesen Betrag innerhalb von 7 Tagen über Ihr Kundencenter begleichen, um eine Unterbrechung des Dienstes zu vermeiden.

Wenn Sie kein Zahlungsmittel hinterlegt haben, empfehlen wir Ihnen deshalb, einen **Alarm** einzurichten, um sicherzustellen, dass Sie über genügend Mittel für Ihre nächsten Rechnungen verfügen:

<img className="thumbnail" alt="warning_prepaid_account" src="/images/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods/warning_prepaid_account.png" loading="lazy" />

Wenn das für Ihren Prepaid-Account verfügbare Guthaben unter den festgelegten Grenzwert fällt, wird Ihnen eine Benachrichtigung per E-Mail gesendet.

#### Wie kann ich den Prepaid-Account aufladen?

Klicken Sie im Tab <code className="action">Mein Prepaid-Account</code> auf den Button <code className="action">Aufladen</code>.

<img className="thumbnail" alt="credit-prepaid-account" src="/images/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods/credit-prepaid-account.png" loading="lazy" />

Geben Sie im neuen Fenster den aufzuladenden Betrag ein, klicken Sie auf <code className="action">Weiter</code> und dann auf <code className="action">Bestellen</code>.

<img className="thumbnail" alt="order-prepaid-account" src="/images/account-and-service-management/managing-billing-payments-and-services/manage-payment-methods/order-prepaid-account.png" loading="lazy" />

Wählen Sie im angezeigten Bestellschein die Zahlungsart Ihrer Wahl aus und führen Sie die Zahlung aus.
