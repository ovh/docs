## Ziel

OVHcloud bietet Linux, Windows Server und Windows SQL Server Templates (im OVF Format) an, die Sie direkt über Ihren Web-Client (HTML 5) bereitstellen können.

Windows VMs, die von einem Template aus eingerichtet werden, verwenden automatisch die von OVHcloud bereitgestellten SPLA-Lizenzen. Die Inbetriebnahme einer Windows VM führt automatisch zu einer zusätzlichen Abrechnung.

**Hier erfahren Sie, wo Sie die Images finden und wie Sie für die Bereitstellung vorgehen.**

:::info
Auf dieser Seite [finden](https://www.ovhcloud.com/de/managed-bare-metal/options/) Sie die Preise der von OVHcloud angebotenen Images.

:::


## Voraussetzungen

- Sie haben Zugriff auf den Web Client (HTML5).
- [Sie haben die Windows Lizenzen](/guides/bare-metal-cloud/managed-bare-metal/manager-ovhcloud#windows-lizenz/) über Ihr [OVHcloud Kundencenter](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.de/&ovhSubsidiary=de)  aktiviert.

## In der praktischen Anwendung

### Abrufen der URL der OVF Templates

Rufen Sie über Ihren Internetbrowser die Startseite Ihrer Managed Bare Metal auf und klicken Sie auf <code className="action">OVH Templates</code>.

<img className="thumbnail" alt="CNAME-Eintrag" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/gatewayssl.png" loading="lazy" />

Im angezeigten `OVH Templates` Fenster finden Sie Details zu den angebotenen Linux-, Windows- und SQL-Templates. 

Wählen Sie das gewünschte Template aus, es öffnet sich ein Fenster und die Links, die Ihnen für die Inbetriebnahme in Abhängigkeit von Ihrer vSphere Version dienen.

<img className="thumbnail" alt="CNAME-Eintrag" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/copylink.png" loading="lazy" />

### Bereitstellung des OVF Templates

Gehen Sie in Ihrem vSphere Web Client auf <code className="action">Hosts and clusters</code>und wählen Sie mit einem Rechtsklick Ihr Rechenzentrum aus und klicken Sie auf <code className="action">Deploy OVF template...</code>:

<img className="thumbnail" alt="Link kopieren" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/01selectdeploy.png" loading="lazy" />

Das Kontextmenü öffnet sich und die Konfiguration der Bereitstellung beginnt. Fügen Sie in einem ersten Schritt bitte den zuvor kopierten Link ein:

<img className="thumbnail" alt="Link einfügen" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/02puturl.png" loading="lazy" />

Wählen Sie als nächstes das Rechenzentrum aus:

<img className="thumbnail" alt="RZ auswählen" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/03selectdatacenter.png" loading="lazy" />

Und wählen Sie dann das Cluster aus, in dem die virtuelle Maschine bereitgestellt wird:

<img className="thumbnail" alt="Cluster auswählen" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/04selectcluster.png" loading="lazy" />

Sie finden alle Informationen zur Vorlage und ein Standardpasswort. Aus Sicherheitsgründen ist es wichtig, dass Sie das Passwort bei Ihrer ersten Verbindung ändern:

<img className="thumbnail" alt="Template Informationen" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/05detailstemplate.png" loading="lazy" />

Wählen Sie den Speicherort für die virtuelle Maschine und das Festplattenformat aus:

<img className="thumbnail" alt="Speicherort auswählen" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/06selectdatastore.png" loading="lazy" />

Wählen Sie im letzten Schritt das Netzwerk aus, das genutzt werden soll:

<img className="thumbnail" alt="Netzwerk auswählen" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/07selectnetwork.png" loading="lazy" />

Die Konfiguration ist fast beendet. Sie sehen nun einen Überblick aller vorgenommenen Einstellungen.

<img className="thumbnail" alt="Überblick" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/08resume.png" loading="lazy" />

Nachdem Sie auf <code className="action">Finish</code> geklickt haben, wird ein Task erstellt, den Sie zur Nachverfolgung nutzen können.

<img className="thumbnail" alt="Bereitstellung starten" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/09startdeploy.png" loading="lazy" />

Nach Beendigung der Bereitstellung können Sie das Fenster schließen.

Sie finden die bereitgestellte virtuelle Maschine nun in Ihrer Umgebung.

<img className="thumbnail" alt="CNAME-Eintrag" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/10inventory.png" loading="lazy" />

### Fertigstellung der Installation für SQL Server

Starten Sie Ihre dedizierte virtuelle Maschine und öffnen Sie die Konsole.

Öffnen Sie die Windows-Session und geben Sie im dafür vorgesehenen Fenster den Namen Ihrer SQL-Instanz, das Passwort und die gewünschten Zeichensätze ein.

<img className="thumbnail" alt="CNAME-Eintrag" src="/images/bare-metal-cloud/managed-bare-metal/ovf-template/sqlinformations.png" loading="lazy" />

:::info
Es wird empfohlen, ein Passwort zu verwenden, das diese Kriterien erfüllt:

- Es müssen mindestens acht Zeichen enthalten sein.
- Es müssen mindestens drei Arten von Zeichen enthalten sein (Groß-, Klein-, Ziffern, Sonderzeichen).
- Es darf kein Wort aus dem Wörterbuch sein.
- Keine persönlichen Angaben enthalten (Vorname, Name oder Geburtsdatum).

:::


Wenn Sie diese Informationen eingegeben haben, klicken Sie auf <code className="action">OK</code>.

Ein Fenster öffnet sich, in dem die Inbetriebnahme dargestellt ist. Am Ende des Deployments öffnet sich ein letztes Fenster, in dem Sie über den Erfolg der Inbetriebnahme informiert werden.

Klicken Sie erneut auf <code className="action">OK</code>, damit die Installation abgeschlossen und Ihre virtuelle Maschine neu gestartet wird.

Nach dem Neustart können Sie mit der Verwendung Ihrer virtuellen Maschine beginnen.
