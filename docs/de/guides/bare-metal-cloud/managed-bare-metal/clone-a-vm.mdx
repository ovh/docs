## Einleitung

Mit dem Klonen einer VM können Sie eine Kopie der ursprünglichen VM herstellen.

**In dieser Anleitung erklären wir Ihnen, wie Sie diese Aktion durchführen.**

## Voraussetzungen

- Sie verfügen über ein [Managed Bare Metal](https://www.ovhcloud.com/de/managed-bare-metal/) Produkt.
- Sie haben mindestens eine VM in Ihrem Cluster.
- Sie sind auf Ihrem [vSphere Interface](/guides/bare-metal-cloud/managed-bare-metal/vsphere-interface/) angemeldet.

## Praktische Anwendung

### Die VM klonen

Gehen Sie in Ihrem [vSphere Interface ](/guides/bare-metal-cloud/managed-bare-metal/vsphere-interface/) zu `Hosts and Clusters`.

Klicken Sie mit der rechten Maustaste auf die VM, die Sie klonen möchten. Klicken Sie danach auf <code className="action">Clone</code> und daraufhin auf <code className="action">Clone to virtual machine...</code>. 

<img className="thumbnail" alt="Als VM klonen" src="/images/bare-metal-cloud/managed-bare-metal/clone-a-vm/clonevm01.png" loading="lazy" />

Geben Sie dieser neuen VM einen Namen und legen Sie ihren Platz in der Struktur fest. 

<img className="thumbnail" alt="Die VM benennen" src="/images/bare-metal-cloud/managed-bare-metal/clone-a-vm/clonevm02.png" loading="lazy" />

### Ressource auswählen

Geben Sie Cluster, Host, vApp oder Ressourcen-Pool dieser VM an.

<img className="thumbnail" alt="Ressourcen der VM" src="/images/bare-metal-cloud/managed-bare-metal/clone-a-vm/clonevm03.png" loading="lazy" />

### Wahl des Speichers

Legen Sie den Speicherort (Festplattenspeicherplatz) dieser VM fest. 

Das Format der virtuellen Festplatte ist “Thin Provision”. Das bedeutet, dass eine virtuelle Festplatte erstellt wird, diese aber den wirklich verwendeten Speicherplatz einnimmt, ungeachtet des Speicherplatzes, den vorher die ursprüngliche VM eingenommen hat. 

Weitere Erklärungen zu Festplattenformaten finden Sie in [dieser Anleitung](/guides/bare-metal-cloud/managed-bare-metal/choosing-disk-type/).

In der Reihe `VM Storage Policy` können Sie die Standardeinstellung für das Speichern wählen, wenn Sie Datastores haben. Wenn Sie die Option [VM encryption](/guides/bare-metal-cloud/managed-bare-metal/vm-encrypt/) verwenden, können Sie eine nutzerdefinierte Speicherweise wählen.

<img className="thumbnail" alt="VM Storage" src="/images/bare-metal-cloud/managed-bare-metal/clone-a-vm/clonevm04.png" loading="lazy" />

### Systemkonfiguration

In diesem Schritt können Sie die Netzwerkkonfiguration festlegen, die für diese VM gelten soll. Sie haben zwei Optionen zur Wahl:

- Wenn Sie keinen Haken setzen, wird die Netzwerkkonfiguration der neuen VM so sein, wie bei der ursprünglichen VM.

- <code className="action">Die Hardware dieser virtuellen Maschine einrichten (experimentell)</code> : Mit dieser Option können Sie die neuen Konfigurationen angeben, die Sie auf dieser neuen VM vornehmen möchten.

<img className="thumbnail" alt="VM Netzwerk" src="/images/bare-metal-cloud/managed-bare-metal/clone-a-vm/clonevm05.png" loading="lazy" />

:::warning
Wenn Sie keine individuelle Einrichtung der virtuellen Maschine vorgenommen haben, müssen Sie die Konfiguration des Klons vor dem Start ändern. Andernfalls kann es zu Konflikten von IP / MAC kommen. 

:::

>In diesem Fall müssen Sie nur die Wahl der Netzwerkkarte in den Einstellungen der virtuellen Maschine aufheben. Dies tun Sie wenn sie geklont ist und bevor Sie sie starten.
