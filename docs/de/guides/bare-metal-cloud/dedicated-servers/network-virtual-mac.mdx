## Ziel

Bei OVHcloud können Sie eine virtuelle MAC-Adresse mit einer IP-Adresse verbinden, um virtuelle Maschinen mit Bridge-Konfiguration auf Ihrem Server einzurichten.

**Diese Anleitung erklärt, wie Sie eine virtuelle MAC-Adresse erstellen und mit einer Additional IP verbinden.**

## Voraussetzungen

- Sie haben einen [Dedicated Server](https://www.ovhcloud.com/de/bare-metal/) in Ihrem Kunden-Account. Ihr Server muss virtuelle MAC-Adressen unterstützen. Überprüfen Sie dies mithilfe [unserer Anleitung](/guides/bare-metal-cloud/dedicated-servers/network-support-virtual-mac/).
- Sie verfügen über eine [Additional IP](https://www.ovhcloud.com/de/network/additional-ip/).

## In der praktischen Anwendung

### MAC-Adresse zuweisen

:::warning
Wenn ein IP-Block im vRack umgezogen wurde, dann ist es nicht mehr möglich, einer IP eine virtuelle MAC-Adresse zuzuweisen.

:::


#### Über das OVHcloud Kundencenter

Klicken Sie auf den Tab <code className="action">Additional IP</code>.

<img className="thumbnail" alt="manage IPs" src="/images/bare-metal-cloud/dedicated-servers/network-virtual-mac/manageIPs2022.png" loading="lazy" />

Suchen Sie nun in der Liste nach Ihrer Additional IP (oder Ihrem Block) und klicken Sie auf den Button <code className="action">...</code>, um die Optionen anzuzeigen.

<img className="thumbnail" alt="IP" src="/images/bare-metal-cloud/dedicated-servers/network-virtual-mac/addvmac.png" loading="lazy" />

Wenn das Dialogfeld “Virtuelle MAC-Adresse hinzufügen” erscheint, wählen Sie einen Typ in der Drop-down-Liste aus, geben Sie den Namen einer virtuellen Maschine ein und klicken Sie anschließend auf <code className="action">Bestätigen</code>.

:::info
**Typ**: Hierbei handelt es sich um den Typ der virtuellen MAC-Adresse (“VMware” für eine MAC-Adresse für das System VMware ESXi und “OVH” für Adressen für andere Virtualisierungssysteme).

**Name der virtuellen Maschine**: Das ist der gewünschte Name für die virtuelle MAC-Adresse, damit das IP/MAC-Paar später einfacher gefunden werden kann.

:::


<img className="thumbnail" alt="Additional IP" src="/images/bare-metal-cloud/dedicated-servers/network-virtual-mac/addvmac2.png" loading="lazy" />

:::info
Denken Sie daran, die bei der Konfiguration Ihrer virtuellen Maschine erstellte MAC-Adresse zuzuweisen.

:::


#### Über die OVHcloud API

Verwenden Sie folgenden API Aufruf:

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/virtualMac/\{macAddress\}/virtualAddress/\{ipAddress\}"} />


### MAC-Adresse löschen

:::warning
Der Löschvorgang einer MAC-Adresse ist unwiderruflich. Die Adresse kann danach nicht wiederhergestellt werden.

:::


#### Über das OVHcloud Kundencenter

Loggen Sie sich in Ihr [OVHcloud Kundencenter](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.de/&ovhSubsidiary=de) ein, klicken Sie auf <code className="action">Network</code> in der linken Seitenleiste und dann auf <code className="action">Öffentliche IP-Adressen</code>. Wählen Sie den betreffenden Server aus, damit die verbundene Additional IP (oder der mit dem Server verbundene IP-Block) angezeigt wird.

Um den Vorgang abzuschließen, klicken Sie rechts in der Zeile auf den Button <code className="action">...</code> und dann auf <code className="action">Virtuelle MAC-Adresse löschen</code>.

#### Über die OVHcloud API

Verwenden Sie folgenden API Aufruf:

<Api version="v1" section="/dedicated/server" method="DELETE" route={"/dedicated/server/\{serviceName\}/virtualMac/\{macAddress\}/virtualAddress/\{ipAddress\}"} />


## FAQ

- **Was geschieht, wenn ich einen Block mit vMACs auf einen Advance Server der dritten Generation (mit EPYC 4004 Series) verlagere, der bereits über 32 vMACs verfügt?**

Der Block wird nicht verschoben.

Beispiel: Wenn Sie versuchen, einen Block mit 4 IPs zu verschieben, wobei verschiedene vMACs an einen Server mit bereits 30 vMACs angehängt sind, wird der Block nicht verschoben, da die Gesamtanzahl der vMACs die erlaubten 32 vMACs übersteigen würde.
