## Ziel

Dedicated Server der Reihen High Grade und SCALE bieten Ihnen eine Skalierungsoption, mit der Sie Speicherplatz und RAM erhöhen können.

**Diese Anleitung erklärt die Vorgehensweise zum Hardware-Upgrade für OVHcloud Dedicated Server der Reihen High Grade und SCALE.**

:::info
Die in dieser Anleitung beschriebenen Schritte gelten nur für unsere aktuellen Produktreihen High Grade und SCALE. Bei älteren Diensten ist die Anfrage über ein Ticket an den Kundensupport zu richten.

:::


## Voraussetzungen

- Sie haben einen [High Grade Dedicated Server](https://www.ovhcloud.com/de/bare-metal/high-grade/) oder [SCALE Dedicated Server](https://www.ovhcloud.com/de/bare-metal/scale/).

## In der praktischen Anwendung

### RAM hinzufügen

Klicken Sie im Tab <code className="action">Hardware</code> auf <code className="action">RAM hinzufügen</code>.

<img className="thumbnail" alt="increase RAM" src="/images/bare-metal-cloud/dedicated-servers/hardware-upgrade-HG-Scale/increaseram.png" loading="lazy" />

Wählen Sie auf der nächsten Seite die gewünschte Speicheroption aus und klicken Sie auf <code className="action">Bestellen</code>.

<img className="thumbnail" alt="Storage Option" src="/images/bare-metal-cloud/dedicated-servers/hardware-upgrade-HG-Scale/selectram.png" loading="lazy" />

Sobald die Bestellung bezahlt wurde, erhalten Sie eine E-Mail mit einem Link, um den Eingriff für das RAM-Upgrade zu planen.

Wenn Sie auf den Link in der E-Mail klicken, werden Sie zum Dashboard des Dedicated Servers weitergeleitet. Klicken Sie hier auf <code className="action">Den Vorgang planen</code>.

<img className="thumbnail" alt="schedule intervention" src="/images/bare-metal-cloud/dedicated-servers/hardware-upgrade-HG-Scale/ramintervention.png" loading="lazy" />

Setzen Sie einen Haken unter <code className="action">Haben Sie bereits ein Backup Ihrer Daten durchgeführt?</code> und wählen Sie Datum und Uhrzeit aus den angebotenen Zeitfenstern. Bitte beachten Sie, dass ein Eingriff durch die Techniker in unseren Rechenzentren eine gewisse Vorbereitungszeit erfordert. Das erste Verfügbarkeitsdatum wird daher nach einem Zeitraum von mindestens 10 Tagen festgelegt.

Klicken Sie dann auf <code className="action">Bestätigen</code>.

<img className="thumbnail" alt="confirm intervention" src="/images/bare-metal-cloud/dedicated-servers/hardware-upgrade-HG-Scale/ramconfirm.png" loading="lazy" />

Sie erhalten dann eine E-Mail, in der Datum und Uhrzeit des Eingriffs bestätigt werden.

### Storage erhöhen

Klicken Sie im Tab <code className="action">Hardware</code> auf <code className="action">Storage erhöhen</code>.

<img className="thumbnail" alt="increase Storage" src="/images/bare-metal-cloud/dedicated-servers/hardware-upgrade-HG-Scale/increasestorage.png" loading="lazy" />

Wählen Sie auf der nächsten Seite die gewünschte Speicheroption aus und klicken Sie auf <code className="action">Bestellen</code>.

<img className="thumbnail" alt="option de stockage" src="/images/bare-metal-cloud/dedicated-servers/hardware-upgrade-HG-Scale/selectstorage.png" loading="lazy" />

Sobald die Bestellung bezahlt wurde, erhalten Sie eine E-Mail mit einem Link, um den Eingriff für das Hardware-Upgrade zu planen.

Wenn Sie auf den Link in der E-Mail klicken, werden Sie zum Dashboard des Dedicated Servers weitergeleitet. Klicken Sie hier auf <code className="action">Den Vorgang planen</code>.

<img className="thumbnail" alt="schedule intervention" src="/images/bare-metal-cloud/dedicated-servers/hardware-upgrade-HG-Scale/storageintervention.png" loading="lazy" />

Setzen Sie einen Haken unter <code className="action">Haben Sie bereits ein Backup Ihrer Daten durchgeführt?</code> und wählen Sie Datum und Uhrzeit aus den angebotenen Zeitfenstern. Bitte beachten Sie, dass ein Eingriff durch die Techniker in unseren Rechenzentren eine gewisse Vorbereitungszeit erfordert. Das erste Verfügbarkeitsdatum wird daher nach einem Zeitraum von mindestens 10 Tagen festgelegt.

Klicken Sie dann auf <code className="action">Bestätigen</code>.

<img className="thumbnail" alt="confirm intervention" src="/images/bare-metal-cloud/dedicated-servers/hardware-upgrade-HG-Scale/confirmintervention.png" loading="lazy" />

Sie erhalten dann eine E-Mail, in der Datum und Uhrzeit des Eingriffs bestätigt werden.

Möchten Sie gleichzeitig Storage und RAM erweitern? Dann bestellen und bezahlen Sie einfach die beiden Upgrades innerhalb eines Zeitraums von einer Stunde.
