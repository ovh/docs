## Objective

With the private network, compatible dedicated servers benefit from a guaranteed minimum bandwidth of 1 Gbps. In the event of increased activity, this bandwidth can be increased on compatible servers.

**In this guide, we explain how you can easily increase or decrease the private bandwidth of a dedicated server.**

## Requirements

- A [vRack](https://www.ovhcloud.com/de/network/vrack/) service activated in your account
- A [Dedicated Server](https://www.ovhcloud.com/de/bare-metal/) compatible with the vRack
- Access to the [OVHcloud API](/guides/manage-and-operate/api/first-steps/)

:::warning
Please note that this option is not available on dedicated servers located in the APAC (Asia-Pacific) region, which come with an unmetered 25Gbit/s private bandwidth.

:::


## Instructions

### Find available services

Use the following API call to list all the available services for upgrade (or downgrade) and verify that the service you wish to upgrade/downgrade is listed:

<Api version="v1" section="/order" method="GET" route={"/order/upgrade/baremetalPrivateBandwidth"} />


<img className="thumbnail" alt="bandwidth" src="/images/bare-metal-cloud/dedicated-servers/manage-bandwidth-vRack-api/bandwidth_01.png" loading="lazy" />

### Find the plan code

List available offers and find the **planCode** of your choice with the API call below:

<Api version="v1" section="/order" method="GET" route={"/order/upgrade/baremetalPrivateBandwidth/\{serviceName\}"} />

Enter the variables:

- serviceName: the name of your dedicated server, for example `ns1234567.ip-203.0.113.eu`

<img className="thumbnail" alt="bandwidth" src="/images/bare-metal-cloud/dedicated-servers/manage-bandwidth-vRack-api/private-bandwidth-1.png" loading="lazy" />

The `RESPONSE` field should display information similar to the following:

<img className="thumbnail" alt="bandwidth" src="/images/bare-metal-cloud/dedicated-servers/manage-bandwidth-vRack-api/private-bandwidth-2.png" loading="lazy" />

### Review your order

Use the following API call for a preview of your order, including pricing:

<Api version="v1" section="/order" method="GET" route={"/order/upgrade/baremetalPrivateBandwidth/\{serviceName\}/\{planCode\}"} />

Enter the variables:

- planCode: the reference retrieved in the previous step
- serviceName: the name of your dedicated server
- quantity: 1

<img className="thumbnail" alt="bandwidth" src="/images/bare-metal-cloud/dedicated-servers/manage-bandwidth-vRack-api/private-bandwidth-3.png" loading="lazy" />

The `RESPONSE` field should display information similar to the following:

<img className="thumbnail" alt="bandwidth" src="/images/bare-metal-cloud/dedicated-servers/manage-bandwidth-vRack-api/private-bandwidth-4.png" loading="lazy" />

### Submit your order

To officially submit the order, use the following API call:

<Api version="v1" section="/order" method="POST" route={"/order/upgrade/baremetalPrivateBandwidth/\{serviceName\}/\{planCode\}"} />


<img className="thumbnail" alt="bandwidth" src="/images/bare-metal-cloud/dedicated-servers/manage-bandwidth-vRack-api/private-bandwidth-5.png" loading="lazy" />

The order will be processed once you have clicked <code className="action">Execute</code>. The amount displayed corresponds to your option’s first billing month, calculated on a pro rata basis for the current month.
