## Ziel

RAID (Redundant Array of Independent Disks) ist eine Kombination von Techniken, die Datenverluste auf einem Server reduzieren, indem Daten auf mehreren Disks repliziert werden.

Der Standard-RAID-Level der OVHcloud Server ist RAID 1. Dieser verdoppelt das Volumen Ihrer Daten und reduziert so den verfügbaren Speicherplatz.

**Diese Anleitung erklärt, wie Sie die Disks Ihres Servers im RAID 0 Modus konfigurieren, um den maximal nutzbaren Speicherplatz zu verwenden.**

:::warning
Achtung: RAID 0 bietet weder **Fehlertoleranz** noch **Datenredundanz**. Dadurch ist es sehr wahrscheinlich, dass bei einem Ausfall Daten verloren gehen.

:::

Wählen Sie das gewünschte Betriebssystem aus und klicken Sie auf <code className="action">Weiter</code>.

Setzen Sie einen Haken bei **Hardware-RAID-Konfiguration anpassen** und **Konfiguration der Partitionen anpassen** und klicken Sie auf <code className="action">Weiter</code>.

### Rescue-Modus verwenden

Klicken Sie im Bereich **Allgemeine Informationen** auf <code className="action">...</code> neben `Boot`. Wählen Sie dann <code className="action">Bearbeiten</code>, um den Startmodus zu ändern.

<img className="thumbnail" alt="MegaRAID" src="/images/bare-metal-cloud/dedicated-servers/megaraid-config/rescue_mode_raid0_1.png" loading="lazy" />

Klicken Sie auf <code className="action">Im Rescue-Modus booten</code> und wählen Sie <code className="action">rescue-customer</code> aus.

Geben Sie eine alternative E-Mail-Adresse an, wenn Sie *nicht* möchten, dass die Login-Daten an die Hauptadresse Ihres OVHcloud Kunden-Accounts gesendet werden.

<img className="thumbnail" alt="MegaRAID" src="/images/bare-metal-cloud/dedicated-servers/megaraid-config/rescue_mode_raid0_2.png" loading="lazy" />

Klicken Sie auf <code className="action">Weiter</code> um fortzufahren, und dann auf <code className="action">Bestätigen</code>.

<img className="thumbnail" alt="MegaRAID" src="/images/bare-metal-cloud/dedicated-servers/megaraid-config/rescue_mode_raid0_3.png" loading="lazy" />

Wenn die Änderung abgeschlossen ist, klicken Sie auf <code className="action">...</code> rechts neben `Status` im Bereich **Dienststatus**.

Wählen Sie <code className="action">Neu starten</code> aus, um den Server im Rescue-Modus zu starten. Die Durchführung dieser Operation kann einige Minuten dauern. 

<img className="thumbnail" alt="MegaRAID" src="/images/bare-metal-cloud/dedicated-servers/megaraid-config/server_installation_raid0_6.png" loading="lazy" />

Sobald Ihr Server neu gestartet wurde, loggen Sie sich via SSH unter Verwendung Ihrer Zugangsdaten zum Rescue-Modus ein. Diese wurden Ihnen an die Haupt-E-Mail-Adresse des Kunden-Accounts oder gegebenenfalls an die zuvor angegebene E-Mail-Adresse gesendet.

Geben Sie in der Kommandozeile die folgenden Befehle ein, um die bestehenden RAID-Einstellungen zu löschen. Alle RAID-Daten werden gelöscht.

```sh
MegaCli -CfgLdDel -L0 -a0
MegaCli -CfgLdDel -Lall -aAll
```

Geben Sie folgenden Befehl ein, um die Standortdaten Ihrer Disks abzurufen:

```sh
MegaCli -PdList -aALL | egrep "Slot|Device ID"
```

Geben Sie folgenden Befehl ein, um RAID 0 zu konfigurieren:

```sh
MegaCli -CfgLDAdd -R0[252:0,252:1] -a0
```

In diesem Beispiel ist 252 die Kennung des Plattengehäuses.

Nachdem Sie den neuen RAID-Level festgelegt haben, können Sie die Einstellungen mit folgendem Befehl überprüfen:

```sh
MegaCli -LDInfo -Lall -a0 | grep -i size
```
