## Ziel

Die OVHcloud Link Aggregation (OLA) wurde von unseren Teams entwickelt, um die Verfügbarkeit Ihres Servers zu erhöhen und die Effizienz Ihrer Netzwerkverbindungen zu steigern. Mit nur wenigen Klicks können Sie Ihre Netzwerkkarten aggregieren und Ihre Netzwerkverbindungen redundant machen. Wenn also eine Verbindung ausfällt, wird der Datenverkehr automatisch auf eine andere verfügbare Verbindung umgeleitet.<br/>
Die Aggregation basiert auf dem Standard IEEE 802.3ad, Link Aggregation Control Protocol (LACP).

**Diese Anleitung erklärt, wie Sie OLA im OVHcloud Kundencenter einrichten.**

## Voraussetzungen

- Sie haben einen [Dedicated Server](https://www.ovhcloud.com/de/bare-metal/) der Advance, Scale oder High Grade Reihe.
- Sie verwenden ein Betriebssystem / einen Hypervisor mit Unterstützung für das Aggregationsprotokoll 802.3ad (LACP).

## In der praktischen Anwendung

:::warning
OLA wird über alle Netzwerkinterfaces konfiguriert. Sie werden dadurch zu einem Aggregat vom Typ "private aggregation".

Nach der Umsetzung von OLA ist die öffentliche IP nicht mehr verfügbar.

:::


### OLA in Ihrem OVHcloud Kundencenter konfigurieren

Klicken Sie auf <code className="action">Dedicated Server</code> und wählen Sie Ihren Server aus der Liste aus.

<img className="thumbnail" alt="network interfaces" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-manager/network_interfaces2022.png" loading="lazy" />

Klicken Sie im Tab <code className="action">Netzwerkinterfaces</code> (1) auf den Button <code className="action">...</code> (2) rechts von "Modus" in **OLA: OVHcloud Link Aggregation**. Klicken Sie auf <code className="action">Private Aggregation konfigurieren</code> (2).

<img className="thumbnail" alt="select Interface" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-manager/interface_select2021.png" loading="lazy" />

Überprüfen Sie, dass Ihre beiden Interfaces oder Schnittstellengruppen ausgewählt sind, und geben Sie dem OLA Interface einen Namen. Klicken Sie auf <code className="action">Bestätigen</code>, sobald Ihre Überprüfungen abgeschlossen sind.

Es kann einige Minuten dauern, bis der Vorgang abgeschlossen ist. Anschließend werden im nächsten Schritt die Schnittstellen in Ihrem Betriebssystem in einem "NIC link" oder einem "NIC team" konfiguriert. In den folgenden Anleitungen finden Sie Informationen zu den beliebtesten Betriebssystemen:

[Konfigurieren Ihrer Netzwerkkarte für die OVHcloud Link Aggregation in Debian 9 über ifupdown](/guides/bare-metal-cloud/dedicated-servers/ola-enable-debian9/)

[Konfigurieren Ihrer Netzwerkkarte für die OVHcloud Link Aggregation in Windows Server 2019](/guides/bare-metal-cloud/dedicated-servers/ola-enable-w2k19/)

[Konfigurieren der OVHcloud Link Aggregation in SLES 15](/guides/bare-metal-cloud/dedicated-servers/ola-enable-sles15/)

[How to configure Your NIC for OVHcloud Link Aggregation in Debian 12 or Ubuntu 24.04 using Netplan](/guides/bare-metal-cloud/dedicated-servers/lacp-enable-netplan/)

### OLA auf die Standardwerte zurücksetzen

Um OLA auf die Standardwerte wiederherzustellen, klicken Sie auf <code className="action">...</code> rechts neben "Modus" in **OLA: OVHcloud Link Aggregation**. Klicken Sie auf <code className="action">Private Aggregation dekonfigurieren</code>. Klicken Sie im Kontextmenü auf <code className="action">Bestätigen</code>.

<img className="thumbnail" alt="network interfaces" src="/images/bare-metal-cloud/dedicated-servers/ola-enable-manager/default_settings2021.png" loading="lazy" />

Die Operation kann einige Minuten in Anspruch nehmen.
