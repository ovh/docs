## Voraussetzungen

- Sie haben einen [VPS](https://www.ovhcloud.com/de/vps/) mit Windows installiert in Ihrem Kunden-Account.
- Sie haben administrativen Zugriff (root/sudo) auf Ihren Server über. 

## In der praktischen Anwendung

### Schritt 1: Windows Firewall konfigurieren

Um auf die Windows Firewall zuzugreifen, führen Sie die folgenden Schritte aus:

- Öffnen Sie <code className="action">Start</code>.
- Klicken Sie auf <code className="action">Suchen</code>.
- Suchen Sie nach "Windows Firewall" über die Suchleiste.
- Klicken Sie auf <code className="action">Windows Firewall</code>.

Klicken Sie anschließend auf die Zeile <code className="action">Erweiterte Einstellungen</code>.

<img className="thumbnail" alt="Step1" src="/images/bare-metal-cloud/virtual-private-servers/activate-port-firewall-soft-win/step1.PNG" loading="lazy" />

### Schritt 2: Eine Regel für eingehenden Traffic aktivieren

Im angezeigten Fenster finden Sie Einstellungen wie:

- Eingangs- und Ausgangsregeln
- Regeln für die Verbindungssicherheit
- Optionen zur Überwachung der Firewall des Servers

Unter den <code className="action">Eingangsregeln</code> werden alle vorkonfigurierten Windows Server Traffic-Regeln angezeigt, die mit Netzwerkverbindungen und eingehenden Paketen zusammenhängen. Einige dieser Regeln sind nicht standardmäßig aktiviert. Wenn Sie diese aktivieren möchten, klicken Sie mit der rechten Maustaste auf die Regel und wählen Sie die Option <code className="action">Regel aktivieren</code>.

<img className="thumbnail" alt="Step1" src="/images/bare-metal-cloud/virtual-private-servers/activate-port-firewall-soft-win/step2.PNG" loading="lazy" />

### Schritt 3: Eine neue Regel erstellen 

Um eine neue Regel zu erstellen, gehen Sie in das Menü <code className="action">Aktionen</code> und wählen Sie <code className="action">Neue Regel</code> aus.
Klicken Sie auf die Option <code className="action">Neue Regel</code> im rechten Feld.

<img className="thumbnail" alt="Step3" src="/images/bare-metal-cloud/virtual-private-servers/activate-port-firewall-soft-win/step3.PNG" loading="lazy" />

### Schritt 4: Den Typ der zu aktivierenden Regel festlegen

Der Assistent wird angezeigt, um den Typ der zu erstellenden Regel zu definieren. Wählen Sie das Feld <code className="action">Port</code> aus.

<img className="thumbnail" alt="Step4" src="/images/bare-metal-cloud/virtual-private-servers/activate-port-firewall-soft-win/step4.PNG" loading="lazy" />

### Schritt 5: Art des zu aktivierenden Ports festlegen

Geben Sie im nächsten Schritt den Typ des zu aktivierenden Ports an:

<img className="thumbnail" alt="Step5" src="/images/bare-metal-cloud/virtual-private-servers/activate-port-firewall-soft-win/step5.PNG" loading="lazy" />

:::info
:::

>- TCP (Transmission Control Protocol)
>TCP ist ein verbindungsorientiertes Protokoll, d.h. mit TCP können Verbindungen hergestellt werden, um Datenströme zu senden. Dieses Protokoll gewährleistet, dass die Datenpakete dem Empfänger fehlerfrei und in der gleichen Reihenfolge, in der sie versendet wurden, geliefert werden.
>
> - UDP (User Datagram Protocol)
> UDP ist ein nicht-verbindungsorientiertes Protokoll, dessen Entwicklung auf dem Austausch von Datagrammen basiert. Es erleichtert den Versand von Datagrammen über das Netzwerk. Es ist notwendig, dass Sie zuvor eine Verbindung zum Ziel hergestellt haben.
>
>Sie können <code className="action">Alle lokalen Ports</code> auswählen, um alle TCP oder UDP Ports auf einem ungesicherten Server zu aktivieren. Sie können auch die Option <code className="action">Spezifische lokale Ports</code> anhaken, um zu bestimmen, welcher Port zugelassen werden soll. 
>

### Schritt 6: Verbindung erlauben oder blockieren

Für die Aktion, die diese Regel auslösen wird, stehen folgende Optionen zur Verfügung. Wählen Sie die für Sie passende aus.

- **Verbindung erlauben**. Diese Option ermöglicht die vollständige Kommunikation über diesen Port.
- **Verbindung erlauben, wenn sie gesichert ist**. Diese Option erlaubt die Übertragung der Daten nur, wenn die Verbindung per IPsec authentifiziert wird.
- **Verbindung blockieren**. Diese Option verhindert, dass Daten über diesen Port weitergeleitet werden.

Klicken Sie auf <code className="action">Weiter</code>. 

<img className="thumbnail" alt="Step6" src="/images/bare-metal-cloud/virtual-private-servers/activate-port-firewall-soft-win/step6.PNG" loading="lazy" />

### Schritt 7: Firewall-Profil festlegen und Regel benennen 

Wählen Sie dann aus, in welchen Netzwerken die Regel gelten soll: Domain-weites, privates oder öffentliches Profil.
Sie können auch mehrere Profile auswählen.

<img className="thumbnail" alt="Step7" src="/images/bare-metal-cloud/virtual-private-servers/activate-port-firewall-soft-win/step7.PNG" loading="lazy" />

Geben Sie der neuen Regel einen Namen und eine Beschreibung, um deren Verwendung zu erleichtern (optional).

<img className="thumbnail" alt="Step7_01" src="/images/bare-metal-cloud/virtual-private-servers/activate-port-firewall-soft-win/step7-01.PNG" loading="lazy" />

Klicken Sie auf die Schaltfläche <code className="action">Fertigstellen</code>, um den Vorgang abzuschließen und die neue Regel zu erstellen.

<img className="thumbnail" alt="Step7_02" src="/images/bare-metal-cloud/virtual-private-servers/activate-port-firewall-soft-win/step7_02.PNG" loading="lazy" />

Danach wird die neue Regel in der Übersicht angezeigt und Sie können die Einstellungen der Regel ändern.
