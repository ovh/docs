## Obiettivo

Questo manuale ti spiega come connettersi alla Veeam Service Provider Console (VSPC) per visualizzare le tue copie di backup, i tuoi agenti e consultare i report dei tuoi job di backup.

## Prerequisiti

- Avere ricevuto i dati di accesso alla VSPC via e-mail dopo l'acquisto del servizio Backup Agent.
- Avere un browser web compatibile.

## Procedura

### Accedere alla VSPC

Accedi all'URL della VSPC: `https://vspc.prod01.eu-west-rbx.backup.ovhcloud.com`

<img className="thumbnail" alt="Backup Agent Login VSPC" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-login-vspc.png" loading="lazy" />

### Connessione

Effettua l'accesso utilizzando le credenziali che ti sono state fornite via e-mail. Il formato del login è generalmente `vspc-tenant-XXXXXX\user-XXXXXX`.

:::info
Se non hai più le tue credenziali, puoi generarle nuovamente [contattando l'assistenza](https://help.ovhcloud.com/csm?id=csm_get_help).

:::


<img className="thumbnail" alt="Backup Agent Login VSPC" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-login-vspc.png" loading="lazy" />

:::info
Questo account è in sola lettura e ti permette di visualizzare le tue copie di backup e i tuoi agenti.

:::


### Visualizzare i Backup Jobs

Una volta connesso, clicca su <code className="action">Backup Jobs</code> nel menu a sinistra.

<img className="thumbnail" alt="Backup Agent Backup Jobs" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-backup-jobs.png" loading="lazy" />

### Visualizzare i job riusciti

Clicca su <code className="action">Successful Jobs</code> per il tuo tenant.

<img className="thumbnail" alt="Backup Agent Successful Jobs" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-successful-jobs.png" loading="lazy" />

### Visualizzare i punti di ripristino

Puoi consultare i punti di ripristino disponibili per le tue copie di backup.

<img className="thumbnail" alt="Backup Agent Restore Points" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-restore-points.png" loading="lazy" />

### Accedere agli agenti gestiti

Per visualizzare l'elenco dei tuoi agenti installati, vai su <code className="action">Managed Computers</code>.

<img className="thumbnail" alt="Backup Agent Managed Computers" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-managed-computers.png" loading="lazy" />

### Visualizzare i report

Accedi alla sezione <code className="action">Reports</code> per visualizzare i report delle tue copie di backup.

<img className="thumbnail" alt="Backup Agent Reports" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-reports.png" loading="lazy" />

### Aprire l'ultimo report

Apri l'ultimo report disponibile per consultare i dettagli delle tue ultime copie di backup.

<img className="thumbnail" alt="Backup Agent Last Report" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-last-report.png" loading="lazy" />

### Visualizzare le ultime allerte

Puoi visualizzare le ultime allerte sui tuoi agenti e copie di backup nella sezione <code className="action">Alarm Management</code>.

<img className="thumbnail" alt="Backup Agent Alarm Management" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-alarm.png" loading="lazy" />
