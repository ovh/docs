## Objective

This guide shows you how to create a pool, using the OVHcloud Control Panel or the OVHcloud API.

## Requirements

- A [Cloud Disk Array](https://www.ovhcloud.com/it/storage-solutions/cloud-disk-array/) solution

{/* CP-NAV-START:storage-cloud-disk-array */}
---

### OVHcloud Control Panel Access

- **Direct link:** [Cloud Disk Array](https://manager.eu.ovhcloud.com/#/dedicated/cda)
- **Navigation path:** <code className="action">Bare Metal Cloud</code> > <code className="action">Cloud Disk Array</code> > Select your service

---
{/* CP-NAV-END:storage-cloud-disk-array */}

## Instructions

:::info
Using the OVHcloud Control Panel is the easiest way to create a pool.

:::


### Using the OVHcloud Control Panel

On your Cloud Disk Array service page, you will find the existing pools in <code className="action">Pools</code>.

<img className="thumbnail" alt="Ceph pools" src="/images/storage-and-backup/block-storage/cloud-disk-array/ceph-create-a-pool/ceph-add-pool-1.png" loading="lazy" />

Enter a poolname. It must contain at least three characters.

<img className="thumbnail" alt="Ceph pool creation" src="/images/storage-and-backup/block-storage/cloud-disk-array/ceph-create-a-pool/ceph-add-pool-2.png" loading="lazy" />

You can then see that the cluster status has changed because the pool is being created.

<img className="thumbnail" alt="Ceph pool creation is running" src="/images/storage-and-backup/block-storage/cloud-disk-array/ceph-create-a-pool/ceph-task-1.png" loading="lazy" />

### Using the API

:::tip[Success]
If you are not familiar with the OVHcloud API, read our [First Steps with the OVHcloud API](/guides/manage-and-operate/api/first-steps/) guide.

:::


Use the following API call to create a pool:

<Api version="v1" section="/dedicated/ceph" method="POST" route={"/dedicated/ceph/\{serviceName\}/pool"} />


`serviceName` is the fsid of your cluster.

You can check the pool creation by listing pools with the following endpoint:

<Api version="v1" section="/dedicated/ceph" method="GET" route={"/dedicated/ceph/\{serviceName\}/pool"} />

For example:

```bash
GET /dedicated/ceph/98d166d8-7c88-47b7-9cb6-63acd5a59c15/pool
[
{
  replicaCount: 3
  serviceName: "98d166d8-7c88-47b7-9cb6-63acd5a59c15"

  poolType: "REPLICATED"
  backup: false
},
{
  replicaCount: 3

  name: "testpool"
  minActiveReplicas: 2
  poolType: "REPLICATED"
  backup: true
  }
]
```
