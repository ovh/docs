## Obiettivo

I servizi Enterprise File Storage possono essere gestiti [tramite le API OVHcloud](/guides/storage-and-backup/file-storage/enterprise-file-storage/netapp-quick-start/) o dallo Spazio Cliente OVHcloud.

**Questa guida ti mostra come gestire i volumi e gli Snapshot di Enterprise File Storage nello Spazio Cliente OVH.**

## Prerequisiti

- Disporre di un servizio Enterprise File Storage sul proprio account OVHcloud. Il servizio può essere ordinato dalla [pagina prodotto](https://www.ovhcloud.com/it/storage-solutions/enterprise-file-storage/) o dallo [Spazio Cliente OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.it/&ovhSubsidiary=it).

## Procedura <a name="instructions"></a>

Seleziona il tuo servizio nella lista.

<img className="thumbnail" alt="Informazioni generali" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise01.png" loading="lazy" />

Nella scheda <code className="action">Informazioni generali</code> vengono mostrate informazioni tecniche sul tuo servizio, informazioni generali sull'abbonamento e una scorciatoia per [creare un volume](#create_volume).

:::info
Consulta la pagina [Concetti](/guides/storage-and-backup/file-storage/enterprise-file-storage/netapp-concepts/) per ottenere informazioni dettagliate sulle proprietà tecniche della soluzione Enterprise File Storage.

:::


### Gestione dei volumi <a name="manage_volume"></a>

Clicca sulla scheda <code className="action">Volumi</code>. La tabella elenca tutti i volumi creati per il servizio selezionato. Clicca su un identificativo di volume per aprire la [pagina di gestione](#modify_volume). 

<img className="thumbnail" alt="Volumi" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise02.png" loading="lazy" />

Cliccando sul pulsante <code className="action">...</code> in ogni riga della tabella, puoi effettuare diverse azioni.

- **Modifica il volume**: apri la sezione "[Informazioni generali](#modify_volume)" del volume.
- **Crea uno Snapshot**: apri la sezione "[Backup](#snapshots)" per effettuare uno Snapshot manuale del volume.
- **Ripristina ultimo Snapshot**: apre la sezione "[Snapshots](#snapshots)" e una finestra che permette di ripristinare il volume.
- **Gestisci gli Snapshot**: apri la sezione "[Backup](#snapshots)" del volume
- **Gestisci IP Access (ACL)**: apre la sezione "[ACL](#access_control)" che permette di gestire il controllo di accesso al volume.
- **Modifica dimensione**: apre una finestra che consente di modificare la dimensione del volume.
- **Elimina il volume**: permette di eliminare questo volume una volta confermata l'azione nella finestra che appare.

#### Crea un volume <a name="create_volume"></a>

Clicca sul pulsante <code className="action">Crea un volume</code>. Nella nuova finestra, inserisci il nome e la descrizione del volume. Determina la dimensione in GB e clicca su <code className="action">Crea un volume</code> per confermare la creazione.

<img className="thumbnail" alt="Volume di creazione" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise03.png" loading="lazy" />

#### Modifica di un volume <a name="modify_volume"></a>

Clicca su un ID di volume nella tabella per aprire la pagina di gestione di questo volume.

Nella scheda <code className="action">Informazioni generali</code> vengono visualizzati i dettagli del volume e le istruzioni dettagliate per la connessione al volume, inclusi i singoli parametri.

<img className="thumbnail" alt="Gestione dei volumi" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise04.png" loading="lazy" />

Da questa scheda è inoltre possibile modificare il nome e la descrizione del volume.

#### Eliminazione di un volume <a name="delete_volume"></a>

Per eliminare un volume, clicca sul pulsante <code className="action">...</code> nella tabella dalla scheda <code className="action">Volumes</code> e seleziona <code className="action">Elimina il volume</code>.

<img className="thumbnail" alt="Volume delete" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise05.png" loading="lazy" />

Digita `DELETE` e clicca su <code className="action">Conferma</code> per confermare l’eliminazione.

### Gestione degli Snapshot di un volume <a name="snapshots"></a>

:::info
Gli Snapshot utilizzano la capacità di storage della soluzione Enterprise File Storage. Di default, il 5% della dimensione di un volume è sempre riservato agli Snapshot.

:::


Nella scheda <code className="action">Snapshots</code> sono elencati tutti gli Snapshot creati per il volume selezionato.

<img className="thumbnail" alt="Snapshots" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise06.png" loading="lazy" />

Nella stessa scheda è inoltre possibile visualizzare tutte le [politiche di Snapshot](#snapshot_policy) create per il servizio e applicarle a questo volume.

<img className="thumbnail" alt="Volume Snapshot Policy Management" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise07.png" loading="lazy" />

Clicca sulla riga della regola corrispondente per visualizzare i dettagli della pianificazione degli Snapshot. Seleziona una politica cliccando sul pulsante di selezione dedicato e poi sul pulsante <code className="action">Applica la politica</code> sotto la tabella.

Per configurare le [politiche di Snapshot](#snapshot_policy), torna alla sezione [Gestione dei volumi](#instructions) del tuo servizio e apri la scheda <code className="action">Snapshot policies</code>.

#### Creazione di uno Snapshot <a name="create_snapshot"></a>

Per creare un nuovo Snapshot di un volume nello stato attuale, clicca sul pulsante <code className="action">Actions</code> e poi su <code className="action">Crea uno Snapshot</code>.

<img className="thumbnail" alt="Snapshot create" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise08.png" loading="lazy" />

Nella nuova finestra, inserisci un nome e una descrizione.

Clicca sul pulsante <code className="action">Crea uno Snapshot</code> per avviare la creazione.

<img className="thumbnail" alt="Snapshot create window" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise09.png" loading="lazy" />

#### Modifica uno Snapshot <a name="modify_snapshot"></a>

Per modificare il nome o la descrizione di uno Snapshot, clicca sul pulsante <code className="action">...</code> nella tabella e seleziona <code className="action">Modifica</code>. Si aprirà una finestra che ti permetterà di scegliere un nuovo nome e/o una nuova descrizione.

<img className="thumbnail" alt="Snapshot edit" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise10.png" loading="lazy" />

Clicca su <code className="action">Conferma</code> per applicare le modifiche.

<img className="thumbnail" alt="Snapshot edit window" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise11.png" loading="lazy" />

#### Elimina uno Snapshot <a name="delete_snapshot"></a>

:::warning
Non è possibile eliminare uno Snapshot di tipo `system`.
sono indispensabili per il corretto funzionamento della soluzione Enterprise File Storage.

:::


Per eliminare uno Snapshot, clicca sul pulsante <code className="action">...</code> nella tabella e seleziona <code className="action">Elimina</code>.

<img className="thumbnail" alt="Snapshot delete" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise12.png" loading="lazy" />

Clicca su <code className="action">Elimina uno Snapshot</code> per confermare l’eliminazione.

<img className="thumbnail" alt="Snapshot delete confirmation" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise13.png" loading="lazy" />

#### Ripristino del volume utilizzando uno snapshot <a name="restore_volume"></a>

:::warning
Ti ricordiamo che, una volta ripristinato un volume con uno Snapshot, tutti i file e gli Snapshot creati in seguito andranno persi.
Quando un volume viene ripristinato, tutti i dati in esso contenuti vengono sovrascritti con i dati dello Snapshot. Questa azione è irreversibile.

:::


È possibile ripristinare un volume utilizzando l’ultimo Snapshot `manuale`. Clicca sul pulsante <code className="action">Actions</code> e poi su <code className="action">Ripristina l’ultimo Snapshot</code>.

:::info
Per ripristinare il volume utilizzando uno Snapshot precedente all'ultimo Snapshot, è necessario eliminare gli Snapshot fino a quando quello da utilizzare per il ripristino non sarà il più recente.

:::


<img className="thumbnail" alt="Volume revert to latest snapshot" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise14.png" loading="lazy" />

#### Backup di uno Snapshot automatico <a name="hold_snapshot"></a>

Gli Snapshot `automatici` creati dalle [politiche di Snapshot](#snapshot_policy) possono essere salvati cliccando sul pulsante <code className="action">...</code> nella tabella e poi su <code className="action">Salva</code>.

<img className="thumbnail" alt="Volume hold" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise15.png" loading="lazy" />

Salvando uno Snapshot `automatico`, quest’ultimo diventerà `manuel`, cosa che impedirà la sua rotazione da parte della politica di Snapshot e quindi la sua eliminazione automatica.

### Gestione delle ACL dei volumi <a name="access_control"></a>

Il controllo degli accessi ai volumi funziona tramite le restrizioni degli indirizzi IP. Dal momento che per impostazione predefinita non vengono configurate restrizioni, il primo passo per la creazione di volumi consiste nell'impostare indirizzi IP o intervalli da cui sarà consentito l'accesso.

Nella scheda <code className="action">Controllo di accesso (ACL)</code>, clicca sul pulsante <code className="action">+ Aggiungi un nuovo accesso</code>.

<img className="thumbnail" alt="ACL" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise16.png" loading="lazy" />

Questa azione crea una nuova riga nella tabella in cui è possibile immettere un indirizzo IP o un blocco di indirizzi (CIDR). Selezionare `Sola lettura` o `Lettura e scrittura` come tipo di accesso dal menu a comparsa, quindi selezionare questa voce per aggiungerla all'ACL.

Per rimuovere l'accesso al volume, fare clic sull'icona del cestino corrispondente nella tabella.

### Gestione delle politiche di snapshot <a name="snapshot_policy"></a>

:::info
Per impostazione predefinita, ogni volume è protetto da una politica di Snapshot chiamata `default`, che crea snapshot del volume a intervalli regolari.

:::


Aggiungere delle politiche ti permette di pianificare la creazione di Snapshot per tutti i tuoi volumi.

Clicca sulla scheda <code className="action">Snapshot poliziesche</code>. La tabella elenca tutte le politiche create per il servizio selezionato.

Esiste già una politica predefinita che non può essere modificata. Per aggiungere la tua, clicca sul pulsante <code className="action">Crea una politica di Snapshot</code>.

<img className="thumbnail" alt="Snapshot policies" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise17.png" loading="lazy" />

Nella nuova pagina, inserisci un nome e una descrizione per la politica. Poi clicca su <code className="action">+ Aggiungi una nuova regola</code> per aggiungere una o più regole alla politica.

<img className="thumbnail" alt="Snapshots" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise18.png" loading="lazy" />

Compila i campi per indicare i criteri per la periodicità di creazione dello Snapshot. È inoltre necessario indicare un prefisso per gli Snapshot, necessario alla loro denominazione.

Per maggiori informazioni su ciascun valore, clicca sull'icona con il punto di domanda (<code className="action">?</code>). Sviluppando la sezione <code className="action">Esempio</code>, potete visualizzare due serie di regole di politica con una spiegazione del loro risultato.

Seleziona la nuova regola per aggiungerla. Una volta inserite tutte le regole, clicca su <code className="action">Crea uno Snapshot policy</code>.

[Seleziona un volume](#manage_volume) e clicca sulla scheda <code className="action">Snapshot</code> per [applicare le tue regole](#snapshots).

Per eliminare una politica, clicca sull'icona del cestino corrispondente nella tabella.
