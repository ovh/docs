## Obiettivo

Per inviare una campagna SMS a contatti multipli, è possibile importare una o più liste di destinatari nel tuo Spazio Cliente OVHcloud.

**Questa guida ti mostra come creare una lista di destinatari SMS tramite un foglio di calcolo o un editor di testo e importarla nel tuo Spazio Cliente OVHcloud.**

## Prerequisiti

- Disporre di un account SMS OVHcloud attivo
- Disporre di un programma di fogli di calcolo o un editor di testo

## Procedura

### Passaggio 1: Crea una lista di destinatari

#### Crea la tua lista tramite un foglio di calcolo

È possibile creare una lista di destinatari tramite un foglio di calcolo oppure riutilizzare una lista già esistente. La lista deve essere in formato .csv e avere il seguente layout:

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/img_4831.png" loading="lazy" />

:::warning
Per evitare che il foglio di calcolo effettui un calcolo automatico sui tuoi numeri, devi personalizzare il formato della tua colonna `number`.

Con Microsoft Excel, seleziona la colonna `number` intero, clicca con il tasto destro e clicca su <code className="action">Formato della cella</code>. Clicca su <code className="action">Personalizzata</code> e inserisci questo valore nel campo `Tipo`: ```[>0]+0;Standard```.

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/sms-recipientlist-2.png" loading="lazy" />

Con LibreOffice, seleziona la colonna `number` intero, clicca con il tasto destro e clicca su <code className="action">Formatare le cellule</code>. Inserisci questo valore nel campo `Descrizione del formato`: ```[>0]+0;Standard```

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/sms-recipientlist-2b.png" loading="lazy" />

:::


Se apri il file .csv con un blocco note dovrebbe apparire così:

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/sms-recipientlist-1.png" loading="lazy" />

Per essere riconosciuta dallo Spazio Cliente OVHcloud, la lista di destinatari deve soddisfare i seguenti requisiti: 

- Tutti i contatti dovranno essere sullo stesso foglio di calcolo in una colonna `number`.
- È necessario eliminare i caratteri speciali, come gli accenti, poiché non saranno accettati durante l’importazione del file .csv nello Spazio Cliente.
- I numeri devono rispettare il formato internazionale. Ad esempio, un numero italiano avrà questo formato: +39212345678.
- Salva il file nel formato .csv (separatore: punto e virgola).

#### Crea la tua lista tramite un editor di testo

Un metodo alternativo consiste nel creare semplicemente un file .txt da un editor di testo o un blocco note.

- Digita “number” nella prima riga.
- Inserisci un numero nel formato internazionale (+39212345678) in ogni riga.

Il risultato ottenuto dovrebbe essere di questo tipo:

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/sms-recipientlist-1.png" loading="lazy" />

### Passaggio 2: Importare la tua lista dallo Spazio Cliente OVHcloud

Clicca sulla scheda <code className="action">Contatti</code> e su <code className="action">Crea una lista di contatti</code>.

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/sms-recipientlist-3b.png" loading="lazy" />

Hai la possibilità di creare fino a 9 liste di contatti tramite file di testo.

Per farlo, è necessario cliccare su <code className="action">Azioni</code>, quindi su <code className="action">Aggiungi</code>.

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/sms-recipientlist-5b.png" loading="lazy" />

Attribuisci un nome alla lista di destinatari e importa il file locale nello Spazio Cliente.

<img className="thumbnail" alt="recipients" src="/images/web-cloud/messaging/sms/liste-de-destinataire-sms/sms-recipientlist-6b.png" loading="lazy" />

### Passaggio 3: Inviare un SMS alla tua lista di destinatari

Adesso che hai importato la tua lista, segui la guida [Inviare SMS dal tuo Spazio Cliente](/guides/web-cloud/messaging/sms/envoyer-des-sms-depuis-mon-espace-client/) per inviare un SMS ai destinatari della lista.
