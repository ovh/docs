## Obiettivo

Vuoi che il tuo sito sia accessibile tramite il tuo dominio? Per fare ciò, il dominio deve puntare verso l’indirizzo IP del servizio su cui è situato il sito Web (hosting Web, server dedicato, VPS, ecc.). A questo punto, è necessario configurare la zona DNS attiva del dominio con un record DNS di tipo AAAA.

**Questa guida ti mostra come aggiungere un record DNS di tipo AAAA a una zona DNS gestita in OVHcloud per il tuo dominio.**

:::info
Per modificare o eliminare un record DNS di tipo AAAA da una zona DNS di OVHcloud, segui [questa guida](/guides/web-cloud/domains/dns-zone-edit/).

:::


## Prerequisiti

- Disporre di un [dominio](https://www.ovhcloud.com/it/domains/).
- Disporre di una zona DNS associata a questo dominio in OVHcloud.

## Procedura

:::warning
L'aggiunta, la modifica o la cancellazione di record DNS in una zona DNS attiva è un'operazione delicata. In caso di dubbi, contatta un [provider specializzato](https://partner.ovhcloud.com/it/directory/).

:::


### Aggiungere un record DNS di tipo AAAA per un dominio

Clicca sulle schede qui sotto per visualizzare ciascuno dei **5** step.

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina [Zone DNS](https://manager.eu.ovhcloud.com/#/web/zone), poi seleziona il dominio interessato.
    
    <img className="thumbnail" alt="DNS zones" src="/images/assets/screens/control-panel/product-selection/web-cloud/dns-zones.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Clicca sul pulsante <code className="action">Aggiungi un record</code>.
  </Tab>
  <Tab label="Step 3">
    Nella finestra che si apre, seleziona il campo di puntamento di tipo <code className="action">AAAA</code>.
  </Tab>
  <Tab label="Step 4">
    Inserisci l’indirizzo IP (ad esempio, `2001:db8:1:1b00:203:0:113:0`) del servizio su cui è situato il tuo sito Web (hosting Web, server dedicato, VPS, ecc.) nel campo `Destinazione *` e clicca su <code className="action">Continua</code>.
  </Tab>
  <Tab label="Step 5">
    Verifica il riepilogo e clicca su <code className="action">Conferma</code>. Attendi fino a **24** ore affinché la propagazione dell’aggiunta sulla rete DNS sia pienamente effettiva.
  </Tab>
</Tabs>

### Aggiungere un record DNS di tipo AAAA per il sottodominio di un dominio

Clicca sulle schede qui sotto per visualizzare ciascuno dei **5** step.

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina [Zone DNS](https://manager.eu.ovhcloud.com/#/web/zone), poi seleziona il dominio interessato.
    
    <img className="thumbnail" alt="DNS zones" src="/images/assets/screens/control-panel/product-selection/web-cloud/dns-zones.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Clicca sul pulsante <code className="action">Aggiungi un record</code>.
  </Tab>
  <Tab label="Step 3">
    Nella finestra che si apre, seleziona il campo di puntamento di tipo <code className="action">AAAA</code>.
  </Tab>
  <Tab label="Step 4">
    Inserisci nel campo `Sottodominio` il sottodominio interessato (ad esempio: `www` per il sottodominio `www.domain.tld`) e, nel campo `Destinazione *`, l’indirizzo IP (ad esempio: `2001:db8:1:1b00:203:0:113:0`) del servizio su cui è situato il tuo sito Web (hosting Web, server dedicato, VPS, ecc.). Clicca su <code className="action">Continua</code>.
  </Tab>
  <Tab label="Step 5">
    Verifica il riepilogo e clicca su <code className="action">Conferma</code>. Attendi fino a **24** ore affinché la propagazione dell’aggiunta sulla rete DNS sia pienamente effettiva.
  </Tab>
</Tabs>
