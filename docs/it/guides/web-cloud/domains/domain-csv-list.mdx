## Obiettivo

Vuoi recuperare la lista di tutti i domini presenti sul tuo account cliente OVHcloud? Hai bisogno di recuperare, in un solo gesto, tutte le informazioni relative ai tuoi domini (contatti associati, titolari, opzioni attive, date di creazione e di scadenza, ecc.)?

**Questa guida ti mostra come esportare la lista dei tuoi domini e le informazioni associate in formato CSV dallo Spazio Cliente OVHcloud.**

## Prerequisiti

- Disporre di un [dominio](https://www.ovhcloud.com/it/domains/) registrato in OVHcloud.

{/* CP-NAV-START:web-domains */}
---

### Accesso allo Spazio Cliente OVHcloud

- **Link diretto:** [Domini](https://manager.eu.ovhcloud.com/#/web-domains/domain)
- **Percorso di navigazione:** <code className="action">Web Cloud</code> > <code className="action">Domini</code> > Seleziona il tuo nome di dominio

---
{/* CP-NAV-END:web-domains */}

## Procedura

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **3** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina [Domini](https://manager.eu.ovhcloud.com/#/web-domains/domain). Clicca sul pulsante <code className="action">Esporta in CSV</code>.
  </Tab>
  <Tab label="Passaggio 2">
    Nella nuova finestra, seleziona le informazioni che vuoi includere nel file CSV per tutti i tuoi domini.
    
    <img className="thumbnail" alt="Export domains in CSV format step 1" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/export-csv/export-domains-in-csv-format-step-1.png" loading="lazy" />

Clicca sul pulsante <code className="action">Esporta</code> per avviare la generazione del file in formato CSV.
  </Tab>
  <Tab label="Passaggio 3">
    Viene visualizzata una finestra di caricamento. Attendere che la barra di avanzamento raggiunga il 100%.
    
    <img className="thumbnail" alt="Export domains in CSV format step 2 in progress" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/export-csv/export-domains-in-csv-format-step-2a.png" loading="lazy" />

Una volta generato il file CSV, visualizzi questo messaggio e il download del file avvia automaticamente:
    
    <img className="thumbnail" alt="Export domains in CSV format step 2 done" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/export-csv/export-domains-in-csv-format-step-2b.png" loading="lazy" />

Se il download del file CSV non si è avviato automaticamente, clicca sul link <code className="action">scaricarlo manualmente</code> per recuperarlo.
  </Tab>
</Tabs>
