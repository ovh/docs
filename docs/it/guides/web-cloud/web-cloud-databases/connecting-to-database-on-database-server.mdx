## Obiettivo

È possibile consultare il contenuto del tuo database tramite un'interfaccia. Esistono diversi modi per connettersi.

**Scopri come connetterti al database sulla tua soluzione database server.**

## Prerequisiti

- Una [istanza Web Cloud Databases](https://www.ovhcloud.com/it/web-cloud/databases/) (inclusa in un piano di [hosting web Performance](https://www.ovhcloud.com/it/web-hosting/)).

## Procedura

:::info
Le soluzioni [Web Cloud Databases](https://www.ovhcloud.com/it/web-cloud/databases/) non danno accesso al sistema di gestione dei database, ma ai database ospitati su di esso.

- Non sono presenti accessi super utente "root".
- I comandi SQL generici funzionano normalmente e software come HeidiSQL, SQuirreL SQL o Adminer sono completamente compatibili.

:::


### Connettersi a un database MySQL o MariaDB

:::info
Poiché MariaDB è un derivato di MySQL, i comandi sono esattamente gli stessi per entrambi i tipi di database.

:::


#### Connessione tramite phpMyAdmin OVHcloud

Clicca sulle schede qui sotto per visualizzare i **4** step in sequenza.

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina [Web Cloud Databases](https://manager.eu.ovhcloud.com/#/web/web/private_database), poi seleziona la soluzione interessata.
    
    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Recupera le seguenti informazioni di connessione:
    
    - **Server (hostname) e porta:** visibili nella scheda <code className="action">Informazioni generali</code>, sezione "Informazioni di login".
    - **Nome utente:** visibile nella scheda <code className="action">Utenti e diritti</code>.
    - **Password:** la password associata all'utente. Se l'hai dimenticata, accedi alla scheda <code className="action">Utenti e diritti</code>, clicca su <code className="action">...</code> a destra dell'utente interessato, poi su <code className="action">Modifica la password</code>.
    
    :::warning
    Se modifichi la password di un utente di database, tutte le applicazioni/siti Web che accedono a questo database devono essere aggiornati di conseguenza.

    :::

  </Tab>
  <Tab label="Step 3">
    Nella scheda <code className="action">Informazioni generali</code>, individua la sezione **"Gestione database"** e clicca sul link phpMyAdmin sotto **"Interfaccia utente"**.
    
    <img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/general-information/database-administration.png" loading="lazy" />
  </Tab>
  <Tab label="Step 4">
    Nella pagina di login di phpMyAdmin, inserisci le informazioni recuperate allo step 2:
    
    <img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-login-web-cloud-db.png" loading="lazy" />
    
    - **Server:** inserisci l'"hostname" seguito dal "numero di porta", separati da "**:**" o da uno "**spazio**". Ad esempio: **aaXXXXX-XXX.eu.clouddb.ovh.net:12345**.
    - **Username:** inserisci il "nome utente".
    - **Password:** inserisci la "password".
  </Tab>
</Tabs>


Se la connessione ha esito positivo, verrà visualizzata la pagina seguente.

<img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-main-page-web-cloud-db.png" loading="lazy" />

:::warning
**In caso di errore:**

- Errore #1045 significa che le credenziali non sono corrette. Verifica il nome utente e/o la password.
- Errore #2005 significa che il nome del server deve essere verificato, così come il suo corretto funzionamento.

:::


#### Connessione al database al di fuori dello Spazio Cliente

:::warning
Se utilizzi una soluzione "Web Cloud Databases"/"SQL Privato", ricorda di autorizzare il tuo IP seguendo la guida sulla [configurazione del tuo database server](/guides/web-cloud/web-cloud-databases/configure-database-server#gerer-vos-acces/).

:::


Clicca sulle schede qui sotto per visualizzare i **2** step in sequenza.

<Tabs>
  <Tab label="Step 1">
    Accedi alla pagina [Web Cloud Databases](https://manager.eu.ovhcloud.com/#/web/web/private_database), poi seleziona la soluzione interessata.
    
    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    Recupera le seguenti informazioni di connessione:
    
    - **Server (hostname):** visibile nella scheda <code className="action">Informazioni generali</code>, sezione **"Gestione database"**, voce "Hostname" nella parte **SQL**.
    - **Porta:** visibile nella stessa posizione, voce "Porta" nella parte **SQL**.
    - **Nome utente:** visibile nella scheda <code className="action">Utenti e diritti</code>.
    - **Password:** la password associata all'utente interessato.
    - **Nome del database:** visibile nella scheda <code className="action">Database</code>.
  </Tab>
</Tabs>


**Clicca sul metodo di connessione che preferisci per visualizzare il contenuto.**

<details>

<summary>Connessione da riga di comando</summary>


```bash
mysql --host=server --user=user --port=port --password=password database_name
```

</details>


<details>

<summary>Connessione tramite script PHP</summary>


```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

</details>


<details>

<summary>Connessione tramite software (SQuirreL SQL)</summary>


:::info
Nel nostro esempio utilizziamo il software open source SQuirreL, ma altre interfacce come HeidiSQL o Adminer sono completamente compatibili.

:::


- Avvia SQuirreL SQL e clicca su <code className="action">Aliases</code>, poi su <code className="action">+</code>

<img className="thumbnail" alt="launch SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Compila i campi seguenti e conferma con il pulsante <code className="action">OK</code>:
    - **Name**: Scegli un nome
    - **Driver**: Scegli "MySQL Driver"
    - **URL**: Inserisci l'indirizzo del server e la porta nel formato jdbc:mysql://server:port
    - **User Name**: Inserisci il nome utente
    - **Password**: Inserisci la password

<img className="thumbnail" alt="config connection" src="/images/assets/screens/other/web-tools/squirrel/add-alias.png" loading="lazy" />

- Conferma nuovamente con il pulsante <code className="action">Connetti</code>

<img className="thumbnail" alt="valid connection" src="/images/assets/screens/other/web-tools/squirrel/connect-to-mysql.png" loading="lazy" />

Sei ora connesso al tuo database:

<img className="thumbnail" alt="config connection" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard.png" loading="lazy" />

</details>


<details>

<summary>Connessione tramite phpMyAdmin</summary>


Puoi utilizzare la tua interfaccia phpMyAdmin per esplorare il contenuto del tuo database. Per farlo, installa phpMyAdmin sul tuo server o hosting Web. Durante l'installazione, assicurati di configurare correttamente le informazioni del tuo database server e del database desiderato affinché phpMyAdmin possa connettersi.

</details>
