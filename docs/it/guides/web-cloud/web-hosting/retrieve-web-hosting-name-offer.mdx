## Obiettivo

Non ricordi più il nome della tua [offerta di hosting web](https://www.ovhcloud.com/it/web-hosting/)?
Vuoi consultare i suoi dettagli o confrontarla con un'altra offerta?

Nell'utilizzo dei tuoi servizi, potresti aver bisogno del nome della tua offerta di hosting web.

**Questa guida ti mostra come identificare il tipo di offerta di hosting web che possiedi dal tuo Spazio Cliente OVHcloud.**

## Prerequisiti

- Disporre di un'[offerta di hosting web](https://www.ovhcloud.com/it/web-hosting/).
{/* CP-NAV-START:web-hosting */}
---

### Accesso allo Spazio Cliente OVHcloud

- **Link diretto:** [Hosting plans](https://manager.eu.ovhcloud.com/#/web/hosting)
- **Percorso di navigazione:** <code className="action">Web Cloud</code> > <code className="action">Hosting</code> > Seleziona il tuo hosting web

---
{/* CP-NAV-END:web-hosting */}

## Procedura

Clicca sulle schede qui sotto per visualizzare in sequenza ciascuno dei **2** passi.

<Tabs>
  <Tab label="Passaggio 1">
    Accedi alla pagina [Hosting plans](https://manager.eu.ovhcloud.com/#/web/hosting), poi seleziona l'hosting Web interessato.
    
    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Passaggio 2">
    Nel riquadro **Abbonamento**, troverai l'indicazione **Piano**.
    
    <img className="thumbnail" alt="Plan" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-plan-pro.png" loading="lazy" />

Sotto questa dicitura, troverai il nome della tua offerta di hosting web (ad esempio: Perso, Pro, Performance, ecc.).
  </Tab>
</Tabs>
