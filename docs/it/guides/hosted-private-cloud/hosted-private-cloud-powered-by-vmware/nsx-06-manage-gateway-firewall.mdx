## Objective

Gateway Firewall allows filtering between internal segments and the network outside the incoming or outgoing cluster.

It works on the North-South (Tier-0 Gateways) and East-West (Tier-1 Gateways) gateways if the source or destination is not inside the cluster.

If you want to create filtering rules between internal segments, you will need to use distributed firewall using our guide on [distributed firewall management](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/).

## Requirements

- Being an administrative contact of your [Hosted Private Cloud infrastructure](https://www.ovhcloud.com/it/enterprise/products/hosted-private-cloud/) to receive login credentials.
- A user account with access to the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.it/&ovhSubsidiary=it).
- Having **NSX** deployed with one segment configured in your NSX configuration. You can use our guide on [segment management in NSX](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/) for more information.

## Instructions

We will create a strategy to improve the visibility and administration of rules based on their usefulness.

Next, we will add a rule within our strategy that blocks access to the entire external network of a cluster from a group that contains a segment (you can use our [Distributed Firewall Management](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/) guide to create groups) and **any** for the destination.

Go to the <code className="action">Security</code> tab, select <code className="action">Gateway Firewall</code> and click <code className="action">+ ADD POLICY</code>.

<img className="thumbnail" alt="01 Create gateway firewall rules 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules01.png" loading="lazy" />

Select <code className="action">ovh-T0-gw</code> to the right of **Gateway**, name your policy <code className="action">my policy</code> below the **Name** column and click the <code className="action">three vertical dots</code> to the left of your policy.

<img className="thumbnail" alt="01 Create gateway firewall rules 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules02.png" loading="lazy" />

Click <code className="action">Add Rule</code> in the menu.

<img className="thumbnail" alt="01 Create gateway firewall rules 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules03.png" loading="lazy" />

Name your rule <code className="action">block segment1 to any</code> below the **Name** column.

<img className="thumbnail" alt="01 Create gateway firewall rules 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules04.png" loading="lazy" />

Click on the <code className="action">pen</code> to the right of "Any" in the **Source** column.

<img className="thumbnail" alt="01 Create gateway firewall rules 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules05.png" loading="lazy" />

Stay in the <code className="action">Group</code> tab, select the <code className="action">g-segment1</code> group and click <code className="action">APPLY</code>.

<img className="thumbnail" alt="01 Create gateway firewall rules 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules06.png" loading="lazy" />

Choose <code className="action">Drop</code> under the **Action** column and click <code className="action">PUBLISH</code>.

<img className="thumbnail" alt="01 Create gateway firewall rules 07" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules07.png" loading="lazy" />

Your rule is active on the **ovh-T0-gw** gateway, it blocks all outgoing traffic from members of the **g-segment01** group.
