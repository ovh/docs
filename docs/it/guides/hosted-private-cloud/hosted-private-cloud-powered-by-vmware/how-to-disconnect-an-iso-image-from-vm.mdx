## Objective

If an ISO is connected to a VM, the VM cannot be migrated, either manually or automatically. This can prevent DRS from working properly, and the host to be put in maintenance mode.

## Requirements

- You must be an administrative contact for the [Hosted Private Cloud](https://www.ovhcloud.com/it/enterprise/products/hosted-private-cloud/) infrastructure to receive login credentials.
- An active username (created in the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.it/&ovhSubsidiary=it))

## Instructions

If you simply untick the <code className="action">Connected</code> checkbox in the ISO File datastore, the VM is still linked to the ISO:

<img className="thumbnail" alt="Disconnect" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-disconnect-an-iso-image-from-vm/disconnect1.png" loading="lazy" />

To disconnect the ISO from the VM, first click the dropdown arrow next to CD/DVD drive 1 and select <code className="action">Client Device</code>.

<img className="thumbnail" alt="Disconnect" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-disconnect-an-iso-image-from-vm/disconnect2.png" loading="lazy" />

The ISO is now disconnected:

<img className="thumbnail" alt="Disconnect" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-disconnect-an-iso-image-from-vm/disconnect3.png" loading="lazy" />
