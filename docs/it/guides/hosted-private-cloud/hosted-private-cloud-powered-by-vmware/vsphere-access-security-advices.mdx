## Obiettivo

Per assicurare un livello di sicurezza ottimale di un’infrastruttura, limitare gli accessi potrebbe rivelarsi la scelta più giusta. Questa operazione può essere eseguita con diversi metodi. 

**Questa guida fornisce alcuni consigli utili per rendere più sicuro l’accesso al client vSphere in modo semplice e rapido.**

## Prerequisiti

- Avere accesso allo [Spazio Cliente OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.it/&ovhSubsidiary=it)

## Procedura

### Controlla gli accessi tramite IP

Il primo consiglio è relativo alla restrizione dell’accesso tramite IP, per cui suggeriamo di utilizzare un sistema di registrazione basato su <i>whitelist</i>. Questa tecnica consiste nel rifiutare di default l’accesso a tutti gli indirizzi IP e aggiungere gli indirizzi autorizzati a connettersi all’infrastruttura.

Questa operazione è disponibile nello [Spazio Cliente OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.it/&ovhSubsidiary=it). Accedi alla sezione Private Cloud, seleziona il servizio in questione e clicca sulla scheda <code className="action">Sicurezza</code>: compare una tabella che mostra gli indirizzi IP autorizzati o bloccati. Per aggiungerne di nuovi, clicca sul pulsante <code className="action">Aggiungi IP</code> a destra:

<img className="thumbnail" alt="Aggiunta di IP" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vsphere-access-security-advices/adding_ip.png" loading="lazy" />

### Crea utenti specifici

Consigliamo vivamente di creare un accesso personale per ogni utente che ha bisogno di connettersi all’infrastruttura. Anche questa operazione è disponibile nello [Spazio Cliente](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.it/&ovhSubsidiary=it): accedi alla scheda <code className="action">Utenti</code> e clicca sul pulsante <code className="action">Crea un utente</code>.

<img className="thumbnail" alt="Utenti" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vsphere-access-security-advices/users.png" loading="lazy" />

Durante la creazione dell’account utente, sarà necessario impostare una password.

:::info
Per una protezione ottimale dei dati, la password deve possedere alcuni requisiti specifici:

- contenere almeno 8 caratteri
- contenere almeno 3 tipi di caratteri
- non essere tratta dal dizionario
- non contenere informazioni personali (nome, cognome o data di nascita)
- non essere utilizzata per più accessi
- essere salvata in un <i>password manager</i>
- essere cambiata ogni 3 mesi
- essere diversa dalle password precedenti

:::


In seguito sarà possibile gestire i diritti di ogni account cliccando sul pulsante <code className="action">...</code> in corrispondenza dei diversi utenti:

<img className="thumbnail" alt="Modifica dei parametri degli utenti" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vsphere-access-security-advices/users_edit.png" loading="lazy" />

### Limita la durata delle sessioni

Al termine dell’utilizzo, consigliamo di chiudere la sessione aperta con l’account utilizzato.   Per limitare la durata delle connessioni è possibile impostare la scadenza della sessione.

Questa operazione è disponibile nello [Spazio Cliente OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.it/&ovhSubsidiary=it). Accedi alla sezione Private Cloud, seleziona la scheda <code className="action">Sicurezza</code> e clicca sul pulsante <code className="action">Modifica la durata di una sessione </code> a destra.

<img className="thumbnail" alt="Scadenza della sessione" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vsphere-access-security-advices/security-expiration.png" loading="lazy" />

A questo punto, inserisci il numero di minuti di validità di una sessione.

<img className="thumbnail" alt="Scadenza della sessione" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vsphere-access-security-advices/expiration.png" loading="lazy" />
