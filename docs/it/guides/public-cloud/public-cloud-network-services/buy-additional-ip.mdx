## Obiettivo

È possibile configurare un indirizzo Additional IP sulle tue istanze Public Cloud per diversi motivi:

- se ospiti più siti sulla tua istanza
- se ospiti progetti internazionali

Per rispondere a queste esigenze, puoi acquistare un indirizzo Additional IP per le tue istanze.

Questi indirizzi possono essere trasferiti esclusivamente verso le istanze di uno stesso progetto.

**Questa guida ti mostra come acquistare un Additional IP per il tuo progetto Public Cloud OVHcloud.**

## Prerequisiti

- Avere accesso allo [Spazio Cliente OVHcloud](/links/manager).
- Disporre di almeno un'istanza. A questo proposito, consulta [la guida per creare un'istanza dallo Spazio Cliente](/guides/public-cloud/compute/compute-getting-started).

> [!warning]
> Questa funzionalità al momento non è disponibile per le istanze Metal.
>

## Procedura

Accedi allo [Spazio Cliente OVHcloud](/links/manager), clicca su `Public Cloud` e seleziona il progetto Public Cloud interessato.

Nel menu a sinistra, apri `IP pubblici` in **Network**.

Apri la scheda `Additional IP` e clicca sul pulsante `Azioni`. Seleziona `Aggiungi un nuovo IP`.

![Aggiunta IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_01.png)

Nello Step 1 dell'ordine, clicca su `Avanti`.

![Aggiunta IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_02.png)

Lo Step 2 permette di selezionare un Paese per il nuovo indirizzo IP.

![Aggiunta IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_03.png)

Per la geolocalizzazione degli IP sono disponibili i seguenti Paesi:

|          |          |          |           |                |
|:--------:|:--------:|:--------:|:---------:|:--------------:|
| Belgio  | Finlandia  | Francia   | Germania   | Repubblica Ceca |
| Irlanda  |  Italia   | Lituania | Paesi Bassi | Regno Unito    |
| Portogallo |  Spagna   |  Polonia |  Svizzera |                 |

> [!info] **Disponibilità**
> 
> È possibile che alcuni di questi Paesi non siano elencati, in base alla disponibilità attuale degli indirizzi IPv4.
> 

> [!info] **Noleggio**
>
> La geolocalizzazione di IP è basata esclusivamente su organismi di riferimento.
> 
> Ad esempio, il [RIPE NCC](https://www.ripe.net/) serve l'Europa come Registro Internet Regionale.
>
> Se hai bisogno di verificare la geolocalizzazione in un altro modo, contatta direttamente le organizzazioni interessate. OVHcloud non potrà fornirti assistenza al riguardo.

Una volta selezionato il Paese, clicca su `Seguente`.

Allo step successivo, seleziona la tua istanza nel menu a tendina. Clicca su `Genera ordine`.

![Aggiunta IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_04.png)

Il buono d'ordine si aprirà automaticamente per completare l'acquisto.

Per maggiori informazioni, consulta la nostra guida sulla [gestione degli ordini](/guides/account-and-service-management/managing-billing-payments-and-services/ovh-orders) OVHcloud.

Il buono d'ordine è disponibile anche nello Spazio Cliente, sezione `Dashboard`, cliccando su `Visualizza i tuoi ordini`.

Il prossimo step consiste nel configurare l'IP nel tuo sistema operativo. Consulta [la nostra guida dedicata a questa configurazione](/guides/public-cloud/public-cloud-network-services/configure-additional-ip).
