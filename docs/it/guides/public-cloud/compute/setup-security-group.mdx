## Obiettivo

Per motivi di sicurezza, è possibile configurare e utilizzare regole di filtraggio che definiranno gli accessi alle tue istanze. È possibile autorizzare o bloccare alcune connessioni in entrata o in uscita tramite gruppi di sicurezza. Queste regole possono essere applicate al traffico proveniente da alcuni indirizzi IP o anche alle istanze configurate su gruppi di sicurezza in particolare.

**Questa guida ti mostra come creare un gruppo di sicurezza e configurarlo su un'istanza Public Cloud.**

## Prerequisiti

- Un [progetto Public Cloud](https://www.ovhcloud.com/it/public-cloud/)
- [Essere connesso all'interfaccia Horizon](/guides/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/)

## Procedura

### Step 1: creare un gruppo di sicurezza

Accedi all'interfaccia [Horizon](/guides/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/). Scegli la Region in cui vuoi creare un gruppo di sicurezza, cliccando sul pulsante in alto a sinistra.

<img className="thumbnail" alt="definire la regione" src="/images/public-cloud/compute/setup-security-group/security-group0.png" loading="lazy" />

:::info
Se un gruppo di sicurezza deve essere utilizzato in più localizzazioni, è necessario crearlo per ciascuna di esse.

:::


A questo punto, apri il menu <code className="action">Network</code> e clicca su <code className="action">Security Groups</code>.

Una tabella elenca i gruppi di sicurezza creati. Il gruppo "default" vi è già stato inserito. che permette di passare tutto il traffico in entrata e in uscita.

:::danger
**Non modificare o eliminare il gruppo "default". È necessario creare un nuovo gruppo di sicurezza e configurarvi le regole.**

Le operazioni automatiche sull'infrastruttura possono ripristinare il gruppo di sicurezza di default, quindi è importante non modificarlo.

OpenStack chiude di default tutti gli accessi alle istanze. Se elimini il gruppo di sicurezza "default", è necessario creare un gruppo proprio che apra gli accessi alle tue istanze e applicarlo a ogni creazione di un’istanza. In seguito, il gruppo "default" sarà creato nuovamente con le operazioni automatizzate sull’infrastruttura.

:::


Per aggiungere un nuovo gruppo di sicurezza, clicca sul pulsante <code className="action">+ Create Security Group</code>.

<img className="thumbnail" alt="accedere ai gruppi di sicurezza" src="/images/public-cloud/compute/setup-security-group/security-group1.png" loading="lazy" />

Nella nuova pagina, assegna un nome e una descrizione al gruppo che stai per creare. Clicca sul pulsante <code className="action">Create Security Group</code>.

<img className="thumbnail" alt="creare un gruppo di sicurezza" src="/images/public-cloud/compute/setup-security-group/security-group2.png" loading="lazy" />

Di ritorno alla scheda <code className="action">Security Groups</code>, la tabella mostra il gruppo appena creato. Le regole sono configurate di default Queste ultime lasciano passare solo il traffico in uscita. Prosegui seguendo lo step successivo per modificarle.

Se le regole sono corrette, prosegui nella lettura di questa guida allo Step 3 "[Configura un gruppo di sicurezza sull'istanza](#instance-security-group)".

### Step 2: configurare le regole di un gruppo di sicurezza

Clicca sul pulsante <code className="action">Manage Rules</code>.

<img className="thumbnail" alt="gestire le regole" src="/images/public-cloud/compute/setup-security-group/security-group3.png" loading="lazy" />

Se hai lasciato le regole di default sul tuo gruppo di sicurezza, queste passano solo al traffico in uscita.

```bash
root@serveur:~$ ssh admin@149.xxx.xxx.177

ssh: connect to host 149.xxx.xxx.177 port 22: Connection timed out
```

A questo punto, sulla pagina di gestione delle regole, hai la possibilità di:

- eliminare una regola esistente: utilizzando il pulsante <code className="action">Delete Rule</code>;
- aggiungi una nuova regola: utilizzando il pulsante <code className="action">+ Add Rule</code>.

Quando aggiungi una regola, completa le informazioni richieste e clicca su <code className="action">Add</code>.

Nel nostro esempio, autorizzeremo la connessione SSH all'istanza.

<img className="thumbnail" alt="aggiungi una regola" src="/images/public-cloud/compute/setup-security-group/security-group4.png" loading="lazy" />

Una volta aggiunta la nuova regola, attendi qualche minuto per la sua elaborazione.

```bash
root@serveur:~$ ssh admin@149.xxx.xxx.177

Last login: Tue Oct 13 13:56:30 2015 from proxy-109-190-254-35.ovh.net
admin@serveur1:~$
```

### Configura un gruppo di sicurezza su un'istanza <a name="instance-security-group"></a>

Dall'interfaccia Horizon, apri il menu <code className="action">Compute</code> e seleziona <code className="action">Istanze</code>. Da questa pagina crei una nuova istanza tramite il pulsante <code className="action">Launch Instance</code>.

Durante la creazione dell'istanza, è possibile scegliere il nuovo gruppo di sicurezza creato nello step precedente tramite il menu <code className="action">Security Groups</code>.

<img className="thumbnail" alt="assegnare il gruppo di sicurezza" src="/images/public-cloud/compute/setup-security-group/security-group5.png" loading="lazy" />

Per applicare un nuovo gruppo di sicurezza su un'istanza già creata, clicca su <code className="action">Edit Security Groups</code> a destra dell'istanza.

<img className="thumbnail" alt="modifica il gruppo di sicurezza" src="/images/public-cloud/compute/setup-security-group/security-group6.png" loading="lazy" />

### Elimina un gruppo di sicurezza

Per eliminare un gruppo di sicurezza, selezionalo selezionando la casella corrispondente a sinistra e clicca su <code className="action">Delete Security Groups</code>.

<img className="thumbnail" alt="eliminare il gruppo di sicurezza" src="/images/public-cloud/compute/setup-security-group/security-group7.png" loading="lazy" />
