## Obiettivo

Le autorizzazioni e le password associate agli utenti del client vSphere possono essere gestite dallo Spazio Cliente di OVHcloud.

**Questa guida ti mostra come modificare la password di un utente.**

## Prerequisiti

- Avere accesso allo [Spazio Cliente OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.it/&ovhSubsidiary=it)
- Disporre di un account utente creato dallo Spazio Cliente OVHcloud. Per maggiori informazioni, consulta [questa guida](/guides/bare-metal-cloud/managed-bare-metal/manager-ovhcloud#utenti/)
  
## Procedura

### Modifica la password

Accedi allo [Spazio Cliente OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.it/&ovhSubsidiary=it) e, nella sezione <code className="action">Bare Metal Cloud</code>  (1), clicca su <code className="action">Managed Bare Metal</code> (2), seleziona il server dalla lista (3) e clicca sulla scheda <code className="action">Utenti</code>(4).

<img className="thumbnail" alt="Accesso allo Spazio Cliente" src="/images/bare-metal-cloud/managed-bare-metal/changer-user-password/userpassword1.png" loading="lazy" />

Clicca sul pulsante <code className="action">(...)</code> in corrispondenza dell’account interessato e seleziona <code className="action">Modifica la password</code>.

<img className="thumbnail" alt="Modifica password" src="/images/bare-metal-cloud/managed-bare-metal/changer-user-password/userpassword2.png" loading="lazy" />

Nella nuova finestra, inserisci la password e confermala.

<img className="thumbnail" alt="Modifica password" src="/images/bare-metal-cloud/managed-bare-metal/changer-user-password/userpassword3.png" loading="lazy" />

:::info
Se non viene inserita una password, ne verrà generata una in modo casuale che sarà poi inviata via email all’indirizzo associato all’utente.

:::


:::warning
:::

>Per non compromettere la sicurezza dell’infrastruttura, consigliamo di seguire alcune best practice. La password deve:
>
> - contenere almeno 8 caratteri
> - contenere almeno 3 tipi di caratteri
> - non essere tratta dal dizionario
> - non contenere informazioni personali
> - non essere utilizzata per più accessi
> - essere salvata in un <i>password manager</i>
> - essere cambiata ogni 3 mesi
> - essere diversa dalle password precedenti
>
