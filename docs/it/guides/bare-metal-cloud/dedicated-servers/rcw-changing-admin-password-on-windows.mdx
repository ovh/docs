## Obiettivo

Questa guida ti mostra come ripristinare la password `Administrator` con **Windows customer rescue system**.

## Prerequisiti

- Microsoft Windows Server 2016 o versione successiva installata sul tuo [server dedicato](https://www.ovhcloud.com/it/bare-metal/)
- Almeno 16 GB di RAM installati sul server

- **Link diretto:** [Server dedicati](https://manager.eu.ovhcloud.com/#/dedicated-servers/server)
- **Percorso di navigazione:** <code className="action">Bare Metal Cloud</code> > <code className="action">Server dedicati</code> > Seleziona il tuo server

:::warning
Questa guida non si applica al **sistema Windows Rescue *legacy* (modalità Rescue WinPE)** (per maggiori informazioni, consulta la [guida alla modalità Rescue](/guides/bare-metal-cloud/dedicated-servers/rescue-mode/)).

Se la versione di Windows Server in uso non è supportata, potrebbe non essere possibile attivare il sistema Rescue corrente per Windows. In questo caso, consulta la nostra guida che spiega [come reimpostare la password amministratore di Windows con il sistema Windows rescue *legacy*](/guides/bare-metal-cloud/dedicated-servers/changing-admin-password-on-windows/).  
Troverai anche un metodo alternativo per reimpostare la password amministratore con il sistema Rescue Customer di OVHcloud basato su Debian.

:::



## Procedura

### Step 1 - Riavvia il server in modalità Rescue <a name="step1"></a>

Per modificare la password è necessario avviare il sistema in modalità **Windows customer rescue system**.

Per maggiori dettagli, consulta la [guida sul Rescue mode](/guides/bare-metal-cloud/dedicated-servers/rescue-customer-windows/).

### Step 2 - Cancella la password corrente <a name="step2"></a>

Connettiti al server con la "Connessione desktop remoto" (RDP) e le credenziali trasmesse via email.

Il nome utente è `Administrator`.

- Se il tuo server utilizza un RAID software sul disco di sistema, devi prima importarlo prima di poter reimpostare la password: segui le istruzioni della [sezione A](#sectionA) di questa guida.
- Se il tuo server non utilizza un RAID software sul disco di sistema, puoi reimpostare la password direttamente seguendo le istruzioni della [sezione B](#sectionB) di questa guida.

#### A - Importare il disco locale Windows <a name="sectionA"></a>

##### 1. Accedi alla gestione dei dischi

Clicca con il tasto destro sul menu <code className="action">Start</code> e seleziona <code className="action">Disk Management</code>.

<img className="thumbnail" alt="disk_manager_menu" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_manager_menu.png" loading="lazy" />

Ora è possibile visualizzare i dischi e i volumi del server.

<img className="thumbnail" alt="disk_manager_window" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_manager_window1.png" loading="lazy" />

Il disco che contiene Windows sul tuo server è probabilmente il *disk 1*, quindi è necessario importarlo per potervi accedere.

Si noti che se il server dispone di più gruppi di dischi, il numero di disco contenente Windows potrebbe essere diverso e potrebbe essere necessario importare più dischi prima di trovarli.

È inoltre necessario importare il secondo disco per importare correttamente il volume di RAID software.

##### 2. Importa dischi

Clicca con il tasto destro su *Disk 1* e seleziona <code className="action">Online</code>.

<img className="thumbnail" alt="disk_import_disk1" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_manager_disk1on.png" loading="lazy" />

Per importare correttamente il volume del RAID software, fare lo stesso con il secondo disco (Disk 2).

Clicca con il tasto destro su *Disk 2* e seleziona<code className="action">Online</code>.

<img className="thumbnail" alt="disk_import_disk2" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_manager_disk2on.png" loading="lazy" />

I dischi vengono ora visualizzati come *Dynamic* e *Foreign*.

Clicca con il tasto destro del mouse su *Disk 1* e seleziona <code className="action">Import Foreign Disks</code>.

<img className="thumbnail" alt="disk_import_menu" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_manager_diskimport.png" loading="lazy" />

Clicca due volte su <code className="action">OK</code>.

<img className="thumbnail" alt="disk_import1" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_import1.png" loading="lazy" />

<img className="thumbnail" alt="disk_import2" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_import2.png" loading="lazy" />

Il disco locale è ormai accessibile e il disco Windows corrisponde al volume "(E:)" (che si estende su due dischi configurati in RAID software di tipo Mirrored Volume).

<img className="thumbnail" alt="disk_import_sync" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_import_sync.png" loading="lazy" />

:::info
In questo esempio, lo stato del volume è "Resynching" perché il server è stato bruscamente riavviato in modalità Rescue. È uno stato normale che non è causato dal rescue stesso.  
Questa operazione non avrà alcun impatto sui dati del volume e la risincronizzazione continuerà anche dopo il riavvio del server sul sistema installato.

:::


:::warning
È necessario utilizzare il percorso della cartella locale di Windows (in questo caso E:\Windows) quando si naviga per trovare il file di configurazione _SAM_ nella sezione successiva.

:::


A questo punto, è possibile reimpostare la password seguendo le istruzioni riportate nella sezione successiva.

#### B - Reimposta la password <a name="sectionB"></a>

Per reimpostare una password, è necessaria l'utilità NTPWEdit.

Una volta connesso tramite il desktop remoto (RDP), apri il browser Internet (MS Edge) e scarica l’utilità dal [sito Web ufficiale](http://www.cdslow.org.ru/files/ntpwedit/ntpwed07.zip).

Passare alla cartella in cui si trova il file ZIP scaricato ed estrarre il contenuto.

Apri il file eseguibile `ntpwedit64.exe` per avviare l’applicazione.

Tramite questa interfaccia, è possibile modificare il file *SAM* per cancellare la password dell’utente admin.

Per trovare il file *SAM* del sistema, è necessario spostarsi nella cartella locale di Windows.

Fare clic sul pulsante <code className="action">...</code> per spostarsi nell'unità in cui si trova la cartella locale di Windows.

Generalmente è l’unità `Windows (E:\)`

<img className="thumbnail" alt="ntpwedit1" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/ntpwedit_1.png" loading="lazy" />

Passare a `E:\WINDOWS\SYSTEM32\CONFIG\`.

Seleziona e apri il file *SAM* per visualizzare gli account utente selezionando <code className="action">Open</code>.

![ntpwedit_sam](/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/SAM.png)

Seleziona l’account utente "admin" e clicca su <code className="action">Change password</code>.

<img className="thumbnail" alt="ntpwedit2" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/ntpwedit_2.png" loading="lazy" />

Nella nuova finestra, inserisci la nuova password in entrambi i campi e clicca su <code className="action">OK</code>.

:::warning
La nuova password verrà accettata senza verificarne la complessità.

Tieni presente che questa password permetterà di connettersi a distanza sul server, una volta riavviato sul suo sistema operativo.

:::


Clicca su <code className="action">Save changes</code> e poi su <code className="action">Exit</code>.

Riavviare il server nel normale sistema operativo.

### Step 3 - Riavvia il server <a name="step3"></a>

Inizia sostituendo il netboot con <code className="action">Avviare da hard disk</code> nello Spazio Cliente OVHcloud (vedi [Step 1](#step1)).

Riavvia il server dallo Spazio Cliente. Clicca sul pulsante <code className="action">...</code> vicino alla sezione "Stato dei servizi" e seleziona <code className="action">Riavvia</code>.

<img className="thumbnail" alt="reboot" src="/images/assets/screens/control-panel/product-selection/bare-metal-cloud/dedicated-servers/general-information/cp-dedicated-restart.png" loading="lazy" />
