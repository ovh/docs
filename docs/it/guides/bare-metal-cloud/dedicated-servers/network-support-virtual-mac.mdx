## Obiettivo

Per utilizzare la funzionalità dei MAC virtuali (VMAC) su un server dedicato, è necessario prima determinare se il server supporta questa funzionalità.

Il supporto di questa funzionalità è un prerequisito per tutte le azioni relative ai MAC virtuali.

**Questa guida ti mostra come verificare se il tuo server dedicato supporta la funzionalità dei MAC virtuali.**

## Prerequisiti

- Possedere un [server dedicato](https://www.ovhcloud.com/it/bare-metal/)
- Essere connesso all'[API OVHcloud](https://eu.api.ovh.com/)

:::info
Se non conosci l'utilizzo dell'API OVHcloud, consulta la nostra guida Iniziare a utilizzare le [API OVHcloud](/guides/manage-and-operate/api/first-steps/).

:::


## Procedura

### Ottenere le informazioni

Utilizza la seguente chiamata API:

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/specifications/network"} />

Inserisci il nome del tuo server nel campo `serviceName` e clicca su <code className="action">Execute</code>.

<img className="thumbnail" alt="SVMAC" src="/images/bare-metal-cloud/dedicated-servers/network-support-virtual-mac/support_virtual_mac_02.png" loading="lazy" />

Una lista con un record "vmac / supported" che sarà "true" o "false" (valore booleico).

<img className="thumbnail" alt="SVMAC" src="/images/bare-metal-cloud/dedicated-servers/network-support-virtual-mac/support_virtual_mac_04.png" loading="lazy" />

:::info
**Interpretazione del risultato**

- **false**: su questo server non è possibile utilizzare le funzionalità associate ai MAC virtuali.

- **true**: su questo server è possibile utilizzare le funzionalità associate ai MAC virtuali.

:::
