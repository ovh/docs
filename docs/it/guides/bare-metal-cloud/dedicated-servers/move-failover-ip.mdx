:::info
Questo articolo riguarda lo spostamento di indirizzi Additional IPv4, che è limitato secondo le [restrizioni regionali](#limitations).

La configurazione di Additional IP in una vRack (rete privata) aggira queste restrizioni regionali, perdendo la dipendenza da una sola regione e facilitando l'interconnessione su un'ampia gamma di servizi OVHcloud.

Scopri come configurare gli Additional IP in una vRack utilizzando le nostre guide per [IPv4](/guides/bare-metal-cloud/dedicated-servers/configuring-an-ip-block-in-a-vrack/) e [IPv6](/guides/bare-metal-cloud/dedicated-servers/configure-an-ipv6-in-a-vrack/).

:::


## Obiettivo

Gli Additional IP possono essere trasferiti tra i servizi utilizzati. L'interesse è di non perdere la tua reputazione, la tua referenziazione e migliorare la continuità di servizio delle tue applicazioni e sistemi.

Questa tecnologia permette di scambiare gli indirizzi IP da una soluzione all'altra in meno di un minuto, praticamente senza alcuna interruzione per i tuoi utenti. Può essere utilizzata in caso di migrazione di servizi (ad esempio, spostamento dei progetti dall'ambiente di sviluppo a quello di produzione) o in caso di trasferimento verso un server di backup in caso di guasto.

:::info
È possibile assegnare blocchi di indirizzi IP a qualsiasi servizio compatibile all'interno di una Region. I blocchi di indirizzi IP di una Region possono essere trasferiti da un datacenter a un altro all'interno della stessa Region, ma non al suo esterno.

Fanno eccezione eu-west-gra, eu-west-rbx e eu-west-sbg: i blocchi di indirizzi IP possono essere spostati tra queste 3 Region.

Una regione è un'area geografica composta da uno o più datacenter.

Solo l'intero blocco può essere spostato, non è possibile migrare i singoli IP all'interno di un blocco.

:::


**Scopri come spostare un Additional IP dallo Spazio Cliente OVHcloud o tramite le API OVHcloud. Scopri anche come spostare un Additional IP da un conto So you Start a un conto OVHcloud.**

- Disporre di un [server dedicato](https://www.ovhcloud.com/it/bare-metal/) nello Spazio Cliente OVHcloud
- Disporre di un [indirizzo Additional IP](https://www.ovhcloud.com/it/network/additional-ip/)

In caso contrario, i MAC virtuali devono essere eliminati dagli Additional IP prima dello spostamento.

## Procedura

:::info
Quando un blocco IP contenente indirizzi MAC virtuali unici viene spostato tra due server, questi indirizzi vengono temporaneamente sospesi. Appariranno sul nuovo server una volta completato lo spostamento.

D'altra parte, i blocchi che contengono indirizzi MAC virtuali duplicati non possono essere spostati. Devi prima cancellare il duplicato dell'indirizzo MAC virtuale sul blocco da spostare.

Se un blocco IP viene spostato/aggiunto al vRack, non è più legato a un server fisico. In questo caso, qualsiasi indirizzo MAC virtuale andrà perso durante il trasferimento.

:::


### Blocchi IP geolocalizzati

La geolocalizzazione di un indirizzo IP è indipendente dalla regione di collegamento.

Se ordini un blocco Additional IP su un server ma scegli una localizzazione diversa (geolocalizzazione) per il blocco IP, il blocco IP non può essere spostato verso un altro server situato nello stesso Paese del blocco. Ad esempio, un blocco Additional IP geolocalizzato in Polonia (eu-central-war) e ordinato su un server situato in un datacenter in Francia (eu-west-gra) non può essere spostato verso un server situato in un datacenter in Polonia (eu-central-war). Il blocco IP può essere trasferito solo verso un server idoneo localizzato in un datacenter in Francia.

### Spostare un Additional IP dallo Spazio Cliente OVHcloud

:::warning
Solo un blocco di dimensioni singole (/32) potrà essere spostato da un server dedicato a un VPS.

:::


È possibile utilizzare il menu a tendina sotto **I tuoi indirizzi IP pubblici e servizi associati** e selezionare <code className="action">Tutti gli Additional IP</code> per filtrare i servizi, oppure digitare direttamente l'indirizzo IP desiderato nella barra di ricerca.

<img className="thumbnail" alt="Spazio Cliente" src="/images/assets/screens/control-panel/product-selection/bare-metal-cloud/network/manage-additional-ips-new.png" loading="lazy" />

Clicca sul pulsante <code className="action">⁝</code> a destra dell'indirizzo IP da spostare, quindi su <code className="action">Sposta Additional IP</code>.

<img className="thumbnail" alt="Spazio Cliente" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/move_ip_1_new.png" loading="lazy" />

Nel menu contestuale che appare, seleziona il servizio verso cui spostare l'indirizzo IP.

Clicca su <code className="action">Successivo</code> e poi su <code className="action">Confermare</code>.

<img className="thumbnail" alt="Spazio Cliente" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/move_ip_2_new.png" loading="lazy" />

:::warning
Si prega di notare che per alcuni prodotti, gli indirizzi IP (o blocchi) devono prima essere spostati in un **Parking IP** (una posizione di archiviazione temporanea), prima di poter essere spostati nel prodotto desiderato.

Per spostare i blocchi IP su una rete vRack specifica, utilizzare **l'interfaccia di gestione vRack**, accessibile cliccando su <code className="action">Network</code> nel menu a sinistra dello schermo, quindi su <code className="action">Rete privata vRack</code>.

:::


### Spostare un Additional IP via API

Accedi alla pagina web delle [API OVHcloud](https://eu.api.ovh.com/).

Per prima cosa, è meglio verificare se l'indirizzo IP può essere spostato.
<br/>Per verificare se l'IP può essere spostato verso uno dei tuoi server dedicati, utilizza questa chiamata:

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/ipCanBeMovedTo"} />


- `serviceName`: il riferimento del server dedicato di destinazione
- `ip`: l'indirizzo Additional IP da spostare

Per spostare l'indirizzo IP, utilizza questa chiamata:

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/ipMove"} />


- `serviceName`: il riferimento del server dedicato di destinazione
- `ip`: l'indirizzo Additional IP da spostare

### Spostare un Additional IP da un conto So you Start a un conto OVHcloud

Per spostare un Additional IP da un conto SYS a un conto OVHcloud, è necessario tenere conto di diversi elementi:

- Lo spostamento di un Additional IP comporta dei costi di installazione. L'indirizzo IP non verrà spostato se la fattura rimane insoluta.
- Non è possibile spostare un Additional IP da un conto OVHcloud a un conto So you Start.
- Assicurati che il server su cui stai trasferendo l'indirizzo Additional IP si trovi nella stessa regione compatibile con esso. Consulta la sezione “Restrizioni” qui sotto.

Per iniziare, accedi al tuo conto So you Start e clicca su <code className="action">IP</code> nella dashboard principale.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/sys-ip-section.png" loading="lazy" />

Clicca sul pulsante delle impostazioni (a forma di ingranaggio <code className="action">⚙</code>) accanto all'indirizzo IP corrispondente e seleziona <code className="action">Trasferire l'IP FO</code>.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/move-ip-sys.png" loading="lazy" />

Seleziona <code className="action">Trasferisci su un servizio OVH</code>, inserisci il tuo ID cliente OVHcloud e clicca su <code className="action">Seguente</code>.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/move-to-ovh.png" loading="lazy" />

Verrà generato un ID unico (token ID). Salvalo.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/token-id.png" loading="lazy" />

Quindi, [accedi al tuo account OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.it/&ovhSubsidiary=it), clicca su <code className="action">Network</code> nel menu a sinistra, quindi su <code className="action">Indirizzi IP Pubblici</code>.

Clicca sul pulsante delle impostazioni (a forma di ingranaggio <code className="action">⚙</code>) a destra e seleziona <code className="action">Importare i tuoi indirizzi IP da SyS a OVHcloud</code>.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/import-ip-to-ovh.png" loading="lazy" />

Apparirà una finestra pop-up, inserisci l'indirizzo Additional IP (o il blocco) e l'ID unico (recuperato dall'account So you Start). Quindi, clicca su <code className="action">Successivo</code>.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/Step-1.png" loading="lazy" />

Seleziona il server di destinazione e clicca su <code className="action">Successivo</code>. Se il server dedicato è compatibile con l'indirizzo IP, verrà visualizzato un messaggio verde. In caso contrario, riceverai un messaggio di errore.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/Step-2.png" loading="lazy" /><br/>
<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/Step-2.1.png" loading="lazy" />

Nella finestra successiva, la durata viene selezionata automaticamente e vengono visualizzate le tariffe. Clicca su <code className="action">Successivo</code> per procedere.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/Step-3.png" loading="lazy" />

Seleziona la casella <code className="action">Accetta i contratti</code> per accettare le condizioni del servizio dopo averle lette. Quindi, clicca su <code className="action">Successivo</code>.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/Step-4.png" loading="lazy" />

Prendi nota del riepilogo dell'ordine e clicca su <code className="action">Confermare</code> per confermarlo.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/Step-5.png" loading="lazy" />

Verrai reindirizzato a una nuova pagina per effettuare il pagamento.

Una volta effettuato il pagamento, il tuo Additional IP verrà trasferito al tuo account OVHcloud e associato al server selezionato. Questo processo potrebbe richiedere del tempo.
