## Objetivo

Public Cloud Archive es una solución de almacenamiento ilimitado con una facturación sencilla y adaptada a sus necesidades. Hay muchos tipos de contenedores de objetos:

- para alojamiento estático (sitio web estático);
- para el alojamiento privado (p. ej.: almacenamiento de datos personales);
- para alojamiento público (para almacenar todo lo que sea accesible al público);
- para almacenamiento en frío (archivado).

El primer paso es crear un contenedor que agrupe sus archivos. 

**Esta guía explica cómo crear un contenedor desde el área de cliente de OVHcloud.**

## Procedimiento

### Creación de un contenedor de Public Cloud Archive desde el área de cliente de OVHcloud

Haga clic en <code className="action">Cloud Archive</code> en la barra de navegación de la izquierda, en la sección "Storage".
Si se trata de su primer contenedor:

![pca dashboard](/images/storage-and-backup/object-storage/pca-create-container/create-container-20211006094158312.png)

Si ya ha creado uno o más contenedores:

![pca dashboard](/images/storage-and-backup/object-storage/pca-create-container/create-container-20211006094851682.png)

Seleccione la región del contenedor y haga clic en <code className="action">Siguiente</code>.

![select a region](/images/storage-and-backup/object-storage/pca-create-container/create-container-20211006094448923.png)

Asigne un nombre al contenedor y haga clic en <code className="action">Añadir el contenedor</code>.

:::warning
Si quiere asociar su contenedor a un dominio, el nombre del contenedor no debe contener los siguientes caracteres:

- [ . ]
- [ _ ]
- y no debe utilizar mayúsculas.

Para más información, consulte nuestra guía "[Asociar un contenedor a un dominio](/guides/storage-and-backup/object-storage/pcs-link-domain/)".

:::


![container name](/images/storage-and-backup/object-storage/pca-create-container/create-container-20211006094550334.png)

Su contenedor está creado:

![container created](/images/storage-and-backup/object-storage/pca-create-container/create-container-20211006094630754.png)
