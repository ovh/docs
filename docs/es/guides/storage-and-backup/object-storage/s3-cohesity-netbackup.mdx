## Objective

This guide aims to help you configure and use OVHcloud Object Storage as a backup target in Cohesity NetBackup, through a deduplicated Disk Pool.

It covers the steps to add a cloud volume, configure optional WORM (Write Once Read Many) settings, and integrate the storage into NetBackup backup policies.

## Requirements

- A NetBackup Primary Server installed and configured. See the following documentation: "[Installing NetBackup Primary Server](https://www.veritas.com/support/en_US/doc/27801100-157469020-0/v13834345-157469020)".
- A Media Server with deduplication option installed on Red Hat Enterprise or SUSE Linux Enterprise Server. See the following documentation: "[Deduplication Guide](https://www.veritas.com/support/en_US/doc/25074086-168257404-0/index)".
- Approximately 1 TB of local disk space available for deduplication metadata management.

## Instructions

This section provides a step-by-step guide to configuring a deduplicated Disk Pool using OVHcloud Object Storage as a cloud volume in Cohesity NetBackup.

You will be guided through the entire process, from selecting the Storage Server to integrating the configuration into your backup policies. Each step is accompanied by a screenshot to assist with setup.

1. Ensure that an MSDP Storage Server is already created.

2. Log in to the NetBackup interface as an administrator.

    <img className="thumbnail" alt="connection page" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/user_connection.png" loading="lazy" />

3. Access the <code className="action">Storage</code> menu, the <code className="action">Disk storage</code> submenu, then click the <code className="action">Storage Servers</code> tab.

    <img className="thumbnail" alt="storage menu" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/storage_menu-b.png" loading="lazy" />

4. Open the <code className="action">Disk Pools</code> tab and click on <code className="action">Add</code> to create a new Disk Pool.

    <img className="thumbnail" alt="diskpool menu" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/diskpool_menu.png" loading="lazy" />

5. Select the <code className="action">Storage Server MSDP</code> on which you want to create the deduplicated pool.

    <img className="thumbnail" alt="storage server selection" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/storage_server_selection.png" loading="lazy" />

6. When selecting the volume, click on <code className="action">Add Cloud Volume</code>.

    <img className="thumbnail" alt="add cloud volume" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/add_cloud_volume.png" loading="lazy" />

7. Choose <code className="action">OVHcloud Standard Object Storage</code> as the cloud storage type.

    <img className="thumbnail" alt="type selection of storage" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/type_selection_of_storage.png" loading="lazy" />

8. Select the desired endpoint, and add the OVHcloud credential if not already done.

    <img className="thumbnail" alt="credentials page" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/credentials_page.png" loading="lazy" />

9. (Optional) To enable WORM mode (S3 Object Lock), check <code className="action">Use Object Lock</code>. Select the NetBackup lock mode matching the OVhcloud Object Lock mode:

    - Compliance -> Compliance
    - Enterprise -> Governance

    Then, set the minimum and maximum retention periods for the lock.

    <img className="thumbnail" alt="activate worm mode" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/activate_worm_mode.png" loading="lazy" />

10. Enter the name of the bucket you want to use, or create a new one.

    <img className="thumbnail" alt="bucket name" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/bucket_name.png" loading="lazy" />

11. Click on <code className="action">Next</code>, then review the settings in the Review tab.

    <img className="thumbnail" alt="review page" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/review_page.png" loading="lazy" />

12. Click on <code className="action">Add Storage Unit</code> at the top of the screen, then name the storage unit.

    <img className="thumbnail" alt="add storage unit popup" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/add_storage_unit_popup.png" loading="lazy" />

    <img className="thumbnail" alt="unit storage name" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/unit_storage_name.png" loading="lazy" />

13. (Optional) To enable WORM locking, check <code className="action">Lock until Expiration</code>.

    :::info

    Note: WORM and non-WORM data can coexist within the same deduplicated Disk Pool.

    :::


14. Review all settings in the Review tab, then confirm.

    <img className="thumbnail" alt="unit storage review" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/unit_storage_review.png" loading="lazy" />

15. You can now:

    - Use the storage unit directly in your backup jobs,
    - Or use it as a secondary target via a Storage Lifecycle Policy (SLP).

16. Modify your backup policies accordingly to integrate OVHcloud Object Storage.

    <img className="thumbnail" alt="storage lifecycle policy" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/storage_lifecycle_policy.png" loading="lazy" />
    <img className="thumbnail" alt="create storage lifecycle policy" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/new_operation_storage_lifecycle_policy.png" loading="lazy" />
    <img className="thumbnail" alt="create new policy" src="/images/storage-and-backup/object-storage/s3-cohesity-netbackup/create_new_policy.png" loading="lazy" />
