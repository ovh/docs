## Objetivo

Este guía le explica cómo eliminar diferentes elementos de su servicio Backup Agent: los agentes, los vaults y los tenants.

## Requisitos

- Tener un servicio Backup Agent activo.

## Procedimiento

### Eliminar un agente

:::info
**Comportamiento según el uso del agente:**

- **Si el agente no se ha utilizado para transferir datos** : Puede eliminarse inmediatamente. Se desactivará en primer lugar, y luego se eliminará.
- **Si se han transferido datos** : Aplicamos una suspensión del agente en estado "Desactivado" durante 14 días, el tiempo necesario para que se puedan eliminar los datos inmutables.

:::


:::warning
Una vez que su agente esté suspendido, ya no puede crear un nuevo agente en el mismo servidor, debe esperar a que el primer agente se elimine.

:::


Vaya a la sección <code className="action">Agents</code> y haga clic en el botón de eliminación para el agente correspondiente.

Confirme la eliminación del agente en la ventana que aparece.

<img className="thumbnail" alt="Backup Agent Delete Agent" src="/images/storage-and-backup/backup-agent/backup-agent-deletion/01-backup-agent-delete-agent.png" loading="lazy" />

### Eliminar un vault

:::warning
Un vault no puede eliminarse si contiene datos. Si desea eliminar un vault, debe [contactar al soporte](https://help.ovhcloud.com/csm?id=csm_get_help), quien realizará comprobaciones con usted antes de iniciar la eliminación.

:::


Vaya a la sección <code className="action">Vaults</code> y haga clic en el botón de eliminación para el vault correspondiente.

Confirme la eliminación en la ventana que aparece.

<img className="thumbnail" alt="Backup Agent Delete Vault" src="/images/storage-and-backup/backup-agent/backup-agent-deletion/01-backup-agent-delete-vault.png" loading="lazy" />

### Eliminar un tenant

:::warning
Por el momento, un tenant no puede eliminarse de forma autónoma. Si desea eliminar un tenant, debe [contactar al soporte](https://help.ovhcloud.com/csm?id=csm_get_help). Tomaremos en cuenta su solicitud.

:::


Seleccione su tenant y haga clic en el botón de eliminación.

Confirme la eliminación en la ventana que aparece.

<img className="thumbnail" alt="Backup Agent Delete Tenant" src="/images/storage-and-backup/backup-agent/backup-agent-deletion/01-backup-agent-delete-tenant.png" loading="lazy" />
