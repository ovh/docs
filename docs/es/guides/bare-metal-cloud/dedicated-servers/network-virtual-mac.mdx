## Objetivo

OVHcloud permite asociar una dirección MAC virtual a una dirección IP para poder desplegar máquinas virtuales con una configuración bridge en los servidores.

**Esta guía explica cómo crear una MAC virtual y asociarle una Additional IP.**

## Requisitos

- Tener [un servidor dedicado](https://www.ovhcloud.com/es-es/bare-metal/) que soporte las MAC virtuales. Consulte [esta guía](/guides/bare-metal-cloud/dedicated-servers/network-support-virtual-mac/) para averiguarlo.
- Tener una [dirección Additional IP](https://www.ovhcloud.com/es-es/network/additional-ip/) o un bloque de Additional IP (RIPE).

## Procedimiento

### Asignar una dirección MAC

:::warning
Si un bloque IP ha sido movido al vRack, ya no está asignado a un servidor físico por este motivo, ya no es posible asignar una MAC virtual a una IP.

:::


#### Desde el área de cliente de OVHcloud

Haga clic en la pestaña <code className="action">Additional IP</code>.

<img className="thumbnail" alt="manage IPs" src="/images/bare-metal-cloud/dedicated-servers/network-virtual-mac/manageIPs2022.png" loading="lazy" />

Localice su dirección Additional IP (o su bloque) en la lista, haga clic en el botón <code className="action">···</code> situado al final de la línea correspondiente para ver la lista de opciones y seleccione <code className="action">Añadir una MAC virtual</code>.

<img className="thumbnail" alt="IP" src="/images/bare-metal-cloud/dedicated-servers/network-virtual-mac/addvmac.png" loading="lazy" />

En el cuadro de diálogo, seleccione un tipo en la lista desplegable, introduzca el nombre de la máquina virtual y haga clic en <code className="action">Aceptar</code>.

* **Tipo**: Elija el tipo de dirección MAC virtual («VMware» para el sistema VMware ESXi y «ovh» para todos los demás sistemas de virtualización).
* **Nombre de la máquina virtual**: Nombre que quiera asignarle a la dirección MAC virtual, para luego encontrar más fácilmente la pareja IP-MAC.

<img className="thumbnail" alt="IP" src="/images/bare-metal-cloud/dedicated-servers/network-virtual-mac/addvmac2.png" loading="lazy" />

:::info
No olvide asignar la dirección MAC virtual creada en la configuración de su máquina virtual.

:::


#### Vía la API OVHcloud

Utilice la siguiente llamada a la API:

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/virtualMac/\{macAddress\}/virtualAddress/\{ipAddress\}"} />


### Eliminar una dirección MAC

:::warning
Si elimina una dirección MAC, no será posible recuperarla más adelante.

:::


#### Desde el área de cliente de OVHcloud

Conéctese a su [área de cliente de OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.es/&ovhSubsidiary=es), haga clic en <code className="action">Network</code> en el menú situado a la izquierda de la pantalla y seleccione <code className="action">Direcciones IP públicas</code>. Seleccione el servidor para ver las Additional IP o bloques de IP asociados.

Por último, haga clic en el botón <code className="action">···</code> situado al final de la línea correspondiente y seleccione <code className="action">Eliminar la MAC virtual</code>.

#### Vía la API OVHcloud

Utilice la siguiente llamada a la API:

<Api version="v1" section="/dedicated/server" method="DELETE" route={"/dedicated/server/\{serviceName\}/virtualMac/\{macAddress\}/virtualAddress/\{ipAddress\}"} />


## FAQ

- **¿Qué ocurre si muevo un bloque con vMAC a un servidor Advance de tercera generación (equipado con un procesador EPYC 4004 Series) que ya tenga 32 vMACs?**

El bloque no se moverá.

Ejemplo: si intenta mover un bloque de 4 IP con diferentes vMAC asociadas a un servidor que ya tiene 30 vMAC, el bloque no se moverá porque el total de vMAC sería superior a las 32 vMAC autorizadas.
