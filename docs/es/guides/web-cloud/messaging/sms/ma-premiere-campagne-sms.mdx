## Objetivo

OVHcloud ofrece una serie de herramientas, disponibles en el área de cliente, que permiten enviar SMS. Esta guía explica cómo utilizar esas herramientas para crear una campaña de envío de SMS.

## Requisitos

- Disponer de una cuenta de SMS en OVHcloud con saldo de SMS.

## Procedimiento

La barra de herramientas y los accesos rápidos le permitirán acceder a las principales funcionalidades para enviar su campaña de SMS.

<img className="thumbnail" alt="firstsms" src="/images/web-cloud/messaging/sms/ma-premiere-campagne-sms/firstsms01.png" loading="lazy" />

### 1. Añadir contactos

#### Añadir una lista de contactos

Puede importar una lista de contactos a través de un archivo .csv o .txt.

Para añadir una lista de contactos, abra la pestaña <code className="action">Contactos</code> y haga clic en <code className="action">Crear una lista de contactos</code>. 

<img className="thumbnail" alt="firstsms" src="/images/web-cloud/messaging/sms/ma-premiere-campagne-sms/firstsms03.png" loading="lazy" />

En [esta guía](/guides/web-cloud/messaging/sms/liste-de-destinataire-sms/) se explica cómo hacerlo.

#### Añadir una agenda de contactos

A diferencia de las listas de contactos, las agendas de contactos contienen contactos que puede nombrar y, por tanto, identificar más fácilmente para campañas específicas.

Para añadir una agenda de contactos, abra la pestaña <code className="action">Contactos</code> y haga clic en la <code className="action">Agenda de contactos</code>.

<img className="thumbnail" alt="firstsms" src="/images/web-cloud/messaging/sms/ma-premiere-campagne-sms/firstsms04.png" loading="lazy" />

Para más información sobre las agendas de contactos, consulte [esta guía](/guides/web-cloud/messaging/sms/gerer-mes-carnets-dadresses-sms/).

### 2. Crear un remitente

Por defecto, el envío de SMS desde una cuenta de OVHcloud se realiza desde un número que permite responder (funcionalidad solo disponible en Francia). 

Sin embargo, en algunos casos puede ser más apropiado utilizar un remitente alfanumérico (que se crea desde la pestaña <code className="action">Remitentes</code>) para que el SMS se envíe a nombre de su empresa u organización.

<img className="thumbnail" alt="firstsms" src="/images/web-cloud/messaging/sms/ma-premiere-campagne-sms/firstsms05.png" loading="lazy" />

Para ello, consulte el apartado de la guía «[Enviar SMS desde el área de cliente](/guides/web-cloud/messaging/sms/envoyer-des-sms-depuis-mon-espace-client#3-elegir-el-remitente-del-sms/)» relativo a la elección de remitentes.

### 3. El envío de una campaña de SMS

La pestaña <code className="action">Mensaje y campaña</code> le permitirá acceder a las opciones de envío, al historial de sus SMS enviados y recibidos, así como a sus envíos de SMS planificados como parte de los envíos aplazados.

<img className="thumbnail" alt="firstsms" src="/images/web-cloud/messaging/sms/ma-premiere-campagne-sms/firstsms02.png" loading="lazy" />

Para enviar un SMS unitario desde el área de cliente, consulte [la guía correspondiente](/guides/web-cloud/messaging/sms/envoyer-des-sms-depuis-mon-espace-client/).

Para enviar una campaña de SMS, haga clic en <code className="action">Gestión de campañas</code> y seleccione <code className="action">Crear una campaña</code>.

<img className="thumbnail" alt="firstsms" src="/images/web-cloud/messaging/sms/ma-premiere-campagne-sms/firstsms06.png" loading="lazy" />

En primer lugar, indique un nombre para la campaña en el campo correspondiente.

Seleccione el remitente entre los disponibles.

<img className="thumbnail" alt="firstsms" src="/images/web-cloud/messaging/sms/ma-premiere-campagne-sms/firstsms07.png" loading="lazy" />

Componga su mensaje y elija entre un envío inmediato o planificado. En caso de envío planificado, deberá definir la fecha y la hora del envío.

<img className="thumbnail" alt="firstsms" src="/images/web-cloud/messaging/sms/ma-premiere-campagne-sms/firstsms08.png" loading="lazy" />

Haga clic en el botón <code className="action">Enviar</code> para enviar o planificar la campaña.
