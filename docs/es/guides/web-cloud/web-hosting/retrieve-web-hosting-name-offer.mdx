## Objetivo

¿No recuerda el nombre de su [solución de alojamiento web](https://www.ovhcloud.com/es-es/web-hosting/)?
¿Desea consultar sus detalles o compararla con otra solución?

Mientras utiliza sus servicios, es posible que necesite el nombre de su solución de alojamiento web.

**Descubra cómo identificar el tipo de solución de alojamiento web que posee desde su área de cliente de OVHcloud.**

## Requisitos

- Tener un [plan de alojamiento web](https://www.ovhcloud.com/es-es/web-hosting/).
{/* CP-NAV-START:web-hosting */}
---

### Acceso al área de cliente de OVHcloud

- **Enlace directo:** [Hosting plans](https://manager.eu.ovhcloud.com/#/web/hosting)
- **Ruta de navegación:** <code className="action">Web Cloud</code> > <code className="action">Alojamientos</code> > Seleccione su alojamiento web

---
{/* CP-NAV-END:web-hosting */}

## Procedimiento

Haga clic en las fichas siguientes para ver cada una de las **2** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Acceda a la página [Hosting plans](https://manager.eu.ovhcloud.com/#/web/hosting) y seleccione el alojamiento web correspondiente.
    
    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    En el marco **Suscripción**, encontrará la etiqueta **Solución**.
    
    <img className="thumbnail" alt="Plan" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-plan-pro.png" loading="lazy" />

Debajo de esta etiqueta, encontrará el nombre de su solución de alojamiento web (por ejemplo: Personal, Pro, Performance, etc.).
  </Tab>
</Tabs>
