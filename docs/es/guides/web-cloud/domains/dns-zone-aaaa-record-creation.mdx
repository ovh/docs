## Objetivo

¿Desea que su sitio web sea accesible a través de su nombre de dominio? Para ello, el dominio debe apuntar a la dirección IP del servicio en el que esté alojado el sitio web (alojamiento web, servidor dedicado, VPS, etc.). A continuación, deberá configurar la zona DNS activa del dominio con un registro DNS de tipo AAAA.

**Descubra cómo añadir un registro DNS de tipo AAAA a una zona DNS gestionada en OVHcloud para un dominio.**

:::info
Para modificar o eliminar un registro DNS de tipo AAAA de una zona DNS de OVHcloud, siga [esta guía](/guides/web-cloud/domains/dns-zone-edit/).

:::


## Requisitos

- Tener un [dominio](https://www.ovhcloud.com/es-es/domains/).
- Tener una zona DNS asociada al dominio en OVHcloud.

{/* CP-NAV-START:web-dns-zone */}
---

### Acceso al área de cliente de OVHcloud

- **Enlace directo:** [Zonas DNS](https://manager.eu.ovhcloud.com/#/web/zone)
- **Ruta de navegación:** <code className="action">Web Cloud</code> > <code className="action">Zonas DNS</code> > Seleccione su nombre de dominio

## Procedimiento

:::warning
Añadir, modificar o eliminar registros DNS en una zona DNS activa es una operación delicada. En caso de duda, contacte con un [proveedor especializado](https://partner.ovhcloud.com/es-es/directory/).

:::


### Añadir un registro DNS de tipo AAAA a un dominio

Haga clic en las pestañas siguientes para ver cada uno de los **5** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página [Zonas DNS](https://manager.eu.ovhcloud.com/#/web/zone) y seleccione el dominio correspondiente.
    
    <img className="thumbnail" alt="DNS zones" src="/images/assets/screens/control-panel/product-selection/web-cloud/dns-zones.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en el botón <code className="action">Añadir un registro</code>.
  </Tab>
  <Tab label="Paso 3">
    En la ventana que se abre, seleccione el tipo de registro <code className="action">AAAA</code>.
  </Tab>
  <Tab label="Paso 4">
    Introduzca la dirección IP (por ejemplo, `2001:db8:1:1b00:203:0:113:0`) del servicio en el que esté situado su sitio web (alojamiento web, servidor dedicado, VPS, etc.) en el campo `Destino *` y haga clic en <code className="action">Siguiente</code>.
  </Tab>
  <Tab label="Paso 5">
    Revise el resumen y haga clic en <code className="action">Aceptar</code>. Espere hasta **24** horas para que la propagación de la adición en la red DNS sea plenamente efectiva.
  </Tab>
</Tabs>

### Añadir un registro DNS de tipo AAAA para el subdominio de un dominio

Haga clic en las pestañas siguientes para ver cada uno de los **5** pasos.

<Tabs>
  <Tab label="Paso 1">
    Acceda a la página [Zonas DNS](https://manager.eu.ovhcloud.com/#/web/zone) y seleccione el dominio correspondiente.
    
    <img className="thumbnail" alt="DNS zones" src="/images/assets/screens/control-panel/product-selection/web-cloud/dns-zones.png" loading="lazy" />
  </Tab>
  <Tab label="Paso 2">
    Haga clic en el botón <code className="action">Añadir un registro</code>.
  </Tab>
  <Tab label="Paso 3">
    En la ventana que se abre, seleccione el tipo de registro <code className="action">AAAA</code>.
  </Tab>
  <Tab label="Paso 4">
    Introduzca en el campo `Subdominio` el subdominio correspondiente (por ejemplo, `www` para el subdominio `www.domain.tld`) y, en el campo `Destino *`, la dirección IP (por ejemplo, `2001:db8:1:1b00:203:0:113:0`) del servicio en el que esté situado el sitio web (alojamiento web, servidor dedicado, VPS, etc.). Haga clic en <code className="action">Siguiente</code>.
  </Tab>
  <Tab label="Paso 5">
    Revise el resumen y haga clic en <code className="action">Aceptar</code>. Espere hasta **24** horas para que la propagación de la adición en la red DNS sea plenamente efectiva.
  </Tab>
</Tabs>
