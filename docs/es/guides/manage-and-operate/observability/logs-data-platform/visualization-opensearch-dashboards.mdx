## Objective

This guide will help you unleash the full power of [OpenSearch Dashboards](https://opensearch.org/docs/latest/dashboards/index/) and craft some beautiful Dashboards from your logs.

## Requirements

This is what you need to know to get you started:

- You are already sending logs on a stream you own: [see the quick start tutorial](/guides/manage-and-operate/observability/logs-data-platform/getting-started-quick-start/)
- There is nothing else

After some training you will be able to do this kind of Dashboard:

## Instructions

### Create your Stream Alias

To access your logs from OpenSearch Dashboards, you will need to setup an OpenSearch Alias and link them to your Graylog streams, so here we go:

1. In the <code className="action">Alias</code> tab, click on the <code className="action">Add an alias</code> button
2. Choose a name and define a description for your alias
3. Save the entry by clicking the <code className="action">Save</code> button
4. Once the alias has been created, use the **...** menu to the right and select <code className="action">Attach content to the alias</code> option.
5. Define there the graylog streams you want to associate to your alias
6. That's it.

<img className="thumbnail" alt="Alias creation" src="/images/manage-and-operate/observability/logs-data-platform/visualization-opensearch-dashboards/alias.png" loading="lazy" />

So now Logs Data Platform knows which stream you want to browse. Now let's configure OpenSearch Dashboards and see if it works!

### Access your OpenSearch Dashboards instance

To create your OpenSearch Dashboards instance, click on OpenSearch Dashboards tab, click on <code className="action">Add a instance</code>, put a description and click on **Order** to launch the creation of your instance. Your instance will be created and delivered in approximately 20 minutes.

<img className="thumbnail" alt="osd creation" src="/images/manage-and-operate/observability/logs-data-platform/visualization-opensearch-dashboards/osd_created.png" loading="lazy" />

Use the **...** menu to the right and select <code className="action">Access to your OpenSearch Dashboards instance</code> option to be redirected.

<img className="thumbnail" alt="osd access" src="/images/manage-and-operate/observability/logs-data-platform/visualization-opensearch-dashboards/url.png" loading="lazy" />

Once there, use the right Identity provider to sign in and set on the first page. Click on the <code className="action">Add data</code> button to add sample data you can play with. However if you want to use your own data, you must configure **Index Patterns** in the stack management page. This page is accessible by clicking on the <code className="action">Manage</code> button next to the "Add data" button. You can also use the "Stack Management" option in the left side menu, displayable by using the top left the sandwich button.

In this configuration page, you can configure as the Index name, the full name of your alias **ldp-XXXXX-a-XXXXX**, but you can also use wildcards. Choose **timestamp** for the time field name then click on Discover tab to read your log entries.

<img className="thumbnail" alt="osd setup" src="/images/manage-and-operate/observability/logs-data-platform/visualization-opensearch-dashboards/osd_setup.png" loading="lazy" />

You can also explore any [OpenSearch index](/guides/manage-and-operate/observability/logs-data-platform/opensearch-index/) you created on the platform. One OpenSearch Dashboards instance allows you to explore all the data you delivered on Logs Data Platform.

To know what you can do with OpenSearch Dashboards, read the [OpenSearch Dashboards documentation](https://opensearch.org/docs/latest/dashboards/index/)
