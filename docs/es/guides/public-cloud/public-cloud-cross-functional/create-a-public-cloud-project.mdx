## Objetivo

Crear un proyecto es el primer paso para implementar [instancias Public Cloud](https://www.ovhcloud.com/es-es/public-cloud/).

**Esta guía le guiará a través de los pasos para crear su primer proyecto de Public Cloud.**

### Acceso al área de cliente de OVHcloud

- **Enlace directo:** [Public Cloud Projects](https://manager.eu.ovhcloud.com/#/pci/projects)
- **Ruta de navegación:** <code className="action">Public Cloud</code> > Seleccione su proyecto

## Procedimiento

Una vez que haya consultado la documentación disponible, acepte los términos del contrato marcando la casilla correspondiente y haga clic en <code className="action">Descubrir el universo Public Cloud</code>.

<img className="thumbnail" alt="crear proyecto" src="/images/public-cloud/public-cloud-cross-functional/create-a-public-cloud-project/firstproject2024.png" loading="lazy" style={{ maxWidth: '400px' }} />

- Si todavía no tiene una forma de pago válida en su cuenta de OVHcloud, comenzará el proceso de creación del proyecto Public Cloud. El proyecto se creará en [Modo Discovery](#discovery).
- Si ya ha introducido una forma de pago en su cuenta de OVHcloud, deberá nombrar en primer lugar su proyecto de Public Cloud y seleccionar su forma de pago.

<img className="thumbnail" alt="crear proyecto" src="/images/public-cloud/public-cloud-cross-functional/create-a-public-cloud-project/project-creation.png" loading="lazy" style={{ maxWidth: '400px' }} />

Una vez finalizado el proceso de creación, podrá ver su nuevo proyecto de Public Cloud en la esquina superior izquierda de la sección <code className="action">Public Cloud</code> de su área de cliente de OVHcloud:

<img className="thumbnail" alt="Nuevo proyecto creado" src="/images/public-cloud/public-cloud-cross-functional/create-a-public-cloud-project/pci-interface-2025.png" loading="lazy" style={{ maxWidth: '400px' }} />

Ya puede acceder a todo el ecosistema Public Cloud de OVHcloud y consultar nuestra guía "[Conocer la interfaz de Public Cloud](/guides/public-cloud/public-cloud-cross-functional/03-public-cloud-interface-walk-me/)" para conocer esta nueva interfaz en el área de cliente.

<a name="discovery"></a>

:::info
**Modo Discovery**

Si es su primer proyecto de Public Cloud y no ha introducido una forma de pago en su cuenta, el proyecto de Public Cloud se limitará al "Modo Discovery" del área de cliente de OVHcloud. Esto significa que puede explorar y descubrir los productos de Public Cloud, pero todavía no puede crear recursos como instancias.

Para aprovechar al máximo el potencial del Public Cloud y empezar a utilizar sus primeros recursos, haga clic en <code className="action">Activar el proyecto</code> en la página de inicio de su proyecto.

:::
