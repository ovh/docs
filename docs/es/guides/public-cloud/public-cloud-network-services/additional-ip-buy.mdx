## Objetivo

Es posible que necesite configurar una dirección Additional IP en sus instancias por diferentes razones:

- Tiene varios sitios en su instancia.
- Aloja proyectos internacionales.

Para satisfacer estas necesidades, puede comprar una dirección Additional IP para sus instancias Public Cloud.

Estas direcciones Additional IP solo pueden migrar a las instancias de un mismo proyecto.

**Esta guía explica cómo comprar una Additional IP para su proyecto Public Cloud OVHcloud.**

## Requisitos

- Disponer al menos de una instancia. A tal efecto, consulte [la guía para crear una instancia desde el área de cliente](/guides/public-cloud/compute/public-cloud-first-steps#3-crear-una-instancia/).

:::warning
Esta funcionalidad no está actualmente disponible para instancias Metal.

## Procedimiento

En el menú de la izquierda, abra <code className="action">IP públicas</code> en **Network**.

Abra la pestaña <code className="action">Additional IP</code> y haga clic en el botón <code className="action">Acciones</code>. Seleccione <code className="action">Añadir una nueva IP</code>.

<img className="thumbnail" alt="Añadir IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_01.png" loading="lazy" />

En el paso 1 del pedido, haga clic en <code className="action">Siguiente</code>.

<img className="thumbnail" alt="Añadir IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_02.png" loading="lazy" />

El paso 2 permite seleccionar un país para la nueva dirección IP.

<img className="thumbnail" alt="Añadir IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_03.png" loading="lazy" />

Están disponibles los siguientes países para la geolocalización de las IP:

|          |          |          |           |                |
|:--------:|:--------:|:--------:|:---------:|:--------------:|
| Bélgica  | Finlandia  | Francia   | Alemania   | República Checa |
| Irlanda  |  Italia   | Lituania | Países Bajos | Reino Unido    |
| Portugal |  España   |  Polonia |  Suiza |                 |

> [!primary] **Disponibilidad**
> 
> Es posible que algunos de estos países no estén listados, en función de la disponibilidad actual de las direcciones IPv4.
> 

> [!primary] **Localización**
>
> La geolocalización de IP está basada únicamente en organismos de referencia.
> 
> Por ejemplo, el [RIPE NCC](https://www.ripe.net/) sirve a Europa como registro regional de Internet.
>
> Si necesita comprobar la geolocalización de otra forma, póngase en contacto directamente con las organizaciones pertinentes. OVHcloud no le ayudará.

Una vez seleccionado el país, haga clic en <code className="action">Siguiente</code>.

En la última etapa, seleccione su instancia en el menú desplegable. Haga clic en <code className="action">Generar la orden de pedido</code>.

<img className="thumbnail" alt="Añadir IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_04.png" loading="lazy" />

La orden de pedido se abrirá automáticamente para finalizar la compra.

Para más información, consulte nuestra guía sobre la [gestión de los pedidos en OVHcloud](/guides/account-and-service-management/managing-billing-payments-and-services/managing-ovh-orders/).

También puede consultar la orden de pedido en el área de cliente, en la sección "<code className="action">Cuadro de mando</code>", haciendo clic en "<code className="action">Ver mis pedidos</code>".

El siguiente paso es configurar la IP en el sistema operativo. Consulte [nuestra guía sobre cómo configurar](/guides/public-cloud/public-cloud-network-services/getting-started-04-configure-additional-ip-to-instance/) el alojamiento web.
