## Objetivo

Es posible que necesite configurar una dirección Additional IP en sus instancias por diferentes razones:

- Tiene varios sitios en su instancia.
- Aloja proyectos internacionales.

Para satisfacer estas necesidades, puede comprar una dirección Additional IP para sus instancias Public Cloud.

Estas direcciones Additional IP solo pueden migrar a las instancias de un mismo proyecto.

**Esta guía explica cómo comprar una Additional IP para su proyecto Public Cloud OVHcloud.**

## Requisitos

- Tener acceso al [área de cliente de OVHcloud](/links/manager).
- Disponer al menos de una instancia. A tal efecto, consulte [la guía para crear una instancia desde el área de cliente](/guides/public-cloud/compute/compute-getting-started#3-crear-una-instancia).

> [!warning]
> Esta funcionalidad no está actualmente disponible para instancias Metal.
>

## Procedimiento

Conéctese al [área de cliente de OVHcloud](/links/manager), acceda a la sección de  `Public Cloud` y seleccione el proyecto de Public Cloud correspondiente.

En el menú de la izquierda, abra `IP públicas` en **Network**.

Abra la pestaña `Additional IP` y haga clic en el botón `Acciones`. Seleccione `Añadir una nueva IP`.

![Añadir IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_01.png)

En el paso 1 del pedido, haga clic en `Siguiente`.

![Añadir IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_02.png)

El paso 2 permite seleccionar un país para la nueva dirección IP.

![Añadir IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_03.png)

Están disponibles los siguientes países para la geolocalización de las IP:

|          |          |          |           |                |
|:--------:|:--------:|:--------:|:---------:|:--------------:|
| Bélgica  | Finlandia  | Francia   | Alemania   | República Checa |
| Irlanda  |  Italia   | Lituania | Países Bajos | Reino Unido    |
| Portugal |  España   |  Polonia |  Suiza |                 |

> [!info] **Disponibilidad**
> 
> Es posible que algunos de estos países no estén listados, en función de la disponibilidad actual de las direcciones IPv4.
> 

> [!info] **Localización**
>
> La geolocalización de IP está basada únicamente en organismos de referencia.
> 
> Por ejemplo, el [RIPE NCC](https://www.ripe.net/) sirve a Europa como registro regional de Internet.
>
> Si necesita comprobar la geolocalización de otra forma, póngase en contacto directamente con las organizaciones pertinentes. OVHcloud no le ayudará.

Una vez seleccionado el país, haga clic en `Siguiente`.

En la última etapa, seleccione su instancia en el menú desplegable. Haga clic en `Generar la orden de pedido`.

![Añadir IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_04.png)

La orden de pedido se abrirá automáticamente para finalizar la compra.

Para más información, consulte nuestra guía sobre la [gestión de los pedidos en OVHcloud](/guides/account-and-service-management/managing-billing-payments-and-services/ovh-orders).

También puede consultar la orden de pedido en el área de cliente, en la sección "`Cuadro de mando`", haciendo clic en "`Ver mis pedidos`".

El siguiente paso es configurar la IP en el sistema operativo. Consulte [nuestra guía sobre cómo configurar](/guides/public-cloud/public-cloud-network-services/configure-additional-ip) el alojamiento web.
