## Objectif

En cas de mauvaises configurations, ou de perte de clé SSH, votre instance peut être inaccessible.

Dans de telles circonstances, vous pouvez utiliser le mode rescue pour reconfigurer votre instance ou récupérer vos données. 

**Ce guide vous explique comment redémarrer votre instance Public Cloud OVHcloud en mode rescue et accéder à vos fichiers.**

## Prérequis

- Une [instance Public Cloud](https://www.ovhcloud.com/fr/public-cloud/compute/) dans votre compte OVHcloud

## En pratique

:::danger
A ce jour, le mode rescue pour les instances Metal n'est pas accessible via l'espace client OVHcloud. Pour plus d'informations, consultez notre guide dédié au [mode rescue pour les instances Metal](/guides/public-cloud/compute/rescue-mode-metal-instance/).

:::


### Activer le mode rescue

Cliquez sur l’onglet <code className="action">Instances</code> dans la barre de navigation à gauche.

Cliquez sur <code className="action">...</code> à droite de l’instance et sélectionnez <code className="action">Redémarrer en mode rescue</code>.

<img className="thumbnail" alt="tableau de bord" src="/images/public-cloud/compute/put-an-instance-in-rescue-mode/rescue2022.png" loading="lazy" />

Vous allez maintenant voir la boîte de dialogue « Démarrer en mode rescue ». Cliquez sur la liste déroulante pour sélectionner la distribution Linux que vous souhaitez utiliser en mode rescue, puis cliquez sur le bouton <code className="action">Redémarrer</code>.

<img className="thumbnail" alt="tableau de bord" src="/images/public-cloud/compute/put-an-instance-in-rescue-mode/rescue2.png" loading="lazy" />

Une fois l’instance redémarrée en mode rescue, une boîte d’information affiche les méthodes d’accès disponibles.

<img className="thumbnail" alt="tableau de bord" src="/images/public-cloud/compute/put-an-instance-in-rescue-mode/rescuedata.png" loading="lazy" />

Votre **mot de passe du mode rescue** temporaire sera uniquement affiché dans la console VNC. Cliquez sur votre instance dans le tableau, puis accédez à l'onglet <code className="action">Console VNC</code> pour le récupérer.

### Accéder à vos données

Une fois le mode rescue activé, les données de votre instance seront attachées en tant que disque supplémentaire. Il suffit donc de le monter, en suivant les étapes suivantes.

En premier lieu, ouvrez une [connexion SSH](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction/) avec votre instance. Une fois connecté, vérifiez les disques disponibles avec cette commande :

```bash
lsblk
```

Le résultat sera similaire à l'exemple de sortie suivant :

```console
NAME    MAJ:MIN RM  SIZE RO TYPE MOUNTPOINTS
sda       8:0    0  2.9G  0 disk
└─sda1    8:1    0  2.9G  0 part /
sdb       8:16   0   25G  0 disk
├─sdb1    8:17   0   24G  0 part
├─sdb14   8:30   0    4M  0 part
├─sdb15   8:31   0  106M  0 part
└─sdb16 259:0    0  913M  0 part
```

En mode rescue, `sda` est le disque en mode rescue et `sda1` est la partition de secours principale montée sur `/`.

Dans cet exemple, le disque principal est `sdb` et la partition système est `sdb1` (indiquée par la taille).

Montez cette partition avec la commande suivante :

```bash
mount /dev/sdb1 /mnt/
```

Vos fichiers sont maintenant accessibles depuis le point de montage `/mnt`.

### Désactiver le mode rescue

Une fois vos tâches terminées, vous pouvez désactiver le mode rescue en redémarrant votre instance depuis l'espace client. Pour cela, cliquez sur <code className="action">...</code> et sélectionnez <code className="action">Sortir du mode rescue</code>.

<img className="thumbnail" alt="tableau de bord" src="/images/public-cloud/compute/put-an-instance-in-rescue-mode/rescueexit2022.png" loading="lazy" />

:::warning
Si le bouton <code className="action">Sortir du mode rescue</code> n'apparaît pas une fois l'instance en mode rescue, nous vous recommandons de rafraîchir votre onglet.

:::


### Activer le mode rescue avec les API OpenStack

Vous pouvez activer le mode rescue via les API OpenStack en utilisant la commande suivante :

```bash
nova rescue INSTANCE_ID
```

Pour sortir du mode rescue, utilisez la commande suivante :

```bash
nova unrescue INSTANCE_ID
```
