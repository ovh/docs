## Requirements

- A Nutanix cluster in your OVHcloud account

- Being connected to the cluster via the Prism Element web interface

## Overview of storage operations in a Nutanix cluster

When a Nutanix cluster is created, the system connects all the nodes' disks in a **Storage Pool**. It is not recommended to have multiple Storage Pools.

By default, the **replication factor** is set to 2, and it can be changed to 3 if you have at least 5 nodes.

The data is not stored directly in the Storage Pool, it is stored in **Storage Containers** where it is possible to enable options for compression, deduplication, etc. to optimise storage utilisation. 

There are also **Volume Groups** that provide the ability to access via ISCSI or directly in SCSI simulation for:

- A third-party computer outside the cluster or a cluster VM
- Multiple third-party computers or VMs in the cluster for applications that require shared storage, such as Microsoft SQL databases in Cluster mode

## Instructions

### Modifying **replication factor** 

Click the gear in the top right of the Prism Element interface.

<img className="thumbnail" alt="prism element dashboard" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/prism-element-dashboard.PNG" loading="lazy" />

Scroll through the settings and click <code className="action">Redundancy state</code>.

If you have 5 nodes, you can change the **Desired Redundancy factor** setting from 2 to 3.

<img className="thumbnail" alt="Redundancy State" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/RedondancyState.PNG" loading="lazy" />

It takes some time for the data to be on 3 nodes.

### Creating a **Storage Container**

We will create a **Storage Container**, with a minimum of 300 GB reserved for this storage. The other settings are default ones.

From the menu, select <code className="action">Storage</code>.

<img className="thumbnail" alt="Storage Menu" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/StorageMenu.png" loading="lazy" />

Select the <code className="action">Storage Container</code> tab and click <code className="action">+ Storage Container</code> on the right.

<img className="thumbnail" alt="Storage Container Dashboard" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/StorageContainerDashboard.PNG" loading="lazy" />

Enter a name for the storage container in the **NAME** entry box.<br/>
Then click <code className="action">Advanced Settings</code>.

<img className="thumbnail" alt="Storage Container Creation1" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/StorageContainerCreation1.PNG" loading="lazy" />

In the **RESERVED CAPACITY** field, enter the size of your container. Other options are also available.

<img className="thumbnail" alt="Storage Container Creation2" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/StorageContainerCreation2.PNG" loading="lazy" />

Then click <code className="action">Save</code> to finish creating the **Storage Container**.

<img className="thumbnail" alt="Storage Container Creation3" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/StorageContainerCreation3.PNG" loading="lazy" />

The new **Storage Container** is then visible in the dashboard.

<img className="thumbnail" alt="Storage Container Dasboard" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/StorageContainerDasboardNC.PNG" loading="lazy" />

For details on creating a **Storage Container**, see the [Go further](#gofurther) section of this guide.

### Create a **Volume Group**

Select the <code className="action">Volume Group</code> tab and click <code className="action">+ Volume Group</code> on the right.

<img className="thumbnail" alt="Volume Group DashBoard" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/VolumeGroupDashBoard.PNG" loading="lazy" />

Click **+ Add New Disk**.

<img className="thumbnail" alt="Volume Group Creation1" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/VolumeGroupCreation1.PNG" loading="lazy" />

Enter a **size** in the dedicated field and click <code className="action">Add</code>.

<img className="thumbnail" alt="Volume Group Creation2" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/VolumeGroupCreation2.PNG" loading="lazy" />

The disk appears in the **Volume Group**. You can then add several other disks.

<img className="thumbnail" alt="Volume Group Creation3" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/VolumeGroupCreation3.PNG" loading="lazy" />

Once you have created your disk(s), browse the available options and confirm that you want to create the **Volume Group** by clicking <code className="action">Save</code>.

<img className="thumbnail" alt="Volume Group Creation4" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/VolumeGroupCreation4.PNG" loading="lazy" />

The **Volume Group** will then appear in the list.

<img className="thumbnail" alt="VolumeGroupDashBoardCreated" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/04-storage/VolumeGroupDashBoardCreated.PNG" loading="lazy" />
