## Defining alerts, events, and tasks in Prism Central

Everything that happens in a cluster associated with Prism Central is recorded in the **events**.

When an anomaly occurs, such as excessive CPU usage on a virtual machine, **alerts** are triggered automatically.<br/>
Prism Central alerts are in addition to Prism Element alerts.

You can add custom alerts to increase sensitivity on an item in the cluster.<br/>
Alerts can be sent to recipients through e-mail.

Each action that a Prism Central user performs appears as a **task** and is listed with a *complete*, *in progress*, or *in error* status.

## Instructions

### Configuring SMTP Server in Prism Central

In order for **Prism Central** to send alerts, you must configure an SMTP server.

Click the <code className="action">Gear</code> icon in the top right of the **Prism Central** interface to configure it.

<img className="thumbnail" alt="Configure Prism Central SMTP Server 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/07-alert-management/ConfigurePrismCentralSmtp01.PNG" loading="lazy" />

In the right-hand menu, click <code className="action">SMTP Server</code>.

Enter the SMTP server sending settings and click <code className="action">Save</code>.

<img className="thumbnail" alt="Configure Prism Central SMTP Server 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/07-alert-management/ConfigurePrismCentralSmtp02.PNG" loading="lazy" />

### Managing alerts 

Open the main menu in the top left-hand corner.

Select <code className="action">Alerts</code> from the Activity menu.

<img className="thumbnail" alt="Display Alert 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/07-alert-management/DisplayAlert01.PNG" loading="lazy" />

The list of triggered alerts appears. Configure recipients by clicking <code className="action">Email Configuration</code>.

<img className="thumbnail" alt="Display Alert 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/07-alert-management/DisplayAlert02.PNG" loading="lazy" />

Enter recipient names in the "Email Recipients" input box and click <code className="action">Save</code>.

<img className="thumbnail" alt="Configure Alert Mail 01 " src="/images/hosted-private-cloud/nutanix-on-ovhcloud/07-alert-management/ConfigureAlertMail01.PNG" loading="lazy" />

#### Creating a custom alert

To create a custom alert with different trigger thresholds, click <code className="action">Alerts Policies</code> and select <code className="action">User Defined</code>. 

<img className="thumbnail" alt="Create Alert 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/07-alert-management/CreateAlert01.PNG" loading="lazy" />

Then click <code className="action">Create Alert Policy</code>.

On the left, select the settings you want to monitor, such as, in the example below, CPU usage on a single virtual machine.

Next, modify the Behavioral Anomaly settings by ticking <code className="action">Every time there is an anomaly, alert</code> and choosing <code className="action">Critical</code>.

Change the "Static Threshold" settings by ticking <code className="action">Alert Critical if</code> and choosing a threshold higher than 60%.

Click <code className="action">Save</code> to save the custom alert.

<img className="thumbnail" alt="Create Alert 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/07-alert-management/CreateAlert02.PNG" loading="lazy" />

The alert you have created will then appear in the list.

<img className="thumbnail" alt="Create Alert 03" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/07-alert-management/CreateAlert03.PNG" loading="lazy" />

#### Resolving an alarm

In **Prism Central**, when an alarm is triggered, a red circle appears in the top right next to a bell. This alert will disappear after 180 minutes if the threshold has returned to normal.

The trigger threshold may return to normal within 180 minutes. In this case, you can delete the alert manually.

To delete an alert manually, click the red numbered circle.

<img className="thumbnail" alt="Show triggered alarm 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/07-alert-management/ShowTriggeredAlarm01.PNG" loading="lazy" />

The raised alarm appears.

<img className="thumbnail" alt="Show triggered alarm 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/07-alert-management/ShowTriggeredAlarm02.PNG" loading="lazy" />

Select the alarm and click <code className="action">Resolve</code>.

<img className="thumbnail" alt="Resolv Alarm 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/07-alert-management/ResolvAlarm01.PNG" loading="lazy" />

The alarm is then resolved and no longer appears in the **Prism Central dashboard**.

<img className="thumbnail" alt="Resolv Alarm 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/07-alert-management/ResolvAlarm02.PNG" loading="lazy" />
