## Objective

You can use a DNS forwarder in NSX that centralises all DNS queries and redirects them to external DNS servers, which reduces network traffic. You can attach the DNS forwarder to the north-south gateway (ovh-T0-gw) or the east-west gateway (ovh-T1-gw), depending on your needs.

**Discover how to configure a DNS forwarder.**

## Requirements

- Being an administrative contact of your [Hosted Private Cloud infrastructure](https://www.ovhcloud.com/es-es/enterprise/products/hosted-private-cloud/) to receive login credentials
- A user account with access to the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.es/&ovhSubsidiary=es)
- You need to have **NSX** deployed with a segment configured in your NSX configuration. Use our guide on [segment management in NSX](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/) for more information.

## Instructions

We will create a DNS redirector and attach it to the north-south gateway (ovh-t0-gw), it will be usable on all segments of NSX.

### DNS forwarder configuration

Through the NSX interface go to the <code className="action">Networking</code> tab and click on <code className="action">DNS</code> on the left in the **IP Management** section. Then click <code className="action">ADD DNS SERVICE</code>.

<img className="thumbnail" alt="Configure DNS forwarder 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/01-configure-dns-forwarder01.png" loading="lazy" />

Enter this information :

- **Name** : Your service name, such as `dns-forwarder`.
- **Tier-0/Tier-1 Gateway** : Your North-South gateway `ovh-T0-gw`.
- **DNS Service IP** : a private IP address not used in your segments, such as `192.168.200.1`.

Next, click the <code className="action">three vertical dots</code> below **Default DNS Zone**.

<img className="thumbnail" alt="Configure DNS forwarder 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/01-configure-dns-forwarder02.png" loading="lazy" />

Click <code className="action">Add New Default Zone</code>.

<img className="thumbnail" alt="Configure DNS forwarder 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/01-configure-dns-forwarder03.png" loading="lazy" />

Fill in these values :

- **Name** : The name of the zone, such as `cdns.ovh.net`.
- **DNS Servers** : OVHcloud DNS server `213.186.33.99`.

Then click <code className="action">SAVE</code>.

<img className="thumbnail" alt="Configure DNS forwarder 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/01-configure-dns-forwarder04.png" loading="lazy" />

Click <code className="action">SAVE</code>.

<img className="thumbnail" alt="Configure DNS forwarder 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/01-configure-dns-forwarder05.png" loading="lazy" />

Your DNS forwarder is active and usable on all your overlay or VLAN segments connected to your north-south gateway (ovh-t0-gw).

<img className="thumbnail" alt="Configure DNS forwarder 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/01-configure-dns-forwarder06.png" loading="lazy" />

### Editing the DHCP server to use a DNS forwarder

If you have configured DHCP servers in NSX as described in our [Configuring DHCP](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/) guide, you have the option to modify the configuration to use the DNS forwarder in your DHCP configurations.

We will see how to modify the DNS server on the DHCP configuration of one of your segments.

Still from the <code className="action">Networking</code> tab, click <code className="action">Segments</code> on the left in the **Connectivity** section. 

Then click on the <code className="action">three vertical dots</code> next to your segment and choose <code className="action">Edit</code> from the menu.

<img className="thumbnail" alt="Modify DHCP overlay segment 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/02-modify-dhcp-overlay-segment01.png" loading="lazy" />

Click <code className="action">EDIT DHCP CONFIG</code>.

<img className="thumbnail" alt="Modify DHCP overlay segment 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/02-modify-dhcp-overlay-segment02.png" loading="lazy" />

Click the <code className="action">X</code> to the right of the existing DNS in the **DNS Servers** option to remove it from the configuration.

<img className="thumbnail" alt="Modify DHCP overlay segment 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/02-modify-dhcp-overlay-segment03.png" loading="lazy" />

Add your DNS redirector IP address in **DNS Servers** as <code className="action">192.168.200.1</code> and click <code className="action">APPLY</code>.

<img className="thumbnail" alt="Modify DHCP overlay segment 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/02-modify-dhcp-overlay-segment04.png" loading="lazy" />

Click <code className="action">SAVE</code>.

<img className="thumbnail" alt="Modify DHCP overlay segment 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/02-modify-dhcp-overlay-segment05.png" loading="lazy" />

Click <code className="action">CLOSE EDITING</code>.

<img className="thumbnail" alt="Modify DHCP overlay segment 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/02-modify-dhcp-overlay-segment06.png" loading="lazy" />

Your segment's DHCP settings now use the DNS forwarder you created earlier.
