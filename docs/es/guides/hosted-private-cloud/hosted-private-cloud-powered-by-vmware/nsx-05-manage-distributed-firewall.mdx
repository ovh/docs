## Objective

The distributed firewall feature in NSX allows filtering with all elements in your VMware cluster that are on Overlay or VLAN segments. It should be used normally on east-west connections (ovh-T1-gw), but it also works with elements of the VMware cluster that are connected on the north-south gateway (ovh-T0-gw). Filtering applies from the source (VM, segment, network, etc.).

To simplify the administration of NSX, it is possible to place tags on your elements (segments, virtual machines, roles, etc..) and create groups that contain the objects associated with the tags or IP address ranges (this solution should not be preferred).

**Learn how to manage the distributed firewall by creating a rule that blocks traffic between a virtual machine and all virtual machines in another segment.**

## Instructions

We will isolate communication between a virtual machine and all virtual machines in a segment bi-directionally by performing these operations :

- Create two tags, one on a virtual machine and one on a segment.
- Create two associated groups, one containing the first tag and the other the second.
- Create a policy in the distributed firewall that will contain two rules:
    - A rule that will forbid traffic from the first group to the second.
    - Another rule that will forbid traffic from the second group to the first.

### Creating tags

In the NSX interface, go to the <code className="action">Networking</code> tab and click <code className="action">Segments</code> to the left in **Connectivity**.

Then click on the <code className="action">three vertical dots</code> to the left of the segment you want to tag and choose <code className="action">Edit</code> from the menu.

To the right of **Tags**, enter <code className="action">ovsegment</code> instead of tag and click <code className="action">Add Item(s) ovsegment</code> below the input box.

<img className="thumbnail" alt="01 Create tag on segment 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/01-create-tag-on-segment02.png" loading="lazy" />

Enter <code className="action">ov1</code> instead of **Scope** and click <code className="action">Add Item(s) ov1</code> below the input box.

<img className="thumbnail" alt="01 Create tag on segment 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/01-create-tag-on-segment02.png" loading="lazy" />

Click the <code className="action">+</code> button to the left of your tag.

<img className="thumbnail" alt="01 Create tag on segment 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/01-create-tag-on-segment03.png" loading="lazy" />

The created tag is displayed in the bottom right of **Tags**, you can create more tags depending on your needs.

Click <code className="action">SAVE</code>.

<img className="thumbnail" alt="01 Create tag on segment 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/01-create-tag-on-segment04.png" loading="lazy" />

Click <code className="action">CLOSE EDITING</code> to complete the markup for your segment.

Then click on the <code className="action">three vertical dots</code> to the left of the virtual machine that you want to tag and choose <code className="action">Edit</code> from the menu.

<img className="thumbnail" alt="02 Create tag on vm 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/02-create-tag-on-vm02.png" loading="lazy" />

Click the <code className="action">+</code> button to the left of your tag.

### Add groups that contain tags

In the inventory, go to <code className="action">Groups</code> on the left and click <code className="action">ADD GROUP</code> to create a group.

Type <code className="action">g-segment01</code> below the **Name** column and click <code className="action">Set</code> under the **Compute Members** column.

- **Type** : `NSX Segment`.
- **Tags** : Equals `ovsegment`.

### Setting up a distributed firewall rule

We will now create a two-way blocking rule, on the distributed firewall, between the two created groups.

Go to the <code className="action">Security</code> tab, select <code className="action">Distributed Firewall</code> and click <code className="action">+ ADD POLICY</code>.

<img className="thumbnail" alt="06 Create distributed firewall rules 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/06-create-distributed-firewall-rules01.png" loading="lazy" />

Name your strategy <code className="action">Isolate vm and segment</code>.

<img className="thumbnail" alt="06 Create distributed firewall rules 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/06-create-distributed-firewall-rules02.png" loading="lazy" />

Click the <code className="action">three vertical dots</code> to the left of your policy and choose <code className="action">Add Rule</code> from the menu.

<img className="thumbnail" alt="06 Create distributed firewall rules 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/06-create-distributed-firewall-rules03.png" loading="lazy" />

Click the <code className="action">Pen</code> icon to the right of **Any** in the **Sources** column.

<img className="thumbnail" alt="06 Create distributed firewall rules 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/06-create-distributed-firewall-rules04.png" loading="lazy" />

Stay on the <code className="action">groups</code> tab, check the <code className="action">g-segment01</code> group and click <code className="action">APPLY</code>.

<img className="thumbnail" alt="06 Create distributed firewall rules 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/06-create-distributed-firewall-rules05.png" loading="lazy" />

<img className="thumbnail" alt="06 Create distributed firewall rules 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/06-create-distributed-firewall-rules06.png" loading="lazy" />

Select the <code className="action">g-vm</code> group and click <code className="action">APPLY</code>.

<img className="thumbnail" alt="06 Create distributed firewall rules 07" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/06-create-distributed-firewall-rules07.png" loading="lazy" />
