## Objective

**This guide details how to create or modify a global IAM policy and add a vSphere role**.

## Requirements

- An [OVHcloud account](/guides/account-and-service-management/account-information/ovhcloud-account-creation/).
- One or more Hosted Private Cloud products - VMware on OVHcloud linked to this account (Hosted Private Cloud powered by VMware, VMware Service Pack).
- IAM enabled for your Hosted Private Cloud service - VMware on OVHcloud. Follow the steps in the guide [IAM for VMware on OVHcloud - How to enable IAM](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-iam-activation/).

## Instructions

### Creating or editing a policy

Log in to your [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.es/&ovhSubsidiary=es). Click on your name in the top right-hand corner of the OVHcloud Control Panel, then click on your initials to go to the <code className="action">My account</code> section.<br/>
Under <code className="action">My account</code>, click `Identity and Access Management (IAM)`&#123;.action].

<img className="thumbnail" alt="OVHCLOUD IAM" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-iam-role-policy/iam_role_policy_9.png" loading="lazy" />

Click <code className="action">Create a Policy</code>.<br/>
To modify a policy, click the <code className="action">...</code> button to the right of the policy concerned, then <code className="action">Modify policy</code>.

<img className="thumbnail" alt="IAM POLICY" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-iam-role-policy/iam_role_policy_10.png" loading="lazy" />

Enter the requested settings:

- **Policy name**: Choose a name.
- **Description**: Enter a description for your policy.
- **Product types**: Hosted private cloud powered by VMware / VMware Service Pack.
- **Resources**: Add the resources concerned by your policy (**pcc-XX-XX-XX-XX/servicepack**, **pcc-XX-XX-XX-XX**, etc.)
- **Actions**: This is where you add your role (see below).

#### Adding an IAM role to a global policy

When enabling IAM in vSphere, two roles are added by default (`iam-admin`, `iam-auditor`).

Copy the roles from the code section below, paste them into the field labeled "Actions added manually" under the “Actions” section, then click the <code className="action">Add +</code> button.

```bash
pccVMware:vSphere:assumeRole?iam-admin
pccVMware:vSphere:assumeRole?iam-auditor
```

If you have created an additional IAM role (after following the steps in the guide “[IAM for VMware on OVHcloud - How to create an IAM vSphere role](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-iam-role/)”), you can also add it by copying the code below and adapting it to your role:

```bash
pccVMware:vSphere:assumeRole?{role_name}
```

<img className="thumbnail" alt="IAM ACTION ADD" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-iam-role-policy/iam_role_policy_11.png" loading="lazy" />

Be sure to click the <code className="action">Add +</code> button to add the action.

Finally, click <code className="action">Create policy</code> (or <code className="action">Modify policy</code> if applicable).
