## Objective

Within your OVHcloud environment, you can add a new dedicated host in just a few minutes.

**Learn how to add compute capabilities to your infrastructure.**

## Requirements

- Being an administrative contact of your [Hosted Private Cloud infrastructure](https://www.ovhcloud.com/es-es/enterprise/products/hosted-private-cloud/) to receive login credentials
- A user account with access to vSphere (created in the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.es/&ovhSubsidiary=es))

## Instructions

:::warning
Adding resources through vSphere adds them as hourly resources for billing purposes. If you wish to switch them to monthly resources, it can be changed in the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.es/&ovhSubsidiary=es).
For more info on this, check out our [Introduction to the Hosted Private Cloud Control Panel](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/manager-ovh-private-cloud/)

:::


In the vSphere interface menu, go to the <code className="action">Hosts and Clusters</code> dashboard.

<img className="thumbnail" alt="Menu" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-add-host/en01dash.png" loading="lazy" />

The <code className="action">Configure</code> tab gives you access to the OVHcloud plugin.<br/>
in the <code className="action">Add Host</code> menu, choose the type of host you would like to add and click <code className="action">Next</code>.

<img className="thumbnail" alt="Choose" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-add-host/en02choose.png" loading="lazy" />

Verify your order and confirm by clicking <code className="action">Next</code>.

<img className="thumbnail" alt="Confirm" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-add-host/en03validate.png" loading="lazy" />

Your order is then confirmed. The progression of the delivery is showing with an estimated time of availability.

<img className="thumbnail" alt="Delivery" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-add-host/en04deliver.png" loading="lazy" />

Once done, a new host is showing in your datacenter and is ready for use.
