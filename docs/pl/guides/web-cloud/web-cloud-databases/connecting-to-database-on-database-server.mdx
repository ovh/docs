## Wprowadzenie

Zawartość bazy danych można przeglądać za pomocą interfejsu. Istnieje kilka sposobów połączenia się z bazą danych.

**Dowiedz się, jak połączyć się z bazą danych na serwerze baz danych.**

## Wymagania początkowe

- Posiadanie [instancji Web Cloud Databases](https://www.ovhcloud.com/pl/web-cloud/databases/) (zawartej w ofercie [hostingu www Performance](https://www.ovhcloud.com/pl/web-hosting/)).

## W praktyce

:::info
Rozwiązania [Web Cloud Databases](https://www.ovhcloud.com/pl/web-cloud/databases/) nie dają dostępu do samego systemu zarządzania bazami danych, lecz do baz danych na nim hostowanych.

- Nie ma dostępu super użytkownika "root".
- Ogólne polecenia SQL działają normalnie, a oprogramowanie takie jak HeidiSQL, SQuirreL SQL lub Adminer jest w pełni kompatybilne.

:::


### Połączenie z bazą danych MySQL lub MariaDB

:::info
Ponieważ MariaDB jest pochodną MySQL, polecenia są dokładnie takie same dla obu typów baz danych.

:::


#### Połączenie przez phpMyAdmin OVHcloud

Kliknij poniższe karty, aby wyświetlić kolejne **4** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę [Web Cloud Databases](https://manager.eu.ovhcloud.com/#/web/web/private_database), następnie wybierz odpowiednie rozwiązanie.
    
    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Pobierz następujące informacje dotyczące połączenia:
    
    - **Serwer (nazwa hosta) i port:** widoczne w zakładce <code className="action">Informacje ogólne</code>, sekcja "Informacje na temat połączenia".
    - **Nazwa użytkownika:** widoczna w zakładce <code className="action">Użytkownicy i uprawnienia</code>.
    - **Hasło:** hasło powiązane z użytkownikiem. Jeśli nie pamiętasz hasła, przejdź do zakładki <code className="action">Użytkownicy i uprawnienia</code>, kliknij <code className="action">...</code> po prawej stronie danego użytkownika, a następnie <code className="action">Zmień hasło</code>.
    
    :::warning
    Jeśli zmienisz hasło użytkownika bazy danych, wszystkie aplikacje/strony internetowe korzystające z tej bazy danych muszą zostać odpowiednio zaktualizowane.

    :::

  </Tab>
  <Tab label="Krok 3">
    W zakładce <code className="action">Informacje ogólne</code> odszukaj sekcję **Administrowanie bazą danych** i kliknij link phpMyAdmin pod napisem **Panel użytkownika**.
    
    <img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/general-information/database-administration.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 4">
    Na stronie logowania phpMyAdmin wprowadź informacje pobrane w kroku 2:
    
    <img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-login-web-cloud-db.png" loading="lazy" />
    
    - **Serwer:** wpisz *nazwę hosta*, a następnie *numer portu*, oddzielone znakiem "**:**" lub "**spacją**". Na przykład: **aaXXXXX-XXX.eu.clouddb.ovh.net:12345**.
    - **Użytkownik:** wpisz *nazwę użytkownika*.
    - **Hasło:** wpisz *hasło*.
  </Tab>
</Tabs>


Jeśli połączenie zakończy się pomyślnie, wyświetli się następująca strona.

<img className="thumbnail" alt="web-cloud-databases" src="/images/assets/screens/other/web-tools/phpmyadmin/pma-main-page-web-cloud-db.png" loading="lazy" />

:::warning
**W przypadku błędu:**

- Błąd #1045 oznacza, że dane logowania są nieprawidłowe. Sprawdź nazwę użytkownika i/lub hasło.
- Błąd #2005 oznacza, że należy sprawdzić nazwę serwera oraz czy działa on prawidłowo.

:::


#### Połączenie z bazą danych poza Panelem klienta

:::warning
Jeśli korzystasz z rozwiązania "Web Cloud Databases"/"Prywatny SQL", pamiętaj, aby autoryzować swój adres IP, korzystając z przewodnika dotyczącego [konfiguracji serwera bazy danych](/guides/web-cloud/web-cloud-databases/configure-database-server#gerer-vos-acces/).

:::


Kliknij poniższe karty, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę [Web Cloud Databases](https://manager.eu.ovhcloud.com/#/web/web/private_database), następnie wybierz odpowiednie rozwiązanie.
    
    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    Pobierz następujące informacje dotyczące połączenia:
    
    - **Serwer (nazwa hosta):** widoczny w zakładce <code className="action">Informacje ogólne</code>, sekcja **"Administrowanie bazą danych"**, pole "Nazwa hosta" w części **SQL**.
    - **Port:** widoczny w tym samym miejscu, pole "Port" w części **SQL**.
    - **Nazwa użytkownika:** widoczna w zakładce <code className="action">Użytkownicy i uprawnienia</code>.
    - **Hasło:** hasło powiązane z danym użytkownikiem.
    - **Nazwa bazy danych:** widoczna w zakładce <code className="action">Bazy danych</code>.
  </Tab>
</Tabs>


**Kliknij wybraną metodę połączenia, aby wyświetlić jej zawartość.**

<details>

<summary>Połączenie z poziomu wiersza poleceń</summary>


```bash
mysql --host=server --user=user --port=port --password=password database_name
```

</details>


<details>

<summary>Połączenie przez skrypt PHP</summary>


```php
1. <?php
2. $db = new PDO('mysql:host=host;port=port;dbname=dbname', 'username', 'password');
3. ?>
```

</details>


<details>

<summary>Połączenie przez oprogramowanie (SQuirreL SQL)</summary>


:::info
W naszym przykładzie wykorzystujemy oprogramowanie open source SQuirreL, ale inne interfejsy, takie jak HeidiSQL lub Adminer, są w pełni kompatybilne.

:::


- Uruchom SQuirreL SQL i kliknij <code className="action">Aliases</code>, a następnie <code className="action">+</code>

<img className="thumbnail" alt="launch SQuirreL SQL" src="/images/assets/screens/other/web-tools/squirrel/aliases.png" loading="lazy" />

- Wypełnij poniższe pola i zatwierdź przyciskiem <code className="action">OK</code>:
    - **Name**: Wybierz nazwę
    - **Driver**: Wybierz "MySQL Driver"
    - **URL**: Podaj adres serwera i port w formacie jdbc:mysql://server:port
    - **User Name**: Wpisz nazwę użytkownika
    - **Password**: Wpisz hasło

<img className="thumbnail" alt="config connection" src="/images/assets/screens/other/web-tools/squirrel/add-alias.png" loading="lazy" />

- Zatwierdź ponownie za pomocą przycisku <code className="action">Połącz</code>

<img className="thumbnail" alt="valid connection" src="/images/assets/screens/other/web-tools/squirrel/connect-to-mysql.png" loading="lazy" />

Jesteś teraz połączony z bazą danych:

<img className="thumbnail" alt="config connection" src="/images/assets/screens/other/web-tools/squirrel/general-dashboard.png" loading="lazy" />

</details>


<details>

<summary>Połączenie przez phpMyAdmin</summary>


Możesz skorzystać z własnego interfejsu phpMyAdmin, aby przeglądać zawartość bazy danych. W tym celu zainstaluj phpMyAdmin na swoim własnym serwerze lub hostingu. Podczas instalacji upewnij się, że informacje dotyczące serwera baz danych i wybranej bazy danych są prawidłowo skonfigurowane, aby phpMyAdmin mógł się z nim połączyć.

</details>
