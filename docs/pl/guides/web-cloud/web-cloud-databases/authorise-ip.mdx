## Wprowadzenie

Rozwiązania [Web Cloud Databases](https://www.ovhcloud.com/pl/web-cloud/databases/) mogą być używane z usługami OVHcloud lub zewnętrznymi wobec OVHcloud.

Domyślnie i ze względów bezpieczeństwa:

- Dostęp do zawartości baz danych jest możliwy tylko dla adresów IP powiązanych z naszą infrastrukturą hostingu.
- Dostęp do logów rozwiązania nie jest ograniczony na podstawie adresów IP. Pozwala to na przykład na dostęp do danych z komputera.

Chcesz zmienić te uprawnienia/ograniczenia?

**Dowiedz się, jak autoryzować jeden lub więcej adresów IP, aby uzyskać dostęp do rozwiązania Web Cloud Databases.**

## Wymagania początkowe

- Posiadanie rozwiązania [Web Cloud Databases](https://www.ovhcloud.com/pl/web-cloud/databases/).
- Sprawdź adres IP (lub zakres adresów IP), który chcesz autoryzować w Twoim rozwiązaniu.

## W praktyce

### Autoryzacja adresu IP lub zakresu adresów IP

:::info
Przypominamy, że jeśli właśnie aktywowałeś rozwiązanie [Web Cloud Databases](https://www.ovhcloud.com/pl/web-cloud/databases/) i chcesz z niego korzystać w ramach oferty [hostingu OVHcloud](https://www.ovhcloud.com/pl/web-hosting/), adresy IP tych ofert są już domyślnie autoryzowane.

:::


Kliknij poniższe zakładki, aby wyświetlić kolejne **4** kroki.

<Tabs>
  <Tab label="Etap 1">
    Przejdź na stronę [Web Cloud Databases](https://manager.eu.ovhcloud.com/#/web/web/private_database), następnie wybierz odpowiednie rozwiązanie.
    
    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 2">
    Na stronie, która się wyświetli kliknij zakładkę <code className="action">Autoryzowane IP</code>.
    
    <img className="thumbnail" alt="Authorised IPs" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/authorised-ips.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 3">
    Na stronie, która się wyświetli kliknij przycisk <code className="action">Dodaj adres IP / maskę</code> znajdujący się nad tabelą.
    
    <img className="thumbnail" alt="Authorised IPs interface" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/authorized-ips/tab-0000-sftp-hosting-enabled.png" loading="lazy" />
    
    :::tip[Success]
    Jeśli chcesz zmienić już autoryzowany adres IP lub zakres adresów IP, kliknij bezpośrednio w tabeli przycisk <code className="action">...</code> znajdujący się po prawej stronie wiersza odpowiadającego adresowi IP lub zakresowi adresów IP do zmodyfikowania, a następnie kliknij <code className="action">Edytuj białą listę</code>.

    :::

  </Tab>
  <Tab label="Etap 4">
    W oknie, które się otworzy, wypełnij kilka pól:
    
    <img className="thumbnail" alt="Add an IP address or mask" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/authorized-ips/add-an-ip-address-mask-confirmation.png" loading="lazy" />
    
    - <code className="action">IP / maska *</code>: Tutaj wpisz adres IP (na przykład: `203.0.113.44`) lub zakres adresów IP (na przykład: `203.0.113.0/24` reprezentujący wszystkie adresy IP od `203.0.113.0` do `203.0.113.255`), które chcesz autoryzować w rozwiązaniu Web Cloud Databases.
    - <code className="action">Opis</code> (opcjonalnie): Możesz na przykład dodać informacje o roli adresu IP lub zakresu adresów IP.
    - <code className="action">Bazy danych</code>: Zaznacz to pole, aby adres IP lub zakres adresów IP miał prawo dostępu do baz danych znajdujących się w Twoim rozwiązaniu Web Cloud Databases.
    - <code className="action">SFTP</code>: Zaznacz to pole, aby adres IP lub zakres adresów IP miał dostęp do logów Twojego rozwiązania Web Cloud Databases.
    
    :::warning
    Odradzamy zaznaczenie pola <code className="action">Bazy danych</code>, aby zezwolić zakresowi adresów IP `0.0.0.0/0` na dostęp do Twoich baz danych.
    
    Umożliwiłoby to autoryzację dostępu do Twoich baz danych dla wszystkich istniejących adresów IPv4.

    :::

    
    Po wpisaniu informacji kliknij przycisk <code className="action">Zatwierdź</code>.
  </Tab>
</Tabs>


## Szczególne przypadki

**Kliknij na poniższe przykłady, aby wyświetlić odpowiednie informacje.**

<details>

<summary>Zakres adresów IP 0.0.0.0/0</summary>


Podczas aktywacji usługi Web Cloud Databases linia dla zakresu adresów IP `0.0.0.0/0` jest już domyślnie obecna, aby zezwolić na dostęp **SFTP** do rozwiązania.

Upoważnienie to zostało wprowadzone dobrowolnie, abyś mógł uzyskać dostęp do plików logów Twojego rozwiązania Web Cloud Databases bez konieczności deklarowania adresu IP punktu dostępu do Internetu.

Adres IP może się regularnie zmieniać w zależności od dostawców usług internetowych.

Ponadto zalecamy, aby **nie** zmienić tego uprawnienia i nie zezwalać na dostęp do baz danych znajdujących się w rozwiązaniu Web Cloud Databases.

Umożliwiłoby to autoryzację dostępu do Twoich baz danych dla wszystkich istniejących adresów IPv4, co stanowi zagrożenie dla bezpieczeństwa danych.

</details>


<details>

<summary>Autoryzacja dostępu do hostingu WWW OVHcloud</summary>


Podczas aktywacji rozwiązania Web Cloud Databases autoryzacja dostępu do hostingu WWW OVHcloud jest aktywowana domyślnie.

Jeśli chcesz wyłączyć to uprawnienie, ponieważ nie korzystasz z hostingu WWW z rozwiązaniem Web Cloud Databases, kliknij poniższe zakładki, aby wyświetlić kolejne **3** kroki.

<Tabs>
  <Tab label="Etap 1">

    <img className="thumbnail" alt="Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png" loading="lazy" />
  </Tab>
  <Tab label="Etap 2">
    Na stronie, która się wyświetli kliknij zakładkę <code className="action">Autoryzowane IP</code>.
    
    <img className="thumbnail" alt="Authorised IPs" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/authorised-ips.png" loading="lazy" />
  </Tab>

    Na stronie, która się wyświetli, usuń zaznaczenie w kratce przed wzmianką <code className="action">Zezwól hostingowi OVHcloud na dostęp do bazy danych</code>.
    
    <img className="thumbnail" alt="Authorised IPs interface" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/authorized-ips/tab-0000-sftp-hosting-enabled.png" loading="lazy" />
