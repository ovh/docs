## Wprowadzenie

Nie pamiętasz nazwy swojej [oferty hostingu](https://www.ovhcloud.com/pl/web-hosting/)?
Chcesz sprawdzić jej szczegóły lub porównać ją z inną ofertą?

W trakcie korzystania z usług może się zdarzyć, że będziesz potrzebował nazwy swojej oferty hostingu.

**Dowiedz się, jak zidentyfikować typ oferty hostingu, którą aktualnie posiadasz w Panelu klienta OVHcloud.**

## Wymagania początkowe

- Posiadanie [oferty hostingu](https://www.ovhcloud.com/pl/web-hosting/).


{/* CP-NAV-START:web-hosting */}
---

### Dostęp do Panelu klienta OVHcloud

- **Link bezpośredni:** [Hosting plans](https://manager.eu.ovhcloud.com/#/web/hosting)
- **Ścieżka nawigacji:** <code className="action">Web Cloud</code> > <code className="action">Hosting</code> > Wybierz hosting WWW

---

## W praktyce

Kliknij poniższe zakładki, aby wyświetlić kolejne **2** kroki.

<Tabs>
  <Tab label="Krok 1">
    Przejdź na stronę [Hosting plans](https://manager.eu.ovhcloud.com/#/web/hosting), następnie wybierz odpowiedni hosting.
    
    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Krok 2">
    W sekcji **Abonament** znajdziesz wpis **Pakiet**.
    
    <img className="thumbnail" alt="Plan" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-plan-pro.png" loading="lazy" />

Pod tą nazwą znajdziesz nazwę oferty hostingu (np. Perso, Pro, Performance, itd.).
  </Tab>
</Tabs>
