:::warning
OVHcloud oddaje do Twojej dyspozycji usługi, których konfiguracja, zarządzanie i odpowiedzialność spoczywa na Ciebie. W związku z tym należy zapewnić ich prawidłowe funkcjonowanie.

Oddajemy w Twojej ręce niniejszy przewodnik, którego celem jest pomoc w jak najlepszym wykonywaniu bieżących zadań. ## W praktyce

Aby usunąć tę anomalię, należy:

1. określenie hostingu, do którego jest podłączona Twoja domena, w celu przeprowadzenia interwencji na właściwym serwerze;
2. tworzenie, aktywacja lub odnawianie [certyfikatu SSL](/guides/web-cloud/web-hosting/ssl-on-webhosting/) dla Twojej domeny na wybranym hostingu.

### 1: Sprawdź hosting przypisany do Twojej domeny

#### Sprawdź adres IP hostingu

[Poprzednie](#objective) komunikaty błędów niekoniecznie oznaczają, że Twoja strona WWW jest zainstalowana na jednym z naszych [pakietów Web Cloud](https://www.ovhcloud.com/pl/web-hosting/). Należy zatem sprawdzić adres IP serwera, do którego jest podłączony Twoja [nazwa domeny](https://www.ovhcloud.com/pl/domains/).

Aby odnaleźć adres IP Twojego [hostingu OVHcloud](https://www.ovhcloud.com/pl/web-hosting/), kliknij poniższe zakładki, aby wyświetlić kolejne **2** kroki.

#### Sprawdź adres IP w strefie DNS

Teraz sprawdź, czy adres IP podany w [Strefa DNS](/guides/web-cloud/domains/dns-zone-edit/) odpowiada adresowi Twojej [hostingu Web Cloud](https://www.ovhcloud.com/pl/web-hosting/).

Zaloguj się do [Panelu klienta OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pl/&ovhSubsidiary=pl) i przejdź do sekcji <code className="action">Web Cloud</code>. Kliknij menu <code className="action">Strefy DNS</code>, następnie wybierz odpowiednią domenę.

Zapisz docelowy wpis `A` dla Twojej domeny:

### 2: Sprawdź certyfikat SSL na Twoim hostingu <a name="step2"></a>

W zakładce <code className="action">Informacje ogólne</code> Twojego hostingu OVHcloud sprawdź sekcję `Certyfikat SSL`:

<img className="thumbnail" alt="ssl-certificate-in-general-tab" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/no-ssl-certificate.png" loading="lazy" />

#### Scenariusz 1: Twój hosting nie zawiera certyfikatu SSL

Włącz [certyfikat SSL](https://www.ovhcloud.com/pl/web-hosting/options/ssl/) na Twoim hostingu postępując zgodnie z instrukcjami zawartymi w tym [przewodniku](/guides/web-cloud/web-hosting/ssl-on-webhosting/).

#### Scenariusz 2: certyfikat SSL nie działa

Jeśli wygenerowałeś **certyfikat SSL "Let's Encrypt"**, aktywuj opcję SSL dla swojego hostingu, postępując zgodnie z instrukcjami w [tym przewodniku](/guides/web-cloud/web-hosting/ssl-on-webhosting/).

Jeśli posiadasz importowany **certyfikat SSL** i certyfikat ten nie działa, skontaktuj się z dostawcą.

Jeśli zamówiłeś jeden z płatnych **certyfikatów SSL** od naszego partnera [SECTIGO](https://sectigo.com/), sprawdź, czy otrzymałeś wiadomość e-mail z propozycją odnowienia certyfikatu.
<br/>W razie potrzeby skontaktuj się z [pomocą SECTIGO](https://sectigo.com/support) w tej sprawie.
