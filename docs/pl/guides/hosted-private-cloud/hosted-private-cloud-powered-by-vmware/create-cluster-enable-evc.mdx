## Objective

You can set up multiple clusters in your environment to segment your activities.<br/>
Learn how to create them and configure their functionalities (DRS, HA & EVC).

**This guide offers a step by step study case to achieve the objective.**

## Requirements

- Being an administrative contact of your [Hosted Private Cloud infrastructure](https://www.ovhcloud.com/pl/enterprise/products/hosted-private-cloud/) to receive login credentials
- A user account with access to vSphere (created in the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pl/&ovhSubsidiary=pl))

## Instructions

### Cluster creation

In the vSphere interface menu, go to the <code className="action">Hosts and Clusters</code> dashboard.

<img className="thumbnail" alt="Menu" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-cluster-enable-evc/en01dash.png" loading="lazy" />

Right click your Datacenter.<br/>
Select <code className="action">New Cluster</code>.

<img className="thumbnail" alt="New Cluster" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-cluster-enable-evc/en02newcluster.png" loading="lazy" />

In the pop-up window, name your cluster and select the relevant options you want set.<br/>
Click <code className="action">OK</code> when done.

<img className="thumbnail" alt="Cluster" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-cluster-enable-evc/en03cluster.png" loading="lazy" />

:::warning
vSAN requires vSAN compatible hosts. Find more details [here](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/manager-ovh-private-cloud/) on how to order them if needed.

:::


### DRS

DRS spreads the compute load accross your hosts.<br/>
If you activated the option, it is set on "Fully Automated" by default.

Select your cluster. In the <code className="action">Configure</code> tab, select <code className="action">vSphere DRS</code> and click <code className="action">Edit</code>.

<img className="thumbnail" alt="DRS" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-cluster-enable-evc/en04drsedit.png" loading="lazy" />

Three options are available to you:

- Manual Mode. DRS generates both power-on placement recommendations, and migration recommendations for virtual machines. Recommendations need to be manually applied or ignored.
- Partially Automated. DRS automatically places virtual machines onto hosts at VM power-on. Migration recommendations need to be manually applied or ignored.
- Fully Automated. DRS automatically places virtual machines onto hosts at VM power-on, and virtual machines are automatically migrated from one host to another to optimize resource utilization.

Automated modes also allow to set the sensitivity of the service, from the most conservative to the most aggressive threshold.<br/>
Click <code className="action">OK</code> when done.

<img className="thumbnail" alt="DRS" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-cluster-enable-evc/en05drs.png" loading="lazy" />

### HA

High Availability allows for redundancy so a failing host will not impact the services running in your VMs.<br/>
If you activated the option, it is set on its default settings.

To modify them, select your cluster. In the <code className="action">Configure</code> tab, select <code className="action">vSphere HA</code> and click <code className="action">Edit</code>.

<img className="thumbnail" alt="HA" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-cluster-enable-evc/en06haedit.png" loading="lazy" />

The response types for the different host failures can be custom set to your needs.<br/>
Click <code className="action">OK</code> when done.

<img className="thumbnail" alt="HA" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-cluster-enable-evc/en07ha.png" loading="lazy" />

### EVC

EVC (Enhanced vMotion Compatibility) allows for migration of live VMs between hosts.

Prior to activating the functionality, check your hosts summary pages to determine their types.

<img className="thumbnail" alt="EVC" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-cluster-enable-evc/en10host.png" loading="lazy" />

Select your cluster. In the <code className="action">Configure</code> tab, select <code className="action">VMware EVC</code> and click <code className="action">Edit</code>.

<img className="thumbnail" alt="EVC" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-cluster-enable-evc/en08EVCedit.png" loading="lazy" />

Enable EVC for the type of CPUs your hosts hold.<br/>
Downward compatibility is assured. To help you verify the settings are working, you will see a compatibility validation at the bottom of the window.<br/>
Click <code className="action">OK</code> when done.

<img className="thumbnail" alt="EVC" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-cluster-enable-evc/en09EVC.png" loading="lazy" />

:::warning
EVC activation can only happen on a cluster with no active VM running. Make sure to turn off or evacuate all VMs before doing it. 

:::
