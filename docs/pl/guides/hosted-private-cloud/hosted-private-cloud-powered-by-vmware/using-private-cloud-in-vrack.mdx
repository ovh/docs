## Wprowadzenie

vRack umożliwia podłączenie różnych usług cloud OVHcloud w ramach jednej lub kilku zabezpieczonych prywatnych sieci (VLAN).

**Niniejszy przewodnik wyjaśnia, jak go uruchomić**

## Wymagania początkowe

- Posiadanie usługi [vRack](https://www.ovhcloud.com/pl/network/vrack/) na Twoim koncie lub zamówienie usługi.
- Posiadanie statusu kontaktu administratora infrastruktury [Hosted Private Cloud](https://www.ovhcloud.com/pl/enterprise/products/hosted-private-cloud/), aby otrzymywać dane do logowania.
- Posiadanie aktywnego identyfikatora użytkownika [utworzonego w Panelu klienta OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pl/&ovhSubsidiary=pl).

## W praktyce

### Panel klienta

Podczas dostarczania usługi [Hosted Private Cloud](https://www.ovhcloud.com/pl/enterprise/products/hosted-private-cloud/) część *datacenter* jest już w sieci vRack. Aby uzyskać dostęp do sekcji vRack,
przejdź do sekcji <code className="action">Bare Metal Cloud</code>, kliknij <code className="action">Network</code>, następnie kliknij <code className="action">vRack</code>. Wybierz vRack z listy, aby wyświetlić zawartość.

<img className="thumbnail" alt="Centrum danych" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/using-private-cloud-in-vrack/vRackDatacenter.PNG" loading="lazy" />

Możesz przenieść *centrum danych* usługi Hosted Private Cloud do innego rozwiązania vRack klikając na przycisk <code className="action">Przenieś</code>

### Klient vSphere

W panelu klienta vSphere możesz odnaleźć kompatybilne sieci *VLANs* vRack w rozproszonym wirtualnym switchu (vds), który znajduje się w katalogu **vrack**.

:::tip[Success]
OVHcloud dostarcza domyślnie infrastrukturę z 11 sieciami VLAN (VLAN10-VLAN20).

:::


<img className="thumbnail" alt="vlan" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/using-private-cloud-in-vrack/vRackVsphere.png" loading="lazy" />

Możesz zmienić lub utworzyć nowe parametry, postępując zgodnie z instrukcjami dotyczącymi [tworzenia sieci VLAN](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/creation-vlan/).

Następnie będziesz mógł przypisać te *grupy* serwerów do interfejsów sieciowych Twoich wirtualnych maszyn.
