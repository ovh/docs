## Wprowadzenie

Oferta Public Cloud Archive to rozwiązanie do przechowywania danych bez ograniczeń. Fakturowanie jest proste i dostosowane do Twoich potrzeb. Istnieje wiele rodzajów kontenerów obiektów:

- w przypadku hostingu statycznego (statyczna strona internetowa);
- dla hostingu prywatnego (Przykład: przechowywanie danych osobowych);
- do hostingu publicznego (do przechowywania wszystkiego, co jest dostępne publicznie);
- do archiwizacji danych.

Pierwszy etap polega na utworzeniu kontenera, który gromadzi Twoje pliki. 

**Niniejszy przewodnik wyjaśnia, jak utworzyć kontener w Panelu klienta OVHcloud.**

## W praktyce

### Utworzenie kontenera Public Cloud Archive w Panelu klienta OVHcloud

Kliknij <code className="action">Cloud Archive</code> na pasku nawigacji po lewej stronie, w sekcji "Storage".
W przypadku pierwszego kontenera:

![pca dashboard](/images/storage-and-backup/object-storage/pca-create-container/create-container-20211006094158312.png)

Jeśli już utworzyłeś jeden/kilka kontenerów:

![pca dashboard](/images/storage-and-backup/object-storage/pca-create-container/create-container-20211006094851682.png)

Wybierz region kontenera i kliknij <code className="action">Dalej</code>:

![select a region](/images/storage-and-backup/object-storage/pca-create-container/create-container-20211006094448923.png)

Nazwij kontener i kliknij na <code className="action">Dodaj kontener</code>:

:::warning
Jeśli chcesz przypisać kontener do domeny, nazwa kontenera nie może zawierać następujących znaków:

- [ . ]
- [ _ ]
- nie wolno używać wielkich liter.

Aby uzyskać więcej informacji, zapoznaj się z naszym przewodnikiem "[Powiązanie kontenera z nazwą domeny](/guides/storage-and-backup/object-storage/pcs-link-domain/)".

:::


![kontener name](/images/storage-and-backup/object-storage/pca-create-container/create-container-20211006094550334.png)

Kontener został utworzony:

![kontener created](/images/storage-and-backup/object-storage/pca-create-container/create-container-20211006094630754.png)
