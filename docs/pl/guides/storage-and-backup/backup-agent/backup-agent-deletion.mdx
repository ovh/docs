## W praktyce

### Usunięcie agenta

:::info
**Zachowanie w zależności od użycia agenta:**

- **Jeśli agent nie był używany do przesyłania danych** : Można go usunąć natychmiast. Najpierw zostanie wyłączony, a następnie usunięty.
- **Jeśli dane zostały przesłane** : Zastosowana zostanie 14-dniowa zawiesina agenta w stanie "Wyłączony", pozwalając na usunięcie danych niemutowalnych.

:::


:::warning
Po zawieszeniu agenta nie możesz już utworzyć nowego agenta na tym samym serwerze. Musisz poczekać, aż pierwszy agent zostanie usunięty.

:::


Przejdź do sekcji <code className="action">Agenci</code> i kliknij przycisk usuwania dla odpowiedniego agenta.

Potwierdź usunięcie agenta w oknie, które się pojawi.

<img className="thumbnail" alt="Backup Agent Usuwanie agenta" src="/images/storage-and-backup/backup-agent/backup-agent-deletion/01-backup-agent-delete-agent.png" loading="lazy" />

### Usunięcie skarbonek

:::warning
Skarbonkę nie można usunąć, jeśli zawiera dane. Jeśli chcesz usunąć skarbonkę, musisz [skontaktować się z obsługą](https://help.ovhcloud.com/csm?id=csm_get_help), która przeprowadzi z Tobą sprawdzenia przed uruchomieniem usunięcia.

:::


Przejdź do sekcji <code className="action">Skarbonki</code> i kliknij przycisk usuwania dla odpowiedniej skarbonki.

Potwierdź usunięcie w oknie, które się pojawi.

<img className="thumbnail" alt="Backup Agent Usuwanie skarbonki" src="/images/storage-and-backup/backup-agent/backup-agent-deletion/01-backup-agent-delete-vault.png" loading="lazy" />

### Usunięcie dzierżawcy

:::warning
Obecnie dzierżawcę nie można usunąć samodzielnie. Jeśli chcesz usunąć dzierżawcę, musisz [skontaktować się z obsługą](https://help.ovhcloud.com/csm?id=csm_get_help). Przetworzymy Twoją prośbę.

:::


Wybierz swojego dzierżawcę i kliknij przycisk usuwania.

Potwierdź usunięcie w oknie, które się pojawi.

<img className="thumbnail" alt="Backup Agent Usuwanie dzierżawcy" src="/images/storage-and-backup/backup-agent/backup-agent-deletion/01-backup-agent-delete-tenant.png" loading="lazy" />
