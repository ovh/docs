## Wprowadzenie

Blok IP umożliwia udostępnianie witryn w Internecie. 

**Niniejszy przewodnik wyjaśnia, jak zamawiać, dodawać i przenosić blok IP powiązany z Twoją usługą Managed Bare Metal.**

## Wymagania początkowe

* Dostęp do [Panelu klienta OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pl/&ovhSubsidiary=pl).
* Posiadanie [infrastruktury Managed Bare Metal](https://www.ovhcloud.com/pl/managed-bare-metal/) na koncie OVHcloud.

## W praktyce

### Zamówienie bloku IP

Aby zamówić dodatkowy blok IP dla Twojej usługi **Managed Bare Metal**, przejdź do Panelu klienta OVHcloud. W sekcji `Bare Metal Cloud` kliknij rubrykę `IP` w lewej kolumnie, a następnie wybierz opcję <code className="action">Zamów dodatkowe IP</code>. Teraz wybierz Twoją usługę **Managed Bare Metal** w rozwijanym menu, aby móc przejść do następnego etapu.

Utworzenie bloku IP wymaga wypełnienia następujących pól

- Wielkość bloku IP (od /28 do /24)

:::info
Dla przypomnienia, oto tabela podsumowująca liczbę IP obecnych w bloku i liczbę adresów IP do wykorzystania.

:::


|Wielkość bloku|IP w bloku|IP do wykorzystania w OVHcloud|
|:---:|:---:|:---:|
|28|16|11|
|27|32|27|
|26|64|59|
|25|128|123|
|24|256|251|

:::info
Zapoznaj się z naszym przewodnikiem dotyczącym [wtyczki OVHcloud Network](/guides/bare-metal-cloud/managed-bare-metal/plugin-ovh-network/), aby dowiedzieć się, jakie IP zarezerwowano dla Twojego bloku oraz jak są wykorzystywane.

:::


- Kraj bloku IP, ważny w niektórych przypadkach dla pozycjonowania Twoich witryn (strona internetowa skierowana do Polaków będzie lepiej pozycjonowana, jeśli ma polski adres IP).
- Nazwa sieci (informacja widoczna w bazie WHOIS bloku IP).
- Szacowana liczba klientów (ile klientów będzie docelowo hostowanych pod tymi adresami IP).
- Opis sieci (informacja widoczna w bazie WHOIS bloku IP).
- Wykorzystanie \[informacje dotyczące wykorzystania (WWW, SSL, Cloud itp.)].

Po potwierdzeniu ostatniego etapu otrzymasz formularz zamówienia na blok IP. Jeśli odpowiada on Twoim oczekiwaniom, wystarczy go opłacić za pomocą środków płatności oferowanych na dole strony, aby otrzymać zamówione adresy.

### Przenoszenie bloku IP między dwiema usługami Managed Bare Metal

Migracja bloku IP wymaga ręcznego przeniesienia bloków za pośrednictwem APIv6 OVHcloud.

Należy zastosować następujące wywołanie API:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/move"} />

Pola należy wypełnić w następujący sposób:

- ip: blok IP z /maską
- nexthop “newPrimaryIp” (wielkość liter jest rozróżniana)
- to: docelowa usługa Managed Bare Metal w formie pcc-XXX-XXX-XXX-XXX

<img className="thumbnail" alt="champ nexthop" src="/images/bare-metal-cloud/managed-bare-metal/ip-block-addition/move-api.png" loading="lazy" />

Wynik będzie następujący:

<img className="thumbnail" alt="champ nexthop" src="/images/bare-metal-cloud/managed-bare-metal/ip-block-addition/api-result.png" loading="lazy" />

Następnie użyj tego wywołania API, aby przenieść IP na “parking adresów IP”:

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/park"} />


:::warning
To wywołanie odcina dostęp do sieci maszynom wirtualnym, które wykorzystują dane adresy IP.

:::


Możesz śledzić przenoszenie bloku IP z poziomu Twojego [Panelu klienta OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pl/&ovhSubsidiary=pl) w sekcji <code className="action">Bare Metal Cloud</code>, a następnie <code className="action">Managed Bare Metal</code>. Kliknij Twoją usługę Managed Bare Metal, a następnie kartę <code className="action">Operacje</code>.

Odnośnik do operacji to “removeIpRipeBlock”.

<img className="thumbnail" alt="operations manager" src="/images/bare-metal-cloud/managed-bare-metal/ip-block-addition/operations.png" loading="lazy" />
