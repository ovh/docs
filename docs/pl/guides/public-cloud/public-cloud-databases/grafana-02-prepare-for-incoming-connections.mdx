## Instructions

### Configure your Dashboards instance to accept incoming connections

Before making a connection, we need to verify that our Dashboards instance is correctly configured.
Click on <code className="action">Data Analysis</code> in the left-hand navigation bar and select your Dashboards instance.

#### Step 1: Verify your user roles and password

Select the <code className="action">General information</code> tab and <code className="action">Reset the password</code> of **avnadmin** user, which comes with the **Admin** role, in the `Login information` section.

:::info
Other users can be created in your Dashboards instance web UI, from the `Users` tab of the <code className="action">Server Admin</code> panel.

:::


#### Step 2: Authorise incoming connections to your Dashboards instance

:::warning
For security reasons the default network configuration doesn't allow any incoming connections. It is thus critical you authorise the suitable IP addresses in order to successfully access your service.

:::


In this step, select the <code className="action">Authorised IPs</code> tab. IP addresses must be authorised here before they can connect to your serbice.

Clicking on <code className="action">Add an IP address or IP address block (CIDR)</code> opens a new window in which you can add single IP addresses or blocks to allow access to the service.

<img className="thumbnail" alt="Add an IP" src="/images/public-cloud/public-cloud-databases/grafana-02-prepare-for-incoming-connections/ip_authorize.png" loading="lazy" />

You can edit and retract database access via the <code className="action">...</code> button in the IP table.

:::info
If you want to allow connections from the outside, you can enter the IP 0.0.0.0/0. Please use it carefully.

:::


### Connect to your Dashboards Instance

In your Dashboards instance, collect the URI in the `Login informations` section of the <code className="action">General information</code> tab.

<img className="thumbnail" alt="Login information tab" src="/images/public-cloud/public-cloud-databases/grafana-02-prepare-for-incoming-connections/grafana_02_prepare_for_incoming_connections-20220530065929522.png" loading="lazy" />

Then connect to your Dashboards instance:

![Welcome to Grafana](/images/public-cloud/public-cloud-databases/grafana-02-prepare-for-incoming-connections/grafana_02_prepare_for_incoming_connections-20220530071539383.png)

Congratulations! You are now connected to your Dashboards instance.

![Grafana first connection](/images/public-cloud/public-cloud-databases/grafana-02-prepare-for-incoming-connections/grafana_02_prepare_for_incoming_connections-20220530071725524.png)

Learn more about Grafana® in the following tutorial: [Grafana fundamentals](https://grafana.com/tutorials/grafana-fundamentals/?utm_source=grafana_gettingstarted)
