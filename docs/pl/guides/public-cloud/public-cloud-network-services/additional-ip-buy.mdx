## Wprowadzenie

Potrzeba skonfigurowania adresu Additional IP na swoich instancjach może zajść z różnych powodów:

- Masz kilka stron na swojej instancji.
- Hostujesz projekty międzynarodowe.

Aby spełnić te potrzeby, możesz wykupić adres Additional IP dla swoich instancji Public Cloud.

Te adresy Additional IP można migrować tylko do instancji tego samego projektu.

**Z tego przewodnika dowiesz się, jak wykupić adres Additional IP na potrzeby projektu Public Cloud OVHcloud.**

## W praktyce

W menu po lewej stronie otwórz <code className="action">Publiczne adresy IP</code> w **Sieć**.

Otwórz kartę <code className="action">Additional IP</code> i kliknij przycisk <code className="action">Operacje</code>. Wybierz <code className="action">Dodaj nowy adres IP</code>.

<img className="thumbnail" alt="Dodaj IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_01.png" loading="lazy" />

W etapie 1 zamówienia kliknij <code className="action">Dalej</code>.

<img className="thumbnail" alt="Dodaj IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_02.png" loading="lazy" />

Etap 2 umożliwia wybór kraju dla nowego adresu IP.

<img className="thumbnail" alt="Dodaj IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_03.png" loading="lazy" />

Dla geolokalizacji IP dostępne są następujące kraje:

|          |          |          |           |                |
|:--------:|:--------:|:--------:|:---------:|:--------------:|
| Belgia  | Finlandia  | Francja   | Niemcy   | Czechy |
| Irlandia  |  Włochy   | Litwa | Niderlandy | Wielka Brytania    |
| Portugalia |  Hiszpania   |  Polska |  Szwajcaria |                 |

> [!primary] **Dostępność**
> 
> Niektóre z tych krajów mogą nie być wymienione w zależności od dostępności obecnie adresów IPv4.
> 

> [!primary] **Dzierżawa**
>
> Geolokalizacja IP opiera się wyłącznie na organizacjach referencyjnych.
> 
> Na przykład [RIPE NCC](https://www.ripe.net/) obsługuje Europę jako regionalny rejestr internetowy.
>
> Jeśli chcesz sprawdzić geolokalizację w inny sposób, skontaktuj się bezpośrednio z odpowiednimi organizacjami. OVHcloud nie będzie mógł udzielić Ci wsparcia w tym zakresie.

Po wybraniu kraju kliknij <code className="action">Dalej</code>.

Na ostatnim etapie wybierz instancję z rozwijanego menu. Następnie kliknij <code className="action">Wygeneruj zamówienie</code>.

<img className="thumbnail" alt="Dodaj IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_04.png" loading="lazy" />

Zamówienie zostanie automatycznie otwarte, aby sfinalizować zamówienie.

Więcej informacji znajdziesz w przewodniku dotyczącym [zarządzania zamówieniami OVHcloud](/guides/account-and-service-management/managing-billing-payments-and-services/managing-ovh-orders/).

Możesz również wyświetlić zamówienie w Panelu klienta, sekcja <code className="action">Dashboard</code>, klikając <code className="action">Pokaż moje zamówienia</code>.

Następnym krokiem jest konfiguracja IP w systemie operacyjnym. Zapoznaj się [z przewodnikiem dotyczącym tej konfiguracji](/guides/public-cloud/public-cloud-network-services/getting-started-04-configure-additional-ip-to-instance/).
