## Objective

Utworzenie projekt jest pierwszym krokiem we wdrażaniu [instancji Public Cloud](https://www.ovhcloud.com/pl/public-cloud/).

**Dowiedz się, jak utworzyć pierwszy projekt Public Cloud.**

- **Link bezpośredni:** [Public Cloud Projects](https://manager.eu.ovhcloud.com/#/pci/projects)
- **Ścieżka nawigacji:** <code className="action">Public Cloud</code> > Wybierz projekt

## Wskazówki

Zapoznaj się z nimi i zaakceptuj warunki umów, zaznaczając odpowiednie pole, następnie kliknij <code className="action">Poznaj naszą ofertę Public Cloud</code>.

<img className="thumbnail" alt="Tworzenie projektu" src="/images/public-cloud/public-cloud-cross-functional/create-a-public-cloud-project/firstproject2024.png" loading="lazy" style={{ maxWidth: '400px' }} />

- Jeśli nie masz jeszcze ważnego sposobu płatności na koncie OVHcloud, rozpoczyna się proces tworzenia projektu Public Cloud. Twój projekt zostanie utworzony w [Tryb Discovery](#discovery).
- Jeśli masz już na koncie OVHcloud sposób płatności, najpierw nazwij Twój projekt Public Cloud, a następnie wybierz sposób płatności.

<img className="thumbnail" alt="tworzenie projektu" src="/images/public-cloud/public-cloud-cross-functional/create-a-public-cloud-project/project-creation.png" loading="lazy" style={{ maxWidth: '400px' }} />

Po zakończeniu procesu tworzenia Twój nowy projekt Public Cloud będzie widoczny w lewym górnym rogu sekcji <code className="action">Public Cloud</code> w Twoim Panelu klienta OVHcloud:

<img className="thumbnail" alt="Nowy utworzony projekt" src="/images/public-cloud/public-cloud-cross-functional/create-a-public-cloud-project/pci-interface-2025.png" loading="lazy" style={{ maxWidth: '400px' }} />

Od tej pory będziesz miał dostęp do całego ekosystemu Public Cloud OVHcloud. Sprawdź nowy interfejs Panelu klienta. Zapoznaj się z naszym przewodnikiem "[Poznaj interfejs Public Cloud](/guides/public-cloud/public-cloud-cross-functional/03-public-cloud-interface-walk-me/)".

<a name="discovery"></a>

:::info
**Tryb Discovery**

Jeśli jest to Twój pierwszy projekt Public Cloud i nie wskazałeś sposobu płatności na Twoim koncie, Twój projekt Public Cloud zostanie ograniczony do `Trybu Discovery` w Panelu klienta OVHcloud. Oznacza to, że możesz przeglądać i odkrywać produkty Public Cloud, ale nie możesz jeszcze tworzyć zasobów, takich jak instancje.

Aby w pełni wykorzystać potencjał Public Cloud i uruchomić pierwsze zasoby, kliknij przycisk <code className="action">Aktywuj projekt</code> na stronie głównej projektu.

<img className="thumbnail" alt="Włącz projekt" src="/images/public-cloud/public-cloud-cross-functional/create-a-public-cloud-project/activate-project.png" loading="lazy" style={{ maxWidth: '400px' }} />

:::
