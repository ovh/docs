## Wprowadzenie

**Rewers DNS** (*rDNS*) to uzupełnienie konfiguracji "klasycznej" serwerów DNS, która pozwala na konwersję domeny na adres IP (rekord typu **A**). Dzięki tego typu zapytaniu, adres IP może zostać usunięty w nazwie domeny (rejestracja typu **PTR**). Oznacza to, że zapytania DNS na danym adresie IP będą miały nazwę domeny.

Konfiguracja **rewersu DNS** instancji jest szczególnie przydatna przy wysyłaniu e-maili. Ryzyko odrzucenia wiadomości przez system ochrony przed spamem zostanie zmniejszone, jeśli adres IP Twojego serwera poczty wychodzącej zostanie poprawnie rozwiązany w Twojej domenie.

**Dowiedz się, jak skonfigurować rewers DNS dla adresu lub adresów IP instancji Public Cloud.**

## Wymagania początkowe

- Posiadanie [instancji Public Cloud](https://www.ovhcloud.com/pl/public-cloud/) na koncie OVHcloud
- Nazwa domeny z polem `A` wskazującym na instancję

## W praktyce

Przejdź do sekcji <code className="action">Sieć</code> i kliknij przycisk <code className="action">Publiczne adresy IP</code>.

W rozwijanym menu **Moje publiczne adresy IP i usługi powiązane** możesz podzielić Twoje usługi na kategorie. Możesz również wyszukać konkretny adres IP w pasku wyszukiwania po lewej stronie menu rozwijanego.

<img className="thumbnail" alt="Reverse DNS" src="/images/assets/screens/control-panel/product-selection/bare-metal-cloud/network/filterip-new.png" loading="lazy" />

Kliknij przycisk <code className="action">⁝</code> w wierszu odpowiedniego adresu IP i wybierz opcję <code className="action">Skonfiguruj rewers DNS</code>.

<img className="thumbnail" alt="Reverse DNS" src="/images/assets/screens/control-panel/product-selection/bare-metal-cloud/network/modifyreverse-new.png" loading="lazy" />

W nowym oknie wprowadź swoją ścieżkę odwrotną i kliknij <code className="action">Zatwierdź</code>.

<img className="thumbnail" alt="Reverse DNS" src="/images/assets/screens/control-panel/product-selection/bare-metal-cloud/network/enterreverse-new.png" loading="lazy" />

Możesz również edytować ścieżkę odwrotną bezpośrednio za pomocą ikony <code className="action">ołówek</code> w kolumnie **Rewers DNS** tabeli.

:::info
:::

Jeśli modyfikacja nie działa zgodnie z oczekiwaniami, sprawdź, czy pole `A` jest poprawnie skonfigurowane w strefie DNS Twojej domeny. Uwaga, modyfikacja [strefy DNS](/guides/web-cloud/domains/dns-zone-edit/) może trwać do 24 godzin, jeśli ostatnio zmieniłeś pole `A`.
