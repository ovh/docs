## Objective

**This guide details how to activate IAM with Hosted Private Cloud - VMware on OVHcloud via the OVHcloud Control Panel or with the OVHcloud API**.

## Requirements

- An [OVHcloud account](/guides/account-and-service-management/account-information/ovhcloud-account-creation/)
- One or more Hosted Private Cloud - VMware on OVHcloud products linked to this account (Hosted Private Cloud powered by VMware, VMware Service Pack).

## Instructions

### Enabling IAM

:::info
This may take up to 30 minutes.

:::


### Via the OVHcloud Control Panel

Log in to your [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pt/&ovhSubsidiary=pt) and click on the <code className="action">Hosted Private Cloud</code> tab.

Click on the <code className="action">VMware</code> section, select your infrastructure, then go to the <code className="action">Users</code> tab.

Under the <code className="action">OVHcloud IAM</code> section, click <code className="action">Enable OVHcloud IAM</code>.

<img className="thumbnail" alt="Enable IAM" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-iam-activation/iam_enable_2.png" loading="lazy" />

:::tip[Success]
Once IAM is enabled, its status will be `Enabled` and green.

:::


<img className="thumbnail" alt="Enable IAM" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-iam-activation/iam_enable_3.png" loading="lazy" />

### Via the OVHcloud API

:::tip[Success]
Read the guide [Getting started with OVHcloud APIs](/guides/manage-and-operate/api/first-steps/) to get familiar with using OVHcloud APIv6.

:::


:::warning
Make sure to replace the `serviceName` with the reference of your Hosted Private Cloud service, in the form `pcc-XXX-XXX-XXX-XXX`.

:::


To enable the IAM option, execute the following API call:

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/iam/enable"} />


#### Checking that IAM is enabled

To control IAM activation, execute the following API call:

<Api version="v1" section="/dedicatedCloud" method="GET" route={"/dedicatedCloud/\{serviceName\}/iam"} />

API return:

```shell
{
  "state": "enabled",
  "identityProviderId": 275
}
```
