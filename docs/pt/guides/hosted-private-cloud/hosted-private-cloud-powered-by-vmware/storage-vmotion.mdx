## Objetivo

O **Storage vMotion** permite alterar a localização de armazenamento dos ficheiros da máquina virtual, conservando a máquina virtual em execução. É possível mover a máquina virtual por completo ou disco por disco.

**Este manual mostra como realizar esta operação.**

## Instruções

### Migrar o disco de uma máquina virtual

Para mover os ficheiros de uma máquina virtual para outro datastore, basta clicar com o botão direito do rato na máquina virtual em execução e selecionar o menu `Migrate...`.

![migrar disco](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion/VmotionStorage1.png)

### Escolha do tipo de vMotion

O menu propõe várias opções de **vMotion**. No nosso exemplo, iremos apenas migrar a máquina virtual para outro datastore. Assim, deve selecionar a opção "Change storage only".

A opção "Change compute resource only" permite migrar a máquina virtual para outro host.  

Esta operação, chamada **vMotion**, é descrita [neste manual](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vmotion-new).

![escolha vMotion](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion/VmotionStorage2.png)

### Escolha do datastore

Escolha o armazenamento para o qual pretende migrar os dados.

Também é possível alterar a política de armazenamento durante esta operação.

Assim, poderá aplicar as políticas de armazenamento criadas se dispuser de um [armazenamento vSAN](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan) ou da opção [VMencryption](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/hosted-private-cloud-powered-by-vmware-vm-encrypt).

![escolha datastore](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion/VmotionStorage3.png)

Caso tenha vários discos virtuais na mesma máquina, é possível migrar apenas um disco da VM utilizando o botão `Advanced`.

Poderá ver a seguinte visualização:

![datastore vMotion](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion/VmotionStorage6.png)

### Finalizar o vMotion

Clique em `Finish` para lançar o procedimento de migração.

![finalizar vMotion](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion/VmotionStorage4.png)

### Seguimento do vMotion

Nas tarefas recentes, poderá acompanhar o estado da migração, que demorará algum tempo dependendo do tamanho da VM, dos acessos IO e da largura de banda utilizada.

![seguimento vMotion](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion/VmotionStorage5.png)
