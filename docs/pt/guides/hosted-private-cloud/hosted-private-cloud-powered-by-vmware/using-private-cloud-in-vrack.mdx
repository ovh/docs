## Objetivo

O vRack é a possibilidade de ligar diferentes serviços cloud da OVHcloud entre si, no seio de uma ou várias redes privadas seguras (VLAN).

**Este guia explica como implementar**

## Requisitos

- Ter um serviço [vRack](https://www.ovhcloud.com/pt/network/vrack/) na sua conta ou encomendar um serviço se necessário.
- Ter contacto com o administrador da infraestrutura [Hosted Private Cloud](https://www.ovhcloud.com/pt/enterprise/products/hosted-private-cloud/), para receber dados de acesso.
- Ter um identificador de utilizador ativo [criado na Área de Cliente OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pt/&ovhSubsidiary=pt).

## Instruções

### Área de Cliente

Aquando da entrega do seu serviço [Hosted Private Cloud](https://www.ovhcloud.com/pt/enterprise/products/hosted-private-cloud/), a parte *datacenter* já está dentro de um vRack. Para aceder à secção vRack, aceda à secção <code className="action">Bare Metal Cloud</code>, clique em <code className="action">Network</code>, e em <code className="action">vRack</code>. Selecione o seu vRack na lista para visualizar o conteúdo.

<img className="thumbnail" alt="Datacenter" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/using-private-cloud-in-vrack/vRackDatacenter.PNG" loading="lazy" />

É possível mover o *datacenter* do seu Hosted Private Cloud para outro vRack clicando no botão <code className="action">Migrar</code>

### Client vSphere

No vSphere, pode encontrar as *VLANs* compatíveis com vRack no switch virtual distribuído (vds), que está situado na pasta **vRack**.

:::tip[Success]
Por predefinição, a OVHcloud disponibiliza-lhe uma infraestrutura com 11 VLANs (VLAN10 a VLAN20).

:::


<img className="thumbnail" alt="vlan" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/using-private-cloud-in-vrack/vRackVsphere.png" loading="lazy" />

É possível alterar os parâmetros ou criar novos parâmetros de acordo com o guia de [criação da VLAN](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/creation-vlan/).

Poderá de seguida atribuir estas *portgroup* às interfaces de rede das suas máquinas virtuais.
