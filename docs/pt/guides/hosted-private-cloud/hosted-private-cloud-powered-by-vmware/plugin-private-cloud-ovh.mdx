## Sumário

O plugin OVHcloud permite-lhe adicionar recursos dedicados à sua infraestrutura, em apenas alguns minutos.

**Saiba como utilizar este plugin.**

## Requisitos

- Dispor do serviço [Hosted Private Cloud](https://www.ovhcloud.com/pt/enterprise/products/hosted-private-cloud/).
- Aceder à interface de gestão vSphere.

## Instruções

Existem dois recursos dedicados com faturação à hora:

- os servidores host
- os datastores.

A partir do cliente web vSphere, só precisa de aceder à parte “Host and Cluster” e abrir a arborescência à esquerda. Desta forma, irá aceder aos menus do plugin através da janela  <code className="action">Configure</code> do datacenter ou do cluster.

O menu <code className="action">Add Host</code> é dedicado aos servidores host: apresenta os detalhes técnicos e permite encomendá-los.

<img className="thumbnail" alt="OVHcloud plugin - add host" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/plugin-private-cloud-ovh/Plugin01.jpg" loading="lazy" />

A encomenda de datastores adicionais é feita no menu <code className="action">Add Storage</code>.

<img className="thumbnail" alt="OVHcloud plugin - add storage" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/plugin-private-cloud-ovh/Plugin02.jpg" loading="lazy" />

Nota: existe uma alternativa para aceder a estes menus. Para o fazer, clique com o botão direito do rato no datacenter ou no cluster da infraestrutura e, em seguida, selecione a opção <code className="action">OVHcloud</code>.

<img className="thumbnail" alt="Opção OVH Hosted Private Cloud" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/plugin-private-cloud-ovh/Plugin03.jpg" loading="lazy" />
