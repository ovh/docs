## Objective

This guide will explain how to replace the outgoing internet gateway (OVHgateway) with another network operating system that will give you, in addition to internet access, the ability to configure NAT and VPN (Ipsec or SSL VPN).

:::warning
OVHcloud provides services for which you are responsible, with regard to their configuration and management. It is therefore your responsibility to ensure  that they function correctly.

This guide is designed to assist you in common tasks as much as possible. Nevertheless, we recommend contacting a [specialist service provider](https://partner.ovhcloud.com/pt/directory/) or reaching out to [our community](https://community.ovh.com/en/) if you experience any issues.

:::


## Requirements

- One Nutanix cluster provided by OVHcloud
- Access to the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pt/&ovhSubsidiary=pt)
- Access to your clusters via Prism Central

## Instructions

The OVHgateway uses two network cards by default: 

- One on VLAN 0 (base) connected to the internet with an additional OVHcloud IP address.
- One on VLAN 1 (infra) connected to the local administration network with a range of IP addresses, in this example in 192.168.10.0/24.

In our guide, we will replace this gateway with the network operating system **pfSense Community edition** without software support.

:::info
It is entirely possible to use this guide to install other network operating systems compatible with AHV.

:::

### Retrieving the public address in the OVHcloud Control Panel 

Retrieve information about the OVHcloud gateway network settings.

Log in to the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pt/&ovhSubsidiary=pt), select your Nutanix cluster, and find the information in the `IPFO` field.

<img className="thumbnail" alt="Get IP Fail OVER" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/30-software-gateway-replacement/02-get-ipfailover.png" loading="lazy" />

**IPFO** is a range of 4 addresses. The first and last are reserved, the third is on OVHcloud hardware and serves as an **Internet** gateway. The only usable IP address is the second address in the range.

During installation, we will reuse this information to assign it to the new **GW-PFSENSE virtual machine**.

```console
XX.XX.XX.N Reserved network address that appears on the OVHcloud client site
XX.XX.XX.N+1 IP address to be assigned to the GW-PFSENSE virtual machine WAN interface
XX.XX.XX.N+2 Address to be used as a gateway on the GW-PFSENSE VM WAN interface
XX.XX.XX.N+3 Reserved broadcast IP address
```

For example, if the **IPFO** address displayed on the client site is 198.51.100.0/30, use:

- **198.51.100.1** for the **WAN** interface address.
- **198.51.100.2** for the gateway on the **WAN** interface.

Log in to the pfSense interface in https, with the public address (for example, **https://198.51.100.1**) in your pfSense administration interface, and follow these instructions:

Go to the <code className="action">Interfaces</code> menu and click <code className="action">Assignments</code>.

<img className="thumbnail" alt="10 addinterface-in-pfsense 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/30-software-gateway-replacement/10-addinterface-in-pfsense01.png" loading="lazy" />

Click <code className="action">+ Add</code> to the right of **Available network ports:**.

<img className="thumbnail" alt="10 addinterface-in-pfsense 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/30-software-gateway-replacement/10-addinterface-in-pfsense02.png" loading="lazy" />

Click <code className="action">Save</code>.

<img className="thumbnail" alt="10 addinterface-in-pfsense 03" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/30-software-gateway-replacement/10-addinterface-in-pfsense03.png" loading="lazy" />

In the <code className="action">Interfaces</code> menu, click <code className="action">OPT1</code>

<img className="thumbnail" alt="11 assign ip to new interface 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/30-software-gateway-replacement/11-assign-ip-to-new-interface01.png" loading="lazy" />

Check **Enable Interfaces** and modify these settings :

* **Description** : `VLAN2`
* **IPv4 Address** : `192.168.2.254/24`

Click <code className="action">Save</code>.

<img className="thumbnail" alt="11 assign ip to new interface 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/30-software-gateway-replacement/11-assign-ip-to-new-interface02.png" loading="lazy" />

Click <code className="action">Apply Changes</code>.

<img className="thumbnail" alt="11 assign ip to new interface 03" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/30-software-gateway-replacement/11-assign-ip-to-new-interface03.png" loading="lazy" />

Go to the `Firewall` menu and click <code className="action">Rules</code>.

<img className="thumbnail" alt="12 add rule for new card 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/30-software-gateway-replacement/12-add-rule-for-new-card01.png" loading="lazy" />

Go to the <code className="action">VLAN2</code> tab and click the <code className="action">Add</code> button on the left.

<img className="thumbnail" alt="12 add rule for new card 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/30-software-gateway-replacement/12-add-rule-for-new-card02.png" loading="lazy" />

Change these values :

* **Protocol** : `Any`
* **Source** : `VLAN2 net`
* **Destination** : `any`

Click <code className="action">Save</code>.

<img className="thumbnail" alt="12 add rule for new card 03" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/30-software-gateway-replacement/12-add-rule-for-new-card03.png" loading="lazy" />

Click <code className="action">Apply Changes</code>.

<img className="thumbnail" alt="12 add rule for new card 04" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/30-software-gateway-replacement/12-add-rule-for-new-card04.png" loading="lazy" />

Your VLAN 2 is now connected to the Internet.
