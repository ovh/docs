## Objective

HYCU for Nutanix is a backup software available for Nutanix. 

**Find out how to install, configure and use HYCU on a Nutanix cluster with Object Storage storage provided by OVHcloud.**

:::warning
OVHcloud provides services for which you are responsible, with regard to their configuration and management. It is therefore your responsibility to ensure that they work properly.

This guide is designed to assist you as much as possible with common tasks. However, we recommend reaching out to the [OVHcloud Professional Services team](https://www.ovhcloud.com/pt/professional-services/) or a [specialized provider](https://partner.ovhcloud.com/pt/directory/) if you encounter difficulties or have doubts regarding the administration, use, or setup of a service on a server.>

:::


## Requirements

- A valid [HYCU for OVHcloud](https://www.ovhcloud.com/pt/storage-solutions/hycu/) license in your OVHcloud account (the first step of this guide will detail the procedure to follow) or a HYCU license purchased from a third-party provider.
- A Nutanix on OVHcloud cluster in your OVHcloud account.
- Access to your [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pt/&ovhSubsidiary=pt).
- Access to the cluster via Prism Central.
- A Public Cloud project with a High Performance Object Storage type storage bucket, with a user with read and write permissions for this bucket. You can find more information on how to create a Public Cloud project and how to use the High Performance Object Storage service on the following pages:
    - [Creating your first OVHcloud Public Cloud project](/guides/public-cloud/public-cloud-cross-functional/create-a-public-cloud-project/).
    - [Getting started with Object Storage](/guides/storage-and-backup/object-storage/s3-getting-started-with-object-storage/).
    - [Object Storage - Managing object immutability with Object Lock (WORM)](/guides/storage-and-backup/object-storage/s3-managing-object-lock/)
- 60 GB of storage, 8 GB of memory, and 8 cores on your Nutanix Cluster for the HYCU Instance/Appliance.

### Order a HYCU for OVHcloud license <a name="license-order"></a>

We offer different license packs based on the number of virtual machines (VMs) used by your Nutanix workloads.

:::tip[Success]
For more information, visit our [HYCU for OVHcloud](https://www.ovhcloud.com/pt/storage-solutions/hycu/) page.

:::

**You already have a HYCU license?**<br/>

<img className="thumbnail" alt="Add Image HYCU 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/00-addimagehycu02.png" loading="lazy" />

:::info
The URL used for the download is the latest version available on the HYCU website.

- **&lt; IP address >**: The local IP address of the virtual machine with the subnet mask as XX.XX.XX.XX/XX.
- **&lt; GATEWAY >**: Local gateway for the virtual machine to access the Internet.
- **&lt; DNS >**: DNS used on the Internet.

```yaml
#cloud-config
bootcmd:
- /opt/grizzly/bin/cloud_init_setup.sh hycubc < IP address > < GATEWAY > < DNS > `hycu.local,ntnx.local`
```

Modify **Guest Customisation** options by selecting <code className="action">Cloud-init (Linux)</code> in the **Script Type** drop-down menu. Select <code className="action">Custom Script</code> in the **Configuration Method** drop-down menu.

Copy the contents of the yaml script and paste it to the field below **Clear Script**. Then click <code className="action">Next</code>.

<img className="thumbnail" alt="Create HYCUVM 11" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/02-createhycuvm11.png" loading="lazy" />

<img className="thumbnail" alt="Create HYCUVM 12" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/02-createhycuvm12.png" loading="lazy" />

<img className="thumbnail" alt="Create HYCUVM 13" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/02-createhycuvm13.png" loading="lazy" />

<img className="thumbnail" alt="Create HYCUVM 14" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/02-createhycuvm14.png" loading="lazy" />.

#### Configuring HYCU <a name="hycu-configuration"></a>

Connect with a web browser to the HYCU administration interface, which should be similar to **https://nutanixfqdncluster:8443**. The `fqdn` variable corresponds to the URL provided when the Nutanix cluster was created.

Enter the default password and click <code className="action">Sign In</code>.

<img className="thumbnail" alt="Configure HYCU 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/03-configurehycu01.png" loading="lazy" />

Change the login password for more security.

Click <code className="action">Change Password</code> in the <code className="action">admin</code> menu in the top right-hand corner of the interface.

<img className="thumbnail" alt="Configure HYCU 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/03-configurehycu02.png" loading="lazy" />

Enter the default password in the **OLD PASSWORD** field, the new password in the **PASSWORD** and **CONFIRM PASSWORD** fields.

Then click <code className="action">Save</code>.

<img className="thumbnail" alt="Configure HYCU 03" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/03-configurehycu03.png" loading="lazy" />

We will now connect HYCU to the Nutanix cluster.

Click the <code className="action">Administration</code> gear icon in the top right corner and choose <code className="action">Sources</code>

<img className="thumbnail" alt="Configure HYCU 04" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/03-configurehycu04.png" loading="lazy" />

Enter information about **Prism Element**:

- **URL**: `https://url_prism_element_local:9440`
- **USERNAME**: `Prism Element user`
- **PASSWORD**: `Prism Element user password`

Click <code className="action">Next</code>.

<img className="thumbnail" alt="Configure HYCU 05" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/03-configurehycu05.png" loading="lazy" />

### Updating HYCU <a name="hycu-update"></a>

HYCU regularly provides updates for which we detail the process below.

#### Adding sources for a new version of HYCU  <a name="adding-new-sources"></a>

From the **Prism Central** main menu, click <code className="action">Images</code> from the <code className="action">Compute & Storage</code> menu.

<img className="thumbnail" alt="Add Image HYCU for update 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/04-addimageforupdate01.png" loading="lazy" />

<img className="thumbnail" alt="Add Image HYCU for update 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/04-addimageforupdate02.png" loading="lazy" />

Select <code className="action">URL</code>. 

Enter the URL for the qcow2 image of the latest version of HYCU, such as: 

- `https://download.hycu.com/ec/v4.X.X/hotfixes/4.X.X-XXXX/hycu-4.X.X-XXXX.qcow2`

:::info
The URL used for the download is the latest version available on the HYCU website. 

:::


Click <code className="action">Upload file</code>.

Remove the extension **.qcow2** behind the name `hycu-'4.X.X-XXXX`, enter a description and click <code className="action">Next</code>.

:::warning
It is important to remove the extension in the name to facilitate the HYCU update process.

:::


<img className="thumbnail" alt="Add Image HYCU for update 04" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/04-addimageforupdate04.png" loading="lazy" />
