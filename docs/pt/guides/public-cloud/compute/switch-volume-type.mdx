## Objetivo

O objetivo deste guia é mostrar-lhe como alterar um tipo de volume Block Storage, de Classic ou High Speed para High Speed gen2.

## Requisitos

- Aceder à [interface Horizon](/guides/public-cloud/public-cloud-cross-functional/introducing-horizon/).
- Um volume [Block Storage](/guides/public-cloud/compute/create-and-configure-an-additional-disk-on-an-instance/) criado no seu projeto [Public Cloud](https://www.ovhcloud.com/pt/public-cloud/).

## Instruções

Ao alterar um tipo de volume Block Storage para um volume "High Speed gen2", a política de migração deve ser alterada de `Never` para `On Demand`.

Por predefinição, a política de migração está definida para `Never`, uma vez que o volume permanece no mesmo cluster CEPH. No entanto, para o "High Speed gen2", o volume deverá ser migrado para um novo cluster.

Esta alteração pode ser realizada através da interface Horizon ou através da interface de linha de comandos OpenStack.

:::warning
Se o volume Block Storage estiver ligado a uma instância, deverá desligá-lo antes de continuar. Para mais informações, consulte a secção **Desassociar um volume** do guia "[Criar e configurar um disco suplementar numa instância](/guides/public-cloud/compute/create-and-configure-an-additional-disk-on-an-instance#detach-a-volume/)".

A alteração do tipo de volume (retyping) através da área de cliente OVHcloud ou da API OVHcloud só está disponível para volumes não encriptados. Não é possível alterar o tipo de volumes encriptados do tipo **-LUKS** através destas interfaces.

O retyping é possível através do OpenStack / Horizon apenas para volumes **-LUKS** para **-LUKS**. Neste caso, a restauração do volume após o retyping não é possível.

As conversões **-LUKS** para **não -LUKS** não são suportadas, incluindo através do OpenStack / Horizon.

:::


<Tabs>
  <Tab label="A partir da área de cliente OVHcloud">
    Clique em <code className="action">Block Storage</code> no menu à esquerda sob **Storage & Backup**.
    
    Localize o volume relevante na lista, em seguida, clique no botão <code className="action">...</code> à sua direita. Escolha depois <code className="action">Modificar o tipo do volume</code>.
    
    Uma janela abre-se e permite-lhe consultar os diferentes tipos de volumes disponíveis. Selecione o tipo desejado e confirme a sua escolha clicando em <code className="action">Modificar</code>.
    
    :::info
    A atualização do tipo de volume (retyping) pode demorar vários minutos.

    :::

  </Tab>
  <Tab label="A partir da interface Horizon">
    Inicie sessão na [interface Horizon](https://horizon.cloud.ovh.net/auth/login/) e certifique-se de estar na região correta. Pode verificar isso no canto superior esquerdo. 
    
    <img className="thumbnail" alt="Seleção da região" src="/images/public-cloud/compute/switch-volume-type/region2021.png" loading="lazy" />

Clique no menu <code className="action">Volumes</code> à esquerda e depois em <code className="action">Volumes</code>.
    
    Clique na seta pendente ao lado de <code className="action">Edit Volume</code> e selecione <code className="action">Change Volume Type</code>.
    
    <img className="thumbnail" alt="Escolha da opção" src="/images/public-cloud/compute/switch-volume-type/selectoption.png" loading="lazy" />

Na janela que aparece, clique no menu pendente em `Type` e selecione <code className="action">high-speed-gen-2</code>. Em seguida, clique na seta pendente em `Migration Policy` e selecione <code className="action">On Demand</code>.
    
    Após estas ações, clique em <code className="action">Change Volume Type</code> para validar a alteração.
    
    <img className="thumbnail" alt="Escolha da opção" src="/images/public-cloud/compute/switch-volume-type/changevolume.png" loading="lazy" />
  </Tab>
  <Tab label="A partir da CLI OpenStack">
    Antes de começar, consulte o seguinte guia:
    
    - [Preparar o ambiente para utilizar a API OpenStack](/guides/public-cloud/public-cloud-cross-functional/prepare-the-environment-for-using-the-openstack-api/).
    
    Primeiro, liste os tipos de volumes disponíveis na sua região com o seguinte comando:
    
    ```bash
    #~$ openstack volume type list
    +--------------------------------------+----------------------------------------------------+-----------+
    | ID                                   | Name                                               | Is Public |
    +--------------------------------------+----------------------------------------------------+-----------+
    | 27844ef7-1a9a-4944-be59-6e4eb19a71f6 | high-speed-gen2                                    | True      |
    | 23f75fef-d4f6-416a-a884-95aa3fd45695 | classic                                            | True      |
    | 2f78e8af-93c9-4e5c-b177-83c4a7ec456a | high-speed                                         | True      |
    | 9c5b1e42-3d8f-4a67-a9d2-84f3b2e7c1aa | high-speed-gen2-luks                               | True      |
    | f41d7c8e-6a2b-4b91-9e73-2d6c0a58e94f | classic-luks                                       | True      |
    | c8e92a5d-0f6e-4e3b-b1a4-7a9d6f3c2e8b | high-speed-luks                                    | True      |
    ---------------------------------------------------------------------------------------------------------
    ```
    
    :::warning
    Note que se os tipos de volumes "high-speed-gen2" ou **-LUKS** não aparecerem na lista, isso significa que não estão disponíveis nesta região.
    
    Os tipos de volumes **-LUKS** só são mostrados quando são suportados na região e compatíveis com o tipo de encriptação do volume.

    :::

    
    Altere depois o tipo de volume com o seguinte comando:
    
    ```bash
    $ openstack volume set --type <VOLUME_TYPE> --retype-policy on-demand <VOLUME_NAME_OR_ID>
    ```

</Tabs>
