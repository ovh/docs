## Objetivo

Pode precisar de configurar um endereço Additional IP nas suas instâncias por vários motivos:

- Tem vários sites na sua instância.
- Aloja projetos internacionais.

Para responder a estas necessidades, pode comprar um endereço Additional IP para as suas instâncias Public Cloud.

Estes endereços Additional IP só poderão ser migrados para as instâncias de um mesmo projeto.

**Este guia explica como comprar um Additional IP para o seu projeto Public Cloud da OVHcloud.**

## Requisitos

- Ter acesso à [Área de Cliente OVHcloud](/links/manager).
- Dispor de pelo menos uma instância. Para isso, consulte [o guia para criar uma instância a partir da Área de Cliente](/guides/public-cloud/compute/compute-getting-started).

> [!warning]
> Esta funcionalidade não está atualmente disponível para as instâncias Metal.
>

## Instruções

Aceda à [Área de Cliente OVHcloud](/links/manager), vá à secção `Public Cloud` e selecione o projeto Public Cloud em causa.

No menu à esquerda, abra o `IP públicos` em **Network**.

Abra o separador `Additional IP` e clique no botão `Ações`. Selecione `Adicionar um novo IP`.

![Adicionar IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_01.png)

Na etapa 1 do comando, clique em `Seguinte`.

![Adicionar IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_02.png)

A etapa 2 permite selecionar um país para o novo endereço IP.

![Adicionar IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_03.png)

Os seguintes países estão disponíveis para a geolocalização dos IP:

|          |          |          |           |                |
|:--------:|:--------:|:--------:|:---------:|:--------------:|
| Bélgica  | Finlândia  | França   | Alemanha   | República Checa |
| Irlanda  |  Itália   | Lituânia | Países Baixos | Reino Unido    |
| Portugal |  Espanha   |  Polónia |  Suíça |                 |

> [!info] **Disponibilidade**
> 
> É possível que alguns destes países não estejam listados, dependendo da disponibilidade atual dos endereços IPv4.
> 

> [!info] **Locação**
>
> A geolocalização de IP baseia-se unicamente em organismos de referência.
> 
> Por exemplo, o [RIPE NCC](https://www.ripe.net/) serve a Europa como registo regional da Internet.
>
> Se precisar de verificar a geolocalização de outra forma, contacte diretamente as organizações em causa. A OVHcloud não lhe poderá fornecer assistência nesta matéria.

Depois de selecionar o país, clique em `Seguinte`.

No último passo, selecione a sua instância no menu pendente. A seguir, clique em `Gerar nota de encomenda`.

![Adicionar IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_04.png)

A nota de encomenda será aberta automaticamente a fim de finalizar a sua compra.

Para mais informações, consulte o nosso manual sobre a [gestão das encomendas da OVHcloud](/guides/account-and-service-management/managing-billing-payments-and-services/ovh-orders).

Também pode consultar a nota de encomenda na sua Área de Cliente, na secção `Dashboard`, clicando em `Ver as minhas encomendas`.

O próximo passo consiste em configurar o IP no seu sistema operativo. Consulte o [nosso guia dedicado a esta configuração](/guides/public-cloud/public-cloud-network-services/configure-additional-ip).
