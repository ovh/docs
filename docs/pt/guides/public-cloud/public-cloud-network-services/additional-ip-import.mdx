:::info
A partir de 6 de outubro de 2022, a nossa solução "Failover IP" passou a designar-se [Additional IP](https://www.ovhcloud.com/pt/network/additional-ip/). Isto não afeta as suas funcionalidades.

:::


## Objetivo

Se precisa de configurar um endereço Additional IP numa das suas instâncias, quer seja para:

- Tem vários sítios na sua instância. 
- Acolhe projectos internacionais.
- Deseja migrar a sua atividade de um servidor dedicado para uma instância Public Cloud.

Pode importar um endereço Additional IP associado a outro serviço OVHcloud.

**Este guia explica como poderá importar esse Additional IP para o seu projeto Public Cloud OVHcloud.**

## Requisitos

- Um [projeto Public Cloud](https://www.ovhcloud.com/pt/public-cloud/) criado na sua conta OVHcloud
- Um [endereço Additional IP](https://www.ovhcloud.com/pt/bare-metal/ip/)

## Instruções

No menu à esquerda, abra o <code className="action">IP públicos</code> em **Network**.

Abra o separador <code className="action">Additional IP</code> e clique no botão <code className="action">Ações</code>. Selecione <code className="action">Importar um Additional IP</code> para apresentar todos os endereços de IP que podem ser importados no seu projeto Public Cloud.

<img className="thumbnail" alt="Secção IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-import/import22_01.png" loading="lazy" />

Se ainda não tiver um IP adicional no seu projeto Public Cloud, a opção de importação de um IP adicional será apresentada na página inicial.

Clique em <code className="action">...</code> junto do endereço IP que deseja importar e clique em <code className="action">Importar este Additional IP</code>.

<img className="thumbnail" alt="Importação Additional IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-import/import22_02.png" loading="lazy" />

Valide clicando em <code className="action">Importar</code>.

<img className="thumbnail" alt="Importação confirmada" src="/images/public-cloud/public-cloud-network-services/additional-ip-import/import22_03.png" loading="lazy" />

Aguarde alguns minutos até que a importação seja concluída. Abra o separador <code className="action">Additional IP</code> para encontrar o endereço Additional IP importado. Atualize a página caso seja necessário.

Clique em <code className="action">...</code> do lado direito e selecione <code className="action">Alterar a instância associada</code>.

<img className="thumbnail" alt="Importação Additional IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-import/import22_04.png" loading="lazy" />

Surgirá uma janela de contexto para escolher a instância à qual o seu endereço IP deve estar associado.

<img className="thumbnail" alt="Importação Additional IP" src="/images/public-cloud/public-cloud-network-services/additional-ip-import/import22_05.png" loading="lazy" />

Clique em <code className="action">Adicionar</code> para confirmar. A página apresenta então uma mensagem de modificação.

:::warning
Um IP adicional não pode ser migrado entre diferentes zonas. Por exemplo, um IP localizado no datacenter SBG pode ser migrado para GRA ou RBX mas não para BHS.

:::


O seu endereço Additional IP será associado à sua instância.

O próximo passo consiste em configurar o IP no seu sistema operativo. Consulte o [nosso guia dedicado a esta configuração](/guides/public-cloud/public-cloud-network-services/getting-started-04-configure-additional-ip-to-instance/).
