## Objective

This guide explains how to change the size of your Public Cloud Load Balancer using the Horizon interface.

:::tip[Success]
Find more information about the different Load Balancer sizes and their capacities on our [Load Balancer page](https://www.ovhcloud.com/pt/public-cloud/load-balancer/).

:::


## Requirements

- Access to the [OVHcloud Horizon interface](https://horizon.cloud.ovh.net/project/load_balancer)
- A Load Balancer [already created and available](/guides/public-cloud/public-cloud-network-services/getting-started-01-create-lb-service/)
- User privileges to modify the Load Balancer settings

## Instructions

### Step 1 - Log in to Horizon

Go to the [OVHcloud Horizon interface](https://horizon.cloud.ovh.net/project/load_balancer) and log in with your credentials. For more information on how to connect to Horizon, read the [Introducing Horizon](/guides/public-cloud/public-cloud-cross-functional/introducing-horizon/) guide.

### Step 2 - Locate the Load Balancer

Once you are logged in, go to the <code className="action">Load Balancer</code> section and find your existing Load Balancer in the list.

### Step 3 - Edit the Load Balancer

Click the down arrow button on the right side of your load Balancer entry.

Select <code className="action">Edit Load Balancer</code> in the dropdown menu.

<img className="thumbnail" alt="Edit Load Balancer Button" src="/images/public-cloud/public-cloud-network-services/update-load-balancer-size/editButtonLoadBalancer.png" loading="lazy" />

### Step 4 - Resize the Load Balancer

In the options menu, choose <code className="action">Resize Load Balancer</code>.

<img className="thumbnail" alt="Choose Resize Option" src="/images/public-cloud/public-cloud-network-services/update-load-balancer-size/ChoiceOptionLoadBalancer.png" loading="lazy" />

A window will prompt you to select a new size for your load balancer.

- **small**
- **medium**
- **large**
- **xl**

<img className="thumbnail" alt="Select Load Balancer Size" src="/images/public-cloud/public-cloud-network-services/update-load-balancer-size/loadbalancersize.png" loading="lazy" />

Confirm your selection and apply the changes.

Once the new flavor is selected, click <code className="action">Apply</code> or <code className="action">Save</code> to update the size of your Load Balancer.
