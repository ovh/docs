## Objective

Cross Service Integration allows you to expose your Public Cloud Databases Logs and Metrics.

**This guide explains how to use Cross Service Integration.**

:::warning
**Out of scope:**

- Expose metrics and logs outside of OVHcloud Public Cloud
- MongoDB engine is not supported  

:::


## Requirements

- A [Public Cloud project](https://www.ovhcloud.com/pt/public-cloud/) in your OVHcloud account
- A database running on your OVHcloud Public Cloud Databases ([this guide](/guides/public-cloud/public-cloud-databases/databases-01-order-control-panel/) can help you to meet this requirement)
- Access to the [OVHcloud API](https://eu.api.ovh.com/) (optional)

## Concept

The Cross Service Integrations for Logs and Metrics allow you for example:

- To send Valkey or MySQL metrics in PostgreSQL.
- To send PostgreSQL or MySQL metrics to OpenSearch.
- To show metrics in Dashboards service.

For that you need:

- A source service
- A destination service

<img className="thumbnail" alt="Best practices" src="/images/public-cloud/public-cloud-databases/databases-07-cross-service-integration/databases_07_cross_service_integration_best_practice.png" loading="lazy" />

:::warning
Although it is possible to define the same cluster as destination service and source service, this is a bad practice for multiple reasons (performance, security, resiliency, ...)

:::


![Bad practices](/images/public-cloud/public-cloud-databases/databases-07-cross-service-integration/databases_07_cross_service_integration_bad_practice.png)

### Integration matrix

- All services support logs to opensearch & kafka_logs to kafka.
- All services support metrics to pg.

Other integrations:

| source →<br/>↓ destination | dashboards service	| kafka |
|:--|---|---|
| pg | dashboard, datasource | |
| opensearch | datasource | |
| kmm | | kafka_mirrormaker |
| kc | | kafka_connect |

#### Store yours logs or metrics

Click on <code className="action">Databases</code> in the left-hand navigation bar, select your engine instance and open the <code className="action">Service integration</code> tab.

Click on <code className="action">Add an integration</code>:

:::warning
First create a Public Cloud Database for your *Destination* service via your Control Panel or API.

:::


<img className="thumbnail" alt="Create integration" src="/images/public-cloud/public-cloud-databases/databases-07-cross-service-integration/databases_07_cross_service_integration_creation.png" loading="lazy" />

#### Get your service and cluster IDs

You first need to identify your `serviceId` and your `clusterId`.

##### **Get the desired service ID**

Execute the following API call:

<Api version="v1" section="/cloud" method="GET" route={"/cloud/project"} />


<img className="thumbnail" alt="serviceName" src="/images/public-cloud/public-cloud-databases/databases-07-cross-service-integration/04_advanced_configuration-20220405143910846.png" loading="lazy" />
