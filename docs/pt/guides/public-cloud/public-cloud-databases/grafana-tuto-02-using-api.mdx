## Objective

Using the Grafana® API is not obvious and already clearly documented.
This tutorial explains how to configure Grafana® to use the API and how make calls to the exposed API.

## Requirements

- A [Public Cloud project](https://www.ovhcloud.com/pt/public-cloud/) in your OVHcloud account
- A Dashboards service running on your OVHcloud Public Cloud project (see [this guide](/guides/public-cloud/public-cloud-databases/databases-01-order-control-panel/) to create a managed Dashboards service)

## Instructions

### Create a Grafana® service account

In the configuration menu, display the <code className="action">Service accounts</code> tab:

<img className="thumbnail" alt="Grafana service accounts tab" src="/images/public-cloud/public-cloud-databases/grafana-tuto-02-using-api/service-account-tab.png" loading="lazy" />

Create a new service account `sa-editor` with the role `Editor`:

<img className="thumbnail" alt="Grafana service accounts creation" src="/images/public-cloud/public-cloud-databases/grafana-tuto-02-using-api/service-account-creation.png" loading="lazy" />

Click on <code className="action">Add service account token</code>:

<img className="thumbnail" alt="Grafana service accounts token button" src="/images/public-cloud/public-cloud-databases/grafana-tuto-02-using-api/add-service-account-token-button.png" loading="lazy" />

Enter the name of the desired token, `grafana-sa-token-editor`, and click on <code className="action">Generate token</code>:

<img className="thumbnail" alt="Grafana service accounts token generation" src="/images/public-cloud/public-cloud-databases/grafana-tuto-02-using-api/generate-sa-token.png" loading="lazy" />

Copy the generated token:

<img className="thumbnail" alt="Grafana service accounts token generated" src="/images/public-cloud/public-cloud-databases/grafana-tuto-02-using-api/sa-account-generated-token.png" loading="lazy" />

:::warning
After closing the pop-up, you will no longer be able to display the token!

:::


The created token appears in the tokens list:

<img className="thumbnail" alt="Grafana service accounts token list" src="/images/public-cloud/public-cloud-databases/grafana-tuto-02-using-api/sa-account-created-tokens-list.png" loading="lazy" />

You are ready to use this token with the Grafana® API.

### Use the Grafana® API

:::info
Detailed instructions on how to use the API and the possible actions can be found in the official documentation: [https://grafana.com/docs/grafana/latest/developers/http_api/](https://grafana.com/docs/grafana/latest/developers/http_api/)

:::


:::warning
Don't forget to set the `Authorised IP addresses` in the Dashboards configuration. See our guide on [Configuring your Grafana instance to accept incoming connections](/guides/public-cloud/public-cloud-databases/grafana-02-prepare-for-incoming-connections/) for more details.

:::


To send a request to the API you must use the previously created token and set it in the request header as a "Bearer token":

```bash
export GRAFANA_API_TOKEN=042footoken420

curl -H "Authorization: Bearer $GRAFANA_API_TOKEN" https://grafana-xxxxxxxxx-yyyyyyyyy.database.cloud.ovh.net/api/folders    
[
    {
        "id":11,
        "uid":"HnDCAp-4k",
        "title":"foo 1"
    },
    {
        "id":5,
        "uid":"cb_S6Pb4k",
        "title":"foo 2"
    },
    {
        "id":9,
        "uid":"Xav55taVk",
        "title":"foo 3"
    },
    {
        "id":10,
        "uid":"AH8sApaVz",
        "title":"foo 4"
    }
]

```

Here it is, you can now use all the power of the Grafana® API.
