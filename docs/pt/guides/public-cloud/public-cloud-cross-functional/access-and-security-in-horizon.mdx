## Objetivo

A interface OpenStack Horizon fornece opções para configurar o acesso às suas instâncias e a outros serviços.<br/>
Pode, por exemplo, configurar grupos de segurança para filtrar as ligações de entrada e de saída, ou ainda descarregar o ficheiro OpenRC que contém os seus identificadores para utilizar as API OpenStack.

**Saiba como gerir e proteger o acesso às suas instâncias**

## Requisitos

- [Aceder à interface Horizon](/guides/public-cloud/public-cloud-cross-functional/introducing-horizon/)

## Instruções

Ligue-se à [interface Horizon](https://horizon.cloud.ovh.net/auth/login/).

Os parâmetros de acesso e de segurança são compostos pelas seguintes secções, acessíveis através do menu à esquerda:

- **API Access** (ao abrigo do <code className="action">Projeto</code>)

O quadro de acesso à API apresenta os endpoints das API OpenStack.

<img className="thumbnail" alt="horizon - acesso API" src="/images/public-cloud/public-cloud-cross-functional/access-and-security-in-horizon/api_access.png" loading="lazy" />

Para verificar os valores de acesso a utilizar com as API, clique em <code className="action">View Credentials</code>.

Clique no botão <code className="action">Download OpenStack RC File</code> para abrir um menu pendente no qual pode escolher o ficheiro RC apropriado a descarregar.

- **Key Pairs** (em <code className="action">Project</code> e depois <code className="action">Compute</code>)

Esta secção permite-lhe armazenar e gerir os pares de chaves SSH. Pode simplesmente criar e adicionar uma chave pública e uma chave privada ao clicar no botão <code className="action">Create Key Pair</code>.

<img className="thumbnail" alt="horizonte - chaves SSH" src="/images/public-cloud/public-cloud-cross-functional/access-and-security-in-horizon/key_pairs.png" loading="lazy" />

Se deseja adicionar uma chave pré-existente, clique em <code className="action">Import Public Key</code>. Na nova janela, pode introduzir uma chave ou selecionar um ficheiro de chave.

Esta secção da interface contém instruções básicas. Para mais informações sobre as chaves SSH, consulte [este guia](/guides/public-cloud/compute/compute-creating-ssh-keys/).

- **Security Groups** (em <code className="action">Projeto</code> e <code className="action">Network</code>)

Os grupos de segurança são conjuntos de regras de filtragem que são aplicadas às interfaces de rede. Pode utilizá-las para restringir o acesso às instâncias a endereços IP e portas.

<img className="thumbnail" alt="horizon - grupos de segurança" src="/images/public-cloud/public-cloud-cross-functional/access-and-security-in-horizon/security_groups.png" loading="lazy" />

Adicione um grupo de segurança ao clicar no <code className="action">Create Security Group</code> e aplique regras personalizadas ou predefinidas através do botão <code className="action">Manage Rules</code> na tabela.
