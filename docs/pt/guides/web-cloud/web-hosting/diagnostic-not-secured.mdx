## Instruções

Para resolver esta anomalia, deverá:

1. determinar o alojamento ao qual está ligado o seu nome de domínio, para que possa intervir no bom servidor;
2. criar, ativar ou renovar um [certificado SSL](/guides/web-cloud/web-hosting/ssl-on-webhosting/) para o seu nome de domínio no alojamento em causa.

### 1: Verificar o alojamento associado ao seu domínio

#### Verificar o endereço IP do alojamento

As mensagens de erro mencionadas [acima](#objective) não significam necessariamente que o seu site está alojado numa das nossas [ofertas Web Cloud](https://www.ovhcloud.com/pt/web-hosting/). Por isso, verifique o endereço IP do servidor ao qual está ligado o seu [nome de domínio](https://www.ovhcloud.com/pt/domains/).

Para encontrar o endereço IP do seu [alojamento OVHcloud](https://www.ovhcloud.com/pt/web-hosting/), clique nos separadores abaixo para visualizar cada uma das **2** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página [Hosting plans](https://manager.eu.ovhcloud.com/#/web/hosting) e escolha o alojamento web correspondente.
    
    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    No marco **Informações gerais**, encontrará as referências **IPv4** e **IPv6**.

Anote o endereço IPv4 e/ou IPv6 e continue lendo o guia.
  </Tab>

#### Verificar o endereço IP na zona DNS

Agora tem de verificar que o endereço IP indicado na [Zona DNS](/guides/web-cloud/domains/dns-zone-edit/) corresponde ao do seu [alojamento Web Cloud](https://www.ovhcloud.com/pt/web-hosting/).

Aceda à [Área de Cliente OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pt/&ovhSubsidiary=pt) e aceda à secção <code className="action">Web Cloud</code>. Clique no menu <code className="action">Zonas DNS</code> e escolha o domínio em causa.

Nota do destino do tipo `A` para o seu domínio:

<img className="thumbnail" alt="zone-ip" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/dashboard-entry-a.png" loading="lazy" />

### 2: Verificar o certificado SSL do alojamento <a name="step2"></a>

No separador <code className="action">Informações gerais</code> do seu alojamento OVHcloud, verifique a parte `Certificado SSL`:

<img className="thumbnail" alt="ssl-certificate-in-general-tab" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/no-ssl-certificate.png" loading="lazy" />

#### Cenário 1: o seu alojamento não contém um certificado SSL

Ative um [certificado SSL](https://www.ovhcloud.com/pt/web-hosting/options/ssl/) no seu alojamento, seguindo as instruções deste [guia](/guides/web-cloud/web-hosting/ssl-on-webhosting/).

#### Cenário 2: o certificado SSL do seu alojamento não funciona

Se gerou um **certificado SSL "Let's Encrypt"**, ative a opção SSL do seu alojamento seguindo as instruções [deste guia](/guides/web-cloud/web-hosting/ssl-on-webhosting/).

Se dispõe de um **certificado SSL importado** e este não funcionar, contacte o seu fornecedor.

Se encomendou um dos **certificados SSL pagos** do nosso parceiro [SECTIGO](https://sectigo.com/), verifique se recebeu um e-mail que lhe propõe a sua renovação.
<br/>Se necessário, contacte o [suporte de SECTIGO](https://sectigo.com/support) a este respeito.

:::info
Para encontrar o conjunto dos e-mails enviados pelos nossos serviços, clique no canto superior direito do seu [Área de Cliente OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pt/&ovhSubsidiary=pt), depois em <code className="action">As minhas comunicações</code>.
