## Objetivo

Os alojamentos web funcionam numa infraestrutura partilhada chamada *cluster*. A OVHcloud dispõe de vários clusters nos quais estão repartidos vários alojamentos web.
Cada cluster está também dividido virtualmente em vários segmentos, designados *filers*, por razões de eficiência e segurança. Os filers contêm vários alojamentos web.
Durante a utilização do alojamento web, poderá ser necessário conhecer o número do cluster e/ou do filer onde se situa o alojamento web.

**Saiba como encontrar o número de cluster e o número do filer na sua localização.**

## Requisitos

- Ter um serviço de [alojamento web OVHcloud](https://www.ovhcloud.com/pt/web-hosting/).

## Instruções

Clique nos separadores abaixo para visualizar cada uma das **2** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página [Hosting plans](https://manager.eu.ovhcloud.com/#/web/hosting) e escolha o alojamento web correspondente.
    
    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    No quadro **Informações gerais** da página que se apresenta, recupere o número do cluster com a menção **Cluster** (3 algarismos compreendidos entre `0` e `9`) e o número do filer com a menção **Filer**.
