## Objetivo

Já não se recorda do nome da sua [oferta de alojamento web](https://www.ovhcloud.com/pt/web-hosting/)?
Deseja consultar os seus detalhes ou compará-la com outra oferta?

Ao longo da utilização dos seus serviços, pode ter necessidade do nome da sua oferta de alojamento web.

**Saiba como identificar o tipo de oferta de alojamento web que possui a partir da sua Área de cliente OVHcloud.**

## Requisitos

- Ter uma [oferta de alojamento web](https://www.ovhcloud.com/pt/web-hosting/).

{/* CP-NAV-START:web-hosting */}
---

### Acesso à Área de Cliente OVHcloud

- **Ligação direta:** [Hosting plans](https://manager.eu.ovhcloud.com/#/web/hosting)
- **Caminho de navegação:** <code className="action">Web Cloud</code> > <code className="action">Alojamentos</code> > Selecione o seu alojamento web

---
{/* CP-NAV-END:web-hosting */}

## Instruções

Clique nos separadores abaixo para visualizar cada uma das **2** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página [Hosting plans](https://manager.eu.ovhcloud.com/#/web/hosting) e escolha o alojamento web correspondente.
    
    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    No quadro **Subscrição**, encontrará a menção **Plano**.
    
    <img className="thumbnail" alt="Plan" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-plan-pro.png" loading="lazy" />

Abaixo desta menção, encontrará o nome da sua oferta de alojamento web (por exemplo: Perso, Pro, Performance, etc.).
  </Tab>
</Tabs>
