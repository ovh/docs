## Objetivo

A solução [Web Cloud Databases](/links/web/databases) pode conter várias bases de dados. Permite definir um ou vários utilizadores para a gestão e a utilização das suas bases de dados. Estes utilizadores podem ter direitos mais ou menos elevados, em função das suas funções no nível das suas bases de dados.
Durante a utilização do produto, pode ser levado a modificar os direitos de um utilizador no seu [Web Cloud Databases](/links/web/databases).

**Saiba como alterar os direitos de um utilizador no seu serviço Web Cloud Databases.**

## Requisitos

- Ter acesso à [Área de Cliente OVHcloud](/links/manager).
- Dispor de uma solução [Web Cloud Databases](/links/web/databases) e de um ou vários utilizadores.

## Na Prática

> [!info]
> Para criar um novo utilizador na sua solução Web Cloud Databases, consulte **Criar um utilizador** no nosso guia "[Criar bases de dados e utilizadores no servidor de bases de dados](/guides/web-cloud/web-cloud-databases/db-create-databases-users)".

Clique nas guias abaixo para exibir sucessivamente cada um dos **5** etapas.

<Tabs>
<Tab label="Etapa 1">

Aceda à [Área de Cliente OVHcloud](/links/manager) e aceda à secção `Web Cloud`.

![Web Cloud](/images/assets/screens/control-panel/product-selection/web-cloud.png)

</Tab>
<Tab label="Etapa 2">

Clique no menu `Web Cloud Databases` e escolha a solução Web Cloud Databases correspondente.

![Web Cloud Databases](/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases.png)

</Tab>
<Tab label="Etapa 3">

Na página que se abrir, clique no separador `Utilizadores e permissões`.

![Users and rights](/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/users-and-rights.png)

</Tab>
<Tab label="Etapa 4">

Na tabela, clique no botão `...` à direita do utilizador em questão e, a seguir, em `Gerir permissões`.

![Manage rights](/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/users-and-rights/manage-rights-user-alone.png)

</Tab>
<Tab label="Etapa 5">

Na nova página que vai aparecer, encontrará uma tabela que indica todas as bases de dados presentes na sua solução Web Cloud Databases. Consultará neste quadro o conjunto dos direitos de que o seu utilizador dispõe para cada uma das bases de dados presentes na sua solução Web Cloud Databases.

![Changing user rights](/images/assets/screens/control-panel/product-selection/web-cloud/web-cloud-databases/users-and-rights/changing-user-rights-db-alone.png)

É aqui que poderá modificar os direitos do seu utilizador para cada uma das suas bases de dados. Para isso, e para cada uma das bases de dados em causa, basta clicar nos círculos vazios correspondentes às permissões que pretende redefinir para o seu utilizador. A alteração ficará efetiva em alguns instantes.

</Tab>
</Tabs>
