## Objetivo

As soluções [Web Cloud Databases](/links/web/databases) podem ser ativadas gratuitamente a partir dos nossos [planos de alojamento web Performance](/links/web/hosting). Neste caso, elas serão associadas ao alojamento web a partir do qual foram ativadas. Durante a utilização dos serviços, pode ser necessário desassociar a solução Web Cloud Databases do alojamento web Performance ao qual está associada.

**Saiba como desassociar a sua solução Web Cloud Databases de um alojamento web.**

## Requisitos

- Ter um [instância Web Cloud Databases](/links/web/databases) associado a uma oferta de [alojamento web Performance](/links/web/hosting).
- Ter acesso à [Área de Cliente OVHcloud](/links/manager).
- Ser, no mínimo, o contacto "[Administrador](/guides/account-and-service-management/account-information/managing-contacts)" dos serviços sobre os quais deseja agir.

## Instruções

Clique nas guias abaixo para exibir sucessivamente cada uma das **4** etapas.

<Tabs>
<Tab label="Etapa 1">

Aceda à [Área de Cliente OVHcloud](/links/manager) e aceda à secção `Web Cloud`.

![Web Cloud](/images/assets/screens/control-panel/product-selection/web-cloud.png)

</Tab>
<Tab label="Etapa 2">

Clique no menu `Alojamentos` e escolha o alojamento web em causa.

![Web Hosting](/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png)

</Tab>
<Tab label="Etapa 3">

No **Configuração** encontrará uma **Web Cloud Databases**. Clique no botão `...` à direita e, a seguir, em `Desassociar`.

![Detach Web Cloud Databases](/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png)

</Tab>
<Tab label="Etapa 4">

Na nova página que vai aparecer, escolha o novo preço desejado para a sua solução Web Cloud Databases e siga as etapas indicadas até ao pagamento.

![Detach Web Cloud Databases](/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/detach-my-web-cloud-databases.png)

</Tab>
</Tabs>
