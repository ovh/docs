## Objetivo

As soluções [Web Cloud Databases](https://www.ovhcloud.com/pt/web-cloud/databases/) podem ser ativadas gratuitamente a partir dos nossos [planos de alojamento web Performance](https://www.ovhcloud.com/pt/web-hosting/). Neste caso, elas serão associadas ao alojamento web a partir do qual foram ativadas. Durante a utilização dos serviços, pode ser necessário desassociar a solução Web Cloud Databases do alojamento web Performance ao qual está associada.

**Saiba como desassociar a sua solução Web Cloud Databases de um alojamento web.**

## Requisitos

- Ter um [instância Web Cloud Databases](https://www.ovhcloud.com/pt/web-cloud/databases/) associado a uma oferta de [alojamento web Performance](https://www.ovhcloud.com/pt/web-hosting/).
- Ser, no mínimo, o contacto "[Administrador](/guides/account-and-service-management/account-information/managing-contacts/)" dos serviços sobre os quais deseja agir.

## Instruções

Clique nos separadores abaixo para visualizar cada uma das **3** etapas.

<Tabs>
  <Tab label="Etapa 1">
    Aceda à página [Hosting plans](https://manager.eu.ovhcloud.com/#/web/hosting) e escolha o alojamento web correspondente.
    
    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 2">
    No **Configuração** encontrará uma **Web Cloud Databases**. Clique no botão <code className="action">...</code> à direita e, a seguir, em <code className="action">Desassociar</code>.
    
    <img className="thumbnail" alt="Detach Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png" loading="lazy" />
  </Tab>
  <Tab label="Etapa 3">
    Na nova página que vai aparecer, escolha o novo preço desejado para a sua solução Web Cloud Databases e siga as etapas indicadas até ao pagamento.
    
    <img className="thumbnail" alt="Detach Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/detach-my-web-cloud-databases.png" loading="lazy" />
  </Tab>
</Tabs>


Depois de realizar as 4 etapas, a sua solução Web Cloud Databases será desligada dentro de algumas horas, no máximo.
