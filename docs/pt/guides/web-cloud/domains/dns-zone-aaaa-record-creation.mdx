## Objetivo

Deseja que o seu website esteja acessível através do seu nome de domínio? Para isso, o seu domínio deve apontar para o endereço IP do serviço no qual o seu website está situado (alojamento web, servidor dedicado, VPS, etc.). De seguida, deverá configurar a zona DNS ativa do seu domínio através de um registo DNS do tipo AAAA.

**Saiba como adicionar um registo DNS do tipo AAAA numa zona DNS gerida na OVHcloud para o seu domínio.**

:::info
Para alterar ou eliminar um registo DNS do tipo AAAA de uma zona DNS da OVHcloud, siga [este manual](/guides/web-cloud/domains/dns-zone-edit/).

:::


## Requisitos

- Ter um [nome de domínio](https://www.ovhcloud.com/pt/domains/).
- Ter uma zona DNS associada a este domínio na OVHcloud.

## Instruções

:::warning
A adição, modificação ou eliminação de registos DNS numa zona DNS ativa é uma operação sensível. Se não tiver a certeza, entre em contacto com um [fornecedor especializado](https://partner.ovhcloud.com/pt/directory/).

:::


### Adicionar um registo DNS do tipo AAAA para um domínio

Clique nos separadores abaixo para visualizar cada um dos **5** passos.

<Tabs>
  <Tab label="Passo 1">
    Aceda à página [Zonas DNS](https://manager.eu.ovhcloud.com/#/web/zone) e escolha o domínio correspondente.
    
    <img className="thumbnail" alt="DNS zones" src="/images/assets/screens/control-panel/product-selection/web-cloud/dns-zones.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 2">
    Clique no botão <code className="action">Adicionar uma entrada</code>.
  </Tab>
  <Tab label="Passo 3">
    Na janela que aparecer, selecione o campo de apontamento do tipo <code className="action">AAAA</code>.
  </Tab>
  <Tab label="Passo 4">
    Introduza no campo `Alvo *` o endereço IP (por exemplo: `2001:db8:1:1b00:203:0:113:0`) do serviço em que se situa o seu website (alojamento web, servidor dedicado, VPS, etc.) e clique em <code className="action">Seguinte</code>.
  </Tab>
  <Tab label="Passo 5">
    Verifique o resumo e clique em <code className="action">Validar</code>. Aguarde até **24** horas para que a propagação da adição na rede DNS seja plenamente efetiva.
  </Tab>
</Tabs>

### Adicionar um registo DNS do tipo AAAA para o subdomínio de um domínio

Clique nos separadores abaixo para visualizar cada um dos **5** passos.

<Tabs>
  <Tab label="Passo 1">
    Aceda à página [Zonas DNS](https://manager.eu.ovhcloud.com/#/web/zone) e escolha o domínio correspondente.
    
    <img className="thumbnail" alt="DNS zones" src="/images/assets/screens/control-panel/product-selection/web-cloud/dns-zones.png" loading="lazy" />
  </Tab>
  <Tab label="Passo 2">
    Clique no botão <code className="action">Adicionar uma entrada</code>.
  </Tab>
  <Tab label="Passo 3">
    Na janela que aparecer, selecione o campo de apontamento do tipo <code className="action">AAAA</code>.
  </Tab>
  <Tab label="Passo 4">
    Introduza no campo `Subdomínio` o subdomínio em causa (por exemplo: `www` para o subdomínio `www.domain.tld`) e, no campo `Alvo *`, o endereço IP (por exemplo: `2001:db8:1:1b00:203:0:113:0`) do serviço em que se situa o seu website (alojamento web, servidor dedicado, VPS, etc.). Clique em <code className="action">Seguinte</code>.
  </Tab>
  <Tab label="Passo 5">
    Verifique o resumo e clique em <code className="action">Validar</code>. Aguarde até **24** horas para que a propagação da adição na rede DNS seja plenamente efetiva.
  </Tab>
</Tabs>
