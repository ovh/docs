## Sumário

A solução [Managed Bare Metal](https://www.ovhcloud.com/pt/managed-bare-metal/) permite-lhe adicionar recursos faturados à hora.

**Este manual descreve como adicionar um recurso com faturação à hora a partir da interface vSphere do Managed Bare Metal.**

## Requisitos

* Dispor do serviço [Managed Bare Metal](https://www.ovhcloud.com/pt/managed-bare-metal/).
* Dar ao utilizador a autorização [“Adição de recursos”](/guides/bare-metal-cloud/managed-bare-metal/change-user-rights/) quanto ao datacenter em causa a partir da [Área de Cliente OVH](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pt/&ovhSubsidiary=pt).
* Estabelecer uma ligação ao cliente vSphere.

## Instruções

### Selecionar o recurso.

De modo a aceder à interface que permite adicionar recursos horários, deve selecionar o datacenter e, a seguir, clicar no separador <code className="action">Configure</code>.

<img className="thumbnail" alt="Adicionar host" src="/images/bare-metal-cloud/managed-bare-metal/adding-hourly-resources/addhost_ess_01.png" loading="lazy" />

Neste exemplo, vamos adicionar um servidor host faturado à hora. Uma vez feita a escolha do modelo, clique no botão <code className="action">Next</code>. Para adicionar um datastore, basta selecionar o separador <code className="action">Add storage</code>.

<img className="thumbnail" alt="Adicionar host" src="/images/bare-metal-cloud/managed-bare-metal/adding-hourly-resources/addhost_ess_02.png" loading="lazy" />

### Validar a encomenda

Para validar e finalizar a encomenda, clique novamente em <code className="action">Next</code>.

<img className="thumbnail" alt="Validar encomenda" src="/images/bare-metal-cloud/managed-bare-metal/adding-hourly-resources/addhost_ess_03.png" loading="lazy" />

### Acompanhar a instalação

Quando a encomenda estiver validada, pode seguir a operação.

<img className="thumbnail" alt="instalação" src="/images/bare-metal-cloud/managed-bare-metal/adding-hourly-resources/addhost_ess_04.png" loading="lazy" />

Por outro lado, surgirá uma tarefa nas tarefas recentes do vSphere. Também ela lhe permitirá seguir a adição do recurso.
