## Objetivo

O modo rescue é uma ferramenta fornecida pela OVHcloud que permite iniciar num sistema operativo temporário. Tem como objetivo diagnosticar e resolver os problemas no seu servidor.

O funcionamento geral do modo rescue é descrito no nosso guia [Como ativar e utilizar o modo rescue](/guides/bare-metal-cloud/dedicated-servers/rescue-mode/).

A opção **Windows customer rescue system** só está disponível para os servidores dedicados nos quais está instalado um sistema operativo **Windows Server**. São aplicáveis as seguintes condições:

- O sistema rescue para Windows (`rescue-customer-windows`) funciona numa máquina virtual (VM) lançada a partir do sistema rescue client (`rescue-customer`, baseado em Debian GNU/Linux).
- Os discos do servidor estão ligados à VM com *passthrough*. Assim, é possível aceder aos mesmos.
- Os outros componentes do servidor ficarão inacessíveis (CPU, RAM, NIC, RAID).
- A rede é montada com *passthrough* mas sem acesso direto ao adaptador de rede. A VM porta o endereço IP e o endereço MAC do servidor *bare metal*.

:::warning
Certifique-se de que efetua um backup dos seus dados se ainda não dispõe de um backup recente.

Se tiver serviços em produção no seu servidor, o modo rescue interrompe-os-á enquanto a máquina não for reiniciada em modo normal.

:::


**Saiba como iniciar um servidor no SO Windows Client.**

## Requisitos

- Microsoft Windows instalado no seu [servidor dedicado](https://www.ovhcloud.com/pt/bare-metal/)
- Pelo menos 16 GB de RAM instaladas no servidor

## Instruções

### Ativação do modo rescue para Windows

Clique no nome do seu servidor para abrir o separador <code className="action">Informações gerais</code>.

<a name="netboot"></a>

Na casa **Informações gerais**, clique no botão <code className="action">...</code> ao lado de `Boot`. Clique em <code className="action">Alterar</code> no menu contextual.

<img className="thumbnail" alt="Alterar o modo de arranque" src="/images/bare-metal-cloud/dedicated-servers/rescue-customer-windows/rescue-mode-001.png" loading="lazy" />

Na página **Alterar o netboot**, selecione <code className="action">Fazer boot em modo rescue</code>.

Selecione <code className="action">Windows customer rescue system</code> no menu pendente.

<img className="thumbnail" alt="Alterar o modo de arranque" src="/images/bare-metal-cloud/dedicated-servers/rescue-customer-windows/manager-rescue-windows-menu.png" loading="lazy" style={{ maxWidth: '800px' }} />

O e-mail de notificação do modo rescue, bem como os seus dados de acesso, serão enviados para o endereço de e-mail de contacto da sua conta OVHcloud. Para utilizar outro endereço de e-mail, introduza-o no campo `Receber os dados de acesso ao modo para o e-mail:`.

Clique em <code className="action">Seguinte</code>.

Na etapa **Resumo**, clique em <code className="action">Validar</code>.

<img className="thumbnail" alt="Summary" src="/images/bare-metal-cloud/dedicated-servers/rescue-customer-windows/winresc_summ.png" loading="lazy" />

Já deverá ter uma notificação relativa ao parâmetro `Netboot` no separador <code className="action">Informações gerais</code>.

<img className="thumbnail" alt="Netboot" src="/images/bare-metal-cloud/dedicated-servers/rescue-customer-windows/rescue-mode-006.png" loading="lazy" />

O último passo consiste em reiniciar o servidor. Clique no botão <code className="action">...</code> ao lado de "Estado" na zona **Estado dos serviços** e, a seguir, clique em <code className="action">Reiniciar</code>. Clique em <code className="action">Validar</code> na janela pop-up.

<img className="thumbnail" alt="Reboot" src="/images/assets/screens/control-panel/product-selection/bare-metal-cloud/dedicated-servers/general-information/rebooting-your-server.png" loading="lazy" />

Este *hard reboot* demorará alguns minutos a terminar. Pode verificar o estado atual no separador <code className="action">Tarefas</code>.

:::info
Depois de concluir as suas ações em modo rescue, não se esqueça de redefinir o parâmetro `Netboot` em <code className="action">Fazer boot no disco rígido</code> antes de reiniciar o servidor.

:::


### Aceder ao seu servidor em modo rescue

Depois de receber um e-mail a informar que o modo rescue está ativado, poderá aceder ao sistema através do modo rescue do Windows e aceder ao servidor.  
Este e-mail também estará disponível no seu [Área de Cliente OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pt/&ovhSubsidiary=pt) assim que for enviado. Clique no seu ID de cliente no canto superior direito e, em seguida, selecione <code className="action">E-mails de serviço</code>.

Para efetuar uma sessão remota no sistema em modo rescue do Windows, precisará das seguintes informações de identificação:

- Endereço IP do servidor
- Nome de utilizador da conta de administrador temporário (`Administrator`)
- Palavra-passe da conta de administrador temporário

Pode utilizar os seguintes métodos de ligação para aceder ao servidor através do sistema em modo Rescue do Windows:

- Remote Desktop Protocol (RDP)
- KVM over IP (se o seu servidor o permitir)
- OpenSSH (componente oficial do Windows Server)

#### SSH

<details>

<summary>Expanda esta secção</summary>


Abra a aplicação de linha de comandos no seu dispositivo local e introduza este comando:

```bash
ssh Administrator@SERVER_IP
```

Exemplo:

```bash
ssh Administrator@203.0.113.100
```

Introduza a palavra-passe do Modo Rescue Temporário quando tal lhe for solicitado. Exemplo:

```console
Administrator@ns9356771.ip-203-0-113.eu's password:
administrator@WINRESCUEOVH C:\Users\Administrator>
```

Encontre mais informações sobre as ligações SSH no nosso [guia de introdução ao SSH](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction/).  
Também pode utilizar qualquer ferramenta de ligação SSH, como [PuTTY](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows/).

</details>
