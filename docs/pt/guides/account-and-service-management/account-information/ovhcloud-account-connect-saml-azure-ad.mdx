## Objetivo

Pode utilizar a autenticação **SSO** (*Single Sign-On*) para se ligar à sua conta OVHcloud. Para ativar estas ligações, a sua conta e o seu Entra ID (anteriormente Azure Active Directory) devem ser configurados através do SAML (*Security Assertion Markup Language*).

**Saiba como associar a sua conta OVHcloud a um Entra ID externo.**

## Requisitos

- Ter acesso às funções de **Administrador de aplicações** e **Administrador de utilizadores** de um serviço Entra ID
- Ter uma [conta OVHcloud](/guides/account-and-service-management/account-information/ovhcloud-account-creation/)

### Acesso à Área de Cliente OVHcloud

- **Ligação direta:** [SAML SSO](https://manager.eu.ovhcloud.com/#/iam/identities/sso)
- **Caminho de navegação:** <code className="action">Identidade, Segurança e Operações</code> > <code className="action">Users</code> > <code className="action">SSO connection</code>

## Instruções

:::info
Para que um prestador de serviços (por exemplo, a sua conta OVHcloud) estabeleça uma ligação SSO com um fornecedor de identidade (por exemplo, o seu Entra ID), deve estabelecer uma relação de confiança mútua ao registar a ligação SSO em ambos os serviços.

:::


### Utilizadores e grupos Entra ID

O seu Entra ID atua como fornecedor de identidade. Os pedidos de autenticação da sua conta OVHcloud só serão aceites se o tiver declarado como terceiro de confiança.

Concentremo-nos, por um momento, nas identidades do lado do fornecedor de identidade.

#### Utilizadores Entra ID

Para começar, aceda ao painel de controlo Entra ID.

<img className="thumbnail" alt="Painel de controlo Entra ID" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_dashboard.png" loading="lazy" />

A seguir, clique em <code className="action">Users</code> no menu à esquerda.

<img className="thumbnail" alt="Utilizador do menu Entra ID" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_menu_user.png" loading="lazy" />

Crie tantos utilizadores quantos desejar e/ou verifique os seus utilizadores clicando em cima.

Neste exemplo, será utilizado o utilizador **John Smith**.

<img className="thumbnail" alt="Utilizador Entra ID" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_user.png" loading="lazy" />

Quando é efetuada uma autenticação SSO, a identidade de **John Smith** é fornecida pela Entra ID à conta OVHcloud. No entanto, é necessário que essa identidade contenha pelo menos um grupo. Se nenhum grupo existir, veja abaixo como criar um grupo para adicionar **John Smith**.

#### Grupos Entra ID

Clique em <code className="action">Groups</code> no menu à esquerda.

<img className="thumbnail" alt="Grupos de menus Entra ID" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_menu_groups.png" loading="lazy" />

Clique em <code className="action">New group</code> no menu superior e introduza todas as informações necessárias.

Para este exemplo, utilizar-se-á o grupo **manager@ovhcloudsaml**.

<img className="thumbnail" alt="Entra ID Group etapa 1" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_group_1.png" loading="lazy" />

Clique no botão <code className="action">Create</code> para apresentar todas as informações sobre este grupo.

<img className="thumbnail" alt="Entra ID Group etapa 2" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_group_2.png" loading="lazy" />

Agora, os utilizadores que serão utilizados para a autenticação SSO devem ser adicionados a um grupo.

Neste exemplo, associemos o utilizador **John Smith** ao grupo **manager@ovhcloudsaml**.

Na interface do grupo selecionado, clique em <code className="action">Members</code> no menu à esquerda e, a seguir, em <code className="action">Add members</code> no menu superior.

<img className="thumbnail" alt="Entra ID Group User Assignment Passo 1" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_group_user_assignment_1.png" loading="lazy" />

Selecione o utilizador a adicionar neste grupo e clique no botão <code className="action">Select</code>.

<img className="thumbnail" alt="Entra ID Group User Assignment Passo 2" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_group_user_assignment_2.png" loading="lazy" />

Agora, o utilizador é atribuído ao grupo.

Para efetuar as autenticações SSO, deve ser criada uma aplicação Entra ID.

A autenticação única deve ser configurada nesta aplicação.

### Aplicações Entra ID

Em primeiro lugar, crie uma aplicação se ela ainda não existir.

#### Criar uma aplicação Entra ID

Clique em <code className="action">Enterprise applications</code> no menu à esquerda.

<img className="thumbnail" alt="Aplicações de menu Entra ID" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_menu_applications.png" loading="lazy" />

Clique em <code className="action">New application</code> no menu superior.

<img className="thumbnail" alt="Aplicações Entra ID etapa 1" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_applications_1.png" loading="lazy" />

Clique em <code className="action">Create your own application</code> no menu superior.

<img className="thumbnail" alt="Aplicações Entra ID etapa 2" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_applications_2.png" loading="lazy" />

Selecione <code className="action">Non-Gallery</code> no menu à esquerda e clique no botão <code className="action">Create</code>.

<img className="thumbnail" alt="Aplicações Entra ID etapa 3" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_applications_3.png" loading="lazy" />

Os detalhes da aplicação serão apresentados.

<img className="thumbnail" alt="Aplicações Entra ID etapa 4" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_applications_4.png" loading="lazy" />

A aplicação Entra ID foi criada. Os utilizadores que pretendam efetuar autenticações SSO através desta aplicação devem agora ser acrescentados.

#### Aplicação Entra ID - Afetação de utilizadores

:::info
Para que um utilizador efetue uma autenticação SSO a partir de uma aplicação Entra ID, deve ser adicionado a esta aplicação. Encontre aqui como adicionar um utilizador a uma aplicação Entra ID.

No entanto, é melhor adicionar um grupo de utilizadores do que utilizadores se tiver **Entra ID Premium**.

:::


Clique em <code className="action">Users and groups</code> no menu à esquerda e, em seguida, em <code className="action">Add user/group</code> no menu superior.

A seguir, clique na secção <code className="action">Users</code>, selecione o utilizador a adicionar à aplicação e clique no botão <code className="action">Select</code>.

<img className="thumbnail" alt="Entra ID Application User Assignment Passo 1" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_application_user_assignment_1.png" loading="lazy" />

<img className="thumbnail" alt="Entra ID Application User Assignment Passo 2" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_application_user_assignment_2.png" loading="lazy" />

A aplicação é criada, o utilizador é atribuído, só precisa de configurar o SSO via SAML.

#### Entra ID aplicação SSO

Consulte o conjunto através do botão <code className="action">Overview</code> no menu à esquerda e clique na secção <code className="action">Set up single sign on</code> on.

<img className="thumbnail" alt="Entra ID SSO etapa 1" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_sso_1.png" loading="lazy" />

Clique na secção <code className="action">SAML</code>.

<img className="thumbnail" alt="Entra ID SSO etapa 2" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_sso_2.png" loading="lazy" />

Clique em <code className="action">Upload metadata file</code> no menu superior.

<img className="thumbnail" alt="Entra ID SSO etapa 3" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_sso_3.png" loading="lazy" />

Clique no ícone do botão <code className="action">Select a file</code>, selecione o ficheiro de metadados OVHcloud Service Provider e clique no botão <code className="action">Add</code>.

Pode obter o ficheiro de metadados adequado através das seguintes ligações:

- [Metadados da região da UE](https://www.ovh.com/auth/sso/saml/sp/metadata.xml)
- [Metadados de região CA](https://ca.ovh.com/auth/sso/saml/sp/metadata.xml)

Faça o download do ficheiro de metadados, terá necessidade dele mais tarde.

<img className="thumbnail" alt="Entra ID SSO etapa 5" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_sso_5.png" loading="lazy" />

Aparecerá a configuração SAML.

<img className="thumbnail" alt="Entra ID SSO etapa 6" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_sso_6.png" loading="lazy" />

Na secção <code className="action">Attributes & Claims</code>, clique no botão <code className="action">Edit</code>.

<img className="thumbnail" alt="Entra ID SSO etapa 9" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_sso_9.png" loading="lazy" />

Adicione o atributo UPN (User Principal Name) às informações SAML para informar a OVHcloud do e-mail do utilizador. Esta etapa é indispensável.

Clique em <code className="action">Add a new claim</code> no menu superior.

No campo <code className="action">Name</code>, introduza o valor `http://schemas.xmlsoap.org/ws/2005/05/identity/claims/upn`.

No campo <code className="action">Source attribute</code>, introduza <code className="action">user.mail</code>.

A sua interface deverá ser bastante semelhante à seguinte captura de ecrã:

<img className="thumbnail" alt="Entra ID SSO entrado UPN" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_sso_9bis.png" loading="lazy" />

Clique em <code className="action">Save</code>

Declare o atributo utilizado para o grupo do utilizador.

Clique em <code className="action">Add a group claim</code> no menu superior.

<img className="thumbnail" alt="Entra ID SSO etapa 10" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_sso_10.png" loading="lazy" />

Selecione <code className="action">Security groups</code> e **Group ID** na <code className="action">Source attribute</code> e clique no botão <code className="action">Save</code>.

<img className="thumbnail" alt="Entra ID SSO etapa 11" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_sso_11.png" loading="lazy" />

A reivindicação de **groups** deve agora constar da lista.

Copie e registe o valor do **Claim name** algures (por exemplo, um bloco de notas), necessitará dele mais tarde.

<img className="thumbnail" alt="Entra ID SSO etapa 12" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_sso_12.png" loading="lazy" />

Na secção <code className="action">SAML certificates</code>, copie o valor do campo <code className="action">App Federation Metadata Url</code>.

Utilize esta ligação para descarregar o ficheiro de metadados da aplicação Entra ID para o utilizar mais tarde na conta OVHcloud.

<img className="thumbnail" alt="Entra ID SSO etapa 8" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_sso_8.png" loading="lazy" />

### Criar a confiança de uma conta OVHcloud e configurar a ligação

A adição da sua aplicação Entra ID como fornecedor de identidade aprovado é efetuada na página [SAML SSO](https://manager.eu.ovhcloud.com/#/iam/identities/sso) da sua Área de Cliente OVHcloud, onde poderá fornecer os metadados do fornecedor de identidade.

#### Criar confiança na OVHcloud

Complete o campo **Nome de Atributo de utilizador** com a aplicação Entra ID **UPN** nome do pedido e no campo **Nome de atributo de grupo** com o valor de nome de pedido **groups** guardado antes.

Preencha os metadados XML da sua aplicação Entra ID a partir do ficheiro anteriormente registado.

É possível conservar os utilizadores locais marcando a caixa `Manter os utilizadores da OVHcloud ativos`.

Clique no botão <code className="action">Validar</code>.

<img className="thumbnail" alt="Ovhcloud SSO step 1" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/ovhcloud_sso_1.png" loading="lazy" />

A adição da sua aplicação Entra ID como fornecedor de identidade foi estabelecida, mas deve ainda assim adicionar grupos à sua conta OVHcloud.

:::warning
Se tentar conectar-se através de SSO, é provável que apareça uma mensagem de erro "`Not in valid groups`".

A sua conta OVHcloud verifica se o utilizador autenticado pertence a um grupo existente na conta.

:::


Para resolver esta situação, verifique o atributo "Group" devolvido pela sua aplicação Entra ID: o campo **Object Id**.

#### Declaração dos grupos OVHcloud

<img className="thumbnail" alt="Entra ID Group etapa 2" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_group_2.png" loading="lazy" />

Para adicionar um grupo, aceda à secção <code className="action">Identidades</code> e aceda ao separador <code className="action">Grupos de utilizadores</code>. De seguida, clique no botão <code className="action">Declarar um grupo</code> :

<img className="thumbnail" alt="Grupos de gestão de utilizadores Ovhcloud etapa 1" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/ovhcloud_sso_menu_1.png" loading="lazy" />

Introduza o nome do grupo e selecione o privilégio associado e clique no botão <code className="action">Validar</code>.

<img className="thumbnail" alt="Grupos de gestão de utilizadores Ovhcloud etapa 2" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/ovhcloud_sso_menu_2.png" loading="lazy" />

O grupo criado deve constar da lista.

<img className="thumbnail" alt="Grupos de gestão de utilizadores Ovhcloud etapa 3" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/ovhcloud_sso_menu_3.png" loading="lazy" />

Atenção: se conceder o privilégio `Nenhum`, será necessário atribuir permissões a este grupo através das [políticas IAM](/guides/account-and-service-management/account-information/iam-policy-ui/).

### Ligação via SSO

Na [página de identificação da OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pt/&ovhSubsidiary=pt), introduza o seu [identificador de cliente](/guides/account-and-service-management/account-information/ovhcloud-account-creation#qual-e-o-meu-identificador-de-cliente/) seguido de **/idp** sem password e clique no botão <code className="action">Login</code>.

<img className="thumbnail" alt="Ovhcloud SSO Login step 1" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/ovhcloud_sso_login_1.png" loading="lazy" />

De seguida, será redirecionado para a página de ligação à sua aplicação Entra ID. Selecione <code className="action">Use another account</code>.

<img className="thumbnail" alt="Entra ID Login etapa 1" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_login_1.png" loading="lazy" />

Introduza o e-mail do utilizador da aplicação Entra ID e clique no botão <code className="action">Next</code>.

<img className="thumbnail" alt="Entra ID Login etapa 2" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_login_2.png" loading="lazy" />

Introduza a palavra-passe do utilizador da aplicação Entra ID e clique no botão <code className="action">Sign In</code>.

<img className="thumbnail" alt="Entra ID Login etapa 3" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/azure_ad_login_3.png" loading="lazy" />

Já está ligado com o mesmo nichandle, mas através do utilizador Ative Diretory e utilizando o seu SSO de aplicação Entra ID.

<img className="thumbnail" alt="Ovhcloud SSO Login step 2" src="/images/account-and-service-management/account-information/ovhcloud-account-connect-saml-azure-ad/ovhcloud_sso_login_2.png" loading="lazy" />

Se o seu e-mail não aparecer abaixo de `Connected via SSO`, isto significa que não configurou corretamente o atributo **UPN** e que uma parte das funcionalidades não poderá funcionar.
