## Objetivo

O serviço NAS-HA da OVHcloud permite-lhe gerir um armazenamento de ficheiros acessível a partir de uma rede.

**Este manual explica-lhe como gerir as partições do seu serviço NAS-HA através da API OVHcloud.**

## Requisitos

- Um serviço [NAS-HA OVHcloud](https://www.ovhcloud.com/pt/storage-solutions/nas-ha/)
- Consulte o nosso guia dos [primeiros passos com a API OVHcloud](/guides/manage-and-operate/api/first-steps/) para se familiarizar com a APIv6 OVHcloud

## Instruções

Todas as rotas API deste guia estão disponíveis na secção */dedicated/nasha*: [https://api.ovh.com/console/#/dedicated/nasha](https://api.ovh.com/console/#/dedicated/nasha).

:::info
Ao utilizar a API, todos os campos assinalados com um asterisco (\*) são obrigatórios.

:::


### Obter informações sobre o seu serviço

Todos os seus serviços ativos podem ser recuperados utilizando a seguinte rota:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha"} />


### Lista de todas as partições

Utilize a seguinte rota para recuperar as partições de um serviço:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nome interno do seu serviço NAS |

### Obter as propriedades de uma partição

Para visualizar os detalhes de uma partição, utilize a seguinte rota:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nome interno do serviço NAS-HA |
| `partitionName` | Yes | Nome da partição |

### Recuperação das estatísticas de uma partição

Utilize a seguinte rota para recuperar as informações de utilização de uma partição:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/use"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nome interno do serviço NAS-HA |
| `partitionName` | Yes | Nome da partição |
| `type` | Yes | O tipo de estatística a recuperar: *size*, *used* ou *usedbysnapshots* |

### Criação de uma partição

Utilize a seguinte rota para criar uma nova partição:

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nome interno do seu serviço NAS |
| `partitionDescription` |  | Descrição facultativa |
| `partitionName` | Yes | Um nome para a partição |
| `protocol` | Yes | *NFS*, *CIFS* ou *NFS_CIFS* para ambos |
| `size` | Yes | O tamanho da partição |

Escolha `NFS` como protocol e um tamanho de `10` Gigabytes, por exemplo.

### Modificar as propriedades de uma partição

Para alterar uma partição, utilize a seguinte rota:

<Api version="v1" section="/dedicated/nasha" method="PUT" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nome interno do seu serviço NAS |
| `partitionName` | Yes | Nome da partição |
| `partitionDescription` |  | A nova descrição |
| `size` |  | O novo tamanho da partição |

### Obter os parâmetros ZFS de uma partição

Utilize a seguinte rota para recuperar os parâmetros ZFS:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/options"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nome interno do seu serviço NAS |
| `partitionName` | Yes | Nome da partição |

### Modificação dos parâmetros ZFS de uma partição

:::warning
Todos os parâmetros ZFS predefinidos são otimizados. Não é aconselhável alterar estes parâmetros.

:::


Para alterar os parâmetros ZFS, utilize a seguinte rota:

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/options"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nome interno do seu serviço NAS |
| `partitionName` | Yes | Nome da partição |
| `atime` |  | Parâmetro de atualização do tempo de acesso: *on* (default) ou *off* |
| `recordsize` |  | Tamanho máximo do bloco: *131072* (por defeito), *16384*, *32768*, *4096*, *65536* ou *8129* |
| `sync` |  | Parâmetro de sincronização do ficheiro: *always*, *disabled* ou *standard* (valor predefinido) |

### Eliminação de uma partição

Utilize a seguinte rota para eliminar uma partição:

<Api version="v1" section="/dedicated/nasha" method="DELETE" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nome interno do serviço NAS-HA |
| `partitionName` | Yes | Nome da partição |
