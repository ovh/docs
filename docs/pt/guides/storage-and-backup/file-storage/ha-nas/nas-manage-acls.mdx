## Objetivo

O serviço NAS-HA da OVHcloud permite-lhe gerir um armazenamento de ficheiros acessível a partir de uma rede.

**Este guia explica como gerir o ACL de uma partição NAS-HA através da API OVHcloud.**

## Requisitos

- Um serviço [NAS-HA OVHcloud](https://www.ovhcloud.com/pt/storage-solutions/nas-ha/)
- Consulte o nosso guia dos [primeiros passos com a API OVHcloud](/guides/manage-and-operate/api/first-steps/) para se familiarizar com a APIv6 OVHcloud

## Instruções

Todas as rotas API deste guia estão disponíveis na secção */dedicated/nasha*: [https://api.ovh.com/console/#/dedicated/nasha](https://api.ovh.com/console/#/dedicated/nasha).

:::info
Ao utilizar a API, todos os campos assinalados com um asterisco (\*) são obrigatórios.

:::


### Obter informações sobre o seu serviço

Todos os seus serviços ativos podem ser recuperados utilizando a seguinte rota:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha"} />


:::warning
O acesso é recusado por predefinição, exceto se for concedido através do ACL. Apenas os endereços IP ligados aos seus serviços OVHcloud podem ser adicionados.

:::


### Obter o ACL de uma partição

Para obter os endereços IP que podem aceder à partição, utilize a seguinte rota:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/access"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nome interno do serviço NAS-HA |
| `partitionName` | Yes | Nome da partição |

### Recuperação de todos os endereços IP elegíveis

Pode verificar os endereços IP elegíveis para um acesso através das chamadas API seguintes:

<Api version="v1" section="/dedicated/nasha" method="GET" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/authorizableBlocks"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nome interno do seu serviço NAS-HA |
| `partitionName` | Yes | Nome da partição |

### Adicionar uma entrada ACL

Para criar uma nova entrada ACL que lhe permita ligar-se à sua partição, utilize a seguinte rota:

<Api version="v1" section="/dedicated/nasha" method="POST" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/access"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nome interno do serviço NAS-HA |
| `partitionName` | Yes | Nome da partição |
| `ip` | Yes | O endereço IP ou a gama de acesso |
| `type` | Yes | Tipo de acesso ACL para esta entrada: *readonly* ou *readwrite* |

:::info
Utilize a notação CIDR para as gamas IP, por exemplo: 192.0.2.0/24.

:::


### Eliminação de uma entrada ACL

Para eliminar um endereço IP ou um intervalo de endereços do ACL, utilize a seguinte rota:

<Api version="v1" section="/dedicated/nasha" method="DELETE" route={"/dedicated/nasha/\{serviceName\}/partition/\{partitionName\}/access/\{ip\}"} />


| Parameter | Required | Description |
|-----------|----------|-------------|
| `serviceName` | Yes | Nome interno do serviço NAS-HA |
| `partitionName` | Yes | Nome da partição |
| `ip` | Yes | O endereço IP ou a gama a recusar |
