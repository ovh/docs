## Objetivo

Os serviços Enterprise File Storage podem ser geridos [através das API OVHcloud](/guides/storage-and-backup/file-storage/enterprise-file-storage/netapp-quick-start/) ou a partir da Área de Cliente OVHcloud.

**Saiba como gerir os volumes e as snapshots de Enterprise File Storage na sua Área de Cliente.**

## Requisitos

- Ter um serviço Enterprise File Storage na sua conta OVHcloud. O serviço pode ser encomendado a partir da [página produto](https://www.ovhcloud.com/pt/storage-solutions/enterprise-file-storage/) ou a partir da [Área de Cliente OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.pt/&ovhSubsidiary=pt).

## Instruções <a name="instructions"></a>

Selecione o seu serviço na lista.

<img className="thumbnail" alt="Informações gerais" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise01.png" loading="lazy" />

O separador <code className="action">Informações gerais</code> apresenta informações técnicas sobre o seu serviço, informações gerais sobre a subscrição e um atalho para [criar um volume](#create_volume).

:::info
Consulte a página [Conceitos](/guides/storage-and-backup/file-storage/enterprise-file-storage/netapp-concepts/) para obter informações detalhadas sobre as propriedades técnicas da solução Enterprise File Storage.

:::


### Gestão dos volumes <a name="manage_volume"></a>

Clique no separador <code className="action">Volumes</code>. O quadro apresenta todos os volumes criados para o serviço selecionado. Pode clicar num identificador de volume para abrir a sua [página de gestão](#modify_volume). 

<img className="thumbnail" alt="Volumes" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise02.png" loading="lazy" />

Pode efetuar várias ações clicando no botão <code className="action">...</code> em cada linha da tabela.

- **Modificar o volume**: Abre a secção "[Informações gerais](#modify_volume)" do volume.
- **Criar uma snapshot**: abra a secção "[Backups](#snapshots)" para efetuar uma snapshot manual do volume.
- **Restaurar a última snapshot** : abre a secção " [Snapshots](#snapshots) " bem como uma janela que permite restaurar o volume.
- **Gerir as snapshots**: abre a secção "[Backups](#snapshots)" do volume.
- **Gerir IP Access (ACL)**: Abre a secção "[ACL](#access_control)" que permite gerir o controlo de acesso ao volume.
- **Alterar tamanho** : abre uma janela que permite alterar o tamanho do volume.
- **Eliminar o volume**: permite eliminar este volume quando a ação for confirmada na janela que aparecer.

#### Criação de um volume <a name="create_volume"></a>

Clique no botão <code className="action">Criar um volume</code>. Na nova janela, insira o nome e a descrição do volume. Determine o tamanho em GB e clique em <code className="action">Criar um volume</code> para validar a criação.

<img className="thumbnail" alt="Volume de criação" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise03.png" loading="lazy" />

#### Modificação de um volume <a name="modify_volume"></a>

Clique num ID de volume no quadro para abrir a página de gestão deste volume.

O separador <code className="action">Informações gerais</code> apresenta os detalhes do volume, bem como instruções pormenorizadas sobre a ligação ao volume, incluindo os parâmetros individuais.

<img className="thumbnail" alt="Gestão dos volumes" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise04.png" loading="lazy" />

A partir deste separador, também pode alterar o nome e a descrição do volume.

#### Eliminação de um volume <a name="delete_volume"></a>

Pode eliminar um volume clicando no botão <code className="action">...</code> na tabela no separador <code className="action">Volumes</code>, e depois em <code className="action">Eliminar o volume</code>.

<img className="thumbnail" alt="Volume delete" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise05.png" loading="lazy" />

Digite `DELETE` e clique em <code className="action">Confirmar</code> para validar a eliminação.

#### Criação e gestão das snapshots de um volume <a name="snapshots"></a>

:::info
Snapshots nutzen die Speicherkapazität Ihrer Enterprise File Storage-Lösung. Standardmäßig sind 5 % der Größe eines Volumes immer für Snapshots reserviert.

:::


O separador <code className="action">Snapshots</code> regista todas as snapshots criadas para o volume selecionado.

<img className="thumbnail" alt="Snapshots" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise06.png" loading="lazy" />

No mesmo separador, pode também visualizar todas as [políticas de snapshots](#snapshot_policy) criadas para o serviço e aplicá-las a esse volume.

<img className="thumbnail" alt="Volume Snapshot Policy Management" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise07.png" loading="lazy" />

Clique na linha de regra para consultar os detalhes da programação das snapshots. Selecione uma política através do botão de seleção dedicado e, em seguida, clique no botão <code className="action">Aplicar a política</code> na parte inferior da tabela.

Para configurar as suas [políticas de snapshot](#snapshot_policy), volte à secção [Gestão de volumes](#instructions) do seu serviço e abra o separador <code className="action">Políticas de snapshot</code>.

#### Criação de uma snapshot <a name="create_snapshot"></a>

Para criar uma nova snapshot de um volume no seu estado atual, clique no botão <code className="action">Ações</code> e, a seguir, em <code className="action">Criar uma snapshot</code>.

<img className="thumbnail" alt="Snapshot create" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise08.png" loading="lazy" />

Na nova janela que se abrir, pode introduzir um nome e uma descrição.

Clique no botão <code className="action">Criar uma snapshot</code> para iniciar a criação.

<img className="thumbnail" alt="Snapshot create window" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise09.png" loading="lazy" />

#### Modificação de uma snapshot <a name="modify_snapshot"></a>

Pode alterar o nome ou a descrição de uma snapshot clicando no botão <code className="action">..</code> na tabela e, a seguir, clique em <code className="action">Editar</code>. Aparecerá uma janela que lhe permitirá escolher um novo nome e/ou descrição.

<img className="thumbnail" alt="Snapshot edit" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise10.png" loading="lazy" />

Clique em <code className="action">Confirmar</code> para validar as suas alterações.

<img className="thumbnail" alt="Snapshot edit window" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise11.png" loading="lazy" />

#### Eliminação de uma snapshot <a name="delete_snapshot"></a>

:::warning
Não é possível eliminar uma snapshot de tipo `sistema`.
Estes são indispensáveis ao bom funcionamento da sua oferta Enterprise File Storage.

:::


Pode eliminar uma snapshot clicando no botão <code className="action">...</code> na tabela e, a seguir, em <code className="action">Eliminar</code>.

<img className="thumbnail" alt="Snapshot delete" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise12.png" loading="lazy" />

Clique em <code className="action">Eliminar uma snapshot</code> para validar a eliminação.

<img className="thumbnail" alt="Snapshot delete confirmation" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise13.png" loading="lazy" />

#### Restauro do volume através de uma snapshot <a name="restore_volume"></a>

:::warning
Tenha em conta que, após o restauro de um volume com a utilização de uma snapshot, todos os ficheiros ou snapshots criados posteriormente serão perdidos.
Quando um volume é restaurado, todos os dados nele contidos são substituídos pelos dados da snapshot. Esta operação é irreversível.

:::


É possível restaurar um volume utilizando a última snapshot `manual`. Clique no botão <code className="action">Ações</code> e, a seguir, em <code className="action">Restaurar a última snapshot</code>.

:::info
Para restaurar o volume utilizando uma snapshot anterior à última snapshot, é necessário eliminar as snapshots até que a snapshot a utilizar para o restauro seja a mais recente.

:::


<img className="thumbnail" alt="Volume revert to latest snapshot" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise14.png" loading="lazy" />

#### Backup de uma snapshot automática <a name="hold_snapshot"></a>

As snapshots `automáticas`, criadas pelas [políticas de snapshot](#snapshot_policy) podem ser guardadas clicando no botão <code className="action">...</code> no quadro e, a seguir, em <code className="action">Guardar</code>.

<img className="thumbnail" alt="Volume hold" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise15.png" loading="lazy" />

Ao guardar uma snapshot `automática`, esta tornar-se-á `manual`, o que impedirá a sua rotação pela política de snapshots e a sua eliminação automática.

### Gestão das ACL de volumes <a name="access_control"></a>

O controlo de acesso aos volumes funciona através de restrições de endereços IP. Uma vez que não existem restrições configuradas por predefinição, a primeira etapa aquando da criação de volumes consiste em definir endereços IP ou intervalos a partir dos quais o acesso será autorizado.

No separador <code className="action">Controlo de acesso (ACL)</code>, clique no botão <code className="action">+ Adicionar um novo acesso</code>.

<img className="thumbnail" alt="ACL" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise16.png" loading="lazy" />

Esta ação cria uma nova linha na tabela na qual pode introduzir um endereço IP ou um bloco de endereço (CIDR). Selecione `Leitura isolada` ou `Leitura e escrita` como tipo de acesso no menu pendente e selecione esta entrada para a adicionar ao ACL.

Para remover o acesso ao volume, clique no ícone da lixeira correspondente na tabela.

### Gestão das políticas de snapshots <a name="snapshot_policy"></a>

:::info
Por predefinição, cada volume está protegido por uma política de snapshots chamada `default` que cria snapshots de volume a intervalos regulares.

:::


A adição de políticas permite-lhe planificar a criação de snapshots para todos os seus volumes.

Clique no separador <code className="action">Snapshot policies</code>. O quadro apresenta todas as políticas criadas para o serviço selecionado.

Uma política predefinida já está em vigor e não pode ser alterada. Para adicionar a sua, clique no botão <code className="action">Criar uma política de snapshots</code>.

<img className="thumbnail" alt="Snapshot policies" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise17.png" loading="lazy" />

Na página que aparecer, introduza um nome e uma descrição para a política. De seguida, utilize o botão <code className="action">+ Adicionar uma nova regra</code> para adicionar uma ou mais regras à política.

<img className="thumbnail" alt="Snapshots" src="/images/storage-and-backup/file-storage/enterprise-file-storage/netapp-control-panel/manage_enterprise18.png" loading="lazy" />

Preencha os campos para indicar os critérios de periodicidade de criação da snapshot. Deve igualmente indicar um prefixo para as snapshots, necessário à sua denominação.

Encontrará mais informações sobre cada valor ao clicar no ícone que representa um ponto de interrogação (<code className="action">?</code>). Ao desenvolver a secção <code className="action">Exemplo</code>, pode visualizar dois conjuntos de regras de política com uma explicação do seu resultado.

Selecione a nova regra para a adicionar. Depois de adicionar todas as regras, clique em <code className="action">Criar uma nova Snapshot policy</code>.

[Selecione um volume](#manage_volume) e aceda ao separador <code className="action">Snapshots</code> para [aplicar as suas regras](#snapshots).

Para eliminar uma política, clique no ícone de lixo correspondente na tabela.
