## Objetivo

Acabou de encomendar a sua oferta Backup Agent para o seu servidor Bare Metal, descubra como configurar as suas primeiras cópias de segurança.

**Este guia explica como configurar a sua primeira cópia de segurança com o Backup Agent num servidor Bare Metal.**

:::info
Encontre mais informações sobre o produto Backup Agent nesta [página](/guides/storage-and-backup/backup-agent/backup-agent-product-presentation/).

:::


## Requisitos

- Ter encomendado um serviço Backup Agent no momento da encomenda do seu servidor Bare Metal ou posteriormente através do menu <code className="action">Backup Agent</code> da sua área de cliente.
- Ter iniciado e configurado um sistema operativo no seu servidor Bare Metal.

### Acesso à Área de Cliente OVHcloud

- **Ligação direta:** [Backup Agent](https://manager.eu.ovhcloud.com/#/bmc-backup-agent-baremetal/service)
- **Caminho de navegação:** <code className="action">Bare Metal Cloud</code> > <code className="action">Backup Agent</code>

:::warning
Deve garantir que o seu servidor possa ser alcançado pela nossa infraestrutura Veeam.
Receberá as informações exatas no seu e-mail de entrega.

Aqui estão as informações a autorizar no seu servidor Bare Metal:

- IP/DNS do servidor: `vspc-cgw1.prod01.eu-west-rbx.backup.ovh.net` ou `vspc-cgw21.prod01.eu-west-rbx.backup.ovh.net`
- Porta: 6180

Recomendamos vivamente que permita também que o seu servidor possa alcançar outros endereços externos para poder enviar os seus dados para o Vault. Não é necessário autorizar um fluxo de entrada neste contexto.

:::


## Instruções

As etapas para criar uma cópia de segurança para o seu servidor são as seguintes:

- Adicionar o seu servidor ao seu Backup Agent.
- Transferir o agente.
- Instalar o agente no seu servidor.

Uma vez instalado o agente, este receberá a política de cópia de segurança e permitirá realizar as cópias de segurança.

Assim que estas etapas forem concluídas, a sua primeira cópia de segurança será executada automaticamente.

### Adicionar o seu servidor ao seu Backup Agent

Clique [neste link](https://manager.eu.ovhcloud.com/#/bmc-backup-agent-baremetal/service) para aceder à secção <code className="action">Backup Agent</code> e, de seguida, clique no seu vspc-tenant na secção <code className="action">Services</code>.

<img className="thumbnail" alt="Backup Agent Services" src="/images/storage-and-backup/backup-agent/backup-agent-first-configuration/01-backup-agent-services-en.png" loading="lazy" />

Vá à secção <code className="action">Agents</code>.

<img className="thumbnail" alt="Backup Agent Tenant Infos" src="/images/storage-and-backup/backup-agent/backup-agent-first-configuration/01-backup-agent-tenant-infos-en.png" loading="lazy" />

:::info
Deverá encontrar na tabela o servidor Bare Metal que selecionou na sua encomenda, com o estado `not_installed`. É normal nesta fase, terá agora de instalar o agente no seu servidor.

:::


Clique no botão <code className="action">Transferir</code> no topo da tabela que lista os seus agentes.

<img className="thumbnail" alt="Backup Agent Agents" src="/images/storage-and-backup/backup-agent/backup-agent-first-configuration/01-backup-agent-agents-en.png" loading="lazy" />

Selecione o seu sistema operativo e escolha se deseja transferir o ficheiro de instalação ou utilizar um dos comandos propostos para o obter.

<img className="thumbnail" alt="Backup Agent Step 13" src="/images/storage-and-backup/backup-agent/backup-agent-first-configuration/01-backup-agent-download-windows-en.png" loading="lazy" />

Para instalar o seu agente no seu servidor Bare Metal, clique no separador correspondente ao seu sistema operativo:
