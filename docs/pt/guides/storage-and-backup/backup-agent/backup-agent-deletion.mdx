## Objetivo

Este guia explica-lhe como eliminar diferentes elementos do seu serviço Backup Agent: os agentes, os vaults e os tenants.

## Requisitos

- Ter um serviço Backup Agent ativo.

## Instruções

### Eliminar um agente

:::info
**Comportamento consoante a utilização do agente :**

- **Se o agente não foi utilizado para transferir dados** : Pode ser eliminado imediatamente. Será desativado em primeiro lugar, depois eliminado.
- **Se dados foram transferidos** : Aplicamos uma suspensão do agente em estado « Desativado » durante 14 dias, tempo necessário para que os dados imutáveis possam ser eliminados.

:::


:::warning
Uma vez o seu agente suspenso, não pode criar um novo agente no mesmo servidor, terá de esperar que o primeiro agente seja eliminado.

:::


Dirija-se à secção <code className="action">Agentes</code> e clique no botão de eliminação para o agente em questão.

Confirme a eliminação do agente na janela que aparece.

<img className="thumbnail" alt="Backup Agent Delete Agent" src="/images/storage-and-backup/backup-agent/backup-agent-deletion/01-backup-agent-delete-agent.png" loading="lazy" />

### Eliminar um vault

:::warning
Um vault não pode ser eliminado se contiver dados. Se pretender eliminar um vault, terá de [contactar o suporte](https://help.ovhcloud.com/csm?id=csm_get_help), que realizará verificações consigo antes de iniciar a eliminação.

:::


Dirija-se à secção <code className="action">Vaults</code> e clique no botão de eliminação para o vault em questão.

Confirme a eliminação na janela que aparece.

<img className="thumbnail" alt="Backup Agent Delete Vault" src="/images/storage-and-backup/backup-agent/backup-agent-deletion/01-backup-agent-delete-vault.png" loading="lazy" />

### Eliminar um tenant

:::warning
Por enquanto, um tenant não pode ser eliminado de forma autónoma. Se pretender eliminar um tenant, terá de [contactar o suporte](https://help.ovhcloud.com/csm?id=csm_get_help). Vamos tratar do seu pedido.

:::


Selecione o seu tenant e clique no botão de eliminação.

Confirme a eliminação na janela que aparece.

<img className="thumbnail" alt="Backup Agent Delete Tenant" src="/images/storage-and-backup/backup-agent/backup-agent-deletion/01-backup-agent-delete-tenant.png" loading="lazy" />
