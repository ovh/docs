## Objetivo

Este guia explica-lhe como se conectar à Veeam Service Provider Console (VSPC) para visualizar as suas cópias de segurança, os seus agentes e consultar os relatórios dos seus jobs de cópia de segurança.

## Requisitos

- Ter recebido as credenciais de acesso à VSPC por e-mail após a encomenda do seu serviço Backup Agent.
- Ter um navegador web compatível.

## Instruções

### Aceder à VSPC

Aceda ao URL da VSPC: `https://vspc.prod01.eu-west-rbx.backup.ovhcloud.com`

<img className="thumbnail" alt="Backup Agent Login VSPC" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-login-vspc.png" loading="lazy" />

### Conectar-se

Conecte-se utilizando as credenciais fornecidas por e-mail. O formato do login é geralmente `vspc-tenant-XXXXXX\user-XXXXXX`.

:::info
Se já não tiver as suas credenciais, pode regenerá-las ao [contactar o suporte](https://help.ovhcloud.com/csm?id=csm_get_help).

:::


<img className="thumbnail" alt="Backup Agent Login VSPC" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-login-vspc.png" loading="lazy" />

:::info
Esta conta é apenas de leitura e permite-lhe aceder a visualizações das suas cópias de segurança e dos seus agentes.

:::


### Consultar os Backup Jobs

Depois de se conectar, clique em <code className="action">Backup Jobs</code> no menu à esquerda.

<img className="thumbnail" alt="Backup Agent Backup Jobs" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-backup-jobs.png" loading="lazy" />

### Visualizar jobs bem-sucedidos

Clique em <code className="action">Successful Jobs</code> para o seu tenant.

<img className="thumbnail" alt="Backup Agent Successful Jobs" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-successful-jobs.png" loading="lazy" />

### Visualizar pontos de restauro

Pode consultar os pontos de restauro disponíveis para as suas cópias de segurança.

<img className="thumbnail" alt="Backup Agent Restore Points" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-restore-points.png" loading="lazy" />

### Aceder aos agentes geridos

Para ver a lista dos seus agentes instalados, vá a <code className="action">Managed Computers</code>.

<img className="thumbnail" alt="Backup Agent Managed Computers" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-managed-computers.png" loading="lazy" />

### Consultar relatórios

Aceda à secção <code className="action">Reports</code> para visualizar os relatórios das suas cópias de segurança.

<img className="thumbnail" alt="Backup Agent Reports" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-reports.png" loading="lazy" />

### Abrir o último relatório

Abra o último relatório disponível para consultar os detalhes das suas últimas cópias de segurança.

<img className="thumbnail" alt="Backup Agent Last Report" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-last-report.png" loading="lazy" />

### Ver as últimas alarmes

Pode ver as últimas alarmes nos seus agentes e cópias de segurança na secção <code className="action">Alarm Management</code>.

<img className="thumbnail" alt="Backup Agent Alarm Management" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-alarm.png" loading="lazy" />
