## Objective

This tutorial explains how to create an online store with the open-source plugin **WooCommerce** for the Content Management System (CMS) **WordPress**.

This tutorial is designed to help you with common tasks. Nevertheless, we recommend contacting a [specialist provider](https://partner.ovhcloud.com/en-gb/directory/) or the [WordPress support](https://wordpress.com/support/) or [the publisher of WooCommerce](https://woocommerce.com/) if you encounter any difficulties. ## Requirements

- An [OVHcloud web hosting plan](https://www.ovhcloud.com/en-gb/web-hosting/) that contains at least one database
- A [domain name](https://www.ovhcloud.com/en-gb/domains/)
- [WordPress installed](/guides/web-cloud/web-hosting/cms-install-1-click-modules/) on your web hosting plan

If one is not already installed, [add an SSL certificate](/guides/web-cloud/web-hosting/ssl-activate-https-website#step-1-activate-the-ssl-certificate-on-the-web-hosting-plan/) for the domain name associated with your website before you continue.
  
## Instructions
  
**WooCommerce** is an extension for **WordPress** and can be installed like any other plugin.

### Installation

Log in to your admin interface by typing `/wp-admin` or `/wp-login` in your address bar after your domain name URL (redirection is done automatically):

<img className="thumbnail" alt="Admin page of WordPress" src="/images/assets/screens/other/cms/wordpress/woocommerce/admin-login.png" loading="lazy" />

In the left-hand menu, go to <code className="action">Plugins</code> then click on <code className="action">Add New</code>:

<img className="thumbnail" alt="Dashboard, Plugins, Add new" src="/images/assets/screens/other/cms/wordpress/woocommerce/plugins.png" loading="lazy" />

On the new `Add Plugins` page, type "woocommerce" in the search bar in the top right and click <code className="action">Install Now</code> in the **WooCommerce** box:

<img className="thumbnail" alt="Install WooCommerce" src="/images/assets/screens/other/cms/wordpress/woocommerce/add-plugin-woocommerce-install-now.png" loading="lazy" />

Now click on <code className="action">Activate</code>:

<img className="thumbnail" alt="Activate WooCommerce" src="/images/assets/screens/other/cms/wordpress/woocommerce/add-plugin-woocommerce-activate.png" loading="lazy" />

### Configuration 

#### Method 1: Using the configuration wizard

If you have not yet set up your **WooCommerce** plugin, a setup wizard will help you fill in the information for your online store. Fill in the form and click <code className="action">Continue</code>:

<img className="thumbnail" alt="Setup Wizard - Store Details" src="/images/assets/screens/other/cms/wordpress/woocommerce/woocommerce-store-details.png" loading="lazy" />

Then select your business domain(s):

<img className="thumbnail" alt="Setup Wizard - Industry" src="/images/assets/screens/other/cms/wordpress/woocommerce/woocommerce-industry.png" loading="lazy" />

Choose the type of products you want to sell on your website (some options are not free):

<img className="thumbnail" alt="Setup Wizard - Product Types" src="/images/assets/screens/other/cms/wordpress/woocommerce/woocommerce-product-types.png" loading="lazy" />

Then enter the nature of your activity:

<img className="thumbnail" alt="Setup Wizard - Business Details" src="/images/assets/screens/other/cms/wordpress/woocommerce/woocommerce-business-details.png" loading="lazy" />

Add optional (and free) features if you want:

<img className="thumbnail" alt="Setup Wizard - Business Details, free features" src="/images/assets/screens/other/cms/wordpress/woocommerce/woocommerce-business-details-2.png" loading="lazy" />

Finally, choose a theme from the list:

<img className="thumbnail" alt="Setup Wizard - Choose a theme" src="/images/assets/screens/other/cms/wordpress/woocommerce/woocommerce-theme.png" loading="lazy" />

**WooCommerce** then prompts you to create an account to use the **Jetpack** plugin, which is automatically installed in addition to **WooCommerce**. This account creation is optional, you will have access to the limited functions of **Jetpack** without having to authenticate.

Your online store is now configured with the general settings.

#### Method 2: Manual configuration

Click <code className="action">Plugins</code> to list the installed extensions and then click `Installed plugins`. You will see a list of your plugins. Click <code className="action">Settings</code> in the **WooCommerce** module:

<img className="thumbnail" alt="Setup Wizard - Extension, WooCommerce, Settings" src="/images/assets/screens/other/cms/wordpress/woocommerce/plugins-woocommerce.png" loading="lazy" />

You can also access these settings by clicking directly on <code className="action">WooCommerce</code>, then <code className="action">Settings</code>:

<img className="thumbnail" alt="Setup Wizard - WooCommerce, Settings" src="/images/assets/screens/other/cms/wordpress/woocommerce/dashboard-woocommerce-settings.png" loading="lazy" />

### Settings

The settings page has several tabs:

<img className="thumbnail" alt="Setup Wizard - WooCommerce, Settings, Tabs" src="/images/assets/screens/other/cms/wordpress/woocommerce/woocommerce-general.png" loading="lazy" />

#### General

This tab allows you to define the following:

- Company address
- Sales and delivery areas
- Default customer location (optional)
- Activate/deactivate taxes
- Coupons
- Monetary data (site currency, display)

<img className="thumbnail" alt="Setup Wizard - WooCommerce, Settings, General tab" src="/images/assets/screens/other/cms/wordpress/woocommerce/woocommerce-general-currency.png" loading="lazy" />

#### Products

Product management is done through a set of subcategories:

- **General**: Is used to define elements such as the home page that will be displayed by default (shop, legal notices, shopping cart, etc.), units of measure, whether or not to comment on products or notes.
- **Inventory**: Is used to configure or not the management of your stock and to configure the behaviour of the website (decremented stock when an object is in the basket, alert thresholds, possibility to hide products that are no longer in stock).
- **Downloadable products**: Concerns cases where documents are made available for download by users.
- **Approved download directories**: Specifies directories on the server where the files will be uploaded.
- **Advanced**: Is used to set product attributes more finely.

#### Shipping

If you enabled the default extensions that were free when you installed, you have the extension [WooCommerce Shipping](https://woocommerce.com/woocommerce-shipping/). Otherwise, you can install it by going to the <code className="action">Extensions</code> submenu.

- **Shipping zones**: Allows you to define and configure shipping areas.
- **Delivery options**: Is used to set up the application for all shipping costs.
- **Shipping classes**: Can be used to group similar products by type of shipment.

#### Payments

Use this tab to enable/disable the payment methods offered on your website. Please refer to the [official documentation](https://woocommerce.com/document/payments/) to configure your payment methods.

#### Accounts and privacy

This section includes all features related to the management of accounts and personal data.

#### Email

Allows you to configure the *standard emails* sent by the application (registration, orders, cancellations, etc.).

#### Integration

To geolocate your customers based on their IP addresses, you can enter the licence key for [MaxMind](https://www.maxmind.com/), a paid geolocation service.

#### Advanced

- **Installing pages**: Useful for modifying the pages that users will be redirected to during the ordering process.
- **REST API**: Section that allows you to configure access to WooCommerce via its REST API.
- **Webhook**: Manage your HTTP callback functions.
- **Ancient API**: Reactivate the old WooCommerce API (disabled by default).
- **WooCommerce.com**: Enable or disable tracking of your online sales site activity by WooCommerce, suggestions for dedicated extensions (the majority are paid).
- **Features**: A page that lists features that are currently being tested on WooCommerce or recently added.
