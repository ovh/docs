## Objective

Want to retrieve a list of all the domain names on your OVHcloud customer account? Do you need to retrieve all information related to your domain names (associated contacts, holder, active options, creation and expiry dates, etc.) in one go?

**Find out how to export a list of your domain names and their associated information in CSV format from the OVHcloud Control Panel.**

## Requirements

- A [domain name](https://www.ovhcloud.com/en-gb/domains/) registered with OVHcloud

{/* CP-NAV-START:web-domains */}
---

### OVHcloud Control Panel Access

- **Direct link:** [Domain names](https://manager.eu.ovhcloud.com/#/web-domains/domain)
- **Navigation path:** <code className="action">Web Cloud</code> > <code className="action">Domain names</code> > Select your domain name

---
{/* CP-NAV-END:web-domains */}

## Instructions

Click on the tabs below to view each of the **3** steps.

<Tabs>
  <Tab label="Step 1">
    Go to the [Domain names](https://manager.eu.ovhcloud.com/#/web-domains/domain) page. Above the table that appears, click <code className="action">Export in CSV format</code>.
    
    <img className="thumbnail" alt="Domain Names" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-names.png" loading="lazy" />
  </Tab>
  <Tab label="Step 2">
    In the window that opens, tick the information that you want to include in the CSV file for all of your domain names.
    
    <img className="thumbnail" alt="Export domains in CSV format step 1" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/export-csv/export-domains-in-csv-format-step-1.png" loading="lazy" />

Then click the <code className="action">Export</code> button to start generating the file in CSV format.
  </Tab>
  <Tab label="Step 3">
    A load window will appear. Wait until the progress bar reaches 100%.
    
    <img className="thumbnail" alt="Export domains in CSV format step 2 in progress" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/export-csv/export-domains-in-csv-format-step-2a.png" loading="lazy" />

As soon as the CSV file is generated, the following message is displayed, and the file is automatically downloaded:
    
    <img className="thumbnail" alt="Export domains in CSV format step 2 done" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/export-csv/export-domains-in-csv-format-step-2b.png" loading="lazy" />

If the CSV file download did not start automatically, click the <code className="action">download it manually</code> link to retrieve it.
  </Tab>
</Tabs>
