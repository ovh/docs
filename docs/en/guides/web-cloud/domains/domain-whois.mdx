## Objective

Want to know if a domain name is available? You want to know certain information related to a domain name, such as the holder's contact details, the expiry date, etc. ?

WHOIS, short for “Who is?”, is a protocol that allows access to different data related to a domain name.

**Find out how to use the WHOIS tool to get information on a domain name.**

## Requirements

- An Internet browser (e.g. Firefox, Chrome, Safari, Edge, etc.) on your computer, tablet or smartphone.

## Instructions

OVHcloud provides an interface to allow you to execute the WHOIS command for a domain name.

:::info
The content and presentation of the information in the result of a WHOIS query may differ depending on the domain name extension (e.g. *.com*, *.net*, *.ovh*, etc.).

In addition, the registries that manage these extensions may allow domain name holders to hide personal information in WHOIS.

:::


The following steps will take you to the WHOIS records associated with a domain name:

1. Access our [WHOIS online tool](https://www.ovhcloud.com/en-gb/domains/whois/).
1. On the page that pops up, enter the domain name (for example: *domain.tld* **without** the *www*) in the <code className="action">Domain name *</code> field, then enter the `Security code` in the <code className="action">Enter security code *</code> field.
1. Click the <code className="action">Whois</code> button to send the request.
1. See the result of the WHOIS query in the new section titled <code className="action">Whois search results :</code> under the <code className="action">Whois</code> button.

In this result, you will find all the information available on the domain name entered in step **2**.
