:::info
This article is about Additional IPv4 configuration over a vRack. You can also configure Additional IPv6 addresses on your vRack using [this guide](/guides/bare-metal-cloud/dedicated-servers/configure-an-ipv6-in-a-vrack/).

:::


## Objective

**This guide will take you through the process of installing Hyper-V, associating a virtual switch, and configuring a VM to work with Additional IPs over a vRack.**

## Requirements

- A [vRack](https://www.ovhcloud.com/en-gb/network/vrack/) compatible dedicated server with Windows Server installed
- An ISO for the OS that will be installed on your VM (CentOS 7 will be used as an example in this guide)
- A vRack delivered to your OVHcloud account
- An Additional IP block of 4 or more IPs

:::warning
This feature might be unavailable or limited on servers of the [**Eco** product line](https://eco.ovhcloud.com/en-gb/about/).

Please visit our [comparison page](https://eco.ovhcloud.com/en-gb/compare/) for more information.

:::


## Instructions

This guide assumes that you have already installed Windows Server, connected via Remote Desktop, and have already assigned your dedicated server and IP block to a vRack. For more information on these steps please refer to steps 1 through 4 on our guide: [Configuring the vRack on your dedicated servers](/guides/bare-metal-cloud/dedicated-servers/vrack-configuring-on-dedicated-server/).

### Installing Hyper-V

The first step you will need to do is install Hyper-V.

In the Server Manager, click <code className="action">Add roles and features</code>.
 
<img className="thumbnail" alt="Installing hyper-v" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/add-roles-features.png" loading="lazy" />

On the Wizard, click <code className="action">Next</code> to proceed to the next page.

<img className="thumbnail" alt="Installing hyper-v" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/add-roles-features-2.png" loading="lazy" />

Make sure "Role-Based or feature-based installation" is selected and click <code className="action">Next</code>.

<img className="thumbnail" alt="Installing hyper-v" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/add-roles-features-3.png" loading="lazy" />

Ensure that "Select a server from the server pool" is selected and that the server you are working on is selected on the list. Then click <code className="action">Next</code>.

<img className="thumbnail" alt="Installing hyper-v" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/add-roles-features-4.png" loading="lazy" />

In the server roles list, check "Hyper-V" and then click <code className="action">Next</code>.

<img className="thumbnail" alt="Installing hyper-v" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/add-roles-features-5.png" loading="lazy" />

On the "Features" page, you can simply click <code className="action">Next</code>.

<img className="thumbnail" alt="Installing hyper-v" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/add-roles-features-9.png" loading="lazy" />

Next, you are asked to identify which network connection on your server you want to use for the virtual switch.

To do this, open a Command Prompt or PowerShell and execute the command `ipconfig /all`.

Note that in our example `Ethernet 2` is the interface used for the vRack. However, it is possible that the vRack NIC is a different interface in your configuration. The correct one to select will be the interface that does not have the server's main IP address or has a self-assigned IP (169.254.x.x).

<img className="thumbnail" alt="check-interface" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/ipconfig.png" loading="lazy" />

Once you have this information, go back to the 'Add Roles and Features Wizard' and click <code className="action">Next</code>.

<img className="thumbnail" alt="Installing hyper-v" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/add-roles-features-6.png" loading="lazy" />

Now select the adapter for the vRack that you identified in the Command Prompt or PowerShell, and click <code className="action">Next</code>.

<img className="thumbnail" alt="Installing hyper-v" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/add-roles-features-7.png" loading="lazy" />

The next two pages are for choosing migration and storage options. You can configure those as you please.

Once you reach the confirmation page, check "Restart the destination server automatically if required" and click <code className="action">Yes</code>, then <code className="action">Install</code>.

<img className="thumbnail" alt="Installing hyper-v" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/add-roles-features-8.png" loading="lazy" />

Hyper-V will now install and the server should reboot.

### Creating and Configuring a VM

Once the server has rebooted, log in and open Hyper-V Manager.

Select your server on the left and click <code className="action">New</code>. Select "Virtual Machine" in the context menu.

<img className="thumbnail" alt="create-vm" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/create-vm.png" loading="lazy" />

In the "New Virtual Machine Wizard", you can configure the VM as you please. When you reach the "Configure Networking" step, make sure to select the virtual switch. Once selected, click <code className="action">Next</code> to continue.

<img className="thumbnail" alt="create-vm" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/create-vm-2.png" loading="lazy" />

In the "Installation Options" section, be sure to add the ISO for the operating system you are going to install. Click <code className="action">Next</code> to continue.

<img className="thumbnail" alt="create-vm" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/create-vm-3.png" loading="lazy" />

When you reach the "Summary" page, ensure that the "Network" (Virtual Switch) and "Operating System" settings are correct and click <code className="action">Finish</code>.

<img className="thumbnail" alt="create-vm" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/create-vm-4.png" loading="lazy" />

### Installing the OS and Configuring the IP

When you start the virtual machine, the OS installation should launch automatically. If not, you will likely get the following error message:

>"The unsigned image's hash is not allowed (DB)"

If this occurs, you will need to disable "Secure Boot".

Turn off the VM and click on <code className="action">Settings</code>.

<img className="thumbnail" alt="disable-secure-boot" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/disable-secure-boot.png" loading="lazy" />

Next, open the "Security" section, deselect "Enable Secure Boot", then click <code className="action">Apply</code>.

<img className="thumbnail" alt="disable-secure-boot" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/disable-secure-boot-2.png" loading="lazy" />

Once done, start the Virtual Machine again.

Configure the operating system as you prefer.
<br/>As for the networking settings, you will need to set a static IP.

In our example, the IP block assigned to the vRack is 192.xxx.xxx.80/29. The following is the breakdown of the block:

192.xxx.xxx.80 - Network Address (Reserved - Not usable)
<br/>192.xxx.xxx.81 - First usable IP
<br/>192.xxx.xxx.82
<br/>192.xxx.xxx.83
<br/>192.xxx.xxx.84
<br/>192.xxx.xxx.85 - Last usable IP
<br/>192.xxx.xxx.86 - Default Gateway (Reserved - Not usable)
<br/>192.xxx.xxx.87 - Broadcast Address (Reserved - Not usable)

Using 192.xxx.xxx.81 for this example, the configuration should look like the following:

Address: 192.xxx.xxx.81
<br/>Subnet Mask: 255.255.255.248
<br/>Gateway: 192.xxx.xxx.86
<br/>DNS: 213.186.33.99 (You can put another DNS if you wish.)

Once the OS is installed, it should have a network connection established.

You can also see in the example below how the `ifcfg-eth0` file should appear.

<img className="thumbnail" alt="configured" src="/images/bare-metal-cloud/dedicated-servers/ipfo-vrack-hyperv/configured.png" loading="lazy" />
