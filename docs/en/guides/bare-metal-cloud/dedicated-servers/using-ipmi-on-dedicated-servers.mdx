## Objective

With the IPMI (Intelligent Platform Management Interface) console, you can access your dedicated server directly, without depending on the operating system connectivity state. This guide will explain how to boot this console.

## Instructions

You can access the IPMI using several different methods¹. SSH keys stored on the server will not be used for these connections. Here is a summary:

|Method Name|Short Name|Description|Copy-Paste|Virtual ISO reader²|Use Case Example|
|---|---|---|---|---|---|
|**KVM**³ via **web browser**|**HTML KVM**|Redirection of the video screen to an **HTML canvas**, exactly as if you were physically connecting a keyboard/mouse via USB and a screen via VGA to your dedicated server.|❌|⚠️⁴|- Troubleshoot a boot issue on your dedicated server.|
|**KVM**³ via **Java applet**|**Java KVM**|Same as HTML KVM, except that it uses **Java applet** rather than HTML canvas.|❌|✅|- Troubleshoot a boot issue on your dedicated server. <br />- Perform a manual installation of a specific OS (not in the [catalog](https://www.ovhcloud.com/en-gb/bare-metal/os/))⁵.|
|**SoL**⁶ via **web browser**|**JavaScript SoL**|Redirection of a serial connection to the web browser, exactly as if you were physically connecting a serial console via RS-232 to your dedicated server.|✅|❌|- Troubleshoot a network issue: get system logs and manipulate configuration files.|
|**SoL**⁶ via **SSH**|**SSH SoL**|Same as JavaScript SoL, except redirection is done to an SSH gateway. You then connect via your preferred SSH client to a remote SSH server that converts SSH commands to serial commands to the dedicated server.|✅|❌|- Same as JavaScript SoL but from a machine without any graphical interface.|

¹ Depending on your dedicated server hardware compatibility (some methods will not be shown in the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB)).<br />
² Feature that enables the user to mount an ISO image stored locally on your machine to your remote dedicated server, so you can install an OS via IPMI.<br />
³ KVM = Keyboard Video and Mouse<br />
⁴ Depending on your dedicated server hardware compatibility: use Java KVM instead if not compatible.<br />
⁵ If the OS you want to install is not in the list of [operating systems available with OVHcloud Bare Metal servers](https://www.ovhcloud.com/en-gb/bare-metal/os/), please note that you can also use a custom image: See [Bring Your Own Image (BYOI) / Bring Your Own Linux (BYOLinux), a comparison sheet](/guides/bare-metal-cloud/dedicated-servers/bring-your-own-image-versus-bring-your-own-linux/) for more details.<br />
⁶ SoL = Serial over Lan

To enable one of these methods, click on the <code className="action">IPMI/KVM</code> tab.

### Open KVM via Java applet <a name="applet-java"></a>

:::info
We recommend installing the latest version of Java.

:::


You will need to ensure that Java is installed on your desktop for the Java applet to work. If you do not have Java installed, go to the [official page](https://www.java.com/en/download/) to do so.

In the <code className="action">Remote KVM</code> section of the OVHcloud Control Panel, click on <code className="action">From a Java applet (KVM)</code>:

<img className="thumbnail" alt="Java KVM Access" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-java-01.png" loading="lazy" />

Download the file `kvm.jnlp` when you are prompted to do so, and run it:

<img className="thumbnail" alt="Java KVM Opening" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-java-02.png" loading="lazy" />

You will then land on the login page, where you will be prompted to enter your credentials, as you would need to when logging in via a terminal or external software application:

<img className="thumbnail" alt="Java KVM Overview" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-java-03.png" loading="lazy" />

You can now manage your server.

Activation takes a few seconds. You will receive a message confirming that the IPMI connection is available.

<img className="thumbnail" alt="HTML KVM Opening" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-html-02.png" loading="lazy" />

<img className="thumbnail" alt="HTML KVM Overview" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-html-03.png" loading="lazy" />

### Open SoL via SSH <a name="sol-ssh"></a>

For more details about creating SSH key pairs, see [this page](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys-dedicated#create-ssh-key/).

In the <code className="action">Serial over LAN (SoL)</code> section of the OVHcloud Control Panel, click on <code className="action">Add SSH key</code>.

<img className="thumbnail" alt="SSH SoL Access" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-sol-sshkey-01.png" loading="lazy" />

A popup will open so you can enter the public SSH key you want to use to connect with. Then click <code className="action">Launch SoL session via SSH</code>.

<img className="thumbnail" alt="SSH SoL SSH Public Key" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-sol-sshkey-02.png" loading="lazy" />

When the session is ready, a success message and an URI will appear so you can connect to the dedicated server via Serial via SSH. Copy that URI to the clipboard.

<img className="thumbnail" alt="SSH SoL Opening" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-sol-sshkey-03.png" loading="lazy" />

For more details about using SSH keys to establish an SSH connection, see [this page](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys-dedicated#multiplekeys/).

### Test and reboot the IPMI <a name="ipmi-test-reboot"></a>

Your IPMI may stop responding. If you cannot access it, you can test it first by clicking on <code className="action">Test the IPMI</code>, and checking the result of the diagnostic:

<img className="thumbnail" alt="IPMI Test" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-test.png" loading="lazy" />

If everything appears to be normal, as per our example, you may be experiencing a local technical issue (internet connection, local desktop). If the IPMI encounters any issues, you can reboot it by clicking <code className="action">Reboot the IPMI</code>.

<img className="thumbnail" alt="IPMI Reboot" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-reboot.png" loading="lazy" />

It will take several minutes for the IPMI to reboot.

:::info
This operation will not affect the applications, data and services running on your dedicated server.

:::


### Installing an OS using IPMI v1

:::warning
OVHcloud does not guarantee the functionality of any operating systems installed via IPMI. This route should only be taken by an experienced server administrator.

64-bit versions of Java can prevent the `Redirect ISO`/`Redirect CDROM` menus from opening and cause JViewer to crash.

:::


To begin, open [IPMI in a Java applet](#applet-java) from the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB). Then, click <code className="action">Device</code> from the menu bar and select <code className="action">Redirect ISO</code> from the drop-down menu.

<img className="thumbnail" alt="Redirect_ISO" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/RedirectISO.jpg" loading="lazy" />

Next, select the ISO you wish to use from your local computer's file system. Once you have selected your ISO, press the <code className="action">Ctrl Alt Del</code> button in the top-right corner of the screen to reboot the server. Press the appropriate `F` key to access the boot options.

:::info
You may need to use the soft keyboard for inputs to register in IPMI. To access this, click the <code className="action">Keyboard</code> option from the menu bar at the top of the window. Then, select `Soft Keyboard` from the dropdown menu and click <code className="action">Show</code>.

:::


Select the **UEFI Virtual CDROM 1.00** option from the boot menu to start the server from the ISO attached previously.

<img className="thumbnail" alt="UEFI_Virt" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/UEFIVirt.jpg" loading="lazy" />

Complete the steps required to install the operating system. Do not forget to remove the ISO from the "Redirect ISO" option.

### Installing an OS using IPMI v2

:::warning
OVHcloud does not guarantee the functionality of any operating systems installed via IPMI. This route should only be taken by an experienced server administrator.

:::


To begin, open [IPMI in a Java applet](#applet-java) from the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB). Then, click <code className="action">Virtual Media</code> and select <code className="action">Virtual Storage</code>.

<img className="thumbnail" alt="Virtual_Storage" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/virtual_storage.png" loading="lazy" />

From the new screen, select `ISO File` from the "Logical Drive Type" drop-down menu. Next, click <code className="action">Open Image</code> and navigate to your ISO file. Finally, click <code className="action">Plug-in</code> and <code className="action">OK</code> to finish.

<img className="thumbnail" alt="ISO_file" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/iso_file.png" loading="lazy" />

In order to be able to boot from our ISO file, we need to access the BIOS and switch our boot options. To do so, select <code className="action">Power Control</code> and click <code className="action">Set Power Reset</code>.

<img className="thumbnail" alt="Power_Reserver" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/power_reset.png" loading="lazy" />

:::info
You may need to use the soft keyboard for inputs to register in IPMI. To access this, click the <code className="action">Virtual Media</code> option from the menu bar at the top of the window. Then, select <code className="action">Virtual Keyboard</code> from the drop-down menu.

:::


During the bootup process, press the `DEL` key when prompted to access the BIOS. You may also press the `F11` key and navigate to the BIOS by selecting the option <code className="action">Enter Setup</code>.

<img className="thumbnail" alt="Boot_Menu" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/boot_menu.png" loading="lazy" />

In the BIOS navigate to the <code className="action">Boot</code> tab and change the `UEFI Boot Order #1` to `UEFI USB CD/DVD:UEFI: CDROM virtual ATEN YSOJ`.

<img className="thumbnail" alt="Bios" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/bios.png" loading="lazy" />

Lastly, press the `F4` key to save your changes and restart the server.

### Installing an OS using web browser KVM (only for the latest servers)

:::warning
OVHcloud does not guarantee the functionality of any operating systems installed via IPMI. This route should only be taken by an experienced server administrator.

:::


In the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB), open the [KVM web browser console](#kvm-browser).

Here you have access to the same information and functionalities as in the Java-based IPMI modules.

:::info
Be sure to execute the next steps at a good pace. The process might be cancelled if there are longer pauses between actions.

:::


Click on the <code className="action">Browse File</code> button and select your image file.

<img className="thumbnail" alt="KVM Install" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install01.png" loading="lazy" />

Click on <code className="action">Start Media</code>. This will prepare the ISO for the installation process.

<img className="thumbnail" alt="KVM Install" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install02.png" loading="lazy" />

The file size displayed is not the actual size. This is normal, since the file is not fully uploaded in this step.

<img className="thumbnail" alt="KVM Install" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install03.png" loading="lazy" />

Click on <code className="action">Power</code> and select <code className="action">Reset Server</code> from the drop-down menu.

<img className="thumbnail" alt="KVM Install" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install04.png" loading="lazy" />

Wait for the boot selection screen to appear and press the appropriate key to enter the boot menu (`F11` in this example).

<img className="thumbnail" alt="KVM Install" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install05.png" loading="lazy" />

In the boot menu, select the optical drive (`UEFI: AMI Virtual CDROM0` in this example) and press `Enter`.

<img className="thumbnail" alt="KVM Install" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install06.png" loading="lazy" />

The ISO file will now be uploaded, then the server will boot from the file.

<img className="thumbnail" alt="KVM Install" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install07.png" loading="lazy" />

### Rebooting a server into the BIOS menu

You might want to access the BIOS when configuring or troubleshooting your server. A convenient way to achieve this is by using the tool `ipmiutil` (refer to the [project page](https://ipmiutil.sourceforge.net/) for more information).

When the server is in [rescue mode](/guides/bare-metal-cloud/dedicated-servers/rescue-mode/) and you have logged in, install it with the following commands:

```bash
apt install ipmiutil
```

Then reboot the server with this command:

```bash
ipmiutil reset -b
```

Afterwards, access the [IPMI console](#procedure) in your [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB). You should see the server's BIOS menu displayed.

<img className="thumbnail" alt="KVM BIOS" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_bios.png" loading="lazy" />
