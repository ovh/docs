## Objective

This guide will help you to reset your `Administrator` account password with the **Windows customer rescue system**.

## Requirements

- Microsoft Windows Server 2016 or greater installed on your [dedicated server](https://www.ovhcloud.com/en-gb/bare-metal/)
- At least 16 GB of RAM installed on the server

## Instructions

### Step 1 - Reboot the server into rescue mode <a name="step1"></a>

The system has to be started into the **Windows customer rescue system** before the admin password can be changed.

For detailed instructions, please refer to the [Windows rescue mode guide](/guides/bare-metal-cloud/dedicated-servers/rescue-customer-windows/).

### Step 2 - Clear the current password <a name="step2"></a>

Connect to your server in Remote Desktop using the credentials provided by email.

Please note that the user name for the rescue mode is `Administrator`.

- If your server uses software RAID on your Windows disk, you have to import your Windows local disk to be able to access it: Follow the instructions of the [section A](#sectionA) below.
- If your server does not use software RAID on your Windows disk, you should be able to directly access the local Windows disk as explained in the [section B](#sectionB) of this guide.

#### A - Importing your local Windows disk <a name="sectionA"></a>

##### 1. Access disk management

Right-click the <code className="action">Start</code> menu and select <code className="action">Disk Management</code>.

<img className="thumbnail" alt="disk_manager_menu" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_manager_menu.png" loading="lazy" />

You can then see the disks and volumes of the server.

<img className="thumbnail" alt="disk_manager_window" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_manager_window1.png" loading="lazy" />

Your server's Windows disk is probably *Disk 1*. You must import it to be able to access it.

Please note that if you have several disk groups, the number of the Windows disk may vary. You may have to import several disks to get the Windows one.

You also have to import the second disk to properly import your software RAID volume.

##### 2. Import local disks

Right-click *Disk 1* and select <code className="action">Online</code>.

<img className="thumbnail" alt="disk_import_disk1" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_manager_disk1on.png" loading="lazy" />

Do the same thing for the second disk (*Disk 2*) to properly import your software RAID volume.

Right-click *Disk 2* and select <code className="action">Online</code>.

<img className="thumbnail" alt="disk_import_disk2" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_manager_disk2on.png" loading="lazy" />

Disks are now seen as "Dynamic" and "Foreign".

Right-click *Disk 1* again and select <code className="action">Import Foreign Disks</code>.

<img className="thumbnail" alt="disk_import_menu" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_manager_diskimport.png" loading="lazy" />

Click `OK` twice.

<img className="thumbnail" alt="disk_import1" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_import1.png" loading="lazy" />

<img className="thumbnail" alt="disk_import2" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_import2.png" loading="lazy" />

You can see that the local disk is now accessible and that the Windows disk is drive `(E:)` (spreading on two software RAID disks with Mirrored volume type).

<img className="thumbnail" alt="disk_import_sync" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/disk_import_sync.png" loading="lazy" />

:::info
In this example, the volume status is "Resynching" because the server was hard-rebooted into rescue mode. This is an expected status and it is not caused by the rescue mode itself.  
This will not affect data on the volume and resynchronisation will continue once the server is rebooted into its installed OS.

:::


:::warning
You must then use the path of your local Windows directory (here it is `E:\Windows`) when browsing to find the "SAM" configuration file below.

:::


You can now reset the password by following the instructions below.

#### B - Reset the password <a name="sectionB"></a>

To reset passwords, the tool NTPWEdit is required.<br/>
Once you are connected via Remote Desktop, open the browser and download it from its [official website](http://www.cdslow.org.ru/files/ntpwedit/ntpwed07.zip).<br/>
Navigate to the folder where the downloaded ZIP file is located and extract its content.<br/>
Next, open the `ntpwedit64` executable to start the application.

In this interface, you can manipulate the SAM file in order to clear the admin user's password.

You must browse the local Windows drive to find your system's SAM file.

Click the three dots button (<code className="action">...</code>) to browse the drive containing your server's local Windows folder.

It usually is the `Windows (E:\)` drive.

<img className="thumbnail" alt="ntpwedit1" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/ntpwedit_1.png" loading="lazy" />

Browse to `E:\WINDOWS\SYSTEM32\CONFIG\`.

Select and open the SAM file to display the user accounts by clicking <code className="action">Open</code>.

<img className="thumbnail" alt="ntpwedit_sam" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/SAM.png" loading="lazy" />

Select the user account "admin" and click on <code className="action">Change password</code>.

<img className="thumbnail" alt="ntpwedit2" src="/images/bare-metal-cloud/dedicated-servers/rcw-changing-admin-password-on-windows/ntpwedit_2.png" loading="lazy" />

In the popup window, enter your new password in both fields and click <code className="action">OK</code>.

:::warning
The new password will be accepted regardless of any password complexity.

Keep in mind that this password will allow remote connection to the server once rebooted on its operating system.

:::


Finish by clicking <code className="action">Save changes</code> and <code className="action">Exit</code>.

After this, the server needs to be rebooted on the normal operating system.

### Step 3 - Reboot the server <a name="step3"></a>

First, change the netboot back to "Boot from the hard disk" in your OVHcloud Control Panel (see [step 1](#step1)).

Then restart the server from the Control Panel.

Click the <code className="action">...</code> button near "Status" in the "Service Status" section and click <code className="action">Restart</code>.

<img className="thumbnail" alt="reboot" src="/images/assets/screens/control-panel/product-selection/bare-metal-cloud/dedicated-servers/general-information/cp-dedicated-restart.png" loading="lazy" />
