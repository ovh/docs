## Objective

To best protect your system, your Windows Server dedicated server has its own built-in firewall. By configuring it, you can increase security levels, which guarantees the availability and integrity of all elements hosted on the server, such as roles, services and shared folders.

**This guide will show you how to apply firewall rules on Windows.**

:::

>

## Requirements

- A [dedicated server](https://www.ovhcloud.com/en-gb/bare-metal/) with Windows installed in your OVHcloud account
- Administrative access via remote desktop to your server

## Instructions

### Step 1: Access Windows Firewall

To access Windows Firewall, you can follow this order:

- Click <code className="action">Start</code>.
- Click <code className="action">Search</code>.
- Search for "Windows Firewall" in the search bar.
- Click <code className="action">Windows Firewall</code>.

Then click <code className="action">Advanced settings</code>.

<img className="thumbnail" alt="Step1" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step1.PNG" loading="lazy" />

### Step 2: Enable an inbound rule

In the window that appears, you will see settings such as:

- Inbound and Outbound Rules
- Connection Security Rules
- Server Firewall Monitoring Options

Selecting <code className="action">Inbound Rules</code> displays all preconfigured Windows Server rules associated with network connections and incoming packets. Some of these rules are not enabled by default. If you want to enable them, right-click the rule and select the <code className="action">Enable rule</code> option.

<img className="thumbnail" alt="Step1" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step2.PNG" loading="lazy" />

### Step 3: Create a new rule 

To create a new rule, go to the <code className="action">Action</code> menu and select <code className="action">New Rule</code>.
Click the <code className="action">New Rule</code> option in the right-hand pane.

<img className="thumbnail" alt="Step3" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step3.PNG" loading="lazy" />

### Step 4: Define the type of rule to activate

The Rule Wizard provides options to define the type of rule to create. Select the <code className="action">Port</code> check box.

<img className="thumbnail" alt="Step4" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step4.PNG" loading="lazy" />

### Step 5: Define the port type to activate

In the next step, define the port type to enable:

<img className="thumbnail" alt="Step5" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step5.PNG" loading="lazy" />

:::info
:::

>- TCP (Transmission Control Protocol)
>It is a connection-orientated protocol, i.e. with TCP, it will be possible to create connections between them in order to send data streams. This protocol ensures that data is delivered to the recipient in the same order and in the same error-free manner.
>
> - UDP (User Datagram Protocol)
> This is a non-connection-orientated protocol. Its development is based on the exchange of datagrams and facilitates the sending of datagrams across the network. You will need to have established a connection to the destination beforehand.
>
>You can also select the <code className="action">All local ports</code> checkbox to enable all TCP or UDP ports on a non-secure server. You can also select the <code className="action">Specific local ports</code> check box to determine which port should be allowed. 
>

### Step 6: Allow or block the connection

To define the action this rule will trigger, the following options are available. Select the one that works for you.

- **Allow the connection**. This option allows full communication through this port.
- **Allow the connection if it is secure**. This option allows data to be transmitted only if the connection is authenticated via IPsec.
- **Block the connection**. This option prevents data from being routed through this port.

Select the <code className="action">Allow Connection</code> option and click <code className="action">Next</code>.

<img className="thumbnail" alt="Step6" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step6.PNG" loading="lazy" />

### Step 7: Define the firewall profile and name to apply

Finally, you must choose which profiles the rule should apply to, from public, domain or private profiles.
You can enable them all if you want.

<img className="thumbnail" alt="Step7" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step7.PNG" loading="lazy" />

Give the new rule a name and description (optional) to make it easier to use:

<img className="thumbnail" alt="Step7_01" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step7-01.PNG" loading="lazy" />

Click the <code className="action">Finish</code> button to complete the process and create the new rule.

<img className="thumbnail" alt="Step7_02" src="/images/bare-metal-cloud/dedicated-servers/activate-port-firewall-soft-win/step7_02.PNG" loading="lazy" />

You can then make changes to the settings of the new rule you have created.
