## Objective

With our [Managed Bare Metal solutions](https://www.ovhcloud.com/en-gb/managed-bare-metal/), you can add resources that are billed per hour of usage.

**This guide will show you how to add hourly resources via the Managed Bare Metal vSphere interface.**

## Requirements

- a [Managed Bare Metal](https://www.ovhcloud.com/en-gb/managed-bare-metal/) solution
- [the "Add resources"](/guides/bare-metal-cloud/managed-bare-metal/change-user-rights/) right for the datacentre concerned (this right is granted via the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB))
- access to the vSphere client

## Instructions

### Select the resource

To access the interface where you can add hourly resources, select the datacenter, then click <code className="action">Configure</code>.

<img className="thumbnail" alt="Add a host" src="/images/bare-metal-cloud/managed-bare-metal/adding-hourly-resources/addhost_ess_01.png" loading="lazy" />

In our example, we will add a host server that will be billed per hour. Once you have chosen a model, click <code className="action">Next</code>. Please note that to add a datastore, you will need to click on the <code className="action">Add storage</code> tab.

<img className="thumbnail" alt="Add a host" src="/images/bare-metal-cloud/managed-bare-metal/adding-hourly-resources/addhost_ess_02.png" loading="lazy" />

### Confirm the order

To confirm and finalise your order, click <code className="action">Next</code>.

<img className="thumbnail" alt="confirm order" src="/images/bare-metal-cloud/managed-bare-metal/adding-hourly-resources/addhost_ess_03.png" loading="lazy" />

### Track the setup

Once you have confirmed your order, you can track progress as the resource is being added.

<img className="thumbnail" alt="track setup" src="/images/bare-metal-cloud/managed-bare-metal/adding-hourly-resources/addhost_ess_04.png" loading="lazy" />

A task will also appear in the 'recent tasks' list on your vSphere interface. You can also use this task to track the resource addition.
