## Objective

vSphere client user permissions and passwords are managed from the OVHcloud Control Panel.

**Learn how to change your user password**

## Requirements

- access to the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB)
- a user account created from the OVHcloud Control Panel. For more information, read [this guide](/guides/bare-metal-cloud/managed-bare-metal/manager-ovhcloud#users-tab/)

## Instructions

### Change Password

Log in to your [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB), go to <code className="action">Bare Metal Cloud</code> (1), click <code className="action">Managed Bare Metal</code> (2) and select your server from the list (3). Click the <code className="action">Users</code> (4) tab.

<img className="thumbnail" alt="control panel" src="/images/bare-metal-cloud/managed-bare-metal/changer-user-password/userpassword1.png" loading="lazy" />

Click the <code className="action">(...)</code> button to the right of the user concerned and then click <code className="action">Change Password</code>.

<img className="thumbnail" alt="change password" src="/images/bare-metal-cloud/managed-bare-metal/changer-user-password/userpassword2.png" loading="lazy" />

Enter a new password and confirm it.

<img className="thumbnail" alt="change password" src="/images/bare-metal-cloud/managed-bare-metal/changer-user-password/userpassword3.png" loading="lazy" />

:::info
If you do not enter a password, a randomly generated password will be emailed to the user's associated address.

:::


:::warning
:::

>We recommend that you follow these few best practices to ensure that your infrastructure is not compromised. Your password must:
>
> - Have at least 8 characters.
> - Have at least 3 character types.
> - Not to be drawn from the dictionary.
> - Not include personal information.
> - Not be used for multiple access.
> - Be stored in a password vault.
> - Be changed every 3 months.
> - Be different from previous passwords.
>
