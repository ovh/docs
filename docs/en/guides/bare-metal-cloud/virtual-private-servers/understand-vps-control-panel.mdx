### Dashboard <a name="controlpanel"></a>

The <code className="action">Home</code> tab is the **main dashboard** of your VPS.

It centralises **key information about the service** and provides access to **essential management actions**.

<img className="thumbnail" alt="VPS Home" src="/images/bare-metal-cloud/virtual-private-servers/understand-vps-control-panel/vpshome.png" loading="lazy" />

#### Your VPS <a name="myvps"></a>

Find below the basic information about your VPS and the service status. Click on the tabs below to display the details.

<Tabs>
  <Tab label="Name">
    To customise the name of your VPS, click on the <code className="action">...</code> button and select <code className="action">Change the name</code>. This feature is useful for easier navigation in the Control Panel when managing multiple VPS services. However, the internal service name remains in the format *VPS-XXXXXXX.VPS.ovh.net*.
  </Tab>
  <Tab label="Boot">
    The boot mode indicated is either:
    
    - In **normal mode** (*LOCAL*), where the server loads the installed operating system.
    - In **rescue mode**, provided by OVHcloud for troubleshooting.
    
    Use the <code className="action">...</code> button to [reboot the VPS](#rebootvps) or boot it in rescue mode if necessary.
    
    If needed, find more information in our guide on [rescue mode](/guides/bare-metal-cloud/virtual-private-servers/rescue/).
  </Tab>
  <Tab label="OS/Distribution">
    This is the currently installed operating system. Use the <code className="action">...</code> button to [reinstall the same operating system or choose another one from the available options](#reinstallvps).
    
    :::warning
    A reinstallation will delete all data currently hosted on the VPS (except for additional disks).

    :::

    
    :::info
    If you ordered a **Windows** VPS, you can only choose a Windows OS for reinstallation. Similarly, if Windows was not selected during the order, it cannot be installed after the VPS is delivered.

    :::

    
    Once the system is installed, you are responsible for applying the operating system security updates. You can find more information in the section "[Reinstall your VPS](#reinstallvps)" as well as in our guide "[Securing a VPS](/guides/bare-metal-cloud/virtual-private-servers/secure-your-vps/)".
  </Tab>
  <Tab label="Zone/Location">
    These sections provide information about the location of your VPS. This can be useful for identifying and assessing any potential impacts on your service, such as those mentioned in [incident or maintenance reports](https://bare-metal-servers.status-ovhcloud.com/).
  </Tab>
</Tabs>

Click on the tabs below to display the details of this section.

<Tabs>
  <Tab label="Model">
    This item indicates the commercial reference identifying the VPS model, corresponding to the [VPS offers on our website](https://www.ovhcloud.com/en-gb/vps/).
  </Tab>
  <Tab label="vCores/Memory/Storage">
    The current resources of your VPS are displayed here and can be updated separately by clicking on the corresponding link. Note that upgrades are limited by the chosen VPS model and may only be available by moving to a [higher range](https://www.ovhcloud.com/en-gb/vps/).
  </Tab>
  <Tab label="Additional disks">

#### IP <a name="ip"></a>

Click on the tabs below to display the details of this section.

<Tabs>
  <Tab label="IPv4">
    The main public IPv4 address of the VPS is automatically configured during installation. Find more information on IP management in our guide "[Configuring an alias IP address](/guides/bare-metal-cloud/virtual-private-servers/configuring-ip-aliasing/)".
  </Tab>
  <Tab label="IPv6/Gateway">
    Find the public IPv6 address and the associated gateway address here. These are automatically attached to the VPS during installation. Find more information in our guide "[Configuring IPv6 on a VPS server](/guides/bare-metal-cloud/virtual-private-servers/configure-ipv6/)".
  </Tab>
  <Tab label="Secondary DNS">
    This feature is useful for hosting DNS services. Consult our guide "[Configuring an OVHcloud secondary DNS on a VPS](/guides/bare-metal-cloud/virtual-private-servers/adding-secondary-dns-on-vps/)" for more details on this subject.
  </Tab>
</Tabs>


#### Backup <a name="save"></a>

These options refer to additional VPS services for backing up and restoring your system.

<Tabs>
  <Tab label="Snapshot">
    A snapshot on a VPS is an instant backup of the server's state, allowing you to quickly restore the system in case of a problem. The `Snapshot` option allows you to create a manual snapshot as a single restore point.
  </Tab>
  <Tab label="Automated backup">
    A daily system backup (excluding additional disks) is automatically performed and kept for 24 hours (applicable only to services ordered from August 7, 2025). By switching to the "**Premium Automated Backup**" option, you will have the last 7 daily backups of your VPS, which you can use for mounting and restoring.  
    Compared to manual snapshots, this feature increases data security by creating multiple restore points at regular intervals.
  </Tab>
</Tabs>


Find all information on the backup solutions available for your service on the [VPS product page](https://www.ovhcloud.com/en-gb/vps/options/) and in [our respective guides](/guides/bare-metal-cloud/virtual-private-servers/overview/).

#### Reboot your VPS <a name="rebootvps"></a>

A reboot may be necessary to apply configuration updates or to resolve a malfunction. Where possible, perform a "software reboot" from the server's graphical interface (Windows, Plesk, etc.) or via the command line below:

```bash
sudo reboot
```

However, you can perform a forced reboot at any time in your [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB). From the <code className="action">Home</code> tab, click on the <code className="action">...</code> button next to `Boot` in the **Your VPS** section. Select <code className="action">Reboot my VPS</code> and click <code className="action">Confirm</code> in the window that appears.

<img className="thumbnail" alt="Reboot" src="/images/assets/screens/control-panel/product-selection/bare-metal-cloud/vps/cp-reboot.png" loading="lazy" />

#### Reinstall your VPS <a name="reinstallvps"></a>

The reinstallation of your VPS can be done from your Control Panel. This operation is generally used in case of system problems, environment change or to start with a clean installation.

Click on the <code className="action">...</code> button to the right of <code className="action">OS/Distribution</code>, then on <code className="action">Reinstall my VPS</code>.

<img className="thumbnail" alt="Reinstall" src="/images/assets/screens/control-panel/product-selection/bare-metal-cloud/vps/cp-reinst.png" loading="lazy" />

In the window that appears, choose an operating system from the drop-down list. The options offered are [images compatible with an OVHcloud VPS](/guides/public-cloud/compute/image-life-cycle/) and are immediately functional after installation.

If you have selected a compatible operating system, you can provide a **public key** to be automatically installed. Two options are available:

- Manually copy the key string and paste it into the `Your SSH Public Key` field.
- If you have previously [stored a public key](/guides/bare-metal-cloud/dedicated-servers/import-keys-control-panel/) in your [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB), select the desired key from the `SSH Key to pre-install` drop-down menu.

<img className="thumbnail" alt="VPSnewreinstallation" src="/images/bare-metal-cloud/virtual-private-servers/understand-vps-control-panel/reinstall.png" loading="lazy" />

For more information on this topic, consult our guides:

- [How to create and use authentication keys for SSH connections to OVHcloud servers](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys-dedicated/)
- [Tutorial - How to use PuTTY for SSH connections and authentication](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows/)

If you have selected an SSH key and do not need a password to connect, enable the option `I do not wish to receive my VPS authentication codes by email`.

:::warning
Reinstallation will format all the server's disks. It is strongly recommended to create a snapshot of your VPS before proceeding, so that you can return to the previous state in case of a problem.

:::


:::info
**Licenses**

Some operating systems or proprietary platforms, such as Plesk or cPanel, require licenses that generate additional costs. Licenses can be managed from your Control Panel: go to the <code className="action">Bare Metal Cloud</code> section, then click on <code className="action">Licenses</code> in the left-hand navigation bar.

To have a **Windows** operating system running on a VPS, you must have previously chosen it **in the ordering process**. A VPS with another OS installed cannot be reinstalled with Windows via the method described above.

:::


The reinstallation process can take a few minutes.
