## Objective

VMware Update Manager allows you to keep your hosts up to date by installing Bug Fixes and Security Patches without intervention from our team.     

:::info
vCenter updates or major updates will still require our involvement.

:::


**This guide will present the Update Manager functionalities**

## Requirements

- being an administrative contact of your [Hosted Private Cloud infrastructure](https://www.ovhcloud.com/en-gb/enterprise/products/hosted-private-cloud/) to receive login credentials.
- a user account with access to vSphere (created in the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB))

## Instructions

### Maintenance Mode

Before working on a host, you'll need to put it in maintenance mode.

Indeed, patching often requires a restart of the host and would impact your live VMs.<br/>

With that in mind, in the vSphere interface menu, go to the <code className="action">Hosts and Clusters</code> dashboard.

<img className="thumbnail" alt="Maintenance" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en01menu.png" loading="lazy" />

On the left side, find your host and right-click on it.  
In the <code className="action">Maintenance Mode</code> section, select <code className="action">Enter Maintenance Mode</code>.

<img className="thumbnail" alt="Maintenance" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en02maintenance.png" loading="lazy" />

Make sure the box in the following window is checked and click <code className="action">OK</code>.

<img className="thumbnail" alt="Maintenance" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en03enter.png" loading="lazy" />

Assuming DRS is implemented, any live VM will be moved.

:::info
If you customized your environment, you may have to manually move live VMs from your host before putting it in Maintenance Mode.

:::


You may see the following warning:     

<img className="thumbnail" alt="Maintenance" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en04warning.png" loading="lazy" />

Your host is now showing in maintenance mode.

<img className="thumbnail" alt="Maintenance" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en05maintenanced.png" loading="lazy" />

### Update Manager

Select your host and go to the <code className="action">Update</code> tab.

You can see a summary of what is set and its compliance.     
Before trusting what is shown, let's set the baseline against which compliance will be checked.

<img className="thumbnail" alt="Update" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en06summary.png" loading="lazy" />

In the `Attached Baselines` section, click on <code className="action">Attach</code> then <code className="action">Attach Baseline or Baseline Group</code>.

<img className="thumbnail" alt="Update" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en07attach.png" loading="lazy" />

There are predefined Baselines which are the recommended patching level for your hosts depending on criticality of the updates.

:::info
We'll be using the Critical Patches in this example but you can either use or create your own baselines. You can also apply several baselines to cover different scopes for a same host.

:::


Select the required baseline and click <code className="action">Attach</code>.

<img className="thumbnail" alt="Update" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en08define.png" loading="lazy" />

Now, the compliance summary may look very different than it used to.     

<img className="thumbnail" alt="Update" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en09noncompliant.png" loading="lazy" />

Back in the `Attached Baselines` section, check the box to select all assigned baselines and click on <code className="action">Stage</code>.

<img className="thumbnail" alt="Update" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en10bisstage.png" loading="lazy" />

Select the host and click on <code className="action">Stage</code> again.

<img className="thumbnail" alt="Update" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en10terstagea.png" loading="lazy" />

The staging process starts and will last for a while.

<img className="thumbnail" alt="Update" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en10terstage.png" loading="lazy" />

In the `Attached Baselines` section still, check the box to select all assigned baselines and click on <code className="action">Remediate</code>.

<img className="thumbnail" alt="Update" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en10remediate.png" loading="lazy" />

Select the host and click on <code className="action">Remediate</code> again.

<img className="thumbnail" alt="Update" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en11remediate.png" loading="lazy" />

The updating process starts and will last for a while. Your host will restart if needed.

<img className="thumbnail" alt="Update" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en12remediating.png" loading="lazy" />

Once the process has gone through, the compliance check will happen again (you can force it by clicking on the check compliance link) and you will see a green checkmark on the Compliance level.

<img className="thumbnail" alt="Update" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-update-manager/en13compliant.png" loading="lazy" />

Your host is now fully up-to-date.

Don't forget to get it out of Maintenance Mode and it will be back in production.
