## Objective

**Learn how to configure a DHCP server in a segment**

:::warning
OVHcloud provides services for which you are responsible, with regard to their configuration and management. It is therefore your responsibility to ensure that they work properly.

This guide is designed to assist you as much as possible with common tasks. However, we recommend contacting a [specialist provider](https://partner.ovhcloud.com/en-gb/directory/) if you experience any difficulties or doubts when it comes to managing, using or setting up a service on a server.

## Requirements

- Being an administrative contact of your [Hosted Private Cloud infrastructure](https://www.ovhcloud.com/en-gb/enterprise/products/hosted-private-cloud/) to receive login credentials
- A user account with access to the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB)
- Having **NSX** deployed with two overlay and VLAN segments configured in your NSX configuration. Use our guide on [segment management in NSX](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/) for more information.

## Instructions

We will configure DHCP for : 

- An overlay segment behind the gateway **ovh-T1-gw** 
- A segment on a VLAN connected to the gateway **ovh-T1-gw**.

### Common DHCP configuration for all overlay segments

First we will create a DCHP server common to all segments in Overlay.

Through the NSX interface, go to the <code className="action">Networking</code> tab and click on <code className="action">Networking Profiles</code> on the left in the **Settings** section. Then go to the <code className="action">DHCP</code> tab and click <code className="action">ADD DHCP PROFILE</code>.

<img className="thumbnail" alt="01 Common DHCP configuration 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/01-common-dhcp-configuration01.png" loading="lazy" />

Type <code className="action">Name</code> in **Name** and click <code className="action">SAVE</code>.

<img className="thumbnail" alt="01 Common DHCP configuration 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/01-common-dhcp-configuration02.png" loading="lazy" />

The DCHP server is active, it uses a network in 100.96.0.1/30, do not use this network in one of your segments.

<img className="thumbnail" alt="01 Common DHCP configuration 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/01-common-dhcp-configuration03.png" loading="lazy" />

### DHCP assignment to the ovh-T1-gw gateway

In the <code className="action">Networking</code> tab, click on <code className="action">Tier-1-Gateways</code> on the left in the **Connectivity** section.

<img className="thumbnail" alt="02 Attach DHCP to OVHT1 GATEWAY 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/02-attach-dhcp-to-ovht1-gateway01.png" loading="lazy" />

Click the <code className="action">three vertical dots</code> and choose <code className="action">Edit</code> from the menu.

<img className="thumbnail" alt="02 Attach DHCP to OVHT1 GATEWAY 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/02-attach-dhcp-to-ovht1-gateway02.png" loading="lazy" />

<img className="thumbnail" alt="02 Attach DHCP to OVHT1 GATEWAY 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/02-attach-dhcp-to-ovht1-gateway03.png" loading="lazy" />

<img className="thumbnail" alt="02 Attach DHCP to OVHT1 GATEWAY 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/02-attach-dhcp-to-ovht1-gateway04.png" loading="lazy" />

Click <code className="action">SAVE</code>.

<img className="thumbnail" alt="02 Attach DHCP to OVHT1 GATEWAY 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/02-attach-dhcp-to-ovht1-gateway05.png" loading="lazy" />

Click <code className="action">CLOSE EDITING</code>.

<img className="thumbnail" alt="02 Attach DHCP to OVHT1 GATEWAY 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/02-attach-dhcp-to-ovht1-gateway06.png" loading="lazy" />

### Setting up DHCP on an Overlay segment

From the NSX interface, go to the <code className="action">Networking</code> tab and click on <code className="action">Segments</code> on the left in the **Connectivity** section.

Go to the <code className="action">Segments</code> section, click on the configuration icon indicated with <code className="action">three vertical dots</code> to the left of your segment and choose <code className="action">Edit</code>.

<img className="thumbnail" alt="03 add DHCP ON Segment 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/03-configure-dhcp-overlay-segment01.png" loading="lazy" />

Click <code className="action">Set DHCP CONFIG</code>.

<img className="thumbnail" alt="03 add DHCP ON Segment 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/03-configure-dhcp-overlay-segment02.png" loading="lazy" />

Fill in this information :

- **DHCP Type** : Leave <code className="action">DHCP Server Gateway</code>.
- **DHCP Ranges** : Enter your range <code className="action">192.168.1.10-192.168.1.200</code>.
- **DNS Servers** : Add OVHcloud DNS server <code className="action">213.186.33.99</code>.

Click on <code className="action">APPLY</code>.

<img className="thumbnail" alt="03 add DHCP ON Segment 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/03-configure-dhcp-overlay-segment03.png" loading="lazy" />

Click <code className="action">SAVE</code>.

<img className="thumbnail" alt="03 add DHCP ON Segment 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/03-configure-dhcp-overlay-segment04.png" loading="lazy" />

Click <code className="action">CLOSE EDITING</code>.

<img className="thumbnail" alt="03 add DHCP ON Segment 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/03-configure-dhcp-overlay-segment05.png" loading="lazy" />

Virtual machines in this segment can now be configured with DHCP.

### Setting up DCHP on a VLAN segment

On a VLAN segment it is not possible to use the profile created for Overlay segments.

In order to have a DHCP server on this segment, we will create a DHCP configuration with a new profile directly attached to the segment.

If you do not have a VLAN type segment, use the [Segment Management in NSX](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/) guide to create it with these settings :

- **VLAN Subnet**: 192.168.100.0/24.
- **Gateway and interface IP address** : 192.168.100.254/24.

Go to the <code className="action">Networking</code> tab, click on <code className="action">Segments</code> on the left in the **Connectivity** section, then click on the <code className="action">three vertical dots</code> on the left of your VLAN segment and choose <code className="action">Edit</code> from the menu.

<img className="thumbnail" alt="04 Configure DHCP fo VLAN SEGMENT 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/04-configure-dhcp-for-vlan-segment-01.png" loading="lazy" />

Click <code className="action">SET DHCP CONFIG</code>.

<img className="thumbnail" alt="04 Configure DHCP fo VLAN SEGMENT 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/04-configure-dhcp-for-vlan-segment-02.png" loading="lazy" />

Leave <code className="action">Local DHCP Server</code> in **DHCP Type**, click the <code className="action">three vertical dots</code> to the right of **DHCP Profile** and choose <code className="action">Create New</code> from the menu.

<img className="thumbnail" alt="04 Configure DHCP fo VLAN SEGMENT 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/04-configure-dhcp-for-vlan-segment-03.png" loading="lazy" />

Enter this information :

- **Name**: Leave `DHCP-VLAN100`.
- **Server IP Address** : IP address of DHCP server `192.168.100.253/24`.

Then select your <code className="action">Edge Cluster</code> and click <code className="action">SAVE</code>.

<img className="thumbnail" alt="04 Configure DHCP fo VLAN SEGMENT 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/04-configure-dhcp-for-vlan-segment-04.png" loading="lazy" />

Verify in **DHCP Profile** that the profile is present and enter this information :

- **DHCP Server** : DHCP server address `192.168.100.253/24`.
- **DHCP Ranges** : DHCP Server range `192.168.100.10-192.168.100.200`.
- **DNS Servers** : OVHcloud DNS server IP address `213.186.33.99`.

Then click <code className="action">APPLY</code>.

<img className="thumbnail" alt="04 Configure DHCP fo VLAN SEGMENT 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/04-configure-dhcp-for-vlan-segment-05.png" loading="lazy" />

Click <code className="action">SAVE</code>.

<img className="thumbnail" alt="04 Configure DHCP fo VLAN SEGMENT 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/04-configure-dhcp-for-vlan-segment-06.png" loading="lazy" />

Click <code className="action">CLOSE EDITING</code>.

<img className="thumbnail" alt="04 Configure DHCP fo VLAN SEGMENT 07" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/04-configure-dhcp-for-vlan-segment-07.png" loading="lazy" />

The DHCP server is active on this VLAN segment.
