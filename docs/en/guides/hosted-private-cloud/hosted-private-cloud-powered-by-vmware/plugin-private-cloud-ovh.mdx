## Objective

With the OVHcloud plugin, you can add dedicated resources to your infrastructure in just a few minutes.

**Find out how to use the OVHcloud plugin in vSphere.**

## Requirements

- an [OVHcloud Hosted Private Cloud solution](https://www.ovhcloud.com/en-gb/enterprise/products/hosted-private-cloud/)
- access to the vSphere interface

## Instructions

Two dedicated resources can be billed hourly as an option:

- host servers
- datastores

In the vSphere web client, simply go to the "Host and Cluster" section, and open the tree-view on the left-hand side. You can then access the plugin menus via the <code className="action">Configure</code> tab for the datacentre or the cluster.

The <code className="action">Add Host</code> menu is dedicated to host servers. You can view their technical details and order new host servers here.

<img className="thumbnail" alt="OVHcloud plugin - add host" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/plugin-private-cloud-ovh/Plugin01.jpg" loading="lazy" />

You can also order additional data stores from the <code className="action">Add Storage</code> menu.

<img className="thumbnail" alt="OVHcloud plugin - add storage" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/plugin-private-cloud-ovh/Plugin02.jpg" loading="lazy" />

There is also another way to access these menus. You can right-click on the infrastructure’s datacentre or cluster, then choose <code className="action">OVHcloud</code>.

<img className="thumbnail" alt="OVHcloud Hosted Private Cloud Option" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/plugin-private-cloud-ovh/Plugin03.jpg" loading="lazy" />
