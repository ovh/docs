## Objective

You can create an alert on all items in your Private Cloud: the data centre itself, the clusters, the VMs, the datastores, the network ...

**This guide explains how to create alerts on your vSphere client.**

## Requirements

- a [Hosted Private Cloud infrastructure](https://www.ovhcloud.com/en-gb/enterprise/products/hosted-private-cloud/)
- a user account with access to [vSphere](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vsphere-interface-connexion/) (created in the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB))

## Instructions

### Creating an alert

To create an alert, right-click on the data centre or any other item you want to monitor, and then click on <code className="action">Alarms</code> and <code className="action">New Alarm Definition</code>.

<img className="thumbnail" alt="Alert creation" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-an-alert/alarms01.png" loading="lazy" />

### Setting name and target

The first step is to name the alert and set its target. You can also add a description.

<img className="thumbnail" alt="Name and target" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-an-alert/alarms02.png" loading="lazy" />

### Setting alert rules

The second step is to define the rules of the alert and the actions it triggers.

The `IF` field allows you to set an alert trigger from a selection of variables. Depending on the variable chosen, a list of arguments will be offered.

The `THEN` field allows you to indicate that the alert is triggered with a certain degree of criticality and will result in actions such as sending an email, executing a script or shutting down a VM.

<img className="thumbnail" alt="Alert rules" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-an-alert/alarms03.png" loading="lazy" />

This allows you to monitor the RAM of a host, for example, by specifying a threshold not to exceed before its status goes on alert and you receive a warning email.

:::info
You can add several rules to your alert by clicking <code className="action">ADD ANOTHER RULE</code>.

:::


### Suspending an alert

The third step allows you to set the end of the alert criteria and trigger new actions.

<img className="thumbnail" alt="Suspending an alert" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-an-alert/alarms04.png" loading="lazy" />

### Alert summary

The last step shows you a summary of the rules defined. You can activate the alarm by checking the cursor or choose to activate it later by right-clicking the selected item and then clicking <code className="action">Alarms</code> and <code className="action">Enable Alarm Actions</code>.

<img className="thumbnail" alt="Alert summary" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/create-an-alert/alarms05.png" loading="lazy" />

You can also configure the frequency of repeat alerts in this step.
