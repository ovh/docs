## Objective

In certain cases — like replacing a datastore or scaling it up to a higher capacity, for example — it may be useful to remove a datastore from your cluster.

**This guide will show you how to securely remove a datastore from your infrastructure.**

## Requirements

* an [OVHcloud Hosted Private Cloud](https://www.ovhcloud.com/en-gb/enterprise/products/hosted-private-cloud/) solution
* access to the vSphere management interface

## Instructions

:::warning
For security reasons, the removal request will be blocked if you have virtual machines (VMs) on the datastore concerned (they will be listed in the confirmation window).

:::


To remove a datastore, right-click on the resource concerned. Then select <code className="action">OVHcloud</code>, and <code className="action">Remove this Storage</code>.

<img className="thumbnail" alt="Choice of datastore" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/delete-datastore/removedatastore01.png" loading="lazy" />

A confirmation window will pop up. Confirm by clicking <code className="action">Next</code>.

<img className="thumbnail" alt="Confirm removal" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/delete-datastore/removedatastore02.png" loading="lazy" />

The removal request will then be processed.

<img className="thumbnail" alt="Removal confirmed" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/delete-datastore/removedatastore03.png" loading="lazy" />

You can also monitor the progress of the datastore removal in <code className="action">Recent Tasks</code>.

<img className="thumbnail" alt="Removal monitoring task" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/delete-datastore/removedatastore04.png" loading="lazy" />
