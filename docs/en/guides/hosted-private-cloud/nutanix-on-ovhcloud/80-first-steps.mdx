## Objective

This guide will outline the steps you need to take to get started with your Nutanix on OVHcloud cluster:

- [Deploy a rebound VM](#deploy-vm)
- [Secure cluster](#secure-cluster)

:::warning
OVHcloud provides services for which you are responsible, responsible and responsible for their configuration. You are therefore responsible for ensuring that it works properly.

This guide is designed to help you with common tasks. Nevertheless, we recommend contacting the [OVHcloud Professional Services team](https://www.ovhcloud.com/en-gb/professional-services/) or a [specialist provider](https://partner.ovhcloud.com/en-gb/directory/) if you experience any difficulties or doubts when it comes to administering, using or setting up a service on a server.

:::


**Find out how to get started with your Nutanix cluster.**

## Requirements

- A Nutanix cluster in your OVHcloud account
- Access to your [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB)
- You must be logged in to Prism Central on the cluster

:::warning
Some software, such as Microsoft products, require a license. You must therefore ensure that all installed systems and software have these licenses.

:::


## Instructions

### Deploy a rebound VM <a name="deploy-vm"></a>

The rebound VM will serve as an entry point for the operations you will need to carry out to secure your cluster.
It can also be used as a relay to reach other VMs after being put into production.

Continue reading this guide, depending on your OS: [Linux - Rebound via SSH](#ssh) or [Windows - Rebound via RDP](#rdp).

#### Rebound via SSH <a name="ssh"></a>

##### Creating and configuring the Linux VM

In this example, the network configuration is as follows:

- Network: 172.16.0.0/22
- Mask: 255.255.252.0
- Gateway: 172.16.3.254

:::warning
Adapt this configuration to your cluster.
You can find this information by using this [OVHcloud API call](https://api.ovh.com/console/#/nutanix/%7BserviceName%7D~GET).

:::

<img className="thumbnail" alt="Prism Central Dashboard - Menu VMs" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/PrismCentralDashBoardWithVMMenu.PNG" loading="lazy" />

<img className="thumbnail" alt="Prism Central Dashboard - VM Management" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/PrismCentralDashVmDashBoard.PNG" loading="lazy" />

Customize the name and features of the VM.

<img className="thumbnail" alt="Deploy VM" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/deploy_vm.png" loading="lazy" />

Click <code className="action">Next</code>.

You then need to attach a disk. To do this, you can select the image already present on your cluster (Alpine Linux).

<img className="thumbnail" alt="Attach Disk1" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/attach_disk.png" loading="lazy" />

<img className="thumbnail" alt="Attach Disk2" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/attach_disk2.png" loading="lazy" />

Then click <code className="action">Attach Subnet</code>.

<img className="thumbnail" alt="Creating a virtual machine - Step 9" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/CreateVM09.PNG" loading="lazy" />

Click <code className="action">Next</code>.

Select cloud-init, copy the "cloud-init" script, then click <code className="action">Next</code> and finally <code className="action">Create VM</code>.

<img className="thumbnail" alt="Customization with cloud-init" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/cloud-init_Alpine.PNG" loading="lazy" />

:::warning
Adapt this configuration to your cluster.
You can find this information by using this [OVHcloud API call](https://api.ovh.com/console/#/nutanix/%7BserviceName%7D~GET).
Make sure to adapt your password and IP configuration.

:::


```yaml
#cloud-config
hostname: bastion-ssh
fqdn: bastion-ssh.domain.local
users:
  - name: bastion
    sudo: ALL=(ALL) NOPASSWD:ALL
    groups: sudo
    shell: /bin/ash
    ssh_pwauth: true
    lock_passwd: false
    plain_text_passwd: OVHcloudR0cks!

growpart:
  mode: growpart
  devices: ["/dev/sda2"]
  ignore_growroot_disabled: true

write_files:
   - path: /etc/network/interfaces
     content: |
        auto lo
        iface lo inet loopback

        auto eth0
        iface eth0 inet static
        address 172.16.2.200
        netmask 255.255.255.252
        gateway 172.16.3.254

runcmd:
   - echo "nameserver 213.186.33.99" > /etc/resolv.conf
   - rc-service networking restart
   - apk update
   - apk upgrade
   - apk add sudo
   - sed -i s/'PasswordAuthentication no'/'PasswordAuthentication yes'/g /etc/ssh/sshd_config
   - sed -i s/'#KbdInteractiveAuthentication yes'/'KbdInteractiveAuthentication yes'/g /etc/ssh/sshd_config
   - rc-service sshd restart
   - lvextend -l +100%FREE /dev/vg0/lv_root
   - resize2fs /dev/vg0/lv_root
   - reboot

final_message: "The system is finally up, after $UPTIME seconds"
```

Open the console after restarting the VM. You can see that the VM has taken the settings from the cloud-init file.

<img className="thumbnail" alt="Customization with cloud-init" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/bastion-sshVM.PNG" loading="lazy" />

#### Load Balancer configuration

Log in to your [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB). Open the Nutanix Cluster configuration page.

In the `Cluster network` box at the bottom of the page, click on the Load Balancer.

<img className="thumbnail" alt="Configure Load Balancer 01 ssh" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/config-lb1-ssh.PNG" loading="lazy" />

In the <code className="action">Server clusters</code> tab, click <code className="action">Add a server cluster</code>.

<img className="thumbnail" alt="Configure Load Balancer 02 ssh" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/config-lb2-ssh.PNG" loading="lazy" />

Name your server farm, then select <code className="action">TCP</code> and enter this information:

- Port: 22
- Datacenter: ALL
- Private network: nutanix

<img className="thumbnail" alt="Configure Load Balancer 03 ssh" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/config-lb3-ssh.PNG" loading="lazy" />

Click <code className="action">Add</code> to confirm the creation of the server cluster.

Then click <code className="action">Add a server</code>.

<img className="thumbnail" alt="Configure Load Balancer 04 ssh" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/config-lb4-ssh.PNG" loading="lazy" />

Enter these values:

- **Name (optional)**: `SSH`
- **IPv4 address**: `IP address of your Windows VM`
- **Port**: `22`

Click <code className="action">Add</code> to confirm the server creation.

<img className="thumbnail" alt="Configure Load Balancer 05-ssh" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/config-lb5-ssh.PNG" loading="lazy" />

Then click on the <code className="action">Front-ends</code> tab, and on <code className="action">Add a front-end</code>.

<img className="thumbnail" alt="Configure Load Balancer 06-ssh" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/config-lb6-ssh.PNG" loading="lazy" />

Name your front-end, choose the <code className="action">TCP</code> protocol and modify these values:

- **Port**: `22`
- **Datacenter**: `ALL`
- **Default server cluster**: `rebound-ssh (TCP)`

Click <code className="action">Add</code>.

<img className="thumbnail" alt="Configure Load Balancer 07 ssh" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/config-lb7-ssh.PNG" loading="lazy" />

Click <code className="action">Apply configuration</code>.

<img className="thumbnail" alt="Configure Load Balancer 08 ssh" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/03a-configureloadbalancer07.png" loading="lazy" />

Select the <code className="action">Datacentre</code> and click <code className="action">Apply configuration</code>.

<img className="thumbnail" alt="Configure Load Balancer 09 ssh" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/03a-configureloadbalancer08.png" loading="lazy" />

You can track the progress of the changes in the <code className="action">Tasks</code> tab.

<img className="thumbnail" alt="Configure Load Balancer 10 ssh" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/03a-configureloadbalancer09.png" loading="lazy" />

The Load Balancer is now configured. Use your preferred terminal to connect to your machine.
You can enter your cluster’s DNS name or Load Balancer’s IP address:

<img className="thumbnail" alt="Connect to CVM" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/80-first-steps/cvm-ssh-linux2.PNG" loading="lazy" />

You can now rebound on the different elements of the cluster:

- CVMs
- Hosts
- Prism Element

