## Objective

Once an upgrade of one Nutanix software component is needed, let's review all the main steps to apply it.

**This guide explain the steps to upgrade your Nutanix Cluster.**

## Requirements

- A Nutanix Cluster in your OVHcloud account
- Access to the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB)

:::warning
OVHcloud is providing you with services for which you are responsible, with regard to their configuration and management. You are therefore responsible for ensuring they function correctly.

This guide is designed to assist you in common tasks as much as possible. Nevertheless, we recommend that you contact the [OVHcloud Professional Services team](https://www.ovhcloud.com/en-gb/professional-services/) or a [specialist service provider](https://partner.ovhcloud.com/en-gb/directory/) if you have difficulties or doubts concerning the administration, usage or implementation of services on a server.

:::


## Instructions

### Official documentation for upgrades

You can either look for this document: "The Nutanix upgrades: Life Cycle Manager" or visit the official Nutanix website for archived documents: [Software Documentation: Upgrade Guide](https://portal.nutanix.com/page/documents/details?targetId=Acropolis-Upgrade-Guide-v5_20:Acropolis-Upgrade-Guide-v5_20).

### Backup

As for any action on the configuration of the cluster system, it is strongly recommended to create a new backup or check the latest one.

### Items to update

Some updates are done from **Prism Central**. These are updates for:

- **Prism Central** itself
- **NCC*

Some other updated must be run from the **Prism Element**. These are updates for:

- **LCM**
- **AOS**
- **Foundation**
- **AHV**

:::warning
Before performing an update, make sure that the versions of **Prim Element** are supported by OVHcloud and that the version of **Prism Central** to be updated is compatible with **Prism Element**

Supported versions of **Prism Element** by OVHcloud are 5.20 LTS and 6.1 STS. You can update these subversions, but it is best to wait a month after a new subversion is released.

The compatibility of the version of **Prism Central** with **Prism Element** can be checked on the [NUTANIX Interoperability](https://portal.nutanix.com/page/documents/compatibility-interoperability-matrix/interoperability) website if you have a customer account on the Nutanix website.

:::


### Prism Central Upgrade

#### LCM Inventory

As documented in the official upgrade process, you should first launch a LCM Inventory to get a view of the software status of the Nutanix Cluster.

<img className="thumbnail" alt="First LCM Inventory" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/lcm_first_time.png" loading="lazy" />

Proceed to run the first or a new Inventory update:

<img className="thumbnail" alt="Proceed LCM Inventory" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/lcm_inventory_proceed.png" loading="lazy" />

After a pre-check phase, you will receive the results as soon as the inventory is done. The available upgrades will be displayed:

<img className="thumbnail" alt="LCM Result Upgrades available" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/lcm_upgrade_available.png" loading="lazy" />

Select the upgrades you want or update all components. You can also decide to manage those upgrades directly as explained in the next two sections.

#### Performing the upgrade

Once you are certain that you can launch the upgrade, open the <code className="action">Prism Central Settings</code>:

<img className="thumbnail" alt="Prism Central Settings" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/menu_prism_setting.png" loading="lazy" />

If there are available upgrades, you can select the ones you need to apply, then choose to only do the pre-check or upgrade immediately:

<img className="thumbnail" alt="Prism Available upgrade" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/required_upgrade.png" loading="lazy" />

The pre-check will be executed in any case:

<img className="thumbnail" alt="Prechecks upgrade" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/preupgrade_checks.png" loading="lazy" />

If you have selected the upgrade process, the process itself will be initiated:

<img className="thumbnail" alt="Upgrade start" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/upgrade_started.png" loading="lazy" />

During the execution, you might lose the connection to Prism Central:

<img className="thumbnail" alt="Prism disconnection" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/loosing_connection_prism_central.png" loading="lazy" />

After a few minutes, you can connect back to the Prism Central interface, and you can then check or wait for the end of the upgrade process:

<img className="thumbnail" alt="End of upgrade" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/upgrade_finished.png" loading="lazy" />

#### NCC upgrade

If there is one or more NCC upgrades available, you can download the ones you need and then launch the upgrade:

<img className="thumbnail" alt="Select the NCC release" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/ncc_available_upgrade.png" loading="lazy" />

#### Validation

##### **LCM Inventory update**

Update the LCM inventory. If no upgrades are available anymore, then only the list of installed software components releases will be presented:

<img className="thumbnail" alt="Up-to-date Nutanix cluster" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/lcm_result_after_upgrades.png" loading="lazy" />

##### **Prism Central upgrade validation**

You can also check that the Nutanix Cluster Prism Central is up-to-date if there is no upgrade available for your cluster: Click on the <code className="action">Prism Central Settings</code> and open <code className="action">Upgrade Prism Central</code>. There should be no available versions:

<img className="thumbnail" alt="No Prism Central upgrade" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/no_upgrade.png" loading="lazy" />

##### **NCC upgrade validation**

You can also check that the Nutanix Cluster NCC is up-to-date if there is no upgrade available for your cluster: Click on the <code className="action">Prism Central Settings</code> and open <code className="action">Upgrade Prism Central</code>. There should be no available versions in the NCC tab:

<img className="thumbnail" alt="No NCC upgrade" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/ncc_upgrade_done.png" loading="lazy" />

### Updating Prism Element

From the **Prism Central** dashboard, in the **Cluster Quick Access** frame, click your cluster.

<img className="thumbnail" alt="Upgrade Prism Element 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element01.png" loading="lazy" />

Open the Menu and click on <code className="action">LCM</code>.

<img className="thumbnail" alt="Upgrade Prism Element 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element02.png" loading="lazy" />

Click the <code className="action">Perform Inventory</code> button.

<img className="thumbnail" alt="Upgrade Prism Element 03" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element03.png" loading="lazy" />

Click <code className="action">Proceed</code>.

<img className="thumbnail" alt="Upgrade Prism Element 04" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element04.png" loading="lazy" />

Click <code className="action">Back to Inventory</code>.

<img className="thumbnail" alt="Upgrade Prism Element 05" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element05.png" loading="lazy" />

First, we will update **NCC**.

Check <code className="action">NCC</code> and click <code className="action">View Update Plan</code>.

<img className="thumbnail" alt="Upgrade Prism Element 06" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element06.png" loading="lazy" />

Click <code className="action">Apply 1 Updates</code>.

<img className="thumbnail" alt="Upgrade Prism Element 07" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element07.png" loading="lazy" />

Click <code className="action">Back to Software Updates</code>.

<img className="thumbnail" alt="Upgrade Prism Element 08" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element08.png" loading="lazy" />

Click <code className="action">NCC Check</code> to check the system before major updates.

<img className="thumbnail" alt="Upgrade Prism Element 09" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element09.png" loading="lazy" />

Leave `All Checks` and click <code className="action">Run</code>.

<img className="thumbnail" alt="Upgrade Prism Element 10" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element10.png" loading="lazy" />

Wait for the `Health check` task to complete. You can view it in the <code className="action">Tasks</code> menu.

<img className="thumbnail" alt="Upgrade Prism Element 11" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element11.png" loading="lazy" />

Select all available updates and click <code className="action">View Update Plan</code>.

<img className="thumbnail" alt="Upgrade Prism Element 12" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element12.png" loading="lazy" />

Click <code className="action">Next</code>.

<img className="thumbnail" alt="Upgrade Prism Element 13" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element13.png" loading="lazy" />

Click <code className="action">Apply N Updates</code>.

<img className="thumbnail" alt="Upgrade Prism Element 14" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/08-upgrade-prismcentral/02-update-prism-element14.png" loading="lazy" />

:::warning
The update process can be very long, it is possible that some slowdowns occur but no downtime is to be expected.

:::
