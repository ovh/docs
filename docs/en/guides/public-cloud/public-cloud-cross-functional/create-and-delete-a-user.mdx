## Objective

Access to Horizon and the OpenStack APIs is established via username/password pairs called "OpenStack users". You can create as many OpenStack users as needed and assign them various access permissions.

Using the Horizon interface, you can also set passwords for each individual user. Please note that when you change a user password, the previous password will be immediately cancelled.

**This guide explains how to manage OpenStack users from the OVHcloud Control Panel and the Horizon interface.**

## Instructions

### Creating an OpenStack user

Click on <code className="action">Users & Roles</code> the left-hand menu under **Settings**.

Click on the button <code className="action">Create User</code>.

<img className="thumbnail" alt="User roles" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/users_roles.png" loading="lazy" />

The user description is not the username for the OpenStack user but a descriptive term to help you organise users and their permissions. Enter a description and click on <code className="action">Next</code>.

<img className="thumbnail" alt="Add user" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/adduser.png" loading="lazy" />

Now you can select user roles representing the permissions the user shall have. For each box checked, the user will gain access privileges according to the table below.

<img className="thumbnail" alt="Permissions" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/permissions.png" loading="lazy" />

Click on <code className="action">Confirm</code> to create the OpenStack user. Username and password will be automatically generated and displayed in your Control Panel.

<img className="thumbnail" alt="User_pw" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/user_pw.png" loading="lazy" />

Be sure to save the password shown in the green message box to a password manager at this time. The password cannot be recovered afterwards. However, you can always create a new password by clicking on <code className="action">...</code> and selecting <code className="action">Generate a password</code>.

<img className="thumbnail" alt="Generate" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/generatepw.png" loading="lazy" />

With the OpenStack user created, you can use its credentials to log into the [Horizon interface](/guides/public-cloud/public-cloud-cross-functional/introducing-horizon/) by clicking on the link <code className="action">Horizon</code> in the left-hand menu.

### Change an OpenStack user password

You can create an OpenStack password once you have logged in to your [OpenStack Horizon](https://horizon.cloud.ovh.net) interface:

<img className="thumbnail" alt="Horizon login" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/1_H_login_window.png" loading="lazy" />

Your user profile is visible in the top right-hand corner of the Horizon interface. Click on your profile to open a menu with various options, select <code className="action">Settings</code>, then <code className="action">Change password</code> on the left-hand side:

<img className="thumbnail" alt="Change password" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/2_H_pass_change_option.png" loading="lazy" />

Enter your current password into the first field, then re-enter and confirm your new password in the next two fields.

:::info
When you change your password, please ensure that it meets the following criteria:

- The password must contain a minimum of eight characters.
- The password must contain a maximum of 30 characters.
- The password must contain at least one upper-case letter.
- The password must contain at least one lower-case letter.
- The password must contain at least one number.
- The password must only contain letters and numbers.

:::


To confirm your new password, click <code className="action">Change</code>.

<img className="thumbnail" alt="Set password" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/3_H_set_new_passord.png" loading="lazy" />

Please note that when you change your user password, your previous password is immediately cancelled.

### Deleting an OpenStack user

Click on <code className="action">Users & Roles</code> the left-hand menu under **Settings**.

<img className="thumbnail" alt="public-cloud" src="/images/public-cloud/public-cloud-cross-functional/create-and-delete-a-user/delete.png" loading="lazy" />

Click on <code className="action">...</code> and select <code className="action">Delete</code>.

:::warning
Deleting a user is permanent and will invalidate all associated tokens, even those with an expiry date not yet exceeded.

:::
