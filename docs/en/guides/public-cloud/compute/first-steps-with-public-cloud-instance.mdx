## Objective

You can manage your Public Cloud instances in the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.co.uk/&ovhSubsidiary=GB).

**This guide explains the available Control Panel actions for a Public Cloud instance.**

## Requirements

- A [Public Cloud project](https://www.ovhcloud.com/en-gb/public-cloud/) in your OVHcloud account
- A [Public Cloud instance](/guides/public-cloud/compute/first-steps-with-public-cloud-instance/) in your project

## Instructions

### Using the management interface for instances

Click on <code className="action">Instances</code> in the left-hand menu.

This page lists all your Public Cloud instances and some of their properties:

- The instance ID, needed for certain API calls
- The location of the data centre i.e. the region of the instance
- The instance template
- The image i.e. the OS installed on the instance
- The IPv4 address of the instance
- The private address currently attached to the instance
- Additional volumes (disks) currently attached to the instance
- The status of the instance, indicating whether it is in the `Activated` state

### Management options on the instance dashboard

From the instance management page, click on the name of the instance concerned. 

This will take you to the `General Information` page, which centralizes the main details and operating status of your instance (status, resources, network, access, and metadata).

Some of these operations are also accessible from the instance management page via the <code className="action">...</code> button in the instance table.

#### Editing the configuration of the instance

Click <code className="action">Edit image</code>, or open <code className="action">Additional actions</code> and then select <code className="action">Edit</code>.

The new page displays a modified version of the [instance creation options](/guides/public-cloud/compute/first-steps-with-public-cloud-instance/) where you can edit the following items:

- **Renaming the instance**: You can give a name to the instance for easier identification.
- **Changing the image**: You can choose a different operating system for the instance. (Note that reinstalling an instance will delete all data stored on it.)
- **Changing the template**: You can switch to a different instance model. Refer to [this guide](/guides/public-cloud/compute/public-cloud-first-steps#model/) for more information about the options.
- **Changing the billing type**: You can change the billing period of the instance from hourly to monthly. Refer to [this guide](/guides/account-and-service-management/managing-billing-payments-and-services/changing-hourly-monthly-billing/) for detailed information.

#### Creating a backup of the instance

Click on <code className="action">Create a backup</code>.

Refer to our guide [Backing up an instance](/guides/public-cloud/compute/save-an-instance/) for detailed information.

#### Deleting an instance

Click on <code className="action">Delete</code>.

This action will permanently delete the instance, as well as all of the data stored on it.

Confirm the request in the popup window.

:::warning
Deleting an instance does not automatically delete all the options associated with it (storage, snapshot, backup, etc...), so make sure that all other options associated with the instance are also deleted to stop being billed.

:::


#### Attach a volume

Click <code className="action">Attach a volume</code>.

Then select the volume to associate with the instance and click <code className="action">Confirm</code>. Once attached, the volume is immediately available and can be mounted from the instance's operating system.

#### Change the reverse DNS

Click on <code className="action">⋮</code> then <code className="action">Change reverse DNS</code>.

Refer to the guide [How to configure the reverse DNS of my connection](/guides/public-cloud/compute/setup-instance-reverse/) for more information.

#### Configure the firewall

Click on <code className="action">⋮</code> then <code className="action">Configure the firewall</code>.

Refer to the guide [Enabling and configuring the Edge Network Firewall](/guides/bare-metal-cloud/dedicated-servers/firewall-network/) for more information.

#### Manage private networks

Click on <code className="action">⋮</code> then <code className="action">Manage private networks</code>.

Refer to the guide [Creating a private network with Gateway](/guides/public-cloud/public-cloud-network-services/getting-started-02-create-private-network-gateway/) for more information.

#### Attach a network

Click on <code className="action">⋮</code> then <code className="action">Attach a network</code>.

Select the desired network from the drop-down list, then click <code className="action">Confirm</code>.

#### Additional actions

Click on <code className="action">Additional actions</code>

##### Creating an automatic backup of the instance

Click on <code className="action">Create an automatic backup</code>.

Refer to our guide [Backing up an instance](/guides/public-cloud/compute/save-an-instance#creating-an-automated-backup-of-an-instance/) for detailed information.

##### Stop the instance

Click on <code className="action">Stop</code>.

This will put the instance in an `Off` state, but you will still be charged the same price for your instance. Refer to our guide [Shelve or pause an instance](/guides/public-cloud/compute/suspend-or-pause-an-instance#suspend-stop-an-instance/) for detailed information.

Click on <code className="action">Boot</code> to reactivate the instance.

##### Using rescue mode

Click on <code className="action">Reboot in rescue mode</code>.

This will activate rescue mode for the instance. Refer to our guide [How to activate rescue mode on a Public Cloud instance](/guides/public-cloud/compute/put-an-instance-in-rescue-mode/) for detailed information.

##### Restarting the instance

:::warning
The Hot reboot option is currently not available for Metal instances.

:::


- Click on <code className="action">Hot reboot (soft)</code> to perform a software-level reboot.
- Click on <code className="action">Cold reboot (hard)</code> to perform a hardware-level reboot.

Confirm the reboot request in the popup window.

##### Shelving the instance

Click on <code className="action">Suspend</code>.

This will put the instance in the "shelved" state, here displayed as `Suspended`. Consult our guide [Shelve or pause an instance](/guides/public-cloud/compute/suspend-or-pause-an-instance#shelve-suspend-an-instance/) to learn more about the different states.

Click on <code className="action">Reactivate</code> to restore the `Activated` state.

##### Reinstalling an instance

Click on <code className="action">Reinstall</code>.

This action will reinstall the instance with the same operating system, provided the image is still supported.

Note that reinstalling **deletes all data** currently stored on your instance.

### Accessing the VNC console <a name="accessvnc"></a>

Click on <code className="action">Instances</code> in the left-hand menu. On the instance management page, click on the name of the instance in the table.

Switch from the dashboard to the tab <code className="action">VNC console</code>.

<img className="thumbnail" alt="public-cloud" src="/images/public-cloud/compute/first-steps-with-public-cloud-instance/vnc1.png" loading="lazy" />

The VNC console provides direct access to your instance. For this to work, first configure a username and password on the instance.

Consult our [Getting started guide](/guides/public-cloud/compute/public-cloud-first-steps#vnc-console/) to learn more about the necessary steps.
