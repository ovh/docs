## Objective

You may need to configure an Additional IP address on your instances for different reasons. For example, you may be:

- Hosting several websites on your instance.
- Hosting international projects.

To meet these needs, you can order an Additional IP address for your Public Cloud instances.

These Additional IP addresses can only be migrated to instances in the same project.

**This guide explains how to obtain an Additional IP for an OVHcloud Public Cloud project.**

## Requirements

- Access to the [OVHcloud Control Panel](/links/manager)
- A [Public Cloud instance](/guides/public-cloud/compute/compute-getting-started) in your Public Cloud project

## Instructions

Log in to the [OVHcloud Control Panel](/links/manager), go to the `Public Cloud` section and select the Public Cloud project concerned.

In the left-hand menu, open `Public IPs` under **Network**.

Open the `Additional IP` tab and click on the `Actions` button. Select `Add a new IP`.

![Adding IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_01.png)

In step 1 of the order process, click on `Next`.

![Adding IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_02.png)

Step 2 allows you to select a country for the new IP address.

![Adding IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_03.png)

The following countries are available for IP geolocation:

|          |          |          |           |                |
|:--------:|:--------:|:--------:|:---------:|:--------------:|
| Belgium  | Finland  | France   | Germany   | Czech Republic |
| Ireland  |  Italy   | Lithuania | Netherlands | United Kingdom    |
| Portugal |  Spain   |  Poland |  Switzerland |                 |

> [!info] **Availability**
> 
> Some of these countries may not be listed, depending on the current availability of IPv4 addresses.
> 

> [!info] **Location**
>
> IP geolocation is solely based on benchmark organisations.
> 
> For example, [RIPE NCC](https://www.ripe.net/) is serving Europe as the Regional Internet Registry.
>
> If you need to verify geolocation otherwise, contact the concerned organisations directly. OVHcloud cannot be involved in this regard.

Once you have selected a country, click on `Next`.

In the final step, select your instance from the drop-down menu. Then click on `Generate purchase order`.

![Adding IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_04.png)

The purchase order will open automatically for you to complete your purchase.

See our guide on [managing OVHcloud orders](/guides/account-and-service-management/managing-billing-payments-and-services/ovh-orders) for more details.

You can also find the purchase order in your Control Panel, by going to the `Dashboard` section and clicking on `View my orders`.

The next step will be the IP configuration in your OS; please refer to our [guide](/guides/public-cloud/public-cloud-network-services/configure-additional-ip).
