## Objective

This guide explains how to connect to the Veeam Service Provider Console (VSPC) to view your backups, agents, and check your backup job reports.

## Requirements

- You must have received VSPC connection credentials by email after ordering your Backup Agent service.
- A compatible web browser.

## Instructions

### Access VSPC

Go to the VSPC URL: `https://vspc.prod01.eu-west-rbx.backup.ovhcloud.com`

<img className="thumbnail" alt="Backup Agent Login VSPC" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-login-vspc.png" loading="lazy" />

### Log in

Log in using the credentials that were provided to you by email. The login format is usually `vspc-tenant-XXXXXX\user-XXXXXX`.

:::info
If you no longer have your credentials, you can regenerate them by [contacting support](https://help.ovhcloud.com/csm?id=csm_get_help).

:::


<img className="thumbnail" alt="Backup Agent Login VSPC" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-login-vspc.png" loading="lazy" />

:::info
This account is read-only and allows you to access visualizations of your backups and agents.

:::


### View Backup Jobs

Once logged in, click on <code className="action">Backup Jobs</code> in the left menu.

<img className="thumbnail" alt="Backup Agent Backup Jobs" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-backup-jobs.png" loading="lazy" />

### View successful jobs

Click on <code className="action">Successful Jobs</code> for your tenant.

<img className="thumbnail" alt="Backup Agent Successful Jobs" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-successful-jobs.png" loading="lazy" />

### View restore points

You can view the available restore points for your backups.

<img className="thumbnail" alt="Backup Agent Restore Points" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-restore-points.png" loading="lazy" />

### Access managed agents

To see the list of your installed agents, go to <code className="action">Managed Computers</code>.

<img className="thumbnail" alt="Backup Agent Managed Computers" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-managed-computers.png" loading="lazy" />

### View reports

Go to the <code className="action">Reports</code> section to view your backup reports.

<img className="thumbnail" alt="Backup Agent Reports" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-reports.png" loading="lazy" />

### Open the last report

Open the last available report to view the details of your latest backups.

<img className="thumbnail" alt="Backup Agent Last Report" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-last-report.png" loading="lazy" />

### View latest alarms

You can view the latest alarms on your agents and backups in the <code className="action">Alarm Management</code> section.

<img className="thumbnail" alt="Backup Agent Alarm Management" src="/images/storage-and-backup/backup-agent/backup-agent-vspc-presentation/01-backup-agent-alarm.png" loading="lazy" />
