## Objective

You have just ordered your Backup Agent offer for your Bare Metal server. Discover how to set up your first backups.

**This guide explains how to configure your first backup using Backup Agent on a Bare Metal server.**

:::info
Find more information about the Backup Agent product on [this page](/guides/storage-and-backup/backup-agent/backup-agent-product-presentation/).

:::


## Requirements

- A Backup Agent ordered simultaneously with your Bare Metal server, or afterwards via the <code className="action">Backup Agent</code> menu in the OVHcloud Control Panel.
- You need to have booted and configured an Operating System on your Bare Metal server.

### OVHcloud Control Panel Access

- **Direct link:** [Backup Agent](https://manager.eu.ovhcloud.com/#/bmc-backup-agent-baremetal/service)
- **Navigation path:** <code className="action">Bare Metal Cloud</code> > <code className="action">Backup Agent</code>

:::warning
You must ensure that your server can be reached by our Veeam infrastructure.  
You will receive the exact information in your delivery email.

Here is the information to allow access on your Bare Metal server:

- IP/DNS of the server: `vspc-cgw1.prod01.eu-west-rbx.backup.ovh.net` or `vspc-cgw21.prod01.eu-west-rbx.backup.ovh.net`
- Port: 6180

We also strongly recommend that you allow your server to reach other external addresses so that it can send your data to the Vault. There is no need to allow incoming traffic in this context.

:::



## Instructions

The steps to create a backup for your server are as follows:

- Adding your server to your Backup Agent.
- Downloading the agent.
- Installing the agent on your server.

Once the agent is installed, it will receive the backup policy and will be able to perform backups.

Once these steps are complete, your first backup will run automatically.

### Add your server to your Backup Agent

Click [this link](https://manager.eu.ovhcloud.com/#/bmc-backup-agent-baremetal/service) to access the <code className="action">Backup Agent</code> section, then click on your vspc-tenant in the <code className="action">Services</code> section.

<img className="thumbnail" alt="Backup Agent Services" src="/images/storage-and-backup/backup-agent/backup-agent-first-configuration/01-backup-agent-services-en.png" loading="lazy" />

Go to the <code className="action">Agents</code> section.

<img className="thumbnail" alt="Backup Agent Tenant Infos" src="/images/storage-and-backup/backup-agent/backup-agent-first-configuration/01-backup-agent-tenant-infos-en.png" loading="lazy" />

:::info
You should see the Bare Metal server you selected in your order in the table, with the status `not_installed`. This is normal at this stage; you now need to install the agent on your server.

:::


Click the <code className="action">Download</code> button at the top of the table listing your agents.

<img className="thumbnail" alt="Backup Agent Agents" src="/images/storage-and-backup/backup-agent/backup-agent-first-configuration/01-backup-agent-agents-en.png" loading="lazy" />

Select your Operating System and choose either to download the installation file or use one of the commands provided to retrieve it.

<img className="thumbnail" alt="Backup Agent Step 13" src="/images/storage-and-backup/backup-agent/backup-agent-first-configuration/01-backup-agent-download-windows-en.png" loading="lazy" />
