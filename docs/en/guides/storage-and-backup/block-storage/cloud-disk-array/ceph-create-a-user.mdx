## Objective

This guide shows you how to create a new Cloud Disk Array user, using the OVHcloud Control Panel or the OVHcloud API.

## Requirements

- A [Cloud Disk Array](https://www.ovhcloud.com/en-gb/storage-solutions/cloud-disk-array/) solution

{/* CP-NAV-START:storage-cloud-disk-array */}
---

### OVHcloud Control Panel Access

- **Direct link:** [Cloud Disk Array](https://manager.eu.ovhcloud.com/#/dedicated/cda)
- **Navigation path:** <code className="action">Bare Metal Cloud</code> > <code className="action">Cloud Disk Array</code> > Select your service

---
{/* CP-NAV-END:storage-cloud-disk-array */}

## Instructions

### Using the OVHcloud Control Panel

:::info
Using the OVHcloud Control Panel is the easiest way to create a user.

:::


On your Cloud Disk Array service page, go to the <code className="action">Users</code> tab.

<img className="thumbnail" alt="Ceph users" src="/images/storage-and-backup/block-storage/cloud-disk-array/ceph-create-a-user/create_a_user_1.png" loading="lazy" />

Enter a username.

:::warning
Your username needs to contain at least three characters.

:::


<img className="thumbnail" alt="Ceph user creation" src="/images/storage-and-backup/block-storage/cloud-disk-array/ceph-create-a-user/create_a_user_2.png" loading="lazy" />

The user is then created.

<img className="thumbnail" alt="Ceph user creation" src="/images/storage-and-backup/block-storage/cloud-disk-array/ceph-create-a-user/create_a_user_3.png" loading="lazy" />

### Using the API

:::tip[Success]
If you are not familiar with the OVHcloud API, read our [First Steps with the OVHcloud API](/guides/manage-and-operate/api/first-steps/) guide.

:::


You can create a user using this API route:

<Api version="v1" section="/dedicated/ceph" method="POST" route={"/dedicated/ceph/\{serviceName\}/user"} />


`serviceName` is the fsid of your cluster.

You can also check the user creation by creating a list of users:

<Api version="v1" section="/dedicated/ceph" method="GET" route={"/dedicated/ceph/\{serviceName\}/user"} />

```bash
GET /dedicated/ceph/98d166d8-7c88-47b7-9cb6-63acd5a59c15/user
[
  {
    mdsCaps: ""
    monCaps: "allow r"
    serviceName: "98d166d8-7c88-47b7-9cb6-63acd5a59c15"
    name: "myuser"
    osdCaps: "allow class-read object_prefix rbd_children"
    key: "AQA9KpdXoBrDNhAAFCM7m/XOtmWh3LMSNlHVqw=="
  }
]
```
