> [!info]
>
> Depuis le 6 octobre 2022, notre solution "IP Failover" s'appelle désormais [Additional IP](/links/network/additional-ip). Cela n'a pas d'impact sur ses fonctionnalités.
>

## Objectif

Si vous avez besoin de configurer une adresse Additional IP sur vos instances parce que :

- vous avez plusieurs sites sur votre instance 
- vous hébergez des projets internationaux
- vous voulez migrer votre activité depuis un serveur dédié vers une instance Public cloud

Il est possible d'importer une adresse Additional IP liée à un autre service OVHcloud.

**Ce guide explique comment importer une Additional IP dans votre projet Public Cloud OVHcloud.**

## Prérequis

- Un [projet Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud.
- Être connecté à votre [espace client OVHcloud](/links/manager).
- Avoir [une Additional IP](/links/bare-metal/ip).

> [!warning]
> Cette fonctionnalité n'est actuellement pas disponible pour les instances Metal.
>

## En pratique

Connectez-vous à l'[espace client OVHcloud](/links/manager), rendez-vous dans la section `Public Cloud` et sélectionnez le projet Public Cloud concerné.

Dans le menu de gauche, ouvrez `IP Publiques` dans **Network**.

Ouvrez l'onglet `Additional IP` et cliquez sur le bouton `Actions`. Sélectionnez `Importer une Additional IP` pour afficher toutes les adresses IP pouvant être importées dans votre projet Public Cloud.

![Section IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-import/import22_01.png)

Si vous n'avez pas encore d'Additional IP sur votre projet Public Cloud, l'option d'importation d'une Additional IP s'affichera sur la page d'accueil.

Cliquez sur `...` à côté de l'adresse IP que vous souhaitez importer et cliquez sur `Importer cette Additional IP`.

![Import Additional IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-import/import22_02.png)

Validez alors en cliquant sur `Importer`.

![Import confirm](/images/guides/public-cloud/public-cloud-network-services/additional-ip-import/import22_03.png)

Patientez quelques minutes le temps que l'importation soit réalisée. Ouvrez l'onglet `Additional IP` pour rechercher l'adresse Additional IP importée. Actualisez la page si nécessaire.

Cliquez sur `...` à droite et sélectionnez `Modifier l'instance associée`.

![Import Additional IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-import/import22_04.png)

Une fenêtre contextuelle apparaîtra pour choisir l'instance à laquelle votre adresse IP doit être attachée.

![Import Additional IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-import/import22_05.png)

Cliquez sur `Joindre` pour confirmer. La page affiche alors un message de modification.

> [!warning]
>
> Une Additional IP ne peut être déplacée entre différentes zones. Par exemple, une IP localisée dans le datacentre de SBG peut être déplacée vers GRA ou RBX mais non vers BHS.
>

Votre adresse Additional IP sera maintenant attachée à votre instance.

La prochaine étape consiste à configurer l'IP dans votre système d'exploitation. Consultez [notre guide dédié à cette configuration](/guides/public-cloud/public-cloud-network-services/configure-additional-ip).
