> [!info]

> Depuis le 6 octobre 2022, notre solution "IP Failover" s'appelle désormais [Additional IP](/links/network/additional-ip). Cela n'a pas d'impact sur ses fonctionnalités.
>

## Objectif

Vous pouvez avoir besoin de configurer une adresse Additional IP sur vos instances pour différentes raisons :

- Vous avez plusieurs sites sur votre instance.
- Vous hébergez des projets internationaux.

Pour répondre à ces besoins, vous pouvez acheter une adresse Additional IP pour vos instances Public Cloud.<br />
Ces adresses Additional IP ne pourront être migrées que vers les instances d'un même projet.

**Ce guide explique comment acheter une Additional IP pour votre projet Public Cloud OVHcloud.**

## Prérequis

- Être connecté à l'[espace client OVHcloud](/links/manager).
- Disposer d'au moins une instance. Consultez à cet effet [le guide pour créer une instance depuis l'espace client](/guides/public-cloud/compute/compute-getting-started).

> [!warning]
> Cette fonctionnalité n'est actuellement pas disponible pour les instances Metal.
>

## En pratique

Connectez-vous à l'[espace client OVHcloud](/links/manager), rendez-vous dans la section `Public Cloud` et sélectionnez le projet Public Cloud concerné.

Dans le menu de gauche, ouvrez `IP Publiques` dans **Network**.

Ouvrez l'onglet `Additional IP` et cliquez sur le bouton `Actions`. Sélectionnez `Ajouter une nouvelle IP`.

![Ajout IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_01.png)

À l'étape 1 de la commande, cliquez sur `Suivant`.

![Ajout IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_02.png)

L'étape 2 permet de sélectionner un pays pour la nouvelle adresse IP.

![Ajout IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_03.png)

Les pays suivants sont disponibles pour la géolocalisation des IP :

|          |          |          |           |                |
|:--------:|:--------:|:--------:|:---------:|:--------------:|
| Belgique  | Finlande  | France   | Allemagne   | République Tchèque |
| Irelande  |  Italie   | Lituanie | Pays-bas | Royaume-Uni    |
| Portugal |  Espagne   |  Pologne |  Suisse |                 |

> [!info] **Disponibilité**
> 
> Il est possible que certains de ces pays ne soient pas listés, en fonction de la disponibilité actuelle des adresses IPv4.
> 

> [!info] **Location**
>
> La géolocalisation d'IP est uniquement basée sur des organismes de référence.
> 
> Par exemple, le [RIPE NCC](https://www.ripe.net/) dessert l'Europe en tant que Registre Internet Régional.
>
> Si vous avez besoin de vérifier la géolocalisation d'une autre manière, contactez directement les organisations concernées. OVHcloud ne pourra vous founir d'assistance à ce sujet.

Une fois le pays sélectionné, cliquez sur `Suivant`.

A la dernière étape, sélectionnez votre instance dans le menu déroulant. Cliquez ensuite sur `Générer le bon de commande`.

![Ajout IP](/images/guides/public-cloud/public-cloud-network-services/additional-ip-buy/buyaddIP_04.png)

Le bon de commande s'ouvrira automatiquement afin de finaliser votre achat.

Consultez notre guide sur la [gestion des commandes OVHcloud](/guides/account-and-service-management/managing-billing-payments-and-services/ovh-orders) pour plus de détails.

Vous pouvez également retrouver le bon de commande dans votre espace client, rubrique `Tableau de bord`, en cliquant sur `Voir mes commandes`.

La prochaine étape consiste à configurer l'IP dans votre système d'exploitation. Consultez [notre guide dédié à cette configuration](/guides/public-cloud/public-cloud-network-services/configure-additional-ip).
