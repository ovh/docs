## Objective

Public Cloud managed databases allow you to send logs of your service to your own Logs Data Platform (LDP) data stream.

**This guide explains how to forward service logs to your own LDP stream with the OVHcloud API.**

## Requirements

- A [Public Cloud database service](https://www.ovhcloud.com/fr/public-cloud/databases/) up and running
- Access to the [OVHcloud API](https://eu.api.ovh.com/console/)
- A Logs Data Platform account within this OVHcloud account with at least one destination stream configured
    - If you are not familiar with all the LDP *Stream* configuration possibilities, simply create a new one with the default options (indexing & websocket enabled, long-term storage disabled) for the purpose of this guide.
- A running database service

## Instructions

### Create your subscription

<Tabs>
  <Tab label="Via the OVHcloud Control Panel">
    On the database instance page, go to the <code className="action">Logs</code> section and click the <code className="action">Subscribe</code> button.
    
    <img className="thumbnail" alt="LDP database subscription" src="/images/public-cloud/public-cloud-databases/databases-16-logs-to-customer/ldp_database_subscription.png" loading="lazy" />

Select the relevant LDP account by clicking the <code className="action">Subscribe</code> button.
    
    <img className="thumbnail" alt="LDP database subscription 2" src="/images/public-cloud/public-cloud-databases/databases-16-logs-to-customer/ldp_database_subscription2.png" loading="lazy" />

The logs will then start to be forwarded to your LDP stream.
  </Tab>
  <Tab label="Via the OVHcloud API">
    1\. Retrieve the required information
    
    **Retrieve your LDP destination `streamId`:**
    
    Log in to the [OVHcloud Control Panel](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr), go to the <code className="action">Identity, Security & Operations</code> section. In the left-hand menu, select <code className="action">Logs Data Platform</code> then click on the relevant LDP instance.
    
    <img className="thumbnail" alt="LDP list page" src="/images/public-cloud/public-cloud-databases/databases-16-logs-to-customer/ldp_page.png" loading="lazy" />

Go to the <code className="action">Data stream</code> tab.
    
    <img className="thumbnail" alt="LDP details page" src="/images/public-cloud/public-cloud-databases/databases-16-logs-to-customer/ldp_page_details.png" loading="lazy" />

Choose your target stream and click on <code className="action">Copy stream ID</code>.
    
    **Retrieve your LDP destination `serviceName`:**
    
    - This refers to your Public Cloud project ID. You can retrieve it in the Public Cloud section of your project.
    
    <img className="thumbnail" alt="LDP project id" src="/images/public-cloud/public-cloud-databases/databases-16-logs-to-customer/ldp_project_id.png" loading="lazy" />

**Retrieve your `clusterId`:**
    
    In the left-hand menu, click on <code className="action">Databases</code>, then choose the database instance you want to manage.
    
    In the cluster details, you can find the `Service ID` field, which corresponds to the cluster ID.
    
    <img className="thumbnail" alt="LDP database details" src="/images/public-cloud/public-cloud-databases/databases-16-logs-to-customer/ldp_database_details.png" loading="lazy" />
    
    2\. Start by retrieving the types of logs available for your database cluster with the following API call:
    
    <Api version="v1" section="/cloud" method="GET" route={"/cloud/project/\\{serviceName\\}/database/\\{engine\\}/\\{clusterId\\}/log/kind"} />

This will return the list of valid kind values you can use when subscribing to logs.
    
    3\. Once you know the valid kind, use it to subscribe to a log stream with this API call:
    
    <Api version="v1" section="/cloud" method="POST" route={"/cloud/project/\\{serviceName\\}/database/\\{engine\\}/\\{clusterId\\}/log/subscription"} />

```console
    body : {
        kind: <log_type_from_previous_call>
        streamId: <your_stream_id>
    }
    ```
    
    The logs will then start to be forwarded to your LDP stream.
  </Tab>
</Tabs>


### Find logs in Graylog

On the LDP page, click the <code className="action">sample-data-stream</code> button (the last data stream modified when you previously subscribed to it), or click the <code className="action">Graylog</code> button.

<img className="thumbnail" alt="LDP database go to graylog" src="/images/public-cloud/public-cloud-databases/databases-16-logs-to-customer/ldp_database_go_to_graylogs.png" loading="lazy" />

You need to log in using your Graylog credentials. You can retrieve them from the LDP details page, in the `Configuration` section. The login corresponds to the value shown on the `Logs Data Platform service` line, and the password is displayed under `Password`.

<img className="thumbnail" alt="LDP database ldp details" src="/images/public-cloud/public-cloud-databases/databases-16-logs-to-customer/ldp_database_ldp_details.png" loading="lazy" />

Once connected, you can view your service logs in your Graylog stream.

<img className="thumbnail" alt="LDP database graylogs result" src="/images/public-cloud/public-cloud-databases/databases-16-logs-to-customer/ldp_database_graylogs_result.png" loading="lazy" />

You can also use the following Graylog queries for more granular filtering:

#### MongoDB

Query: `cluster: "<HostID>"`

You can find this `HostID` in your OVHcloud Control Panel:

- In `Login information` switch `Service` to `mongodb`
- Now you can see the `Host` field with the format `<HostID>.database.cloud.ovh.net`

#### Other Engines

Query: `clusterID: "<Engine>-<HostID>"`

You can find this `HostID` in your OVHcloud Control Panel:

- Find the Cluster ID formatted as a UUID (AAAAAAAA-BBBB-CCCC-DDDDDDDDDDDD)
- `HostID` is the first part of the UUID (AAAAAAAA)

### Delete subscription

You have 2 methods to delete a subscription:

<Tabs>
  <Tab label="Via the OVHcloud Control Panel">
    In the subscription page of the database instance, click the <code className="action">Unsubscribe</code> button.
    
    <img className="thumbnail" alt="LDP database unsubscribe" src="/images/public-cloud/public-cloud-databases/databases-16-logs-to-customer/ldp_database_unsubscribe.png" loading="lazy" />
  </Tab>
  <Tab label="Via the OVHcloud API">
    - You can delete subscriptions using the `subscriptionId` concerned in this API call:
    
    <Api version="v1" section="/cloud" method="DELETE" route={"/cloud/project/\\{serviceName\\}/database/\\{engine\\}/\\{clusterId\\}/log/subscription/\\{subscriptionId\\}"} />
  </Tab>
</Tabs>


- If you delete your database service, all subscriptions of this service are deleted automatically.
