## Objectif

Si votre instance manque de ressources en raison d'une activité accrue ou de nouveaux besoins, vous pouvez augmenter ses ressources en quelques clics grâce au Public Cloud.

**Ce guide vous explique comment redimensionner votre instance depuis l'espace client OVHcloud.**

:::warning
Seul le redimensionnement vers un modèle supérieur est possible pour les modèles classiques.
De plus, cette manipulation entraine une coupure de l'instance le temps de l'opération.

:::


:::tip[Success]
Les instances de type *flex* permettent le redimensionnement vers les modèles supérieurs ou inférieurs grâce à une taille de disque unique.

:::


## Prérequis

- Avoir [créé une instance Public Cloud](https://www.ovhcloud.com/fr/public-cloud/) dans votre compte OVHcloud

## En pratique

Cliquez sur <code className="action">Instances</code> dans le menu de gauche.

Cliquez ensuite sur <code className="action">...</code> à droite de l’instance, puis sélectionnez <code className="action">Editer</code>. Vous pouvez également accéder à cette action depuis les détails de l’instance en cliquant sur son nom, puis sur <code className="action">Modifier le modèle</code>.

Dans le nouvel onglet, faites défiler la page jusqu'à la section **Modèle** pour sélectionner le modèle de votre choix.

:::info
Pour les modèles classiques, vous pouvez basculer vers n'importe quel modèle dont le disque est similaire ou plus grand. Vous ne pouvez pas passer à un modèle avec un disque plus petit.<br/>

Seules **les instances flexibles** peuvent être basculées vers un modèle supérieur ou inférieur tout en conservant une taille de disque fixe de 50 Go.

:::


Si votre disque est égal ou inférieur à 50 Go, vous pouvez passer à une <code className="action">Instance flexible</code> si vous le souhaitez.

:::warning
Si vous éditez une instance *flex*, il n’est pas possible de revenir à une instance classique via l’espace client. Pour plus d’informations, consultez notre guide sur [Basculer d’une instance flex à une instance classique](/guides/public-cloud/compute/revert-a-flex-instance/).

:::


Une fois la sélection effectuée, cliquez sur <code className="action">Modifier le modèle</code> pour confirmer votre choix.

### Redimensionnement du disque sous Windows

Attention, lors d'un redimensionnement pour une instance Windows, la taille de la partition n'est pas automatiquement mise à jour, vous devrez donc l'étendre via le **gestionnaire de disque** :

- Faites un clic droit sur le menu <code className="action">Démarrer</code> et lancez le gestionnaire de disque en cliquant sur <code className="action">Gestion du disque</code> :

<img className="thumbnail" alt="Menu contextuel du menu Démarrer avec l'option Gestion du disque" src="/images/public-cloud/compute/resize-instance-manager/2980.png" loading="lazy" />

- Faites un clic droit sur la partition principale, puis cliquez sur <code className="action">Étendre le volume</code>.

<img className="thumbnail" alt="Clic droit sur la partition principale pour étendre le volume" src="/images/public-cloud/compute/resize-instance-manager/2981a.png" loading="lazy" />

- Cliquez sur <code className="action">Suivant</code> pour accéder à « l'Assistant Extension du volume ». Choisissez les ressources du disque à étendre et cliquez sur <code className="action">Suivant</code>. 

<img className="thumbnail" alt="Assistant Extension du volume avec sélection des ressources" src="/images/public-cloud/compute/resize-instance-manager/2978a.png" loading="lazy" />

Cliquez ensuite sur <code className="action">Terminer</code> pour valider votre choix.

<img className="thumbnail" alt="Étape de finalisation de l'Assistant Extension du volume" src="/images/public-cloud/compute/resize-instance-manager/wizard2021.png" loading="lazy" />

- La nouvelle taille du disque sera alors affichée dans le gestionnaire de disque.

<img className="thumbnail" alt="Gestionnaire de disque affichant la nouvelle taille" src="/images/public-cloud/compute/resize-instance-manager/2979.png" loading="lazy" />
