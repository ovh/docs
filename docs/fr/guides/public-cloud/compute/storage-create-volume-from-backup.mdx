## Objectif

Vous pouvez créer des disques supplémentaires pour vos instances Public Cloud depuis la sauvegarde d'un disque supplémentaire.

Cela peut être utile dans les cas suivants :

- Si vous souhaitez restaurer les données du disque supplémentaires.
- Si vous souhaitez disposer d'un espace de stockage hautement disponible et performant avec vos données.
- Si vous souhaitez déplacer vos données vers une autre instance.

**Découvrez comment créer et configurer un disque supplémentaire sur une de vos instances depuis la sauvegarde d'un disque.**

## Prérequis

- Être connecté votre [espace client OVHcloud](/links/manager).
- Avoir une [instance Public Cloud](/links/public-cloud/public-cloud) dans votre compte OVHcloud.
- Avoir une sauvegarde disque dans la même région OpenStack.
- Avoir accès à votre instance via SSH en tant qu'administrateur (sudo).

## En pratique

### Créer le disque à partir d'une sauvegarde

Connectez-vous à [l'espace client OVHcloud](/links/manager), accédez à la section `Public Cloud` et sélectionnez le projet Public Cloud concerné. Cliquez ensuite sur `Volume Snapshot` dans la barre de navigation de gauche sous **Storage & Backup**.

À droite de la sauvegarde de votre choix, cliquez sur le bouton `...` puis sur `Créer un volume`.

![créer volume](/images/guides/public-cloud/compute/create-volume-from-snapshot/volume01.png)

Définissez alors le nom de ce nouveau disque et sa capacité puis cliquez sur `Créer le volume`.

![créer volume](/images/guides/public-cloud/compute/create-volume-from-snapshot/volume02.png)

La création du disque peut prendre quelques minutes, suivant la taille de celui-ci.

### Attacher le disque à une instance

Une fois le disque créé, vous pouvez décider de l'attacher à une instance. Pour cela, cliquez sur `Block Storage` dans la barre de navigation de gauche sous **Storage & Backup**.

À droite du volume de votre choix, cliquez sur le bouton `...` puis sur `Attacher à l'instance`.

![attacher volume](/images/guides/public-cloud/compute/create-volume-from-snapshot/volume03.png)

Sélectionnez maintenant l'instance et cliquez sur `Confirmer` pour attacher le disque.

![attacher volume](/images/guides/public-cloud/compute/create-volume-from-snapshot/volume04.png)

Le processus d'attachement du disque à votre instance va alors commencer et peut prendre quelques minutes.

![attacher volume](/images/guides/public-cloud/compute/create-volume-from-snapshot/volume05.png)

> [!warning]
> Vous devez éviter la navigation en dehors de l'onglet en cours pendant l'attachement du disque. Cela peut interrompre le processus.
>

Une fois l'attachement effectué, vous pouvez suivre les étapes suivantes pour configurer votre disque supplémentaire [sous Linux](/guides/public-cloud/compute/create-and-configure-an-additional-disk-on-an-instance#sous-linux) ou [sous Windows](/guides/public-cloud/compute/create-and-configure-an-additional-disk-on-an-instance#sous-windows).
