## Objectif

Vous pouvez modifier les contacts administrateur et facturation d'un projet Public Cloud dans votre espace client.<br/>
La modification de ces contacts permet de dissocier la gestion technique de la gestion facturation, pour les services d'un projet .

**Ce guide vous explique comment modifier les contacts d'un projet Public Cloud dans votre espace client.**

## Prérequis

- Avoir un projet [Public Cloud](https://www.ovhcloud.com/fr/public-cloud/) dans votre compte OVHcloud
- Contacts administrateur et facturation dans la même filiale OVHcloud

{/* CP-NAV-START:publiccloud-projects */}
---

### Accès à l'espace client OVHcloud

- **Lien direct :** [Projets Public Cloud](https://manager.eu.ovhcloud.com/#/pci/projects)
- **Pour accéder à vos services :** <code className="action">Public Cloud</code> > Sélectionnez votre projet

---
{/* CP-NAV-END:publiccloud-projects */}

## En pratique

### Modifier les contacts

Cliquez sur <code className="action">Contacts & droits</code> dans le menu de gauche sous **Paramètres**.

Cette page vous permet de voir les contacts administrateur et facturation associés à votre projet.

<img className="thumbnail" alt="change-contacts" src="/images/public-cloud/compute/change-project-contacts/contact1.png" loading="lazy" />

Cliquez sur l'un des boutons <code className="action">Modifier</code> pour modifier les contacts actuels. Cela ouvrira la rubrique **Gestion des contacts** de votre espace client.

Les contacts de votre projet Public Cloud s'affichent dans le tableau. Cliquez sur le bouton <code className="action">...</code> puis sur <code className="action">Modifier les contacts</code>.

<img className="thumbnail" alt="change-contacts" src="/images/public-cloud/compute/change-project-contacts/contactchange.png" loading="lazy" />

Dans la nouvelle fenêtre, indiquez l'identifiant client souhaité pour chaque contact que vous souhaitez modifier. Notez que les comptes OVHcloud pour les `Contact administrateur` et `Contact facturation` doivent être obligatoirement renseignés dans la même filiale OVHcloud.

<img className="thumbnail" alt="change-contacts" src="/images/public-cloud/compute/change-project-contacts/contactchange1.png" loading="lazy" />

Après avoir cliqué sur le bouton <code className="action">Valider</code>, les deux comptes OVHcloud concernés par le changement recevront un e-mail de confirmation. Cet e-mail contient un code (token) permettant de valider le changement de contact dans l'onglet <code className="action">Mes demandes</code> de la section **Gestion des contacts**.

Pour une explication plus détaillée de cette procédure, nous vous invitons à consulter notre guide "[Gérer les contacts de ses services](/guides/account-and-service-management/account-information/managing-contacts/)".
