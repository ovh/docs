## Objectif

La console IPMI (Intelligent Platform Management Interface) permet d’établir une connexion directe à votre serveur dédié sans dépendre de l'état de connectivité du système d'exploitation. Ce guide vous explique comment démarrer cette console.

## Prérequis

{/* CP-NAV-START:baremetal-dedicated-servers */}
---

### Accès à l'espace client OVHcloud

- **Lien direct :** [Serveurs dédiés](https://manager.eu.ovhcloud.com/#/dedicated-servers/server)
- **Pour accéder à vos services :** <code className="action">Bare Metal Cloud</code> > <code className="action">Serveurs dédiés</code> > Sélectionnez votre serveur

## En pratique

La connexion à l’IPMI peut s’effectuer via plusieurs méthodes¹. Les clés SSH stockées sur le serveur ne seront pas utilisées pour ces connexions. En voici un tableau récapitulatif :

|Nom Méthode|Autre Nom|Description|Copier-Coller|Lecteur ISO Virtuel²|Exemples de cas d'utilisation|
|---|---|---|---|---|---|
|**KVM**³ via **navigateur Web**|**KVM HTML**|Emulation de l'écran vidéo à travers un **canvas HTML**, exactement comme si vous connectiez physiquement un clavier/souris en USB et un écran vidéo en VGA à votre serveur dédié.|❌|⚠️⁴|- Diagnostiquer un problème de boot du serveur dédié.|
|**KVM**³ via **applet Java**|**KVM Java**|Idem que pour le KVM HTML, à l'exception que l'émulation s'effectue via un **applet Java** à la place du canvas HTML.|❌|✅|- Diagnostiquer un problème de boot du serveur dédié. <br />- Effectuer une installation d'un OS spécifique (hors [catalogue](https://www.ovhcloud.com/fr/bare-metal/os/)) manuellement⁵.|
|**SoL**⁶ via **navigateur Web**|**SoL JavaScript**|Emulation d'une liaison série via le navigateur web, exactement comme si vous connectiez un console série physiquement en RS-232 à votre serveur dédié.|✅|❌|- Diagnostiquer un problème réseau : récupérer les logs et manipuler les fichiers de configuration.|
|**SoL**⁶ via **SSH**|**SoL SSH**|Idem que pour le SoL JavaScript, à l'exception que l'émulation s'effectue via une passerelle SSH. Vous vous connectez avec votre client SSH favoris à un serveur distant en SSH, qui transpose ensuite les commandes en liaison série au serveur dédié.|✅|❌|- Idem SoL JavaScript mais depuis une machine qui n'a pas d'interface graphique.|

¹ Selon la compatibilité matérielle de votre serveur dédié (certaines méthodes ne seront pas affichées dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr)).<br />
² Fonctionnalité permettant de monter une image ISO stockée localement sur votre machine au serveur dédié distant, et donc d'installer un OS via l'IPMI.<br />
³ KVM = Keyboard Video and Mouse<br />
⁴ Selon la compatibilité matérielle de votre serveur dédié : utiliser le KVM Java à la place si incompatible.<br />
⁵ Si l'OS que vous souhaitez installer n'est pas disponible dans le [catalogue des systèmes d'exploitation disponibles sur les serveurs dédiés OVHcloud](https://www.ovhcloud.com/fr/bare-metal/os/), notez que vous pouvez aussi utiliser une image personnalisée: voir [Comparaison entre Bring Your Own Image (BYOI) et Bring Your Own Linux (BYOLinux)](/guides/bare-metal-cloud/dedicated-servers/bring-your-own-image-versus-bring-your-own-linux/) pour plus de détails.<br />
⁶ SoL = Serial over Lan

Pour activer l'une de ces méthodes, cliquez sur l'onglet <code className="action">IPMI/KVM</code>.

### Ouvrir un KVM via applet Java <a name="applet-java"></a>

:::info
Nous recommandons d'installer la dernière version de Java.

:::


Pour que l’applet Java fonctionne, il faut que Java soit installé sur votre poste. Si ce n’est pas déjà fait, rendez-vous sur la [page officielle](https://www.java.com/en/download/).

Dans la section <code className="action">Remote KVM</code> de votre espace client OVHcloud, cliquez sur <code className="action">Depuis une applet Java (KVM)</code> :

<img className="thumbnail" alt="Accès KVM Java" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-java-01.png" loading="lazy" />

Téléchargez le fichier `kvm.jnlp` lorsque vous y êtes invité, puis lancez-le :

<img className="thumbnail" alt="Ouverture KVM Java" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-java-02.png" loading="lazy" />

Vous accédez alors à la page de connexion. Entrez vos identifiants `root`, comme lors d’une connexion par un terminal ou un logiciel externe :

<img className="thumbnail" alt="Aperçu KVM Java" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-java-03.png" loading="lazy" />

Vous pouvez désormais gérer votre serveur.

### Ouvrir un KVM via navigateur Web <a name="kvm-browser"></a>

Dans la section <code className="action">Remote KVM</code> de votre espace client OVHcloud, cliquez sur <code className="action">Depuis votre navigateur (KVM)</code> :

<img className="thumbnail" alt="Accès KVM HTML" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-html-01.png" loading="lazy" />

L'activation prend quelques secondes. Un message vous informera de la disponibilité de la connexion via IPMI.

<img className="thumbnail" alt="Ouverture KVM HTML" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-html-02.png" loading="lazy" />

Cliquez alors sur <code className="action">Accéder à la console (KVM)</code> pour ouvrir la console dans votre navigateur.

<img className="thumbnail" alt="Aperçu KVM HTML" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-kvm-html-03.png" loading="lazy" />

### Ouvrir SoL via SSH <a name="sol-ssh"></a>

Pour plus de détails concernant la création de paires de clés SSH, voir [cette page](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys-dedicated#create-ssh-key/).

Dans la section <code className="action">Serial over LAN (SoL)</code> de votre espace client OVHcloud, cliquez sur <code className="action">Ajouter la clé SSH</code>.

<img className="thumbnail" alt="Accès SoL SSH" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-sol-sshkey-01.png" loading="lazy" />

Une popup s'ouvre alors afin que vous puissiez saisir la clé publique SSH avec laquelle vous souhaitez vous authentifier pour vous connecter. Ensuite, cliquez sur <code className="action">Lancer la session SoL via SSH</code>.

<img className="thumbnail" alt="SoL SSH clé publique SSH" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-sol-sshkey-02.png" loading="lazy" />

Lorsque la session est prête un message de confirmation et une URI apparaît alors, afin que vous puissiez établir une connexion série à votre serveur dédié via SSH. Copier cette URI dans votre presse-papier.

<img className="thumbnail" alt="Ouverture SoL SSH" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-sol-sshkey-03.png" loading="lazy" />

Pour plus de détails concernant l'utilisation d'une clé SSH pour se connecter en SSH, voir [cette page](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys-dedicated#multiplekeys/).

### Tester et redémarrer l'IPMI <a name="ipmi-test-reboot"></a>

Il est possible que l’IPMI ne réponde plus. Si vous n’arrivez pas à y accéder, vous pouvez effectuer un test dans un premier temps en cliquant sur <code className="action">Tester IPMI</code> et visualiser le résultat du diagnostic :

<img className="thumbnail" alt="Test IPMI" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-test.png" loading="lazy" />

Si tout est normal comme dans notre exemple, vous faites probablement face à un souci local (connexion à Internet, poste local). Si l’IPMI rencontre effectivement une difficulté, vous avez la possibilité de le redémarrer en cliquant sur <code className="action">Redémarrer IPMI</code>.

<img className="thumbnail" alt="Reboot IPMI" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/ipmi-reboot.png" loading="lazy" />

Le redémarrage de l'IPMI prend quelques minutes.

:::info
Cette opération n'affecte pas le fonctionnement du serveur.

:::


### Installation d'un système d'exploitation à l'aide d'IPMI v1

:::warning
OVHcloud ne garantit pas la fonctionnalité des systèmes d'exploitation installés via IPMI. Cette méthode ne doit être envisagée que par un administrateur de serveurs expérimenté.

Les versions 64 bits de Java peuvent empêcher l'ouverture des menus `Redirect ISO`/`Redirect CDROM` et provoquer le blocage de JViewer.

:::


Pour commencer, ouvrez [IPMI depuis une applet Java](#applet-java) via votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr). Cliquez ensuite sur <code className="action">Device</code> dans la barre de menus et sélectionnez <code className="action">Redirect ISO</code> dans le menu déroulant.

<img className="thumbnail" alt="Redirect_ISO" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/RedirectISO.jpg" loading="lazy" />

Sélectionnez ensuite l'ISO que vous souhaitez utiliser dans le système de fichiers de votre ordinateur local. Une fois que vous avez sélectionné votre ISO, appuyez sur le bouton <code className="action">Ctrl Alt Del</code> dans le coin supérieur droit de l'écran pour redémarrer le serveur. Appuyez sur la touche `F` pour accéder aux options de démarrage.

:::info
Vous devrez peut-être utiliser le clavier logiciel pour enregistrer les entrées dans IPMI. Pour y accéder, cliquez sur l'option <code className="action">Keyboard</code> dans la barre de menus en haut de la fenêtre. Sélectionnez ensuite `Soft Keyboard` dans le menu déroulant et cliquez sur <code className="action">Show</code>.

:::


Sélectionnez l'option `UEFI Virtual CDROM 1.00` dans le menu de démarrage (Boot) pour démarrer le serveur à partir de l'ISO précédemment attaché.

<img className="thumbnail" alt="UEFI_Virt" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/UEFIVirt.jpg" loading="lazy" />

Suivez les étapes requises pour installer le système d'exploitation. N'oubliez pas de supprimer l'ISO de l'option « Redirect ISO ».

### Installation d'un système d'exploitation à l'aide d'IPMI v2

:::warning
OVHcloud ne garantit pas la fonctionnalité des systèmes d'exploitation installés via IPMI. Cette méthode ne doit être envisagée que par un administrateur de serveurs expérimenté.

:::


Pour commencer, ouvrez [IPMI depuis une applet Java](#applet-java) via votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr). Cliquez ensuite sur <code className="action">Virtual Media</code> puis sur <code className="action">Virtual Storage</code>.

<img className="thumbnail" alt="Virtual storage" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/virtual_storage.png" loading="lazy" />

Dans la fenêtre qui s'affiche alors, sélectionnez `ISO File` dans la liste déroulante « Logical Drive Type ». Cliquez ensuite sur <code className="action">Open Image</code> et naviguez jusqu'à votre fichier ISO. Enfin, cliquez sur <code className="action">Plug-in</code> et <code className="action">OK</code> pour terminer.

<img className="thumbnail" alt="ISO_file" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/iso_file.png" loading="lazy" />

Afin de démarrer à partir de votre fichier ISO, vous devez accéder au BIOS et changer les options de démarrage. Pour ce faire, cliquez sur <code className="action">Power Control</code> puis sur <code className="action">Set Power Reset</code>.

<img className="thumbnail" alt="Power_Reserver" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/power_reset.png" loading="lazy" />

:::info
Vous devrez peut-être utiliser le clavier logiciel pour enregistrer les entrées dans IPMI. Pour y accéder, cliquez sur l'option <code className="action">Virtual Media</code> dans la barre de menus en haut de la fenêtre. Sélectionnez ensuite <code className="action">Virtual Keyboard</code> dans le menu déroulant.

:::


Pendant le processus de démarrage, appuyez sur la touche `SUPPR` lorsque vous êtes invité à accéder au BIOS. Vous pouvez également appuyer sur la touche `F11` et accéder au BIOS en sélectionnant l'option <code className="action">Enter Setup</code>.

<img className="thumbnail" alt="Menu_démarrage" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/boot_menu.png" loading="lazy" />

Dans le BIOS, naviguez jusqu'à l'onglet <code className="action">Boot</code> et remplacez `UEFI Boot Order #1` par `UEFI USB CD/DVD:UEFI: CDROM virtual ATEN YSOJ`.

<img className="thumbnail" alt="Bios" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/bios.png" loading="lazy" />

Enfin, appuyez sur la touche `F4` pour enregistrer vos modifications et redémarrer le serveur.

### Installer un OS en utilisant le navigateur web KVM (uniquement pour les serveurs les plus récents)

:::warning
OVHcloud ne garantit pas le bon fonctionnement des systèmes d'exploitation installés via IPMI. Cette méthode ne doit être utilisée que par un administrateur de serveur expérimenté.

:::


Dans votre [espace client](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr), ouvrez la [console KVM](#kvm-browser).

Ici, vous avez accès aux mêmes informations et fonctionnalités que dans les modules IPMI basés sur Java.

:::info
Assurez-vous d'exécuter les prochaines étapes à un bon rythme. Le processus peut être annulé s'il existe des pauses plus longues entre les actions.

:::


Cliquez sur le bouton <code className="action">Browse File</code> et sélectionnez votre fichier image.

<img className="thumbnail" alt="Installation du KVM" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install01.png" loading="lazy" />

Cliquez sur <code className="action">Start Media</code>. Cela préparera l'ISO pour le processus d'installation.

<img className="thumbnail" alt="Installation du KVM" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install02.png" loading="lazy" />

La taille de fichier affichée n'est pas la taille réelle. C'est normal car le fichier n'est pas complètement téléversé à cette étape.

<img className="thumbnail" alt="Installation du KVM" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install03.png" loading="lazy" />

Cliquez sur <code className="action">Power</code> et sélectionnez <code className="action">Reset Server</code> (réinitialiser le serveur) dans le menu déroulant.

<img className="thumbnail" alt="Installation du KVM" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install04.png" loading="lazy" />

Attendez que l'écran de sélection de démarrage s'affiche et appuyez sur la touche appropriée pour entrer dans le menu de Boot (`F11` dans cet exemple).

<img className="thumbnail" alt="Installation du KVM" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install05.png" loading="lazy" />

Dans le menu boot, sélectionnez le lecteur optique (`UEFI: AMI Virtual CDROM0` dans cet exemple) et appuyez sur `Entrée`.

<img className="thumbnail" alt="Installation du KVM" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install06.png" loading="lazy" />

Le fichier ISO va maintenant être téléversé, puis le serveur va démarrer à partir du fichier.

<img className="thumbnail" alt="Installation du KVM" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_install07.png" loading="lazy" />

### Redémarrer un serveur dans le menu BIOS

Vous pouvez accéder au BIOS lors de la configuration ou du dépannage de votre serveur. Un moyen pratique d'y parvenir est d'utiliser l'outil `ipmiutil` (voir la [page du projet](https://ipmiutil.sourceforge.net/) pour plus d'informations).

Lorsque le serveur est en [mode rescue](/guides/bare-metal-cloud/dedicated-servers/rescue-mode/) et une fois que vous y êtes connecté, installez-le avec la commande suivante :

```bash
apt install ipmiutil
```

Redémarrez ensuite le serveur avec cette commande :

```bash
ipmiutil reset -b
```

Accédez alors à la [console IPMI](#procedure) dans votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr). Le menu BIOS du serveur doit s'afficher.

<img className="thumbnail" alt="KVM BIOS" src="/images/bare-metal-cloud/dedicated-servers/using-ipmi-on-dedicated-servers/kvm_bios.png" loading="lazy" />
