## Objectif

Les paires de clés sont utilisées pour authentifier les connexions SSH entre les hôtes, par exemple entre le client local de votre ordinateur et un serveur distant. Lors de la réinstallation d'un serveur dédié ou d'un VPS depuis votre espace client, vous avez la possibilité d'ajouter une clé publique au système d'exploitation. Le stockage de clés SSH publiques dans votre espace client facilite ce processus.

**Ce guide vous explique comment stocker vos clés SSH publiques dans votre espace client.**

## Prérequis

- Un [serveur dédié](https://www.ovhcloud.com/fr/bare-metal/) ou un [VPS](https://www.ovhcloud.com/fr/vps/) dans votre compte OVHcloud

:::info
Pour plus d'informations sur l'utilisation des clés SSH avec les services [Public Cloud](https://www.ovhcloud.com/fr/public-cloud/), consultez notre guide dédié :

[Comment créer des clés SSH avec OpenSSH pour les instances Public Cloud](/guides/public-cloud/compute/compute-creating-ssh-keys/)

:::

## En pratique

Si vous n'avez pas encore créé de paire de clés SSH, consultez d'abord nos guides :

- [Créer et utiliser des clés SSH](/guides/bare-metal-cloud/dedicated-servers/creating-ssh-keys-dedicated/)
- [Tutoriel - Comment utiliser PuTTY pour les connexions SSH et l'authentification](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows/)

<img className="thumbnail" alt="products and services" src="/images/assets/screens/control-panel/product-selection/right-menu/my-solutions-and-services.png" loading="lazy" />

Dans la section `Mes services` de votre espace client, cliquez sur <code className="action">Clés SSH</code>.

<img className="thumbnail" alt="control panel ssh keys" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/importkey1.png" loading="lazy" />

Cliquez sur le bouton <code className="action">Ajouter une clé SSH</code> et sélectionnez <code className="action">Dédié</code> dans le menu.

<img className="thumbnail" alt="control panel ssh keys" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/importkey2.png" loading="lazy" />

Dans la fenêtre qui s'affiche, saisissez un « label » pour la clé dans le premier champ.  
Copiez l'intégralité de la chaîne de clé publique et collez-la dans le deuxième champ.

<img className="thumbnail" alt="control panel ssh keys" src="/images/bare-metal-cloud/dedicated-servers/import-keys-control-panel/importkey3.png" loading="lazy" />

Cliquez sur le bouton <code className="action">Valider</code>.

La clé sera désormais disponible lors de la réinstallation d'un serveur dédié ou d'un VPS dans votre espace client.

Consultez nos guides « Premiers pas » pour plus de détails sur ce sujet :

- [Serveur dédié](/guides/bare-metal-cloud/dedicated-servers/getting-started-with-dedicated-server/)
- [Serveur dédié de la gamme **Eco**](/guides/bare-metal-cloud/dedicated-servers/getting-started-with-dedicated-server-eco/)
