## Objectif

Si vous configurez votre serveur dédié en tant que serveur DNS, vous pouvez utiliser le DNS OVHcloud secondaire pour héberger une zone secondaire. Ainsi, le DNS de votre domaine restera disponible même si le serveur DNS principal ne répond plus.

**Ce guide explique comment ajouter votre domaine dans l'espace client OVHcloud afin d'utiliser un serveur DNS secondaire.**

## Prérequis

* Disposer d’un [serveur dédié](https://www.ovhcloud.com/fr/bare-metal/).
* Disposer d’un [nom de domaine](https://www.ovhcloud.com/fr/domains/) dont vous avez la gestion administrative ou technique.

## En pratique

### Ajout d'un domaine <a name="addingdomain"></a>

Cliquez sur l'onglet <code className="action">DNS secondaire</code> puis sur le bouton <code className="action">Ajouter un domaine</code>.

<img className="thumbnail" alt="DNS secondaire" src="/images/bare-metal-cloud/dedicated-servers/adding-secondary-dns-on-dedicated-server/cp-01.png" loading="lazy" />

Entrez votre adresse IP et le domaine à ajouter, puis cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="DNS secondaire" src="/images/bare-metal-cloud/dedicated-servers/adding-secondary-dns-on-dedicated-server/cp-02.png" loading="lazy" />

Une fois que vous aurez cliqué sur <code className="action">Suivant</code> à cette étape, la vérification du domaine sera déclenchée. Si vous n'avez pas déjà ajouté un enregistrement TXT à votre zone DNS, suivez d'abord les instructions [décrites ci-dessous](#verifyingdomain). Sinon, continuez en cliquant sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="DNS secondaire" src="/images/bare-metal-cloud/dedicated-servers/adding-secondary-dns-on-dedicated-server/cp-03.png" loading="lazy" />

Après avoir cliqué sur <code className="action">Ajouter</code> dans la dernière fenêtre, le domaine sera ajouté au serveur DNS secondaire OVHcloud.

Les domaines ajoutés seront répertoriés dans cet onglet et peuvent être supprimés en cliquant sur le bouton <code className="action">...</code>. Le nom du serveur DNS secondaire s'affiche à côté du domaine.

<img className="thumbnail" alt="DNS secondaire" src="/images/bare-metal-cloud/dedicated-servers/adding-secondary-dns-on-dedicated-server/cp-05.png" loading="lazy" />

:::info
Les autres actions requises pour configurer votre propre DNS pour votre domaine sont généralement les suivantes:

- configuration d'un service DNS (tel que *BIND*)
- configuration des enregistrements GLUE
- autorisation des transferts de zone

Reportez-vous aux documentations externes appropriées si vous avez besoin d'informations supplémentaires pour compléter ces tâches administratives.

:::


### Vérification de l'autorisation pour le domaine <a name="verifyingdomain"></a>

Il est nécessaire de confirmer votre autorisation à gérer le domaine concerné avant de pouvoir l'ajouter au DNS secondaire OVHcloud. Cela s'effectue via une recherche DNS automatisée sur le sous-domaine *ownercheck.votrenomdedomaine*. Une chaîne unique de caractères est générée à cette fin et affichée dans l'espace client OVHcloud.

- Si le domaine est géré par un bureau d'enregistrement externe ou utilise des serveurs DNS externes à ce stade, connectez-vous à l'espace client de votre fournisseur DNS et ajoutez un enregistrement TXT avec le sous-domaine « ownercheck » et la valeur fournie à l'étape 2 de ["l'Ajout de domaine"](#addingdomain).

- Si le domaine est géré par OVHcloud en tant que serveur d'enregistrement et qu'il utilise des serveurs DNS OVHcloud, fermez la fenêtre en cliquant préalablement sur <code className="action">Annuler</code>. Vous pouvez ensuite suivre les instructions de [ce guide](/guides/web-cloud/domains/dns-zone-edit/) pour ajouter l'enregistrement TXT dans votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr).

<img className="thumbnail" alt="DNS secondaire" src="/images/bare-metal-cloud/dedicated-servers/adding-secondary-dns-on-dedicated-server/cp-04.png" loading="lazy" />

Après avoir correctement ajouté l'enregistrement TXT à la zone DNS du domaine, répétez les [étapes ci-dessus](#addingdomain) et terminez la procédure.
