## Objectif

Découvrez comment configurer Veeam Agent pour Microsoft Windows pour sauvegarder votre serveur Bare Metal Windows.

:::info
Pour sauvegarder un serveur Bare Metal Linux en utilisant Veeam Backup and Replication (Enterprise), consultez [ce guide](/guides/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-linux/).

:::


## Prérequis

- Un [serveur Bare Metal OVHcloud sous Windows](https://www.ovhcloud.com/fr/bare-metal/)
- Avoir installé [Veeam Backup and Replication 12.0](https://www.veeam.com/download-version.html?ad=downloads&tab=previous)
- Le [logiciel d'installation Veeam Agent for Microsoft Windows 6.0.2](https://login.veeam.com/realms/veeamsso/protocol/openid-connect/auth?client_id=veeam-com&response_type=code&redirect_uri=https%3A%2F%2Fwww.veeam.com%2Foauth&scope=profile&state=e9a55dcbf050f86c5eb69ea264b8fb86) (un compte Veeam est requis)

:::warning
Pour suivre les étapes de ce guide, vous devez avoir préalablement suivi les étapes détaillées de notre premier guide « [Préparer une sauvegarde de serveur Bare Metal avec Veeam Enterprise](/guides/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-preparation/) ».

:::


## En pratique

### Télécharger et installer Veeam Agent

Téléchargez [Veeam Agent for Microsoft Windows 6.0.2](https://login.veeam.com/realms/veeamsso/protocol/openid-connect/auth?client_id=veeam-com&response_type=code&redirect_uri=https%3A%2F%2Fwww.veeam.com%2Foauth&scope=profile&state=e9a55dcbf050f86c5eb69ea264b8fb86) sur le serveur que vous souhaitez sauvegarder.

Installez Veeam Agent et sélectionnez <code className="action">No</code> lorsque vous êtes invité à installer un fichier de licence.

<img className="thumbnail" alt="License" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/01a-licence.PNG" loading="lazy" />

Cliquez sur le bouton de menu et sélectionnez <code className="action">+ Add New Job...</code>.

<img className="thumbnail" alt="Ajouter une nouvelle tâche" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/01b-new-job.PNG" loading="lazy" />

### Configuration de la sauvegarde

#### Nom

Vous pouvez modifier le nom et/ou la description par défaut. Cliquez ensuite sur <code className="action">Next</code>.

<img className="thumbnail" alt="Nom" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/02-name.PNG" loading="lazy" />

#### Mode de sauvegarde

Choisissez les données à sauvegarder et cliquez sur <code className="action">Next</code>.

<img className="thumbnail" alt="Mode de sauvegarde" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/02b-backup-mode.PNG" loading="lazy" />

#### Destination

Choisissez <code className="action">Veeam backup repository</code>. et cliquez sur <code className="action">Next</code>.

<img className="thumbnail" alt="Destination" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/03-destination.PNG" loading="lazy" />

#### Serveur de sauvegarde

Entrez le nom ou l'adresse IP du serveur Veeam Backup et renseignez vos identifiants Veeam (ils doivent être ceux d'un [compte de service Veeam Enterprise](/guides/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication#create/) valide).

Cliquez sur <code className="action">Next</code>.

Le chargement de votre licence va prendre quelques instants.

<img className="thumbnail" alt="Serveur de sauvegarde - identifiants" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/04-backup-server-credentials.PNG" loading="lazy" />

#### Répertoire de sauvegarde

Sélectionnez votre répertoire de sauvegarde (*backup repository*) et, si vous le souhaitez, modifiez la politique de rétention.

Cliquez sur <code className="action">Next</code>.

<img className="thumbnail" alt="Répertoire de sauvegarde" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/05-backup-repository.PNG" loading="lazy" />

:::warning
Si l'option « Standard S3 » n'apparaît pas en tant que réperoire de sauvegarde, suivez les étapes ci-dessous pour vérifier les droits d'accès.
Depuis l'interface de Veeam Enterprise, sélectionnez <code className="action">Backup Repositories</code>, faites un clic droit sur votre répertoire et sélectionnez <code className="action">Access permissions...</code>.

<img className="thumbnail" alt="Backup repository - access permissions" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/05-backup-repository-access-permissions.PNG" loading="lazy" />

Dans l'onglet <code className="action">AStandalone applications</code>, assurez-vous que l'une des options **Allow** est sélectionnée pour l'accès au répertoire. Si vous devez ajouter votre compte ou votre groupe, vous pouvez utiliser le bouton <code className="action">Add...</code> . Si vous avez apporté des modifications, sélectionnez <code className="action">OK</code> pour les appliquer.

<img className="thumbnail" alt="Backup repository - standalone applications" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/05-backup-repository-standalone-applications.PNG" loading="lazy" />

:::


#### Sauvegarde en cache (facultatif)

Si vous le souhaitez, vous pouvez activer le cache de sauvegarde, ce qui peut être utile le répertoire distant de sauvegarde est temporairement indisponible.

Cliquez sur <code className="action">Next</code>.

<img className="thumbnail" alt="Backup cache" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/06-backup-cache.PNG" loading="lazy" />

#### Options avancées (facultatif)

Si vous le souhaitez, vous pouvez activer des options d'accès avancé (*Guest processing*).

Cliquez sur <code className="action">Next</code>.

<img className="thumbnail" alt="Options avancées" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/07-guest-processing.PNG" loading="lazy" />

#### Planification

Choisissez vos préférences de planification de sauvegarde et cliquez sur <code className="action">Apply</code>.

<img className="thumbnail" alt="Planification" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/08-schedule.PNG" loading="lazy" />

#### Résumé

Vérifiez vos paramètres. Si vous souhaitez que la tâche de sauvegarde s'exécute dès que vous avez terminé, cochez la case en bas de la fenêtre.

Cliquez sur <code className="action">Terminer</code>.

<img className="thumbnail" alt="Résumé" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/09-summary.PNG" loading="lazy" />

### Lancer la sauvegarde

Cliquez sur le bouton ☰ du menu, sélectionnez la tâche que vous venez de créer puis cliquez sur <code className="action">Backup Now</code>.

<img className="thumbnail" alt="Lancer la sauvegarde" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/10-start-backup.png" loading="lazy" />

Vous pouvez suivre l'avancement de votre sauvegarde depuis l'application Veeam Agent :

<img className="thumbnail" alt="Progression de la sauvegarde" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/10a-backup-progress.PNG" loading="lazy" />

Sur le serveur Veeam Backup and Recovery, la tâche de sauvegarde apparaîtra :

<img className="thumbnail" alt="Backup jobs" src="/images/bare-metal-cloud/dedicated-servers/veeam-enterprise-server-backup-windows-agent/10b-backup-job.PNG" loading="lazy" />
