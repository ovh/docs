## Objectif

Le mode rescue est un outil fourni par OVHcloud permettant de démarrer sur un système d'exploitation temporaire. Il a pour but de diagnostiquer et de résoudre les problèmes sur votre serveur.

Le fonctionnement général du mode rescue est décrit dans notre guide « [Comment activer et utiliser le mode rescue](/guides/bare-metal-cloud/dedicated-servers/rescue-mode/) ».

L'option **Système de secours client Windows** (`rescue-customer-windows`) n'est disponible que pour les serveurs dédiés sur lesquels est installé un système d'exploitation **Windows Server**. Les conditions suivantes s'appliquent :

- Le système rescue pour Windows (`rescue-customer-windows`) fonctionne dans une machine virtuelle (VM) lancée à partir du système rescue client (`rescue-customer`, basé sur Debian GNU/Linux).
- Les disques du serveur sont attachés à la VM avec *passthrough*, il est donc possible d'y accéder.
- Les autres composants du serveur seront inaccessibles (CPU, RAM, carte réseau, carte RAID).
- Le réseau est monté avec *passthrough* mais sans accès direct à la carte réseau. La VM porte l'adresse IP et l'adresse MAC du serveur *bare metal*.

:::warning
Prenez soin d'effectuer une sauvegarde de vos données si vous ne disposez pas encore de sauvegarde récente.

Si vous avez des services en production sur votre serveur, le mode rescue les interrompt tant que la machine n’a pas été redémarrée en mode normal.

:::


**Découvrez comment démarrer un serveur dans le système de secours client Windows.**

## Prérequis

- Microsoft Windows installé sur votre [serveur dédié](https://www.ovhcloud.com/fr/bare-metal/)
- Au moins 16 Go de RAM installés sur le serveur

## En pratique

### Activation du mode rescue pour Windows

Cliquez sur le nom de votre serveur pour ouvrir l'onglet <code className="action">Informations générales</code>.

<a name="netboot"></a>

Dans la case **Informations générales**, cliquez sur le bouton <code className="action">...</code> à côté de `Boot`. Cliquez sur <code className="action">Modifier</code> dans le menu contextuel.

<img className="thumbnail" alt="Modifier le mode de démarrage" src="/images/bare-metal-cloud/dedicated-servers/rescue-customer-windows/rescue-mode-001.png" loading="lazy" />

Sur la page **Modifier le netboot**, sélectionnez <code className="action">Booter en mode rescue</code>.

Sélectionnez <code className="action">Windows customer rescue system</code> dans le menu déroulant.

<img className="thumbnail" alt="Modifier le mode de démarrage" src="/images/bare-metal-cloud/dedicated-servers/rescue-customer-windows/manager-rescue-windows-menu.png" loading="lazy" style={{ maxWidth: '800px' }} />

L'e-mail de notification du mode rescue, ainsi que ses identifiants, seront envoyés à l'adresse e-mail de contact de votre compte OVHcloud. Pour utiliser une autre adresse e-mail, renseignez-la dans le champ `Recevoir les identifiants du mode sur l'adresse e-mail :`.

Cliquez sur <code className="action">Suivant</code>.

Dans l'étape **Résumé**, cliquez sur <code className="action">Valider</code>.

<img className="thumbnail" alt="Summary" src="/images/bare-metal-cloud/dedicated-servers/rescue-customer-windows/winresc_summ.png" loading="lazy" />

Vous devriez maintenant avoir une notification concernant le paramètre `Netboot` dans l'onglet <code className="action">Informations générales</code>.

<img className="thumbnail" alt="Netboot" src="/images/bare-metal-cloud/dedicated-servers/rescue-customer-windows/rescue-mode-006.png" loading="lazy" />

La dernière étape consiste à redémarrer le serveur. Cliquez sur le bouton <code className="action">...</code> à côté de « Statut » dans la zone **État des services**, puis cliquez sur <code className="action">Redémarrer</code>. Cliquez sur <code className="action">Valider</code> dans la fenêtre contextuelle.

<img className="thumbnail" alt="Reboot" src="/images/assets/screens/control-panel/product-selection/bare-metal-cloud/dedicated-servers/general-information/rebooting-your-server.png" loading="lazy" />

Ce *hard reboot* prendra quelques minutes à se terminer. Vous pouvez vérifier l'état actuel dans l'onglet <code className="action">Tâches</code>.

:::info
Après avoir terminé vos actions en mode rescue, n'oubliez pas de redéfinir le paramètre `Netboot` sur <code className="action">Booter sur le disque dur</code> avant de redémarrer le serveur.

:::


### Accéder à votre serveur en mode rescue

Une fois que vous avez reçu l'e-mail vous informant que le mode rescue est activé, vous pouvez vous connecter au système via le mode rescue de Windows et accéder à votre serveur. 
Cet e-mail est également disponible dans votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr) dès son envoi. Cliquez sur le nom associé à votre identifiant client dans la barre de menu en haut à droite, puis sélectionnez <code className="action">E-mails de service</code>.

Pour établir une session à distance sur le système en mode rescue de Windows, vous aurez besoin des informations d'identification suivantes :

- Adresse IP du serveur
- Nom d'utilisateur du compte administrateur temporaire (`Administrator`)
- Mot de passe du compte administrateur temporaire

Vous pouvez utiliser les méthodes de connexion suivantes pour accéder à votre serveur via le système en mode rescue de Windows :

- Protocole RDP (Remote Desktop Protocol)
- KVM sur IP (si votre serveur le permet)
- OpenSSH (composant officiel de Windows Server)

#### SSH

<details>

<summary>Dépliez cette section</summary>


Ouvrez l'application de ligne de commande sur votre périphérique local et entrez la commande suivante :

```bash
ssh Administrator@SERVER_IP
```

Exemple :

```bash
ssh Administrator@203.0.113.100
```

Entrez le mot de passe du mode rescue temporaire lorsque vous y êtes invité. Exemple :

```console
Administrator@ns9356771.ip-203-0-113.eu's password:
administrator@WINRESCUEOVH C:\Users\Administrator>
```

Retrouvez plus d'informations sur les connexions SSH dans notre [guide d'introduction au SSH](/guides/bare-metal-cloud/dedicated-servers/ssh-introduction/).  
Vous pouvez également utiliser n'importe quel outil de connexion SSH, tel que [PuTTY](/guides/web-cloud/web-hosting/ssh-using-putty-on-windows/).

</details>

### Sortie du mode rescue

Dans votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr), [changez le mode de démarrage](#netboot) de nouveau en <code className="action">Booter sur le disque dur</code> et validez.

<img className="thumbnail" alt="Netboot Disk" src="/images/bare-metal-cloud/dedicated-servers/rescue-customer-windows/rescue-mode-007.png" loading="lazy" style={{ maxWidth: '800px' }} />

Utilisez ensuite la fonction <code className="action">Restart</code> dans votre espace client OVHcloud.
