## Objectif

OVHcloud vous permet d’associer une adresse MAC virtuelle à une adresse IP, afin de pouvoir mettre en place des machines virtuelles avec une configuration bridge sur votre serveur.

**Ce guide vous explique comment créer une adresse MAC virtuelle et comment l’associer à une adresse Additional IP.**

## Prérequis

- Posséder [un serveur dédié](https://www.ovhcloud.com/fr/bare-metal/) qui supporte les MAC virtuelles. Consultez [ce guide](/guides/bare-metal-cloud/dedicated-servers/network-support-virtual-mac/) afin de le déterminer.
- Disposer d’une [adresse Additional IP](https://www.ovhcloud.com/fr/network/additional-ip/) ou un bloc d’Additional IP (RIPE).

## En pratique

### Assigner une adresse MAC

:::warning
Si un bloc IP a été déplacé dans le vRack, il n’est plus assigné à un serveur physique à ce titre, il n’est plus possible d’assigner une MAC virtuelle à une IP.

:::


#### Via l'espace client OVHcloud

Cliquez sur l'onglet <code className="action">Additional IP</code>.

<img className="thumbnail" alt="IP" src="/images/bare-metal-cloud/dedicated-servers/network-virtual-mac/manageIPs2022.png" loading="lazy" />

Localisez ensuite votre adresse Additional IP (ou votre bloc) dans la liste, puis cliquez sur le bouton <code className="action">...</code> pour afficher la liste des options.

<img className="thumbnail" alt="IP" src="/images/bare-metal-cloud/dedicated-servers/network-virtual-mac/addvmac.png" loading="lazy" />

Lorsque la boîte de dialogue « Ajouter une MAC virtuelle » apparaît, sélectionnez un type dans la liste déroulante, entrez un nom de machine virtuelle, puis cliquez sur <code className="action">Confirmer</code>.

:::info
**Type** : il s'agit du type d’adresse MAC virtuelle (« VMware » sera une adresse MAC faite pour le système VMware ESXi tandis qu'« ovh » conviendra à tous les autres types de systèmes de virtualisation).

**Nom de la machine virtuelle** : il s'agit du nom souhaité pour l’adresse MAC virtuelle, pour retrouver ensuite plus facilement ce couple IP/MAC.

:::


<img className="thumbnail" alt="IP" src="/images/bare-metal-cloud/dedicated-servers/network-virtual-mac/addvmac2.png" loading="lazy" />

:::info
N’oubliez pas d’assigner l’adresse MAC virtuelle créée lors de la configuration de votre machine virtuelle.

:::


#### Via l'API OVHcloud

Utilisez l'appel API suivant :

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/virtualMac/\{macAddress\}/virtualAddress/\{ipAddress\}"} />


### Supprimer une adresse MAC

:::warning
La suppression d'une adresse MAC est définitive, aucune récupération ultérieure ne sera possible.

:::


#### Via l'espace client OVHcloud

Connectez-vous à votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr), cliquez sur <code className="action">Network</code> dans le menu situé à gauche de l'écran, puis sur <code className="action">Adresses IP Publiques</code>.

Pour finir, cliquez sur le bouton <code className="action">...</code> à droite puis cliquez sur <code className="action">Supprimer la MAC virtuelle</code>.

#### Via l'API OVHcloud

Utilisez l'appel API suivant :

<Api version="v1" section="/dedicated/server" method="DELETE" route={"/dedicated/server/\{serviceName\}/virtualMac/\{macAddress\}/virtualAddress/\{ipAddress\}"} />


## FAQ

- **Que se passe-t-il si je déplace un bloc avec des vMACs sur un serveur Advance de troisième génération (équipé d'un processeur EPYC 4004 Series) possédant déjà 32 vMACs ?**

Le bloc ne sera pas déplacé.

Exemple : si vous tentez de déplacer un bloc de 4 IP avec des vMACs différentes attachées sur un serveur ayant déjà 30 vMACs le bloc ne sera pas déplacé car le total de vMACs serait supérieur aux 32 vMACs autorisées.
