:::info
Cet article concerne le déplacement d'adresses Additional IPv4, qui est limité selon des [restrictions régionales](#limitations).

La configuration d'Additional IP dans un vRack (réseau privé) contourne ces restrictions régionales en perdant la dépendance à une seule région, tout en facilitant l'interconnexion sur une large gamme de services OVHcloud.

Apprenez à configurer des Additional IP dans un vRack avec nos guides pour [IPv4](/guides/bare-metal-cloud/dedicated-servers/configuring-an-ip-block-in-a-vrack/) et [IPv6](/guides/bare-metal-cloud/dedicated-servers/configure-an-ipv6-in-a-vrack/).

:::


## Objectif

Les Additional IP peuvent être déplacées entre les services que vous utilisez. L'intérêt est de ne pas perdre votre réputation, votre référencement et d'améliorer la continuité de service de vos applications et systèmes.

Cette technologie vous permet d’échanger les adresses IP d'une solution à l'autre en moins d'une minute, pratiquement sans aucune interruption pour vos utilisateurs. Elle peut être utilisée lors des migrations de services (déplacement des projets de l'environnement de développement à celui de production, par exemple) ou lors du basculement vers un serveur de secours en cas de défaillance.

:::info
Vous pouvez attribuer vos blocs d’adresses IP à n’importe quel service compatible au sein d’une région. Les blocs d’adresses IP d’une région peuvent être déplacés d’un centre de données à un autre, mais uniquement au sein de cette même région.

Sauf pour les 3 régions eu-west-gra, eu-west-rbx et eu-west-sbg, où les blocs d'adresses IP peuvent être déplacés entre ces trois régions.

Une région est une zone géographique composée d'un ou de plusieurs datacenters.

La migration ne fonctionne que pour des blocs entiers, il n'est pas possible de migrer des IP individuelles au sein d'un bloc.

:::


**Découvrez comment déplacer une Additional IP depuis votre espace client OVHcloud ou via les API OVHcloud, y compris d'un compte So you Start vers un compte OVHcloud.**

## En pratique

:::info
Lorsqu’un bloc IP contenant des adresses MAC virtuelles uniques est déplacé entre deux serveurs, ces adresses sont temporairement suspendues. Elles apparaîtront sur le nouveau serveur une fois le déplacement effectué.

D’autre part, les blocs contenant des adresses MAC virtuelles en double ne peuvent pas être déplacés. Vous devez d'abord supprimer l'adresse MAC virtuelle en double sur le bloc à déplacer.

Si un bloc IP est déplacé/ajouté dans le vRack, il n’est plus lié à un serveur physique. Dans ce cas, toute adresse MAC virtuelle sera perdue pendant le transfert.

:::


### Blocs IP géolocalisés

La géolocalisation d'une adresse IP est indépendante de sa région de rattachement.

Si vous commandez un bloc Additional IP sur un serveur mais que vous choisissez une localisation différente (géolocalisation) pour le bloc IP, ce bloc IP ne peut pas être déplacé vers un autre serveur situé dans le même pays que ce bloc. Par exemple, un bloc Additional IP géolocalisé en Pologne (eu-central-war) et commandé sur un serveur situé dans un datacenter en France (eu-west-gra) ne peut pas être déplacé vers un serveur situé dans un datacenter en Pologne (eu-central-war). Le bloc IP ne peut être déplacé que vers un serveur éligible situé dans un datacenter en France.

### Déplacer une Additional IP depuis l'espace client OVHcloud

:::warning
Seul un bloc de taille unique (/32) pourra être déplacé depuis un serveur dédié vers un VPS.

:::


Vous pouvez utiliser le menu déroulant sous **Mes adresses IP publiques et services associés** et sélectionner <code className="action">Toutes les Additional IP</code> pour filtrer vos services, ou taper directement l'adresse IP désirée dans la barre de recherche.

<img className="thumbnail" alt="espace client" src="/images/assets/screens/control-panel/product-selection/bare-metal-cloud/network/manage-additional-ips-new.png" loading="lazy" />

Cliquez sur le bouton <code className="action">⁝</code> à droite de l'adresse IP à déplacer puis sur <code className="action">Déplacer Additional IP</code>.

<img className="thumbnail" alt="espace client" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/move_ip_1_new.png" loading="lazy" />

Dans le menu contextuel qui apparaît, sélectionnez le service vers lequel déplacer l'adresse IP.

Cliquez sur <code className="action">Suivant</code> puis sur <code className="action">Valider</code>.

<img className="thumbnail" alt="espace client" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/move_ip_2_new.png" loading="lazy" />

:::warning
Veuillez noter que pour certains produits, les adresses IP (ou blocs) doivent d'abord être déplacées vers un **Parking IP** (un emplacement de stockage temporaire), avant de pouvoir être déplacées vers le produit souhaité.

Pour déplacer des blocs IP vers un réseau vRack spécifique, veuillez utiliser **l'interface de gestion vRack**, à laquelle vous pouvez accéder en cliquant sur <code className="action">Network</code> dans le menu situé à gauche de l'écran, puis sur <code className="action">Réseau privé vRack</code>.

:::


### Déplacer une Additional IP via les API

Connectez-vous sur la page web des [API OVHcloud](https://eu.api.ovh.com/).

Vérifiez d'abord si l'adresse IP peut être déplacée.
<br/>Pour vérifier si l'IP peut être déplacée vers un de vos serveurs dédiés, utilisez l'appel suivant :

<Api version="v1" section="/dedicated/server" method="GET" route={"/dedicated/server/\{serviceName\}/ipCanBeMovedTo"} />


- `serviceName` : la référence du serveur dédié de destination
- `ip` : l'adresse Additional IP à déplacer

Pour déplacer l'adresse IP, utilisez l'appel suivant :

<Api version="v1" section="/dedicated/server" method="POST" route={"/dedicated/server/\{serviceName\}/ipMove"} />


- `serviceName` : la référence du serveur dédié de destination
- `ip` : l'adresse Additional IP à déplacer

### Déplacer une Additional IP d'un compte So you Start vers un compte OVHcloud

Pour déplacer une Additional IP d'un compte SYS vers un compte OVHcloud, vous devez tenir compte de plusieurs éléments :

- Le déplacement d'une Additional IP entraîne des frais d'installation. L'adresse IP ne sera pas déplacée si la facture reste impayée.
- Il n'est pas possible de déplacer une Additional IP d'un compte OVHcloud vers un compte So you Start.
- Assurez-vous que le serveur vers lequel vous transférez l'adresse Additional IP se trouve dans la même région compatible que celle-ci. Consultez la section « Restrictions » ci-dessous.

Pour commencer, connectez-vous à votre compte So you Start et cliquez sur <code className="action">IP</code> dans le tableau de bord principal.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/sys-ip-section.png" loading="lazy" />

Cliquez sur le bouton de paramètres (en forme d'engrenage <code className="action">⚙</code>) à côté de l'adresse IP correspondante et sélectionnez <code className="action">Déplacer l'IP FO</code>.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/move-ip-sys.png" loading="lazy" />

Sélectionnez <code className="action">Déplacer vers un service OVH</code>, entrez votre identifiant client OVHcloud et cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/move-to-ovh.png" loading="lazy" />

Cela générera un code, sauvegardez-le.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/token-id.png" loading="lazy" />

Ensuite, [connectez-vous à votre compte OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr), cliquez sur <code className="action">Network</code> dans le menu situé à gauche de l'écran, puis sur <code className="action">Adresses IP Publiques</code>.

Cliquez sur le bouton de paramètres (en forme d'engrenage <code className="action">⚙</code>) à droite et sélectionnez <code className="action">Importer mes adresses IP de Sys vers OVHcloud</code>.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/import-ip-to-ovh.png" loading="lazy" />

Dans la fenêtre contextuelle, entrez l'adresse Additional IP (ou le bloc) et le code récupéré depuis le compte So you Start, puis cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/Step-1.png" loading="lazy" />

Sélectionnez le serveur de destination et cliquez sur <code className="action">Suivant</code>. Si le serveur dédié est compatible avec l'adresse IP, un message vert s'affichera. Dans le cas contraire, vous recevrez un message d'erreur.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/Step-2.png" loading="lazy" /><br/>
<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/Step-2.1.png" loading="lazy" />

Dans la fenêtre suivante, la durée est automatiquement sélectionnée et les frais sont affichés. Cliquez sur <code className="action">Suivant</code> pour continuer.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/Step-3.png" loading="lazy" />

Cochez la case <code className="action">Accepter les contrats</code> pour accepter les conditions d'utilisation après les avoir lues. Cliquez ensuite sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/Step-4.png" loading="lazy" />

Prenez note du récapitulatif de la commande et cliquez sur <code className="action">Confirmer</code> pour la valider.

<img className="thumbnail" alt="soyoustart to ovh" src="/images/bare-metal-cloud/dedicated-servers/move-failover-ip/Step-5.png" loading="lazy" />

Vous serez redirigé vers une nouvelle page pour effectuer le paiement.

Une fois le paiement effectué, votre Additional IP sera transférée vers votre compte OVHcloud et associée au serveur sélectionné. Ce processus peut prendre du temps.
