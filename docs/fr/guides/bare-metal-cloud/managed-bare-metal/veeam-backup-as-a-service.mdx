## Objectif

Veeam est un éditeur de logiciel spécialisé dans les solutions de sauvegarde et de plan de reprise d'activité (PRA) dans des environnements virtualisés. L'offre Veeam Managed Backup s'appuie sur la brique logicielle Veeam Availability Suite pour vous fournir une solution de backup à la demande.

Les sauvegardes sont réalisées à l'aide d'une machine virtuelle (VM) située à l’intérieur même de votre infrastructure [Managed Bare Metal](https://www.ovhcloud.com/fr/managed-bare-metal/). Les données sauvegardées sont, quant à elles, externalisées vers un espace de stockage indépendant, chez OVHcloud. Les sauvegardes s'effectuent la nuit, avec une durée de rétention en fonction du niveau d'offre choisi.

**Ce guide vous explique comment déployer et utiliser l'option Veeam Managed Backup en quelques minutes.**

## Prérequis

* Posséder une offre [Managed Bare Metal](https://www.ovhcloud.com/fr/managed-bare-metal/).
* [Donner le droit « Ajout de ressources »](/guides/bare-metal-cloud/managed-bare-metal/change-user-rights/) pour le datacenter concerné à l'utilisateur depuis l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr).
* Être connecté au client vSphere.
* Avoir activé la [haute disponibilité (HA)](/guides/bare-metal-cloud/managed-bare-metal/vmware-ha-high-availability/).
* Avoir activé le [Distributed Ressource Scheduler (DRS)](/guides/bare-metal-cloud/managed-bare-metal/vmware-drs-distributed-ressource-scheduler/) sur le ou les clusters.
* Mettre en place la gestion des licences Windows sur le Managed Bare Metal.

:::info
Nos offres Veeam ne sont actuellement pas compatibles avec la dernière version (10) proposée par Veeam. OVHcloud continuera de proposer la version 9.5 jusqu'à nouvel ordre. Veuillez prendre en compte ce point lors de la configuration de Veeam pour vos services.

:::


## En pratique

### Activer le service

La première étape consiste à activer le service depuis l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr). Pour cela, rendez-vous dans la partie <code className="action">Managed Bare Metal</code> de l'onglet <code className="action">Bare Metal Cloud</code>. Cliquez sur l'infrastructure vSphere concernée, puis sur le datacenter souhaité. Choisissez l'onglet <code className="action">Backup</code>.

<img className="thumbnail" alt="Activer le backup" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/veeam-managed-bare-metal.png" loading="lazy" />

Choisissez le niveau de l'offre de sauvegarde puis continuez en cliquant sur <code className="action">Choisir l'offre</code>.

Validez les contrats en cliquant sur <code className="action">Activer le backup</code>.

Une notification vous confirme la demande d'activation.

Une fois l'option installée, un e-mail de confirmation vous est envoyé et l'activation de la sauvegarde vous sera indiqué dans l'espace client, avec le rappel du niveau de l'offre choisi.

<img className="thumbnail" alt="Activer le backup" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/backuppcc_03_en.png" loading="lazy" />

Le service est dès lors utilisable directement depuis vSphere.

Vous verrez apparaître sur votre infrastructure vSphere une machine virtuelle correspondant au serveur de sauvegarde :

<img className="thumbnail" alt="Serveur de sauvegarde" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/backupserver.png" loading="lazy" />

### Activer la sauvegarde pour les machines virtuelles souhaitées

Maintenant que le service est en place, il suffit de réaliser les demandes de sauvegarde pour chaque machine virtuelle identifiée comme critique depuis le vSphere Web Client.

Sélectionnez le datacenter VMware, puis l'onglet <code className="action">Configure</code> et choisissez <code className="action">Backup Management</code> dans la section OVHCloud du menu.

<img className="thumbnail" alt="Backup Management" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/backupvm_01.png" loading="lazy" />

Dans la liste, sélectionnez la VM pour laquelle vous souhaitez activer la sauvegarde. Sur le panneau à droite, cliquez alors sur <code className="action">Enable backup on this VM</code> pour lancer la demande d'activation.

<img className="thumbnail" alt="Activation de la sauvegarde" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/backupvm_02.png" loading="lazy" />

Une fenêtre de confirmation apparaît. Cliquez simplement sur <code className="action">OK</code>.

<img className="thumbnail" alt="Confirmation de la sauvegarde" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/backupvm_03.png" loading="lazy" />

Veeam est informé de cette nouvelle demande et crée le travail de sauvegarde de la machine virtuelle. Chaque nuit, à partir de 22 heures (par défaut), une tâche de sauvegarde sera programmée selon le schéma de sauvegarde défini par l'offre.

Chaque jour, un e-mail contenant les statuts de l'ensemble des travaux effectués est envoyé à l'adresse du compte OVHcloud.

:::warning
La suppression d'une machine virtuelle de votre inventaire ou d'un disque ne désactive pas le travail de sauvegarde relatif à cette machine. Celui-ci apparaîtra en erreur dans le rapport.

:::


### Restaurer une sauvegarde

Sélectionnez le datacenter VMware, puis l'onglet <code className="action">Configure</code> et choisissez <code className="action">Backup Management</code> dans la section OVHcloud du menu.

Dans la liste, sélectionnez la VM pour laquelle vous souhaitez restaurer une sauvegarde (celle-ci doit avoir un **backup state** à **Enabled**).

<img className="thumbnail" alt="Restauration du backup" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/restorebackup_01.png" loading="lazy" />

Sur le panneau à droite, cliquez alors sur <code className="action">Restore Backup</code> pour lancer la demande de restauration.

<img className="thumbnail" alt="Restauration du backup" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/restorebackup_02.png" loading="lazy" />

Une nouvelle fenêtre s'ouvre alors pour créer le travail de restauration. Vérifiez bien le nom de la machine, sélectionnez la date de sauvegarde à restaurer et choisissez le datastore (espace de stockage utilisé comme cible de restauration). Cliquez sur <code className="action">Restore Backup</code> pour lancer la restauration.

<img className="thumbnail" alt="Initialisation de la restauration" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/restorebackup_03.png" loading="lazy" />

Une fenêtre confirme alors que le serveur Veeam est informé de cette nouvelle demande et que la création du travail de restauration de la machine virtuelle a été effectuée.

<img className="thumbnail" alt="Validation de la restauration" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/restorebackup_04.png" loading="lazy" />

La machine est restaurée à côté de la machine source.

<img className="thumbnail" alt="La machine source est restaurée" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/restorebackup_05.png" loading="lazy" />

:::warning
Attention, la machine restaurée est connectée au réseau. Si vous démarrez celle-ci sans avoir désactivé la machine source, il risque d'y avoir un conflit d'adresse IP.

:::


<img className="thumbnail" alt="Conflit d'IP" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/restorebackup_06.png" loading="lazy" />

Pour effectuer ces actions, vous pouvez sélectionner le datacenter dans votre inventaire, cliquer sur l'onglet <code className="action">Configure</code>, puis choisir <code className="action">OVH Backup Management</code>. Dans cette page, vous avez accès à la liste de vos travaux de sauvegarde, avec le nombre de backups et le dernier statut du travail.

### Désactiver la sauvegarde d'une machine virtuelle

Sélectionnez le datacenter VMware, puis l'onglet <code className="action">Configure</code> et choisissez <code className="action">Backup Management</code> dans la section OVHcloud du menu.

Dans la liste sélectionnez la VM pour laquelle vous souhaitez désactiver la sauvegarde.

<img className="thumbnail" alt="Désactivation de la machine" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/restorebackup_01.png" loading="lazy" />

Sur le panneau à droite, cliquez alors sur <code className="action">Disable Backup on this VM</code> pour désactiver la sauvegarde.

<img className="thumbnail" alt="Désactivation de la sauvegarde" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/restorebackup_02.png" loading="lazy" />

Confirmez ensuite la désactivation en cliquant sur <code className="action">OK</code>.

<img className="thumbnail" alt="Confirmation de désactivation" src="/images/bare-metal-cloud/managed-bare-metal/veeam-backup-as-a-service/disablebackup_03.png" loading="lazy" />

:::warning
Il est possible de réactiver la sauvegarde à tout moment à partir du moment où la machine virtuelle est présente dans l'infrastructure.

A noter que les sauvegardes effectuées restent disponibles pour la restauration juqu'à l'expiration du délai de retention.

:::


:::info
Suivez les mêmes instructions pour désactiver la sauvegarde d'une VM supprimée.
Il est également possible de désactiver la sauvegarde temporairement et de la réactiver par la suite.

:::
