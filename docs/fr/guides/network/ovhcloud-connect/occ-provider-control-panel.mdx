## Objectif

OVHcloud Connect permet d’étendre votre réseau d’entreprise avec votre réseau privé OVHcloud vRack sans passer par la création d’un tunnel VPN à travers Internet. Cette connexion sera ainsi plus rapide, plus fiable et avec une bande passante garantie. 

**Ce guide vous présente la mise en service de l'offre OVHcloud Connect Provider depuis l'espace client OVHcloud**

## Prérequis

:::warning
Pour assurer un fonctionnement correct de ce service, vous devez prendre connaissance des [capacités et limites techniques de l'offre OVHcloud Connect](/guides/network/ovhcloud-connect/occ-limits/) et configurer vos équipements réseau en accord avec celles-ci.

:::


- Avoir commandé une [offre OVHcloud Connect Provider](https://www.ovhcloud.com/fr/network/ovhcloud-connect/)
- Disposer d'un [vRack OVHcloud](https://www.ovhcloud.com/fr/network/vrack/)
- Être connecté à votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr)

## En pratique

### Étape 1 : commande de votre offre

Une fois votre offre OVHcloud Connect Provider commandée, vous recevrez une confirmation de commande par e-mail ainsi qu'une clé de service (ServiceKey).

Selon le fournisseur que vous avez choisi, rendez-vous ensuite sur le portail de celui-ci pour vous identifier, le lien étant fourni dans l'e-mail de confirmation de commande. 
Renseignez alors votre clé de service et validez la commande qui vous sera présentée.

Vérifiez par la suite dans votre  [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr) le statut d'activation de votre offre. Pour cela, cliquez sur <code className="action">Bare Metal Cloud</code> puis sélectionnez l'onglet <code className="action">Network</code>. Ensuite, cliquez sur <code className="action">OVHcloud Connect</code> puis sur votre offre. Le statut de votre offre passera à « Actif ».

### Étape 2 : associer un vRack

Connectez-vous à [l’espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr), cliquez sur <code className="action">Bare Metal Cloud</code> en haut à gauche puis sélectionnez l'onglet <code className="action">Network</code>. Cliquez alors sur <code className="action">OVHcloud Connect</code> puis sur votre offre.

<img className="thumbnail" alt="ovhcloud connect selection" src="/images/network/ovhcloud-connect/occ-provider-control-panel/occ_01.png" loading="lazy" />

Vous devez commencer par associer un vRack à votre offre. Cliquez sur le bouton <code className="action">Associer un vRack</code> et sélectionnez un vRack existant dans le menu déroulant. 

<img className="thumbnail" alt="associate vRack" src="/images/network/ovhcloud-connect/occ-provider-control-panel/vrack01.png" loading="lazy" />

Un message vous confirmera l'association du vRack.

<img className="thumbnail" alt="associate vRack" src="/images/network/ovhcloud-connect/occ-provider-control-panel/vrack2.png" loading="lazy" />

### Étape 3 : ajouter une configuration PoP

:::warning
L'offre OVHcloud Connect Provider nécessite une configuration de niveau L3.

:::


Une fois votre vRack associé, cliquez sur <code className="action">Ajouter une configuration PoP</code> et sélectionnez la configuration L3 dans le menu déroulant.

<img className="thumbnail" alt="ajout Pop" src="/images/network/ovhcloud-connect/occ-provider-control-panel/pop1.png" loading="lazy" />

Vous devrez alors saisir les éléments suivants :

| Information    | Description |
|:-------:|:------:|
| ASN client    | Votre numéro d'AS BGP, qui est configuré sur votre routeur situé dans le PoP |
| ASN OVHcloud    | Le numéro d'AS OVHcloud qui sera configuré sur les routeurs de OVHcloud Connect situés dans le PoP |
| Sous-réseau en /30    | Un bloc IPv4 de taille /30, utilisé pour le lien entre votre routeur et le routeur OVHcloud Connect situé dans le PoP |

<img className="thumbnail" alt="ajout Pop" src="/images/network/ovhcloud-connect/occ-provider-control-panel/l3pop1-1.png" loading="lazy" />

Le menu `Configuration PoP` apparaîtra alors.

<img className="thumbnail" alt="ajout Pop" src="/images/network/ovhcloud-connect/occ-provider-control-panel/l3pop2.png" loading="lazy" />

### Étape 4 : ajout d'une configuration Zone de disponibilité (AZ) 

Lorsque votre configuration PoP a été définie, cliquez sur <code className="action">Ajouter une configuration</code> sous le menu `Configuration AZ`.

<img className="thumbnail" alt="ajout AZ" src="/images/network/ovhcloud-connect/occ-provider-control-panel/l3dc0.png" loading="lazy" />

Sélectionnez une zone de disponibilité dans le menu déroulant puis renseignez les informations requises. 

| Information    | Description |
|:-------:|:------:|
| ASN OVHcloud    | Le numéro d'AS OVHcloud qui sera configuré sur les routeurs OVHcloud Connect situés dans l'AZ. Ce numéro peut être différent de l'ASN choisi pour le PoP |
| Sous-réseau en /28    |  Un sous-réseau privé configuré dans votre vRack dans l'AZ sélectionnée. Cela peut être un bloc IPv4 de taille /28 ou supérieur |

<img className="thumbnail" alt="ajout AZ" src="/images/network/ovhcloud-connect/occ-provider-control-panel/l3dc1.png" loading="lazy" />

Vous pouvez ajouter des configurations AZ supplémentaires en cliquant sur le bouton <code className="action">+ Ajouter une configuration</code>.

<img className="thumbnail" alt="ajout AZ" src="/images/network/ovhcloud-connect/occ-provider-control-panel/l3dc1-1.png" loading="lazy" />

Vous devez également ajouter une configuration de routage.

##### **Ajout d'une configuration de routage**

Cliquez sur le bouton <code className="action">(...)</code> sur l'AZ voulue puis sur <code className="action">Ajouter configuration de routage</code>.

<img className="thumbnail" alt="ajout AZ" src="/images/network/ovhcloud-connect/occ-provider-control-panel/l3dc2.png" loading="lazy" />

Choisissez alors le type de routage entre « Static » et « BGP ».

<img className="thumbnail" alt="ajout AZ" src="/images/network/ovhcloud-connect/occ-provider-control-panel/l3dc3.png" loading="lazy" />

Si vous choisissez le type « BGP », saisissez alors les informations requises :

| Information    | Description |
|:-------:|:------:|
| ASN client    | Votre numéro d'AS BGP, qui est configuré sur votre routeur situé dans l'AZ |
| IP Neighbor    | Adresse IP du neighbor BGP de votre routeur dans l'AZ. Cette adresse doit faire partie du sous-réseau renseigné dans la `Configuration AZ` |

<img className="thumbnail" alt="ajout AZ" src="/images/network/ovhcloud-connect/occ-provider-control-panel/l3dc5.png" loading="lazy" />

Si vous choisissez le type « Static », saisissez les informations requises :

| Information    | Description |
|:-------:|:------:|
| Sous-réseau    | Un préfixe utilisant la notation CIDR |
| Nexthop    | Adresse IP agissant comme passerelle dans la plage de sous-réseau |

<img className="thumbnail" alt="ajout AZ" src="/images/network/ovhcloud-connect/occ-provider-control-panel/l3dc4.png" loading="lazy" />

Vous pouvez ajouter plusieurs configurations de routage au sein d'une même zone de disponibilité. Le type de configuration (BGP ou Static) choisi sur votre première configuration s'appliquera alors aux suivantes sur la même zone de disponibilité.

<img className="thumbnail" alt="ajout AZ" src="/images/network/ovhcloud-connect/occ-provider-control-panel/l3dc6.png" loading="lazy" />

### Suppression des ressources

Chaque ressource (PoP ou AZ) peut être supprimée individuellement, mais la suppression d’une ressource parente telle que AZ ou POP supprimera automatiquement toutes les sous-ressources.

La suppression récursive est plus lente que la suppression séquentielle de chaque ressource.

:::info
Si une configuration AZ est partagée entre au moins deux services OVHcloud Connect, la suppression de la configuration PoP d’un seul service OVHcloud Connect n’affectera pas la ressource AZ.

:::


#### Suppression d'une configuration de routage

Pour supprimer une configuration de routage, cliquez sur le bouton <code className="action">(...)</code> sur la configuration de routage à supprimer puis sur <code className="action">Supprimer</code>.

<img className="thumbnail" alt="suppression configuration routage" src="/images/network/ovhcloud-connect/occ-provider-control-panel/deleterouting.png" loading="lazy" />

#### Suppression d'une configuration AZ

Pour supprimer une configuration AZ, cliquez sur le bouton <code className="action">(...)</code> sur la configuration AZ à supprimer puis sur <code className="action">Supprimer</code>.

<img className="thumbnail" alt="suppression configuration DC" src="/images/network/ovhcloud-connect/occ-provider-control-panel/deletedc.png" loading="lazy" />

:::info
La suppression d'une configuration AZ entraînera la suppression des configurations de routage liées.

:::


#### Suppression de la configuration PoP

Pour supprimer une configuration PoP, cliquez sur le bouton <code className="action">(...)</code> sur la configuration PoP puis sur <code className="action">Supprimer la configuration</code>.

<img className="thumbnail" alt="suppression configuration PoP" src="/images/network/ovhcloud-connect/occ-provider-control-panel/deletepopl3.png" loading="lazy" />

:::info
La suppression d'une configuration PoP entraînera la suppression des configurations AZ et de routage.

:::
