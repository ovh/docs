## Présentation de la gestion des machines virtuelles dans Prism Central

Le système Nutanix utilise les mêmes interfaces pour gérer le stockage et la virtualisation, il peut être installé avec plusieurs hyperviseurs (**Hyper-V, VMware ESXi , AHV**). **AHV** est fourni avec Nutanix sans devoir acheter de licences supplémentaires pour l'hyperviseur. 

L'offre d'OVHcloud est fournie avec l'hyperviseur **AHV**.

**AHV** permet entre autres :

- L'utilisation de machines virtuelles sous Windows et Linux.
- La migration de machines virtuelles d'un nœud à l'autre d'un cluster.
- La micro-segmentation et la sécurisation du réseau entre machines virtuelles en utilisant le logiciel **Flow**. 

L'outil **Move** permet de migrer facilement des machines virtuelles existantes sur d'autres environnements (**ESXi, Hyper-V & AWS**) vers Nutanix et son hyperviseur **AHV**.

Pour plus de détails sur **AHV**, reportez-vous à la section « [Aller plus loin](#gofurther) » de ce guide.

## En pratique

Les cas pratiques ci-dessous montrent la création d'une machine virtuelle sous Windows Server 2022 et de la migration d'un machine virtuelle.

### Création d'une Ordinateur virtuel pour un système d'exploitation Windows 2022

L'installation d'une machine virtuelle sous Windows Server 2022 nécessite un paramétrage particulier car Microsoft ne fournit pas le pilote pour le contrôleur de disques de l'hyperviseur **AHV**.

#### Création d'une machine virtuelle Windows Server 2022
 
Dans le menu de gauche de **Prism Central**, dépliez <code className="action">Compute & Storage</code> et cliquez sur <code className="action">VMs</code>

<img className="thumbnail" alt="Tableau de Bord Prism Central - Menu VMs" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/PrismCentralDashBooardWithVMMenu.PNG" loading="lazy" />

Cliquez sur le bouton <code className="action">Create VM</code>.

<img className="thumbnail" alt="Tableau de Bord Prism Central - Gestion des VMs " src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/PrismCentralDashVmDashBoard.PNG" loading="lazy" />

Saisissez un nom dans <code className="action">Name</code>, choisissez les options dans <code className="action">VM Properties</code> et cliquez sur <code className="action">Next</code>

<img className="thumbnail" alt="Création d'une machine virtuelle - Etape 1" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM01.PNG" loading="lazy" />

##### **Ajout d'un disque système**

Cliquez sur le bouton<code className="action">Attach Disk</code>.

<img className="thumbnail" alt="Création d'une machine virtuelle - Etape 2" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM02.PNG" loading="lazy" />

Saisissez **60** dans le champ `capacity` et cliquez sur <code className="action">Save</code> pour créer un disque de 60 Go.

<img className="thumbnail" alt="Création d'une machine virtuelle - Etape 3" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM03.PNG" loading="lazy" />

##### **Ajout de l'image ISO de l'installation de Windows Server 2022**

L'image doit être importée avant d'être utilisable dans une nouvelle machine virtuelle.

Pour plus de détails sur l'importation d'images, reportez-vous à la section « [Aller plus loin](#gofurther) » de ce guide.

Cliquez sur <code className="action">Attach Disk</code>.

<img className="thumbnail" alt="Création d'une machine virtuelle - Etape 4" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM04.PNG" loading="lazy" />

Modifiez les paramètres <code className="action">Type</code> en **CD-ROM**, <code className="action">Operation</code> en **Clone from Image** , <code className="action">Image</code> en **WS2022EN.ISO**.

Cliquez sur <code className="action">Save</code>.

<img className="thumbnail" alt="Création d'une machine virtuelle - Etape 5" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM05.PNG" loading="lazy" />

##### **Ajout de l'image ISO contenant les pilotes spécifiques à AHV** 

Cette image contient notamment le pilote du contrôleur de disques et doit aussi être importée. Elle est disponible sur le site Internet de Nutanix si vous disposez d'un compte client Nutanix.

Cliquez sur <code className="action">Attach Disk</code>.

<img className="thumbnail" alt="Création d'une machine virtuelle - Etape 6" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM06.PNG" loading="lazy" />

Modifiez les paramètres <code className="action">Type</code> en **CD-ROM**, <code className="action">Operation</code> en **Clone from Image**, <code className="action">Image</code> en **Nutanix-VirtIO-1.1.7.iso**.

Cliquez sur <code className="action">Save</code>.

<img className="thumbnail" alt="Création d'une machine virtuelle - Etape 7" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM07.PNG" loading="lazy" />

##### **Configuration du réseau**

Cliquez sur <code className="action">Attach Subnet</code>.

<img className="thumbnail" alt="Création d'une machine virtuelle - Etape 8" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM08.PNG" loading="lazy" />

Laissez les champs par défaut et cliquez sur <code className="action">Save</code>.

<img className="thumbnail" alt="Création d'une machine virtuelle - Etape 9" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM09.PNG" loading="lazy" />

Cliquez sur <code className="action">Next</code>.

<img className="thumbnail" alt="Création d'une machine virtuelle - Etape 10" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM10.PNG" loading="lazy" />

Choisissez le fuseau horaire de votre pays dans le champ <code className="action">Timezone</code> et cliquez sur <code className="action">Next</code>.

<img className="thumbnail" alt="Création d'une machine virtuelle - Etape 11" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM11.PNG" loading="lazy" />

Cliquez sur <code className="action">Create VM</code>.

<img className="thumbnail" alt="Création d'une machine virtuelle - Etape 12" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM12.PNG" loading="lazy" />

La machine virtuelle nouvellement créée apparaît alors dans le tableau de bord.

<img className="thumbnail" alt="Tableau de bord VMs - VM Créé" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/CreateVM13.PNG" loading="lazy" />.

#### Installation des NGT (Nutanix Guest Tools)

Les NGT sont des outils qui permettent une meilleure interaction avec Nutanix, notamment au niveau des sauvegardes et des snapshots.

Lancez la console de la machine virtuelle, faites un clic-droit sur un lecteur de CDROM et cliquez sur <code className="action">Eject</code>.

<img className="thumbnail" alt="NGT Installation 1" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/Ngt-Installation01.png" loading="lazy" />

Revenez dans Prism Central et sélectionnez la machine virtuelle.

<img className="thumbnail" alt="NGT Installation 2" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/Ngt-Installation02.png" loading="lazy" />

Dans le menu <code className="action">Actions</code>, cliquez sur <code className="action">Install NGT</code>.

<img className="thumbnail" alt="NGT Installation 3" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/Ngt-Installation03.png" loading="lazy" />

Cliquez sur <code className="action">Confirm & Enter Password</code>. 

<img className="thumbnail" alt="NGT Installation 4" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/Ngt-Installation04.png" loading="lazy" />

Cliquez sur <code className="action">Skip and Mount</code>.

<img className="thumbnail" alt="NGT Installation 5" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/Ngt-Installation05.png" loading="lazy" />

Revenez dans la console de la machine virtuelle et faites un clic-droit sur le lecteur de CDROM contenant les NGT.

Choisissez <code className="action">Install Nutanix Guest Tools</code>.

<img className="thumbnail" alt="NGT Installation 6" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/Ngt-Installation06.png" loading="lazy" />

Une fois l'installation terminée, fermez l'assistant d'installation via le bouton <code className="action">Close</code>.

<img className="thumbnail" alt="NGT Installation 9" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/Ngt-Installation09.png" loading="lazy" />

L'installation d'une machine virtuelle sous Windows est alors entierement terminée.

### Migration d'une machine virtuelle

La migration d'une machine virtuelle consiste à déplacer une VM à chaud d'un nœud à l'autre d'un cluster. 

Si vous disposez de plusieurs clusters et des licences appropriées, vous pouvez également procéder à une migration d'une VM d'un cluster à l'autre. 

Cette documentation n'illustre que la migration d'une VM à l'intérieur d'un seul et même cluster.

Dans la gestion des machines virtuelles de Prism Central, cliquez sur <code className="action">WS2022N</code>.

<img className="thumbnail" alt="Migrate - VM01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/MigrateVM01.PNG" loading="lazy" />

Vérifiez sur quel nœud la VM fonctionne actuellement. Il est affiché à coté de **Host**.

<img className="thumbnail" alt="Migrate - VM02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/MigrateVM02.PNG" loading="lazy" />

Cliquez sur le bouton <code className="action">More</code> puis sur <code className="action">Migrate</code>.

<img className="thumbnail" alt="Migrate - VM03" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/MigrateVM03.PNG" loading="lazy" />

Choisissez un nœud de destination.

<img className="thumbnail" alt="Migrate - VM04" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/MigrateVM04.PNG" loading="lazy" />

Le nom du nouveau nœud apparaîtra en face de **Host** si la  migration s'est bien terminée.

<img className="thumbnail" alt="Migrate - VM05" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/06-virtual-machine-management/MigrateVM05.PNG" loading="lazy" />
