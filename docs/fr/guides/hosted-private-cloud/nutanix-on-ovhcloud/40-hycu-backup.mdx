## Objectif

HYCU for Nutanix est un logiciel de sauvegarde disponible pour Nutanix. 

**Apprenez à installer, configurer et utiliser HYCU sur un cluster Nutanix avec un stockage de type Object Storage fourni par OVHCloud**

:::warning
OVHcloud vous met à disposition des services dont la configuration, la gestion et la responsabilité vous incombent. Il vous appartient donc de ce fait d’en assurer le bon fonctionnement.

Ce guide a pour but de vous accompagner au mieux sur des tâches courantes. Néanmoins, nous vous recommandons de faire appel à l'équipe [Professional Services OVHcloud](https://www.ovhcloud.com/fr/professional-services/) ou à un [prestataire spécialisé](https://partner.ovhcloud.com/fr/directory/) si vous éprouvez des difficultés ou des doutes concernant l’administration, l’utilisation ou la mise en place d’un service sur un serveur.

:::


## Prérequis

- Une licence [HYCU for OVHcloud](https://www.ovhcloud.com/fr/storage-solutions/hycu/) valide dans votre compte OVHcloud (la première étape de ce guide vous détaille la procédure à suivre) ou une licence HYCU acquise depuis un fournisseur tiers.
- Disposer d'un cluster Nutanix on OVHcloud dans votre compte OVHcloud.
- Être connecté à votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr).
- Être connecté sur le cluster via Prism Central.
- Avoir un projet Public Cloud avec un bucket de stockage de type High Performance Object Storage ainsi qu'un utilisateur ayant les droits en lecture et écriture sur ce bucket. Vous trouverez plus d'informations sur la création d'un projet Public Cloud et sur l’utilisation du service High Performance Object Storage sur les pages suivantes :
    - [Création d'un projet Public Cloud](/guides/public-cloud/public-cloud-cross-functional/create-a-public-cloud-project/).
    - [Débuter avec Object Storage](/guides/storage-and-backup/object-storage/s3-getting-started-with-object-storage/).
    - [Object Storage - Gestion de l'immuabilité des objets avec Object Lock (WORM)](/guides/storage-and-backup/object-storage/s3-managing-object-lock/)
- 60 Go de stockage, 8 Go de mémoire et 8 cœurs sur votre Cluster Nutanix pour l'Instance/Appliance HYCU.

### Commander une licence HYCU for OVHcloud <a name="license-order"></a>

Nous vous proposons différents packs de licences selon le nombre de machines virtuelles (VM) utilisées par vos charges de travail Nutanix.

:::tip[Success]
Retrouvez plus d'informations sur notre page [HYCU for OVHcloud](https://www.ovhcloud.com/fr/storage-solutions/hycu/).

:::


:::info
**Vous avez déjà une licence HYCU ?**<br/>
Poursuivez la lecture de ce guide à l'étape « [Installer et configurer HYCU](#installation) ».

:::


Connectez-vous à [l'espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr) puis rendez-vous successivement dans <code className="action">Hosted Private Cloud</code> et <code className="action">Stockage et sauvegarde</code>.

Cliquez sur <code className="action">HYCU</code> puis sur <code className="action">Toutes mes licenses</code>.

Une fois votre commande effectuée, vous recevrez un e-mail de confirmation et votre souscription apparaîtra dans le tableau de bord <code className="action">Toutes mes licenses</code>.

Cliquez sur votre licence pour procéder à son activation.

### Installer et configurer HYCU <a name="installation"></a>

Connectez-vous à **Prism Central**.

Pour plus d'informations sur la connexion au cluster, reportez-vous à la section « [Aller plus loin](#gofurther) » de ce guide. 

Via le menu principal, cliquez sur <code className="action">Images</code> depuis le menu <code className="action">Compute & Storage</code>

<img className="thumbnail" alt="Add Image HYCU 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/00-addimagehycu01.png" loading="lazy" />

<img className="thumbnail" alt="Add Image HYCU 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/00-addimagehycu02.png" loading="lazy" />

Choisissez <code className="action">URL</code> comme type de source, saisissez l'URL `https://download.hycu.com/ec/v4.X.X/hycu-4.X.X-XXXX.qcow2` dans **Enter Image URL** et cliquez sur <code className="action">Upload file</code>. 

:::info
L'URL utilisée pour le téléchargement correspond à la dernière version disponible sur le site d'HYCU.

<img className="thumbnail" alt="Create HYCUVM 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/02-createhycuvm01.png" loading="lazy" />

- **&lt; GATEWAY >** : Passerelle locale de la machine virtuelle pour aller sur Internet.
- **&lt; DNS >** : DNS utilisé sur Internet.

```yaml
bootcmd:
- /opt/grizzly/bin/cloud_init_setup.sh hycubc < Adresse IP > < GATEWAY >  < DNS > "hycu.local,ntnx.local"
```

Copiez le contenu du script yaml et collez-le à l'emplacement réservé au-dessous de **Clear Script**. Cliquez ensuite sur <code className="action">Next</code>.

<img className="thumbnail" alt="Create HYCUVM 11" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/02-createhycuvm11.png" loading="lazy" />

<img className="thumbnail" alt="Create HYCUVM 12" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/02-createhycuvm12.png" loading="lazy" />

<img className="thumbnail" alt="Create HYCUVM 13" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/02-createhycuvm13.png" loading="lazy" />

Cliquez sur <code className="action">Power On</code> dans le menu `Actions`.

<img className="thumbnail" alt="Create HYCUVM 14" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/02-createhycuvm14.png" loading="lazy" />.

#### Configurer la redirection de l'URL HYCU vers le réseau public <a name="url-redirection"></a>

Dans cette section, nous allons configurer une redirection pour que vous puissiez configurer HYCU en utilisant l’interface web de l’extérieur de votre cluster.

Depuis votre espace client OVHcloud, sélectionnez <code className="action">Bare Metal Cloud</code> puis cliquez sur votre <code className="action">Load Balancer</code> dans la barre de menu à gauche.

Dans l'onglet <code className="action">Fermes de serveurs</code>, cliquez sur <code className="action">Ajouter une ferme de serveurs</code>.

<img className="thumbnail" alt="Configure Load Balancer 01" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/03a-configureloadbalancer01.png" loading="lazy" />

Nommez votre ferme de serveurs puis selectionnez <code className="action">TCP</code> et saisissez ces informations

- **Port** : `8443`
- **Datacenter** : `ALL`
- **Réseau privé** : `nutanix`

Cliquez sur <code className="action">Ajouter</code> pour valider la création de la ferme de serveurs.

<img className="thumbnail" alt="Configure Load Balancer 02" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/03a-configureloadbalancer02.png" loading="lazy" />

Cliquez sur <code className="action">Ajouter un serveur</code>

<img className="thumbnail" alt="Configure Load Balancer 03" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/03a-configureloadbalancer03.png" loading="lazy" />

Saisissez ces valeurs :

- **Name (optional)** : `VM-HYCU`
- **Adresse IPv4** : `addresseiphycu`
- **Port** : `8443`

Cliquez sur <code className="action">Ajouter</code> pour valider la création du cluster.

<img className="thumbnail" alt="Configure Load Balancer 04" src="/images/hosted-private-cloud/nutanix-on-ovhcloud/40-hycu-backup/03a-configureloadbalancer04.png" loading="lazy" />
