## Objectif

Avant de pouvoir déployer des services sur vos baies **OPCP**, il est nécessaire de disposer d’une instance installée et active.

**Ce guide détaille les étapes à suivre pour installer une instance OPCP à partir de l’interface Horizon**.

## Prérequis

- Disposer d'un service [OPCP](https://www.ovhcloud.com/fr/hosted-private-cloud/onprem-cloud-platform/) actif.
- Posséder un **compte utilisateur** avec les droits suffisants pour se connecter à Horizon sur l’offre OPCP.

## En pratique

### 1. Connexion à Horizon

Connectez-vous à l’interface **Horizon** de votre environnement OPCP.<br/><br/>
<img className="thumbnail" alt="horizon-interface" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/01-log-to-horizon-step01.png" loading="lazy" />

Une fois connecté, sélectionnez le **projet** dans lequel vous souhaitez installer votre instance.<br/><br/>
<img className="thumbnail" alt="horizon-select-project" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/01-log-to-horizon-step02.png" loading="lazy" />

### 2. Création d’un réseau privé

Avant de déployer votre instance, il est généralement nécessaire de créer un **réseau privé** afin qu’il soit accessible au sein de votre infrastructure locale.

Dans le menu de gauche, cliquez sur <code className="action">Network</code>, puis sur <code className="action">Networks</code>.<br/><br/>
<img className="thumbnail" alt="horizon-network-networks" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/02-create-network-step01.png" loading="lazy" />

Cliquez sur <code className="action">Create Network</code>.<br/><br/>
<img className="thumbnail" alt="horizon-network-networks" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/02-create-network-step02.png" loading="lazy" />

<Tabs>
  <Tab label="Network">
    <img className="thumbnail" alt="horizon-network-setup-network" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/02-create-network-setup-network.png" loading="lazy" />
    
    | Champ | Description |
    |--------|--------------|
    |**Network Name**|Saisissez un nom pour votre réseau.|
    |**Enable Admin State**|Laissez cette option cochée pour activer le réseau.|
    |**Shared**|Cochez cette case si vous souhaitez rendre le réseau disponible pour plusieurs projets.|
    |**Create Subnet**|Laissez cette option cochée pour créer un sous-réseau.|
    |**Availability Zone Hints**|Laissez la valeur par défaut.|
  </Tab>
  <Tab label="Subnet">
    <img className="thumbnail" alt="horizon-network-setup-subnet" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/02-create-network-setup-subnet.png" loading="lazy" />
    
    :::info
     Bien qu’il soit possible de créer un réseau sans sous-réseau, celui-ci ne pourra pas être attaché à une instance s'il n'a pas de sous-réseau.

    :::

    
    | Champ | Description |
    |--------|--------------|
    |**Subnet Name**|Entrez un nom pour votre sous-réseau.|
    |**Network Address**|Définissez une plage d’adresses privées, par exemple `192.168.100.0/24`.|
    |**IP Version**|Laissez la valeur par défaut **IPv4**.|
    |**Gateway IP**|Optionnel. Si non renseignée, une adresse sera sélectionnée automatiquement.|
    |**Disable Gateway**|Cochez cette case pour ne pas attribuer d’adresse passerelle.|
  </Tab>
  <Tab label="Subnet Details">
    <img className="thumbnail" alt="horizon-network-setup-subnet" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/02-create-network-setup-subnet-details.png" loading="lazy" />
    
    | Champ | Description |
    |--------|--------------|
    |**Enable DHCP** |Laissez activé si vous souhaitez que les adresses IP soient attribuées automatiquement.|
    |**Allocation Pools** |Optionnel. Permet de définir une plage d’adresses IP spécifique.|
    |**DNS Name Servers** |Optionnel. Permet de spécifier un ou plusieurs serveurs DNS.|
    |**Host Routes** |Optionnel. Permet d’ajouter des routes statiques.|
  </Tab>
</Tabs>


### 3. Création d’une instance

Dans le menu de gauche, cliquez sur <code className="action">Compute</code>, puis sur <code className="action">Instances</code>.<br/><br/>
<img className="thumbnail" alt="horizon-compute-instances" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/03-create-instance-horizon-step01.png" loading="lazy" />

Cliquez sur <code className="action">Launch Instance</code> pour lancer la création d’une nouvelle instance.<br/><br/>
<img className="thumbnail" alt="horizon-compute-instances-launch-instance" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/03-create-instance-horizon-step02.png" loading="lazy" />

#### Onglet : Details

<img className="thumbnail" alt="horizon-compute-instances-launch-instance-details" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/03-create-instance-horizon-details.png" loading="lazy" />

| Champ | Description |
|--------|--------------|
|**Instance Name**|Saisissez le nom de l'instance à créer.|
|**Description** |Optionnel. Ajoutez une description si nécessaire.|
|**Availability Zone** |Laissez la valeur par défaut **nova**.|
|**Count**|Indiquez le nombre d'instances à déployer.|

#### Onglet : Source

<img className="thumbnail" alt="horizon-compute-instances-launch-instance-source" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/03-create-instance-horizon-source.png" loading="lazy" />

| Champ | Description |
|--------|--------------|
|**Boot Source**|Sélectionnez la source de démarrage : *Image* ou *Instance Snapshot*.|
|**Image Name**|Choisissez l’image à utiliser (ex. : *Debian 12 BMPOD*).|

#### Onglet : Flavor

<img className="thumbnail" alt="horizon-compute-instances-launch-instance-flavor" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/03-create-instance-horizon-flavor.png" loading="lazy" />

Sélectionnez la **configuration matérielle** adaptée (vCPU, mémoire, stockage).

#### Onglet : Networks

<img className="thumbnail" alt="horizon-compute-instances-launch-instance-network" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/03-create-instance-horizon-networks.png" loading="lazy" />

Sélectionnez le **réseau privé** précédemment créé. Vous pouvez également attacher un **port réseau** existant depuis l’onglet *Network Ports*.

### 4. Gestion des paires de clés SSH

:::warning
Bien que la sélection d’une clé SSH ne soit pas obligatoire dans Horizon, elle est **indispensable pour se connecter à l'instance** une fois celui-ci créé.  

:::


<img className="thumbnail" alt="horizon-compute-instances-launch-instance-key-pairs" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/03-create-instance-horizon-key-pairs.png" loading="lazy" />

<Tabs>
  <Tab label="Créer une nouvelle paire de clés">
    Cliquez sur <code className="action">+ Create Key Pair</code> et renseignez les champs suivants :
    
    | Champ | Description |
    |--------|--------------|
    |**Key Pair Name**| Saisissez un nom pour la clé.|
    |**Key Type**| Sélectionnez **SSH Key**.|
    
    Cliquez sur <code className="action">Create Keypair</code>.  
    Copiez la clé privée avec **Copy Private Key to Clipboard**, puis cliquez sur <code className="action">Done</code>.<br/><br/>
    <img className="thumbnail" alt="horizon-compute-instances-launch-instance-key-pairs-create-step01" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/03-create-instance-horizon-key-pairs-create-step01.png" loading="lazy" />

La clé est désormais sélectionnée par défaut. Cliquez sur <code className="action">Launch Instance</code> pour démarrer la création de l'instance.<br/><br/>
    <img className="thumbnail" alt="horizon-compute-instances-launch-instance-key-pairs-create-step02" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/03-create-instance-horizon-key-pairs-create-step02.png" loading="lazy" />
  </Tab>
  <Tab label="Importer une clé existante">
    Cliquez sur <code className="action">Import Key Pair</code> et renseignez les champs suivants :
    
    | Champ | Description |
    |--------|--------------|
    |**Key Pair Name**|Nom de la clé.|
    |**Key Type**|Sélectionnez **SSH Key**.|
    |**Public Key**|Collez votre clé publique ou importez le fichier correspondant.|
    
    Cliquez sur <code className="action">Import Key Pair</code>.<br/><br/> 
    <img className="thumbnail" alt="horizon-compute-instances-launch-instance-key-pairs-import-step01" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/03-create-instance-horizon-key-pairs-import-step01.png" loading="lazy" />

La clé est désormais sélectionnée par défaut. Cliquez sur <code className="action">Launch Instance</code> pour démarrer la création de l'instance.<br/><br/>
    <img className="thumbnail" alt="horizon-compute-instances-launch-instance-key-pairs-import-step02" src="/images/hosted-private-cloud/opcp/how-to-setup-instance/03-create-instance-horizon-key-pairs-import-step02.png" loading="lazy" />
  </Tab>
</Tabs>
