## Objectif

Dans une solution NSX, un segment est un domaine de niveau 2 virtuel. Il peut être de deux types :

- **VLAN-backed segments** : la communication entre les hôtes et les machines virtuelles se fait au travers de VLANs et d'un switch de couche 2 du modèle OSI. Pour que ces segments puissent communiquer avec les éléments de NSX (Internet et les autres segments), il faut rajouter une interface sur les passerelles **Tier-1 Gateways** ou **Tier-0 Gateways**.
- **Overlay-backed segments** : la connexion se fait à l'aide d'une surcouche logicielle qui établit des tunnels entre les hôtes. Il est obligatoire de rajouter une adresse dans un sous-réseau qui servira pour le routage en dehors de ce segment. Ils doivent être connectés à une passerelle de type **Tier-1 Gateways** comme **ovh-T1-gw**.

Les segments sont liés à des zones de transports qui sont prédéfinies par OVHcloud. 

- **system-owned-vlan-transport-zone-for-rtep | VLAN** : zone prévue pour les réseaux étendues RTEP.
- **system-owned-vlan-transport-zone-for-evpn | VLAN** : zone prévue pour les VPN.
- **ovh-tz-overlay | VLAN** : zone pour les segments de type Overlay derrière les passerelles de type **Tier-1 Gateways**, comme **ovh-T1-gw**.
- **ovh-tz-public | VLAN** : zone connectée au réseau public sur un VLAN unique fourni par OVHcloud.
- **ovh-tz-vrack | VLAN** : zone reliée au vRack OVHcloud sur lequel il est possible de créer des segments avec un VLAN particulier.

**Découvrez la création et l'utilisation des segments dans l'interfaces NSX et vCenter.**

### Création d'un segment de type overlay dans l'interface NSX

Nous allons créer un segment *Overlay-backed segment* relié à **ovh-T1-gw** dans un sous réseau en 192.168.1.0/24 avec comme passerelle 192.168.1.254.

Dans l'interface NSX, allez dans l'onglet <code className="action">Networking</code>.

<img className="thumbnail" alt="01 Create Segment 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/01-create-segment01.png" loading="lazy" />

Cliquez à gauche sur <code className="action">Segments</code>.

<img className="thumbnail" alt="01 Create Segment 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/01-create-segment02.png" loading="lazy" />

Cliquez à droite sur <code className="action">ADD SEGMENT</code>.

<img className="thumbnail" alt="01 Create Segment 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/01-create-segment03.png" loading="lazy" />

Renseignez ces informations :

- **Name** : nom de votre segment.
- **Connected Gateway** : gateway prédefinie ovh-T1-gw | Tier1.
- **Transport Zone** : zone prédéfinie ovh-tz-overlay.
- **Subnet** : adresse de la passerelle du segment dans ce format 192.168.1.254/24.

Cliquez ensuite à droite sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="01 Create Segment 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/01-create-segment04.png" loading="lazy" />

Cliquez sur <code className="action">NO</code> à l'étape suivante.

<img className="thumbnail" alt="01 Create Segment 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/01-create-segment05.png" loading="lazy" />

Le nouveau segment apparait dans la liste.

<img className="thumbnail" alt="01 Create Segment 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/01-create-segment06.png" loading="lazy" />

Toujours dans l'onglet `Networking`, cliquez à gauche sur <code className="action">Network Topology</code> pour voir le nouveau segment et son emplacement dans le réseau. 

<img className="thumbnail" alt="02 Display Network Topology 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/02-display-network-topology-with-onesegment01.png" loading="lazy" />

### Connexion d'une machine virtuelle à un segment de type overlay.

Allez dans l'interface vCenter de votre cluster Hosted Private Cloud.

Faites un clic-droit sur la machine virtuelle et cliquez sur <code className="action">Modifier les paramètres</code>.

<img className="thumbnail" alt="03 Connect Network Card to Segment 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/03-connect-network-card-vm-to-segment01.png" loading="lazy" />

Allez dans la barre de défilement à droite de votre adaptateur réseau et choisissez <code className="action">Parcourir</code>.

<img className="thumbnail" alt="03 Connect Network Card to Segment 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/03-connect-network-card-vm-to-segment02.png" loading="lazy" />

Sélectionnez le <code className="action">réseau</code> qui porte le nom de votre segment. et cliquez sur <code className="action">OK</code>.

<img className="thumbnail" alt="03 Connect Network Card to Segment 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/03-connect-network-card-vm-to-segment03.png" loading="lazy" />

Cliquez sur <code className="action">OK</code>.

<img className="thumbnail" alt="03 Connect Network Card to Segment 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/03-connect-network-card-vm-to-segment04.png" loading="lazy" />

Maintenant que votre machine virtuelle est connectée au segment, revenez sur l'interface NSX.

Allez dans l'onglet <code className="action">Networking</code> et choisissez <code className="action">Network Topology</code>.

<img className="thumbnail" alt="04 display network topology with one segment and one vm 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/04-display-network-topology-with-onesegment-and-one-vm01.png" loading="lazy" />

La machine virtuelle associée au réseau apparait dans la topologie du réseau.

Aidez-vous de la première partie du guide pour créer un deuxième segment nommé `ov2-segment` avec le paramètre **192.168.2.254/24** afin d'avoir deux segments connectés à **ovh-T1-gw**.

<img className="thumbnail" alt="05 display four VM on two segment01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/05-display-four-vm-on-two-segment01.png" loading="lazy" />

Par la suite, depuis la console **vCenter**, mettez deux machines virtuelles sur le premier segment et deux autres sur le deuxième segment.

Revenez sur l'interface NSX dans <code className="action">Network Topology</code> pour faire apparaître la nouvelle configuration réseau.

<img className="thumbnail" alt="05 display four VM on two segment02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/05-display-four-vm-on-two-segment02.png" loading="lazy" />

Les deux segments sont reliés à la passerelle **ovh-T1-gw**, le routage entre les deux sous-réseaux est activé sans aucune restriction réseau par défaut.

### Création d'un segment sur un VLAN 

Depuis l'interface de NSX, cliquez sur l'onglet <code className="action">Networking</code> et cliquez sur <code className="action">Segments</code> à gauche dans la rubrique **Connectivity**. Cliquez ensuite sur <code className="action">ADD SEGMENT</code>.

<img className="thumbnail" alt="06 Add vlan segment 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/06-add-vlan-segment01.png" loading="lazy" />

Remplissez ces informations :

- **Name** : saisissez `vlan100-vrack-segment`.
- **Transport Zone** : sélectionnez `ovh-tz-vrack`.
- **VLAN** : tapez le nombre `100`.
- **Subnets** : saisissez l'adresse et le range de la passerelle sur ce segment `192.168.100.254/24`.

Cliquez sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="06 Add vlan segment 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/06-add-vlan-segment02.png" loading="lazy" />

Cliquez sur <code className="action">NO</code> à l'étape suivante.

<img className="thumbnail" alt="06 Add vlan segment 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/06-add-vlan-segment03.png" loading="lazy" />

### Connexion d'un segment de type VLAN à la passerelle ovh-T1-gw

Vous pouvez router le réseau venant d'un segment de type VLAN vers Internet et les autres segments en créant une interface sur la passerelle **ovh-T1-gw**. Lors de la création de l'interface, il faut utiliser la même adresse IP que celle indiquée dans le sous-réseau du segment.

Depuis l'interface NSX, allez dans l'onglet <code className="action">Networking</code> et cliquez sur <code className="action">Tier-1 Gateways</code> à gauche dans la rubrique **Connectivity**.

Cliquez ensuite sur les <code className="action">trois points de suspensions verticaux</code> et choisissez <code className="action">Edit</code> dans le menu.

<img className="thumbnail" alt="07 add interfaces to ovh-T1-gw with vlan 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/07-add-interface-on-ovh-t1-gw01.png" loading="lazy" />

Cliquez sur la <code className="action">Flèche vers le bas</code> à gauche de **SERVICE INTERFACES** et cliquez sur le bouton <code className="action">Set</code> qui vient de s'afficher à droite de **Service Interfaces**.

<img className="thumbnail" alt="07 add interfaces to ovh-T1-gw with vlan 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/07-add-interface-on-ovh-t1-gw02.png" loading="lazy" />

Cliquez sur <code className="action">ADD INTERFACE</code>.

<img className="thumbnail" alt="07 add interfaces to ovh-T1-gw with vlan 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/07-add-interface-on-ovh-t1-gw03.png" loading="lazy" />

Renseignez ces informations :

- **Name** : saisissez `vlan100-interface` comme nom de votre interface.
- **IP Address / Mask** : saisissez l'adresse IP de l'interface `192.168.100.254/24` qui doit correspondre à la passerelle.
- **Connected To(Segment)** : prenez le segment qui est sur le vlan 100 sur le vrack nommé `vlan100-vrack-segment`.

Cliquez ensuite sur <code className="action">SAVE</code> pour valider la création de l'interface sur **ovh-T1-gw**.

<img className="thumbnail" alt="07 add interfaces to ovh-T1-gw with vlan 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/07-add-interface-on-ovh-t1-gw04.png" loading="lazy" />

Cliquez sur <code className="action">CLOSE</code>

<img className="thumbnail" alt="07 add interfaces to ovh-T1-gw with vlan 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/07-add-interface-on-ovh-t1-gw05.png" loading="lazy" />

Le chiffre `1` à coté de **Service Interfaces** indique que l'interface est créée, cliquez sur <code className="action">CLOSE EDITING</code> pour finaliser la création de l'interface.

<img className="thumbnail" alt="07 add interfaces to ovh-T1-gw with vlan 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/07-add-interface-on-ovh-t1-gw06.png" loading="lazy" />

Vous pouvez maitenant vous connecter en dehors de ce segment par le biais de l'interface avec la passerelle 192.168.100.254/24.
