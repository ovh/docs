## Objectif

En quelques minutes, vous pouvez ajouter un nouvel hôte dans votre environnement OVHcloud.

**Découvrez comment ajouter des capacités de calculs à votre infrastructure.**

## Prérequis

- Être contact administrateur de l'infrastructure [Hosted Private Cloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/), afin de recevoir les identifiants de connexion.
- Avoir un identifiant utilisateur actif (créé dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr))

## En pratique

:::warning
Les ressources ajoutées à partir de vSphere sont facturées à l'heure. Si vous souhaitez passer à une facturation mensuelle, vous pouvez changer les paramètres dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr)).
Pour plus de détails, consultez notre [présentation de l’espace client Hosted Private Cloud OVHcloud](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/manager-ovh-private-cloud/).

:::


Dans l'interface vSphere, rendez-vous dans le tableau de bord <code className="action">Hôtes et clusters</code>.

<img className="thumbnail" alt="Menu" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-add-host/en01dash.png" loading="lazy" />

L'onglet <code className="action">Configurer</code> vous donne accès au plugin OVHcloud.<br/>
Dans le menu <code className="action">Ajout d'un host</code>, choisissez le type d'hôte qui vous convient et cliquez sur <code className="action">Next</code>.

<img className="thumbnail" alt="Choose" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-add-host/en02choose.png" loading="lazy" />

Verifiez votre commande et confirmez en cliquant sur <code className="action">Next</code>.

<img className="thumbnail" alt="Confirm" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-add-host/en03validate.png" loading="lazy" />

Votre commande est prise en compte. La progression de la livraison est visible avec une estimation de la disponibilité.

<img className="thumbnail" alt="Delivery" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-add-host/en04deliver.png" loading="lazy" />

Le nouvel hôte sera ensuite listé dans votre datacenter et prêt à l'usage.
