## Objectif

Vous pouvez créer une librairie de fichiers ISO à utiliser pour vos déploiements de systèmes et de logiciels dans votre infrastructure.

**Ce guide vous accompagne tout au long du processus de connexion d'une image ISO à une VM.**

## Prérequis

- Être contact administrateur de l'infrastructure [Hosted Private Cloud](https://www.ovhcloud.com/fr/hosted-private-cloud/vmware/), afin de recevoir les identifiants de connexion.
- Avoir un identifiant utilisateur actif (créé dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr))

## En pratique

### Création de la librairie

Dans l'interface vSphere, allez dans la section <code className="action">Stockage</code>.<br/>
Choisissez le Datastore qui abritera la librairie (préférez les espaces de stockage partagés aux stockage locaux afin d'éviter les problèmes d'accès).<br/>
Dans l'onglet <code className="action">Fichiers</code>, cliquez sur <code className="action">Nouveau Dossier</code>.

<img className="thumbnail" alt="FOLDER" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en01newfolder.png" loading="lazy" />

Nommez votre dossier (dans notre exemple : ISOs) puis selectionnez-le et cliquez sur <code className="action">Télécharger des fichiers</code>.

<img className="thumbnail" alt="UPLOAD" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en02upload.png" loading="lazy" />

Naviguez jusqu'aux fichiers ISO que vous souhaitez uploader et cliquez sur <code className="action">Ouvrir</code>.

<img className="thumbnail" alt="BROWSE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en03browse.png" loading="lazy" />

Votre librairie est prête. Vous pouvez ajouter des images ISO selon vos besoins et dans la limite de l'espace de stockage disponible.

<img className="thumbnail" alt="LIBRARY" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en04library.png" loading="lazy" />

### Connecter une image à une VM

Dans l'interface vSphere, allez dans la section <code className="action">Hôtes & clusters</code>.<br/>
Faites un clic droit sur la VM qui a besoin de l'image ISO attachée puis cliquez sur <code className="action">Modifier les paramètres</code>.<br/>

<img className="thumbnail" alt="EDIT" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en05edit.png" loading="lazy" />

Changez le paramètre du lecteur CD/DVD en "Fichier ISO banque de données".

<img className="thumbnail" alt="ISO" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en06dataiso.png" loading="lazy" />

Dans la fenêtre de navigation qui apparait, allez dans la librairie créée précédement et selectionnez l'image à utiliser.<br/>
Cliquez sur <code className="action">OK</code>.

<img className="thumbnail" alt="SELECT" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en07choose.png" loading="lazy" />

De retour dans la fenêtre de paramétrage, assurez-vous que l'option "Connecter" est cochée avant de cliquer <code className="action">OK</code>.

<img className="thumbnail" alt="CONNECT" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en08connect.png" loading="lazy" />

L'image est désormais connectée et disponible pour votre VM comme si c'était un media physique directement attaché.
