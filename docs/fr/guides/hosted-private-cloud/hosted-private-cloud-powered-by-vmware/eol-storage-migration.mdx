Néanmoins, nous vous recommandons de faire appel à un [prestataire spécialisé](https://partner.ovhcloud.com/fr/directory/) si vous éprouvez des difficultés ou des doutes concernant l’administration, l’utilisation ou la mise en place d’un service sur un serveur.

## Objectif

Certains stockages ne seront plus disponibles à la fin Mars 2023 car ils ne seront plus maintenus, comme indiqué dans notre guide sur le [cycle de vie du Hosted Private Cloud powered by VMware](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/lifecycle-policy#datastores-stockage/).

**Découvrez les étapes de migration de vos données vers un stockage plus récent et comment désactiver votre stockage obsolète.** 

## Prérequis

- Être contact administrateur de l'infrastructure [Hosted Private Cloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/), afin de recevoir les identifiants de connexion.
- Avoir un identifiant actif dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr)
- Avoir un identifiant actif dans vSphere.

## En pratique

### Ajout d'un stockage

Les nouvelles gammes de stockage vous permettent de bénéficier de disques full-SSD (comparativement à des disques SSD-accelerated sur les précédentes gammes de stockage), de cartes-réseau 2x2x25Gbps (comparativement à des cartes-réseau 2x10Gbps sur les précédentes gammes de stockage), d'une meilleure disponibilité et résilience. 

Consultez notre page [Datastore NFS](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/datastores-nfs/) pour obtenir plus d'informations.

Si vous n'avez pas encore souscrit à une offre plus récente, Utilisez [ce guide](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-add-storage/) pour ajouter un stockage plus important.

### Migration de vos machines virtuelles et des modèles de machines virtuelles

Dans votre interface vCenter, vérifiez les machines virtuelles qui se trouvent sur chacun de vos datastores obsolètes.

Cliquez sur l'icône de <code className="action">stockage</code>, choisissez à gauche votre Datastore dans <code className="action">Shared Storage</code>. Cliquez sur l'onglet <code className="action">VM</code> et restez sur <code className="action">Machines virtuelles</code> pour faire apparaître les machines virtuelles qui se trouvent sur ce stockage obsolète.

<img className="thumbnail" alt="01 check existing VM on datastore 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/01-check-existing-vm-on-datastore01.png" loading="lazy" />

Faites un clic-droit sur chacune des machines virtuelles qui se trouvent sur ce datastore, choisissez <code className="action">Migrer</code> et aidez-vous du guide « [VMware Storage vMotion](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion#finaliser-le-vmotion/) » pour effectuer la migration vers un datastore plus récent.

<img className="thumbnail" alt="01 check existing VM on datastore 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/01-check-existing-vm-on-datastore02.png" loading="lazy" />

Lorsque vous n'aurez plus de machines virtuelles dans l'onglet, rendez-vous sur <code className="action">Modèle de VM dans des dossiers</code> pour afficher les modèles enregistrés sur votre *datastore*.

<img className="thumbnail" alt="02 unregister and move template 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/02-unregister-and-move-template01.png" loading="lazy" />

Faites un clic-droit sur chacun des modèles enregistrés dans votre *datastore* et cliquez sur <code className="action">Supprimer de l'inventaire</code>.

:::warning
Le modèle est supprimé de l'inventaire mais se trouve toujours dans le *datastore*. Vous pouvez le récupérer pour le remettre sur un autre *datastore* ou le supprimer si vous n'en avez plus besoin.

:::


<img className="thumbnail" alt="02 unregister and move template 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/02-unregister-and-move-template02.png" loading="lazy" />

La liste des modèles est vide, vous pouvez maintenant déplacer vos modèles sur un autre datastore.

<img className="thumbnail" alt="02 unregister and move template 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/02-unregister-and-move-template03.png" loading="lazy" />

Allez sur l'onglet <code className="action">Fichiers</code>, positionnez-vous sur un dossier d'un modèle et cliquez sur <code className="action">Déplacez vers</code>.

<img className="thumbnail" alt="02 unregister and move template 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/02-unregister-and-move-template04.png" loading="lazy" />

Choisissez un Datastore et cliquez sur <code className="action">OK</code>.

<img className="thumbnail" alt="02 unregister and move template 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/02-unregister-and-move-template05.png" loading="lazy" />

Attendez que la tâche soit terminée.

<img className="thumbnail" alt="02 unregister and move template 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/02-unregister-and-move-template06.png" loading="lazy" />

Choisissez le Datastore de destination du modèle à gauche, allez dans le dossier du modèle, sélectionnez le fichier du modèle et cliquez sur <code className="action">Enregistrer une VM</code>.

<img className="thumbnail" alt="03 register template 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/03-register-template01.png" loading="lazy" />

Cliquez sur <code className="action">NEXT</code>.

<img className="thumbnail" alt="03 register template 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/03-register-template02.png" loading="lazy" />

Cliquez à nouveau sur <code className="action">NEXT</code>.

<img className="thumbnail" alt="03 register template 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/03-register-template03.png" loading="lazy" />

Cliquez sur <code className="action">FINISH</code>.

<img className="thumbnail" alt="03 register template 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/03-register-template04.png" loading="lazy" />

Allez dans l'onglet <code className="action">VM & modèles</code>. pour faire apparaître votre modèle.

<img className="thumbnail" alt="03 register template 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/eol-storage-migration/03-register-template05.png" loading="lazy" />

### Suppression du stockage de votre cluster VMware

Dès que vous n'aurez plus de données sur votre stockage, il sera alors possible de supprimer votre *datastore*.

Aidez-vous du guide « [Supprimer un datastore](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/delete-datastore/) » pour supprimer votre stockage obsolète.

:::warning
Après avoir supprimé votre *Datastore*, il vous faudra arrêter la souscription à ce service depuis votre espace client OVHcloud.

:::
