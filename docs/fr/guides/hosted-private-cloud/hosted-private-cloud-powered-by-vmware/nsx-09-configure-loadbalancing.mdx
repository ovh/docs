## Objectif

NSX permet l'équilibrage de charge (*Load Balancing*) sur une couche de niveau 4 (TCP ou UDP) ou de Niveau 7 (HTTP ou HTTPS).

**Découvrez comment mettre en place le Load Balancing dans NSX avec des serveurs web NGINX.**

:::warning
OVHcloud vous met à disposition des services dont la configuration, la gestion et la responsabilité vous incombent. Il vous appartient donc de ce fait d’en assurer le bon fonctionnement.

Ce guide a pour but de vous accompagner au mieux sur des tâches courantes. Néanmoins, nous vous recommandons de faire appel à un [prestataire spécialisé](https://partner.ovhcloud.com/fr/) si vous éprouvez des difficultés ou des doutes concernant l’administration, l’utilisation ou la mise en place d’un service sur un serveur.

:::


## Prérequis

- Être contact administrateur de l'infrastructure [VMware on OVHcloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/), celui-ci recevant les identifiants de connexion.
- Avoir un identifiant utilisateur actif avec les droits spécifiques pour NSX (créé dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr))
- Avoir **NSX** déployé avec deux segments configurés dans votre configuration NSX. Vous pouvez vous aider de notre guide sur la [gestion des segments dans NSX](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/).
- Avoir deux machines virtuelles avec le service NGINX activé en HTTP sur un segment.

## En pratique

Nous allons :

- activer le Load Balancing sur la passerelle **ovh-T1-gw** ;
- créer un pool de serveurs à partir de deux machines virtuelles qui utilisent un serveur web en HTTP actif sur le port 80 ;
- ajouter un serveur virtuel dans la configuration du Load Balancer qui contient notre pool de serveurs ;
- définir une règle de NAT pour faire une redirection vers le serveur virtuel.

### Création du marqueur (tag) sur les deux machines virtuelles.

Pour simplifier l'administration du Load Balancer, nous allons utiliser un marqueur (tag) sur les deux machines virtuelles du futur pool de serveurs.

Dans l'interface NSX, allez dans l'onglet <code className="action">Inventory</code> et cliquez sur <code className="action">Virtual Machines</code> à gauche.  

Cliquez ensuite sur les <code className="action">trois points verticaux</code> à gauche de la première machine virtuelle et choisissez <code className="action">Edit</code> dans le menu.

<img className="thumbnail" alt="01 Add tag to VMs 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/01-add-tag-to-two-vm01.png" loading="lazy" />

Remplacez **Tag** par <code className="action">loadbl</code> puis cliquez sur <code className="action">Add Item(s) loadbl</code> en dessous.

<img className="thumbnail" alt="01 Add tag to VMs 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/01-add-tag-to-two-vm02.png" loading="lazy" />

Remplacez **Scope** par <code className="action">nginx</code>, puis cliquez sur <code className="action">Add Item(s) nginx</code> en dessous.

<img className="thumbnail" alt="01 Add tag to VMs 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/01-add-tag-to-two-vm03.png" loading="lazy" />

Cliquez sur le signe <code className="action">+</code> à coté de votre marqueur pour le rajouter à votre machine virtuelle.

<img className="thumbnail" alt="01 Add tag to VMs 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/01-add-tag-to-two-vm04.png" loading="lazy" />

Le marqueur apparaît, cliquez sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="01 Add tag to VMs 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/01-add-tag-to-two-vm05.png" loading="lazy" />

Cliquez sur les <code className="action">trois points verticaux</code> à gauche de la deuxième machine virtuelle et choisissez <code className="action">Edit</code> dans le menu.

<img className="thumbnail" alt="01 Add tag to VMs 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/01-add-tag-to-two-vm06.png" loading="lazy" />

Remplacez **Tag** par <code className="action">load</code> et sélectionnez le marqueur <code className="action">Tag: loadbl Scope: nginx</code> qui vient de s'afficher en dessous.

<img className="thumbnail" alt="01 Add tag to VMs 07" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/01-add-tag-to-two-vm07.png" loading="lazy" />

Cliquez sur le signe <code className="action">+</code> à coté de votre marqueur pour le rajouter à votre deuxième machine virtuelle.

<img className="thumbnail" alt="01 Add tag to VM 08" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/01-add-tag-to-two-vm08.png" loading="lazy" />

Cliquez sur <code className="action">SAVE</code> pour ajouter le marqueur à votre machine virtuelle.

<img className="thumbnail" alt="03 ADD GROUP 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/03-add-group04.png" loading="lazy" />

### Activation du Load Balancer

Allez dans l'onglet <code className="action">Networking</code> et cliquez sur <code className="action">Load Balancing</code> dans la rubrique **Network Services** à gauche.  

Positionnez-vous ensuite sur l'onglet <code className="action">Load Balancers</code> et cliquez sur <code className="action">ADD LOAD BALANCER</code>.

<img className="thumbnail" alt="04 Activate Load Balancer 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/04-activate-loadbalancing01.png" loading="lazy" />

Saisissez <code className="action">loadbalancer-on-t1</code> en dessous de **Name**, sélectionnez sur <code className="action">ovh-T1-gw</code> sous **Attachment** et cliquez sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="04 Activate Load Balancer 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/04-activate-loadbalancing02.png" loading="lazy" />

Cliquez sur <code className="action">NO</code>.

<img className="thumbnail" alt="04 Activate Load Balancer 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/04-activate-loadbalancing03.png" loading="lazy" />

Le Load balancer est créé et actif sur la passerelle **ovh-T1-gw**.

<img className="thumbnail" alt="04 Activate Load Balancer 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/04-activate-loadbalancing04.png" loading="lazy" />

<img className="thumbnail" alt="05 Add server pool 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/05-add-server-pool01.png" loading="lazy" />

Saisissez <code className="action">sp-nginx</code> en dessous de **Name** et cliquez sur <code className="action">Select Members</code> sous **Members/Group**.

<img className="thumbnail" alt="05 Add server pool 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/05-add-server-pool02.png" loading="lazy" />

Cliquez sur <code className="action">Select a group</code> et choisissez le groupe <code className="action">nginx-servers</code> que vous avez créé, puis cliquez sur <code className="action">APPLY</code>.

<img className="thumbnail" alt="05 Add server pool 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/05-add-server-pool03.png" loading="lazy" />

Votre pool de serveur est créé avec vos deux machines virtuelles membres du groupe.

<img className="thumbnail" alt="05 Add server pool 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/05-add-server-pool05.png" loading="lazy" />

### Création du serveur virtuel

Allez sur l'onglet <code className="action">Virtual Servers</code> et cliquez sur <code className="action">ADD VIRTUAL SERVER</code>.

<img className="thumbnail" alt="06 Add virtual Server 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/06-add-virtual-server01.png" loading="lazy" />

Sélectionnez <code className="action">L4 TCP</code>.

<img className="thumbnail" alt="06 Add virtual Server 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/06-add-virtual-server02.png" loading="lazy" />

Renseignez les informations suivantes :

- **Name** : nom de votre virtual server `vs-nginx`.
- **IP Address**: adresse IP en frontal de votre serveur virtuel sur le même réseau que vos machines virtuelles NGINX `192.168.102.3`.
- **Port** : Port `80`.
- **Load Balancer**: votre load balancer `loadbalancer-on-t1`.
- **Server Pool**: votre pool de serveur `sp-nginx`.

Cliquez ensuite sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="06 Add virtual Server 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/06-add-virtual-server03.png" loading="lazy" />

Votre serveur virtuel est actif si vous vous connectez depuis une machine qui utilise un segment sur une passerelle de type **Tier-1 Gateways** avec cette URL `http://192.168.102.3`. Le Load Balancer se connectera à l'une des deux machines virtuelles configurées dans votre groupe.

### Ajout de la règle de NAT

Allez sur <code className="action">NAT</code> dans la rubrique **Network Services** à gauche et cliquez sur <code className="action">ADD NAT RULE</code>.

<img className="thumbnail" alt="07 ADD DNAT TO VIRTUAL SERVER 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/07-add-dnat-to-virtual-server01.png" loading="lazy" />

Saisissez <code className="action">to-lb-virtual-server</code> dans le champ **Name** de votre règle et renseignez les options suivantes :

- **Action** : <code className="action">DNAT</code>.
- **Destination IP** : adresse IP virtuelle de votre T0, telle que `198.51.100.1`.
- **Translated IP** : adresse IP de votre serveur virtuel, telle que `192.168.102.3`.
- **Service PORT** : choisissez le port prédéfini <code className="action">HTTP| 80</code>.

Cliquez ensuite sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="07 ADD DNAT TO VIRTUAL SERVER 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/07-add-dnat-to-virtual-server02.png" loading="lazy" />

Votre règle est désormais active. Si vous cliquez sur `http://adresse-ip-virtuelle-t0`, vous serez connecté à votre serveur virtuel qui redirigera le flux sur l'un des serveurs de votre groupe.

<img className="thumbnail" alt="07 ADD DNAT TO VIRTUAL SERVER 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-09-configure-loadbalancing/07-add-dnat-to-virtual-server03.png" loading="lazy" />
