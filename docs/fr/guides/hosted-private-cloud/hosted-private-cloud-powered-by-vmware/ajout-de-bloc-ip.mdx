## Objectif

Un bloc IP peut vous servir à rendre vos services accessibles sur Internet. 

**Ce guide explique comment commander, ajouter et migrer un bloc IP associé à votre Hosted Private Cloud.**

## Prérequis

- Être contact administrateur de l'infrastructure [Hosted Private Cloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/), pour recevoir des identifiants de connexion.
- Avoir un identifiant utilisateur actif (créé dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr))

## En pratique

### Commander un bloc IP

Pour commander un bloc IP supplémentaire pour votre **Hosted Private Cloud** , dirigez-vous sur votre espace client OVHcloud. Dans la section `Serveur`, cliquez sur la rubrique `IP` dans la colonne de gauche puis cliquez sur <code className="action">Commander des IP additionnelles</code>. Sélectionnez ensuite votre **Private Cloud** dans le menu déroulant avant de passer à l'étape suivante.

Plusieurs champs seront à remplir pour la création de votre bloc IP

- Taille du Bloc IP (de /28 à /24)

:::info
Pour rappel, voici un tableau récapitulant le nombres d'IPs présentes dans un bloc, et le nombres d'IP utilisables.

:::


|Taille du bloc|IP dans le bloc|IP utilisables chez OVHcloud|
|:---:|:---:|:---:|
|28|16|11|
|27|32|27|
|26|64|59|
|25|128|123|
|24|256|251|

:::info
N'hésitez pas à consulter notre guide sur le [plugin OVHcloud Network](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/plugin-ovh-network/) afin de savoir quelles sont les IPs réservées de votre bloc ainsi que leur utilisation.

:::


- Pays du bloc IP, important dans certains cas pour le référencement de vos services (un site à affluence française aura un meilleur référencement en France si l'IP est française également)
- Nom du réseau (Information visible dans le whois du bloc ip).
- Nombre de clients estimés (Combient de clients finaux seront hébérgés sur ces IPs).
- Description du réseau (Information visible dans le whois du bloc ip).
- Usage (Information sur l'utilisation (Web, SSL, Cloud...)).

:::tip[Success]
Vous devrez vous acquitter des frais d'activation de votre bloc IP avant livraison.

:::


Après avoir confirmé la dernière étape, vous obtenez le bon de commande de votre bloc IP. Si celui-ci est conforme à votre souhait, il vous suffit de le payer avec les moyens de paiement proposés en bas de page afin que celui-ci soit livré.

### Migrer un bloc IP entre deux Hosted Private Cloud

<iframe className="video" width="560" height="315" src="https://www.youtube-nocookie.com/embed/Gemao3Fd7rI" frameBorder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowFullScreen={true}></iframe>

La migration d'un bloc d'IP nécessite de déplacer manuellement les blocs via l'APIv6 OVHcloud.

Utilisez l'appel API suivant :

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/move"} />

Les champs doivent être complétés ainsi :

- ip : bloc IP avec le /mask
- nexthop « newPrimaryIp » (sensible a la casse)
- to : Hosted Private Cloud de destination sous la forme pcc-XXX-XXX-XXX-XXX

<img className="thumbnail" alt="champ nexthop" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ajout-de-bloc-ip/move-api.png" loading="lazy" />

Le résultat sera sous cette forme :

<img className="thumbnail" alt="champ nexthop" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ajout-de-bloc-ip/api-result.png" loading="lazy" />

Si, par la suite, vous devez détacher le bloc IP, vous pouvez utiliser cet appel API pour déplacer l'IP dans le parking des IPS :

<Api version="v1" section="/ip" method="POST" route={"/ip/\{ip\}/park"} />


:::warning
Cet appel coupe le réseau sur les VMs qui utilisent les IPs en question.

:::


Vous pourrez suivre le déplacement du bloc IP depuis votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr) dans la partie <code className="action">Hosted Private Cloud</code> puis <code className="action">Private Cloud</code>. Cliquez sur votre service Hosted Private Cloud puis sur l'onglet <code className="action">Operations</code>.

La référence de l'opération est « removeIpRipeBlock ».

<img className="thumbnail" alt="operations manager" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ajout-de-bloc-ip/operations.png" loading="lazy" />

L'IP apparaîtra ensuite dans le <code className="action">Parking des IPs</code>.

<img className="thumbnail" alt="IP parking" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ajout-de-bloc-ip/ip-parking.png" loading="lazy" />
