## Objectif

Le **Storage vMotion** permet de modifier l'emplacement de stockage des fichiers de la machine virtuelle et cela en conservant la machine virtuelle sous tension. Il est possible de déplacer la machine virtuelle complètement ou disque par disque.

**Ce guide montre comment réaliser cette opération.**

## En pratique

### Déplacer le disque d'une machine virtuelle

Pour déplacer les fichiers d'une machine virtuelle vers un autre datastore, il vous suffit de faire un clic droit sur la machine virtuelle allumée puis de sélectionner le menu `Migrer...`.

![déplacer disque](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion/VmotionStorage1.png)

### Choix du type de vMotion

Le menu propose plusieurs options de **vMotion**. Dans notre exemple, nous désirons uniquement migrer la machine virtuelle sur une autre banque de données. Il faut donc sélectionner « Modifier uniquement le stockage ».

L'option « Modifier uniquement la ressource de calcul » permet de migrer la machine virtuelle sur un autre hôte.  

Cette opération appelé **vMotion** est décrit dans [ce guide](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vmotion-new).

![choix de vMotion](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion/VmotionStorage2.png)

### Choix du datastore

Choisissez vers quel stockage migrer les données.

Il est également possible de modifier la politique de stockage lors de cette opération.

Ainsi, vous pouvez appliquer les politiques de stockage créées si vous disposez d'un [stockage vSAN](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan) ou de l'option [VMencryption](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/hosted-private-cloud-powered-by-vmware-vm-encrypt).

![choix datastore](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion/VmotionStorage3.png)

Dans le cas ou vous avez plusieurs disques virtuels sur la même machine, il est possible de ne migrer qu'un seul disque de la VM en utilisant le bouton `Advanced`.

Vous retrouverez cette vue :

![datastore vMotion](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion/VmotionStorage6.png)

### Finaliser le vMotion

Cliquez sur `Terminer` pour lancer la procédure de migration.

![finaliser le vMotion](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion/VmotionStorage4.png)

### Suivi du vMotion

Dans les tâches récentes, vous pourrez suivre l'état de la migration. Celle-ci prend plus ou moins de temps selon la taille de la VM, les accès IO et la bande passante utilisée.

![suivi de vMotion](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-storage-vmotion/VmotionStorage5.png)
