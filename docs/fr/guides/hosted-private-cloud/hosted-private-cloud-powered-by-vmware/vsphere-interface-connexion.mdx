## Objectif

**Ce guide a pour objectif de vous montrer comment vous connecter à votre interface Web vSphere managée depuis l'espace client HPC VMware on OVHcloud.**

## Prérequis

- Être administrateur de l'infrastructure [Hosted Private Cloud - vSphere managé](https://www.ovhcloud.com/fr/hosted-private-cloud/vmware/).
- Avoir ajouté des adresses IP dans la section `Sécurité` de votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr). Pour plus d'informations, consultez notre guide « [Autoriser des IP à se connecter au vCenter](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/autoriser-des-ip-a-se-connecter-au-vcenter/) ».

Pour utiliser IAM, vous devez activer la fonctionnalité afin de déléguer la gestion des droits avec un rôle. Veuillez lire les guides :

- Guide 1 : [IAM pour VMware on OVHcloud - Présentation et FAQ](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-iam-getting-started/)
- Guide 2 : [IAM pour VMware on OVHcloud - Comment activer IAM](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-iam-activation/)
- Guide 3 : [IAM pour VMware on OVHcloud - Comment créer un rôle vSphere IAM](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-iam-role/)

## En pratique

Pour se connecter à la console web vSphere managée, vous avez besoin d'identifiants de connexion OVHcloud. Il peut s'agir d'un utilisateur vSphere (avec un utilisateur local), ou d'un rôle vSphere (avec IAM).

### Étape 1 - Gestion des utilisateurs avec vSphere et OVHcloud

#### Via l'espace client OVHcloud

Vous pouvez gérer vos identifiants de connexion depuis l'espace client OVHcloud de votre produit VMware managé on OVHcloud.

Connectez-vous à votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr) et cliquez sur l'onglet <code className="action">Hosted Private Cloud</code>

Cliquez sur la rubrique <code className="action">Managed VMware vSphere </code>, sélectionnez votre infrastructure puis rendez-vous dans l'onglet <code className="action">Utilisateurs</code>.

<img className="thumbnail" alt="Connexion à l'interface vSphere HTML5" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vsphere-interface-connexion/managed_vsphere_all.png" loading="lazy" />

Pour lister vos environnements VMware, cliquez sur <code className="action">Tous mes services</code>.

Pour accéder à la section <code className="action">Gérer les droits des utilisateurs dans le client vSphere</code>, cliquez sur la section <code className="action">Utilisateur</code>.

Pour créer ou modifier un utilisateur, cliquez sur <code className="action">Créer un utilisateur</code> ou <code className="action">Modifier</code> un utilisateur.

<img className="thumbnail" alt="Connexion à l'interface vSphere HTML5" src="/images/assets/screens/control-panel/product-selection/hosted-private-cloud/vmware/vmware-users.png" loading="lazy" />

En cliquant sur le bouton <code className="action">...</code> à droite d'un utilisateur, vous pouvez modifier les utilisateurs ou les rôles IAM, modifier les droits par DC, changer un mot de passe ou supprimer les utilisateurs.

<img className="thumbnail" alt="Connexion à l'interface vSphere HTML5" src="/images/assets/screens/control-panel/product-selection/hosted-private-cloud/vmware/vmware-user-modification.png" loading="lazy" />

#### Via l'API OVHcloud

La gestion des utilisateurs est possible depuis l'API OVHcloud au sein de Hosted Private Cloud.

:::info
Si vous n'êtes pas familier avec l'utilisation de l'API OVHcloud, consultez notre guide « [Premiers pas avec les API OVHcloud](/guides/manage-and-operate/api/first-steps/)».

:::


Voici quelques exemples d'appels API :

- Créer un utilisateur :

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/user"} />


> **Paramètres** :
> 
> - `serviceName` : votre service sous la forme pcc-XX-XX-XX-XX.
> - `name` : le nom de votre utilisateur sous la forme ci-dessous.
> 

**Exemple** :

```shell
{
"name": "User name"
}
```

- Changer le mot de passe de votre utilisateur :

<Api version="v1" section="/dedicatedCloud" method="POST" route={"/dedicatedCloud/\{serviceName\}/user/\{userId\}/changePassword"} />


> **Paramètres** :
>
> - `serviceName` : votre service sous la forme pcc-XX-XX-XX-XX.
> - `userId` : l' ID de votre utilisateur sous la forme XXXXX.
>

**Exemple** :

```shell
{
"password": "XXX"
}
```
