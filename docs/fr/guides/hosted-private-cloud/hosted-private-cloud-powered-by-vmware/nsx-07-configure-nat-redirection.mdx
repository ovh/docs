## Prérequis

- Être contact administrateur de l'infrastructure [VMware on OVHcloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/), celui-ci recevant les identifiants de connexion.
- Avoir un identifiant utilisateur actif avec les droits spécifiques pour NSX (créé dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr))
- Avoir **NSX** déployé avec deux segments configurés dans votre configuration NSX. Consultez notre guide sur la [gestion des segments dans NSX](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/) pour plus d'informations.
- Avoir une machine virtuelle sous Linux avec OpenSSH activé sur le port 22.

## En pratique

Lors du déploiement de votre solution NSX, une règle de SNAT est automatiquement créée par OVHcloud pour pouvoir sortir sur Internet depuis vos segments.

Nous allons rajouter une règle de redirection (DNAT) depuis l'adresse IP virtuelle publique sur le port 2222 en TCP vers une machine virtuelle sous LINUX sur le port 22 en TCP. Dans notre exemple, nous allons utiliser des adresses IP fictives.

Depuis l'interface NSX, allez sur l'onglet <code className="action">Networking</code>, sélectionnez <code className="action">NAT</code> dans la rubrique **Network Services**. Sélectionnez <code className="action">ovh-T0-gw | Tier-0</code> à droite de **Gateway** et cliquez sur <code className="action">ADD NAT RULE</code>.

<img className="thumbnail" alt="01 Create DNAT rule 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules01.png" loading="lazy" />

Renseignez ces informations :

- **Action** : sélectionnez <code className="action">DNAT</code>.
- **Source IP** : saisissez l'adresse IP ou l'étendue des adresses qui pourront utiliser cette redirection.
- **Destination IP** : sdresse IP virtuelle publique de NSX.
- **Destination PORT** : port d'écoute sur l'adresse publique, tel que `2222`.
- **Translated IP** : adresse IP de la machine virtuelle sur laquelle la redirection est faite.

Cliquez ensuite sur les <code className="action">trois points verticaux</code> à droite de **Select Services**.

<img className="thumbnail" alt="01 Create DNAT rule 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules02.png" loading="lazy" />

Saisissez <code className="action">SSH22</code> sous la colonne **Name** et cliquez sur <code className="action">Set</code> sous la colonne **Service Entry**.

<img className="thumbnail" alt="01 Create DNAT rule 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules03.png" loading="lazy" />

Cliquez sur <code className="action">ADD SERVICE ENTRY</code>.

<img className="thumbnail" alt="01 Create DNAT rule 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules04.png" loading="lazy" />

Renseignez ces valeurs :

- **Name** : saisissez `SSH22`.
- **Service Type** : sélectionnez <code className="action">TCP</code>.
- **Source Ports** : écrivez le nombre `22`.

Cliquez ensuite sur <code className="action">APPLY</code>.

<img className="thumbnail" alt="01 Create DNAT rule 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules05.png" loading="lazy" />

Cliquez sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="01 Create DNAT rule 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules06.png" loading="lazy" />

Cliquez à nouveau sur <code className="action">SAVE</code> pour valider la création de la règle de redirection.

<img className="thumbnail" alt="01 Create DNAT rule 07" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules07.png" loading="lazy" />

La règle est créée et est active. 

<img className="thumbnail" alt="01 Create DNAT rule 08" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-07-configure-nat-redirection/01-create-dnat-rules08.png" loading="lazy" />
