## Objectif

La fonctionnalité **Fault Tolerance** (FT) de VMware vSphere permet de protéger une machine virtuelle des défaillances matérielles en clonant la machine sur deux hôtes distincts.

<img className="thumbnail" alt="Fault Tolerance" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-fault-tolerance/FT10v2.gif" loading="lazy" />

**Découvrez comment utiliser la fonctionnalité Fault Tolerance sur votre machine virtuelle**

## Prérequis

- Activer vSphere HA.
- Réservation de ressource égale à 100 % de la mémoire.
- VMware Tools installés.
- Processeurs de même génération.
- 4 vCPUs maximum.

## En pratique 

Pour activer l'option **Fault Tolerance**, faites un clic droit sur une machine virtuelle, puis cliquez successivement sur `Fault Tolerance` et `Activer Fault Tolerance`.

<img className="thumbnail" alt="Fault Tolerance" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-fault-tolerance/FT.png" loading="lazy" />

Une fenêtre de configuration s'ouvrira, vous invitant à définir vos choix pour la machine virtuelle secondaire.

La banque de données :

<img className="thumbnail" alt="Fault Tolerance" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-fault-tolerance/FT1.png" loading="lazy" />

L'hôte : 

<img className="thumbnail" alt="Fault Tolerance" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-fault-tolerance/FT2.png" loading="lazy" />

Enfin, un résumé des choix effectués. Validez pour activer la FT sur votre machine virtuelle :

<img className="thumbnail" alt="Fault Tolerance" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-fault-tolerance/FT3.png" loading="lazy" />

Votre machine virtuelle est maintenant protégée par **Fault Tolerance**, son icone est désormais différente et son nom affiche alors le statut « Primaire ».

<img className="thumbnail" alt="Fault Tolerance" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-fault-tolerance/FT4.png" loading="lazy" />

Plusieurs opérations sont dès lors disponibles en fonction de votre besoin.

<img className="thumbnail" alt="Fault Tolerance" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-fault-tolerance/FT5.png" loading="lazy" />

## Actions impossibles et incompatibilités

Sur une machine virtuelle avec **Fault Tolerance** activé, il n'est plus possible d'effectuer certaines actions, ni d'utiliser certains périphériques.

Vous retrouverez la liste des actions devenues impossibles sur [cette page](https://docs.vmware.com/fr/VMware-vSphere/6.7/com.vmware.vsphere.avail.doc/GUID-F5264795-11DA-4242-B774-8C3450997033.html) et la liste des incompatibilités sur [celle-ci](https://docs.vmware.com/fr/VMware-vSphere/6.7/com.vmware.vsphere.avail.doc/GUID-C1749AD4-70E2-406C-864C-719F54BF1BC1.html).
