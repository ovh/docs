## Objectif

OVHcloud met à votre disposition un outil de **supervision** et de **monitoring** de vos machines virtuelles et de votre infrastructure : **vScope**.

Cette interface web rassemble toutes les informations essentielles sur vos ressources.

**Ce guide explique comment lire et utiliser l'interface vScope.**

## Prérequis

- Être contact administrateur de l'infrastructure [Hosted Private Cloud](https://www.ovhcloud.com/fr/hosted-private-cloud/vmware/), afin de recevoir des identifiants de connexion.
- Disposer d’un identifiant utilisateur actif (créé dans l’[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr)).

## En pratique

### Accéder à vScope

1. Dans l’[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr), cliquez sur <code className="action">Hosted Private Cloud</code>.

2. Dans le menu de gauche, sélectionnez <code className="action">Managed VMware vSphere</code>.

3. Choisissez votre service PCC.

4. Dans l’onglet <code className="action">Informations générales</code>, descendez puis cliquez sur le lien <code className="action">vScope</code>.

<img className="thumbnail" alt="vScope" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-use-vscope/gatewayPCC.png" loading="lazy" />

L’interface s’ouvre dans un nouvel onglet de votre navigateur.

<img className="thumbnail" alt="vScope" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-use-vscope/vScope12.png" loading="lazy" />

Identifiez-vous avec votre **utilisateur** et votre **mot de passe**, les mêmes que ceux utilisés pour vous connecter au client vSphere.

<img className="thumbnail" alt="vScope" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-use-vscope/vScope11.png" loading="lazy" />

Vous êtes désormais connecté à **vScope**. Cette page centralise les informations clés de vos ressources.

Par exemple, pour chaque hôte, vous visualisez immédiatement :
- le nombre de cœurs et de VM
- la charge CPU et RAM
- le trafic réseau

<img className="thumbnail" alt="vScope" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-use-vscope/vScope.png" loading="lazy" />

### Navigation dans vScope

#### Choix du datacenter

Si votre Hosted Private Cloud contient plusieurs datacenters, sélectionnez celui que vous souhaitez afficher dans le menu déroulant.

Le champ **Last refresh** correspond au dernier rafraîchissement de la page web (et non du vScope). Les données vScope sont mises à jour automatiquement toutes les 2 à 5 minutes.

<img className="thumbnail" alt="vScope" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-use-vscope/vScope1.png" loading="lazy" />

#### Menu Filer

Le menu **Filer** indique l’utilisation de vos datastores : nombre de machines virtuelles et espace consommé.

Utilisez cette vue pour anticiper un besoin d’extension ou surveiller l’équilibre de charge.

<img className="thumbnail" alt="vScope" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-use-vscope/vScope2.png" loading="lazy" />

### Menu Hosts

Le menu **Hosts** détaille les caractéristiques de chaque hôte dans votre datacenter :

- nombre de cœurs, vCPUs et VM
- pourcentage d’utilisation CPU et RAM
- connectivité réseau
- nombre de cartes réseau physiques (VMNic)

<img className="thumbnail" alt="vScope" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-use-vscope/vScope4.png" loading="lazy" />

### Menu Machines virtuelles

Cette section fournit une vue détaillée de chaque machine virtuelle :

- État des VMware Tools
- Trafic réseau
- Taille de la VM
- Activation de FT (Fault Tolerance)
- CPU Ready Time
- Disk IO
- Disk Latency

<img className="thumbnail" alt="vScope" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-use-vscope/vScope6.png" loading="lazy" />
