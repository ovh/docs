## Objectif

**Ce guide fournit des instructions détaillées pour se connecter à Public VCF as-a-Service.**

## Prérequis

- Un navigateur web
- Avoir reçu l'e-mail de création de compte

## En pratique

### Premiere connexion

Ouvrez votre navigateur web et rendez-vous sur la page de connexion du Public VCF as-a-Service. Renseignez votre nom d'organisation (celui-ci est fourni dans l'e-mail de création de compte).

<img className="thumbnail" alt="First page connection" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vcd-logging/vcd-organization-connection.png" loading="lazy" />

Vous êtes maintenant invité à entrer votre nom d'utilisateur et votre mot de passe dans les champs appropriés (ces informations sont fournies dans l'e-mail de création de votre compte).

Cliquez sur le bouton <code className="action">Se connecter</code> pour accéder à Public VCF as-a-Service.

<img className="thumbnail" alt="Login connection" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vcd-logging/vcd-login-connection.png" loading="lazy" />

Vous allez être redirigé vers le tableau de bord de votre organisation que nous allons décrire dans le [ce guide](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vcd-getting-started/).

<img className="thumbnail" alt="Dashboard" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vcd-logging/vcd-dashboard-view.png" loading="lazy" />

### Modification du mot de passe

Une fois connecté, recherchez un lien ou un bouton intitulé **Admin OVHcloud Organization Administrator** ou équivalent. Celui-ci est situé dans le coin supérieur droit de l'interface utilisateur.

<img className="thumbnail" alt="Admin Button" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vcd-logging/vcd-settings.png" loading="lazy" />

Un menu déroulant apparaît, choississez l'option <code className="action">Change Password</code>.

<img className="thumbnail" alt="Option Change Password" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vcd-logging/vcd-change-password-option.png" loading="lazy" />

Vous serez invité à saisir votre ancien mot de passe ainsi que votre nouveau mot de passe.

Complétez les champs correspondants puis cliquez sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="Change password" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vcd-logging/vcd-change-password.png" loading="lazy" />

Vous devriez recevoir un mail de confirmation du changement de mot de passe.
