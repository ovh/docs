## Objectif

VMware offre la possibilité de cloner une VM pour créer une nouvelle VM ou un modèle.

**Ce guide explique comment exécuter ces tâches.**

## Prérequis

- Être contact administrateur de l'infrastructure [Hosted Private Cloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/), pour recevoir des identifiants de connexion.
- Avoir un identifiant utilisateur actif (créé dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr))

## En pratique

### Cloner une VM

Cloner permet un déploiement rapide et facile de VMs similaires.<br/>
Vous pouvez cloner une VM vers une autre VM ou vers un modèle.<br/>
Cloner vers une VM est un moyen rapide de dupliquer une VM et ses paramètres.<br/>
Cloner vers un modèle est un meilleur moyen pour créer une copie originale qui servira à déployer de multiples VMs.

#### Cloner vers une VM

Dans l'interface vSphere, rendez-vous dans le tableau de bord <code className="action">Hôtes et clusters</code>.<br/>
Naviguez jusqu'à votre VM, faites un clic-droit sur celle-ci et, dans le menu <code className="action">Cloner</code>, sélectionnez <code className="action">Cloner vers une machine virtuelle</code>.

<img className="thumbnail" alt="CLONE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/clone-a-vm/en08clonevm.png" loading="lazy" />

Nommez le clone et sélectionnez son datacenter.<br/>
Cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="CLONE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/clone-a-vm/en09clonename.png" loading="lazy" />

Sélectionnez une ressource de calcul.<br/>
Cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="CLONE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/clone-a-vm/en10clonecomp.png" loading="lazy" />

Sélectionnez le lieu de stockage.<br/>
Cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="CLONE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/clone-a-vm/en11clonestor.png" loading="lazy" />

Sélectionnez les options nécessaires pour le clone.

- Personnaliser le système d'exploitation lancera sysprep lors de la première utilisation de la VM.
- Personnaliser le matériel de cette machine virtuelle permet de modifier les caractéristiques techniques de la VM (taille de disque, RAM, éléments réseau...).
- Mettre sous tension la machine virtuelle après la création n'est pas recommandé. Certains changements à froid peuvent être necessaires avant de lancer la VM pour éviter des conflits.

Cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="CLONE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/clone-a-vm/en12clonecustom.png" loading="lazy" />

Vérifiez puis cliquez sur <code className="action">Terminer</code>.

<img className="thumbnail" alt="CLONE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/clone-a-vm/en13clonefinish.png" loading="lazy" />

Le processus de clonage s'enclenche et, à l'issue de celui-ci, la nouvelle VM sera disponible.

:::info
Si le clone a été effectué sans personalisation, assurez-vous que vous pouvez démarrer la VM sans danger. Par exemple, si la VM d'origine a une IP fixe, désactivez la carte réseau du clone pour éviter un conflit d'adresses IP.

:::


#### Cloner vers un modèle

Dans l'interface vSphere, rendez-vous dans le tableau de bord <code className="action">Hôtes et clusters</code>.<br/>
Naviguez jusqu'à votre VM, faites un clic-droit sur celle-ci et, dans le menu <code className="action">Cloner</code>, sélectionnez <code className="action">Cloner vers un modèle</code>.

<img className="thumbnail" alt="TEMPLATE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/clone-a-vm/en14clonetemp.png" loading="lazy" />

Nommez le modèle et selectionnez son datacenter.<br/>
Cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="TEMPLATE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/clone-a-vm/en15clonename.png" loading="lazy" />

Sélectionnez une ressource de calcul.<br/>
Cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="TEMPLATE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/clone-a-vm/en16clonecomp.png" loading="lazy" />

Sélectionnez le lieu de stockage.<br/>
Cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="TEMPLATE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/clone-a-vm/en17clonestor.png" loading="lazy" />

Vérifiez puis cliquez sur <code className="action">Terminer</code>.

<img className="thumbnail" alt="TEMPLATE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/clone-a-vm/en18clonefinish.png" loading="lazy" />

Le processus de clonage va s'exécuter.<br/>
Aucune VM n'est directement visible mais le nouveau modèle est utilisable dans l'option "Déployer depuis un modèle".

<img className="thumbnail" alt="TEMPLATE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/clone-a-vm/en19deploy.png" loading="lazy" />
