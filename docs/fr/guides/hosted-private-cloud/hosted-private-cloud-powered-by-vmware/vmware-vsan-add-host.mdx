## Objectif

Ce guide explique comment ajouter le stockage d'un nouveau serveur ESXi dans un cluster vSAN existant.

## Prérequis

- Être contact administrateur de l'infrastructure [Hosted Private Cloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/), afin de recevoir les identifiants de connexion.
- Avoir un identifiant utilisateur actif avec les droits spécifiques pour NSX (créé dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr))
- Avoir déployé un [datastore vSan](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/)

## En pratique

### Commander un nouvel hôte vSan

Connectez-vous à l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr) avec un compte administrateur.

Dans la section <code className="action">Hosted Private Cloud</code>, sélectionnez votre datacentre et allez dans l'onglet <code className="action">Hosts</code>.<br/>
Cliquez le bouton <code className="action">Commander un Host</code>.

<img className="thumbnail" alt="ORDER" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan-add-host/en02order.png" loading="lazy" />

Choisissez l'hôte vSAN qui vous convient puis cliquez sur <code className="action">Confirmer la commande</code>

<img className="thumbnail" alt="ORDER" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan-add-host/en03hosttype.png" loading="lazy" />

Verifiez le récapitulatif avant de cliquer <code className="action">Suivant</code>

Cochez les cases pour accepter les termes et conditions et payez le bon de commande via le moyen de paiement de votre choix.

Vous obtiendrez une confirmation de commande et un numéro de commande.

Le nouvel hôte sera intégré automatiquement à votre infrastructure. Vous recevrez un email de confirmation quand il sera prêt à l'usage dans vSphere.

### Ajouter l'espace de stockage du nouvel hôte vSAN au datastore

Dans l'interface vSphere, allez dans le Tableau de bord <code className="action">Hôtes et clusters</code>.

<img className="thumbnail" alt="Menu" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan-add-host/en07hosts.png" loading="lazy" />

Le nouvel hôte est visible dans le cluster.<br/>
Sur la gauche de l'écran, sélectionnez le cluster, allez dans l'onglet <code className="action">Configurer</code> puis <code className="action">vSAN</code> / <code className="action">Gestion de disques</code>.<br/>
Cliquez sur <code className="action">Réclamer des disques inutilisés</code>.

<img className="thumbnail" alt="vSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan-add-host/en08cluster.png" loading="lazy" />

Les disques disponibles sont attribués automatiquement au cache ou au stockage (voir la [page officielle VMware VSAN](https://docs.vmware.com/fr/VMware-vSphere/6.7/com.vmware.vsphere.vsan-planning.doc/GUID-18F531E9-FF08-49F5-9879-8E46583D4C70.html) pour plus de détails) en fonction de leur type et de leur taille. Vous pouvez personnaliser les paramètres.

Cliquez sur <code className="action">Créer</code>.

<img className="thumbnail" alt="vSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan-add-host/en09claim.png" loading="lazy" />

Le nouveau groupe de disques prend un peu de temps pour être créé et ajouté au datastore vSAN.

<img className="thumbnail" alt="vSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan-add-host/en10progress.png" loading="lazy" />

Le datastore est ensuite prêt à être utilisé avec l'espace de stockage supplémentaire.
