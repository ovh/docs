## Objectif

Utilisez les outils de surveillance de vSphere pour dépanner une VM.

**Découvrez comment résoudre les problèmes de performance d'une VM via l'interface vSphere**

## Prérequis

- Être contact administrateur de l'infrastructure [Hosted Private Cloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/), afin de recevoir kes identifiants de connexion.
- Avoir un identifiant utilisateur actif (créé dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr))

## En pratique

Vous avez à disposition trois niveaux de surveillance dans vSphere :

- VM
- Cluster
- Stockage

### Surveillance de la VM

Dans l'interface vSphere, rendez-vous dans le tableau de bord <code className="action">Hôtes et clusters</code>.<br/>
Naviguez jusqu'à votre VM et selectionnez-la.<br/>
L'onglet <code className="action">Surveiller</code> montre une <code className="action">Présentation</code> des performances.<br/>
Vous pouvez choisir les mesures en temps réel ou definir une chronologie pour voir l'évolution des performances.<br/>
Vous pouvez modifier la vue pour creuser des sujets spécifiques.

<img className="thumbnail" alt="surveillance VM" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/check-a-slow-machine/en01vm.png" loading="lazy" />

La section <code className="action">Utilisation</code> aidera également vos investigations.

### Surveillance du cluster

Dans l'interface vSphere, rendez-vous dans le tableau de bord <code className="action">Hôtes et clusters</code>.<br/>
Naviguez jusqu'à votre cluster et selectionnez-le.<br/>
L'onglet <code className="action">Surveiller</code> montre une <code className="action">Présentation</code> des performances.<br/>
Vous pouvez choisir les mesures en temps réel ou definir une chronologie pour voir l'évolution des performances.<br/>
Vous pouvez modifier la vue pour creuser des sujets spécifiques.

<img className="thumbnail" alt="surveillance cluster" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/check-a-slow-machine/en02cluster.png" loading="lazy" />

Les sections <code className="action">Allocation des ressources</code> et <code className="action">Utilisation</code> aideront également vos investigations.

:::info
Les pools de resources sont accessibles et surveillés à l'identique des clusters.

:::
