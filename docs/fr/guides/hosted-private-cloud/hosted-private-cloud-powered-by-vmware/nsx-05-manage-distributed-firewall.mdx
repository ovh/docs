## Objectif

La fonctionnalité du pare-feu distribué dans NSX permet de faire du filtrage avec tous les éléments de votre cluster VMware qui sont sur des segments Overlay ou VLAN. Il doit être utilisé normalement sur les connexions est-ouest (ovh-T1-gw)  mais il fonctionne aussi avec des éléments du cluster VMware qui se trouvent connectés sur la passerelle nord-sud (ovh-T0-gw). Le filtrage s'applique à partir de la source (VM, segment, réseau, etc...).

Pour simplifier l'administration de NSX, il est possible de positionner des marqueurs (*tags*) sur vos éléments (segments, machines virtuelles, rôles, etc..) et de créer des groupes qui contiennent les objets associés aux marqueurs ou des plages d'adresses IP (cette solution n'est pas à privilégier).

**Découvrez la gestion du pare-feu distribué au travers de la création d'une règle qui bloque le trafic entre une machine virtuelle et l'ensemble des machines virtuelles d'un autre segment.**

## En pratique

Nous allons isoler les communications entre une machine virtuelle et l'ensemble des machines virtuelles d'un segment, de manière bi-directionnelle en effectuant ces opérations : 

- Création de deux marqueurs (tags), un sur une machine virtuelle et l'autre sur un segment.
- Création de deux groupes associés, l'un contenant le premier marqueur et l'autre le second.
- Création d'une stratégie dans le pare-feu distribué qui contiendra deux règles :
    - Une règle qui interdira le trafic venant du premier groupe vers le second.
    - Une autre règle qui interdira le trafic venant du second groupe vers le premier.

### Création des marqueurs (tags)

Dans l'interface NSX, allez dans l'onglet <code className="action">Networking</code> et cliquez sur <code className="action">Segments</code> à gauche dans la rubrique **Connectivity**.

Cliquez ensuite sur les <code className="action">trois points verticaux</code> à gauche du segment que vous voulez marquer et choisissez <code className="action">Edit</code> dans le menu.

<img className="thumbnail" alt="01 Create tag on segment 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/01-create-tag-on-segment01.png" loading="lazy" />

A droite de **Tags**, saisissez <code className="action">ovsegment</code> à la place de tag et cliquez sur <code className="action">Add Item(s) ovsegment</code> en dessous de la zone de saisie.

<img className="thumbnail" alt="01 Create tag on segment 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/01-create-tag-on-segment02.png" loading="lazy" />

Saisissez <code className="action">ov1</code> à la place de **Scope** et cliquez sur <code className="action">Add Item(s) ov1</code> en dessous de la zone de saisie.

<img className="thumbnail" alt="01 Create tag on segment 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/01-create-tag-on-segment02.png" loading="lazy" />

Cliquez sur le signe <code className="action">+</code> à gauche de votre marqueur.

<img className="thumbnail" alt="01 Create tag on segment 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/01-create-tag-on-segment03.png" loading="lazy" />

Le marqueur créé est affiché en bas à droite de **Tags**, vous pouvez en créer d'autres en fonction de vos besoins.

Cliquez sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="01 Create tag on segment 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/01-create-tag-on-segment04.png" loading="lazy" />

Cliquez sur <code className="action">CLOSE EDITING</code> pour finaliser le balisage de votre segment.

<img className="thumbnail" alt="01 Create tag on segment 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/01-create-tag-on-segment04.png" loading="lazy" />

Allez sur l'onglet <code className="action">Inventory</code> et cliquez sur <code className="action">Virtual Machines</code> à gauche dans l'inventaire pour afficher la liste des machines virtuelles. 

Cliquez ensuite sur les <code className="action">trois points verticaux</code> à gauche de la machine virtuelle que vous voulez marquer et choisissez <code className="action">Edit</code> dans le menu.

<img className="thumbnail" alt="02 Create tag on vm 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/02-create-tag-on-vm01.png" loading="lazy" />

Saisissez <code className="action">vm</code> à la place de **Tag** et cliquez sur <code className="action">Add Item(s) vm</code> en dessous de la zone de saisie.

<img className="thumbnail" alt="02 Create tag on vm 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/02-create-tag-on-vm02.png" loading="lazy" />

Saisissez <code className="action">ov2</code> à la place de **Scope** et cliquez sur <code className="action">Add Item(s) ov2</code> en dessous de la zone de saisie.

<img className="thumbnail" alt="02 Create tag on vm 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/02-create-tag-on-vm03.png" loading="lazy" />

Cliquez sur le signe <code className="action">+</code> à gauche de votre marqueur.

<img className="thumbnail" alt="02 Create tag on vm 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/02-create-tag-on-vm04.png" loading="lazy" />

Le marqueur est créé, cliquez sur <code className="action">SAVE</code> pour enregistrer vos modifications.

<img className="thumbnail" alt="02 Create tag on vm 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/02-create-tag-on-vm05.png" loading="lazy" />

Restez dans l'inventaire et cliquez sur <code className="action">Tags</code> à gauche pour afficher la liste des marqueurs.

### Ajout de groupes qui contiennent les marqueurs (tags)

Toujours dans l'inventaire, allez dans <code className="action">Groups</code> à gauche et cliquez sur <code className="action">ADD GROUP</code> pour créer un groupe.

<img className="thumbnail" alt="04 Create Group With tag on segment 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/04-create-group-with-tag-on-segment01.png" loading="lazy" />

Saisissez <code className="action">g-segment01</code> en dessous de la colonne **Name** et cliquez sur <code className="action">Set</code> sous la colonne **Compute Members**.

<img className="thumbnail" alt="04 Create Group With tag on segment 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/04-create-group-with-tag-on-segment02.png" loading="lazy" />

Laissez <code className="action">Generic</code> sélectionné et cliquez sur <code className="action">+ ADD CRITERION</code>.

<img className="thumbnail" alt="04 Create Group With tag on segment 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/04-create-group-with-tag-on-segment03.png" loading="lazy" />

Choisissez ces paramètres :

- **Type** : `NSX Segment`.
- **Tags** : Equals `ovsegment`.
- **Scope**: Equals `ov1`.

Cliquez sur <code className="action">APPLY</code>.

<img className="thumbnail" alt="04 Create Group With tag on segment 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/04-create-group-with-tag-on-segment04.png" loading="lazy" />

Cliquez sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="04 Create Group With tag on segment 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/04-create-group-with-tag-on-segment05.png" loading="lazy" />

Le groupe est créé, cliquez sur le bouton <code className="action">View Members</code> se trouvant sur la ligne de votre groupe pour en afficher la liste des membres.

<img className="thumbnail" alt="04 Create Group With tag on segment 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/04-create-group-with-tag-on-segment06.png" loading="lazy" />

Cliquez sur <code className="action">IP Addresses</code> pour afficher les adresses IP qui sont utilisées sur votre segment et qui ont été automatiquement ajoutées à votre groupe.

<img className="thumbnail" alt="04 Create Group With tag on segment 07" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/04-create-group-with-tag-on-segment07.png" loading="lazy" />

### Mise en place d'une règle de pare-feu distribué

Nous allons maintenant créer, sur le pare-feu distribué, une règle de blocage bidirectionnel entre les deux groupes créés.

Allez sur l'onglet <code className="action">Security</code>, sélectionnez <code className="action">Distributed Firewall</code> et cliquez sur <code className="action">+ ADD POLICY</code>.

<img className="thumbnail" alt="06 Create distributed firewall rules 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/06-create-distributed-firewall-rules01.png" loading="lazy" />

Nommez votre stratégie <code className="action">Isolate vm and segment</code>.

<img className="thumbnail" alt="06 Create distributed firewall rules 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/06-create-distributed-firewall-rules02.png" loading="lazy" />

Cliquez sur les <code className="action">trois points verticaux</code> à gauche de votre stratégie et choisissez <code className="action">Add Rule</code> dans le menu.

<img className="thumbnail" alt="06 Create distributed firewall rules 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/06-create-distributed-firewall-rules03.png" loading="lazy" />

Cliquez sur l'icône en forme de <code className="action">stylo</code> à droite de **Any** dans la colonne **Sources**.

<img className="thumbnail" alt="06 Create distributed firewall rules 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/06-create-distributed-firewall-rules04.png" loading="lazy" />

Restez sur l'onglet <code className="action">groups</code>, cochez le groupe <code className="action">g-segment01</code> et cliquez sur <code className="action">APPLY</code>

<img className="thumbnail" alt="06 Create distributed firewall rules 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/06-create-distributed-firewall-rules05.png" loading="lazy" />
