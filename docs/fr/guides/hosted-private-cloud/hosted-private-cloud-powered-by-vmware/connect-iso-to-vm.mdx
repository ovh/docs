## Objectif

Vous pouvez créer une librairie de fichiers ISO à utiliser pour vos déploiements de systèmes et de logiciels dans votre infrastructure.

**Ce guide vous accompagne tout au long du processus de connexion d'une image ISO à une VM.**

## Prérequis

- Être contact administrateur de l'infrastructure [Hosted Private Cloud](/links/hosted-private-cloud/vmware), afin de recevoir les identifiants de connexion.
- Avoir un identifiant utilisateur actif (créé dans l'[espace client OVHcloud](/links/manager))

## En pratique

### Création de la librairie

Dans l'interface vSphere, allez dans la section `Stockage`.<br />
Choisissez le Datastore qui abritera la librairie (préférez les espaces de stockage partagés aux stockage locaux afin d'éviter les problèmes d'accès).<br />
Dans l'onglet `Fichiers`, cliquez sur `Nouveau Dossier`.

![FOLDER](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en01newfolder.png)

Nommez votre dossier (dans notre exemple : ISOs) puis selectionnez-le et cliquez sur `Télécharger des fichiers`.

![UPLOAD](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en02upload.png)

Naviguez jusqu'aux fichiers ISO que vous souhaitez uploader et cliquez sur `Ouvrir`.

![BROWSE](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en03browse.png)

Votre librairie est prête. Vous pouvez ajouter des images ISO selon vos besoins et dans la limite de l'espace de stockage disponible.

![LIBRARY](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en04library.png)

### Connecter une image à une VM

Dans l'interface vSphere, allez dans la section `Hôtes & clusters`.<br />
Faites un clic droit sur la VM qui a besoin de l'image ISO attachée puis cliquez sur `Modifier les paramètres`.<br />

![EDIT](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en05edit.png)

Changez le paramètre du lecteur CD/DVD en "Fichier ISO banque de données".

![ISO](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en06dataiso.png)

Dans la fenêtre de navigation qui apparait, allez dans la librairie créée précédement et selectionnez l'image à utiliser.<br />
Cliquez sur `OK`.

![SELECT](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en07choose.png)

De retour dans la fenêtre de paramétrage, assurez-vous que l'option "Connecter" est cochée avant de cliquer `OK`.

![CONNECT](/images/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/how-to-connect-an-iso-image-to-a-vm/en08connect.png)

L'image est désormais connectée et disponible pour votre VM comme si c'était un media physique directement attaché.
