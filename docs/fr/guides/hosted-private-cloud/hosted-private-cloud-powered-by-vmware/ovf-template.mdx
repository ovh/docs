## Objectif

OVHcloud propose des templates Linux, Windows Server et Windows SQL server (au format OVF) que vous pouvez déployer directement depuis votre client Web (HTML 5).

Les VM Windows déployées à partir d'un template utilisent automatiquement les licences SPLA fournies par OVHcloud. Le déploiement d'une VM Windows déclenchera donc automatiquement une facturation supplémentaire.

**Ce guide vous explique où trouver les sources et comment procéder au déploiement.**

:::info
Retrouvez sur cette [page](https://www.ovhcloud.com/fr/hosted-private-cloud/vmware/images-licenses/) les tarifs des images proposées par OVHcloud.

:::


## Prérequis

- Avoir accès au client Web (HTML5)
- [Avoir activé les licences Windows](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/manager-ovh-private-cloud#licence-windows/) depuis votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr)

## En pratique

### Récupérer l'URL du template OVF

Depuis un navigateur internet, rendez-vous sur la page d'accueil de votre Private Cloud puis cliquez sur <code className="action">OVH Template</code>.

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/gatewayssl.png" loading="lazy" />

Dans l'écran `OVH Templates` qui s'affiche, vous accédez au détail des templates Linux, Windows et SQL proposés. 

Sélectionnez le template souhaité, une fenêtre s'ouvrira et vous proposera les liens qui vous serviront pour le déploiement en fonction de votre version de vSphere.

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/copylink.png" loading="lazy" />

### Déployer le template OVF

Une fois connecté au client web vSphere, rendez-vous sur la page <code className="action">Hôtes et clusters</code> puis faites un clic droit sur votre datacenter et cliquez sur <code className="action">Déployer le modèle OVF...</code> :

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/01selectdeploy.png" loading="lazy" />

Le menu contextuel s'ouvre, la configuration du déploiement va pouvoir commencer. Dans la première étape, il faut ajouter le lien que vous avez récupéré précédemment :

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/02puturl.png" loading="lazy" />

L'étape suivante vous permet de choisir le datacenter :

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/03selectdatacenter.png" loading="lazy" />

Choisissez ensuite le cluster dans lequel la machine virtuelle va être déployée :

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/04selectcluster.png" loading="lazy" />

Vous retrouvez tous les détails du template et, notamment, le mot de passe par défaut. Pour des raisons de sécurité, il est important de le changer dès votre première connexion :

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/05detailstemplate.png" loading="lazy" />

Choisissez le datastore dans lequel la machine virtuelle va être stockée ainsi que le format du disque :

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/06selectdatastore.png" loading="lazy" />

Vous devez maintenant choisir le réseau qui sera utilisé.

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/07selectnetwork.png" loading="lazy" />

La configuration est quasiment terminée, vous avez accès à un résumé de la configuration souhaitée :

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/08resume.png" loading="lazy" />

Après avoir cliqué sur <code className="action">Terminer</code>, une tâche est créée et vous permet de suivre le déploiement :

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/09startdeploy.png" loading="lazy" />

Une fois le déploiement terminé, vous pouvez fermer cette fenêtre.

Vous retrouvez alors la machine virtuelle déployée dans votre inventaire.

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/10inventory.png" loading="lazy" />

### Finalisation de l'installation pour SQL Server

Démarrer votre machine virtuelle fraichement déployée et ouvrez la console.

Ouvrez la session Windows et renseignez le nom de votre instance SQL, le mot de passe et le jeux de caractère souhaité dans la fenêtre prévue à cet effet.

<img className="thumbnail" alt="Nom de photo" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/ovf-template/sqlinformations.png" loading="lazy" />

:::info
Il est recommandé de mettre en place un mot de passe respectant ces critères :

* Comporter au minimum huit caractères.
* Comporter au minimum trois types de caractères (Majuscules, minuscules, chiffres, caractères spéciaux).
* Ne pas être tiré du dictionnaire.
* Ne pas comporter d’informations personnelles (votre prénom, nom ou date de naissance).

:::


Une fois ces informations renseignées, cliquez sur <code className="action">OK</code>.

Une fenêtre montrant le déploiement s'ouvrira. A la fin de celui ci, une dernière fenêtre vous informant de la réussite du déploiement s'ouvrira.

Cliquez à nouveau sur <code className="action">OK</code> pour que l'installation se termine et que votre machine virtuelle redémarre.

Suite à ce redémarrage vous pourrez commencer à utiliser votre machine virtuelle.
