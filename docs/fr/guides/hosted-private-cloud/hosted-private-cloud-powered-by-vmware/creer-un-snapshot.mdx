## Objectif

VMware offre la possibilité de créer des snapshots pour permettre le retour à un état précedent de votre VM.

**Ce guide explique comment exécuter cette tâche.**

## Prérequis

- Être contact administrateur de l'infrastructure [Hosted Private Cloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/), afin de recevoir les identifiants de connexion.
- Avoir un identifiant utilisateur actif (créé dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr))

## En pratique

### Prendre un Snapshot

Un snapshot capture l'etat d'une VM.<br/>
Cela ajoute une couche de protection pour votre VM avant de procéder à des changements, en permettant de revenir à cet état si besoin.

Dans l'interface vSphere, rendez-vous dans le tableau de bord <code className="action">Hôtes et clusters</code>.<br/>
Naviguez jusqu'à votre VM, faites un clic-droit sur celle-ci et, dans le menu <code className="action">Snapshots</code>, sélectionnez <code className="action">Prendre un snapshot</code>.

<img className="thumbnail" alt="TAKE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/creer-un-snapshot/en01take.png" loading="lazy" />

Par défaut, le nom du snapshot est la date et l'heure courante. Vous pouvez modifier ce nom à votre convenance.<br/>
Vous pouvez également ajouter une description.

Si la VM est en marche, le processus de snapshot offre deux options :

- Prendre un snapshot de la mémoire de la machine virtuelle. Cela sauvegarde l'état de la RAM sur la VM pour aider les applications qui n'ont pas encore ecrit leurs données sur disque. Cela doit rendre le snapshot résistant au crash et ouvre la possibilité de récupération à chaud.
- Mettre au repos le système fichiers invité (VMware Tools doit être installé). La VM sera paramétrée comme si le sytème allait être sauvegardé : buffers nettoyés, changements enregistrés sur disque...<br/>
Si la VM est éteinte, ces options sont grisées.<br/>
*Nous recommandons de prendre des snapshots de VM à froid. Si cela n'est pas possible, préférez la mise au repos à un simple snapshot de mémoire, pour plus de sécurité.*

Cliquez sur <code className="action">OK</code>.

<img className="thumbnail" alt="SNAP" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/creer-un-snapshot/en02snap.png" loading="lazy" />

Votre snapshot est alors pris.

### Gérer les Snapshots

Vous pouvez prendre de multiples snapshots d'une seule VM en répétant le processus décrit ci-dessus.<br/>
Cependant, avec le temps, les snapshots consomment beaucoup de resources pour se maintenir et finissent par affecter les performances des VMs.<br/>
Voici comment restaurer ou supprimer les snapshots.

#### Restaurer un Snapshot

Dans l'interface vSphere, rendez-vous dans le tableau de bord <code className="action">Hôtes et clusters</code>.<br/>
Naviguez jusqu'à votre VM, faites un clic-droit sur celle-ci et, dans le menu <code className="action">Snapshots</code>, sélectionnez <code className="action">Gérer les snapshots</code>.

<img className="thumbnail" alt="MANAGE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/creer-un-snapshot/en03manage.png" loading="lazy" />

Vérifiez l'arborescence des snapshots et sélectionnez celui auquel vous souhaitez revenir.<br/>
Cliquez sur <code className="action">Restaurer</code>.

<img className="thumbnail" alt="REVERT" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/creer-un-snapshot/en04revert.png" loading="lazy" />

Confirmez en cliquant sur <code className="action">OK</code>.

<img className="thumbnail" alt="CONFIRM" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/creer-un-snapshot/en05confirm.png" loading="lazy" />

Vous pouvez alors cliquer sur <code className="action">Terminé</code>, votre VM est revenue à l'état choisi.

:::info
Si vous n'avez qu'un unique snapshot ou souhaitez revenir au dernier snapshot pris, vous pouvez accélérer le processus en choisissant <code className="action">Restaurer le dernier snapshot</code> dans le menu <code className="action">Snapshots</code>.

:::


#### Supprimer un Snapshot

Dans l'interface vSphere, rendez-vous dans le tableau de bord <code className="action">Hôtes et clusters</code>.<br/>
Naviguez jusqu'à votre VM, faites un clic-droit sur celle-ci et, dans le menu <code className="action">Snapshots</code>, sélectionnez <code className="action">Gérer les snapshots</code>.

<img className="thumbnail" alt="MANAGE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/creer-un-snapshot/en03manage.png" loading="lazy" />

Vérifiez l'arborescence des snapshots et selectionnez celui que vous souhaitez supprimer.<br/>
Cliquez sur <code className="action">Supprimer</code>.<br/>
*Vous pouvez aussi supprimer tous les snapshots existants en cliquant sur <code className="action">Supprimer tout</code>.*

<img className="thumbnail" alt="Delete" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/creer-un-snapshot/en06delete.png" loading="lazy" />

Confirmez en cliquant sur <code className="action">OK</code>.

<img className="thumbnail" alt="CONFIRM" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/creer-un-snapshot/en07confirm.png" loading="lazy" />

Vous pouvez cliquer sur <code className="action">Terminé</code>, le snapshot est alors supprimé.

:::info
Pour supprimer tous les snapshots, vous pouvez accélérer le processus en choisissant <code className="action">Supprimer tous les snapshots</code> dans le menu <code className="action">Snapshots</code>.

:::


#### Consolider les snapshots

La consolidation des snapshots est utile lorsque les disques de snapshots ne parviennent pas à se compresser après une opération de suppression. Après la consolidation, les disques redondants sont supprimés, ce qui améliore les performances des machines virtuelles et permet d'économiser de l'espace de stockage.

Dans l'interface vSphere, rendez-vous dans le tableau de bord <code className="action">Hôtes et clusters</code>.<br/>
Naviguez jusqu'à votre VM, faites un clic-droit sur celle-ci et, dans le menu <code className="action">Snapshots</code>, sélectionnez <code className="action">Consolider</code>

<img className="thumbnail" alt="CONSOLIDATE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/creer-un-snapshot/en08consolidate.png" loading="lazy" />

Confirmez en cliquant sur <code className="action">Oui</code>.

<img className="thumbnail" alt="CONFIRM" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/creer-un-snapshot/en09confirm.png" loading="lazy" />

Vous trouverez plus d'informations sur [la documentation de VMware](https://docs.vmware.com/en/VMware-vSphere/6.7/com.vmware.vsphere.vm_admin.doc/GUID-2F4A6D8B-33FF-4C6B-9B02-C984D151F0D5.html).
