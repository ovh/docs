## Objectif

OVHcloud vous fournit NSX avec deux passerelles, une passerelle de type nord-sud (ovh-T0-gw) et une passerelle de type est-ouest (ovh-T1-gw). Il vous est possible de créer des passerelles supplémentaires de type est-ouest.

**Découvrez comment ajouter une passerelle est-ouest (Tier-1 Gateway) dans votre configuration NSX.**

:::warning
OVHcloud vous met à disposition des services dont la configuration, la gestion et la responsabilité vous incombent. Il vous appartient donc de ce fait d’en assurer le bon fonctionnement.

Ce guide a pour but de vous accompagner au mieux sur des tâches courantes. Néanmoins, nous vous recommandons de faire appel à un [prestataire spécialisé](https://partner.ovhcloud.com/fr/) si vous éprouvez des difficultés ou des doutes concernant l’administration, l’utilisation ou la mise en place d’un service sur un serveur.

:::


## Prérequis

- Être contact administrateur de l'infrastructure [VMware on OVHcloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/), celui-ci recevant les identifiants de connexion.
- Avoir un identifiant utilisateur actif avec les droits spécifiques pour NSX (créé dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr)).
- Avoir **NSX** déployé.

:::warning
Au travers de votre interface NSX, il vous est possible de créer des passerelles de type nord-sud.

Ne le faites pas car certaines options ne sont pas disponibles et vous ne pourrez pas faire fonctionner ces passerelles correctement. 

:::


Pour plus d'informations sur NSX chez OVHcloud, consultez le guide « [Premiers pas avec NSX](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-01-first-steps/) ».

## En pratique

Nous allons ajouter une nouvelle passerelle de type est-ouest (Tier-1-Gateways) et la relier à la passerelle nord-sud fournie par OVHcloud (ovh-T0-gw).

Nous allons ensuite créer un segment et lui attacher une machine virtuelle. 

### Création de la nouvelle passerelle de type est-ouest

Dans l'interface NSX, allez dans l'onglet <code className="action">Networking</code> et cliquez sur <code className="action">Tier-1 Gateway</code> à gauche.

Cliquez ensuite sur <code className="action">ADD TIER-1 GATEWAY</code>.

<img className="thumbnail" alt="Add tier1-gw 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-10-add-new-tier1-gateway/01-add-tier1-gw01.png" loading="lazy" />

Saisissez le nom de votre nouvelle passerelle, tel que <code className="action">new-T1-gw</code>, en dessous de **Name** et choisissez ces paramètres :

- **Linked Tier-0-Gateway** : votre passerelle nord-sud <code className="action">ovh-T0-gw</code>.
- **Edge Cluster** : votre <code className="action">edgeXXX-X</code>.
- **Fail Over** : <code className="action">Non Preemptive</code>.
- **Edge Pool Allocation Size** : <code className="action">Routing</code>.

Cliquez ensuite sur la <code className="action">Flèche vers le bas</code> à gauche de **Route Advertissement**.

<img className="thumbnail" alt="Add tier1-gw 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-10-add-new-tier1-gateway/01-add-tier1-gw02.png" loading="lazy" />

Activez le <code className="action">bouton</code> à droite de **All Connected Segment & Service Ports** si vous souhaitez vous connecter en dehors de cette passerelle et cliquez sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="Add tier1-gw 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-10-add-new-tier1-gateway/01-add-tier1-gw03.png" loading="lazy" />

Cliquez sur <code className="action">NO</code>.

<img className="thumbnail" alt="Add tier1-gw 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-10-add-new-tier1-gateway/01-add-tier1-gw04.png" loading="lazy" />

Votre nouvelle passerelle est affichée et nous voyons qu'elle est connectée à votre passerelle nord-sud (ovh-T0-gw).

<img className="thumbnail" alt="Add tier1-gw 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-10-add-new-tier1-gateway/01-add-tier1-gw05.png" loading="lazy" />

Cliquez sur <code className="action">Network Topology</code> dans la barre de menu verticale à gauche pour afficher votre topologie réseau et pour faire apparaître votre nouvelle passerelle **new-T1-gw** reliée à **ovh-T0-gw**.

<img className="thumbnail" alt="Add tier1-gw 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-10-add-new-tier1-gateway/01-add-tier1-gw06.png" loading="lazy" />

### Ajout d'un segment sur votre nouvelle passerelle

Allez sur <code className="action">Segments</code> à gauche et cliquez sur <code className="action">ADD SEGMENT</code>.

<img className="thumbnail" alt="02 Add Segment on new gateway 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-10-add-new-tier1-gateway/02-add-segment-on-new-gw01.png" loading="lazy" />

Renseignez les informations suivantes : 

* **Name** : nom de votre segment <code className="action">ov3-segment</code>.
* **Connected Gateway** : votre nouvelle passerelle <code className="action">new-T1-gw</code>.
* **Transport Zone** : votre sous-réseau `192.168.120.254/24`.

Cliquez sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="02 Add Segment on new gateway 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-10-add-new-tier1-gateway/02-add-segment-on-new-gw02.png" loading="lazy" />

Cliquez sur <code className="action">NO</code>.

<img className="thumbnail" alt="02 Add Segment on new gateway 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-10-add-new-tier1-gateway/02-add-segment-on-new-gw03.png" loading="lazy" />

Votre nouveau segment est créé et il est relié à votre nouvelle passerelle **new-T1-gw**. 

<img className="thumbnail" alt="02 Add Segment on new gateway 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-10-add-new-tier1-gateway/02-add-segment-on-new-gw03.png" loading="lazy" />

### Affichage d'une configuration complète avec une machine virtuelle sur votre segment.

Le segment créé est de type Overlay mais il est possible d'ajouter un segment de type VLAN et de le connecter à votre nouvelle passerelle.

Aidez-vous du guide sur la [gestion des segments dans NSX](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/) pour ajouter une nouvelle machine virtuelle à votre nouveau segment. 

Cliquez ensuite sur <code className="action">Network Topology</code>.

<img className="thumbnail" alt="03 Display VM on segment in new gw 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-10-add-new-tier1-gateway/03-display-vm-on-segment-in-new-gw01.png" loading="lazy" />
