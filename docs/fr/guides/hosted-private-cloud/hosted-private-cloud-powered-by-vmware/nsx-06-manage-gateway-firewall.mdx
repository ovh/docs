## Objectif

Le pare-feu de passerelles permet le filtrage entre les segments internes et le réseau extérieur au cluster en entrée ou en sortie. 

Il fonctionne sur les passerelles de type nord-sud (Tier-0 Gateways) et est-ouest (Tier-1 Gateways) si la source ou la destination ne se trouvent pas à l'intérieur du cluster.

Si vous souhaitez créer des règles de filtrage entre des segments internes, il sera nécessaire d'utiliser le pare-feu distribué, en vous aidant de notre guide sur la [gestion du pare-feu distribué](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/).

## Prérequis

- Être contact administrateur de l'infrastructure [VMware on OVHcloud](https://www.ovhcloud.com/fr/enterprise/products/hosted-private-cloud/), celui-ci recevant les identifiants de connexion.
- Avoir un identifiant utilisateur actif avec les droits spécifiques pour NSX (créé dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr)).
- Avoir **NSX** déployé avec un segment configuré dans votre configuration NSX. Vous pouvez vous aider de notre guide sur la [gestion des segments dans NSX](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-02-segment-management/).

## En pratique

Nous allons créer une stratégie afin d'améliorer la visibilité et l'administration des règles en fonction de leur utilité.

Nous allons ensuite ajouter, à l'intérieur de notre stratégie, une règle qui bloque l'accès à tout le réseau externe d'un cluster depuis un groupe qui contient un segment (vous pouvez vous aider du guide sur la [gestion du pare-feu distribué](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-05-manage-distributed-firewall/) pour créer des groupes) et de **any** pour la destination. 

Allez sur l'onglet <code className="action">Security</code>, sélectionnez <code className="action">Gateway Firewall</code> et cliquez sur <code className="action">+ ADD POLICY</code>.

<img className="thumbnail" alt="01 Create gateway firewall rules 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules01.png" loading="lazy" />

Sélectionnez <code className="action">ovh-T0-gw</code> à droite de **Gateway**, nommez votre stratégie <code className="action">my policy</code> en dessous de la colonne **Name** et cliquez sur les <code className="action"> trois points verticaux</code> à gauche de votre stratégie.

<img className="thumbnail" alt="01 Create gateway firewall rules 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules02.png" loading="lazy" />

Cliquez sur <code className="action">Add Rule</code> dans le menu.

<img className="thumbnail" alt="01 Create gateway firewall rules 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules03.png" loading="lazy" />

Nommez votre règle <code className="action">block segment1 to any</code> en dessous de la colonne **Name**.

<img className="thumbnail" alt="01 Create gateway firewall rules 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules04.png" loading="lazy" />

Cliquez sur le bouton <code className="action">stylo</code> à droite de Any dans la colonne **Source**.

<img className="thumbnail" alt="01 Create gateway firewall rules 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules05.png" loading="lazy" />

Restez dans l'onglet <code className="action">Group</code>, sélectionnez le groupe <code className="action">g-segment1</code> et cliquez sur <code className="action">APPLY</code>.

<img className="thumbnail" alt="01 Create gateway firewall rules 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules06.png" loading="lazy" />

Choisissez <code className="action">Drop</code> sous la colonne **Action** et cliquez sur <code className="action">PUBLISH</code>.

<img className="thumbnail" alt="01 Create gateway firewall rules 07" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-06-manage-gateway-firewall/01-create-gateway-firewall-rules07.png" loading="lazy" />

Votre règle est active sur la passerelle **ovh-T0-gw**. Elle bloque tout le trafic sortant depuis les membres du groupe **g-segment01**.
