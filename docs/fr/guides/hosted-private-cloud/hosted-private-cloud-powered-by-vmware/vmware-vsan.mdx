## Objectif

Découvrez comment mettre en oeuvre la puissance de l'hyperconvergence pour vos machines virtuelles avec vSAN.

**Ce guide explique comment mettre en place VMware vSAN sur votre Hosted Private Cloud.**

## Prérequis

- Être contact administrateur de l'infrastructure [Hosted Private Cloud](https://www.ovhcloud.com/fr/hosted-private-cloud/vmware/), afin de recevoir des identifiants de connexion.
- Avoir un identifiant utilisateur actif avec les droits spécifiques pour NSX (créé dans l'[espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr))
- Avoir au minimum trois hôtes vSAN

:::warning
Les options de chiffrements **vSAN Data-At-Rest Encryption** et **vSAN Data-In-Transit Encryption** ne sont pas prises en charge par défaut sur les clusters vSAN. Si toutefois vous souhaitez mettre en œuvre ces solutions, veuillez contacter votre **Technical Account Manager**.

Le chiffrement reste possible au niveau de la machine virtuelle et de ses données, comme indiqué dans le guide « [Activation du chiffrement des machines virtuelles avec vSphere Native Key Provider](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vm-encrypt-vnkp/) ».

:::


## En pratique

### Qu'est-ce que vSAN ?

vSAN est une solution de stockage objet proposée par VMware. Elle agrège un ensemble de disques situés directement dans les hôtes VMware et les présente comme un datastore unique. C'est ce que l'on appelle du Software Defined Storage ou SDS. Un des avantages de vSAN est d'être complétement intégré à vSphere et géré directement depuis vCenter.

Pour une vue complète des concepts et des spécifications techniques, rendez-vous sur la [page officielle VMware VSAN](https://docs.vmware.com/fr/VMware-vSphere/6.7/com.vmware.vsphere.vsan-planning.doc/GUID-18F531E9-FF08-49F5-9879-8E46583D4C70.html)

### Paramétrer vSAN

#### Désactiver vSphere HA

vSAN s'appuie sur les fonctionnalités de haute disponibilité du cluster. Cependant, avant toute opération, il est nécessaire que ce mode soit désactivé.

Dans l'interface vSphere, allez dans le Tableau de bord <code className="action">Hôtes et clusters</code>.

<img className="thumbnail" alt="Menu" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en01hosts.png" loading="lazy" />

Sur la gauche de votre écran, selectionnez votre cluster, allez dans l'onglet <code className="action">Configurer</code> puis <code className="action">Disponibilité vSphere</code>.<br/>
Cliquez sur <code className="action">Modifier</code>.

<img className="thumbnail" alt="Menu" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en02cluster.png" loading="lazy" />

Désactivez vSphere HA puis cliquez sur <code className="action">OK</code>.

<img className="thumbnail" alt="HA" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en03ha.png" loading="lazy" />

#### Activer le service vSAN

Dans le menu de configuration du cluster, descendez dans <code className="action">vSAN</code> / <code className="action">Services</code> et cliquez sur <code className="action">Configurer</code>.

<img className="thumbnail" alt="VSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en04vsan.png" loading="lazy" />

Ce guide porte sur les fonctionnalités essentielles de vSAN. Nous utiliserons principalement les options par défaut.<br/>
Tous nos hôtes résidant sur un unique site, nous utiliserons l'option `Cluster à un seul site`. Cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="VSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en05vsantype.png" loading="lazy" />

Il est possible d'activer l'option `Déduplication et compression` pour optimiser l'espace de stockage.<br/>

Cependant, une baisse des performances et une augmentation de la latence peuvent être observées dans certains cas, notamment lors de l'utilisation de bases de données.

Cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="VSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en06vsanservices.png" loading="lazy" />

La fenêtre `Réclamer des disques` attribue automatiquement les disques pour du cache ou du stockage (voir la [page officielle VMware VSAN](https://docs.vmware.com/fr/VMware-vSphere/6.7/com.vmware.vsphere.vsan-planning.doc/GUID-18F531E9-FF08-49F5-9879-8E46583D4C70.html) pour plus de détails) en fonction du type et de la taille. Vous pouvez personnaliser les paramètres.<br/>
Cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="VSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en07vsanclaim.png" loading="lazy" />

Avec trois hôtes, les domaines de pannes sont créés par défaut et la tolérance aux pannes est de 1 hôte.<br/>
Cliquez sur <code className="action">Suivant</code>.

<img className="thumbnail" alt="VSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en08vsanfault.png" loading="lazy" />

Vérifiez les paramètres dans la fenêtre de résumé, puis cliquez sur <code className="action">Terminer</code>.

<img className="thumbnail" alt="VSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en09vsanready.png" loading="lazy" />

Retournez dans la configuration du cluster et réactivez vSphere HA.<br/>
Votre datastore est visible dans le menu Stockage.

<img className="thumbnail" alt="VSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en10vsandata.png" loading="lazy" />

:::warning
Pour des raisons de performance et de résilience, VMware recommande de ne pas dépasser 70 % de remplissage sur un datastore vSAN.

:::


### Désactiver vSAN

Avant de désactiver vSAN, assurez-vous d'évacuer toutes les machines virtuelles résidant sur le datastore ou supprimer celles qui ne vous servent plus.<br/>
Cliquez sur l'onglet <code className="action">Datastore</code> et vérifiez qu'aucune machine virtuelle n'est installée sur le datastore vSAN.

<img className="thumbnail" alt="VSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en11vsanvm.png" loading="lazy" />

#### Suppression des groupes de disques

Pour supprimer toutes les informations de configuration vSAN de vos disques, vous pouvez effacer le groupe de disques créé par vSAN lors de l’activation.<br/>
Dans le menu de configuration du cluster, allez dans <code className="action">vSAN</code> / <code className="action">Gestion de disques</code>.<br/>
Pour chaque groupes de disques, cliquez sur <code className="action">...</code> puis <code className="action">Supprimer</code>.<br/>

<img className="thumbnail" alt="VSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en12vsanremove.png" loading="lazy" />

Vous avez la possibilité de migrer vos données. Si le datastore est vide, aucune migration de données n'est nécessaire.<br/>
Cliquez sur <code className="action">Supprimer</code>.

<img className="thumbnail" alt="VSAN" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en13vsanmig.png" loading="lazy" />

Répétez l’opération sur chacun des nœuds du cluster, jusqu’à la suppression totale des groupes de disques.<br/>
Vous pouvez ignorer les messages d'erreur concernant l'état de santé du groupe de disques.

#### Désactiver les Services.

Comme vous aviez désactivé vSphere HA pour paramétrer vSAN, il vous faut à nouveau la désactiver avant d'arrêter vSAN.

<img className="thumbnail" alt="HA" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en03ha.png" loading="lazy" />

Une fois vSphere HA désactivée, arrêtez le service vSAN dans les paramètres du cluster en cliquant sur <code className="action">Désactiver vSAN</code>.

<img className="thumbnail" alt="SERVICE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en14vsanoff.png" loading="lazy" />

Confirmez par un clic sur <code className="action">Désactiver</code> dans la fenêtre suivante.

<img className="thumbnail" alt="SERVICE" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/vmware-vsan/en15vsanconfirm.png" loading="lazy" />

vSan est désormais désactivé.
