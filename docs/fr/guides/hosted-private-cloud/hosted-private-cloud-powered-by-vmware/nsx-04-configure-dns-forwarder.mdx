## Objectif

Il est possible d'utiliser un redirecteur DNS dans NSX. Son rôle est de centraliser toutes les requêtes DNS et de les rediriger vers des serveurs DNS externes, ce qui permet de réduire le flux réseau. Vous pouvez attacher le redirecteur DNS sur la passerelle nord-sud (ovh-T0-gw) ou la passerelle est-ouest (ovh-T1-gw), en fonction de vos besoins.

**Découvrez comment configurer un redirecteur DNS dans NSX.**

## En pratique

Nous allons créer un redirecteur DNS et l'attacher à la passerelle nord-sud (ovh-T0-gw), il sera utilisable sur l'ensemble des segments de NSX.

### Configuration du redirecteur DNS

Dans l'interface NSX, allez dans l'onglet <code className="action">Networking</code> et cliquez sur <code className="action">DNS</code> à gauche dans la rubrique **IP Management**. Cliquez ensuite sur <code className="action">ADD DNS SERVICE</code>.

<img className="thumbnail" alt="Configure DNS forwarder 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/01-configure-dns-forwarder01.png" loading="lazy" />

Renseignez ces informations :

- **Name** : nom de votre service, par exemple `dns-forwarder`.
- **Tier-0/Tier-1 Gateway** : votre passerelle Nord-Sud `ovh-T0-gw`.
- **DNS Service IP** : adresse IP privée non utilisé dans vos segments comme `192.168.200.1`.

Cliquez ensuite sur les <code className="action">trois points verticaux</code> en dessous de **Default DNS Zone**.

<img className="thumbnail" alt="Configure DNS forwarder 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/01-configure-dns-forwarder02.png" loading="lazy" />

Cliquez sur <code className="action">Add New Default Zone</code>.

<img className="thumbnail" alt="Configure DNS forwarder 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/01-configure-dns-forwarder03.png" loading="lazy" />

Renseignez ces valeurs :

- **Name** : nom de la zone, par exemple `cdns.ovh.net`.
- **DNS Servers** : serveur DNS OVHcloud `213.186.33.99`.

Cliquez ensuite sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="Configure DNS forwarder 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/01-configure-dns-forwarder04.png" loading="lazy" />

Cliquez à nouveau sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="Configure DNS forwarder 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/01-configure-dns-forwarder05.png" loading="lazy" />

Votre redirecteur DNS est actif et utilisable sur tous vos segments en Overlay ou VLAN connectés à votre passerelle nord-sud (ovh-t0-gw).

<img className="thumbnail" alt="Configure DNS forwarder 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/01-configure-dns-forwarder06.png" loading="lazy" />

### Modification du serveur DHCP pour utiliser un redirecteur DNS

Si vous avez configuré des serveurs DHCP dans NSX comme indiqué dans notre guide de [configuration du DHCP](/guides/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-03-configure-dhcp-onsegment/), vous pouvez modifier la configuration pour utiliser le redirecteur DNS dans vos configurations DHCP.

Nous allons voir comment modifier le serveur DNS sur la configuration DHCP d'un de vos segments.

Restez sur l'onglet <code className="action">Networking</code> et cliquez sur <code className="action">Segments</code> à gauche dans la rubrique **Connectivity**. 

Cliquez ensuite sur les <code className="action">trois points verticaux</code> à coté de votre segment et cliquez sur <code className="action">Edit</code> dans le menu.

<img className="thumbnail" alt="Modify DHCP overlay segment 01" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/02-modify-dhcp-overlay-segment01.png" loading="lazy" />

Cliquez sur <code className="action">EDIT DHCP CONFIG</code>.

<img className="thumbnail" alt="Modify DHCP overlay segment 02" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/02-modify-dhcp-overlay-segment02.png" loading="lazy" />

Cliquez sur la <code className="action">croix</code> à droite du DNS existant dans l'option **DNS Servers**, afin de l'enlever de la configuration.

<img className="thumbnail" alt="Modify DHCP overlay segment 03" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/02-modify-dhcp-overlay-segment03.png" loading="lazy" />

Ajoutez, dans **DNS Servers**, l'adresse IP de votre redirecteur DNS, par exemple <code className="action">192.168.200.1</code> et cliquez sur <code className="action">APPLY</code>.

<img className="thumbnail" alt="Modify DHCP overlay segment 04" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/02-modify-dhcp-overlay-segment04.png" loading="lazy" />

Cliquez sur <code className="action">SAVE</code>.

<img className="thumbnail" alt="Modify DHCP overlay segment 05" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/02-modify-dhcp-overlay-segment05.png" loading="lazy" />

Cliquez sur <code className="action">CLOSE EDITING</code>.

<img className="thumbnail" alt="Modify DHCP overlay segment 06" src="/images/hosted-private-cloud/hosted-private-cloud-powered-by-vmware/nsx-04-configure-dns-forwarder/02-modify-dhcp-overlay-segment06.png" loading="lazy" />

Le paramétrage DHCP de votre segment utilise maintenant le redirecteur DNS créé précédemment.
