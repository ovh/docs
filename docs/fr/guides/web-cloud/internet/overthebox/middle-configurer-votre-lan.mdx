## Objectif

Découvrez comment configurer votre réseau local depuis l'interface de votre **OverTheBox**. Ce guide vous permet de :

- Modifier l'adressage du réseau local de l'OverTheBox.
- Modifier la configuration DHCP de l'OverTheBox.
- Modifier la configuration DNS de l'OverTheBox.

## Prérequis

- Une **OverTheBox** fournie par OVHcloud ou une installation depuis [le projet Open Source](/guides/web-cloud/internet/overthebox/advanced-installer-limage-overthebox-sur-votre-materiel/).
- Être connecté à l'interface web de l'**OverTheBox** depuis [overthebox.ovh](http://overthebox.ovh) ou [192.168.100.1](https://192.168.100.1).

## En pratique

### Modifier l'adressage local

- Rendez-vous dans l'onglet <code className="action">Network > Interfaces</code>.
- Cliquez sur le bouton <code className="action">Edit</code> de l'interface `LAN`.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-1-edit-2024.png" loading="lazy" />

:::info
Les plages d'adresses IPv4 privées sont standardisées, votre réseau doit être contenu dans l'une de ces plages :

- 10.0.0.0/8
- 192.168.0.0/16
- 172.16.0.0/12

:::


- Modifiez le paramètre <code className="action">IPv4 address</code> pour modifier l'IP locale de l'**OverTheBox**.
- Modifiez le paramètre <code className="action">IPv4 netmask</code> si vous souhaitez que votre réseau local soit différent d'un sous-réseau `/24`. Un réseau `/24` permet de distribuer 254 IP, il n'est en général pas nécessaire de le modifier.
- Cliquez sur <code className="action">Save</code> pour sauvegarder vos modifications.
- Cliquez sur <code className="action">Save & Apply</code> pour appliquer vos modifications.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-2-generalSettings-2024.png" loading="lazy" />

:::tip[Success]
La plage d'IP hôte du serveur DHCP sera automatiquement mise à jour pour fonctionner avec cette nouvelle IP LAN.

:::


### Modifier la plage du DHCP

- Rendez-vous dans l'onglet <code className="action">Network > Interfaces</code>.
- Cliquez sur le bouton <code className="action">Edit</code> de l'interface `LAN`.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-1-edit-2024.png" loading="lazy" />

:::info
La plage du DHCP doit être incluse dans votre sous-réseau, soit maximum 253 IP pour un réseau `/24`.

:::


- Rendez-vous dans l'onglet <code className="action">DHCP Server</code>.
- Modifiez le paramètre <code className="action">Start</code> pour modifier le début de la plage utilisée par le serveur DHCP.
- Modifiez le paramètre <code className="action">Limit</code> pour modifier le nombre d'IP que le DHCP peut allouer.
- Modifiez le paramètre <code className="action">Lease Time</code> pour modifier la durée de validité d'une allocation DHCP.
- Par défaut, comme dans notre exemple, le serveur DHCP alloue des IP de `192.168.100.100` à `192.168.100.250` pour une durée de `12 heures`.
- Cliquez sur <code className="action">Save</code> pour sauvegarder vos modifications.
- Cliquez sur <code className="action">Save & Apply</code> pour appliquer vos modifications.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-3-DHCPSettings-2024.png" loading="lazy" />

### Désactiver le serveur DHCP

- Rendez-vous dans l'onglet <code className="action">Network > Interfaces</code>.
- Cliquez sur le bouton <code className="action">Edit</code> de l'interface `LAN`.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-1-edit-2024.png" loading="lazy" />

:::warning
Désactiver le DHCP signifie que l'**OverTheBox** n'attribuera plus automatiquement d'IP locale, cette action doit être accompagnée d'une configuration manuelle de vos équipements ou de la présence d'un autre serveur DHCP sur votre réseau local.

:::


- Rendez-vous dans l'onglet <code className="action">DHCP Server</code>.
- Cochez le paramètre <code className="action">Ignore interface</code> pour désactiver le serveur DHCP complètement.
- Cliquez sur <code className="action">Save</code> pour sauvegarder vos modifications.
- Cliquez sur <code className="action">Save & Apply</code> pour appliquer vos modifications.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-4-DisableDHCP-2024.png" loading="lazy" />

### Désactiver l'allocation dynamique du DHCP

- Rendez-vous dans l'onglet <code className="action">Network > Interfaces</code>.
- Cliquez sur le bouton <code className="action">Edit</code> de l'interface `LAN`.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-1-edit-2024.png" loading="lazy" />

:::warning
Désactiver l'allocation dynamique du DHCP signifie que l'**OverTheBox** attribuera automatiquement une IP locale uniquement aux équipements configurés pour recevoir un bail statique.

:::


- Rendez-vous dans l'onglet <code className="action">DHCP Server > Advanced Settings</code>.
- Décochez le paramètre <code className="action">Dynamic DHCP</code> pour désactiver les allocations dynamiques du serveur DHCP.
- Cliquez sur <code className="action">Save</code> pour sauvegarder vos modifications.
- Cliquez sur <code className="action">Save & Apply</code> pour appliquer vos modifications.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-5-DisableDynamicDHCP-2024.png" loading="lazy" />

### Configurer un bail DHCP statique

:::info
Un bail DHCP statique permet d'attribuer toujours la même IP à un appareil du réseau. Cela permet de donner une adresse IP statique à un équipement sans modifier la configuration réseau de l'équipement.

:::


- Rendez-vous dans l'onglet <code className="action">Network > DHCP and DNS</code>.
- Rendez-vous dans la section <code className="action">Static Leases</code>.
- Cliquez sur le bouton <code className="action">Add</code> pour ajouter un nouveau bail statique.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-6-AddDHCPLease-2024.png" loading="lazy" />

:::warning
L'adresse IP utilisée doit être unique pour chaque bail statique. Si deux équipements ont la même adresse, cela créera des conflits réseaux.

:::


- Modifiez le paramètre <code className="action">Hostname</code> pour modifier le nom d'hôte, dans notre exemple l'équipement sera `Laptop`.
- Modifiez le paramètre <code className="action">MAC address</code> pour sélectionner l'adresse MAC sur laquelle s'applique la règle. Vous pouvez la sélectionner dans le menu déroulant si l'appareil est déjà connecté au DHCP de l'**OverTheBox**, ou l'entrer manuellement en remplissant le champ `custom`.
- Modifiez le paramètre <code className="action">IPv4 address</code> pour configurer l'adresse IP que le DHCP allouera à l'équipement. Le serveur DHCP allouera toujours cette adresse IP à l'équipement.
- Si vous le souhaitez, modifiez le paramètre <code className="action">Lease time</code> pour allonger le temps d'allocation du bail DHCP pour cet équipement.
- Cliquez sur <code className="action">Save</code> pour sauvegarder vos modifications.
- Cliquez sur <code className="action">Save & Apply</code> pour appliquer vos modifications.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-7-ConfigureDHCPLease-2024.png" loading="lazy" />

### Configurer les DNS

Par défaut, l'**OverTheBox** utilise les serveurs DNS d'OVHcloud mais vous pouvez les modifier.

- Rendez-vous dans l'onglet <code className="action">Network > DHCP and DNS</code>.
- Rendez-vous dans la section <code className="action">Forwards</code>.
- Modifiez le paramètre <code className="action">DNS Forwards</code> pour configurer les serveurs DNS utilisés par le serveur DHCP.
- Cliquez sur <code className="action">Save</code> pour sauvegarder vos modifications.
- Cliquez sur <code className="action">Save & Apply</code> pour appliquer vos modifications.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-8-ConfigureDNS-2024.png" loading="lazy" />

### Configurer un nom de domaine local

:::warning
Il est possible d'utiliser un nom de domaine avec un TLD officiel, mais vous devez en être le propriétaire pour éviter les conflits réseaux.
Si vous souhaitez obtenir un nom de domaine, consultez [nos offres sur ovhcloud.com](https://www.ovhcloud.com/fr/domains/).

:::


:::info
Depuis août 2024, l'ICANN autorise formellement le TLD `.internal` pour une utilisation au sein d'un réseau privé.

:::


Il est possible de configurer un nom de domaine local qui vous permettra d'accéder directement à vos équipements par un nom de domaine.

- Rendez-vous dans l'onglet <code className="action">Network > DHCP and DNS</code>.
- Rendez-vous dans la section <code className="action">General</code>.
- Modifiez le paramètre <code className="action">Resolve this locally</code> pour indiquer au serveur DHCP qu'il ne doit pas chercher l'équipement sur un DNS externe. Dans notre cas, le nom de domaine utilisé étant `office.internal`, nous indiquons donc `*\.office.internal\`.
- Modifiez le paramètre <code className="action">Local domain</code> pour indiquer au serveur DHCP quel nom de domaine local utiliser. Dans notre cas, le nom de domaine utilisé étant `office.internal`, un serveur **NAS** avec le nom d'hôte `nas` sera accessible via le nom de domaine `nas.office.internal` par les autres équipements présents dans le réseau local de l'**OverTheBox**.
- Cliquez sur <code className="action">Save & Apply</code> pour appliquer vos modifications.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-9-ConfigureDomain-2024.png" loading="lazy" />

### Configurer une option DHCP

- Rendez-vous dans l'onglet <code className="action">Network > Interfaces</code>.
- Cliquez sur le bouton <code className="action">Edit</code> de l'interface `LAN`.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-1-edit-2024.png" loading="lazy" />

- Rendez-vous dans l'onglet <code className="action">DHCP Server > Advanced Settings</code>.
- Modifiez le paramètre <code className="action">DHCP-options</code> avec les paramètres souhaités. Par exemple, pour un serveur **Active Directory** avec l'IP `191.168.100.10`, ajoutez l'option `option:dns-server,192.168.100.10`.
- Cliquez sur `+` pour confirmer vos modifications.
- Cliquez sur <code className="action">Save</code> pour sauvegarder vos modifications.
- Cliquez sur <code className="action">Save & Apply</code> pour appliquer vos modifications.

<img className="thumbnail" alt="overthebox" src="/images/web-cloud/internet/overthebox/middle-configurer-votre-lan/step1-lan-10-OptionsDHCP-2024.png" loading="lazy" />
