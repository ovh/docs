## Objectif

Vous pouvez faire évoluer votre offre OverTheBox pour accéder à de nouvelles fonctionnalités et services.

Le changement d'offre permet de :

- Migrer d'une offre Starter 500Mbps à une offre Business 1Gbps.
- Migrer d'une offre Business 1Gbps à une offre Starter 500 Mbps.
- Migrer d'une ancienne offre de service à une nouvelle offre Starter ou Business.
- Commander un boîtier OTBv3

Lors d'une migration, l'adresse IP de votre service est conservée et votre appareil OverTheBox actuel reste compatible.

## Prérequis

- Disposer d'un service OverTheBox actif.

## En pratique

### Changer d’offre

Depuis votre [espace client OVHcloud](https://manager.eu.ovhcloud.com/#/telecom/overTheBox), sélectionnez le service OverTheBox que vous souhaitez faire évoluer et cliquez sur <code className="action">Changer d'offre</code> dans le cadre « Informations Générales ».

<img className="thumbnail" alt="changement d'offre" src="/images/web-cloud/internet/overthebox/offer-migration/manager-changeOffer-2024.png" loading="lazy" />

La première colonne du tableau récapitule votre offre actuelle (son nom et son tarif). Les autres colonnes concernent les offres auxquelles vous pouvez souscrire.
Dans la deuxième ligne du tableau, vous pouvez, si vous le souhaitez, commander un boîtier OverTheBox v3 en plus de votre changement d'offre.

Une fois votre choix effectué, cliquez sur le bouton <code className="action">Sélectionner</code> sous la colonne correspondant à l'offre que vous souhaitez souscrire.

<img className="thumbnail" alt="selection d'offre" src="/images/web-cloud/internet/overthebox/offer-migration/manager-selectOffer-2024.png" loading="lazy" />

### Sélectionner une adresse de livraison

:::info
Si vous avez choisi l'option <code className="action">Je ne souhaite pas de boîtier</code>, vous pouvez passer à la section « [Valider le changement d'offre](#validation) » de ce guide.

:::


Si vous avez choisi de commander un nouveau boîtier avec votre changement d'offre, vous devez choisir une adresse de livraison.

Par défaut, l'adresse est celle de votre compte OVHcloud. Vous pouvez cependant modifier cette adresse :

- Cliquez sur le bouton <code className="action">+</code> pour renseigner une nouvelle adresse.
- Cliquez sur le bouton <code className="action">loupe</code> pour sélectionner une adresse précédemment renseignée.

Une fois l'adresse saisie, cliquez sur le bouton <code className="action">Sélectionner le contact</code>.

:::info
Les frais de livraison sont inclus dans le prix du boîtier.

:::


<img className="thumbnail" alt="selection d'adresse de livraison" src="/images/web-cloud/internet/overthebox/offer-migration/manager-selectAddress-2024.png" loading="lazy" />

### Valider le changement d'offre <a name="validation"></a>

La page `Résumé du changement d'offre` résume la tarification mensuelle de la nouvelle offre, ainsi que le coût du boîtier (si l'option a été sélectionnée).

Validez les contrats afférents, puis cliquez sur le bouton <code className="action">Valider le changement d'offre</code>.

<img className="thumbnail" alt="validation de la migration" src="/images/web-cloud/internet/overthebox/offer-migration/manager-confirmMigration-2024.png" loading="lazy" />

### Payer le bon de commande

:::info
Une fois le bon de commande payé, le changement d'offre est immédiat si vous n'avez pas choisi de boîtier.
Dans le cas où vous avez choisi un boîtier, le changement d'offre sera réalisé à réception du boîtier.
Un remboursement au prorata de la facturation du mois en cours est alors établi.

:::


Pour finaliser le changement d'offre, ainsi que la livraison du boîtier, vous devez payer le bon de commande généré lors de la confirmation de la migration. Pour ce faire, cliquez sur le lien contenu dans la phrase <code className="action">Pour finaliser la migration de votre offre, vous devez payer le bon de commande.</code>.

:::info
Pour plus d'informations sur le paiement d'un bon de commande, consultez le guide « [Gérer mes commandes OVHcloud](/guides/account-and-service-management/managing-billing-payments-and-services/managing-ovh-orders/) ».

:::
