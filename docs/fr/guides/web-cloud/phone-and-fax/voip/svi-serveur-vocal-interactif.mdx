## Objectif

Configurer un numéro en Serveur Vocal Interactif (SVI) permet de proposer à vos correspondants un menu avec lequel ils pourront interagir, grâce aux touches de leurs téléphones.<br/>
L'exemple le plus courant consiste à orienter un appelant entre plusieurs services d'une société : « *Appuyez sur la touche 1 pour une demande commerciale ou sur la touche 2 pour une demande technique* ».

**Découvrez comment configurer un serveur vocal interactif depuis l'espace client OVHcloud.**

## Prérequis

- Disposer d'un [numéro alias](https://www.ovhtelecom.fr/telephonie/numeros/).

## En pratique

### Étape 1 : Appliquer la configuration « Serveur Vocal Interactif »

- Si votre numéro n'est actuellement pas configuré, cliquez sur l'onglet <code className="action">Configuration</code>, sélectionnez <code className="action">Serveur Vocal Interactif</code> puis cliquez sur <code className="action">Paramétrer</code>.

- Si votre numéro a déjà une configuration en place, cliquez sur l'onglet <code className="action">Configuration</code> puis sur <code className="action">Changer de configuration</code>. Sélectionnez ensuite <code className="action">Serveur Vocal Interactif</code> et cliquez sur <code className="action">Paramétrer</code>. Vous devrez alors confirmer la perte de la configuration actuellement en place.

<img className="thumbnail" alt="sviconfiguration" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/svi-1-2026.png" loading="lazy" />

:::info
Pour appliquer le même type de configuration à plusieurs numéros, cliquez sur <code className="action">Appliquer à plusieurs numéros</code>, sélectionnez les numéros concernés puis cliquez sur <code className="action">Valider</code>.

<img className="thumbnail" alt="configurationnumeroalias" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/selection-alias-conf.png" loading="lazy" />

Cliquez sur le bouton <code className="action">Paramétrer</code> et patientez quelques instants pendant l’application du paramétrage.

Si vous appliquez le même type de configuration à plusieurs numéros, vous devrez finaliser la configuration sur chacun des numéros concernés.

:::


### Étape 2 : Accéder à la configuration du serveur vocal interactif

Une fois la configuration de serveur vocal interactif appliquée, la page de configuration du SVI vous est présentée.

<img className="thumbnail" alt="sviconfiguration" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/2026-VoIP-SVI-01.png" loading="lazy" />

Pour revenir à cette page à tout moment, cliquez sur l'onglet <code className="action">Mon numéro</code> puis, dans le cadre « Configuration », cliquez sur <code className="action">Paramétrer la configuration</code>.

<img className="thumbnail" alt="sviconfiguration" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/svi-1.png" loading="lazy" />

#### Présentation de l'interface

L'interface de configuration du SVI se présente sous la forme d'une arborescence surmontée de deux menus. Un menu supplémentaire est disponible sur chaque étape de l'arborescence.

|Menu du numéro|Menu de la configuration|Menu d'étape|
|---|---|---|

### Étape 3 : Configurer le serveur vocal interactif

Les étapes suivantes peuvent être suivies sans ordre particulier. Néanmoins, à des fins de facilité de prise en main, nous vous recommandons de suivre l'ordre ci-dessous.

#### 3.1 Gérer les sons

**L'ajout d'un son d'accueil est la première étape indispensable pour créer votre SVI**. Ce son d'accueil sera joué dès le début de l'appel. Il précise à l'appelant les différents choix offerts par les touches.

Vous pouvez ajouter plusieurs sons si vous souhaitez créer des choix de touches successifs. En effet, il vous faudra alors un son par menu interactif.
<br/> Nous vous conseillons également de créer un son dédié aux actions invalides. Ainsi, si un appelant compose une touche que vous n'avez pas configurée, un son peut lui rappeler les choix de touches possibles.

:::warning
La création des fichiers-sons est à votre charge. Nous vous conseillons de faire appel à un [prestataire spécialisé](https://partner.ovhcloud.com/fr/) car OVHcloud ne sera pas en mesure de créer ces fichiers pour vous.
<br/>Sachez qu'il est également possible de créer des fichiers-sons via le logiciel open source et gratuit [Audacity](https://www.audacityteam.org/).

:::


Ouvrez le **menu du numéro** puis cliquez sur <code className="action">Gérer les sons</code>.

<img className="thumbnail" alt="gérer les sons" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/gerer-sons-svi.png" loading="lazy" />

Cliquez alors sur <code className="action">Ajouter un son</code> pour téléverser un son depuis votre poste.

#### 3.2 Créer un menu interactif <a name="creer-menu-interactif"></a>

Ouvrez le **menu du numéro** puis cliquez sur <code className="action">Gérer les menus interactifs</code>.

<img className="thumbnail" alt="gérer les menus" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/gerer-menus-svi.png" loading="lazy" />

Sur la nouvelle page qui s'affiche, cliquez sur <code className="action">+ Ajouter un menu interactif</code>.

<img className="thumbnail" alt="sviconfiguration" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/svi-menu-creation.png" loading="lazy" />

Une fenêtre de création s'affiche. Complétez les informations demandées :

|Information|Description|
|---|---|
|Nom du menu interactif|Définissez un nom pour ce menu interactif. Celui-ci ne peut contenir que des lettres (sans accents), des chiffres, des tirets bas ainsi que des espaces.|
|Son d'accueil|Sélectionnez le son qui sera joué dès le début de l'appel. Celui-ci précise à l'appelant les différents choix offerts par les touches.|
|Son en cas d'action invalide|Choisissez le son qui sera joué si l'appelant appuie sur une touche non reconnue par le serveur vocal interactif.|

Une fois les informations renseignées, cliquez sur <code className="action">Créer</code>.

#### 3.3 Ajouter des entrées dans le menu interactif

Une fois votre menu interactif créé, vous pouvez y ajouter des entrées. Pour cela, cliquez sur le bouton <code className="action">+</code> situé en bas de celui-ci.

<img className="thumbnail" alt="sviconfiguration" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/svi-menu-creation-entree.png" loading="lazy" />

Dans la fenêtre qui s'affiche, complétez les informations demandées :

|Information|Description|
|---|---|
|Touche|Définissez la touche d'entrée du menu que vous souhaitez configurer.|
|Action à exécuter|Sélectionnez l'action qui se réalisera lorsque l'appelant appuiera sur la touche correspondante. Aidez-vous des informations qui s'affichent pour choisir l'option la plus adaptée à votre besoin.|
|Paramètre d'action supplémentaire|Selon l'action que vous avez définie, une case supplémentaire peut apparaître et vous inviter à renseigner un élément complémentaire. Suivez alors les indications qui s'affichent.|

Une fois les informations complétées, cliquez sur <code className="action">Créer</code>. Selon vos besoins, répétez ces manipulations si vous voulez créer plusieurs menus interactifs. Vous pourrez alors les imbriquer dans votre serveur vocal interactif en tant que sous-menus, si vous souhaitez par exemple réaliser plusieurs embranchements.

<img className="thumbnail" alt="sviconfiguration" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/svi-sous-menu.png" loading="lazy" />

### Étape 4 : Configurer les étapes et actions

Une fois vos menus interactifs créés, cliquez sur <code className="action">Retour à la configuration du numéro</code>.

Vous devez à présent créer des étapes pour déclencher vos menus interactifs selon vos besoins. Vous pourrez par exemple définir des périodes de disponibilité (plages horaires) et les actions à déclencher en dehors de ces périodes.

#### 4.1 Créer une étape

Pour créer une première étape, ouvrez le **menu de configuration** puis cliquez sur <code className="action">Ajouter une étape</code>.

<img className="thumbnail" alt="sviconfiguration" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/svi-etape2021.png" loading="lazy" />

:::info
Pour réordonner les étapes et actions de votre plan de configuration, cliquez sur le bouton <code className="action">Réordonner les étapes et actions</code> situé en haut à gauche.

Utilisez le bouton dédié (entre chaque étape) pour modifier l'ordre de vos étapes et actions puis validez ce nouvel ordre en cliquant sur <code className="action">Valider les modifications</code>

:::


#### 4.2 Ajouter une action à une étape

Les actions ajoutées à une étape s'activent lorsqu'un appelant contacte votre numéro.

Pour ajouter une action à une étape, cliquez sur le bouton <code className="action">...</code> dans l'étape concernée puis sur <code className="action">Ajouter une action</code>

<img className="thumbnail" alt="sviconfiguration" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/svi-action2021.png" loading="lazy" />

Complétez les informations demandées :

|Information|Description|
|---|---|
|Action à exécuter|Définissez l'action qui sera effectuée lorsque l'appelant contactera votre numéro. Aidez-vous des informations qui s'affichent pour choisir celle la plus adaptée à votre besoin.<br/><br/> Afin de pouvoir utiliser un menu interactif ([créé lors de l'étape 2](#creer-menu-interactif)), vous devez sélectionner l'action « Lancer un menu interactif ».|
|Paramètre d'action supplémentaire|Selon l'action que vous avez définie, une case supplémentaire peut apparaître et vous inviter à renseigner un élément complémentaire. Suivez alors les indications qui s'affichent.|

Une fois les informations complétées, cliquez sur <code className="action">Créer</code>.

<img className="thumbnail" alt="sviconfiguration" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/svi-action2021b.png" loading="lazy" />

Selon vos besoins, répétez ces manipulations si vous souhaitez créer plusieurs actions dans une étape.

:::info
À des fins de lisibilité, vous pouvez choisir à tout moment d'afficher ou masquer toutes les actions définies dans vos étapes. Cliquez sur <code className="action">Options d'affichage</code> en haut à gauche de votre interface puis sur <code className="action">Afficher toutes les actions</code> ou <code className="action">Masquer toutes les actions</code>.

:::


#### 4.3 Ajouter une condition à une étape

Lorsqu'une ou plusieurs conditions sont ajoutées à une étape, celles-ci doivent être remplies pour que l'étape se déclenche. Si les conditions ne sont pas remplies, soit une action correspondant aux **conditions non-vérifiées** se déclenche, soit l'étape suivante de votre plan de configuration se déclenche.

:::tip[Success]
Vous pouvez ainsi faire en sorte que votre SVI se déclenche uniquement lors de vos horaires d'ouverture. En dehors de ces horaires, vous pouvez, par exemple, diffuser un son rappelant les horaires d'ouverture de votre entreprise ou déclencher le [répondeur d'une ligne SIP OVHcloud](/guides/web-cloud/phone-and-fax/voip/configurer-consulter-repondeur-ligne-ovh/).

:::


Pour ajouter une condition à une étape, ouvrez le menu de l'étape via le bouton <code className="action">...</code>, puis choisissez <code className="action">Configuration avancée</code>.

<img className="thumbnail" alt="svi conditions" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/svi-conditions2021.png" loading="lazy" />

Le menu qui apparaît vous permet de définir jusqu'à trois types de conditions.

<img className="thumbnail" alt="svi conditions" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/svi-conditions2021b.png" loading="lazy" />

Une fois vos conditions créées, vous pouvez définir une ou plusieurs action(s) correspondant aux conditions non-vérifiées. Ces actions seront alors prises en compte pour les appels ne remplissant pas les conditions.

Ainsi, dans l'exemple ci-dessous, un appel pendant les plages horaires définies pour l'étape 1 lancera le menu interactif nommé « Menu principal ». (1).
<br/>Un appel en dehors de ces plages horaires sera réceptionné sur le répondeur d'une ligne SIP OVHcloud (2).

<img className="thumbnail" alt="SVI conditions exemple" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/exemple-svi-plages2021.png" loading="lazy" />

Poursuivez la lecture de ce guide selon la condition que vous désirez paramétrer :

- [Condition de « Jours exceptionnels »](#condition-de-jours-exceptionnels)
- [Condition de « Plages horaires génériques »](#condition-de-plages-horaires-generiques)
- [Condition de « Filtrages d'appels »](#condition-de-filtrages-dappels)

##### **Condition de « Jours exceptionnels »** <a name="jours-exceptionnels"></a>

Après avoir cliqué sur <code className="action">Jours exceptionnels</code> depuis le menu de configuration avancée, choisissez le créneau que vous souhaitez appliquer. Vous revenez ensuite automatiquement dans la fenêtre de configuration avancée. Cliquez alors sur <code className="action">Modifier</code>.

<img className="thumbnail" alt="SVI - jours exceptionnels" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/creneaux-activation2021.png" loading="lazy" />

Vous devez à présent configurer le créneau que vous venez de sélectionner (ou vous assurer que celui-ci l'est correctement). Pour cela, ouvrez le **Menu du Numéro** via le bouton <code className="action">...</code> puis cliquez sur <code className="action">Gérer les créneaux exceptionnels</code>.

<img className="thumbnail" alt="gérer créneaux exceptionnels" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/svi-creneaux2021.png" loading="lazy" />

La page de gestion des fermetures exceptionnelles apparaît alors. Dans la partie `Planification des jours de fermeture`, positionnez vos fermetures exceptionnelles sur le calendrier en cliquant sur les jours concernés. Complétez les informations demandées :

|Information|Description|
|---|---|
|Plage horaire/journée entière|Choisissez si la fermeture exceptionnelle concerne uniquement une plage horaire ou une journée entière.|
|Objet|Définissez un titre vous permettant d'identifier cette fermeture exceptionnelle dans le calendrier.|
|Catégorie|Choisissez le créneau dans lequel vous souhaitez ajouter la fermeture exceptionnelle.|
|Du/au|Définissez la date et l'heure (le cas échéant) de la fermeture exceptionnelle.|
|Description|Vous pouvez ajouter une description plus détaillée sur cette fermeture exceptionnelle.|

Une fois les informations renseignées, cliquez sur <code className="action">Créer l'événement</code>. Répétez cette manipulation afin d'ajouter toutes les fermetures exceptionnelles nécessaires. Cliquez enfin sur le bouton <code className="action">Valider</code> pour sauvegarder ces changements.

<img className="thumbnail" alt="gérer fermetures exceptionnels" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/creneaux2021.png" loading="lazy" />

##### **Condition de « Plages horaires génériques »** <a name="plages-horaires"></a>

Après avoir cliqué sur <code className="action">Plages horaires génériques</code> depuis le menu de configuration avancée, cliquez sur <code className="action">Ajouter des plages horaires</code>.

Configurez maintenant les plages horaires qui correspondent à vos besoins. Pour cela, sélectionnez les jours concernés puis renseignez les horaires dans les cases prévues à cet effet. Cliquez sur le bouton <code className="action">V</code> à droite pour enregistrer la plage.

Une fois toutes vos plages horaires définies, cliquez sur le bouton <code className="action">Modifier</code> pour les valider.

<img className="thumbnail" alt="SVI plages horaires" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/plages-svi2021.gif" loading="lazy" />

:::info
Pour modifier une plage horaire déjà créée, il est nécessaire de la supprimer puis de créer une nouvelle plage horaire.

:::


##### **Double condition : « Jours exceptionnels » et « Plages horaires génériques »**

Pour obtenir une configuration contenant à la fois des jours exceptionnels et des plages horaires génériques, il convient de placer les jours exceptionnels sur l'étape 1 et les plages horaires génériques sur l'étape 2.

En effet, le système lit les étapes dans l'ordre : si les conditions de l'étape 1 sont remplies, les actions associées à cette étape sont exécutées. Dans le cas contraire, le système passe automatiquement à l’étape 2.

<img className="thumbnail" alt="SVI - double condition" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/svi-double-condition.png" loading="lazy" />

##### **Condition de « Filtrages d'appels »** <a name="filtrages-appels"></a>

Après avoir cliqué sur <code className="action">Filtrages d'appels</code> depuis le menu de configuration avancée, choisissez si vous souhaitez filtrer vos appels entrants selon une « liste noire » ou une « liste blanche ».

|Liste|Description|
|---|---|
|Liste noire|Les numéros ou les tranches de numéros inscrits dans la liste ne peuvent plus vous contacter.|
|Liste blanche|**Seuls** les numéros ou les tranches de numéros inscrits dans la liste sont autorisés à vous contacter.|

Une fois que vous avez sélectionné la liste que vous souhaitez utiliser, complétez-la en ajoutant les numéros ou les tranches de numéros adéquats. Pour cela, utilisez le champ `Ajouter un numéro à la liste`, puis cliquez sur le bouton <code className="action">Ajouter</code>. Vous pouvez supprimer une entrée dans la liste grâce à l'icône représentant une corbeille.

Pour enregistrer vos modifications, cliquez sur <code className="action">Modifier</code>.

<img className="thumbnail" alt="SVI -filtrages" src="/images/web-cloud/phone-and-fax/voip/svi-serveur-vocal-interactif/filtrages2021.png" loading="lazy" />
