## Objectif

La conférence permet à toutes les personnes composant un numéro donné d’être en communication simultanément. Différentes fonctionnalités sont alors disponibles :

- protéger la conférence par un code ;
- définir une annonce personnalisée ;
- enregistrer les participants et recevoir un rapport par e-mail à la fin de la conférence. 

Une interface spécifique vous propose également de suivre en temps réel les discussions des participants, mais aussi de gérer leur audio et leur micro.

**Découvrez comment créer et gérer des conférences téléphoniques avec votre numéro OVHcloud.**

## Prérequis

- Disposer d'un [numéro alias](https://www.ovhtelecom.fr/telephonie/numeros/).

## En pratique

### Étape 1 : Appliquer la configuration « Conférence »

- Si votre numéro n'est actuellement pas configuré, cliquez sur l'onglet <code className="action">Configuration</code>, sélectionnez <code className="action">Conférence</code> puis cliquez sur <code className="action">Paramétrer</code>.

- Si votre numéro a déjà une configuration en place, cliquez sur l'onglet <code className="action">Configuration</code> puis sur <code className="action">Changer de configuration</code>. Sélectionnez ensuite <code className="action">Conférence</code> et cliquez sur <code className="action">Paramétrer</code>. Vous devrez alors confirmer la perte de la configuration actuellement en place.

L'application de la configuration prend quelques secondes.

<img className="thumbnail" alt="conférence" src="/images/web-cloud/phone-and-fax/voip/conference/conference2026-01.png" loading="lazy" />

:::info
Pour appliquer le même type de configuration à plusieurs numéros, cliquez sur <code className="action">Appliquer à plusieurs numéros</code>, sélectionnez les numéros concernés puis cliquez sur <code className="action">Valider</code>.

<img className="thumbnail" alt="configurationnumeroalias" src="/images/web-cloud/phone-and-fax/voip/conference/selection-alias-conf.png" loading="lazy" />

Cliquez sur le bouton <code className="action">Paramétrer</code> et patientez quelques instants pendant l’application du paramétrage.

Si vous appliquez le même type de configuration à plusieurs numéros, vous devrez finaliser la configuration sur chacun des numéros concernés.

:::


### Étape 2 : Accéder à la configuration de la conférence

Une fois la configuration appliquée, vous accédez directement aux paramètres de la conférence.

Pour retrouver ce menu ultérieurement, cliquez sur l'onglet <code className="action">Configuration</code> puis sur <code className="action">Conférence</code>.

### Étape 3 : Gérer les paramètres de la conférence

#### Configurer la conférence

Dans la partie « Configuration », définissez les paramètres de la conférence.

<img className="thumbnail" alt="conference" src="/images/web-cloud/phone-and-fax/voip/conference/conference2022-02.png" loading="lazy" />

|Paramètres|Description|
|---|---|
|Code PIN d’accès|Le code PIN défini devra être renseigné lorsqu'un participant rejoindra la conférence. Celui-ci doit être compris entre 1 et 8 numéros. Indiquez « 0 » ou laissez la case vide pour ne pas utiliser de code PIN.|
|Annonce personnalisée|Permet de personnaliser l'annonce d'entrée d'un nouveau participant dans la conférence. Pour cela, cliquez sur <code className="action">Ajouter un son</code> puis suivez les étapes qui apparaissent.|
|Enregistrement de la conférence|Permet d'activer ou non l'enregistrement des conférences réalisées sur le numéro.|
|Microphone des participants à l’entrée|Permet d'activer ou de rendre muet le microphone des participants lorsqu'ils rejoignent la conférence.|
|Appels anonymes|Permet d'autoriser ou d'interdire l'accès à la conférence aux numéros anonymes.|
|Langue de votre conférence|Permet de définir la langue de la conférence parmi plusieurs options.|

Cliquez enfin sur le bouton <code className="action">Valider</code> en bas de la page afin de confirmer les changements.

#### Administrer la conférence

Dans la partie « Administration », définissez également vos paramètres.

<img className="thumbnail" alt="conference" src="/images/web-cloud/phone-and-fax/voip/conference/conference2022-03.png" loading="lazy" />

|Paramètres|Description|
|---|---|
|Rapport de la conférence|Permet de définir si vous souhaitez recevoir un rapport concernant l'activité de la conférence ; et si oui, l'adresse e-mail sur laquelle le recevoir.|
|Suivi et contrôle de la conférence|Permet d'activer des liens pour suivre et contrôler la conférence. Pour les activer, cliquez sur <code className="action">Générer les URL</code>. Un bouton à droite de chaque URL vous permet de la copier.<br/><br/> Si des URL sont déjà générées, vous avez la possibilité de :<br/><br/> - **Régénérer les URL** : permet de remplacer les URL existantes par d'autres ;<br/> - **Supprimer les URL** : permet de désactiver le suivi et le contrôle de la conférence.|

Cliquez enfin sur le bouton <code className="action">Valider</code> pour confirmer les changements.

### Étape 4 : Utiliser la conférence

Une fois votre conférence active et paramétrée, celle-ci est prête à être utilisée. Les participants peuvent donc appeler le numéro défini en tant que conférence, puis interagir selon la configuration que vous avez mise en place.

Les participants ont aussi la possibilité de se servir des raccourcis ci-dessous pendant une conférence :

|Raccourcis|Description|
|---|---|
|##|Quitter la conférence|
|00|Désactiver ou activer le mode muet|
|**|Désactiver ou activer le mode muet et sourd|
