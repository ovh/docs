## Objectif

Votre ligne SIP OVHcloud vous permet de recevoir et d’émettre des appels. Pour faciliter les interactions avec vos correspondants, vous pouvez créer un carnet de contacts permettant de retrouver ou d'identifier ceux-ci directement depuis vos téléphones, dans le répertoire ou lors d'un appel entrant.

**Apprenez à gérer le carnet de contacts et les numéros abrégés de vos lignes SIP OVHcloud.**

## Prérequis

- Disposer au moins d'une [ligne SIP OVHcloud](https://www.ovhtelecom.fr/telephonie/voip/).

## En pratique

### Étape 1 : accéder à la gestion du carnet de contacts

Vous pouvez gérer le carnet de contacts d'une seule ligne ou d'un groupe de lignes, permettant ainsi à toutes les lignes rattachées à ce groupe d'en bénéficier.

:::tip[Success]
L'avantage de l'ajout d'un carnet de contacts sur un **groupe de lignes** est qu'il permet d'avoir un carnet **commun** pour toutes les lignes du groupe.

:::


Pour bénéficier d'un carnet de contacts sur une seule ligne SIP, celle-ci doit être associée à un téléphone fourni par OVHcloud.

- **Pour accéder à la gestion du carnet de contacts d'une seule ligne** :

Cliquez sur l'onglet <code className="action">Téléphone</code> puis sur <code className="action">Carnets de contacts</code>.

<img className="thumbnail" alt="carnet de contacts" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/carnetligne.png" loading="lazy" />

- **Pour accéder à la gestion du carnet de contacts d'un groupe de lignes** :

Cliquez sur l'onglet <code className="action">Carnet de contacts</code>.

<img className="thumbnail" alt="carnet de contacts" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/carnetgroupe.png" loading="lazy" />

### Étape 2 : gérer le carnet de contacts

La gestion du carnet de contacts s'effectue de la même manière, que vous ayez sélectionné une seule ligne ou un groupe de lignes. Poursuivez en fonction de la manipulation que vous souhaitez réaliser.

#### Créer un carnet de contacts

Pour créer un carnet de contacts, renseignez le nom du carnet dans la zone de texte en dessous de « Nom du carnet de contacts », puis cliquez sur le bouton <code className="action">Créer le carnet de contacts</code>.

<img className="thumbnail" alt="carnet de contacts" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/creercarnet.png" loading="lazy" />

#### Ajouter ou modifier un contact

Pour ajouter un nouveau contact, cliquez sur le bouton <code className="action">Actions</code>, puis sur <code className="action">Ajouter</code>. Pour modifier un contact existant, cliquez sur le bouton représentant trois points à droite du contact concerné, puis sur <code className="action">Éditer</code>.

<img className="thumbnail" alt="carnet de contacts" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/creercarnetV2.png" loading="lazy" />

Remplissez ensuite les informations demandées. Les numéros doivent être renseignés au format international (par exemple, « 0033123456789 » pour un numéro français). Une fois les informations complétées, cliquez sur le bouton <code className="action">Valider</code> pour ajouter le contact. Répétez cette manipulation autant de fois que nécessaire.

<img className="thumbnail" alt="carnet de contacts" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/carnet-contacts-step5.png" loading="lazy" />

#### Importer des contacts

Pour importer des contacts dans le carnet de contacts, cliquez sur le bouton <code className="action">Actions</code>, puis sur <code className="action">Importer</code>. Dans la fenêtre qui s'affiche, cliquez sur le bouton <code className="action">Fichier de contact</code>. Pour être accepté par l'outil d'import, le fichier doit être au format .csv et respecter une forme précise dans son contenu. Vous trouverez un exemple ci-dessous :

|group|surname|name|workPhone|workMobile|homePhone|homeMobile|countryCode|
|---|---|---|---|---|---|---|---|
|Aucune|OVH|Support|100000000| | |6000000000|33|

Vous pouvez également utiliser une version texte en séparant chaque cellule du tableau par un point-virgule (donnant par exemple : « Aucune;OVH;Support;100000000;;;6000000000;33 »). Une fois le fichier sélectionné dans la fenêtre d'import, cliquez sur le bouton <code className="action">Valider</code>.

:::warning
Si aucun indicatif pays n'est renseigné dans la colonne « countryCode », nous y ajouterons automatiquement l'indicatif correspondant au pays de votre identifiant client. 

:::


<img className="thumbnail" alt="carnetcontacts" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/carnet-contacts-step6.png" loading="lazy" />

#### Télécharger le carnet de contacts

Pour télécharger la liste actuelle des contacts ajoutés dans le carnet, cliquez sur le bouton <code className="action">Actions</code>, puis sur <code className="action">Exporter</code>. Une fenêtre apparaît alors, vous invitant à enregistrer le fichier.

Le fichier obtenu sera au format .csv.

#### Supprimer un ou plusieurs contacts

Pour supprimer un seul contact, cliquez sur le bouton <code className="action">...</code> à droite du contact concerné, puis sur <code className="action">Supprimer</code>. Pour en supprimer plusieurs, cochez la case à gauche des contacts concernés, puis cliquez sur <code className="action">Supprimer les contacts sélectionnés</code>.

<img className="thumbnail" alt="carnetcontacts" src="/images/web-cloud/phone-and-fax/voip/importer-un-carnet-de-contacts/supprimercontact.png" loading="lazy" />

#### Supprimer un carnet de contacts

Pour supprimer un carnet de contacts, cliquez sur le bouton <code className="action">Supprimer le carnet de contacts</code>, puis sur <code className="action">Valider</code>.

### Étape 3 : utiliser le carnet de contacts sur votre téléphone

Afin que votre téléphone puisse utiliser le carnet de contacts ou récupérer les éventuelles modifications effectuées dans celui-ci, commencez par le redémarrer. Une fois votre téléphone redémarré, il devrait avoir téléchargé le nouveau carnet de contacts.
