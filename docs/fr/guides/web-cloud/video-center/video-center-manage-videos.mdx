## Objectif

:::warning
Le Video Center est actuellement en **bêta**. Ses fonctionnalités et son interface sont susceptibles d'évoluer. Ce guide sera mis à jour en conséquence.

:::


L'[OVHcloud Video Center](https://www.ovhcloud.com/fr/web/video-center/) est une solution d'hébergement et de diffusion vidéo hébergée en Europe, sans publicité ni tracking tiers. Elle vous permet d'importer vos vidéos, de les intégrer à n'importe quelle page web via un code iframe, et de les gérer depuis une interface dédiée.

**Ce guide vous explique comment accéder au Video Center depuis votre espace client OVHcloud et gérer vos vidéos : import, intégration iframe, partage, téléchargement et suppression.**

## Prérequis

- Disposer d'un [Video Center OVHcloud](https://www.ovhcloud.com/fr/web/video-center/) actif.

## En pratique

### Accéder au Video Center depuis l'espace client

Rendez-vous dans votre [espace client OVHcloud, section Video Center](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/%23/web/video-center).

La page présente votre abonnement Video Center :

- **Votre offre actuelle** : nom de l'offre souscrite.
- **Nombre de vidéos** : nombre de vidéos déjà hébergées sur votre quota total.
- **Nombre de minutes** : durée cumulée de vos vidéos par rapport au quota de l'offre.

<img className="thumbnail" alt="Page Video Center dans l'espace client OVHcloud avec les compteurs vidéos et minutes" src="/images/web-cloud/video-center/video-center-manage-videos/fr-cp-video-center-detail.png" loading="lazy" />

Pour accéder à l'interface de gestion vidéo, cliquez sur <code className="action">Accéder au Video Center</code>. L'interface s'ouvre dans un nouvel onglet.

### Importer une vidéo

Depuis l'interface Video Center, la zone d'import se situe en haut de la page, sous la barre de navigation.

<img className="thumbnail" alt="Interface principale du Video Center avec la zone d'import et la liste des vidéos" src="/images/web-cloud/video-center/video-center-manage-videos/fr-vc-dashboard.png" loading="lazy" />

2 méthodes sont disponibles :

- **Glisser-déposer** : faites glisser un fichier vidéo depuis votre explorateur de fichiers directement dans la zone délimitée par les pointillés.
- **Parcourir les fichiers** : cliquez sur <code className="action">Parcourir les fichiers</code>, naviguez jusqu'au fichier à importer depuis votre machine locale, puis sélectionnez-le.

:::info
La taille maximale par vidéo est de **500 Mo**. Les formats vidéo courants (MP4, MOV, AVI, etc.) sont acceptés.

:::


Une fois le fichier sélectionné, l'import démarre automatiquement. La vidéo apparaît dans la section **Mes vidéos** une fois le traitement terminé.

### Intégrer une vidéo dans une page web

Le Video Center permet d'intégrer des vidéos dans des pages web via un code iframe.

Dans la section **Mes vidéos**, repérez la vidéo à intégrer et cliquez sur <code className="action">Intégrer</code>.

<img className="thumbnail" alt="Fenêtre d'intégration iframe affichant le code à copier" src="/images/web-cloud/video-center/video-center-manage-videos/fr-vc-integrer-iframe.png" loading="lazy" />

La fenêtre **Intégrer la vidéo** affiche le **code d'intégration iframe**. Cliquez sur l'icône de copie pour le copier dans le presse-papiers, puis collez-le dans le code source HTML de votre page web à l'endroit souhaité.

Cliquez sur <code className="action">Fermer</code> pour refermer la fenêtre.

### Partager une vidéo

Le Video Center vous permet de partager un lien direct vers le lecteur vidéo.

Dans la section **Mes vidéos**, cliquez sur <code className="action">Partager</code> en regard de la vidéo concernée.

<img className="thumbnail" alt="Fenêtre de partage affichant l'URL de partage de la vidéo" src="/images/web-cloud/video-center/video-center-manage-videos/fr-vc-partager.png" loading="lazy" />

La fenêtre **Partager la vidéo** affiche l'**URL de partage**. Cliquez sur l'icône de copie pour la copier, puis transmettez-la à vos destinataires.

Cliquez sur <code className="action">Fermer</code> pour refermer la fenêtre.

### Télécharger ou supprimer une vidéo

Pour accéder aux actions supplémentaires sur une vidéo, cliquez sur le bouton <code className="action">...</code> situé à droite de la vidéo concernée.

<img className="thumbnail" alt="Menu d'actions avec les options Modifier, Télécharger et Supprimer" src="/images/web-cloud/video-center/video-center-manage-videos/fr-vc-actions-menu.png" loading="lazy" />

Le menu propose 3 options :

| Action | Description |
|---|---|
| <code className="action">Modifier</code> | Modifie les informations (titre, tags) de la vidéo. |
| <code className="action">Télécharger</code> | Télécharge le fichier vidéo original sur votre machine locale. |
| <code className="action">Supprimer</code> | Supprime définitivement la vidéo de votre Video Center. |

:::warning
La suppression d'une vidéo est irréversible. Tout code iframe ou lien de partage associé à cette vidéo cessera immédiatement de fonctionner.

:::
