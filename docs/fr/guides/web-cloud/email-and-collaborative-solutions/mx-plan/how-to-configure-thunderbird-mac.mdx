## Objectif

Les comptes e-mail MX Plan peuvent être configurés sur différents logiciels de messagerie compatibles. Cela vous permet d’utiliser votre adresse e-mail depuis l’appareil de votre choix. Thunderbird est un client de messagerie libre et gratuit.

**Découvrez comment configurer votre adresse e-mail MX Plan sur Thunderbird pour macOS.**

## Prérequis

- Disposer d'une offre MX Plan. Celle-ci est disponible via :
    - Une offre d’[hébergement web](https://www.ovhcloud.com/fr/web-hosting/).
    - Un [hébergement gratuit 100M](https://www.ovhcloud.com/fr/domains/free-web-hosting/) compris avec un nom de domaine (activé au préalable).
    - Une offre MX Plan commandée séparément.
    - Disposer d’une adresse e-mail [Zimbra Starter](https://www.ovhcloud.com/fr/emails/zimbra-emails/).
- Disposer du logiciel Thunderbird installé sur votre Mac.
- Posséder les identifiants relatifs à l'adresse e-mail que vous souhaitez paramétrer.

## En pratique

### Ajouter le compte

- **Lors du premier démarrage de l'application** : un assistant de configuration s'affiche et vous invite à renseigner votre adresse e-mail.

- **Si un compte est déjà paramétré sur l'application** :

    1. Cliquez sur le menu <code className="action">☰</code> dans la barre horizontale supérieure.
    2. Cliquez sur <code className="action">Nouveau Compte</code>.
    3. Cliquez sur <code className="action">Adresse E-mail</code>.

<img className="thumbnail" alt="thunderbird" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/how-to-configure-thunderbird-mac/configuration-thunderbird-mac-01.png" loading="lazy" />

:::warning
Il est nécessaire de bien relever la valeur correspondante à votre localisation (**EUROPE** ou **AMERIQUE / ASIE-PACIFIQUE**).

:::


Suivez les étapes de configuration en cliquant successivement sur les **5** onglets ci-dessous :

<Tabs>
  <Tab label="Étape 1">
    Dans la fenêtre qui s'affiche, saisissez les 2 informations suivantes :
    
     - Votre nom complet (nom d'affichage).
     - L'adresse e-mail à paramétrer.
    
    Cliquez sur <code className="action">Continuer</code> pour compléter les paramètres.
    
    <img className="thumbnail" alt="thunderbird" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/how-to-configure-thunderbird-mac/configuration-thunderbird-mxplan-02.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Lorsque Thunderbird détecte un nom de domaine OVHcloud, une configuration automatique relative à l'offre MX Plan est proposée :
    
     - Si les informations sont correctes, cliquez sur <code className="action">Continuer</code> et passez à l'étape 5.
     - Sinon, cliquez sur <code className="action">MODIFIER LA CONFIGURATION</code> pour effectuer une configuration manuelle.
    
    <img className="thumbnail" alt="thunderbird" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/how-to-configure-thunderbird-mac/configuration-thunderbird-ssl0-03.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Paramètres du serveur de réception :
    
     - **Protocole** : IMAP
     - **Nom d'hôte EUROPE (entrant)** : imap.mail.ovh.net **ou** ssl0.ovh.net
     - **Nom d'hôte AMERIQUE/ASIE-PACIFIQUE (entrant)** : imap.mail.ovh.ca
     - **Port** : 993
     - **Sécurité de la connexion** : SSL/TLS
     - **Méthode d'authentification** : Mot de passe normal
     - **Nom d'utilisateur** : Votre adresse e-mail complète
    
    <img className="thumbnail" alt="thunderbird" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/how-to-configure-thunderbird-mac/configuration-thunderbird-mxplan-04.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Paramètres du serveur d'envoi :
    
     - **Protocole** : SMTP
     - **Serveur EUROPE (sortant)** : smtp.mail.ovh.net **ou** ssl0.ovh.net
     - **Serveur AMERIQUE/ASIE-PACIFIQUE (sortant)** : smtp.mail.ovh.ca
     - **Port** : 587
     - **Sécurité de la connexion** : STARTTLS
     - **Méthode d'authentification** : Mot de passe normal
     - **Nom d'utilisateur** : Votre adresse e-mail complète
    
    1\. Cliquez sur <code className="action">Tester</code> pour vérifier les paramètres saisis.
    
    2\. Cliquez sur <code className="action">Continuer</code> pour valider ces paramètres.
    
    <img className="thumbnail" alt="thunderbird" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/how-to-configure-thunderbird-mac/configuration-thunderbird-mxplan-05.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 5">
    Saisissez le mot de passe associé à l'adresse e-mail, puis cliquez sur <code className="action">Continuer</code> pour finaliser la configuration.
    
    <img className="thumbnail" alt="thunderbird" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/how-to-configure-thunderbird-mac/configuration-thunderbird-password-06.png" loading="lazy" />
  </Tab>
</Tabs>


:::info
**Configuration POP**

Si vous souhaitez une configuration POP pour votre adresse e-mail, remplacez les paramètres de **l'étape 3** par les suivants :

Paramètres du serveur de réception :

- **Protocole** : POP3
- **Nom d'hôte EUROPE (entrant)** : pop.mail.ovh.net **ou** ssl0.ovh.net
- **Nom d'hôte AMERIQUE/ASIE-PACIFIQUE (entrant)** : pop.mail.ovh.ca
- **Port** 995
- **Sécurité de la connexion** : SSL/TLS
- **Méthode d'authentification** : Mot de passe normal
- **Nom d'utilisateur** : Votre adresse e-mail complète

:::

**Configuration POP**

Si vous souhaitez une configuration POP pour votre adresse e-mail, remplacez les paramètres de l'étape 3 par les suivants :

Paramètres du serveur de réception :

- Protocole : POP3
- Nom d'hôte EUROPE (entrant) : pop.mail.ovh.net ou ssl0.ovh.net
- Nom d'hôte AMERIQUE/ASIE-PACIFIQUE (entrant) : pop.mail.ovh.ca
- Port 995
- Sécurité de la connexion : SSL/TLS
- Méthode d'authentification : Mot de passe normal
- Nom d'utilisateur : Votre adresse e-mail complète


### Utiliser l'adresse e-mail

Une fois votre adresse e-mail configurée, vous pouvez commencer à l'utiliser ! Vous pouvez dès à présent envoyer et recevoir des e-mails.

OVHcloud propose également une application web permettant d'accéder à votre adresse e-mail depuis un navigateur Internet. Pour accéder au Webmail OVHcloud, cliquez sur [ce lien](https://www.ovhcloud.com/fr/mail/). Vous pouvez vous y connecter grâce aux identifiants de votre adresse e-mail.

### Récupérer une sauvegarde de votre adresse e-mail

Si vous devez effectuer une manipulation qui risquerait d'entrainer la perte des données de votre compte e-mail, nous vous conseillons d'effectuer une sauvegarde préalable du compte e-mail concerné. Pour ce faire, consultez le paragraphe « **Exporter** » dans la partie « **Thunderbird** » de notre guide « [Migrer manuellement votre adresse e-mail](/guides/web-cloud/email-and-collaborative-solutions/migrating/manual-email-migration/) ».

### Modifier les paramètres existants

Si votre compte e-mail est déjà paramétré et que vous devez accéder aux paramètres du compte pour les modifier :

1. Cliquez sur le menu <code className="action">☰</code> dans la barre horizontale supérieure.
2. Cliquez sur <code className="action">Paramètres des comptes</code>.

<img className="thumbnail" alt="Thunderbird" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/how-to-configure-thunderbird-mac/configuration-thunderbird-mac-07.png" loading="lazy" />

- Pour modifier les paramètres liés à la **réception** de vos e-mails, cliquez sur <code className="action">Paramètres serveur</code> dans la colonne de gauche sous votre adresse e-mail.

<img className="thumbnail" alt="thunderbird" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/how-to-configure-thunderbird-mac/configuration-thunderbird-mxplan-mac-08.png" loading="lazy" />

- Pour modifier les paramètres liés à **l'envoi** de vos e-mails, cliquez sur <code className="action">Serveur sortant (SMTP)</code> tout en bas de la colonne de gauche.
- Cliquez sur l'adresse e-mail concernée dans la liste, puis cliquez sur <code className="action">Modifier</code>.

<img className="thumbnail" alt="thunderbird" src="/images/web-cloud/email-and-collaborative-solutions/mx-plan/how-to-configure-thunderbird-mac/configuration-thunderbird-mxplan-mac-09.png" loading="lazy" />
