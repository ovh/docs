## Objectif

Vous souhaitez sauvegarder vos comptes e-mail hébergés sur une plateforme Private Exchange OVHcloud ? Utilisez le logiciel Veeam Backup for Microsoft 365. Ce guide vous détaille tous les éléments nécessaires pour installer, configurer et utiliser Veeam Backup pour vos comptes e-mail.

**Découvrez comment sauvegarder les comptes e-mail de votre plateforme Private Exchange avec Veeam Backup for Microsoft 365.**

## Prérequis

- Avoir souscrit à une [offre Private Exchange OVHcloud](https://www.ovhcloud.com/fr/emails/private-exchange/) et créé des comptes e-mails sur celle-ci.
- [Télécharger Veeam Backup for Microsoft 365](https://www.veeam.com/products/free/backup-microsoft-office-365.html) sur un ordinateur sous Microsoft Windows 10 minimum.

## En pratique

### Installer Veeam Backup <a name="install-veeam"></a>

Téléchargez la dernière version de [Veeam Backup for Microsoft 365](https://www.veeam.com/products/free/backup-microsoft-office-365.html) depuis le site de Veeam.

Suivez les étapes d'installation en cliquant successivement sur les 8 onglets ci-dessous :

<Tabs>
  <Tab label="Etape 1">
    - Lancez le fichier téléchargé au format `.iso` pour monter le DVD virtuel.
    - Ouvrez le DVD virtuel `Veeam Backup for Microsoft 365` monté sur votre ordinateur, puis exécutez le fichier d'installation `Veeam.Setup.exe`.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup01-2.png" loading="lazy" />
  </Tab>
  <Tab label="Etape 2">
    Cliquez sur <code className="action">Install</code>, puis sélectionnez le premier élément de la liste `Veeam Backup for Microsoft 365` pour installer l'ensemble des composants.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup02.png" loading="lazy" />
  </Tab>
  <Tab label="Etape 3">
    Lisez et validez les conditions générales d'utilisation de Veeam Backup en cliquant sur <code className="action">I Accept</code>.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup03.png" loading="lazy" />
  </Tab>
  <Tab label="Etape 4">
    - Si vous possédez une licence Veeam Backup, vous pouvez la charger depuis votre ordinateur en cliquant sur le bouton <code className="action">Browse...</code>.
    - Laissez la case `Update license automatically` cochée.
    - Cliquez sur <code className="action">Next</code> pour passer à l'étape suivante.
    
    :::info
    Sans licence, l'utilisation de Veeam Backup est **limitée à 10 comptes e-mail**.

    :::

    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup04.png" loading="lazy" />
  </Tab>
  <Tab label="Etape 5">
    - Le tunnel d'installation définit automatiquement les identifiants de l'instance de base de données et du serveur NATS. Récupérez les éléments indiqués sur la fenêtre ci-dessous ou cliquez sur <code className="action">Customize Settings</code> pour définir vous-même les paramètres.
    - Lancez l'installation en cliquant sur <code className="action">Install</code>.
    - À l'issue de cette installation, vous pouvez passer au chapitre [Configurer Veeam Backup](#configure-veeam).
    
    :::warning
    Si Veeam Backup a déjà été installé sur votre ordinateur et/ou que vous n'obtenez pas la même fenêtre que ci-dessous, **passez à l'étape 6**.

    :::

    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup05bis.png" loading="lazy" />
  </Tab>
  <Tab label="Etape 6">
    - Si vous n'avez pas d'instance de base de données Veeam Backup, vous pouvez en créer une en cliquant directement sur <code className="action">Next</code>.
    - **OU** vous pouvez vous connecter à une instance existante en sélectionnant `Use existing instance` et `Native authentication with the following credentials`, puis en remplissant les informations de connexion.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup05.png" loading="lazy" />
  </Tab>
  <Tab label="Etape 7">
    - Pour une nouvelle instance, saisissez un nom d'utilisateur (`Username`) et un mot de passe (`Password`) fort. Si vous avez déjà une instance existante, sélectionnez `Use existing instance` et saisissez les informations correspondantes.
    - Cliquez sur <code className="action">Next</code> pour passer à l'étape suivante.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup06.png" loading="lazy" />
  </Tab>
  <Tab label="Etape 8">
    Lancez l'installation en cliquant sur <code className="action">Install</code>.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup07.png" loading="lazy" />
  </Tab>
</Tabs>


### Configurer Veeam Backup <a name="configure-veeam"></a>

#### Connecter Veeam Backup à votre plateforme Exchange

Découvrez comment ajouter votre plateforme Exchange à Veeam Backup avant de pouvoir créer des opérations de sauvegarde sur vos comptes e-mail.

Suivez les étapes de configuration en cliquant successivement sur les 10 onglets ci-dessous :

<Tabs>
  <Tab label="Etape 1">
    Lancez l'application `Veeam Backup for Microsoft 365` depuis le menu Windows ou sur votre bureau.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup08.png" loading="lazy" />
  </Tab>
  <Tab label="Etape 2">
    Par défaut, Veeam Backup vous propose de vous connecter en local sur votre ordinateur. Cliquez sur <code className="action">Connect</code>.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup09.png" loading="lazy" />
  </Tab>
  <Tab label="Etape 3">
    Si vous n'avez pas renseigné de licence, un message vous rappelle que vous êtes limité à 10 utilisateurs (10 comptes e-mail). Cliquez sur <code className="action">No</code> pour continuer ou sur <code className="action">Yes</code> si vous souhaitez associer une licence à votre installation.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup10.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Cliquez sur <code className="action">Add Org</code> en haut à gauche de votre fenêtre.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup11.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 5">
    Dans le menu déroulant `Select organization deployment type`, sélectionnez <code className="action">On-premise</code>, puis désélectionnez `Sharepoint Server`.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup12.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 6">
    Avant de poursuivre, vous devez créer un utilisateur appelé « Impersonate User » sur votre plateforme Exchange. Pour créer ce type d'utilisateur, connectez-vous aux [API OVHcloud](https://eu.api.ovh.com/) et utilisez l'appel API suivant:
    
    <Api version="v1" section="/email/exchange" method="POST" route={"/email/exchange/\\{organizationName\\}/service/\\{exchangeService\\}/impersonatedUser"} />    - Dans les cases `exchangeService` et `organizationName` , renseignez la référence de votre plateforme Exchange. Cliquez sur [ce lien](https://manager.eu.ovhcloud.com/#/web/exchange) pour accéder à la section <code className="action">Exchange</code>, puis sélectionnez la plateforme concernée pour retrouver sa référence.
    
    - Saisissez un mot de passe de 15 caractères minimum entre les guillemets, à côté de `"password": `.
    
    - Cliquez sur <code className="action">Execute</code> plus bas pour lancer la création de votre « Impersonate User ».
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup13.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 7">
    Récupérez le nom de votre « Impersonate User » avec l'appel API suivant :
    
    <Api version="v1" section="/email/exchange" method="GET" route={"/email/exchange/\\{organizationName\\}/service/\\{exchangeService\\}/impersonatedUser"} />    - Dans les cases `exchangeService` et `organizationName` , renseignez la référence de votre plateforme Exchange que vous avez récupérée à l'étape précédente.
    
    - Cliquez sur <code className="action">Execute</code> plus bas.
    
    - Le nom du « Impersonate User » correspond à la valeur `"upn": ` visible dans la `REPONSE` de l'appel API.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup14.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 8">
    - Relevez le nom d'hôte de votre plateforme Exchange. Cliquez sur [ce lien](https://manager.eu.ovhcloud.com/#/web/exchange) pour accéder à la section <code className="action">Exchange</code>, puis sélectionnez la plateforme concernée.
    
    - Le nom d'hôte correspond à la valeur mentionnée pour accéder au webmail.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup15.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 9">
    Depuis l'interface Veeam Backup, saisissez les informations suivantes :
    
    - `Server name` : Nom d'hôte de la plateforme Exchange relevé à l'étape 8, renseignez-le sans le `https://`.
    - `Username` : Nom d'utilisateur relevé à l'étape 7 correspondant à l'« Impersonate User ».
    - `Password` : Mot de passe de l' « Impersonate User » défini à l'étape 6.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup16.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 10">
    - Vous devriez obtenir les mêmes résultats que sur la capture d'écran ci-dessous (ne tenez pas compte de l'avertissement `Check ApplicationImpersanation role`).
    - Cliquez sur <code className="action">Finish</code> pour terminer la connexion avec la plateforme Exchange.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup17.png" loading="lazy" />
  </Tab>
</Tabs>


#### Créer des opérations de sauvegarde de comptes e-mail

Une fois que votre plateforme Exchange a été ajoutée à Veeam backup, découvrez comment créer une opération de sauvegarde pour vos comptes e-mail.

Suivez les étapes de création en cliquant successivement sur les 9 onglets ci-dessous :

<Tabs>
  <Tab label="Étape 1">
    Votre serveur Exchange est visible dans la colonne `Organization` à gauche. Sélectionnez-le.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup18.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Faites un clic droit dans la fenêtre au centre et cliquez sur <code className="action">Add to backup job...</code>.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup19.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Saisissez un nom et une description pour votre opération de sauvegarde, puis cliquez sur <code className="action">Next</code>.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup20.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    - Sélectionnez <code className="action">Back up the following object</code>.
    - Cliquez sur <code className="action">Add</code>, puis sur <code className="action">Users</code>.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup21.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 5">
    Depuis cette fenêtre, déterminez si votre opération de sauvegarde agit sur un ou plusieurs comptes à la fois.
    
    - Sélectionnez le ou les comptes e-mail que vous souhaitez attribuer à votre opération de sauvegarde.
    - Cliquez sur <code className="action">Add</code> lorsque vous avez terminé votre sélection.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup22.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 6">
    - Les éléments sélectionnés apparaissent dans la fenêtre.
    - Cliquez sur <code className="action">Next</code> pour passer à l'étape suivante.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup23.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 7">
    Depuis cette fenêtre, vous pouvez ajouter des règles d'exclusion avec le bouton <code className="action">Add</code>. Celles-ci seront appliquées sur les comptes e-mail sélectionnés précédemment. Vous pouvez par exemple exclure un calendrier ou un dossier spécifique.
    
    :::warning
    Si vous souhaitez des règles d'exclusion spécifiques pour chacun des comptes e-mail, il sera nécessaire de créer plusieurs opérations de sauvegarde pour chaque compte e-mail.

    :::

    
    - Cliquez sur <code className="action">Next</code> pour passer à l'étape suivante.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup24.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 8">
    Sélectionnez le dépôt de sauvegarde qui se situe, par défaut, sur votre ordinateur.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup25.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 9">
    - Depuis cette fenêtre, définissez les options de planification de sauvegarde si vous le souhaitez.
    - Cochez `Start the job` si vous souhaitez lancer l'opération de sauvegarde immédiatement.
    - Cliquez sur <code className="action">Create</code> pour terminer la création de l'opération de sauvegarde.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup26.png" loading="lazy" />
  </Tab>
</Tabs>


#### Lancer une opération de sauvegardes de comptes e-mail

Lorsqu'une opération de sauvegarde est créée, découvrez comment la lancer et récupérer la sauvegarde.

Suivez les étapes de lancement en cliquant successivement sur les 4 onglets ci-dessous :

<Tabs>
  <Tab label="Étape 1">
    Dans la liste des opérations de sauvegarde, sélectionnez celle que vous souhaitez lancer, faites un clic droit dessus puis cliquez sur <code className="action">Start</code>.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup27.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Une fois l'opération terminée, dans la partie inférieure de votre interface Veeam Backup, vous retrouverez le rapport de sauvegarde.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup28.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    - Cliquez sur <code className="action">Explore</code> dans la barre de menu horizontale supérieure.
    - Choisissez la dernière sauvegarde avec le bouton <code className="action">Explore lastest Exchange state of...</code> **ou** choisissez d'autres sauvegardes via <code className="action">Explore Exchange point-in-time state...</code>.
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup29.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Dans la colonne de gauche, vous obtenez la liste de vos comptes e-mail sauvegardés. Faites un clic droit sur le compte e-mail de votre choix. Deux choix vous sont alors proposés  :
    
    - Exporter une sauvegarde dans un fichier `.pst` à l'aide des boutons <code className="action">Export to...</code>
    - Restaurer directement une sauvegarde sur un compte e-mail à l'aide des boutons <code className="action">Restore to...</code>
    
    <img className="thumbnail" alt="veeam backup exchange" src="/images/web-cloud/email-and-collaborative-solutions/microsoft-exchange/exchange-veeam-backup/exchange_veeam_backup30.png" loading="lazy" />
  </Tab>
</Tabs>
