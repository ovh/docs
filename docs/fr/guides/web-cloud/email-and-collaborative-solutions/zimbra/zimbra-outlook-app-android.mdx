## Objectif

:::info
Ce guide s'adresse aux clients possédant une offre e-mail [Zimbra Pro](https://www.ovhcloud.com/fr/emails/zimbra-emails/). Ce service sera disponible en bêta à partir de juillet 2025.

:::


Les comptes Zimbra Pro peuvent être configurés sur un mobile Android en utilisant le protocole ActiveSync. Cela vous permet de configurer l'ensemble des fonctionnalités collaboratives de votre adresse e-mail en une seule fois. L'application Outlook de Microsoft sur Android est disponible gratuitement depuis le Google Play Store.

**Découvrez comment configurer votre adresse e-mail Zimbra Pro sur l'application mobile Outlook pour Android via le protocole ActiveSync.**

OVHcloud met à votre disposition des services dont la configuration, la gestion et la responsabilité vous incombent. Il est de votre responsabilité d'assurer le bon fonctionnement de ces services.

Ce guide est conçu pour vous aider à accomplir des tâches courantes. ## Prérequis

- Disposer d’une adresse e-mail [Zimbra Pro](https://www.ovhcloud.com/fr/emails/zimbra-emails/).
- Disposer de l'[application Outlook](https://play.google.com/store/apps/details?id=com.microsoft.office.outlook&hl=fr) sur votre appareil mobile Android.
- Posséder les identifiants relatifs à l'adresse e-mail que vous souhaitez paramétrer.

:::info
Cette documentation a été réalisée depuis un appareil utilisant la version 14 d'Android.

:::


## En pratique

### Ajouter le compte <a name="add-account"></a>

- **Lors du premier démarrage de l'application Outlook**, un assistant de configuration s'affiche :
    - Appuyez sur <code className="action">Ajouter un compte</code>.

  <img className="thumbnail" alt="outlook android" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-android/outlook-app-android-add01.png" loading="lazy" />

- **Si un compte est déjà paramétré sur l'application Outlook** :
    - Appuyez sur l'enveloppe (<code className="action">✉</code>) dans la partie supérieure gauche de votre écran.
    - Appuyez ensuite sur le bouton <code className="action">+</code> dans la barre verticale de gauche.
    - Appuyez sur <code className="action">Ajouter un compte</code>.

  <img className="thumbnail" alt="outlook android" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-android/outlook-app-android-add02.png" loading="lazy" />

Suivez les étapes d'installation en cliquant successivement sur les **3** onglets ci-dessous :

  <Tab label="Étape 1">
    Saisissez votre adresse e-mail et appuyez sur <code className="action">Continuer</code>.
    
    <img className="thumbnail" alt="outlook android" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-android/outlook-app-android-add-step01.png" loading="lazy" />

    - Sélectionnez **Exchange** dans la liste des types de compte.

Sur la fenêtre suivante, appuyez sur le bouton <code className="action">?</code> dans le coin supérieur droit de l'écran, puis choisissez <code className="action">Changer de fournisseur de compte</code>. Sélectionnez alors `Exchange`.
    
    <img className="thumbnail" alt="outlook android" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-android/outlook-app-android-add-step021.png" loading="lazy" />

    - **Description** : Renseignez un nom permettant d'identifier ce compte parmi vos autres comptes e-mail enregistrés sur Outlook.

### Utiliser l'adresse e-mail

Une fois l'adresse e-mail configurée, vous pouvez commencer à l'utiliser ! Vous pouvez dès à présent envoyer et recevoir des messages, mais aussi gérer vos calendriers et tâches.

OVHcloud propose également une application web permettant d'accéder à votre adresse e-mail depuis un navigateur Internet. Vous pouvez connecter au [webmail OVHcloud](https://www.ovhcloud.com/fr/mail/) avec les identifiants de votre adresse e-mail. Pour toute question relative à son utilisation, consultez notre guide « [Utiliser le webmail Zimbra](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-zimbra/) ».

### Comment modifier les paramètres existants ? <a name="modify-settings"></a>

L'application Outlook ne permet pas de modifier les paramètres serveur de votre compte e-mail.

Si votre compte e-mail est déjà configuré et que vous souhaitez en modifier les paramètres, vous devez alors le supprimer et le recréer :

1. Appuyez sur l'enveloppe (<code className="action">✉</code>) dans la partie supérieure gauche de votre écran.
2. Appuyez sur l'icône de réglage (<code className="action">⛭</code>) dans le bas de la colonne de gauche.
3. Dans la section « Général » appuyez sur `Comptes` pour visualiser l'ensemble des adresses e-mail configurées sur l'application.

  <img className="thumbnail" alt="outlook android" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-android/outlook-app-android-delete-account-01.png" loading="lazy" />

4. Sélectionnez le compte e-mail concerné.
5. Appuyez sur <code className="action">Supprimer le compte</code>.
6. Appuyez sur <code className="action">Supprimer</code> lorsque la question « Voulez-vous supprimer le compte ? » apparaît.

  <img className="thumbnail" alt="outlook android" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-android/outlook-app-android-delete-account-02.png" loading="lazy" />

:::tip[Success]
Une fois votre compte e-mail supprimé, suivez les étapes d'installation indiquées dans la rubrique « [Ajouter le compte](#add-account) » de ce guide.

:::
