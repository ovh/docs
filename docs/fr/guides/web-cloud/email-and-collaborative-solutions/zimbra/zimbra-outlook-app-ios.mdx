## Objectif

:::info
Ce guide s'adresse aux clients possédant une offre e-mail [Zimbra Pro](https://www.ovhcloud.com/fr/emails/zimbra-emails/). Ce service sera disponible en bêta à partir de juillet 2025.

:::


Les comptes Zimbra Pro peuvent être configurés sur un iPhone en utilisant le protocole ActiveSync. Cela vous permet de configurer l'ensemble des fonctionnalités collaboratives de votre adresse e-mail en une seule fois. L'application Outlook de Microsoft sur iOS est disponible gratuitement depuis l'App Store d'Apple.

**Découvrez comment configurer votre adresse e-mail Zimbra Pro sur l'application mobile Outlook pour iOS via le protocole ActiveSync.**

## Prérequis

- Disposer d’une adresse e-mail [Zimbra Pro](https://www.ovhcloud.com/fr/emails/zimbra-emails/).
- Disposer de l'application [Outlook pour iOS](https://apps.apple.com/app/microsoft-outlook/id951937596).
- Posséder les identifiants relatifs à l'adresse e-mail que vous souhaitez paramétrer.

## En pratique

### Ajouter le compte <a name="add-account"></a>

- **Lors du premier démarrage de l'application Outlook**, un assistant de configuration s'affiche :
    - Appuyez sur <code className="action">Ajouter un compte</code>.

  <img className="thumbnail" alt="outlook ios" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-ios/outlook-app-ios-add-01.png" loading="lazy" />

- **Si un compte est déjà paramétré sur l'application Outlook** :
    1. Appuyez sur le cercle contenant les initiales du compte e-mail consulté ou sur l'icône de maison (<code className="action">⌂</code>) dans la partie supérieure gauche de votre écran.
    2. Appuyez sur l'engrenage (<code className="action">⛭</code>) dans la partie inférieure gauche de votre écran.
    3. Appuyez ensuite sur <code className="action">Comptes</code> dans le menu **Réglages**.
    4. Appuyez sur <code className="action">Ajouter un compte</code>.
    5. Appuyez sur <code className="action">Compte de courrier</code>.

  <img className="thumbnail" alt="outlook ios" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-ios/outlook-app-ios-add-02.png" loading="lazy" />

Suivez les étapes d'installation en cliquant successivement sur les **3** onglets ci-dessous :

<Tabs>
  <Tab label="Étape 1">
    Saisissez votre adresse e-mail et appuyez sur <code className="action">Ajouter un compte</code>.
    
    <img className="thumbnail" alt="outlook ios" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-ios/outlook-app-ios-add-step-01.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Deux scénarios sont possibles :
    
    - Si la mention « **IMAP** » est présente en haut de la page : appuyez sur le bouton `?` dans le coin supérieur droit de l'écran **(1)**, puis choisissez <code className="action">Changer de fournisseur de compte</code> **(2)**. Sélectionnez alors `Exchange` **(3)** et passez à l'étape 3.
    
    <img className="thumbnail" alt="outlook ios" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-ios/outlook-app-ios-add-step-02.png" loading="lazy" />
    
    - Si vous êtes directement dirigé vers le choix du type de compte, sélectionnez `Exchange`.
  </Tab>
  <Tab label="Étape 3">
    Dans la fenêtre suivante, cochez <code className="action">Paramètres avancés</code> et complétez les informations suivantes :
    
    - **Adresse e-mail** : Saisissez votre adresse e-mail complète.
    - **Mot de passe** : Saisissez le mot de passe associé à votre adresse e-mail.
    - **Description** : Renseignez un nom permettant d'identifier ce compte parmi vos autres comptes e-mail enregistrés sur Outlook.
    - **Serveur** : saisissez « zimbra1.mail.ovh.net ».
    - **Domaine** : Laissez ce champ vide.
    - **Nom d'utilisateur** : Saisissez votre adresse e-mail complète.
    
    Pour finaliser la configuration, appuyez sur <code className="action">Connexion</code>.
    
    <img className="thumbnail" alt="outlook ios" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-ios/outlook-app-ios-add-step-03.png" loading="lazy" />
  </Tab>
</Tabs>


:::warning
Si vous rencontrez un défaut d'envoi ou de réception après avoir suivi les étapes de configuration ci-dessus, consultez la rubrique « [Modifier les paramètres existants](#modify-settings) » de ce guide.

### Utiliser l'adresse e-mail

Une fois l'adresse e-mail configurée, vous pouvez commencer à l'utiliser ! Vous pouvez dès à présent envoyer et recevoir des messages, mais aussi gérer vos calendriers et tâches.

OVHcloud propose également une application web permettant d'accéder à votre adresse e-mail depuis un navigateur Internet. Vous pouvez connecter au [webmail OVHcloud](https://www.ovhcloud.com/fr/mail/) avec les identifiants de votre adresse e-mail. Pour toute question relative à son utilisation, consultez notre guide « [Utiliser le webmail Zimbra](/guides/web-cloud/email-and-collaborative-solutions/mx-plan/email-zimbra/) ».

### Comment modifier les paramètres existants ? <a name="modify-settings"></a>

1. Appuyez sur le cercle contenant les initiales du compte e-mail consulté ou l'icône de maison (<code className="action">⌂</code>) dans la partie supérieure gauche de votre écran.
1. Appuyez sur l'engrenage (<code className="action">⛭</code>) dans la partie inférieure gauche de votre écran.
1. Appuyez ensuite sur <code className="action">Comptes</code> dans le menu **Réglages**.
1. Sélectionnez le compte concerné.
1. Appuyez sur <code className="action">Modifier les informations de connexion</code>.

<img className="thumbnail" alt="outlook ios" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-ios/outlook-app-ios-modify-01.png" loading="lazy" />

Retrouvez les paramètres à **l'étape 3** du chapitre « [Ajouter le compte](#add-account) ».

### Comment supprimer un compte e-mail ? <a name="delete-account"></a>

1. Appuyez sur le cercle contenant les initiales du compte e-mail consulté ou l'icône de maison (<code className="action">⌂</code>) dans la partie supérieure gauche de votre écran.
1. Appuyez sur l'engrenage (<code className="action">⛭</code>) dans la partie inférieure gauche de votre écran.
1. Appuyez ensuite sur <code className="action">Comptes</code> dans le menu **Réglages**.
1. Sélectionnez le compte concerné.
1. Appuyez sur <code className="action">Suppression du compte</code>.

<img className="thumbnail" alt="outlook ios" src="/images/web-cloud/email-and-collaborative-solutions/zimbra/zimbra-outlook-app-ios/outlook-app-ios-delete-01.png" loading="lazy" />
