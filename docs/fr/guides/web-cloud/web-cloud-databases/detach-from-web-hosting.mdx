## Objectif

Les solutions [Web Cloud Databases](https://www.ovhcloud.com/fr/web-cloud/databases/) peuvent être activées gratuitement à partir de nos [offres d'hébergement web Performance](https://www.ovhcloud.com/fr/web-hosting/). Dans ce cas de figure, elles sont alors associées à l'hébergement web depuis lesquelles elles ont été activées. Au cours de l'utilisation de vos services, vous pouvez être amenés à devoir délier votre solution Web Cloud Databases de l'hébergement web Performance auquel elle est associée.

**Découvrez comment délier votre solution Web Cloud Databases d'un hébergement web.**

## Prérequis

- Disposer d'une [instance Web Cloud Databases](https://www.ovhcloud.com/fr/web-cloud/databases/) associée à une offre d'[hébergement web Performance](https://www.ovhcloud.com/fr/web-hosting/).
- Être, a minima, contact « [Administrateur](/guides/account-and-service-management/account-information/managing-contacts/) » des services sur lesquels vous souhaitez agir.

### Accès à l'espace client OVHcloud

- **Lien direct :** [Hébergements](https://manager.eu.ovhcloud.com/#/web/hosting)
- **Pour accéder à vos services :** <code className="action">Web Cloud</code> > <code className="action">Hébergements</code> > Sélectionnez votre hébergement web

## En pratique

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **3** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page [Hébergements](https://manager.eu.ovhcloud.com/#/web/hosting), puis choisissez l'hébergement web concerné.
    
    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans le cadre **Configuration** vous trouverez la mention **Web Cloud Databases**. Cliquez sur le bouton <code className="action">...</code> à droite puis sur <code className="action">Délier</code>.
    
    <img className="thumbnail" alt="Detach Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Sur la nouvelle page qui s'affiche, choisissez la nouvelle tarification désirée pour votre solution Web Cloud Databases, puis suivez les étapes indiquées jusqu'au paiement.
    
    <img className="thumbnail" alt="Detach Web Cloud Databases" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/detach-my-web-cloud-databases.png" loading="lazy" />
  </Tab>
</Tabs>


Un fois les 4 étapes réalisées, votre solution Web Cloud Databases sera déliée dans un délai de quelques heures maximum.
