## Objectif

Les solutions [Web Cloud Databases](/links/web/databases) peuvent être activées gratuitement à partir de nos [offres d'hébergement web Performance](/links/web/hosting). Dans ce cas de figure, elles sont alors associées à l'hébergement web depuis lesquelles elles ont été activées. Au cours de l'utilisation de vos services, vous pouvez être amenés à devoir délier votre solution Web Cloud Databases de l'hébergement web Performance auquel elle est associée.

**Découvrez comment délier votre solution Web Cloud Databases d'un hébergement web.**

## Prérequis

- Disposer d'une [instance Web Cloud Databases](/links/web/databases) associée à une offre d'[hébergement web Performance](/links/web/hosting).
- Être connecté à votre [espace client OVHcloud](/links/manager).
- Être, a minima, contact « [Administrateur](/guides/account-and-service-management/account-information/managing-contacts) » des services sur lesquels vous souhaitez agir.

## En pratique

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
<Tab label="Etape 1">

Connectez-vous à votre [espace client OVHcloud](/links/manager), puis rendez-vous dans la partie `Web Cloud`.

![Web Cloud](/images/assets/screens/control-panel/product-selection/web-cloud.png)

</Tab>
<Tab label="Etape 2">

Cliquez sur le menu `Hébergements`, puis choisissez l'hébergement web concerné.

![Web Hosting](/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png)

</Tab>
<Tab label="Etape 3">

Dans le cadre **Configuration** vous trouverez la mention **Web Cloud Databases**. Cliquez sur le bouton `...` à droite puis sur `Délier`.

![Detach Web Cloud Databases](/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/wcdb-detach.png)

</Tab>
<Tab label="Etape 4">

Sur la nouvelle page qui s'affiche, choisissez la nouvelle tarification désirée pour votre solution Web Cloud Databases, puis suivez les étapes indiquées jusqu'au paiement.

![Detach Web Cloud Databases](/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/detach-my-web-cloud-databases.png)

</Tab>
</Tabs>
