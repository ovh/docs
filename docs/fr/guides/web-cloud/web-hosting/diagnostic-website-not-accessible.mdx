## En pratique

### 1 : Vérifier la validité de votre nom de domaine

:::warning
Le renouvellement de vos offres est sous votre entière responsabilité.<br/>
OVHcloud, en tant qu'hébergeur, a l'obligation de supprimer définitivement les services (domaines, hébergements, e-mails, etc.) qui n'ont pas été renouvelés à temps, ainsi que l'ensemble des données qu'ils contiennent.

De ce fait, nous vous recommandons fortement d'activer le [renouvellement automatique](/guides/account-and-service-management/managing-billing-payments-and-services/how-to-use-automatic-renewal#en-pratique/) sur l'ensemble de vos abonnements OVHcloud.

:::


Pour vérifier la validité de l'abonnement relatif à votre nom de domaine, cliquez sur votre nom en haut à droite de votre [espace client](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr), afin de faire apparaître le menu contextuel, puis sur <code className="action">Mes offres & services</code>.

<img className="thumbnail" alt="control-panel" src="/images/assets/screens/control-panel/product-selection/right-menu/my-solutions-and-services.png" loading="lazy" />|

Renouvelez votre domaine si nécessaire via le bouton <code className="action">...</code> à droite de l'écran, puis <code className="action">Renouveler le service</code>.

<img className="thumbnail" alt="renew-service-button" src="/images/assets/screens/control-panel/product-selection/web-cloud/order/renew-service-button.png" loading="lazy" />

Suite à ce renouvellement, votre site sera accessible sous 48 heures maximum.

### 2 : Vérifier les serveurs DNS

Pour vérifier la validité de vos [serveurs DNS](/guides/web-cloud/domains/dns-server-edit/), dans votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr) cliquez sur <code className="action">Noms de domaine</code>, puis sur le domaine de votre site.

#### Scénario 1 : Aucune anomalie sur les serveurs DNS

Vérifiez les serveurs indiqués dans l'onglet <code className="action">Serveurs DNS</code> :

<img className="thumbnail" alt="srv-dns-ok2" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/name-dns-server.png" loading="lazy" />

S'ils sont identiques aux cibles des entrées de type `NS` dans la <code className="action">Zone DNS</code>, passez à [l'étape 3](#etape3) :

<img className="thumbnail" alt="srv-dns-ok" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/dashboard-entry-ns.png" loading="lazy" />

#### Scénario 2 : Un avertissement apparaît au-dessus de la zone DNS

Un avertissement dans l'onglet <code className="action">Zone DNS</code> indique que les serveurs DNS utilisés par votre domaine ne sont pas ceux indiqués dans votre zone. Deux scénarios sont ici possibles :

- Sous la phrase « Vous utilisez actuellement les serveurs DNS suivants : », les serveurs indiqués sont du type « ns **?** .ovh.net » et « dns **?** .ovh.net » (remplacez le « **?** » par n'importe quel numéro) :

<img className="thumbnail" alt="warning_other_ovh_dns_srv" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/message-other-ovh-dns-servers.png" loading="lazy" />

Modifiez les serveurs DNS en suivant les instructions de [ce guide](/guides/web-cloud/domains/dns-server-edit/), afin qu'ils soient identiques aux cibles des entrées de type `NS` dans la <code className="action">Zone DNS</code>.

Votre site sera de nouveau accessible sous 48 heures maximum.

- Sous la phrase « Vous utilisez actuellement les serveurs DNS suivants : », les serveurs indiqués ne sont pas du type « ns **?** .ovh.net » et « dns **?** .ovh.net ».

<img className="thumbnail" alt="warning_external_dns_srv" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/message-external-dns-servers.png" loading="lazy" />

:::warning
Dans cette situation, contactez l'hébergeur de votre Zone DNS, votre webmaster ou les [partenaires OVHcloud](https://partner.ovhcloud.com/fr/directory/) avant toute manipulation.

Il est en effet possible que les serveurs DNS utilisés par votre nom de domaine soient fonctionnels et que le problème d'accès à votre site soit lié à une entrée manquante ou erronée dans la [zone DNS](/guides/web-cloud/domains/dns-zone-general-information/). Toute modification des serveurs DNS dans cette situation peut rendre vos adresses e-mails ou d'autres applications en ligne indisponibles.

:::


#### Scénario 3 : Aucune entrée de type NS n'apparaît dans la zone DNS

La <code className="action">Zone DNS</code> de votre domaine ne contient pas d'entrée de type `NS` :

<img className="thumbnail" alt="srv_dns_missing" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/dashboard-entry-ns-missing.png" loading="lazy" />

Effectuez une sauvegarde de la zone actuelle en cliquant sur le bouton <code className="action">Modifier en mode textuel</code> à droite de votre écran :

<img className="thumbnail" alt="change_DNS_zone_change_text_format" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/change-in-text-format.png" loading="lazy" />

Puis copiez/collez le contenu de votre <code className="action">Zone DNS</code> dans un document texte. Enregistrez localement ce document.

Cliquez ensuite sur <code className="action">Réinitialiser ma zone DNS</code>, puis sélectionnez <code className="action">Non, mais je veux réinitialiser ma zone DNS</code>, indiquez vos serveurs e-mail et d'hébergement et cliquez sur <code className="action">Valider</code>.

<img className="thumbnail" alt="change_DNS_zone_reset" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/reset-my-dns-zone.png" loading="lazy" />

Votre site sera de nouveau accessible sous 24 heures maximum.

### 3 : Vérifier la zone DNS <a name="etape3"></a>

Dans cette étape, vous allez retrouver l'adresse IP de votre hébergement, puis l'ajouter à votre <code className="action">Zone DNS</code>.

Si votre site est hébergé en dehors de l'infrastructure OVHcloud ou géré par une tierce personne, contactez l'hébergeur ou le prestataire concerné.

Si votre site est hébergé sur l'une de nos [offres d'hébergement web](https://www.ovhcloud.com/fr/web-hosting/), cliquez sur les onglets ci-dessous pour afficher successivement chacune des **2** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page [Hébergements](https://manager.eu.ovhcloud.com/#/web/hosting), puis choisissez l'hébergement web concerné.
    
    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans le cadre **Informations générales**, vous trouverez les mentions **IPv4** et **IPv6**.
    
    <img className="thumbnail" alt="IPv4-IPv6" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-ipv4-and-ipv6.png" loading="lazy" />

Copiez l'adresse IPV4 et/ou IPV6 de votre domaine.
  </Tab>
</Tabs>


Puis reportez-la dans la [zone DNS](/guides/web-cloud/domains/dns-zone-edit/) de votre domaine, en modifiant ou créant une ou plusieurs entrées de type `A`.

<img className="thumbnail" alt="ipv4-DNSzone" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-zone/dashboard-entry-a.png" loading="lazy" />

Votre site sera de nouveau accessible sous 24 heures maximum.
