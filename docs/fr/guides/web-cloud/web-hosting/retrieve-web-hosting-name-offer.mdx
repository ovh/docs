## Objectif

Vous ne vous souvenez plus du nom de votre [offre d'hébergement web](https://www.ovhcloud.com/fr/web-hosting/) ?
Vous souhaitez consulter ses détails ou la comparer à une autre offre ?

Au cours de l'utilisation de vos services, vous pourriez avoir besoin du nom de votre offre d’hébergement web.

**Découvrez comment identifier le type d'offre d'hébergement web dont vous disposez depuis votre espace client OVHcloud.**

## Prérequis

- Disposer d'une [offre d'hébergement web](https://www.ovhcloud.com/fr/web-hosting/).

{/* CP-NAV-START:web-hosting */}
---

### Accès à l'espace client OVHcloud

- **Lien direct :** [Hébergements](https://manager.eu.ovhcloud.com/#/web/hosting)
- **Pour accéder à vos services :** <code className="action">Web Cloud</code> > <code className="action">Hébergements</code> > Sélectionnez votre hébergement web

---
{/* CP-NAV-END:web-hosting */}

## En pratique

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **2** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page [Hébergements](https://manager.eu.ovhcloud.com/#/web/hosting), puis choisissez l'hébergement web concerné.
    
    <img className="thumbnail" alt="Web Hosting" src="/images/assets/screens/control-panel/product-selection/web-cloud/hosting-plans.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Dans le cadre **Abonnement**, vous trouverez la mention **Offre**.
    
    <img className="thumbnail" alt="Plan" src="/images/assets/screens/control-panel/product-selection/web-cloud/web-hosting/general-information/find-plan-pro.png" loading="lazy" />

Sous cette mention, vous retrouverez le nom de votre offre d'hébergement web (par exemple : Perso, Pro, Performance, etc.).
  </Tab>
</Tabs>
