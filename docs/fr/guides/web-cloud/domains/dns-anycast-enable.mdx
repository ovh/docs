## Objectif 

Vous avez besoin que vos services (par exemple : votre site web) soient accessibles en un temps record sur l'ensemble du globe ? Vous souhaitez que la résolution DNS de votre nom de domaine soit optimisée ?
OVHcloud vous propose l'option [DNS Anycast](https://www.ovhcloud.com/fr/domains/options/dns-anycast/).

**Découvrez comment accélérer l'accès à vos services web grâce à la vitesse de résolution DNS offerte par l’option DNS Anycast de votre nom de domaine.**

## Prérequis

- Disposer d’un [nom de domaine](https://www.ovhcloud.com/fr/domains/).
- Le nom de domaine concerné doit posséder une extension compatible avec l'option DNS Anycast.

{/* CP-NAV-START:web-domains */}
---

### Accès à l'espace client OVHcloud

- **Lien direct :** [Noms de domaine](https://manager.eu.ovhcloud.com/#/web-domains/domain)
- **Pour accéder à vos services :** <code className="action">Web Cloud</code> > <code className="action">Noms de domaine</code> > Sélectionnez votre nom de domaine

## En pratique

Cliquez sur les onglets ci-dessous pour afficher successivement chacune des **4** étapes.

<Tabs>
  <Tab label="Étape 1">
    Accédez à la page [Noms de domaine](https://manager.eu.ovhcloud.com/#/web-domains/domain), puis choisissez le nom de domaine concerné.
    
    <img className="thumbnail" alt="Domain Names" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-names.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 2">
    Sélectionnez l'onglet <code className="action">Serveurs DNS</code> une fois positionné sur le domaine concerné.
    
    <img className="thumbnail" alt="DNS Servers" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 3">
    Sur la page qui s'affiche, cliquez sur le bouton <code className="action">Commander DNS Anycast</code>.
    
    <img className="thumbnail" alt="Order Anycast DNS" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/order-anycast-dns.png" loading="lazy" />
  </Tab>
  <Tab label="Étape 4">
    Sur la nouvelle page qui s'affiche :
    
    - Choisissez la durée proposée dans la section `1` et cliquez sur <code className="action">suivant</code>.
    - Sélectionnez votre moyen de paiement puis cliquez sur <code className="action">Payer</code> pour poursuivre l'activation des DNS Anycast.
    
    <img className="thumbnail" alt="Order Anycast DNS step 2" src="/images/assets/screens/control-panel/product-selection/web-cloud/domain-dns/dns-servers/order-anycast-dns-step-2.png" loading="lazy" />

Dans le message qui apparaît ensuite en vert, cliquez sur le bouton <code className="action">Bon de commande</code> pour être redirigé vers le bon de commande d'activation de l'option DNS Anycast.
    
    Dès que vous êtes sur le bon de commande, poursuivez jusqu'à sa validation à l'aide d'un moyen de paiement pour finaliser la prise en compte de la commande.
  </Tab>
</Tabs>


L'activation de l'option DNS Anycast peut prendre plusieurs minutes.
