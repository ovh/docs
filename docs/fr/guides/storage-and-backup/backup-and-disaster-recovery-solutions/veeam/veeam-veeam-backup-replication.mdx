## Objectif

Veeam Backup & Replication est un logiciel de protection des données. Il offre diverses possibilités de sauvegarde, de réplication et de restauration.

**Apprenez à installer un serveur Veeam Backup & Replication, puis à l'enregistrer auprès du serveur de licences Veeam Enterprise de OVHcloud.**

:::warning
Si une machine virtuelle est protégée à l'aide de plusieurs méthodes de sauvegarde (par exemple [VM backup](https://helpcenter.veeam.com/docs/vbr/qsg/vm_backup.html?ver=13) et [Agent backup](https://helpcenter.veeam.com/docs/vbr/userguide/protect_comp.html?ver=13)), chaque méthode consomme une licence distincte et est facturée indépendamment.

Pour éviter des frais supplémentaires, protégez chaque machine virtuelle en utilisant **une seule méthode de sauvegarde**.

:::


## Prérequis

- Posséder une [offre Veeam Enterprise](https://www.ovhcloud.com/fr/storage-solutions/veeam-enterprise/).
- Avoir à disposition une machine Windows Server 2012 ou une version plus récente.
- Utiliser Veeam Backup & Replication v12.3 ou une version antérieure.

## En pratique

### Installer Veeam Backup & Replication

Téléchargez la solution **Veeam Backup & Replication** depuis le site de [Veeam](https://www.veeam.com/downloads.html?ad=top-sub-menu). Si vous n'avez pas de compte, il sera nécessaire d'en créer un (celui-ci est gratuit).

Le fichier se présente sous la forme d'une image disque au format ISO. Après l'avoir transférée sur votre serveur, sélectionnez le lecteur CD de la machine puis choisissez l'image.

Dans la machine, vous pouvez désormais lancer l'installeur. Sélectionnez alors <code className="action">Veeam Backup & Replication Install</code>.

<img className="thumbnail" alt="installation Veeam" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeamBandR_inst_01.png" loading="lazy" />

Après l'avoir lu, acceptez le contrat de licence en choisissant <code className="action">Next</code>.

<img className="thumbnail" alt="contrat de licence" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeamBandR_inst_02.png" loading="lazy" />

Passez l'étape de renseignement du fichier de licence avec <code className="action">Next</code>.

<img className="thumbnail" alt="fichier de licence" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeamBandR_inst_03.png" loading="lazy" />

Dans l'étape de sélection des composants à installer, ne modifiez rien. Selon vos besoins, vous pouvez cependant changer le chemin de destination de l'installation. Validez ensuite avec <code className="action">Next</code>.

L'installateur va maintenant effectuer un contrôle des prérequis. Si vous partez d'une installation brute de Windows, certains composants seront absents. Mais pas de panique : l'installeur téléchargera et installera ceux-ci automatiquement. Validez ensuite avec <code className="action">Next</code>.

<img className="thumbnail" alt="validation" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeamBandR_inst_05.png" loading="lazy" />

### Créer un compte de service Veeam Enterprise

#### Étape 1 - Lancer un compte de service

Au préalable, il est nécessaire de générer un mot de passe **complexe**.

Pour commencer, lancez Windows Powershell en tant qu'administrateur.

Créez ensuite un compte de service, en entrant ces lignes de commande :

```powershell
New-LocalUser "OVHVeeamEnterprise" -Password (ConvertTo-SecureString -AsPlainText "P@ssword01" -Force) -Description "OVH Service Account for Veeam Enterprise" -PasswordNeverExpires:$true -UserMayNotChangePassword:$true -AccountNeverExpires:$true
```

Notez que le nom du compte et le mot de passe correspondent à un exemple et doivent être remplacés :

* Nom du compte : OVHVeeamEnterprise
* Mot de passe : P@ssword01

<img className="thumbnail" alt="users and roles" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeamBandR_conf_2.png" loading="lazy" />

####  Étape 3 - Autorisations d'exécution et d'activation

L'utilisateur OVHVeeamEntreprise est accessible uniquement en local, il faut donc ajouter les permissions dans l’interface graphique d’utilisateur Windows pour l'activation de la connexion à distance.

Via l’interface graphique d’utilisateur :

1. Dans votre barre de recherche Windows, tapez <code className="action">Services de composants</code> et lancez le service.
2. Dans le menu à gauche et suivant l'arborescence, cliquez sur <code className="action">Services de composants</code>, puis <code className="action">Ordinateurs</code>, puis <code className="action">Poste de travail</code>.
3. À droite, sous l'onglet <code className="action">Actions</code>, cliquez sur <code className="action">Autres actions</code> puis sur <code className="action">Propriétés</code>.
4. Allez dans <code className="action">Sécurité COM</code> et sous la deuxième option <code className="action">Autorisations d'exécution d'activation</code>, cliquez sur <code className="action">Modifier les limites</code>. Ensuite, cliquez sur <code className="action">Ajouter...</code>.

<img className="thumbnail" alt="Propriétés Autorisations d'exécution et d'activation" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeamuseradd.png" loading="lazy" />

<ol start="5">
  <li>Cliquez sur <code className="action">Avancé...</code> pour localiser le compte de service précédemment ajouté. Cliquez ensuite sur <code className="action">Rechercher</code> et sélectionnez l'utilisateur <code className="action">OVHVeeamEnterprise</code> dans la liste des utilisateurs.</li>
</ol>

<img className="thumbnail" alt="Propriétés Autorisations d'exécution et d'activation" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeamuseradd1.png" loading="lazy" />

<ol start="6">
  <li>Cliquez sur <code className="action">OK</code> pour confirmer la sélection et sur <code className="action">OK</code> pour valider. Ensuite, activez toutes les permissions sur l'utilisateur <code className="action">OVHVeeamEnterprise</code>.</li>
</ol>

<img className="thumbnail" alt="Autorisations de lancement et d'activation" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeamuseradd3.png" loading="lazy" />

<ol start="7">
  <li>Cliquez sur <code className="action">OK</code> pour confirmer et sur <code className="action">Appliquer</code> pour valider les changements.</li>
</ol>

Votre utilisateur OVHVeeamEntreprise est maintenant accessible en local et à distance.

###  Étape 4 - Enregistrer le serveur Veeam Backup

#### Depuis l'espace client OVHcloud

Connectez-vous à votre [espace client OVHcloud](https://www.ovh.com/auth/?onsuccess=https://manager.eu.ovhcloud.com/&from=https://www.ovh.com/fr/&ovhSubsidiary=fr), accédez à la section <code className="action">Hosted Private Cloud</code> et sélectionnez <code className="action">Plateformes et services</code>. Sélectionnez alors votre service **backupserverenterprise** puis cliquez sur <code className="action">Activer la licence</code> dans la section `Raccourcis`.

Pour configurer votre environnement, assurez-vous d'avoir ouvert les ports d'OVHcloud vers vos serveurs Veeam Backup and Replication :

- `Port 9392/TCP`
- `Port 9405/TCP`

<img className="thumbnail" alt="installation Veeam" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/architecture.png" loading="lazy" />

<img className="thumbnail" alt="espace client OVHcloud" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeam001.png" loading="lazy" />

Dans la nouvelle fenêtre, saisissez les informations suivantes :

- L'adresse IP publique par laquelle votre serveur **Veeam Backup & Replication** peut être contacté.
- Le login du compte de service précédemment créé.
- Le mot de passe du compte de service.

Puis validez avec <code className="action">OK</code>.

<img className="thumbnail" alt="activation licence" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeam03.png" loading="lazy" />

Lorsque l'activation est faite, vous retrouvez les informations principales sur la page du service.

<img className="thumbnail" alt="licence activée" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeam02.png" loading="lazy" />

**Mise à jour des identifiants de connexion depuis l'espace client** :

Pour mettre à jour vos identifiants de connexion, vous pouvez utiliser le bouton <code className="action">Mettre à jour mes informations</code>.

<img className="thumbnail" alt="Update 1" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeam_update_cred.png" loading="lazy" />

Dans la fenêtre qui s'affiche, renseignez l'`IP`, le `Nom d'utilisateur`, et le `Mot de passe`. 

Pour terminer, cliquez sur <code className="action">OK</code>.

<img className="thumbnail" alt="Update 2" src="/images/storage-and-backup/backup-and-disaster-recovery-solutions/veeam/veeam-veeam-backup-replication/veeam_update_cred_2.png" loading="lazy" />

#### Via l'API OVHcloud

D'abord, récupérez votre serviceName :

<Api version="v1" section="/veeam/veeamEnterprise" method="GET" route={"/veeam/veeamEnterprise"} />

Puis effectuez l'enregistrement :

<Api version="v1" section="/veeam/veeamEnterprise" method="POST" route={"/veeam/veeamEnterprise/\{serviceName\}/register"} />

Vous devez vous munir des informations suivantes :

- L'adresse IP publique par laquelle votre serveur **Veeam Backup & Replication** peut-etre contacté.
- Le port de votre Veeam Backup (usuellement **9392/TCP**)
- le login du compte de service précédemment crée
- le mot de passe du compte de service

Vous pouvez obtenir l'adresse IP publique utilisée par Veeam Enterprise pour contacter votre serveur **Veeam Backup & Replication** via :

<Api version="v1" section="/veeam/veeamEnterprise" method="GET" route={"/veeam/veeamEnterprise/\{serviceName\}"} />


:::info
L'activation de votre serveur Veeam Backup & Replication peut prendre plusieurs heures.

:::


**Mise à jour des identifiants de connexion depuis l'API** :
