## Utilisation de l'interface web
L'utilisation d'une interface web est le moyen le plus simple de modifier les droits des utilisateurs.

Vous devez d'abord sélectionner votre utilisateur.

<img className="thumbnail" alt="Ceph users" src="/images/storage-and-backup/block-storage/cloud-disk-array/ceph-change-user-rights/change_user_rights_1.png" loading="lazy" />

Il énumérera les droits actuels, par défaut il n'y a pas de droits.

<img className="thumbnail" alt="Ceph pool creation" src="/images/storage-and-backup/block-storage/cloud-disk-array/ceph-change-user-rights/change_user_rights_2.png" loading="lazy" />

Choisissons quelques droits pour notre utilisateur.

<img className="thumbnail" alt="Ceph pool creation" src="/images/storage-and-backup/block-storage/cloud-disk-array/ceph-change-user-rights/change_user_rights_3.png" loading="lazy" />

Comme d'habitude, le statut du cluster et la liste des tâches changent.

## Utiliser l'API

<Api version="v1" section="/dedicated/ceph" method="PUT" route={"/dedicated/ceph/\{serviceName\}/pool"} />


<Api version="v1" section="/dedicated/ceph" method="GET" route={"/dedicated/ceph/\{serviceName\}/user"} />

Exemple de résultat:

```bash
GET /dedicated/ceph/98d166d8-7c88-47b7-9cb6-63acd5a59c15/user
[
  {
    mdsCaps: "",
    monCaps: "allow r",
    serviceName: "98d166d8-7c88-47b7-9cb6-63acd5a59c15",
    name: "myuser"
    osdCaps: "allow class-read object_prefix rbd_children, allow rwx pool=mypool",
    key: "AQA9KpdXoBrDNhAAFCM7m/XOtmWh3LMSNlHVqw==",
  }
]
```
