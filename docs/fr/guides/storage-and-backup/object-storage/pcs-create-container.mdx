## Objectif

L'offre Object Storage pour Public Cloud propose une solution de stockage illimité avec une facturation simple et adaptée à vos besoins. Il existe de nombreux types de conteneurs d'objets :

- pour de l'hébergement statique (site web statique);
- pour de l'hébergement privé (Exemple : stockage de données personnelles);
- pour de l'hébergement public (pour stocker tout ce qui est accessible au public);
- pour du stockage à froid (archivage).

La première étape est la création d’un conteneur qui regroupera vos fichiers.

**Ce guide explique comment le créer depuis l'espace client OVHcloud et depuis l’interface Horizon d’Openstack.**

## En pratique

### Création d'un conteneur Object Storage depuis l'espace client OVHcloud <a name="controlpanel"></a>

Cliquez sur <code className="action">Object Storage</code> dans la barre de navigation de gauche sous `Storage`, puis sur <code className="action">Create an object container</code>.

S'il s'agit de votre premier conteneur :

![pcs dashboard](/images/storage-and-backup/object-storage/pcs-create-container/create-container-20211005102334181.png)

Si vous avez déjà créé un/des conteneur(s) :

![pcs dashboard](/images/storage-and-backup/object-storage/pcs-create-container/create-container-20211005115040834.png)

Sélectionnez votre solution puis cliquez sur <code className="action">Next</code> :

![select your solution](/images/storage-and-backup/object-storage/pcs-create-container/create-container-20211005110710249.png)

Sélectionnez la région de votre conteneur, puis cliquez sur <code className="action">Next</code> :

![select a region](/images/storage-and-backup/object-storage/pcs-create-container/create-container-20211005110859551.png)

Sélectionnez le type de conteneur, puis cliquez sur <code className="action">Next</code> :

![select a type of container](/images/storage-and-backup/object-storage/pcs-create-container/create-container-20211005111542718.png)

Nommez votre conteneur, puis cliquez sur <code className="action">Create the container</code> :

:::warning
Si vous souhaitez lier votre conteneur à un nom de domaine, le nom de votre conteneur ne doit pas contenir les caractères suivants :

- [ . ]  
- [ _ ]  
- et vous ne devez pas utiliser de majuscules.  

Pour plus d'informations, consultez notre guide « [Lier un conteneur a un nom de domaine](/guides/storage-and-backup/object-storage/pcs-link-domain/) ».

:::


![container name](/images/storage-and-backup/object-storage/pcs-create-container/create-container-20211005111805966.png)

Votre conteneur est créé :

![container created](/images/storage-and-backup/object-storage/pcs-create-container/create-container-20211005112013807.png)

### Création d'un conteneur Object Storage depuis Horizon <a name="horizon"></a>

:::info
Il n'est pas possible de créer un conteneur Public Cloud Archive depuis Horizon

:::


Connectez-vous à votre [espace Horizon](https://horizon.cloud.ovh.net) :

![horizon login](/images/storage-and-backup/object-storage/pcs-create-container/create-container-20211005155245752.png)

Développez le menu <code className="action">Object Store</code>, cliquez sur <code className="action">Containers</code> puis sur <code className="action">+ Container</code>

![Horizon containers](/images/storage-and-backup/object-storage/pcs-create-container/create-container-20211005155704887.png)

Nommez votre conteneur.

:::warning
Si vous souhaitez lier votre conteneur à un nom de domaine, le nom de votre conteneur ne doit pas contenir les caractères suivants :

- [ . ]  
- [ _ ]  
- et vous ne devez pas utiliser de majuscules.  

Pour plus d'informations, consultez notre guide « [Lier un conteneur a un nom de domaine](/guides/storage-and-backup/object-storage/pcs-link-domain/) ».

:::


Sélectionnez la politique d'accès de votre conteneur puis cliquez sur <code className="action">Suivant</code>

![horizon create container](/images/storage-and-backup/object-storage/pcs-create-container/create-container-20211005155824902.png)

Votre conteneur est créé.

![horizon container created](/images/storage-and-backup/object-storage/pcs-create-container/create-container-20211005155936971.png)

Vous pouvez également le voir dans votre espace client OVHcloud :

![pcs dashboard](/images/storage-and-backup/object-storage/pcs-create-container/create-container-20211005160503200.png)
