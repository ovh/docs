## Objectif

Owncloud est une suite de logiciels client-serveur pour créer et utiliser des services d'hébergement de fichiers.

**Ce guide explique comment configurer le stockage dans Owncloud pour utiliser un bucket Object Storage.**

:::warning
OVHcloud met à votre disposition des services dont la configuration, la gestion et la responsabilité vous incombent. Il vous revient de ce fait d'en assurer le bon fonctionnement.

Nous mettons à votre disposition ce guide afin de vous accompagner au mieux sur des tâches courantes. Néanmoins, nous vous recommandons de faire appel à un [prestataire spécialisé](https://partner.ovhcloud.com/fr/directory/) et/ou de contacter l'éditeur du logiciel si vous éprouvez des difficultés. En effet, nous ne serons pas en mesure de vous fournir une assistance. Plus d'informations dans la section « Aller plus loin » de ce guide.

:::


## Prérequis

- Avoir créé un bucket
- Avoir créé un utilisateur et avoir défini les droits d'accès requis sur le bucket
- Connaître vos informations d'identification Object Storage (access_key et secret_access_key).

Consultez notre guide « [Débuter avec Object Storage](/guides/storage-and-backup/object-storage/s3-getting-started-with-object-storage/) » pour plus de détails.

:::info
Afin d'identifier votre Endpoint correspondant à votre classe de stockage, veuillez vous référer à ce guide : [Object Storage - Endpoints et géo-disponibilité de l’Object Storage](/guides/storage-and-backup/object-storage/s3-location/)

:::


## En pratique

Si besoin, installez le plugin `External Storage: S3` depuis le <code className="action">Market</code>.

<img className="thumbnail" alt="Owncloud open Market" src="/images/storage-and-backup/object-storage/s3-owncloud/HighPerf-Owncloud-20211209131331778.png" loading="lazy" />

Recherchez le plugin `External Storage: S3`.

<img className="thumbnail" alt="Owncloud plugin External Storage S3" src="/images/storage-and-backup/object-storage/s3-owncloud/HighPerf-Owncloud-20211209131556714.png" loading="lazy" />

Puis installez le plugin.

<img className="thumbnail" alt="Owncloud install plugin" src="/images/storage-and-backup/object-storage/s3-owncloud/HighPerf-Owncloud-20211209131648711.png" loading="lazy" />

Rendez-vous dans les <code className="action">Paramètres</code>.

<img className="thumbnail" alt="Owncloud open Settings" src="/images/storage-and-backup/object-storage/s3-owncloud/HighPerf-Owncloud-20211209131942821.png" loading="lazy" />

Puis :

1. dans <code className="action">Storage</code>
2. activez <code className="action">Enable external storage </code>
3. nommez votre dossier
4. ajoutez un stockage de type <code className="action">Amazon S3 compatible (SDK v3)</code>

<img className="thumbnail" alt="Owncloud create AWS S3 storage" src="/images/storage-and-backup/object-storage/s3-owncloud/HighPerf-Owncloud-20211209143008822.png" loading="lazy" />

Renseignez les informations suivantes :

1. Indiquez le nom de votre bucket
2. Définissez l'hôte comme tel : `s3.<region_in_lowercase>.io.cloud.ovh.net`
3. Définissez le port : 443
4. Indiquez la région
5. Activez SSL
6. Renseignez votre clé d'accès
7. Renseignez votre clé secrète

<img className="thumbnail" alt="Owncloud complete AWS S3 storage" src="/images/storage-and-backup/object-storage/s3-owncloud/HighPerf-Owncloud-20211209133630272.png" loading="lazy" />

Allez dans <code className="action">Files</code>.

<img className="thumbnail" alt="Owncloud open Files" src="/images/storage-and-backup/object-storage/s3-owncloud/HighPerf-Owncloud-20211209133730832.png" loading="lazy" />

Puis dans <code className="action">External storage</code>.

<img className="thumbnail" alt="Owncloud Files External Storage" src="/images/storage-and-backup/object-storage/s3-owncloud/HighPerf-Owncloud-2021120913382299.png" loading="lazy" />

Voici le résultat que vous devez obtenir :

<img className="thumbnail" alt="Owncloud Bucket listing" src="/images/storage-and-backup/object-storage/s3-owncloud/HighPerf-Owncloud-20211209140757288.png" loading="lazy" />
