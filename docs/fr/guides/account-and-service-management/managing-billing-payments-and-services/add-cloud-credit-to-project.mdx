## Objectif

L'option de « crédit cloud » vous permet d'allouer un montant spécifique à votre projet Public Cloud, qui servira de moyen de paiement par défaut pour la [facturation de votre projet](/guides/public-cloud/public-cloud-cross-functional/analyze-billing/).<br/>
Cela signifie que ce crédit cloud est débité en premier et que toute dette sera ensuite payée par les autres moyens de paiement disponibles. N’hésitez pas à consulter les [guides de facturation de Public Cloud](/guides/account-and-service-management/managing-billing-payments-and-services/getting-started/) pour en savoir plus sur le sujet.

**Ce guide vous explique comment ajouter du crédit sur votre compte Public Cloud à l’aide d’un voucher ou via la génération d’un bon de commande.**

## Prérequis

- Un projet [Public Cloud](https://www.ovhcloud.com/fr/public-cloud/) dans votre compte OVHcloud

## En pratique

Ouvrez <code className="action">Crédits & Vouchers</code> dans le menu de gauche sous **Paramètres**.

:::warning
Notez que les crédits ajoutés dans cette section ne peuvent pas être transférés ni remboursés. Il n'ont aucune valeur monétaire et tout crédit non utilisé dans les 13 mois suivant son achat est perdu.

:::


### Ajouter du crédit

Cliquez sur le bouton <code className="action">Acheter du crédit cloud</code>.

<img className="thumbnail" alt="addpubliccloudcredit" src="/images/account-and-service-management/managing-billing-payments-and-services/add-cloud-credit-to-project/cloudcredit1.png" loading="lazy" />

Renseignez le montant (HT) que vous souhaitez ajouter, dans votre devise. Cliquez sur <code className="action">Générer un bon de commande</code> pour valider.

<img className="thumbnail" alt="addpubliccloudcredit" src="/images/account-and-service-management/managing-billing-payments-and-services/add-cloud-credit-to-project/cloudcredit2.png" loading="lazy" />

Un bon de commande sera alors généré. Cliquez sur le lien dans le cadre vert de notification pour le consulter et initier le paiement.

<img className="thumbnail" alt="addpubliccloudcredit" src="/images/account-and-service-management/managing-billing-payments-and-services/add-cloud-credit-to-project/cloudcredit3.png" loading="lazy" />

Une fois le paiement effectué, votre crédit apparaîtra dans la liste `Crédits & Vouchers`.

### Utiliser un voucher

Cliquez sur le bouton <code className="action">Activer un voucher</code>.

<img className="thumbnail" alt="addpubliccloudcredit" src="/images/account-and-service-management/managing-billing-payments-and-services/add-cloud-credit-to-project/voucher1.png" loading="lazy" />

Dans la fenêtre qui apparaît, renseignez le code du voucher et cliquez sur <code className="action">Valider</code>.

<img className="thumbnail" alt="addpubliccloudcredit" src="/images/account-and-service-management/managing-billing-payments-and-services/add-cloud-credit-to-project/voucher2.png" loading="lazy" />

Le solde du voucher apparaîtra dans la liste `Crédits & Vouchers`.

:::info
Les périodes de validité des vouchers étant généralement plus limitées, le solde du voucher sera utilisé avant le crédit Public Cloud.

:::
